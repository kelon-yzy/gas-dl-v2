# Phase 0 物理可行性核对记录

> 依据 [`传感器仿真对齐改造计划.md`](传感器仿真对齐改造计划.md) Phase 0 执行。
> 核对日期：2026-07-02
> 方法：不改代码，直接调用 `src/sim/generation/acoustic_physics.py::hidden_attenuation_v2` 计算 40 kHz vs 200 kHz 衰减与回波 SNR。

## 1 核对方法

- 衰减模型：`hidden_attenuation_v2`，返回 `alpha_true`（Np/m），振幅衰减 `exp(-αL)`。
- 信号峰值：脉冲归一化到 1.0 V（`transducer_response_pulse` 除以 peak），`amp_scale = exp(-αL)`，故信号峰值 = `exp(-αL)` V。
- 噪声：`WaveformSpec.noise_std_v = 1e-3` V。
- SNR = `20·log10(exp(-αL) / 1e-3)` dB。
- 可用判据：SNR ≥ 20 dB（即信号 ≥ 10× 噪声）。
- 环境基准：T=25°C、P=0.5 MPa、RH=50%（另核对高温/高湿/低压端 35°C/80%/0.10MPa）。
- 声程：L=0.2/0.5/1.0/1.8 m（实际 LHS 采样范围 0.2~1.8 m）。

### 2.5 daq_full_scale_v 量程推荐

200 kHz 下最短声程/低衰减气样（H₂ 50%/N₂ 50%, L=0.2m）信号峰值 = 0.913 V。脉冲峰值上限 ≤ 1.0 V。

- **±2.5 V**：信号占满量程 36.5%，20-bit LSB = 4.77 μV，分辨率最优，留 2.5× 余量。**推荐**。
- ±5.0 V：信号占满量程 18.3%，20-bit LSB = 9.54 μV（当前默认，可保留但分辨率减半）。

## 3 结论

**200 kHz 在当前声程范围（0.2~1.8 m）与组分范围（CH₄≥40%）下不可用。**

- 物理原因：CH₄/CO₂ 振动弛豫吸收在 200 kHz 接近峰值，叠加经典吸收 ∝f² 放大，导致 CH₄ 主导气样在 L≥0.5m 信号被完全吸收。这是真实物理现象，非模型误差。
- 弛豫常数（`alpha_lambda_max_*`、`f_relax_*`）为标准 Bass 文献值，量级合理，重标定无法改变结论（预案 B/C 无效）。
- H₂ 扩散项不是主因（预案 B 不适用）。
- 唯一能让 200 kHz 可用的路径是缩短 L_m 至 ≤0.3m（预案 A），但这会：
  - 丢失 TOF 动态范围（TOF=L/c，L=0.3m 时 TOF≈0.4~0.9ms，vs 当前 0.3~2.5ms）；
  - 高 CO₂ 工况在 0.3m 仍临界；
  - 声学通道对组分（尤其 H₂/CH₄ 对比）的区分能力大幅下降。

**触发计划 §0.3 卡点**：结论为"200 kHz 下信号不可用且无法通过调参挽救"，停止后续阶段，回到附录 A.3 问题 1 重新决策。

## 4 重新决策选项

| 选项                            | 说明                                                        | 影响                             |
| ----------------------------- | --------------------------------------------------------- | ------------------------------ |
| A. 保留 40 kHz，标注与 PSC200K 不匹配  | 仿真频率不改，在文档明确声明 40 kHz 是设计选择，与硬件 PSC200K 200kHz 不一致；物理可行为先 | 超声通道物理可用，但仿真≠硬件频率，迁移实测数据需重新评估  |
| B. 缩短 L_m 至 ≤0.3m + 改 200 kHz | 保 200kHz 对齐硬件，但声程范围压缩                                     | TOF 动态范围丢失，声学通道区分力下降，高 CO₂ 仍临界 |
| C. 换超声型号假设为 40 kHz 器件         | 把硬件假设从 PSC200K(200k) 换成 40kHz 压电陶瓷（如通用工业级），仿真与硬件重新对齐      | 需更新硬件资料文档与附录 A，但物理一致           |
| D. 保留 200kHz，接受长声程信号丢失        | 仿真"物理诚实"地输出噪声                                             | 训练数据含大量无效波形，模型学不到声学特征，不可取      |

## 5 建议

推荐 **选项 A 或 C**（本质相同：承认 40 kHz 是该气体/声程下的合理频率）。

- 选项 A 改动最小（仅文档声明，不动代码），保留现有 462 测试与全部 benchmark。
- 选项 C 更彻底（同步修订硬件假设），但需确认是否有 40 kHz 工业超声换能器的实际采购计划。

Phase 1~5 在选项 A 下需相应调整：Phase 2（频率对齐）取消，Phase 3（20-bit ADC）仍可独立执行（NI-6453 20-bit 与频率无关）。
