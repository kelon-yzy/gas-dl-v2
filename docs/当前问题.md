# 当前问题跟踪

更新日期：2026-05-28。

| 问题 | 当前状态 | 后续处理 |
| --- | --- | --- |
| 声学衰减模型未显式表达 N2 对分子弛豫吸收的贡献 | 仍待增强。当前 `hidden_attenuation_v2(...)` 已标注为 `semi_empirical_relaxation_proxy_v1`，不是标准化 QARS/AGA/GERG 模型，也不是仪器标定模型。 | 中期改为可解释的多气体弛豫吸收模型，并把 N2 作为背景气体或碰撞弛豫项纳入参数。 |
| 慢变量中的 `TOF`、`Amp`、`f_peak`、`A_fft_max` 等声学参数不是从波形参数计算 | 部分解决。超声链路已显式落盘 `ultrasonic_tof_s`、`ultrasonic_peak_index`、`ultrasonic_sound_speed_m_per_s`、`ultrasonic_alpha_true_npm`；但 slow 旧字段仍不是由波形反演得到。 | 保留当前派生数组作为生成真值；后续若需要观测特征，应从 waveform 做峰值/相关/FFT 提取，生成 `tof_observed_s`、`tof_quality` 和频域质量指标。 |
| `ultrasonic` 与 `fiber_mic` 两路波形物理语义混淆，`fiber_mic` 作为声衰减链路却包含 TOF 类信息 | 短期已澄清。`manifest.json` 和 `metadata/waveform_spec.json` 记录 `ultrasonic_model = "simplified_tof_proxy_v1"`、`fiber_mic_model = "acoustic_proxy_v1"`、`fiber_optical_demodulation_model = "not_implemented"`。当前 `fiber_mic` 是光纤声学传感简化代理，不是完整光纤干涉解调链路。 | 中期新增 `fiber_interferometric_proxy_v1`，补光纤探头、干涉转导、光纤传输、光电解调、放大器和 DAQ 参数。 |

详细声学链路分析见 `docs/当前声学链路问题.md`。
