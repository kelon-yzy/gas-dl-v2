# 多传感器多组分气体检测算法创新深度调研报告

**调研日期：2026-08-24**

**定位：** 基于[项目总体规划](../general_fusion/项目总体规划.md)和 2024–2026 年文献，对候选算法进行领地核查、排序和最小证伪设计。本报告给出研究建议，不修改 P1 冻结门值。

## 1. 核心结论

“再设计一个更复杂的气体深度网络”已不是优先创新路线。GNN、Transformer、轻量网络、量化、普通知识蒸馏和多任务学习在混合气检测中均已有直接先例。

当前真正可保留的空档是：

- 用信息量、CRB 和 target–nuisance Jacobian 夹角描述问题难度；
- 根据观测状态选择算法、采样量和计算预算；
- 让收益同时体现在精度、计算效率或数据效率上；
- 先完成 P3 最小证伪，再决定是否进入 P4。

### 推荐排序（项目内部评分）

| 排名  | 候选                              | 分数  | 主要目标                 | 对应规划         |
| --- | ------------------------------- | ---:| -------------------- | ------------ |
| 1   | 信息条件化正则化 VarPro 展开网络 IC-RDU-VP  | 91  | 同精度下减少迭代和求解时间        | C2           |
| 2   | Fisher 信息驱动异构求解器路由 FIGS         | 89  | 按工况选择最合算的算法          | C1 + C2 + C5 |
| 3   | CRB 驱动自适应采样与 Early Exit         | 87  | 少测、少算、缩短测量时间         | C5           |
| 4   | 跨表示物理知识蒸馏 CR-PKD                | 84  | 用低成本输入接近原始波形模型       | C4 + C5      |
| 5   | Fisher 正交多模态 PLS-ELM FO-MPLSELM | 81  | 小数据、快速训练、抵抗 nuisance | C5 / 强基线     |

结论上，**IC-RDU-VP 与 FIGS 适合作为主创新线**；CRB 自适应采样承担效率线；CR-PKD 承担部署线；FO-MPLSELM 承担低风险轻量线和强基线角色。

## 2. 已占领领地与可保留空档

| 已有方向                    | 代表性先例                               | 项目边界                                          |
| ----------------------- | ----------------------------------- | --------------------------------------------- |
| GNN / Transformer 混合气检测 | GGCT、GACA                           | “Sensor–Gas 图 + GNN/Attention”不能单独作为创新        |
| 轻量网络、量化、动态响应编码          | PTQ-CNN、SADDCN-HFF、SDRMixer         | 只做更小 CNN/TCN/Transformer 不够                   |
| 普通知识蒸馏                  | GT-KANet 等                          | 普通 Teacher → Student KD 不够；跨信息源蒸馏仍可研究         |
| VarPro 与展开网络            | VPLR、TSVD/Ridge-VP、Deep-Unfolded VP | “VP + Deep Unfolding”已有先例；信息条件化、正则化和自适应深度仍有空间 |
| PLS-ELM、物理模块、多任务组合      | PLSELM、PI-MTL                       | 不能直接复制；可做项目特有的 Fisher 正交投影和效率评估               |

因此，本项目不应把“模型更大”作为主要假设，而应围绕可控 bench 回答：**什么信息条件下，哪种算法或测量策略真正更值得使用？**

## 3. 五个候选方向

### 3.1 C2：IC-RDU-VP

**机制：** 对模型 y = A(eta)c + r(eta) + epsilon 中的 nuisance 参数做 Variable Projection，并用 z = [I_eff, CRB, angle(J_x, J_eta), kappa(J)] 条件化正则化强度、Jacobian 近似和展开深度。

**可声明的窄创新：** 不是首次提出 VarPro 展开网络，而是根据有效信息量和目标–nuisance 可分离程度，自适应调整求解器。

**主收益轴：** 在 P90/RMSE 不劣于强基线的前提下，减少迭代步数和 wall-clock；精度收益作为次要指标。

**最小实验：** 3 档信息量 × 3 档 Jacobian 夹角，比较 Joint LM、Classical VP、VPLR、TSVD/Ridge-VP、固定深度展开和 IC-RDU-VP。记录误差、迭代、耗时、收敛失败率。

**停止条件：** 自适应条件化不能超过最佳固定 VP 的效率，或收益只来自真值 nuisance 泄漏，则淘汰。

### 3.2 C1 + C2 + C5：FIGS

**机制：** 建立轻量模型、VarPro 和深度模型组成的 solver portfolio，根据 g(I_eff, CRB, angle(J_x, J_eta), SNR, kappa) 选择求解器。第一版应采用物理规则路由，再用轻量模型修正，不直接做黑箱 MoE。

**可声明的窄创新：** 将 Fisher/CRB 和可辨识性几何用于多组分气体反演的算法选择，研究算法优势出现在哪个信息区域。

**主收益轴：** 以 C = L_error + lambda_t × t + lambda_e × E 衡量误差–计算成本，使平均代价低于固定使用单一最强模型。

**前置条件：** 至少两个专家必须在不同信息区域分别占优；如果一个 solver 在所有区域都最好，则不启动 FIGS。

### 3.3 C5：CRB 驱动自适应采样与 Early Exit

**机制：** 持续计算当前信息量、CRB 和单位成本增量信息 ΔI / ΔC。当 CRB 达标且新增采样的收益低于阈值时停止；也可采用“廉价声学 → 光学 → 完整波形”的逐级模态策略。

**主收益轴：** 测量时间、采样点数、激活传感器数和 FLOPs，同时保持 P90/RMSE 在目标带内。

**最小实验：** 比较完整采样、固定短窗口、uncertainty early exit、CRB early exit 和 CRB + 动态模态选择。

### 3.4 C4 + C5：CR-PKD

**机制：** Teacher 使用 raw acoustic + raw optical + slow sensors；Student 只使用 DSP 特征 + slow sensors，把“信息丰富的表示”蒸馏到“低成本输入”。蒸馏分三层：输出、物理 latent、Fisher 加权表示。

**边界：** 跨模态知识蒸馏已有先例，普通 Teacher → Student KD 不能作为创新；项目特有空间在 raw/DSP 表示差异和物理信息加权。

**最小实验：** 比较 raw teacher、DSP student、普通 KD 和 Physics/Fisher KD，报告误差、参数量、FLOPs、CPU 延迟和输入带宽。

**前置条件：** raw teacher 必须显著优于 DSP 强基线；否则不值得蒸馏。

### 3.5 C5 / 强基线：FO-MPLSELM

**机制：** 在 PLS-ELM 之前构造目标敏感、nuisance 不敏感的投影，优化“目标方向灵敏度 / nuisance 灵敏度与噪声”的比值，再将 acoustic、optical、slow 模态投影送入 Ensemble ELM。

**边界：** PLSELM 已有先例，不能直接复制；FO-MPLSELM 首先承担低成本强基线和数据效率评估，只有在固定误差下显著减少训练样本或计算量时才升级为算法创新。

**最小实验：** Ridge、PLS、ELM、PLSELM、XGBoost、轻量 CNN 与 FO-MPLSELM，在 10%–100% 训练数据下比较 learning curve、误差和训练时间。

## 4. 降级或暂不进入 P2/P3 主线的方向

| 方向                                   | 处置       | 原因                                           |
| ------------------------------------ | -------- | -------------------------------------------- |
| Physics Sensor–Gas GNN               | 降级       | GGCT/GACA 已覆盖图结构、注意力、辅助任务和低浓度叙事              |
| Physics-matched Filter + CNN         | 作为模块     | 目标谱导数卷积、双分支 CNN 已有先例，可嵌入 CR-PKD 或 FO-MPLSELM |
| Physics Residual MTL                 | 留至 P5    | 纯仿真中自注入、自去除 discrepancy 的证据强度不足，需要真实硬件数据     |
| 多速率 Masked Autoencoder               | 留至标签昂贵阶段 | 当前 MFC bench 标签相对便宜，SSL 的边际收益不明确             |
| Active Learning + Drift Compensation | 留至 P5    | 漂移补偿需要真实时间跨度和现场标定数据                          |

## 5. 推荐的验证顺序与论文主线

### P3 最小证伪顺序

1. **低成本：** FO-MPLSELM、Classical VP/VPLR/TSVD-VP、CRB 自适应采样仿真。
2. **条件化求解器：** 只有普通 VP 在部分 Jacobian 夹角档位存在明确 headroom，才实现 IC-RDU-VP。
3. **部署蒸馏：** 只有 raw teacher 优于 DSP 强基线，才实现 CR-PKD。
4. **求解器路由：** 只有至少两个 expert 在不同信息区域占优，才启动 FIGS。

### 论文组织

- **主论文：** IC-RDU-VP + FIGS，回答“不同信息状态下是否应使用不同复杂度的反演算法”。
- **效率线：** CRB Adaptive Sensing，回答“达到目标精度后是否可以少测、少算”。
- **部署线：** CR-PKD，回答“低成本输入能否继承原始波形中的有效信息”。
- **低风险线：** FO-MPLSELM，作为强基线、数据效率基准和轻量模型候选。

## 6. P2 bench 必须新增或明确的输出

除总体规划中的 S1–S6 外，bench 还必须支持：

1. **样本级 Fisher/CRB**，不能只有档位平均值；
2. **增量信息**，能够计算新增时间窗或新增模态带来的 ΔI；
3. **solver difficulty ground truth**，保存 iteration、convergence、condition number、residual 和 runtime；
4. **Raw + DSP 双数据层**，同时保存原始波形和可部署特征；
5. **目标–nuisance Jacobian 夹角旋钮**，区分信息总量与可分离性；
6. **精度轴 + 效率轴**，效率必须在相同硬件、预算、多 split、多 seed 下报告，不能用单次计时替代。

[工业应用调研](工业多传感器气体组分检测_工业应用方向调研报告.md)中的 MFC 动态混气系统可作为 P2/P3 的工程载体，用于获得准确标签并施加浓度阶跃、T/P/RH 扰动、MFC 偏差、漂移和未知组分；但其具体硬件和实验协议仍需在 P5 前完成审计。

## 7. 最终边界

本报告的推荐不等于算法已被证明。当前应保持以下判断：

- C1 是信息谱评估框架，不是基础信息论算法创新；
- C2–C4 仍需 P3 G3-4 最小证伪；
- C3 更适合真实硬件阶段，C4 需先证明跨模态互补性；
- C2 收益门和 C5 新候选必须通过显式修订记录后才能生效；
- 没有候选通过 G3-4，不得绕过阶段门进入 P4。

因此，下一步不是同时开发五个完整模型，而是先完成 FO-MPLSELM、VP 系列和 CRB 自适应采样的低成本证伪，并同步把上述六项输出写入 P2 规格书。
