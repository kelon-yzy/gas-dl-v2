# 视角 4 · 不确定度校准与拒绝机制（推广稿）

> 检索日期：2026-08-22  
> 目标：把 tv3 的 CC-SBI 从单一 O2 弛豫谱推广到多传感器、多组分后验，并区分“后验更准”与“点估计更准”。

## 1. 证据边界

Cranmer、Brehmer 与 Louppe 的综述把 simulation-based inference 定位为“只有模拟器、似然不可直接计算时的后验推断”框架（`10.1073/pnas.1912789117`）。Tejero-Cantero 等发布的 `sbi` 工具包把 neural posterior / likelihood / ratio estimation 变成可复用实现（`10.21105/joss.02505`）。这两项支持 SBI 的适用性，不支持任何特定后验网络天然校准。

## 2. 一般多模态后验

后验应写成 `q_phi(theta | {y_s, d_s, quality_s}_{s=1..S})`，而不是把多个模态压成一个点回归头。输入应允许模态缺测、频点数量变化和质量标记；`theta` 采用组分闭包约束，`eta_s` 通过边缘化或显式 nuisance 变量处理。

校准至少包含：SBC / rank histogram、50% / 80% / 90% / 95% 覆盖率、NLL、后验预测检验、OOD 覆盖率和拒绝率。覆盖率正确但区间宽，应解释为观测信息不足；不能为了缩短区间而后校准。

## 3. 与 tv3 的推广差异

tv3 主要面对单一观测臂和窄窗 O2；新 bench 应把传感器开关、噪声档位和干扰先验作为后验条件。这样可以回答“哪一档信息量下后验开始失真”以及“模态缺失时是否应拒绝输出”。这比只比较 MAE 更适合多组分工程部署。

## 4. 失效条件与最小证伪实验

失效条件包括：仿真先验未覆盖真实分布、模型偏差未进入模拟器、后验密度估计器过度自信、以及把校准集与测试集混用。最小实验是同一模拟器、同一先验下比较未校准 posterior、校准 posterior 和解析 / VarPro 参考；若覆盖率不改善，或仅 NLL 改善而覆盖率恶化，候选出局。若覆盖率改善但 P90 变宽，应保留为“可信度改善”而不是“精度改善”。

## 5. 视角 7 判定

| 机制 | 大气遥感 / 地球物理 | 医学成像 | 系统辨识 | 计量学 |
|---|---|---|---|---|
| SBI 后验推断 | 常规做法 | 零散工作 | 零散工作 | 零散工作 |
| 覆盖率 / SBC 校准 | 常规做法 | 零散工作 | 零散工作 | 零散工作 |

结论：SBI 本身是 T4/T5 领地；可保留的候选是“多模态缺测与信息量档位条件下的覆盖率校准 + 拒绝规则”，贡献类型为迁移与审计协议，不是新后验网络。
