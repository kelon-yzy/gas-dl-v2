# P1 补充检索与正式关闭审查

> 审查日期：2026-08-23  
> 审查对象：P1 候选集、领地清单、应用证据边界与 P2/P3 预注册门。  
> 结论：P1 阶段门通过并正式关闭；C1 进入 P2 规格草案，C2-C4 保留观察。

## 1. 审查问题

本次补充审查回答三个问题：

1. **RQ1**：气体传感内是否已有信息量、CRLB、局部条件化或性能标准化的直接先例？
2. **RQ2**：关键应用论文与公开代码能支持到什么证据边界？
3. **RQ3**：C1-C4 是否满足 P1 关闭条件，哪些结论必须留给 P2/P3 实测？

补充检索集中在首轮最容易造成误判的交叉轴：`gas sensor array + information theory / resolving power / CRLB / feature selection / limit of detection`，以及关键应用论文的开放全文和公开代码。元数据仍以 [references.json](references/references.json) 为唯一结构化事实源。

## 2. RQ1 · 气体传感内的直接先例

| 文献 | 可确认内容 | 对 C1 的约束 |
|---|---|---|
| Gardner 与 Bartlett 1996，`10.1016/0925-4005(96)01819-9` | 电子鼻 performance definition 与 standardization 的早期框架 | 不能把“建立气体传感性能评估框架”写成新问题定义 |
| Fonollosa 等 2014，`10.1016/j.aca.2013.10.030` | 用信息论度量估计传感器 limit of detection | 不能声明气体传感尚未使用信息论性能度量 |
| Johnson 与 Knapp 2017，`10.1016/j.snb.2017.05.182` | 用 Cramer-Rao lower bound 定义非特异性传感器阵列 selectivity | 不能声明 CRLB 首次进入气体传感阵列评估 |
| Fernandez 等 2018，`10.3389/fchem.2018.00209` | 用 Shannon resolving power 评估非线性、异方差 MOX 阵列；在 CO/H2O 浓度空间局部分区，不同分区选择不同特征组合 | 信息量评估、局部条件化与特征选择已有直接同领域先例 |
| Lakhmi 等 2024，`10.3390/s24113499` | H2/CO/CH4/CO2 阵列比较 PLS 与 ANN；ANN 仅在呈对数响应的 CH4 上更优 | 已有“算法优势随响应非线性变化”的应用证据，但没有 Fisher/CRB 信息轴 |

**RQ1 verdict：C1 属于 T2 组合改进空间。** 气体传感内已有信息论 resolving power、CRLB selectivity、信息论检测限、局部浓度分区和传感器特征选择。当前仍可保留的窄问题是：在预注册信息档位上，同时报告强基线、候选算法与 oracle 的差值，并给出算法优势出现和消失的区间。该组合适合作为 P2 的评估框架，不构成基础信息论方法或算法创新。

## 3. RQ2 · 关键应用证据边界

| 条目 | 已核实证据 | 不能外推 |
|---|---|---|
| Costa 2024，`10.1115/ipc2024-120952` | CrossRef 与会议摘要支持 185 个数据点、超声与热导融合、融合 `r2 = 0.98` | 完整模型、调参、强回归基线、重复与不确定度仍不能确认 |
| Monsalve 2025，`10.3389/fenrg.2025.1339598` | 开放全文支持理想气、mixture-of-mixtures、Monte Carlo 和多热力学传感器可达性评估 | 不是 Fisher/CRB 下界，不能写成对任意算法成立的误差下界 |
| Nguyen 2026，`10.1088/1361-6501/ae3252` | 论文摘要与公开代码支持原始时序、多任务结构和 5 折流程；代码按各气体浓度索引留一档测试，最大浓度不进入测试；仓库含 KNN、SVM、LDA、MLP、RF、GB 等分类基线，浓度回归公开基线主要是逐气体 `LinearRegression` | 不是按 `mixture_id` 或批次分组的严格 OOD；“显著优于经典 ML”只能作为作者声明，不能当作强回归基线结论 |
| Ha 2026，`10.1109/jsen.2025.3642226` | 摘要支持“随机打乱时序会造成泄漏”的方法学批评 | 不能据此确认该文自身采用了与 `mixture_id` 等价的分组划分 |
| Lakhmi 2024，`10.3390/s24113499` | 开放全文支持 PLS 与 ANN 的分气体比较，以及 ANN 优势集中在非线性 CH4 响应 | 不是信息谱 benchmark，也没有 oracle 空档或 CRB 条件化 |

这些边界足以冻结 P1 的领地和措辞；Costa 的全文基线细节、其余应用论文的完整重复与区间，属于投稿引用或后续复现实验需要，不阻塞 P1 关闭。

## 4. RQ3 · 候选最终 verdict

| 候选 | P1 verdict | 关闭依据 | 后续门 |
|---|---|---|---|
| C1 信息谱条件化评估 | **进入 P2 规格草案** | 作为 T2 组合改进的评估框架保留；收益量级先验和预注册 endpoint 已完整 | P2 冻结信息档位、oracle 隔离和报告协议；不作为 G3-4 算法候选 |
| C2 变量投影展开 | **保留观察** | 变量投影与 algorithm unrolling 基础方法已成熟，当前只有跨模态 nuisance 结构的迁移问题 | 必须通过 P3 G3-4 最小证伪实验 |
| C3 目标雅可比正交 discrepancy | **保留观察** | discrepancy、orthogonal GP 与 scaled GP 已成熟，当前只有目标方向投影的迁移问题 | 必须通过 P3 G3-4 最小证伪实验 |
| C4 可辨识共享 / 私有表示 | **保留观察** | 多视图可辨识理论与多任务融合已有先例，创新空间只在可审计约束和负对照 | 必须通过 P3 G3-4 最小证伪实验 |

## 5. P1 关闭检查

| 关闭条件 | 结论 |
|---|---|
| 至少 3 个候选且五项齐全 | 通过；C1-C4 均含机制、现有方法边界、收益量级、最小证伪实验和失效条件 |
| 已占领领地清单完整 | 通过；已补入气体传感内信息量、CRLB、LOD 和局部分区直接先例 |
| 至少 1 个可测量收益先验 | 通过；C1 以 tv3 冻结的 `0.1799 R2` 空档推导 P2 可测量门，但不把该数当作新 bench 实测结果 |
| P2/P3 判据已预注册 | 通过；C1 进入 P2 规格，C2-C4 只能经 P3 G3-4 晋级 |
| 引用和证据边界可执行检查 | 通过；散文 DOI 由 `check_citations.py` 检查，开放全文、摘要和公开代码证据分层记录 |
| 未伪造后续实验结果 | 通过；C1-C4 的最小证伪实验均未执行，状态明确留在 P2/P3 |

## 6. 正式关闭结论

P1 已完成候选集、领地清单和 P2/P3 预注册判据，阶段门于 2026-08-23 通过并关闭。关闭不代表已确认算法创新：C1 是评估框架与组合改进空间，C2-C4 仍是待证伪机制。后续工作不得把 C1 写成“气体传感首次使用信息量或 CRLB”，也不得绕过 P3 G3-4 直接启动 P4 大规模训练。
