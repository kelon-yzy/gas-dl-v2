# 视角 5 · 低浓度与不平衡多目标回归（推广稿）

> 检索日期：2026-08-22  
> 目标：把 tv3 的尺度、加权和低浓度问题推广为多组分回归中的可审计损失设计。

## 1. 问题重写

多组分目标的量程、方差和重要性通常不同。直接使用未标准化 MSE 会让高方差组分主导梯度，直接使用固定反比例权重又可能放大低浓度噪声。因而必须分开三件事：目标尺度、样本稀有度、任务不确定度。

## 2. 已有方法与迁移边界

Cipolla、Gal 与 Kendall 用任务不确定度学习多任务损失权重（`10.1109/cvpr.2018.00781`）；Liu、Liang 与 Gitter 则指出多任务学习存在 negative transfer，并提出动态 loss-balanced weighting（`10.1609/aaai.v33i01.33019977`）。Steininger 等针对 imbalanced regression 以目标密度估计构造 DenseWeight / DenseLoss，使稀有目标区域获得可控的额外权重（`10.1007/s10994-021-06023-5`）。

这些工作表明“自动权重”和“稀有样本加权”已有明确领地。项目可研究的窄问题是：在组分闭包约束和跨模态噪声异方差同时存在时，如何把目标尺度权重、样本稀有度权重与传感器质量权重分开，并用低浓度 P90 而非平均 R2 评估。

## 3. 推荐的审计形式

先对每个目标做训练集内标准化，再报告原单位误差。候选损失可写成 `L = sum_j w_task,j L_j + w_sample(x) L`，其中 `w_task` 由训练集估计或不确定度学习，`w_sample` 由目标密度估计；两者不能同时自由漂移。必须报告每个组分的 MAE、P90、低浓度子区间覆盖率、梯度占比和负迁移差值。

## 4. 最小证伪实验

比较未加权、逐目标标准化、固定物理权重、不确定度权重、稀有度权重及两者组合。设置等量的低浓度留出集和常规浓度留出集；若平均指标改善但低浓度 P90 变差，候选出局。若只有改变目标单位就有效，结论应归为量纲修复，不能包装为新损失。

## 5. 视角 7 判定

| 机制 | 大气遥感 / 地球物理 | 医学成像 | 系统辨识 | 化学计量学 |
|---|---|---|---|---|
| 不确定度任务加权 | 常规做法 | 常规做法 | 零散工作 | 零散工作 |
| 不平衡回归密度加权 | 零散工作 | 零散工作 | 零散工作 | 零散工作 |

结论：不能声明“首次解决低浓度多目标 loss”；可保留“组分闭包 + 多模态质量 + 低浓度 P90 的联合审计”作为迁移候选。
