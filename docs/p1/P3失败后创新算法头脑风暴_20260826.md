# P3 失败后的创新算法头脑风暴（2026-08-26）

> **状态：候选草案，不是 P4 授权。** 本文响应 P3 的 `return_to_P1_P2`，只把失败机制转换为下一轮可检验的算法假设；不改写 [项目总体规划](../../general_fusion/项目总体规划.md)、[P3 评审记录](../p3/P3评审记录.md) 或既有 G3-4 门值。
> 2026-08-27 增补：§9 记录七个候选与 general_fusion 新主线（A0–A6）的兼容评价；候选清单与既有门值未变，增补不构成选型授权。

## 0. 结论先行

本轮不再寻找“更大的网络”或“再做一个漂移补偿网络”。当前最值得重新立项的不是一个单一模型，而是四类可归因机制：

1. **把静态反演变成带漂移状态的时序估计**：同时估计组分、传感器漂移和响应滞后。
2. **把被动截窗变成改变可分离性的主动激励**：主动改变目标与 nuisance 的 Jacobian 几何，而不是只减少采样点。
3. **把理论信息量改造成样本级风险决策**：用校准后的多输出风险决定继续测量、切换求解器或明确拒答。
4. **把直接预测改造成物理求解器的可验证初始化与偏差分解**：降低重复 forward/Jacobian 成本，并把模型偏差当作可测的正交残差，而不是让网络吞掉它。

如果只能选一条软件优先路线，建议先做 **Warm-IR**；如果硬件能够控制声学激励或测量窗口，优先做 **JEDI-Gas**；如果可以采集跨时间或跨传感器域，优先做 **Dyna-DRIF**。这三个方向的失败条件彼此不同，不会把同一假设重复包装成多个网络。

- **精度、效率和信息几何必须分开测量。** 不能用一个 R² 或一次计时替代机制证据。
- **算法必须改变一个可观察的因果环节。** 例如改变漂移状态估计、测量动作、求解器初值或偏差分解；普通换骨干不算。
- **新数据需求要显式写入 P1/P2。** 需要时序、主动激励、真实硬件偏差或缺失模态时，不能在现有静态 `GIB` 上偷偷模拟成“已验证”。
- **所有拒答、升级和失效都要显式报告。** 不用静默兜底制造成功样本。

## 4. 算法草案与最小证伪实验

### A. Dyna-DRIF：联合估计组分、漂移和响应状态

把当前静态映射改成显式状态空间模型。令 `x_t` 为四组分 composition，`b_{s,t}` 为第 `s` 个传感器的慢漂移，`d_t` 为响应滞后或输运状态：

```text
x_{t+1} = x_t + v_t + w^x_t
b_{s,t+1} = rho_s b_{s,t} + g_s(T_t, RH_t, flow_t) + w^b_{s,t}
y_{s,t} = h_s(x_t, b_{s,t}, d_t, T_t, RH_t, flow_t) + eps_{s,t}
```

滤波器可以从 square-root EKF/UKF 或可微 assumed-density filter 开始；神经网络只预测过程噪声、测量噪声或小幅增益修正，主观测方程和物理 Jacobian 保留在一个地方。在线更新只使用到达的观测和明确的参考/blank 信息，不用伪标签偷偷改写组分。

它与已有在线漂移适配的差别不在“又一个域适配器”，而在于把**漂移状态和浓度状态分开**，并允许检查“浓度变化”和“传感器变化”是否被错误互相解释。

最小证伪实验：

- 生成慢漂移、阶跃漂移、温湿度耦合漂移和响应滞后四类留出过程；按时间而不是随机样本切分。
- 对照静态 Ridge/GBDT、纯滤波、只跟踪 drift 的模型、Dyna-DRIF 和已有 KD/TTA 基线。
- 主指标为四组分 tracking MAE/P90、漂移发生后的恢复时间、预测区间覆盖率；`b_t` 与真值的相关性只作机制辅助指标。
- 负对照包括时间打乱、未来窗口泄漏、去掉独立参考通道和把漂移状态固定为零。

杀停条件：如果联合状态模型只在随机切分上提升，时间留出不提升；或 drift 状态与 composition 完全不可区分且新增参考通道也不能解除，则停止，不继续扩大状态网络。

### B. JEDI-Gas：用主动激励改变 Jacobian 几何

C5-A 的根本问题是“信息量多”不等于“目标可分离”。JEDI-Gas 在每一步从动作集合 `a` 中选下一段激励或测量协议，动作可以是声学频段、幅值、相位、光学积分窗口或热学 duty cycle。动作评分同时考虑信息量、目标–nuisance 可分离性和成本，例如：

```text
a* = argmax_a { robust_min_component_information(a)
                 + gamma * separation_gain(target, nuisance; a)
                 - alpha * measurement_cost(a) }
```

其中 `separation_gain` 应由目标与 nuisance 的 whitened Jacobian 夹角、最小奇异值或局部条件数定义；不能只用 CRB 总量替代。先用前向模型做 offline action audit，再决定是否值得上真实硬件。

最小证伪实验：

- 固定总测量能量和总时间，比较 JEDI、随机激励、最大 EIG、最大 CRB、固定激励。
- 在每个动作下保存 `J_target`、`J_nuisance`、最小奇异值、夹角、预测 P90 和实际误差；检验几何指标是否能预测真实困难。
- 必须有“动作改变几何但不改变总信息量”的对照，否则无法区别 JEDI 与普通自适应采样。

杀停条件：动作库在硬件约束下不能让夹角或最小奇异值产生稳定变化；或者几何指标提高但真实四组分尾部误差不降，则不进入正式实验。若现有硬件无法主动激励，JEDI 只能作为仿真设计研究，不能包装成硬件算法。

### C. RACER：校准风险驱动的序贯测量与显式拒答

RACER 不把 CRB 当成预测误差。每个测量动作后，模型输出四组分的联合预测区间或风险上界；用独立 calibration split 按模态掩码、信息区间和部署上下文做 conformal 校准。动作选择最大化“最坏组分风险下降 / 增量成本”，而不是最大化裸 `Delta I`：

```text
choose a* = argmax_a  predicted_reduction(max_k calibrated_risk_k) / cost(a)
stop      if every component interval meets its tolerance
abstain   if the action budget is exhausted or no calibrated interval meets it
```

这条路线直接吸取 C5-A 和 C5-D 的失败：风险来自样本级实际预测，路由不再依赖静态 S1 区域；`abstain` 是正式输出，不是隐藏 fallback。它也需要承认一个评价变化：主结果应是 coverage–risk–cost 曲线，而不能只沿用“所有样本都必须给出同样输出”的单一门。

最小证伪实验：

- 对照固定全测量、固定短窗、CRB early exit、uncertainty early exit、随机策略和 RACER。
- 预先冻结 calibration split、联合覆盖率算法、动作预算和拒答规则；测试集不得参与校准。
- 报告接受率、联合覆盖率、每个组分尾部风险、平均/95 分位测量成本，并按 S1 信息量与 Jacobian 夹角分层。

杀停条件：在目标覆盖率下成本没有下降；或 marginal coverage 通过但 critical/high-collinearity 分层覆盖失败；或去掉真实风险只保留 CRB 后结果一样，则停止 RACER 的“风险驱动”主张。

### D. Warm-IR：可验证的 amortized warm start，而不是长链展开

使用轻量网络根据 Raw、DSP 和慢通道上下文给出 `theta_0, eta_0`，随后只执行固定的一到两次物理 Gauss–Newton/Levenberg–Marquardt 或 variable-projection correction：

```text
(theta_0, eta_0) = g_phi(raw, dsp, slow)
delta = (J^T W J + lambda I)^(-1) J^T W (y - f(theta_0, eta_0))
(theta_1, eta_1) = project(theta_0, eta_0, delta)
```

`f`、`J`、残差和参数约束仍是显式物理路径；网络不能直接跳过残差。每个样本都记录初始残差、修正后残差、forward calls、Jacobian calls、solver wall-clock 和是否达到精度目标。可用一个在 calibration split 上冻结的残差证书决定 `accept / continue / abstain`，而不是隐式调用第二套兜底模型。

它与 C2 的关键区别是：C2 学一串更新并重复调用模型，Warm-IR 学的是**初值和可复用局部几何**，物理修正步数固定且成本可审计。ASPIRE、amortized inverse optimization 和 learned singular-value quasi-Newton 已说明该类思想成熟，因此本项目只能把贡献限定在四组分共享/private nuisance、物理约束和样本级证书的组合验证。

最小证伪实验：

- 对照经典 VP/VPLR/TSVD-VP、C2-IC-RDU-VP、纯 direct predictor、warm start only、learned preconditioner only。
- 使用随机初值、远离训练域的 composition、nuisance 扰动和 critical/high-collinearity 单元；不能只在训练分布上计时。
- 主门同时要求四组分精度 non-inferiority，以及 forward calls、batch-1 latency 或达标点的预注册改善；只少迭代但多调用 forward 不算通过。

杀停条件：warm start 的网络耗时吞掉物理修正节省；或 OOD 初值导致残差证书失效；或固定修正步不能恢复 C2 的精度，则停止，不改成更深的 unrolling。

### E. IFM-Fuse：以信息形式融合模态，而不是平均共享表示

每个模态分支输出 composition 坐标中的局部估计 `mu_s` 和正定精度矩阵 `Lambda_s`，融合时使用信息形式：

```text
Lambda = Lambda_0 + sum_s w_s Lambda_s
mu     = Lambda^(-1) (Lambda_0 mu_0 + sum_s w_s Lambda_s mu_s)
```

`w_s` 由传感器质量、模态内部残差和跨模态一致性共同决定，并在 calibration split 上做约束和校准；缺失模态贡献为零，冲突模态降低权重并显式输出 conflict score。composition 可在 log-ratio 坐标中融合，再投影回合法单纯形。

这条路线不再声称“共享/私有表示本身可辨识”，而是要求每个模态贡献可检查、可关闭、可量化。它仍然有较成熟的 product-of-experts、MNP 和 evidential fusion 先例，故新颖性风险高于 Warm-IR 和 JEDI。

最小证伪实验：

- 对照 C4、early/late concat、等权信息融合、单模态模型和 oracle reliability。
- 分别遮蔽 NDIR、声学、热学；再对单一模态注入幅值漂移、时延、非线性和互相矛盾的观测。
- 报告四组分 MAE/P90、NLL、联合 coverage、缺失模态退化量和 conflict score 的识别能力。

杀停条件：固定等权融合与 IFM-Fuse 无差异；或置信度只在全模态 ID 样本上有效；或随机/错误配对对照不能破坏结果，则不再投入表示学习。

### F. Meta-Cal：只适配物理校准参数的上下文模型

把部署适配限制在可解释的校准参数，而不是整个预测器。训练时按传感器批次、年龄、温湿度、流量、增益和响应时间构造 episodic domains；上下文编码器从 blank/reference 或短校准序列得到 `z`，hypernetwork 只输出每个模态的 gain、bias、时常数或低秩校准修正：

```text
z = context_encoder(calibration_or_reference_sequence)
(gain_s, bias_s, tau_s, low_rank_s) = H_psi(z)
prediction = physical_inverse(correct(raw_s; gain_s, bias_s, tau_s, low_rank_s))
```

与 BDA、CDC、TTA、KD 和 MDFE-Net 的区分只能是“物理校准参数受限 + 留一传感器/留一时间域 + 不使用目标浓度标签”，不能把 meta-learning 这个名词本身当作创新。

最小证伪实验：

- 域划分必须按传感器或时间留出；随机切分仅作 sanity check。
- 比较无适配、简单 affine recalibration、BDA、KD/TTA 和 Meta-Cal；校准样本量按 0、1、5、10 个 reference 序列画曲线。
- 同时测试 calibration sequence 与 deployment sequence 的不一致，避免上下文泄漏。

杀停条件：简单 affine 已达到同样效果；或需要目标浓度标签才能稳定；或 leave-domain-out 失败，则停止，不堆更强 hypernetwork。

### G. TANGENT-RES：把模型偏差分成 target tangent 与正交残差

重新启用 C3 只允许在有独立硬件偏差或真实测量残差时进行。对观测残差 `e = y - f(theta)` 和目标 Jacobian `J`，定义：

```text
P_J    = J (J^T W J + lambda I)^(-1) J^T W
e_para = P_J e
e_orth = (I - P_J) e
```

`e_para` 是可能改变 composition 的部分；`e_orth` 主要用于估计 model discrepancy 和预测不确定度，不应被直接当作浓度更新。可以训练一个条件 discrepancy 模型预测 `e_orth` 的均值/协方差，再在校准后的 forward 中修正 `e_para`。所有 discrepancy 参数必须来自独立来源，不能由同一仿真脚本注入后再由同一脚本验证。

最小证伪实验：

- 数据分为物理模型训练域、真实/硬件偏差校准域和最终留出域；偏差来源至少有温湿度、流量、传感器响应或未知组分中的一个独立变化。
- 对照无 discrepancy、普通 additive residual、C3 旧式自注入版本和 TANGENT-RES。
- 报告 `e_orth` 的校准 coverage、composition 误差、模型偏差预测误差和跨域稳定性；不得只报最终 MAE。

杀停条件：没有独立偏差来源；或收益随自注入幅度单调增加但在真实/外部偏差上消失；或正交分解不能稳定重复，则将 C3 永久保留为方法学警告，不进入正式算法。

## 5. 推荐的重新立项组合

不要把 7 条路线同时送入新一轮 G3-4。先根据资源选择一条主线和一条对照线：

| 条件                | 主线          | 对照线                         | 需要先冻结的新增事实                                      |
| ----------------- | ----------- | --------------------------- | ----------------------------------------------- |
| 只能使用现有软件与 forward | Warm-IR     | 经典 VP + 直接 predictor        | forward/Jacobian 调用计数、batch-1 latency、初值 OOD 方案 |
| 可以控制声学/光学/热学动作    | JEDI-Gas    | CRB/EIG/随机动作                | 动作是否真的改变 Jacobian 夹角，且总能量/总时间可配对                |
| 可以做长时间或跨传感器采集     | Dyna-DRIF   | 静态回归 + 纯滤波                  | 漂移、温湿度、响应滞后和时间留出协议                              |
| 能拿到独立真实硬件偏差       | TANGENT-RES | 普通 residual + 无 discrepancy | 偏差来源隔离、校准域/测试域分离                                |
| 目标是降低测量成本且允许拒答    | RACER       | 固定全测量和 CRB early exit       | coverage–risk–cost 的新评价契约，不能事后改门                |

建议的第一轮筛选顺序是：

1. **先做无训练的可行性审计**：JEDI 检查动作能否改变几何；Dyna-DRIF 检查漂移状态是否可观测；TANGENT-RES 检查是否存在独立偏差；Warm-IR 检查 forward 成本是否足以产生收益。
2. **再做小规模最小证伪**：每次只启用一个机制，保留当前 GIB 的 9 个信息单元、5 个 group split 和 3 个 seed；新增数据只为新机制服务。
3. **最后才改 G3-4 候选门**：效率型候选必须同时过精度 non-inferiority 和真实调用成本门；动态型候选必须过时间留出；选择性候选必须把覆盖率、拒答率和成本一起冻结。

任何候选若只能在全模态、随机切分、单次计时或自注入偏差下成功，均不得进入 P4。

## 6. 对现有 GIB/P1/P2 的最小变更建议

这些是下一轮 P1/P2 的候选变更，不是本次直接修改的配置：

- **时间轴**：为每个 `mixture_id` 增加有序时刻、漂移轨迹类型、响应滞后和 reference/blank 标记；不新增 `sequence_id` 回退语义。
- **动作轴**：若上 JEDI，记录 action id、总激励能量、测量时间、动作前后 Jacobian 几何和实际传感器成本；若硬件不可控，明确标记为 simulation-only。
- **风险轴**：为 RACER/IFM-Fuse 增加 calibration split、模态 presence mask、联合区间、conflict score 和 explicit abstain 状态。
- **偏差轴**：为 TANGENT-RES 增加独立 discrepancy source 和 provenance；不能复用 self-injected discrepancy 作为正式效果证据。
- **效率轴**：所有 solver 记录 forward calls、Jacobian calls、迭代、wall-clock、batch-1 latency 和达到固定误差阈值所需数据量。

上述变更完成前，不得在现有 `gib-benchmark-1` 上把动态、主动或真实偏差结论写成正式算法优势。

## 7. 检索与证据边界

本轮检索问题固定为：气体传感器漂移与在线适配、主动/序贯测量、集合与选择性预测、物理约束多模态融合、sim-to-real/model discrepancy、神经状态空间和 amortized inverse solver。使用了 `nature-academic-search` 的 Crossref、Semantic Scholar、OpenAlex、arXiv 多源检索，以及 `smart-search` 的 Exa 搜索和逐页 fetch；纳入设计依据的候选均以 DOI 元数据加出版社或 arXiv 可获得的摘要/正文进行二次核对，无法充分核对的搜索结果不作为结论依据。

`smart-search doctor` 显示主兼容 provider 返回 HTTP 403，但 Exa/Tavily/Firecrawl 路径可用；因此没有把该失败静默当成成功，也没有用未经核实的搜索摘要替代 DOI/出版社或 arXiv 页面。原始检索响应和页面摘录保存在被 `.gitignore` 排除的 `gas_information_bench/outputs/runs/` 下；正式结论只依赖本节列出的可复核链接和项目自身冻结证据。

## 8. 当前判断

- **最有希望的“新机制”**：JEDI-Gas、Dyna-DRIF、Warm-IR、TANGENT-RES；它们分别改变测量几何、状态变量、求解器成本和模型偏差分解。
- **最容易做成但最容易被审稿人判成熟组合的方向**：IFM-Fuse、Meta-Cal、RACER。只有把气体 Jacobian、独立校准和样本级风险门写进机制，才有继续价值。
- **明确不建议重跑的方向**：更大 TCN/Transformer、普通 KD、普通 MoE、固定 S1 区域路由、只用 CRB 做 early exit、无独立偏差来源的 C3 自注入版本。

下一次正式决策应回答一个问题：**我们能否为候选机制增加一个真实可控的观测或状态变量，并为它设计一个失败也有信息量的最小实验？** 若不能，继续换模型只会重复 P3。
