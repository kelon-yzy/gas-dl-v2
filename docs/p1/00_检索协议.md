## 3. 数据库与工具（含 2026-08-22 实测可用性）

| 工具                                      | 后端               | 实测结果                                                                           | 定位               |
| --------------------------------------- | ---------------- | ------------------------------------------------------------------------------ | ---------------- |
| `mcp__academic-search__get_paper_by_id` | CrossRef 内容协商    | **13/13 成功**                                                                   | **元数据核实的唯一权威来源** |
| `mcp__paper-search__search_semantic`    | Semantic Scholar | 可用。短具体查询命中好；长查询与抽象方法学查询会空返回或严重漂移                                               | 发现（recall）主力     |
| `mcp__academic-search__search_papers`   | CrossRef + arXiv | CrossRef 首轮 15 s read timeout，后自行恢复；arXiv 一次 HTTP 429、一次 SSL handshake timeout | 备用发现             |
| `mcp__paper-search__search_openalex`    | OpenAlex         | 空返回                                                                            | 本轮不可用            |
| WebSearch / 出版商 OA / 公开代码            | Web、开放全文与仓库      | 补充核验用于 Fernandez 2018、Monsalve 2025、Lakhmi 2024 全文和 Nguyen 2026 公开代码边界                   | 全文与实现证据补充         |
| `cnki-search` / `cnki-advanced-search`  | CNKI             | 本轮未用                                                                           | 学位论文阶段，期刊论文非必需   |

**分工纪律：Semantic Scholar 负责发现，CrossRef 负责核实。** 二手元数据不得直接进入 `references.json`。本轮 13 条中有 6 条的二手元数据与 CrossRef 不符，清单见 §7.3。

**查询写法（针对 Semantic Scholar 的实测经验）**：控制在 6–10 个实词内、全部是领域名词。以下两条本轮返回空或完全漂移，记录为反面样本：

- `is deep learning necessary chemometrics outperform PLS review critical assessment`（漂移到 XRF / 医学影像 / 假新闻检测）
- `benchmark tunable information content inverse problem identifiability simulation study estimator comparison`（漂移到临床缺失数据 / 神经网络会议论文集）

抽象方法学问题走 Semantic Scholar 关键词检索无效，应改为：先用具体机制名 + 具体应用名定位一篇，再顺引文网络走。

## 4. 各视角检索式

英文检索，中文输出。每个视角给主查询与补充查询；补充查询用于覆盖主查询漏掉的表述。

### 视角 1 · 多传感器多组分气体检测 DL 现状

要回答：哪些创新声明已经不能提？有没有人做过"DL 相对调好的线性基线是否有优势"的对照？

主查询：

```
electronic nose deep learning multi-component gas concentration regression
multimodal sensor fusion deep learning gas mixture concentration quantification
ultrasonic gas concentration measurement machine learning multicomponent mixture
hydrogen natural gas blend concentration ultrasonic thermal conductivity sensor fusion
```

补充查询：

```
photoacoustic spectroscopy deep learning mixture gas concentration overlapping
gas sensor array concentration prediction multi-task learning attention
deep learning versus partial least squares spectroscopy quantitative comparison benchmark
NDIR thermal conductivity gas composition neural network compensation
gas sensor array information theory resolving power feature selection
gas sensor array Cramer Rao lower bound selectivity limit of detection
```

纳入：以**浓度定量**为任务之一。排除纯分类/纯识别（但单列成表，因为该领域大量文献是分类，不列会误判领地为空）。

### 视角 2 · 物理引导与可微前向反演

主查询：

```
algorithm unrolling inverse problem interpretable deep learning
variable projection separable nonlinear least squares nuisance parameter
physics informed neural network spectroscopy quantitative inversion
differentiable forward model sensor inversion learned optimizer
```

纳入：明确把前向物理写进模型或求解器结构的。排除只在 loss 里加一个软惩罚项就自称 physics-informed 的（单列）。

### 视角 3 · 多模态贡献可辨识与解耦

主查询：

```
multi-view nonlinear ICA identifiability shared latent variable
modality contribution disentanglement multimodal fusion identifiability
partial observability multi-view causal representation shared information
```

纳入：给出可辨识性条件或反例的。排除只报融合后指标提升、无可辨识性论证的。

### 视角 4 · 不确定度校准

主查询：

```
simulation-based inference posterior coverage calibration
simulation based calibration rank histogram diagnostic
conformal prediction regression coverage guarantee sensor
neural posterior estimation overconfident coverage loss
```

纳入：报告覆盖率或校准诊断的。排除只报 NLL 或后验均值误差的（这是 CC-SBI 构想明确点出的失效模式）。

### 视角 5 · 低浓度与不平衡多目标回归

主查询：

```
imbalanced multi-target regression scale weighting low concentration
multi-task loss weighting uncertainty balancing regression targets
trace component quantification low concentration spectroscopy machine learning
```

纳入：显式处理量级差或目标间尺度的。

### 视角 6 · sim-to-real 与模型偏差

主查询：

```
model discrepancy calibration computer model orthogonal Gaussian process
sim-to-real transfer sensor inversion domain gap physical simulator
digital twin inversion model bias identifiability confounding
```

纳入：把模型偏差与目标参数的混淆当问题处理的。

### 视角 7 · 相邻领域检查（逐候选执行）

对每个候选机制 M，在下列领域各查一次 `<M 的通用名> <领域名>`：

```
<mechanism> atmospheric sounding retrieval
<mechanism> geophysical inversion
<mechanism> medical image reconstruction
<mechanism> system identification
<mechanism> metrology measurement uncertainty
<mechanism> chemometrics calibration
```

判定输出只有三种：**该领域常规做法** / **该领域有零散工作** / **未检索到**。第三种必须写成"未检索到"，不能写成"首次"。

## 5. 通用纳入与排除标准

**纳入**（四项全满足）：

1. 题名 + 作者 + 刊名或会议名 + DOI 四项经 CrossRef 核对一致
2. 与该视角的问题直接相关，不是仅关键词字面匹配
3. 2015 年之后；方法学奠基文献和直接占领目标声明的早期域内先例不限年份（Rodgers 2000、Gardner–Bartlett 1996、Golub–Pereyra 2003、Kennedy–O'Hagan 2001 一类）
4. 有可核对的定量结果，或有明确的理论主张

**排除**：

1. 无法核对 DOI 或元数据
2. 无同行评审、且不属于该领域预印本惯例的。ML 方法学的 arXiv 条目按惯例接受，但需标注"仅 arXiv，未见期刊版"
3. 疑似掠夺性期刊。本轮遇到若干（域名形如 `gengpi.com`、`afropolitanjournals.com`），一律不入库
4. 只做定性趋势描述、无数值也无理论主张的综述——可作背景，不作证据

## 6. 两套正交的证据分级

分开是因为"证据有多硬"和"领地被占多牢"是两件事。一篇高引教科书对领地是极强占领，但对具体硬件误差是零证据。

### 6.1 证据类型分级（这条证据能支持什么结论）

沿用 2026-07-27 检索报告 §2.2 的表并细化为分级。

| 级   | 证据类型                       | 能支持                | 不能支持          |
| --- | -------------------------- | ------------------ | ------------- |
| E1  | 解析理论、统计定理                  | 可辨识条件、信息上限、优化等价性   | 任何具体硬件能达到的误差  |
| E2  | 纯前向审计（Fisher / CRB / 一阶传播） | 已登记域内任何算法都越不过的下界   | 存在未建模误差时的真实性能 |
| E3  | 仿真基准实验                     | 给定仿真器与噪声下的**相对**表现 | 现场泛化、绝对校准     |
| E4  | 实验室实测                      | 特定装置、组分、工况下的可行性    | 跨装置外推         |
| E5  | 现场或工业实测                    | 部署可行性              | —             |
| E6  | 综述、二手引用                    | 领域态势               | 任何具体数值        |

引用时必须同时写清等级与限定范围。规划 §11 的 N3（结论要写清适用范围）在这里落成硬要求。

### 6.2 领地强度分级（这个声明被占到什么程度）

沿用 [00_related_work.md](../../tunnel_ventilation/docs/paper/00_related_work.md) §2 的强度列并定标。

| 级       | 判据                       | 后果                    |
| ------- | ------------------------ | --------------------- |
| T5 极强   | 教科书或 >1000 引的标准做法，写在方法章节 | 不能声明为新，只能声明为迁移        |
| T4 强    | 目标期刊或同领域顶刊有直接同类工作        | 不能声明为新；必须正面处理该文献      |
| T3 中强   | 相邻领域有直接同类工作              | 声明须写成"迁移"并说明迁移要克服什么   |
| T2 中    | 有零散工作，未成标准               | 可声明改进，须逐条区分           |
| T1 弱    | 只有间接相关                   | 可声明，须列出最近的间接工作        |
| T0 未检索到 | 本轮检索未发现                  | **只能写"未检索到"，不能写"首次"** |

T3 的处理方式来自规划 §5.1：把成熟做法迁入尚未采用它的领域本身是可声明的贡献，但要写成迁移不是发明，并说明迁移时需要克服什么。tv3 的例子是秩亏——Rodgers 那套的信息量度量在秩亏时不给出目标单位的数。

## 7. 引用核实纪律

这条直接继承 P0 的纪律 1：**引用数值必须由脚本从冻结产物生成，不手工誊写。** P0 抓到五处描述漂移——数字都在冻结产物里没错，错的是描述那个数字的句子。P1 的对应风险是**引用漂移**：作者名、年份、刊名、乃至"那篇文章到底声明了什么"在誊抄中变形。

### 7.1 结构化事实源

`references/references.json` 是 P1 引用的唯一结构化事实源。约束：

- `verified_via` 只允许 `crossref`
- 只从 Semantic Scholar / OpenAlex 得到的条目在核实前放 `pending_verification`，不进 `entries`
- tv3 时期已核实的条目（Phillips 2003、Liu 2023 ARGD、Rodgers 2000 等）留在 `00_related_work.md`，P1 文档引用时**重新核实后迁入**，不复制未核实副本。这是 N7（一个数不要在两个地方维护）的应用

### 7.2 可执行检查

```bash
python docs/p1/tools/check_citations.py            # 离线：覆盖性与字段完整性
python docs/p1/tools/check_citations.py --online   # 联网：逐条向 CrossRef 复核
```

离线检查：`docs/p1/**/*.md` 里出现的每个 DOI 必须已登记；每条登记项必填字段非空；`verified_via` 合法；key 与 DOI 无重复；`entries` 与 `pending_verification` 无交叉。

联网检查：逐条比对题名、首作者姓、年份、刊名。题名与刊名比对前解 HTML 实体（CrossRef 返回 `&amp;` 一类）。

**年份按多口径判定。** online-first 与 print 跨年是期刊常态，脚本收集 `issued` / `published` / `published-online` / `published-print` 全部口径；本地年份落在其中之一即通过，但若不等于 `issued` 则出 warning，提示该条的引用口径需要固定。

2026-08-22 首次运行结果：13 条登记项，联网复核 13/13，0 error，1 warning。2026-08-23 完成七视角与补充交叉检索后，结构化事实源增至 36 条。`ding2026_lacnet_multitask_attention`（MST 37(2) 025102）的 warning 来自 online-first 2025-12-23 与 print 2026-01-16 跨年，属真实口径分歧，保留待投稿前统一。

## 8. 产出物规格

规划 §5.2 要求三个产出物。

### 8.1 创新点候选集

每个候选必须写全五项，缺一项不得进入评审。

| 项             | 要求                            | 不合格的样子           |
| ------------- | ----------------------------- | ---------------- |
| 机制            | 具体改变了什么——观测、噪声协方差、先验、求解器，还是表示 | "用注意力更好地建模跨模态关系" |
| 现有方法为什么做不到    | 引用具体文献 + 具体限制，附证据等级与领地强度      | "现有方法难以处理复杂耦合"   |
| **收益量级的先验估计** | 机制成立后指标能改善多少，给出数量级与推导         | 缺失，或只写"预期显著提升"   |
| 最小证伪实验        | 成本最低的判生死实验，**必须先于大规模训练**      | 把完整训练当成第一步       |
| 失效条件          | 什么情况下机制不成立                    | 缺失               |

第三项是硬要求。规划 §5.2 列了五次同型失败——E1r 帧保真通过但序列平价失败、F5 流速解耦降 98% 但 OOD MAE 只改善 0.117 vol%、MRS-2 升秩成立但 P90 2.40、MEI-3 VarPro 结构准入但 CI 下界不过界、MEI-4 Laplace 构造完全正确但区间宽于量程。每次都是机制上做对了、收益不够。**只论证机制可行不足以立项。**

每个候选另附视角 7 的相邻领域判定行：`机制 M 在 <领域> 属 <常规做法 / 零散工作 / 未检索到>`，逐领域列，不合并。

### 8.2 已占领领地清单

按 §6.2 分级，逐条给出：不能声明什么、占领者、领地强度、证据等级、该文献必须被正面处理还是仅需引用。

### 8.3 进入 P2 的判据

**预注册，不在看到 P2 结果后调整。** 至少写明：

- 候选数量下限（规划 §5.3 定为 ≥3，五项齐全）
- 至少 1 个候选的收益量级估计要支持"能在 bench 上做出可测量的差异"——**这里的"可测量"必须给出数值门与其来源**，不能留成形容词
- 领地强度上限：T4 及以上的候选若无法改写成迁移声明，不得进入 P2
- 淘汰条件：哪些情况直接出局
