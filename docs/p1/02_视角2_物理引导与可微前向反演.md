# 视角 2 · 物理引导与可微前向反演（推广稿）

> 检索日期：2026-08-22  
> 范围：把 tv3 的 NP-VPNet、RG-cOED、SIMD-MRS 从单一声学弛豫谱推广到多传感器、多组分、共享干扰参数的前向反演。  
> 核验：本文 DOI 均已通过 CrossRef 题名、首作者、年份与刊名核验；本文是方法边界稿，不把摘要级性能当作项目收益证据。

## 1. 统一问题

多模态观测写为 `y_s = F_s(theta, eta_s; d_s) + epsilon_s`。`theta` 是共享组分向量，`eta_s` 是各传感器的增益、延迟、温度或背景参数，`d_s` 是频率、功率、采样时长等设计变量。推广的关键不是把 tv3 的网络换成更大的网络，而是分别处理三类对象：可消去的 nuisance 参数、真正能改变雅可比方向的设计变量，以及跨传感器噪声协方差。

## 2. 三条可迁移结论

### 2.1 变量投影是求解器改进，不是信息增益

Golub 与 Pereyra 的变量投影将可分离非线性最小二乘中的线性参数先消去，再优化非线性参数；Español 与 Pasha 将该结构扩展到一般形式 Tikhonov 正则化和 Gauss–Newton 迭代（`10.1088/0266-5611/19/2/201`；`10.1088/1361-6420/acdd1b`）。在本项目中，可消去块可以是每个传感器的基线、增益、固定延迟或线性串扰系数，而组分与跨模态耦合仍保留在非线性块。

算法展开的通用依据是把迭代求解器展开为有限层、学习预条件器或阻尼参数，同时保留数据一致性；Monga 等的综述把这类方法定位为“可解释的迭代结构 + 数据学习”，而不是任意黑盒主干（`10.1109/msp.2020.3016905`）。因此候选应写成“跨模态可分离反演的变量投影迁移”，不能写成首次提出 algorithm unrolling。

**边界**：若目标与 nuisance 参数的灵敏度仍共线，变量投影只能改善条件数或收敛，不能突破同一观测模型的 CRB。最小证伪实验是固定观测、固定噪声，比较解析 Gauss–Newton、纯 MLP 和 VP 展开；若 VP 只在 nuisance 真值输入时有效，说明收益来自泄漏而非结构。

### 2.2 目标导向实验设计可以改变有效信息

Attia、Alexanderian 与 Saibaba 将 goal-oriented OED 定义为直接最小化目标量的后验不确定度，而不是平均优化全部参数（`10.1088/1361-6420/aad210`）。Alexanderian、Nicholson 与 Petra 进一步把模型不确定性和 secondary parameters 纳入非线性 OED，明确指出忽略模型不确定性会导致设计失真（`10.1088/1361-6420/ad602e`）。

推广到多传感器 bench 后，设计变量应包含传感器开关、频点、压力、RH、激励功率和 dwell time；目标函数使用组分方向的 `c^T I_eff^-1 c` 或 P90，而不是 `det(Fisher)`。这正是 tv3 的 RG-cOED 从“选频”升级为“跨模态资源分配”。

**边界**：设计只对模型正确、硬件可切换且状态在切换期间近似稳定时成立。最小证伪实验是不生成波形，先用三档信息量旋钮比较固定设计、随机设计和稳健目标导向设计的留出工况 CRB；留出工况不改善则停止进入训练阶段。

### 2.3 同步采样只在共模误差真实存在时有价值

系统辨识文献已把 multisine 作为输入设计问题，而不是网络结构问题。Bombois 等研究了不确定性下的稳健 multisine 实验设计（`10.1016/j.automatica.2020.109431`）；González 等讨论了 multisine 输入下连续时间系统的一致辨识（`10.1016/j.automatica.2021.109859`）。这些工作支持“同步激励可能改变采样效率”，但不支持本项目预先假定跨频误差是共模的。

因此 SIMD 的一般化版本必须先测误差协方差：若跨传感器或跨频误差有显著低秩主成分，再比较同步与顺序采样；若误差独立，multisine 可能因互调和单频能量下降而变差。

## 4. 对候选集的结论

可进入候选集的不是“物理引导网络”这一宽泛表述，而是两个窄机制：**共享组分 / 传感器私有 nuisance 的变量投影展开**（估计效率候选）和**在模型不确定性下的组分目标导向 OED**（信息增益候选）。同步 multisine 先列为条件性候选，必须等台架协方差证据。
