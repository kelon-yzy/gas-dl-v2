## 本阶段已确认的两条结论

1. **"DL 未超过调好的线性基线"不能作为对外的方法学发现。** 化学计量学已有同类结论（Yan 2020 分项、Fan 2025 轻量方法反超 DL）。作为项目内部决策依据仍然成立。
2. **C1 的基础组件已有直接先例，保留的是更窄的组合改进空间。** 气体传感内已经有 resolving power、CRLB selectivity、信息论检测限、局部分区和特征选择；本轮仍未检索到把预注册信息档位、强基线、候选算法与 oracle 的优势区间放在同一基准中的工作。该空间约为 T2，适合作为 P2 评估框架，不得写成基础信息论方法的首次提出。
