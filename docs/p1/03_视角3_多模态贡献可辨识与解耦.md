# 视角 3 · 多模态贡献可辨识与解耦（推广稿）

> 检索日期：2026-08-22  
> 目标：判断“共享潜变量 + 模态私有 nuisance + 一致性约束”能否在多组分传感器融合中被辨识，而不是只带来指标提升。

## 1. 从 tv3 的 SMVCI 到一般多视图反演

一般多视图模型为 `y_s = F_s(theta_shared, eta_s; d_s) + epsilon_s`。多视图的可用性取决于：组分在视图间保持不变、各视图的干扰参数确实不同、且至少一个视图提供新的条件信息。简单拼接、共享编码器或 attention 不能自动保证这些条件。

Lyu 与 Fu 对 nonlinear multiview analysis 给出了可辨识性与神经网络实现的统一讨论（`10.1109/tsp.2020.2986351`）。Zheng、Ng 与 Zhang 进一步说明，非线性 ICA 的可辨识性需要额外结构，如稀疏性或有信息量的辅助变量（`10.52202/068431-1194`）。这两项结果直接否定“多个模态自然会分离组分”的假设。

## 2. 可迁移机制

候选结构应显式拆成三层：

1. `theta_shared`：组分向量或共享物理参数；
2. `eta_s`：传感器私有的增益、延迟、背景和缺测模式；
3. `d_s`：受控变化的频率、RH、压力或激励条件。

训练时以正确配对视图重建各模态，同时加入错误配对、顺序打乱和屏蔽 `d_s` 的负对照。只有当正确配对优于这些对照，才能把收益归因于可辨识的跨模态信息，而不是普通正则化或数据泄漏。

## 3. 已占领领地与本项目可写范围

“多视图共享潜变量具有可辨识性”属于 T3/T4 的方法学领地，不能作为首次发明。可以写的迁移差异是：本项目的视图不是同一图像的不同增强，而是声学、光学、热导等具有不同物理前向的传感器；共享变量是组分，私有变量是跨传感器 nuisance。这个差异必须在前向模型和负对照中落地，不能只写在网络图上。

## 4. 最小证伪实验

在同一 `mixture_id` 下生成两个或三个受控视图，比较：直接拼接、共享 / 私有潜变量、错误配对、时间顺序打乱、单视图和屏蔽条件标签。指标同时报告组分误差、OOD 条件误差、每个模态的遮蔽增益和潜变量交换后的重建误差。若错误配对也改善，候选出局；若只在同分布测试改善，视为表示正则化而非可辨识性收益。

## 5. 视角 7 判定

| 机制            | 大气遥感 / 地球物理 | 医学成像 | 系统辨识 | 计量学      |
| ------------- | ----------- | ---- | ---- | -------- |
| 共享 / 私有多视图潜变量 | 零散工作        | 常规做法 | 零散工作 | 零散工作     |
| 非线性多视图可辨识性    | 零散工作        | 零散工作 | 零散工作 | 未检索到直接同类 |

结论：SMVCI 只能作为“跨物理模态、共享组分与私有干扰的可辨识迁移”候选，不能作为一般 multi-view disentanglement 的新方法声明。
