# P1 创新点候选集（冻结版）

> 版本：2026-08-23  
> 依据：`00_检索协议.md`、`01–07` 视角文档、`references/references.json`。  
> 进入 P2 的候选必须满足本文件 §6 的预注册门。

## 1. 评审结论摘要

P1 阶段门判定为**通过并关闭**：候选集、领地清单和预注册判据齐全，且 C1 有可追溯的收益量级先验。进入 P2 时以 C1 为评估框架与组合改进规格草案，C2–C4 保留为观察候选：

1. **C1 信息谱条件化评估**：把传感器、噪声、先验和组分窗口做成信息量刻度，比较算法优势出现在哪一段。
2. **C2 共享组分 / 私有 nuisance 的变量投影展开**：将可消去的增益、基线、延迟或串扰参数从迭代中解析消去，再学习剩余非线性更新。
3. **C3 目标雅可比正交的 model discrepancy**：把模型偏差投影到目标组分灵敏度的加权正交补，降低偏差与组分的混淆。
4. **C4 可辨识性约束的跨模态共享 / 私有表示**：共享组分信息进入共享支路，模态私有 nuisance 保留在私有支路，并用模态遮蔽与随机置换检验贡献是否真实。

C1 是主评估框架，不是基础信息论算法候选；C2–C4 是待由 P2/P3 前向审计和最小证伪实验筛选的机制候选。候选不是“换一个更大的网络”，而是改变观测设计、求解器、偏差参数化或表示约束。

## 2. 候选 C1 · 信息谱条件化评估

### 机制

把传感器组合、噪声水平、干扰先验宽度和组分窗口设为预注册的离散 / 连续因素；每档先计算目标方向 Fisher 有效信息、CRB 与等效目标误差 P90，再报告强基线到 oracle 上限之间的可争夺空间，以及候选算法优势出现的档位。

### 现有方法为什么做不到

信息量分析和目标导向 OED 在大气遥感、地球物理和逆问题中是成熟做法（Rodgers；Attia；Alexanderian）；气体传感内也已有 resolving power、CRLB selectivity、信息论 LOD、局部分区和特征选择先例（Gardner；Fonollosa；Johnson；Fernandez）。视角 1–7 的补充反向核查仍未检索到把预注册信息档位、强基线、候选算法与 oracle 优势区间联合报告的气体多组分基准。该空间按 **T2 组合改进**处理，不能写成基础信息论方法的“首次”。

### 收益量级先验

收益先验来自 tv3 冻结产物 `tunnel_ventilation/docs/paper/artifacts/fig2_d0_information.csv`：oracle Ridge 的验证集 R² 为 `0.6025`，测量级 Ridge 为 `0.4226`，oracle inflation 为 `0.1799`，计算式为 `0.6025 - 0.4226`。因此把 `Δ_oracle ≥ 0.05 R²` 作为可测差异的预注册下限，相当于已观测 oracle–measurement 空档的 27.8%，高于项目现有约 `0.001 R²` 的报告分辨率；这只是收益量级先验，不是新 bench 的实测结果。C1 的 primary endpoint 预注册为信息档位上强基线到 oracle 空档的回收比例：以 5 个固定 split × 3 个 seed 的 paired 差值计算 95% bootstrap CI；只有当空档点估计 `≥ 0.05 R²` 且回收比例 CI 下界 `≥ 20%` 时，才认定达到可测收益。P90 下降只能作为 secondary endpoint，不能与 primary endpoint 择优替代。

### 最小证伪实验

不训练大规模深度模型。先固定三档预设因素：低档仅慢通道 + 高噪声，中档慢 / 快通道组合 + 中噪声，高档全模态 + 低噪声；每档运行 Ridge、GBDT 和固定容量 MLP / TCN，计算 Fisher / CRB、oracle、测量级基线和强表格基线。5 个固定 split × 3 个 seed 的 primary endpoint 未达到门值时，C1 只保留为评估协议，不进入算法主张。

### 失效条件

信息旋钮不能独立改变有效信息；CRB 计算遗漏主要噪声或模型偏差；强基线已贴近 oracle；或优势只在单个随机种子 / 单个 split 出现，均视为候选失败。

## 3. 候选 C2 · 共享组分 / 私有 nuisance 的变量投影展开

### 机制

将多传感器前向模型拆为共享组分 `theta` 与传感器私有、可分离的 nuisance `eta_s`。每层展开执行一次解析变量投影，再用学习到的阻尼或预条件器更新 `theta`；不把 nuisance 真值输入网络。

### 现有方法为什么做不到

变量投影和 algorithm unrolling 的基础方法已被 Golub–Pereyra、Español–Pasha、Monga 等占领。可迁移的缺口不是“首次提出展开”，而是验证共享组分 / 私有 nuisance 的跨模态结构是否在气体组分反演中提升估计效率。若目标与 nuisance 的雅可比共线，变量投影不会突破同一观测模型的 CRB。

### 收益量级先验

在 nuisance 可分离且存在明显共线时，先验目标为：相对同容量 MLP / TCN，目标组分 P90 下降 `≥ 10%`，或固定计算预算下达到同一 P90 所需迭代步数下降 `≥ 30%`。若 nuisance 与目标灵敏度近正交，预期收益为 0，不能强行解释成算法失败。

### 最小证伪实验

固定前向模型、噪声、参数量和训练预算，只比较解析 Gauss–Newton、纯 MLP、无真值泄漏的 VP 展开。设置 nuisance 与目标雅可比夹角为高、中、低三档；若高共线档仍无 P90 或收敛效率改善，候选淘汰。

### 失效条件

不可分离 nuisance、错误的可分离假设、投影数值不稳定、真实噪声协方差未进入投影度量，或收益仅来自把 nuisance 真值泄漏给网络。

## 4. 候选 C3 · 目标雅可比正交的 model discrepancy

### 机制

把真实观测写成 `y_real = F_sim(theta, eta) + delta + epsilon`。用前向审计得到的目标雅可比 `J_theta` 定义加权正交补，将 discrepancy 基函数投影到该补空间，再对不同模态使用独立协方差；校准数据必须含留出工况和留出传感器组合。

### 现有方法为什么做不到

Bayesian calibration、orthogonal GP 与 scaled GP 已占领模型偏差校准的基础方法（Kennedy–O'Hagan；Plumlee–Joseph；Gu–Wang）。候选的窄问题是：在多传感器组分反演中，按目标雅可比而不是输入参数坐标构造正交补，能否减少目标偏差而不牺牲留出工况覆盖率。该方向必须写成迁移和实证检验。

### 收益量级先验

在预先注入的模型偏差幅度为目标信号尺度 `0.2–1.0` 倍时，目标为：相对自由残差模型，留出工况目标 MAE 下降 `≥ 15%`，且 90% 区间覆盖率保持在 `0.85–0.95`；若只改善波形重建而不改善目标误差，判为失败。

### 最小证伪实验

使用已知偏差生成器，比较无 discrepancy、自由残差、目标雅可比正交残差三种模型；训练工况与留出工况、传感器遮蔽组合分列报告。若正交残差不能同时改善留出目标误差和覆盖率，候选淘汰。

### 失效条件

模型偏差与目标方向不可分、正交投影依赖测试真值、校准数据覆盖不足、偏差随工况非平稳且基函数无法表达，或后验覆盖率改善来自过度保守区间。

## 5. 候选 C4 · 可辨识性约束的跨模态共享 / 私有表示

### 机制

共享支路只接收跨模态可重复的组分信息，私有支路承载传感器增益、延迟、背景和模态特有 nuisance；训练时加入跨模态一致性、私有正交和模态遮蔽负对照。结构收益必须与同参数量随机置换结构比较。

### 现有方法为什么做不到

非线性多视图可辨识性理论已经说明，仅凭融合指标不能证明共享潜变量代表真实组分（Lyu–Fu；Zheng 等）。多任务和注意力气体传感已有大量先例（Wang；Ding；Nguyen），因此“注意力融合”本身不构成创新。候选只关注可辨识性约束、模态贡献可审计以及在遮蔽条件下的稳定性。

### 收益量级先验

在至少一个模态被遮蔽或加入未见 nuisance 的 OOD split 上，目标为相对无约束融合模型 MAE 下降 `≥ 10%`，同时完整模态 test 性能不下降超过 `0.01 R²`。若完整模态提升、遮蔽模态恶化，说明模型只记住模态捷径，候选失败。

### 最小证伪实验

使用同一 encoder 容量，比较普通 early fusion、共享 / 私有分支、同参数量随机分组；加入错误配对、模态遮蔽和 nuisance OOD 三个负对照。只要随机分组不劣于物理分组，或共享表示与目标组分不可线性探测，候选淘汰。

### 失效条件

模态之间没有互补信息、共享组分本身不可辨识、私有 nuisance 与目标完全共线、遮蔽任务改变了数据分布，或一致性损失造成负迁移。

## 6. 候选进入 P2 的预注册判据

### 必须满足

1. 至少 3 个候选，每个候选完整填写“机制、现有方法限制、收益量级、最小证伪实验、失效条件”。
2. 至少 1 个候选的收益量级先验支持 bench 可测差异；本版由 C1 的 `0.1799 R²` 冻结空档推导 `0.05 R²` 预注册下限。P2 前置小样本实验仍需以 paired 95% bootstrap CI 验证，文献先验不能替代实测门。
3. 每个候选都完成视角 7 六领域检查；T4/T5 机制必须改写为迁移，不能保留“首次”措辞。
4. P2 规格书必须把信息量档位、强表格基线、oracle 隔离、负对照和停止条件写成冻结条款。

### 直接淘汰

- 收益门只在 oracle 真值特征或测试真值输入下成立。
- 强基线与 oracle 空档小于 `0.05 R²`，且没有 P90 或覆盖率上的独立收益。
- 候选机制无法关闭或无法做单机制消融。
- 结果依赖随机划分、单 seed、单 split，或存在模态配对 / 目标泄漏。
- 已有直接先例的基础组件被写成“首次”，或把 T2 组合改进写成基础方法原创。

### 评审输出

评审只给出 `进入 P2 规格草案`、`保留观察`、`淘汰` 三种 verdict，并记录证据等级、领地强度、最小实验结果和停止原因；不因 P2 结果回溯修改本节门值。
