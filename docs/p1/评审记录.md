## 3. 阶段门状态

P1 的“候选集结构门”和“收益量级先验门”通过：候选数量、五项完整性、补充后的领地清单、预注册判据齐全；C1 的收益量级由冻结产物 `tunnel_ventilation/docs/paper/artifacts/fig2_d0_information.csv` 中 `0.6025 - 0.4226 = 0.1799 R²` 的已知空档支撑。C1 定位为 T2 组合改进空间，气体传感内已有 resolving power、CRLB selectivity、信息论 LOD 和局部分区先例。P1 文献阶段**于 2026-08-23 正式关闭**，但 P2 的实测收益门尚未通过。

1. Costa 2024 等应用条目的完整模型、重复和强回归基线仍缺；当前只能按摘要 / CrossRef 证据使用，不影响 P1 的领地与候选结构判定。Monsalve 2025、Fernandez 2018、Lakhmi 2024 已完成开放全文核验，Nguyen 2026 已完成公开代码边界核验。
2. C1–C4 尚未完成最小证伪实验；这些实验属于 P2/P3 前置，不在 P1 文献阶段伪造结果。

因此当前允许进入 P2 的动作是：以 C1 为评估框架与组合改进规格草案，保留 C2–C4 作为待审计候选；不允许绕过 P2/P3 实测门直接进入大规模 P4 训练。P1 文献阶段门已通过并关闭，P2 实测门尚未开始。正式关闭条件与 RQ1–RQ3 证据矩阵见 [09_P1补充检索与正式关闭审查](09_P1补充检索与正式关闭审查.md)。
