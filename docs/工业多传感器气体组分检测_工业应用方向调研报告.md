# 工业多传感器气体组分检测应用方向调研报告

**调研日期：2026-08-23**

**定位：** 面向[项目总体规划](../general_fusion/项目总体规划.md)，筛选既有工业需求、又能在实验室获得可靠标签的多传感器气体检测应用。本文保留调研文献、证据边界和实验决策，不替代后续系统综述。

## 1. 筛选原则与第一轮结论

方向按五项指标筛选：工业需求、实验可实现性、真值与数据获取、多传感器/算法空间、后续扩展能力。

如果以“现在开始搭实验”为标准，推荐顺序是：

**工业混合气在线质量控制 → 生物反应器尾气 → 焊接保护气 → 增材制造气氛 → 热处理炉气氛。**

## 2. 五个优先方向：文献证据与研究空白

### 2.1 工业混合气在线质量控制

**文献证据：**

- 多组分真实气体混合系统已经能够生成三元、四元混合气，组成误差优于 0.8%，并用气相色谱验证；MFC 在线混气和多通道分配系统已有工程基础。[9][10]
- 近年研究仍在处理 MFC 误差、自动校准、流量分配和动态稳定性。[11]
- 声速、声衰减、分子内比热、热导率和折射率等物性可用于混合气组成或燃烧性质反演。[12–14]
- 传感器阵列与树模型、自适应修正平台、Transformer 多任务模型已用于混合气识别和浓度预测。[15–17]

**研究空白：** 现有工作通常分别关注高精度配气或电子鼻识别，较少把动态 MFC 混气、异构传感器、物理信息和闭环质量控制放在同一框架中。

**推荐实验：**

气瓶 → MFC → 混气室 → 参考分析仪 → 多传感器腔体 → 排气。优先使用 N2/CO2/O2、Ar/CO2/O2 或 Ar/N2/CO2 等低风险体系；MFC 流量提供标签，参考分析仪负责校验。

建议注入总流量变化、组分阶跃、温压湿度扰动、MFC 偏差、泄漏、漂移和未知组分。该平台最适合支撑 P2/P3 的动态 bench、强基线比较和闭环控制研究。

**评价：** 数据、标签和实验可控性最佳；需要绑定具体工业场景，避免停留在通用静态浓度回归。

### 2.2 工业生物反应器尾气监测

**文献证据：**

- TOM 系统用电化学 O2、红外 CO2、微型泵和动态停气测量在线估计 OTR、CTR 和 RQ，RQ 精度约为 ±4%，可并行连接多个摇瓶。[18]
- 尾气 O2/CO2 已用于工业发酵软测量、生物聚合物过程监测和关键状态预测。[19][20]
- Raman 尾气 CO2 预测、Biofuser 多源数据平台和 Sartorius BioPAT Xgas 说明光谱、尾气、湿度、压力及过程变量正在走向融合。[21–23]

**研究空白：** 低成本替代高价尾气分析仪、湿度交叉影响、批次/菌种迁移、瞬态信息利用，以及由 O2/CO2 进一步预测 OUR、CER、RQ、生物量、底物和产物。

**推荐实验：**

摇瓶或小型发酵罐 → 冷凝/除水 → 多传感器 → 排气；同步采集 O2、CO2、温度、湿度、流量、压力、pH 和 DO，可选浊度、称重、VOC。任务分为尾气组分反演、OUR/CER/RQ 软测量、发酵阶段识别和难测变量估计。

**评价：** 最适合长时序、多模态融合和软传感器研究；O2/CO2 的基础测量已有成熟产品，创新应放在动态融合与过程泛化。

### 2.3 焊接保护气与焊接过程智能监测

**文献证据：**

- 图像与电弧光谱双模态网络已用于焊丝成分和保护气流量监测，多模态优于单一信号。[24]
- 声学加 CNN 可识别保护气流量状态；声音、电流、电压和焊速已用于识别保护气中断、导电嘴磨损和污染。[25][26]
- 声发射、VAE、物理引导和可解释模型正在用于保护气不足及焊接异常监测。[27][28]

**研究空白：** 文献更多判断保护气是否中断或流量是否异常，直接进行保护气多组分浓度反演的工作较少。

**推荐实验：**

第一阶段先用 Ar/CO2、Ar/CO2/O2 或 Ar/He/CO2 做气体组分反演；第二阶段接入 GMAW 或焊接机器人，融合声、光谱、电流、电压和图像；第三阶段预测焊缝质量，形成“气体状态 → 过程信号 → 制造质量”链条。

**评价：** 若实验室具备焊机或机器人平台，该方向优先级很高，论文链条完整。

### 2.4 金属增材制造保护气氛监测

**文献证据：**

- L-PBF 中 lambda probe 可能产生约 700 ppm 偏差，残余氧会影响 Ti-6Al-4V 的 O/N 含量、缺陷和延性。[29][30]
- 低至约 50 ppm 的 O2 控制、Ar 气流与金属蒸气动力学监测已有研究。[31][32]
- 综述和近期工作显示，增材制造正在融合多传感器、机器学习和闭环控制，并将声发射、热信号等用于缺陷监测。[33][34]

**研究空白：** 现有多模态研究多以熔池图像、热辐射或声发射为主，气氛通常只作为单一 O2 数值或背景条件，尚未充分成为独立模态。

**推荐实验：**

先用小型密闭惰性气氛舱、Ar/N2 和人为微量空气泄漏做气氛异常识别，再接入打印设备。重点采集 O2、H2O/露点、气体流量、压力，并与熔池光信号、热像和声发射融合。

**评价：** 前沿性和论文价值最高之一，但 ppm 级传感器、打印设备和材料验证带来较高门槛。

### 2.5 金属热处理炉气氛与碳势监测

**文献证据：**

- 工业资料覆盖 CO/CO2 红外、O2 探头、露点和 NH3 分析，并指出只假设 CO 恒定会造成碳势误差。[35]
- 热处理炉 NDIR 分析仪可连续测量 CO、CO2、CH4 并计算碳势。[36]
- 近年研究已用混合深度学习、机器学习和物理信息机器学习预测渗碳碳含量、浓度分布及工艺结果。[37–39]

**研究空白：** 将 CO、CO2、H2、CH4、H2O、O2 作为动态多组分系统，用异构传感器重建炉气状态、碳势并连接材料质量，仍有明显空间。

**推荐实验：**

先做室温模拟气氛分析，再接入小型或工业炉；采样端需要冷却、过滤和除尘。后续链条为“气体组成 → 碳势 → 硬度/渗层/材料质量”。

**评价：** 工业机理最强，但高温、有毒/可燃气体和材料验证使其不适合作为最早启动方向。

## 4. 推荐研究路线

### 4.1 以实验可行性和数据规模为先

先搭建动态 MFC 多组分气体平台，完成准确标签、信息量刻度、扰动注入和多传感器基线；再迁移到焊接保护气、食品气调、热处理保护气等具体场景。

### 4.2 以深度时序建模为先

选择生物反应器尾气，围绕 O2、CO2、温湿度、流量、压力、pH 和 DO，研究 OUR/CER/RQ 软测量、批次迁移和异常状态预测。

### 4.3 以智能制造价值为先

选择焊接保护气，把上游气体组分和焊接声、光、电信号连接到焊缝质量预测；若有增材制造平台，则可将气氛感知作为独立模态接入熔池/声学监测。

### 4.4 与项目主线的关系

工业 MFC 平台最适合作为 P2/P3 的可控 bench 或工程载体；焊接、生物制造、增材制造和热处理适合作为 P5 的应用验证。应用调研不能替代 P1/P3 的候选晋级实验。

## 5. 下一轮检索重点

下一轮应按方向建立独立文献矩阵，不再泛搜 multi-gas sensor。每篇至少记录：目标气体、浓度范围、传感器、采样频率、数据量、装置、算法、验证方式、误差指标、数据开放性、是否动态、是否含温压湿度、是否考虑漂移、是否有工业现场验证。
