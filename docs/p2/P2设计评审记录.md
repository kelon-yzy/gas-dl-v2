# P2 bench 设计评审记录

> 评审日期：2026-08-25
> 评审范围：`controlled_synthetic` 多模态四组分算法 benchmark
> H3 verdict：`pass`

## 1. 评审边界

本评审判断 P2 规格是否足以约束 P3 实现，不判断任何候选算法已经优于基线。目标 TraceGas、PSC200K 和完整仪器链路不是当前前向模型的保真对象；P2/P3 只允许在同一冻结合成 profile 下作配对相对比较。设备绝对误差、检测限、响应时间和现场性能不在本 verdict 的适用范围。

## 3. G3 可达性复核

- G3-1：任一前向负对照失败都会停止数据生成并返回前向设计。
- G3-2：任一信息/夹角单元不可达都会返回 S1 旋钮设计。
- G3-3：数据完整性与强基线空档分别有失败路径；强基线打平 oracle 时不进入候选实验。
- G3-4：至少一个候选清除预注册门才允许进入 P4；全失败是合法阶段结论。
- G3-5：正式数据只从通过门的冻结配置生成，hash、split 或 profile 漂移均使 attempt 失败。

## 4. 评审结论

P2 的必填规格、数值证据、授权门、失败路径与工程所有权均已闭合，没有需要在 P3 启动前补写的规格字段。H3 verdict 为 `pass`，P2 关闭，允许启动 P3 G3-1。

该结论不改变现实硬件验证仍属于 P5 的事实，也不允许把 synthetic `source_complete` 改写为目标器件已验证。
