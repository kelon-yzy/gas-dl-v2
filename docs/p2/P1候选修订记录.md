### 1.3 已授权的新 endpoint

将 C2 主收益轴改为“同精度下效率非劣或优越”，保留精度改善为 secondary endpoint：

- primary：在预注册的 3 × 3 信息量 × Jacobian 夹角单元中，C2 的 P90 误差相对强基线不劣，并在固定硬件、预算、split 和 seed 下比较 iterations、forward calls、wall-clock 与推理延迟。
- secondary：P90/RMSE 的相对改善；不再把小幅精度改善单独作为 C2 主张。
- 配对单位：同一 `mixture_id`、同一 3 × 3 单元、同一 split/seed、同一硬件和预算下的 paired 运行。
- 统计：点估计、重复计时的配对置信区间、按信息单元分层的 bootstrap；禁止单次计时结论。
- 非劣带：候选相对配对强基线的分组分 P90 绝对差之 95% CI 上界不得超过 `N2=0.008`、`CO2=0.003`、`O2=0.010`、`Ar=0.005 mol/mol`。四项分别取 P2-06 已冻结 `tau_j` 的 10%，即至少保留 90% 的 bench 容差预算；四项必须同时通过，不能用宏平均掩盖单组分失败。
- 效率门：`iterations` 与 `forward_calls` 至少下降 30%，`solver_wall_clock` 与 batch size 1 的 `single_sample_latency` 至少下降 20%；上述任一指标的 95% 配对 CI 清除对应门值，且其余 primary efficiency metric 的相对回退均不超过 5%，才记为效率优越。
- 计时口径：固定 30 次独立重复；每次推理先 warm-up 10 batch，再计时 30 batch，batch size 为 `1/32/256`；采用配对随机交错顺序，报告中位数和 95% paired group bootstrap CI。单次结果不得形成结论。
- 硬件 profile：`GIB-HW-WIN-R9-8940HX-RTX5060L-20260825`，CPU 为 AMD Ryzen 9 8940HX（32 逻辑线程），GPU 为 NVIDIA GeForce RTX 5060 Laptop GPU（8151 MiB，driver 610.62），Windows NT 10.0.26200.0 64-bit，Python 3.13.11。CPU 与 GPU track 分开报告；配对方法必须共享完全相同的设备、线程和软件指纹。

## 3. C5 候选登记

C5 是效率类候选池，不是四个方向同时自动立项。每张卡均须先通过廉价前置，随后才可由 P3 矩阵决定是否执行。

### C5-A · CRB 驱动自适应采样与 Early Exit

- 角色：测量时间、采样点数、激活模态和 FLOPs 的效率候选。
- 前置：P2 提供样本级 Fisher/CRB、增量信息和 3 × 3 单元；目标误差非劣带与停止阈值必须先授权。
- 对照：完整采样、固定短窗口、uncertainty early exit、CRB early exit、CRB + 动态模态选择。
- primary endpoint：在 P90/RMSE 不劣于完整采样的条件下，测量时间、采样点数、激活传感器数和 FLOPs 的配对变化。
- secondary endpoint：新增时间窗、采样点或模态的 `Delta I` 与 `Delta I / Delta cost`。
- 最小证伪：在每个信息量与夹角单元记录当前 CRB、下一步增量信息和实际成本，并与固定策略配对。
- 停止条件：非劣带失败、增量信息与成本记录不闭合、收益只在单一 seed 或单一单元出现，或 CRB early exit 不优于固定短窗口时停止。

### C5-B · FO-MPLSELM

- 角色：低成本轻量候选、强基线和数据效率基准；不得默认写成新算法晋级。
- 前置：固定误差带、相同 mixture group split/seed、相同预算；先建立 Ridge、PLS、ELM、PLSELM、XGBoost 和轻量 CNN 对照。
- primary endpoint：在目标误差不劣的条件下，训练 mixture group 数量、训练时间、推理成本和 FLOPs 的减少。
- secondary endpoint：常规误差、learning curve 和跨模态/噪声单元稳定性。
- 最小证伪：在嵌套 `10% / 25% / 50% / 75% / 100%` mixture group 子集上配对比较；不得使用 oracle 真值特征。
- 停止条件：固定误差下没有样本或计算成本优势、只在单一比例或 seed 优势、或优势来自 oracle 输入时停止；PLSELM 已有先例，不得用“首次”表述。

### C5-C · CR-PKD

- 角色：低成本 DSP 部署路径；同时受 C4 跨模态互补性和 C5 效率前置约束。
- 前置：raw teacher 必须显著优于 DSP 强基线；否则不建立蒸馏实验对象。
- 对照：raw teacher、DSP student、普通 KD、Physics/Fisher KD，保持输入层、参数预算和 split/seed 可配对。
- primary endpoint：DSP student 在误差非劣的前提下达到更低 CPU 延迟、FLOPs、输入带宽或存储成本。
- secondary endpoint：参数量、原始波形与 DSP 的信息差、跨模态遮蔽稳定性。
- 最小证伪：先完成 raw teacher 对 DSP 强基线的独立比较，再运行四路对照并分列报告。
- 停止条件：raw teacher 不显著优于 DSP 强基线、student 无成本优势、或优势只来自真值/未部署字段时停止。

### C5-D · FIGS

- 角色：基于信息区域的异构求解器路由，连接 C1、C2 与 C5。
- 前置：至少两个 solver 必须在不同信息区域分别占优；若一个 solver 在所有区域最好，不启动 FIGS。
- 对照：固定使用单一最强 solver、物理规则路由、轻量模型修正规则路由；第一版不得直接使用黑箱 MoE。
- primary endpoint：在误差非劣约束下，组合成本 `C = L_error + lambda_t × t + lambda_e × E` 相对固定 solver 的配对下降。
- secondary endpoint：路由准确率、错误路由代价、每个 3 × 3 单元的 solver difficulty。
- 最小证伪：先分别完成至少两个专家在不同单元的独立胜出，再运行固定 solver 与规则路由的配对实验。
- 停止条件：没有两个区域化胜出专家、一个 solver 全域不劣、路由不降低成本，或收益只来自测试结果后调规则时停止。

### 4.1 C5 授权门

- C5-A：四组分 P90 同时通过上述非劣带；测量时间、采样点数或激活模态数至少一项下降 20%，其余已登记原生成本回退不超过 5%。

授权值的统计设计遵循“门值预先指定并由 CI 排除超界损失”的非劣原则；具体 10% `tau_j`、20% runtime 与 30 次重复是结合本项目容差、原 P1 30% 结构收益门和当前硬件 profile 作出的工程冻结，不冒充外部文献给出的通用常数。
