1. `gas_head` 和 `softmax100` 不再作为主线尝试。

### 3.1 执行优先级（审查修订）

证据（ML-DL 全分量级差距、每个 run 的 CH4↔CO2 此消彼长）指向瓶颈在"相位窗口信息的提取"，不在权重或容量。据此调整执行顺序与预期：

1. **P4-lite 先做，零训练**：每个 run 的 `metrics.json` 已含 `conditional_metrics.n2_bins` 的 per-bin 指标，无需新训练即可对比 DL 与 Ridge 在哪些浓度区间失败。先做这步，再决定后续投入方向。
2. **P0 作为低成本排除项**：~半小时一次，保留，但**预期不高**——在固定的 raw 模型能力上限内调权重，难以让 overall 跳到 0.52+。把它当筛除而非期望赢家。
3. **P3-A 提前**：这是证据指向的方向，**不再严格以 P0/P2 失败为前提**。P4-lite 确认相位信息缺失后，可与 P0 并行或紧随启动。
4. **P2 容量扩张降级**：在 train ~4000 上给 raw 模型加容量，过拟合风险大于收益，仅在 P3-A 也无效时再考虑，且必须带过拟合监控。

### 3.2 DL 的价值主张（需在结果中说明）

Ridge 多窗口已达 0.925。继续做 DL 要先界定目标：
- 若目标是**逼近 ML 精度**：P3-A（把已验证的相位统计喂给 DL）合理，但本质是"Ridge 特征 + 神经 head"，需在结论中如实说明这一点。
- 若目标是**无需手工窗口的端到端学习**：P3-A 偏离该目标，应优先 P3-B 或纯 raw 路线。

文档默认采用第一目标（逼近精度），结果报告中标注 DL 是否依赖手工特征。

## 4. ✅ P0：温和组件权重（最低成本）— 配置已创建，待服务器执行

目标：验证 CO2 可学信号能否在不牺牲 CH4 的情况下转化为 overall 增益。

**实现方式修正（关键）**：baseline 用 `inverse_train_var`，代码中它与显式 `component_weights` 互斥（`losses.py:253-254`），不能直接组合；且 loss 无归一化（`losses.py:106`）。要做"相对 baseline 的温和加权"，正确做法是**先取 baseline 的 inverse_train_var 权重，再逐分量乘以温和因子**，把乘积作为显式 `component_weights` 写入配置。这样 scale 与相对方向都与 baseline 一致，只多了目标组分的温和倍率，才是真正的单变量改动。

precompute 步骤（一次性）：

```text
w_invvar = 1.0 / var(train_targets[:, :4])     # 四个数，量级约 0.003~0.05
component_weights = w_invvar * multiplier       # 逐元素相乘
```

直接写 `[0.8,0.8,1.6,0.8]`（均值=1）是错误做法：它把 loss 放大约 50×（≈35 vs baseline 0.69），并把相对方向改成近似均匀，可能反而降低 CO2/N2 的相对权重。**不要用均值=1 的归一化。**

### 精确 precompute 结果（2026-06-24）

通过复现 LHS 采样计划（seed=20260525）计算训练集 4200 样本的精确方差：

```text

w_invvar:  [0.009596, 0.006450, 0.054021, 0.029976]
Sum(w_invvar) = 0.100（baseline loss 量级 ~0.69，null-model loss = 4.0）
```

## 5. P1：raw4 轻量闭包约束

进入条件：P0 让 overall 或 CO2 有改善，但 sum_abs_error 仍高于 baseline，或下游必须控制四组分加总误差。

目标：保留 `raw4` 的可训练性，同时缓解 sum 不等于 100 的问题。

### P1-0：先做无训练后处理评估

对已保存预测做闭包投影：

```text
pred_closed = pred - (sum(pred) - 100) / 4
```

只用于评估，不改训练。

若投影后 overall R2、CH4 R2 或 CO2 R2 明显下降，则不要进入训练版 closure penalty。

### P1-A：轻量 closure penalty

在 raw4 loss 上加入闭包项：

```text
base_loss = weighted_component_mse(pred, target)
closure_loss = mean(((sum(pred) - 100) / 100) ^ 2)
total_loss = base_loss + lambda_closure * closure_loss
```

**lambda 标定（修正）**：baseline 下 sum_abs_error≈7，则 `closure_loss ≈ (7/100)² ≈ 0.005`；base_loss≈0.69。原建议 lambda=1/5 时 closure 仅占 base 的 0.7%~3.6%，按梯度量级算 closure_grad/base_grad ≈ lambda·1.4%，推不动 25% 的 sum_abs_error 下降目标。要让 closure 占 base 梯度约 30%，lambda 需 ~20。

建议先试：

```text
lambda_closure = 10
lambda_closure = 20
lambda_closure = 40
```

**前置依赖**：lambda 的标定基于 base_loss≈0.69 的量级。若 P0 的权重量级未按第 4 节修正、base_loss 跳到几十，则上述 lambda 全部失效，必须先修好 P0 量级再标定 lambda。

### P1 判据

通过条件：

```text
sum_abs_error 相比 baseline 至少下降 25%
test overall R2 不低于 baseline - 0.02
CH4 R2 不低于 baseline - 0.05
CO2 R2 不低于 baseline
```

若 closure penalty 让 overall 或 CH4 明显退化，则保留纯 raw4，不继续加大闭包权重。

## 7. 🔲 P3：相位信息接入强 backbone（P4-lite 确认后即启动）

进入条件（修订）：P4-lite 确认相位信息缺失后即可启动，**不必等 P0、P2 全部失败**。这是证据指向的主方向（见第 3.1 节）。

**P4-lite 验证结果（2026-06-24）**：
- ✅ DL 全分量失败，CH₄ 和 CO₂ 差距最大（R² 差距分别为 0.500 和 1.027）
- ✅ Ridge 全分量 per-bin 为正（除 N₂ 外），DL 均负值——相位信息缺失确认
- → P3-A 方向有强依据，代码待开发

目标：利用 ML 多窗口 Ridge 已验证有效的 `full + exposure + recovery` 信息，但避免重复 PhaseWindowTCN 的失败路径。

不建议直接复活原始 PhaseWindowTCN concat-only 结构。推荐两条更稳路线：

### P3-A：手工相位统计特征分支

把 ML 多窗口中的统计特征作为额外 tabular branch 接入 CNN1DTCNFusion：

```text
raw sequence branch -> CNN1DTCNFusion pooled feature
phase-stat branch   -> MLP
concat              -> shared head -> raw4
```

目的：先验证"已知有效的相位统计特征"能否帮助 DL head。

P3-A 判据：

```text
test overall R2 >= 0.65
test N2 R2 > 0.10
sum_abs_error 不高于 baseline
```

若 P3-A 无效，说明问题不只是特征入口，而是 DL head/训练目标不能复用 ML 特征。

### P3-B：full anchor + phase delta 分支

保留 full window 主分支作为 anchor，不让 exposure/recovery 直接覆盖主预测：

```text
full branch -> base_pred
exposure/recovery branch -> delta_feature
component_gate -> delta_pred
final_pred = base_pred + gated_delta
```

目的：让 phase window 只提供组件级修正，避免像 PhaseWindowTCN 一样把 full、exposure、recovery 简单 concat 后整体破坏 H2/CH4。

P3-B 判据：

```text
test overall R2 >= 0.65
test N2 R2 > 0
CH4 R2 不低于 baseline
```

## 8. ✅ P4：CO2 与 N2 数据侧诊断（前置 P4-lite）

P4 与 P0-P3 并行，不阻塞训练。其中 **P4-lite 无需训练，应最先做**（见第 3.1 节）。

### P4-lite 执行结果（2026-06-24）

通过读取 `outputs/runs/` 下已有 `metrics.json` 的 `conditional_metrics` 完成分析：

**N₂ per-bin 关键发现**：
- Ridge 在所有 4 个 N₂ 浓度区间的 per-bin N₂ R² 均为**负值**（-1.65 ~ -5.95）
- DL 同样在所有区间为负值（-1.65 ~ -30.94）
- 结论：N₂ 在窄浓度带内对**两个模型都不可预测**，这是数据可辨识性问题（H₂+CH₄+CO₂ 的高协方差），不是模型容量问题
- Ridge 的 +0.712 总体 N₂ R² 只来自跨浓度区间趋势捕获，不是细粒度预测

**CH₄ per-bin（DL vs Ridge 真实差距）**：

| CH₄ 区间 | Ridge CH₄ R² | DL CH₄ R² |
|---|---|---|
| 40-54% (n=97) | -0.26 | -3.85 |
| 54-68% (n=192) | 0.50 | -1.06 |
| 68-82% (n=219) | 0.18 | -4.15 |
| 82-95% (n=92) | 0.06 | -16.68 |

- Ridge 在所有区间保持正或接近零的 CH₄ R²；DL 在所有区间严重负值，极端区间完全崩坏
- 这是 DL 与 Ridge 的**真差距共 0.500**（比 N₂ 的 0.718 更本质）

**结论**：
1. ✅ 相位信息缺失确认——ML 多窗口统计（full/exposure/recovery）捕获了组分特异性时序特征，DL raw 波形未学到
2. ✅ P3-A 方向有强依据——特别对 CH₄ 和 CO₂ 有最大提升空间
3. ✅ P0 仍应作为低成本排除项——权重调整不会解决相位信息缺失，但~30 分钟训练成本值得做
4. ✅ N₂ 在窄浓度区间的不可预测性是数据约束，不是模型改进能解决的

目标：避免把数据分布问题误判为模型问题，并据此选定后续投入方向。

诊断项：

| 诊断 | 方法 | 是否需训练 | 判断问题 |
|---|---|---|---|
| CO2/N2 条件表现 | 直接读各 run `metrics.json` 的 `conditional_metrics.n2_bins` per-bin 指标 | 否（P4-lite） | 模型是全局失败还是只在某些浓度区间失败 |
| Ridge 多窗口 per-bin 对比 | 对比 ML 成功区间与 DL 失败区间 | 否（P4-lite） | DL 是否缺失某类相位信息 |
| CO2 与 N2 cross-split 方差 | 读取 split label stats | 否 | split 分布是否一致 |
| 与 CH4 的条件关系 | 计算给定 H2、CH4 后 CO2/N2 残差可解释性 | 是 | CO2 是否被 CH4 协方差遮蔽 |

P4-lite（前两项 + cross-split 方差）先跑，结论直接影响是否值得投 P2、是否应优先 P3-A。

若 P4 显示 CO2 或 N2 只在特定区间可学，则后续实验按区间报告，不只看全局 R2。

## 9. Multi-seed 进入条件

本项目目标核心是 N2，两支进入条件都要求 N2 转正（修正第二支原本不要求 N2>0 的矛盾）：

```text
test overall R2 >= 0.60 且 test N2 R2 > 0
或 test overall R2 >= 0.65 且 test N2 R2 > 0 且 CH4/CO2 均不退化
```

例外记录：若出现 `overall R2 >= 0.65 但 N2 R2 <= 0`，记为"高总体精度但 N2 未解"候选，写入结果但**不进入 multi-seed**，除非后续把 N2 推正。

推荐 seeds：

```text
[20260615, 20260623, 20260630]
```

通过标准：

```text
3 个 seed 中至少 2 个 test overall R2 >= 0.60
3 个 seed 中至少 2 个 test N2 R2 > 0
mean test overall R2 >= 0.60
不存在 overall R2 < 0.45 的崩坏 seed
```

## 10. 停止条件

满足以下任一条件时，停止当前 DL 子路线：

```text
连续两个同类改动 test overall R2 < 0.52
任一改动导致 CH4 R2 比 baseline 下降超过 0.08
sum_abs_error 持续高于 8.0
N2 R2 仍为负且 overall R2 已饱和在 0.50 附近
P3-A 与 P3-B 均无效（相位信息接入也无法提升）
```

此时正式结果仍保留 ML 多窗口 Ridge，DL 只作为负结果和补充讨论。

---

## 11. 不再投入的方向

明确停止：

```text
gas_head 闭包残差参数化
softmax100
ILR/ALR 作为主线
[1,1,5,5] 或更强的 CO2/N2 硬权重
均值=1 归一化的显式 component_weights（应改用 inverse_train_var * multiplier）
从 epoch 1 开始 cosine annealing
未建立同 seed baseline 的跨实验比较
直接上复杂 attention / DCT / PAF-Net 式结构
```

保留但低优先级：

```text
带 warmup 的 cosine
更复杂的 window attention
N2 独立 head
P2 raw 模型容量扩张（过拟合风险，仅 P3 失败后考虑）
```

这些只在 P0-P3 出现正信号后再考虑。
