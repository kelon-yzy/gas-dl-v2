# 当前声学链路问题记录

## 1. 背景

当前项目中存在两路声学波形模拟：

1. `ultrasonic`：超声波发射探头与接收探头构成的对射式 TOF 检测链路。
2. `fiber_mic`：用于声衰减特征提取的光纤探头 + 光纤麦克风分离式传感链路。

相关代码主要位于：

- `src/sim/generation/waveforms.py`
- `src/sim/generation/acoustic_physics.py`
- `src/sim/generation/slow.py`

根据实际装置原理，`ultrasonic` 和 `fiber_mic` 不应只是两条相似声学波形通道，而应分别对应不同物理测量机制。

## 2. 实际装置原理摘要

### 2.1 超声 TOF 链路

实际原理：

- 超声波发射探头与超声波接收探头隔空相对；
- 构成完整对射式声学检测链路；
- 主要用于精准锁定声波飞行时间，即 TOF；
- 通过 TOF 反演宏观声速；
- 推杆轴向位移可动态调节检测声程。

该链路的核心观测量应为：

- TOF；
- 声程 `L_m`；
- 由 `L_m / TOF` 反演得到的宏观声速；
- 可选的传播幅值衰减。

### 2.2 光纤声衰减链路

实际原理：

- 装置采用“探头 + 麦克风”分离式光纤传感架构；
- 光纤探头深入混合气团内部，作为无源敏感前端；
- 光纤探头利用光波干涉原理捕获声压变化；
- 声压变化与天然气组分引发的分子弛豫效应和微弱声能衰减有关；
- 光纤探头将光参量信号通过光纤传输至腔体边界的光纤麦克风；
- 光纤麦克风作为光电解调中枢，完成光电转换、放大和模拟电信号输出；
- 最终信号进入高速数据采集卡。

该链路的核心观测量应为：

- 局部声压响应；
- 分子弛豫导致的声能衰减特征；
- 光纤干涉相位或光强变化；
- 光电解调后的模拟电压波形；
- DAQ 采样后的数字波形。

## 3. 当前代码实现现状

### 3.1 `ultrasonic` 当前实现

代码位置：

- `src/sim/generation/waveforms.py`
- 函数：`simulate_waveform_measurement(...)`

当前实现逻辑：

```text
气体组分 + 温度 + 压力 + 湿度 + 声程
   ↓
hidden_sound_speed_v2(...)
   ↓
计算声速 c_sound
   ↓
hidden_attenuation_v2(...)
   ↓
计算声衰减 alpha_true_npm
   ↓
tof_s = l_m / c_sound
   ↓
peak_index = tof_s * sample_rate
   ↓
生成 40 kHz burst pulse
   ↓
将 pulse 放入 peak_index 位置
   ↓
按 exp(-alpha * l_m) 缩放幅值
   ↓
加噪声
   ↓
量化为 int16
```

该实现与实际“对射式 TOF 链路”基本一致。

### 3.2 `fiber_mic` 当前实现

代码位置：

- `src/sim/generation/waveforms.py`
- 函数：`simulate_fiber_mic_measurement(...)`

当前实现逻辑：

```text
气体组分 + 温度 + 压力 + 湿度 + 声程
   ↓
hidden_sound_speed_v2(...)
   ↓
计算声速 c_sound
   ↓
hidden_attenuation_v2(...)
   ↓
计算声衰减 alpha_true_npm
   ↓
生成直达声 pulse
   ↓
生成多次墙面反射 pulse
   ↓
按 wall_reflection_coef 和 exp(-alpha * path_length) 衰减
   ↓
叠加噪声
   ↓
量化为 int16
```

当前 `fiber_mic` 更像是：

```text
声衰减 + 多路径反射 + 理想 ADC 量化的声学代理模型
```

而不是完整的：

```text
光纤探头干涉感知 + 光纤传输 + 光电解调 + 采集卡输出
```

## 4. 原理一致性评估

| 链路      | 实际原理                   | 当前代码                                                   | 一致性    |
| ------- | ---------------------- | ------------------------------------------------------ | ------ |
| 超声 TOF  | 发射探头与接收探头对射，测 TOF 反演声速 | 用 `tof_s = l_m / c_sound` 决定主脉冲位置                      | 基本正确   |
| 推杆调声程   | 推杆轴向位移动态改变声程           | `path_lms` 和 `_path_l_m_for_timestep(...)` 离散改变 `L_m`  | 简化正确   |
| 声衰减模型   | 分子弛豫导致声能衰减             | `hidden_attenuation_v2(...)` 包含 CO2、CH4、H2O 弛豫与 H2 扩散项 | 部分正确   |
| 光纤探头    | 无源敏感前端深入气团，捕获局部声压      | 无独立光纤探头模型                                              | 缺失     |
| 光波干涉    | 声压变化引起光相位或光强变化         | 无相位、干涉、光参量模型                                           | 缺失     |
| 光纤传输    | 光参量信号通过光纤传输至边界解调端      | 未显式建模，可理解为理想折叠但未声明                                     | 缺失或隐含  |
| 光电解调    | 光纤麦克风完成光电转换、解调、放大      | 当前为声学波形直接 int16 量化                                     | 不准确    |
| 高保真衰减特征 | 提取微弱能量衰减特征             | 通过 `exp(-alpha * path_length)` 体现幅值衰减                  | 部分正确   |
| 多路径反射   | 实际描述中不是核心机制            | 当前 `fiber_mic` 的主要差异来自多次反射                             | 物理重点偏移 |

## 5. 当前主要问题

### 问题 1：`fiber_mic` 物理语义不准确

当前代码中的 `fiber_mic` 名称容易让人理解为完整光纤麦克风链路，但实际实现只是声学多路径回波代理模型。

当前实现缺少：

- 光纤探头无源敏感前端；
- 声压到光相位或光强的转导；
- 光波干涉机制；
- 光纤传输层；
- 光电解调层；
- 放大器和采集卡前端模型。

因此不能在正式文档或论文中表述为：

```text
已实现光纤干涉式声衰减检测链路。
```

更准确的表述应为：

```text
当前 fiber_mic 是光纤声学传感链路的简化代理模型。
```

### 问题 2：`fiber_mic` 的主要差异来自多路径反射，而非光纤干涉

当前 `fiber_mic` 与 `ultrasonic` 的主要区别是：

```text
ultrasonic：单一主脉冲
fiber_mic：直达脉冲 + 多次墙面反射
```

但实际装置中第二路的核心应是：

```text
光纤探头对分子弛豫导致的微弱声压变化进行高保真感知。
```

因此当前实现的物理重点偏向：

```text
腔体多路径回波
```

而不是：

```text
光纤干涉式微弱声压解调
```

### 问题 3：未显式保存或建模 TOF 观测特征

`ultrasonic` 函数内部返回了：

```text
tof_s
peak_index
sound_speed_m_per_s
alpha_true_npm
```

修正前在 `slow.py` 中主要保存：

```text
ultrasonic waveform_int16
ultrasonic scale_factor
```

TOF 信息只隐含在波形主脉冲位置中。

本轮短期修正后，benchmark 会额外写出：

```text
sequences/ultrasonic_tof_s.npy
sequences/ultrasonic_peak_index.npy
sequences/ultrasonic_sound_speed_m_per_s.npy
sequences/ultrasonic_alpha_true_npm.npy
```

这解决了“TOF 信息没有显式落盘”的问题；但 `tof_observed_s`、系统延迟修正后的声速估计和 `tof_quality` 仍属于下一步硬件模型修正范围。

如果实验设计明确强调：

```text
超声链路专用于精准锁定 TOF 并反演宏观声速
```

则后续可考虑显式保存或提取：

```text
tof_observed_s
tof_peak_index
sound_speed_estimated_m_per_s
tof_quality
```

### 问题 4：超声波形缺少系统延迟和探头响应

`acoustic_physics.py` 中 `main_sensor_features(...)` 使用了：

```text
t_delay_s
```

但 `waveforms.py::simulate_waveform_measurement(...)` 中：

```text
tof_s = l_m / c_sound
```

未加入系统延迟。

当前超声波形未显式建模：

- 发射探头响应；
- 接收探头响应；
- 触发延迟；
- 换能器带宽；
- 前端放大器；
- 安装偏差。

这不影响当前一阶仿真使用，但需要在文档中说明其为简化模型。

### 问题 5：`fiber_mic` 缺少光电链路参数

如果要符合实际光纤链路，应至少考虑以下参数：

```text
probe_position_m
pressure_sensitivity_rad_per_pa
interferometer_phase_bias_rad
optical_wavelength_nm
optical_link_loss_db
demod_gain_v_per_rad
photodetector_noise_std_v
amplifier_noise_std_v
voltage_saturation_v
daq_full_scale_v
```

当前 `FiberMicSpec` 主要包含：

```text
sample_rate_hz
center_frequency_hz
burst_cycles
measurement_window_s
adc_max_int16
noise_std_v
l_direct_factor
wall_reflection_coef
max_reflections
calibration_status
```

这些参数更像声学回波模型参数，不是光纤干涉解调链路参数。

## 6. 建议的准确描述

在未重构前，建议文档中采用如下表述：

```text
当前 ultrasonic 通道实现了简化的对射式超声 TOF 波形模拟：
代码根据混合气声速和检测声程计算 TOF，并将 40 kHz burst pulse 放置在对应采样位置，同时用声衰减模型调制幅值。

当前 fiber_mic 通道是光纤声学传感链路的简化代理模型：
代码使用同一套声速与声衰减模型生成受传播衰减影响的声学波形，并通过多路径反射近似腔体声场结构，最后理想量化为采集卡 int16 波形。
该实现尚未显式建模光纤探头的干涉式声压转导、光纤传输、光电解调和放大过程。
```

## 7. 建议后续修正方向

### 7.1 短期修正：文档和命名澄清

短期不改模型时，应在文档和 manifest 中明确：

```text
fiber_mic_model = acoustic_proxy_v1
```

并说明：

```text
当前为声学代理模型，不是完整光纤干涉模型。
```

可补充字段：

```text
calibration_status = pending
fiber_optical_demodulation_model = not_implemented
```

### 7.2 中期修正：增加光纤探头代理层

建议将 `fiber_mic` 链路拆成：

```text
声场传播
   ↓
探头位置声压 p(t)
   ↓
光纤探头声压-相位转导
   ↓
理想光纤传输
   ↓
光电解调
   ↓
电压波形
   ↓
DAQ 量化
```

建议新增或扩展配置：

```python
@dataclass(frozen=True, slots=True)
class FiberProbeSpec:
    probe_position_m: float
    pressure_sensitivity_rad_per_pa: float
    interferometer_phase_bias_rad: float
    demod_gain_v_per_rad: float
    optical_link_loss_db: float = 0.0
    photodetector_noise_std_v: float = 1e-4
    amplifier_noise_std_v: float = 1e-4
    voltage_saturation_v: float = 5.0
```

### 7.3 长期修正：区分两路任务目标

建议明确两路声学信号的分工：

```text
ultrasonic：
  面向宏观声速反演，核心特征是 TOF。

fiber_mic：
  面向微观声能衰减和分子弛豫响应，核心特征是局部声压幅值、包络衰减、相位/光强解调电压。
```

模型输入可继续保留两路波形，但生成逻辑应体现不同测量机制。

## 8. 最终结论

当前代码中：

```text
ultrasonic 链路基本符合实际对射式 TOF 检测原理；
fiber_mic 链路只部分符合声衰减检测思想，但尚未实现真实光纤探头干涉感知与光电解调链路。
```

因此，当前声学链路问题可以概括为：

```text
第一路 ultrasonic 的物理方向正确，但仍是简化硬件模型；
第二路 fiber_mic 的命名和实际装置原理存在偏差，目前实现的是声学多路径代理模型，而非完整光纤干涉式声衰减测量模型。
```

后续正式实验或论文表述前，应至少完成以下二选一：

1. 明确声明 `fiber_mic` 是简化代理模型；
2. 或重构 `fiber_mic`，补充光纤探头、干涉转导、光纤传输、光电解调和 DAQ 输出模型。

## 9. 联网文献调研后的解决方案

### 9.1 资料结论

本节基于 2026-05-28 联网检索得到的论文、行业报告和标准资料，对前述问题给出可落地修正方向。

结论如下：

1. `ultrasonic` 的主物理路径应继续以 transit time / TOF 为核心。天然气超声表计和气体声速资料都把声波传播时间、路径长度、声速和信号质量作为关键诊断量。当前短期修正已显式保存生成真值 TOF、主峰位置、声速和声衰减数组；后续还应补齐带系统延迟和质量指标的观测 TOF。
2. 超声链路不能长期只用 `tof_s = L / c`。GERG 对超声气体表计的研究明确讨论了换能器、线缆、电子学和衍射相关的 transit-time correction；换能器延迟会随压力和温度变化，量级可达到微秒，足以带来可见测量误差。因此当前实现应标注为简化链路，并在下一版引入系统延迟、换能器响应和质量指标。
3. `fiber_mic` 的真实可解释模型应是声压到光学相位/腔长变化，再到解调电压和 DAQ 的链路，而不是只靠多路径反射区分于 `ultrasonic`。Fabry-Perot 光纤麦克风文献中，声压使悬臂梁或膜片振动，改变 F-P 腔长；干涉谱再经 WLI、相位解调或 MZI/NE-MZI 转成可采集信号。
4. 分子弛豫吸收是第二路声学链路值得保留的核心物理重点。气体混合物声弛豫模型文献指出，CO2、CH4 等可激发分子在混合气中可分别贡献弛豫吸收过程；CO2 的光纤 DBR 激光超声传感实验证明可通过吸收谱恢复 CO2 弛豫吸收曲线，并与气体浓度关联。
5. 在没有真实光纤探头、解调器、放大器和 DAQ 标定参数之前，正式数据和论文中不能称为“已实现完整光纤干涉式声衰减检测链路”。当前最稳妥处理是把现有实现冻结为 `acoustic_proxy_v1`，再新增一个可校准的 `fiber_interferometric_proxy_v1`。

### 9.3 推荐的不变量

后续代码重构应保持以下不变量：

1. `ultrasonic` 只负责宏观声速/TOF 任务。它的核心可观测量是 `L_m`、`tof_observed_s`、`sound_speed_estimated_m_per_s` 和质量指标；幅值衰减只是辅助特征。
2. `fiber_mic` 负责局部声压和声能衰减任务。它的核心可观测量是探头位置声压包络、弛豫吸收导致的幅值/谱变化、光学相位或腔长变化、解调电压和 DAQ 波形。
3. `hidden_attenuation_v2(...)` 可以继续作为半经验弛豫吸收代理，但必须在文档中说明它不是标准化 QARS/AGA/GERG 模型，也不是已标定仪器模型。
4. 多路径反射可以保留为声场扰动项，但不能继续作为 `fiber_mic` 的主要物理语义。
5. 所有新增模型参数必须写入 `metadata/waveform_spec.json` 或 manifest，避免训练集只保存波形而丢失生成契约。

### 9.4 中期模型建议

#### 9.4.1 超声 TOF 链路

建议将当前：

```text
tof_s = L_m / c_sound
peak_index = round(tof_s * sample_rate_hz)
```

扩展为：

```text
tof_true_s = L_m / c_sound
tof_observed_s = tof_true_s + system_delay_s + cable_delay_s + trigger_jitter_s
tof_peak_index = round(tof_observed_s * sample_rate_hz)
sound_speed_estimated_m_per_s = L_m / max(tof_observed_s - delay_correction_s, eps)
tof_quality = f(SNR, peak_width, correlation_score, accepted_pulse_flag)
```

波形生成增加：

```text
excitation burst
  -> 发射换能器响应 h_tx(t)
  -> 气体传播延迟与 exp(-alpha * L)
  -> 接收换能器响应 h_rx(t)
  -> 前端噪声/增益/饱和
  -> ADC
```

最低可实现版本不需要完整换能器有限元，只需用带通滤波或二阶谐振响应近似 `h_tx/h_rx`，并把 `system_delay_s`、`delay_correction_s`、`trigger_jitter_std_s` 和 `tof_quality` 写入元数据。

#### 9.4.2 光纤干涉式声压代理链路

建议将 `fiber_mic` 新链路定义为：

```text
声源/局部声场
  -> 探头位置声压 p_probe(t, x_probe)
  -> 分子弛豫吸收 alpha(f, composition, T, P, RH)
  -> 光纤探头声压-腔长或声压-相位转导
  -> 光纤传输损耗
  -> 干涉解调
  -> 光电探测器/放大器噪声和饱和
  -> DAQ 量化
```

可用一阶代理方程：

```text
p_probe(t) = p_source(t - tau_probe) * exp(-alpha_npm * L_probe)
delta_phi(t) = pressure_sensitivity_rad_per_pa * p_probe(t)
phi(t) = interferometer_phase_bias_rad + delta_phi(t)
v_demod(t) = demod_gain_v_per_rad * unwrap_or_linearize(phi(t))
v_frontend(t) = saturate(v_demod(t) + n_photodetector(t) + n_amplifier(t))
daq_int16(t) = quantize(v_frontend(t), daq_full_scale_v)
```

若采用 Fabry-Perot 腔长代理，也可以写成：

```text
delta_d(t) = displacement_sensitivity_m_per_pa * p_probe(t)
I(lambda, t) = 2 I0(lambda) * [1 + gamma * cos(4*pi*(d0 + delta_d(t))/lambda + phi0)]
v_demod(t) = white_light_or_phase_demod(I(lambda, t))
```

这个形式与 FPI 光纤麦克风文献一致：声压驱动悬臂梁/膜片，改变 F-P 腔长，再用 WLI 或相位解调得到输出。
