# 当前声学链路问题记录

## 1. 背景

当前项目中存在两路声学波形模拟：

1. `ultrasonic`：超声波发射探头与接收探头构成的对射式 TOF 检测链路。
2. `fiber_mic`：用于声衰减特征提取的光纤探头 + 光纤麦克风分离式传感链路。

相关代码主要位于：

- `src/sim/generation/waveforms.py`
- `src/sim/generation/acoustic_physics.py`
- `src/sim/generation/slow.py`

根据实际装置原理，`ultrasonic` 和 `fiber_mic` 不应只是两条相似声学波形通道，而应分别对应不同物理测量机制。

## 2. 实际装置原理摘要

### 2.1 超声 TOF 链路

实际原理：

- 超声波发射探头与超声波接收探头隔空相对；
- 构成完整对射式声学检测链路；
- 主要用于精准锁定声波飞行时间，即 TOF；
- 通过 TOF 反演宏观声速；
- 推杆轴向位移可动态调节检测声程。

该链路的核心观测量应为：

- TOF；
- 声程 `L_m`；
- 由 `L_m / TOF` 反演得到的宏观声速；
- 可选的传播幅值衰减。

### 2.2 光纤声衰减链路

实际原理：

- 装置采用“探头 + 麦克风”分离式光纤传感架构；
- 光纤探头深入混合气团内部，作为无源敏感前端；
- 光纤探头利用光波干涉原理捕获声压变化；
- 声压变化与天然气组分引发的分子弛豫效应和微弱声能衰减有关；
- 光纤探头将光参量信号通过光纤传输至腔体边界的光纤麦克风；
- 光纤麦克风作为光电解调中枢，完成光电转换、放大和模拟电信号输出；
- 最终信号进入高速数据采集卡。

该链路的核心观测量应为：

- 局部声压响应；
- 分子弛豫导致的声能衰减特征；
- 光纤干涉相位或光强变化；
- 光电解调后的模拟电压波形；
- DAQ 采样后的数字波形。

## 3. 当前代码实现现状

### 3.1 `ultrasonic` 当前实现

代码位置：

- `src/sim/generation/waveforms.py`
- 函数：`simulate_waveform_measurement(...)`

当前实现逻辑：

```text
气体组分 + 温度 + 压力 + 湿度 + 声程
   ↓
hidden_sound_speed_v2(...)
   ↓
hidden_attenuation_v2(...)
   ↓
tof_true_s = l_m / c_sound
   ↓
tof_observed_s = tof_true_s + system_delay_s + cable_delay_s + trigger_jitter_s
   ↓
tof_peak_index = tof_observed_s * sample_rate
   ↓
40 kHz burst pulse + 二阶谐振带通换能器响应
   ↓
按 exp(-alpha * l_m) 缩放幅值
   ↓
加噪声，计算 TOF 质量和延迟修正后的估计声速
   ↓
按固定 DAQ full-scale 量化为 int16
```

该实现已覆盖对射式 TOF 链路的核心观测过程，并显式保留系统延迟、触发抖动、延迟修正、换能器响应和质量指标的生成契约。

### 3.2 `fiber_mic` 当前实现

代码位置：

- `src/sim/generation/waveforms.py`
- 函数：`simulate_fiber_mic_measurement(...)`

当前实现逻辑：

```text
气体组分 + 温度 + 压力 + 湿度 + 声程
   ↓
hidden_sound_speed_v2(...)
   ↓
hidden_attenuation_v2(...)
   ↓
探头位置声压 p_probe(t)，并按 exp(-alpha * L_probe) 衰减
   ↓
弱墙面反射作为声场扰动项
   ↓
声压-光相位转导 delta_phi(t)
   ↓
线性相位解调为电压 v_demod(t)
   ↓
叠加光电探测器和放大器噪声
   ↓
电压饱和 + DAQ full-scale 量化为 int16
```

当前 `fiber_mic` 已实现为：

```text
探头声压 + 光纤相位转导 + 线性解调 + 电噪声/饱和 + DAQ 量化的光纤干涉代理模型
```

## 5. 当前主要问题

### 问题 1：`fiber_mic` 物理语义不准确（已修正为代理模型）

当前代码已将 `fiber_mic` 明确实现为 `fiber_interferometric_proxy_v1`。它不是实测标定模型，但已具备光纤声衰减链路应有的代理层级。

当前实现包含：

- 光纤探头无源敏感前端；
- 声压到光相位或光强的转导；
- 光波干涉机制；
- 光纤传输层；
- 光电解调层；
- 放大器和采集卡前端模型。

因此正式文档或论文中可表述为：

```text
已实现光纤干涉式声衰减代理仿真链路。
```

但不能表述为：

```text
已完成真实仪器标定的光纤干涉式声衰减检测链路。
```

### 问题 2：`fiber_mic` 的主要差异来自多路径反射，而非光纤干涉（已修正）

旧实现中 `fiber_mic` 与 `ultrasonic` 的主要区别是：

```text
ultrasonic：单一主脉冲
fiber_mic：直达脉冲 + 多次墙面反射
```

但实际装置中第二路的核心应是：

```text
光纤探头对分子弛豫导致的微弱声压变化进行高保真感知。
```

当前实现已把物理重点改为：

```text
探头位置声压 -> 光纤相位扰动 -> 线性解调电压 -> DAQ 波形
```

多路径反射只作为弱声场扰动项保留，不再作为 `fiber_mic` 的主要语义。

### 问题 3：未显式保存或建模 TOF 观测特征（已修正）

`ultrasonic` 函数内部返回了：

```text
tof_s
peak_index
sound_speed_m_per_s
alpha_true_npm
```

修正前在 `slow.py` 中主要保存：

```text
ultrasonic waveform_int16
ultrasonic scale_factor
```

TOF 信息只隐含在波形主脉冲位置中。

本轮短期修正后，benchmark 会额外写出：

```text
sequences/ultrasonic_tof_s.npy
sequences/ultrasonic_peak_index.npy
sequences/ultrasonic_sound_speed_m_per_s.npy
sequences/ultrasonic_alpha_true_npm.npy
sequences/ultrasonic_tof_observed_s.npy
sequences/ultrasonic_sound_speed_estimated_m_per_s.npy
sequences/ultrasonic_tof_quality.npy
sequences/ultrasonic_tof_accepted.npy
```

这解决了“TOF 信息没有显式落盘”和“只有真值 TOF、没有观测 TOF”的问题。当前超声链路已支持“精准锁定 TOF 并反演宏观声速”的代理仿真需求。

### 问题 4：超声波形缺少系统延迟和探头响应（已修正为代理模型）

`acoustic_physics.py` 中 `main_sensor_features(...)` 使用了：

```text
t_delay_s
```

当前 `waveforms.py::simulate_waveform_measurement(...)` 已使用：

```text
tof_true_s = l_m / c_sound
tof_observed_s = tof_true_s + system_delay_s + cable_delay_s + trigger_jitter_s
```

并显式建模：

- 发射探头响应；
- 接收探头响应；
- 触发延迟；
- 换能器带宽；
- 延迟修正；
- TOF 质量；
- DAQ full-scale 量化。

其中发射/接收探头响应合并为二阶谐振带通代理，不是换能器有限元模型。

### 问题 5：`fiber_mic` 缺少光电链路参数（已修正为代理参数）

如果要符合实际光纤链路，应至少考虑以下参数：

```text
probe_position_m
pressure_sensitivity_rad_per_pa
interferometer_phase_bias_rad
optical_wavelength_nm
optical_link_loss_db
demod_gain_v_per_rad
photodetector_noise_std_v
amplifier_noise_std_v
voltage_saturation_v
daq_full_scale_v
```

当前 `FiberProbeSpec` 已包含上述参数，并额外包含：

```text
source_pressure_pa
probe_path_length_factor
displacement_sensitivity_m_per_pa
daq_bits
```

当前参数仍是仿真占位，正式实验前必须替换为真实硬件标定值。

## 8. 最终结论

当前代码中：

```text
ultrasonic 链路已按对射式 TOF 检测原理实现观测延迟、换能器响应、延迟修正和质量指标代理；
fiber_mic 链路已实现光纤探头声压感知、相位转导、线性解调、噪声/饱和和 DAQ 量化代理。
```

因此，当前声学链路问题可以概括为：

```text
第一路 ultrasonic 已是可校准的 TOF 观测代理模型；
第二路 fiber_mic 已是可校准的光纤干涉式声衰减代理模型。
```

后续正式实验或论文表述前仍需保留以下边界：

1. 当前参数是仿真占位值；
2. 不能声称已完成真实硬件标定；
3. 若用于论文实测对照，必须用目标换能器、光纤探头、解调器、放大器和 DAQ 参数替换默认值。

## 9. 联网文献调研后的解决方案

### 9.1 资料结论

本节基于 2026-05-28 联网检索得到的论文、行业报告和标准资料，对前述问题给出可落地修正方向。

结论如下：

1. `ultrasonic` 的主物理路径应继续以 transit time / TOF 为核心。天然气超声表计和气体声速资料都把声波传播时间、路径长度、声速和信号质量作为关键诊断量。当前实现已显式保存生成真值 TOF、观测 TOF、主峰位置、真实声速、估计声速、声衰减、质量指标和接收标志。
2. 超声链路不能长期只用 `tof_s = L / c`。GERG 对超声气体表计的研究明确讨论了换能器、线缆、电子学和衍射相关的 transit-time correction；换能器延迟会随压力和温度变化，量级可达到微秒，足以带来可见测量误差。因此当前实现已引入系统延迟、线缆延迟、触发抖动、延迟修正、二阶谐振换能器响应和 TOF 质量指标。
3. `fiber_mic` 的真实可解释模型应是声压到光学相位/腔长变化，再到解调电压和 DAQ 的链路，而不是只靠多路径反射区分于 `ultrasonic`。Fabry-Perot 光纤麦克风文献中，声压使悬臂梁或膜片振动，改变 F-P 腔长；干涉谱再经 WLI、相位解调或 MZI/NE-MZI 转成可采集信号。
4. 分子弛豫吸收是第二路声学链路值得保留的核心物理重点。气体混合物声弛豫模型文献指出，CO2、CH4 等可激发分子在混合气中可分别贡献弛豫吸收过程；CO2 的光纤 DBR 激光超声传感实验证明可通过吸收谱恢复 CO2 弛豫吸收曲线，并与气体浓度关联。
5. 在没有真实光纤探头、解调器、放大器和 DAQ 标定参数之前，正式数据和论文中不能称为“已完成真实仪器标定的光纤干涉式声衰减检测链路”。当前实现已升级为可校准的 `fiber_interferometric_proxy_v1`。

### 9.3 推荐的不变量

后续代码重构应保持以下不变量：

1. `ultrasonic` 只负责宏观声速/TOF 任务。它的核心可观测量是 `L_m`、`tof_observed_s`、`sound_speed_estimated_m_per_s` 和质量指标；幅值衰减只是辅助特征。
2. `fiber_mic` 负责局部声压和声能衰减任务。它的核心可观测量是探头位置声压包络、弛豫吸收导致的幅值/谱变化、光学相位或腔长变化、解调电压和 DAQ 波形。
3. `hidden_attenuation_v2(...)` 继续作为半经验多气体弛豫吸收代理，包含 CO2、CH4、H2O、N2 背景弛豫和 H2 扩散项；但它仍不是标准化 QARS/AGA/GERG 模型，也不是已标定仪器模型。
4. 多路径反射可以保留为声场扰动项，但不能继续作为 `fiber_mic` 的主要物理语义。
5. 所有新增模型参数必须写入 `metadata/waveform_spec.json` 或 manifest，避免训练集只保存波形而丢失生成契约。

### 9.4 中期模型建议

#### 9.4.1 超声 TOF 链路

已将旧模型：

```text
tof_s = L_m / c_sound
peak_index = round(tof_s * sample_rate_hz)
```

扩展为：

```text
tof_true_s = L_m / c_sound
tof_observed_s = tof_true_s + system_delay_s + cable_delay_s + trigger_jitter_s
tof_peak_index = round(tof_observed_s * sample_rate_hz)
sound_speed_estimated_m_per_s = L_m / max(tof_observed_s - delay_correction_s, eps)
tof_quality = f(SNR, clipping, accepted_pulse_flag)
```

波形生成增加：

```text
excitation burst
  -> 发射换能器响应 h_tx(t)
  -> 气体传播延迟与 exp(-alpha * L)
  -> 接收换能器响应 h_rx(t)
  -> 前端噪声/增益/饱和
  -> ADC
```

当前版本用二阶谐振带通响应近似 `h_tx/h_rx`，并把 `system_delay_s`、`delay_correction_s`、`trigger_jitter_std_s` 和 `tof_quality` 写入数据资产或元数据。

#### 9.4.2 光纤干涉式声压代理链路

当前 `fiber_mic` 新链路定义为：

```text
声源/局部声场
  -> 探头位置声压 p_probe(t, x_probe)
  -> 分子弛豫吸收 alpha(f, composition, T, P, RH)
  -> 光纤探头声压-腔长或声压-相位转导
  -> 光纤传输损耗
  -> 干涉解调
  -> 光电探测器/放大器噪声和饱和
  -> DAQ 量化
```

可用一阶代理方程：

```text
p_probe(t) = p_source(t - tau_probe) * exp(-alpha_npm * L_probe)
delta_phi(t) = pressure_sensitivity_rad_per_pa * p_probe(t)
phi(t) = interferometer_phase_bias_rad + delta_phi(t)
v_demod(t) = demod_gain_v_per_rad * unwrap_or_linearize(phi(t))
v_frontend(t) = saturate(v_demod(t) + n_photodetector(t) + n_amplifier(t))
daq_int16(t) = quantize(v_frontend(t), daq_full_scale_v)
```

若采用 Fabry-Perot 腔长代理，也可以写成：

```text
delta_d(t) = displacement_sensitivity_m_per_pa * p_probe(t)
I(lambda, t) = 2 I0(lambda) * [1 + gamma * cos(4*pi*(d0 + delta_d(t))/lambda + phi0)]
v_demod(t) = white_light_or_phase_demod(I(lambda, t))
```

这个形式与 FPI 光纤麦克风文献一致：声压驱动悬臂梁/膜片，改变 F-P 腔长，再用 WLI 或相位解调得到输出。

#### 9.4.3 建议配置

建议新增：

```python
@dataclass(frozen=True, slots=True)
class FiberProbeSpec:
    model_name: str = "fiber_interferometric_proxy_v1"
    probe_position_m: float = 0.5
    probe_path_length_factor: float = 0.5
    pressure_sensitivity_rad_per_pa: float = 1.0
    displacement_sensitivity_m_per_pa: float | None = None
    interferometer_phase_bias_rad: float = 1.57079632679
    optical_wavelength_nm: float = 1550.0
    optical_link_loss_db: float = 0.0
    demod_gain_v_per_rad: float = 1.0
    photodetector_noise_std_v: float = 1e-4
    amplifier_noise_std_v: float = 1e-4
    voltage_saturation_v: float = 5.0
    daq_full_scale_v: float = 5.0
    daq_bits: int = 16
    calibration_status: str = "pending"
```

参数初值只能作为仿真占位；正式实验前必须用目标光纤探头、解调器和 DAQ 标定值替换。
