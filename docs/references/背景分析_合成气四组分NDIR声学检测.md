# 合成气四组分（CO/CO₂/CH₄/H₂）NDIR + 声学双模态在线检测 — 文献与背景分析

**分析日期**: 2026-06-22
**背景**: 当前项目基础不支持多烃类（C₂H₆/C₃H₈ 等）检测，将研究场景从掺氢天然气收敛至合成气四组分在线检测。
**检索工具**: MCP academic-search + paper-search

---

## 一、为什么从掺氢天然气转向合成气？

### 1.1 项目能力边界

| 项目已有能力       | 可测气体                                           | 局限                               |
| ------------ | ---------------------------------------------- | -------------------------------- |
| NDIR（1–3 通道） | CH₄ (3.3 μm), CO₂ (4.26 μm), + CO (4.6 μm 可扩展) | 需要明确的光谱吸收峰，对同核双原子分子（H₂/N₂/O₂）无响应 |
| 声学（声速 + 衰减）  | H₂（分子量极小，声速差异大）；对分子量不同的气体有区分力                  | 对分子量相近的气体（CO/N₂ 均为 28）区分力有限      |
| DL 融合模型      | 多模态信号融合与浓度反演                                   | 依赖物理模态提供的信息量                     |

### 1.2 场景收敛逻辑

- **掺氢天然气** = CH₄ + C₂H₆ + C₃H₈ + ... + H₂，多烃类需要多个独立光谱通道或色谱分离，当前 NDIR 通道数不够
- **合成气** = **CO + CO₂ + CH₄ + H₂**（四组分），恰好匹配"NDIR 三通道 + 声学一通道"的物理架构
- CO/CO₂/CH₄ 各自有明确的中红外吸收峰 → NDIR 可直接覆盖
- H₂ 是 NDIR 的检测盲区，但声速/衰减对其极敏感 → **声学通道替代商用方案中的 TCD**

## 二、合成气的工业背景与组分范围

### 2.1 合成气来源与典型组分

合成气（syngas）是含碳原料（煤、生物质、天然气）经气化或重整产生的混合气，是化工、冶金、能源行业的核心中间产物。

| 气化/重整工艺        | CO (%) | H₂ (%) | CO₂ (%) | CH₄ (%) | 其他        | 来源文献 |
| -------------- | ------ | ------ | ------- | ------- | --------- | ---- |
| 煤气化（气流床，O₂ 鼓风） | 45–60  | 25–35  | 5–15    | 0–5     | N₂ < 2%   | [A1] |
| 煤气化（固定床，空气鼓风）  | 25–30  | 12–15  | 5–8     | 2–4     | N₂ 45–50% | [A1] |
| 生物质气化（空气鼓风）    | 15–20  | 10–15  | 10–15   | 2–5     | N₂ 40–55% | [A2] |
| 生物质气化（O₂/蒸汽鼓风） | 30–40  | 25–35  | 15–25   | 5–10    | N₂ < 5%   | [A2] |
| 天然气蒸汽重整（SMR）   | 10–15  | 70–75  | 5–10    | 2–5     | H₂O 痕量    | [A3] |
| 高炉煤气（BFG）      | 20–25  | 2–5    | 18–22   | 0–1     | N₂ 50–55% | [A4] |
| 焦炉煤气（COG）      | 5–8    | 55–60  | 1–3     | 22–28   | C₂H₆ 2–3% | [A4] |

**关键观察**：

- CO 和 H₂ 是合成气价值的核心指标（决定热值和后续合成工艺效率）
- 四组分（CO/CO₂/CH₄/H₂）覆盖了合成气 95%+ 的摩尔分数（空气鼓风场景 N₂ 除外）
- 高炉煤气和焦炉煤气涉及 N₂ 和微量烃类，但四组分仍是核心

### 2.2 在线监测需求

- **气化炉控制**：O₂/煤比和蒸汽/煤比的实时调整依赖 CO/H₂/CO₂ 比例的在线反馈
- **合成气质量**：H₂/CO 比是费托合成（~2.0）、甲醇合成（~2.0）、氨合成（H₂/N₂ = 3）的关键参数
- **安全监控**：CO 和 H₂ 均为易燃有毒气体，泄漏检测是安全运行的必须条件
- **碳排放核算**：CO₂ 浓度在线监测是碳交易和碳税的合规要求

## 三、已有文献中的四组分检测方案

### 3.1 商用方案（NDIR + TCD）

| 产品                   | 技术架构                                      | CO  | CO₂ | CH₄ | H₂      | 精度                    |
| -------------------- | ----------------------------------------- | --- | --- | --- | ------- | --------------------- |
| Cubic Gasboard-3100  | NDIR(CO/CO₂/CH₄/CnHm) + TCD(H₂) + ECD(O₂) | ✓   | ✓   | ✓   | ✓ (TCD) | NDIR ±1%FS, TCD ±2%FS |
| MRU VARIOluxx SYNGAS | NDIR + TCD + EC                           | ✓   | ✓   | ✓   | ✓ (TCD) | ±2%FS                 |
| ABYSS Syngas         | Micro-flow NDIR + TCD                     | ✓   | ✓   | ✓   | ✓ (TCD) | ±2%FS                 |

**商用的共同特征**：H₂ 全部依赖 TCD。TCD 的已知问题：

- 对温度波动敏感（Akasaka et al., 2024 [S27]）
- 需要针对 CO/CO₂/CH₄ 的交叉补偿（Gasboard PCT 专利 EP2796856）
- 响应时间 T90 通常 > 10s，慢于 NDIR

**本项目的差异化**：用**声学通道（声速 + 衰减）替代 TCD**，预期优势：

- 声速法不需要压力补偿（Monsalve, 2025 [18]），优于 TCD 的双参数依赖
- 响应时间可 < 1s（超声传播时间测量）
- 声衰减提供额外的气体区分维度（Phillips et al., 2003 [12]）

### 3.2 NDIR 三通道 CO/CO₂/CH₄ 的文献支撑

| 文献                                       | 关键内容                                               | 对本项目的意义             |
| ---------------------------------------- | -------------------------------------------------- | ------------------- |
| Xu et al. (2022) — *Sensors*, 65 引 [6]   | 单光源 + 四通道热释电探测器实现 CO₂/CO/C₃H₈ 三气体检测，全量程误差 <3.5% FS | NDIR 多气体同时检测的可行性基准  |
| Mao et al. (2025) — *IEEE SAS* [N1]      | MOF 预浓缩器增强多通道 NDIR 灵敏度                             | 提升 NDIR 检测限的可行方案    |
| Wei & Gao (2023) — *SPIE* [N2]           | 基于 NDIR 的多组分气体传感检测系统设计                             | NDIR 多组分系统架构参考      |
| Cięszczyk & Komada (2015) — *SPIE* [S9a] | NN 融合与反演模型用于 NDIR 传感器测量                            | NDIR 信号 → 浓度的 NN 建模 |

**NDIR 通道配置建议**（基于上述文献）：

1. **CH₄ 通道**：3.3 μm 滤光片（C-H 伸缩振动）
2. **CO₂ 通道**：4.26 μm 滤光片（C=O 不对称伸缩）
3. **CO 通道**：4.6 μm 滤光片（C≡O 伸缩振动）
4. **参考通道**：3.95 μm（无气体吸收的窗口区）

### 3.3 声学四组分检测的理论与实验支撑

| 文献                                                                 | 关键内容                                                            | 对本项目的意义                   |
| ------------------------------------------------------------------ | --------------------------------------------------------------- | ------------------------- |
| Phillips, Dain & Lueptow (2003) — *Meas. Sci. Technol.*, 46 引 [12] | 声速 + 声衰减在组分平面上定义两条相交线，交点即为组分浓度；在 N₂-CH₄-H₂O 和 H₂-O₂-H₂O 体系上理论验证 | **理论基础**——双参数声学可区分三组分以上体系 |
| QARS (2012) — *Sens. Actuators B* [13]                             | 频率相关的声速 + 弛豫吸收反演气体组成；论证仅靠声速无法区分分子量相同的气体（如 CO₂ 与 C₃H₈ 均为 44）     | **双参数必要性**——声速+衰减缺一不可     |
| Monsalve et al. (2024) — *JSSS*, 6 引 [14]                          | CMUT 测 H₂-NG 声速，分辨 <2 mol% H₂                                   | **声速 H₂ 灵敏度实验验证**         |
| CMUT (2022) — *Sci. Rep.* [15]                                     | 声速+声衰减同时测量，区分 H₂/CO₂/CH₄ 在 N₂ 背景下的浓度                            | **三组分声学区分的直接实验证据**        |
| Liu et al. (2023) — *Applied Acoustics*, 5 引 [N3]                  | 从声速频散中分解弛豫强度来识别气体组成                                             | **声速频散用于气体识别的最近方法**       |
| Chaudhary et al. (2024) — *JASA* [S20]                             | 20 kHz–10 MHz 宽带超声声速+衰减谱区分 H₂/He 混合物的比例                         | **弛豫声谱区分 H₂/He 实验**       |

**CO/CO₂/CH₄/H₂ 四组分声学可区分性分析**：

| 气体  | 分子量 | 声速 (m/s, 0°C) | 弛豫特征          | 声学可区分性                    |
| --- | --- | ------------- | ------------- | ------------------------- |
| H₂  | 2   | 1270          | 极弱的振动弛豫       | **极高**——声速远高于其他气体         |
| CH₄ | 16  | 430           | 有振动弛豫（C-H 模式） | **高**——分子量和弛豫均不同于其他       |
| CO  | 28  | 338           | 有振动弛豫         | **中**——与 N₂ 分子量相同，需依赖弛豫区分 |
| CO₂ | 44  | 259           | 强振动弛豫         | **高**——分子量最大，弛豫最强         |

**结论**：四组分在声速-衰减平面上分布具有足够的分离度，声学双参数可提供有效区分信息。

## 四、本项目方案与商用方案的差异

| 维度         | 商用方案（Gasboard-3100 等）      | 本项目方案                    |
| ---------- | -------------------------- | ------------------------ |
| CO/CO₂/CH₄ | NDIR（3–4 通道）               | NDIR（3 通道），与商用一致         |
| H₂         | TCD（热导检测器）                 | **声学（声速 + 衰减）**          |
| 温度补偿       | TCD 需要温度补偿                 | 声速法仅需温度补偿（无需压力补偿）        |
| 响应时间       | T90 ~15s（TCD 热平衡限制）        | 预期 < 1s（声传播时间）           |
| 交叉干扰       | TCD 需要 CO/CO₂/CH₄ 补偿（黑箱算法） | 声学信号 + NDIR 信号通过 DL 联合反演 |
| 创新空间       | 无（成熟商用技术）                  | **NDIR + 声学双模态融合是空白**    |

## 五、识别的研究空白与贡献点

### 5.1 已有但本项目不做主攻的方向

- 拉曼全组分检测（2024–2026 进展很快，S29–S35 已详述）——全组分能力强但成本/体积不适合在线工业部署
- TDLAS CO 单组分高精度检测——有工业标准（ASTM D8488），但无法测 H₂

### 5.2 本项目的三个核心贡献点

1. **声学替代 TCD 用于合成气 H₂ 检测**：首次在合成气四组分场景中验证声速+衰减双参数替代 TCD 的可行性
2. **NDIR（CO/CO₂/CH₄）+ 声学（H₂）双模态融合**：将 NDIR 三通道输出作为声学反演的约束输入，通过 DL 联合建模解决四组分同时定量问题
3. **公开的交叉干扰补偿模型**：区别于商用黑箱"智能校正"，提供可复现的物理+DL 联合校正方案

## 七、建议的实验验证路径

1. **四组分标准气配气实验**：配制 CO/CO₂/CH₄/H₂ 四组分标准混合气（覆盖 2.1 节典型范围），验证 NDIR 三通道 + 声学双参数的测量精度
2. **声学 TCD 替代验证**：与商用 TCD H₂ 传感器（如 Gasboard-3100 的 TCD 模块）做同条件对比
3. **DL 融合反演 vs 经典最小二乘**：在四组分数据上比较 NN 融合模型与经典矩阵反演的性能
4. **温度/压力鲁棒性测试**：验证声学法"仅需温度补偿"的理论优势在实践中是否成立
