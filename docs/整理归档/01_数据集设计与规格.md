### 1.2 V3.1 核心变化

V3.1 数据集将原先单通道 waveform 升级为**两条物理独立链路**：

- **通道 1**：超声对射波形（TOF 链路）
- **通道 2**：光纤麦克风波形（声衰减 / 多次反射混响链路）

**设计目标**：

| 目标 | 验收 |
|------|------|
| 硬件链路对应 | 通道 1 ↔ 超声对射；通道 2 ↔ 光纤麦克风；两通道物理独立 |
| 物理量解耦 | 通道 1 主要承载 TOF；通道 2 主要承载声衰减时间常数 tau |
| 信息可提取 | 从两通道波形可分别估出 TOF / tau，与 ground truth 误差 < 5% |
| 方向性正确 | CO2 / H2O / H2 浓度变化时，两通道频谱 / 包络出现可观察的单调响应 |
| ML 与 DL 公平 | 两端都吃同一个双通道 waveform，差异只在抽取方式 |

## 5. 两条物理链路

### 5.1 通道 1：超声对射波形

**物理模型**：
```text
emit(t) = A0 × Hanning(t, T_pulse) × sin(2π × f_c × t)
recv_us(t) = emit(t − TOF) × exp(−alpha(f_c) × L_m) + n_us(t)
```

| 属性 | 值 |
|------|---|
| 物理职责 | 承载 TOF 主信息 |
| 生成模型 | 发射 burst 经气体传播后到达接收端 |
| 主要观测量 | 主峰位置、主峰幅值 |
| 测量窗 | 5 ms |
| sample_rate | 200 kHz |
| waveform_samples | 1000 |
| noise_std_us | 1e-3 V |

**承载信息**：
- TOF 位置 → `c_sound` 反演
- 峰值幅度 → `alpha(f_c)` 在单频点的标量信息

### 5.2 通道 2：光纤麦克风波形

**物理模型**：
```text
p_field(t) = direct(t) + Σ reflection_k(t) + n_fm(t)
```

其中：
- `T_round = 2L / c_sound`
- `A_direct = exp(-alpha × L_direct)`
- `tau ≈ 1 / (alpha × c_sound)`
- 反射系数 `R = 0.5`（默认，calibration pending）

| 属性 | 值 |
|------|---|
| 物理职责 | 承载声衰减时间常数 tau 主信息 |
| 生成模型 | 直达波 + 多次反射混响叠加 |
| 主要观测量 | 包络衰减时间常数、反射峰间隔、反射峰计数 |
| 测量窗 | 10 ms |
| sample_rate | 200 kHz |
| waveform_samples | 2000 |
| l_direct_factor | 0.5 |
| wall_reflection_coef | 0.5 |
| max_reflections | 15 |
| noise_std_fm | 1e-3 V |

**承载信息**：
- 包络衰减时间常数 `tau`
- 反射峰间隔 `T_round`
- 反射峰数量与尾部能量统计
