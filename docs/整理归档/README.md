## 9. 注意事项

### 9.1 数据集版本

- **重要**：目标主线使用 `waveform_v3_seedpath_formal`（30000 序列）
- 旧版 `waveform_v3`（10000 序列）仅作历史对照
- 两者的 split 文件和 scaler 文件**不兼容**

### 9.2 实验状态

- 文档中的状态（✅ 🟡 ⏳）反映 2026-06-08 的仓库复核结果
- `outputs/STATUS.tsv` 当前内容不完整，不能单独作为唯一真相
- 实际进度请同时查看 `outputs/` 目录实物与 `python src/pipeline/aggregate.py` 刷新的汇总表

### 9.3 性能数据

- 性能数据必须区分 `waveform_v3` 与 `waveform_v3_seedpath_formal`
- 当前深度学习 YAML 仍默认指向 `data/waveform_v3/`
- 做正式 ML vs DL 结论前，必须先统一到同一数据源口径
