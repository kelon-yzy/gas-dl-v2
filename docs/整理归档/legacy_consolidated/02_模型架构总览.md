# 模型架构总览

> 整理日期：2026-06-08
> 适用项目：V3 正式实验
> 数据版本：V3.1 dual-channel waveform
> 复核说明：当前深度学习 YAML 配置实际仍指向 `data/waveform_v3/`；本页中涉及 `seedpath_formal` 的内容仅代表目标主线，不代表所有已跑结果

## 1. 模型分类体系

### 1.1 总体分类

本项目的模型分为两大类：

| 类别 | 技术路线 | 输入 | 主要模型 |
|------|----------|------|----------|
| **传统机器学习（ML）** | 信号处理 + 浅层模型 | 手工提取的表格特征 | SVR, PLS, XGBoost + Ridge 融合 |
| **深度学习（DL）** | 端到端学习 | 原始波形 + 慢变量序列 | CNN1D, TCN, LSTM, GRU, Transformer, BranchFusion |

### 1.2 深度学习模型体系

#### 按输入类型分类

| 类型 | 输入 | 模型示例 | 配置文件示例 |
|------|------|----------|--------------|
| **慢变量专用** | slow[8] | GRU, LSTM, TCN, Transformer | `slow_only_*_formal.yaml` |
| **双波形专用** | ultrasonic[1000] + fiber_mic[2000] | MultimodalFusionV3 | `fusion_formal.yaml` |
| **全融合** | ultrasonic + fiber_mic + slow | CNN1D/GRU/LSTM/TCN/Transformer/CNN-LSTM_Multimodal | `slow_only_*_multimodal_formal.yaml` |

#### 按融合策略分类

| 策略 | 融合位置 | 实现方式 | 配置文件 |
|------|----------|----------|----------|
| **Early Fusion** | 编码器后 | `early_fusion_film` 先做逐模态编码，再做较早层拼接 | `configs/deep/slow_only_early_fusion_film_multimodal_formal.yaml` |
| **Middle Fusion** | 中间层 | `multimodal_fusion_v3` 与 `*_multimodal` 系列在中间表征层汇合 | `configs/deep/fusion_formal.yaml`、`configs/deep/slow_only_*_multimodal_formal.yaml` |
| **Late Fusion** | 输出层 | 当前仓库没有独立的深度学习 `fusion_late.yaml`；晚期融合主要体现在传统 ML 的 `acoustic/optical/thermal/fused` 二阶段融合 | 当前无独立深度 YAML |

## 2. 传统机器学习架构

### 2.1 整体架构

**核心设计**：三模态四输出基学习器 + 动态权重 + 二次融合器

```
输入特征（表格）
    ↓
┌──────────────────────────────────┐
│  三模态基学习器（并行）              │
│  ├─ 声学模态（基于通道 1）           │
│  ├─ 光学模态（NDIR 传感器）          │
│  └─ 热导模态（TCS 传感器）           │
└──────────────────────────────────┘
    ↓
┌──────────────────────────────────┐
│  四输出层                           │
│  ├─ acoustic_output[4]            │
│  ├─ optical_output[4]             │
│  ├─ thermal_output[4]             │
│  └─ fused_output[4] ← Ridge 融合   │
└──────────────────────────────────┘
```

### 2.2 模型列表

| 模型组合 | 基学习器 | 融合器 | 输出 | 主要用途 |
|----------|----------|--------|------|----------|
| `svr_ridge` | SVR（RBF kernel）| Ridge | acoustic/optical/thermal/fused | 传统基线 |
| `pls_ridge` | PLS（偏最小二乘）| Ridge | acoustic/optical/thermal/fused | 降维 + 回归 |
| `xgboost_ridge` | XGBoost | Ridge | acoustic/optical/thermal/fused | 树模型 + 融合 |

### 2.3 特征定义

**来源**：`src/pipeline/feature_extraction.py` 从双通道波形导出

**采样策略**：每个 120 时步序列抽取 4 个代表性时间点
- 基线段：1 个
- 目标气体稳定段：2 个
- 恢复段：1 个

**特征维度**：

| 模态 | 特征来源 | 主要特征 |
|------|----------|----------|
| 声学（acoustic）| 通道 1 超声波形 | TOF、主峰幅值、频域峰值、声速估计、声衰减近似 |
| 光学（optical）| 慢通道 NDIR | V_NDIR_CH4, V_NDIR_CO2 及其派生量 |
| 热导（thermal）| 慢通道 TCS | V_TCS 及其派生量 |
| 环境 | 慢通道环境变量 | T_C, P_MPa, H_RH, L_m 及其相对基线变化 |

**环境特征的重要性**：
- 历史 `waveform_v3` 口径中：`svr_ridge` / `v3_raw_tph` / `fused` 最优 `macro_RMSE≈0.6122`
- 同一历史口径中：`xgboost_ridge` / `v3_raw_no_env` / `fused` 为 `macro_RMSE≈1.3958`
- `seedpath_formal` 30k 口径下，当前可见传统 ML 最优 fused 结果约为 `2.4292`
- **结论**：环境特征重要，但当前仓库中的结果必须按数据源区分阅读

### 2.4 训练配置

| 参数 | 值 | 说明 |
|------|---|------|
| n_jobs | -1 | CPU 并行（使用全部核心）|

## 4. CNN1D-TCN 融合模型详解（当前结构性消融主线之一）

### 4.1 模型标识

- **配置文件**：`configs/deep/bounded_simplex_3task_loss_slow_branch.yaml`
- **模型类**：`src/dl/models/cnn1d_tcn_fusion_slow_branch.py`
- **当前关注版本**：`slow_branch + bounded_simplex + 3-task loss`

### 4.2 架构图

```
ultrasonic[T,1000]    fiber_mic[T,2000]    slow[T,8]
       ↓                      ↓                 ↓
  CNN1D Encoder          CNN1D Encoder    SlowFeatureEncoder
  (专用于通道1)           (专用于通道2)       (逐时间步MLP)
       ↓                      ↓                 ↓
   embed1[T,128]          embed2[T,128]     embed_slow[T,64]
       └──────────────┬──────────────┘           │
                      │                           │
                  Concat[T, 256]                  │
                      └─────────────┬─────────────┘
                                    ↓
                              Concat[T, 320]
                                    ↓
                           Causal TCN (4 blocks)
                            感受野 = 29 timesteps
                                    ↓
                            Last timestep output
                                    ↓
                         ┌──────────┴──────────┐
                         ↓                     ↓
                  Shared MLP Head      Bounded Simplex Head
                      [256→128]              [4 params]
                         ↓                     ↓
                  Normalized logits    [x_H2, x_CH4, x_CO2, x_N2]
                         └──────────┬──────────┘
                                    ↓
                           Output: [4] (sum=100)
```

### 4.3 关键设计

| 设计点 | 实现 | 优势 |
|--------|------|------|
| **双路波形独立编码** | 两个专用 CNN1D encoder | 保留各通道特性 |
| **慢变量独立编码** | SlowFeatureEncoder (逐时步 MLP) | 避免裸拼接 |
| **时序建模** | 因果 TCN（4 blocks，感受野 29）| 捕获时序依赖 |
| **约束输出** | bounded_simplex 参数化 | 保证非负、和为 100 |

| 项 | 值 |
|----|---|
| 总参数量 | 266,564 |
