## 核心发现

1. **CNN1DTCNFusion backbone 强证实**：历史强 backbone 远优于 PhaseWindowTCN，特征提取能力不足确认为前阶段的根本瓶颈。
2. **gas_head 死刑**：闭包残差参数化在两个 backbone 上均完全不可训练——方向正式废弃。
3. **raw4 是唯一可训练模式**：已在两个 backbone 上交叉验证。
4. **H2 可以学到高精度**（R² 0.869），**CH4 中等**（0.44），**CO2/N2 困难**——可能是数据分布限制而非纯架构问题。
5. **训练未收敛**：epoch 80 未触发早停，val_loss 持续下降中。

### 🟠 P1：Multi-seed 验证（仅在 P0 通过后执行）

**目标**：消除运行间方差的混淆风险，确认结果稳定可复现。

**进入条件**：P0 任一 run 的 overall R² >= 0.6 且 N2 R² > 0

**配置**：在 P0 最佳配置基础上，seed 设置为 [20260615, 20260623, 20260630]

**判据**：
- 3 个 seed 中至少 2 个 test N2 R² > 0
- 3 个 seed 的 mean test overall R² >= 0.6
- 不出现某个 seed 完全崩掉（overall R² < 0）

**若通过**：将 CNN1DTCNFusion + raw4 提升为正式 DL 主线候选基线，写入 AGENTS.md 和 RecallLoom context_brief。

---

### 🟡 P2：Backbone 扩容（P0 灰区 / P0 不通过时执行）

**目标**：增大特征提取容量，试探是否瓶颈在模型规模。

**实验配置**（`stage2_backbone_scale_up`）：

| run | 改动 | 目的 |
|---|---|---|
| `cnn1d_tcn_fusion_raw4_wide_acoustic` | acoustic_channels [32, 64, 128, 128] | 增大声学 encoder 容量 |
| `cnn1d_tcn_fusion_raw4_deeper_tcn` | tcn_channels [64, 64, 64, 64] | 加深 TCN 时间建模 |
| `cnn1d_tcn_fusion_raw4_wide_shared` | shared_hidden_dims [256, 128] | 增大共享 MLP 容量 |

每组都要确保不过拟合：增加 dropout 至 0.3，patience 15。

**判据**：任一 run overall R² >= 0.6 且无明显过拟合 → 进入 P1 multi-seed。

---

### 🟢 P3：PhaseWindowTCN + window_attention（后备方向）

**目标**：探索窗口间交互是否是 PhaseWindowTCN 的主要失败原因。

**进入条件**：P0 和 P2 均未通过，或 P0/P1/P2 整体饱和 (< 0.65)，需要换一条技术路线。

**实验**：新建 `phase_window_attention` 模型，1 层 TransformerEncoder 替代 concat-only 融合。

**判据**：若 window_attention overall R² > PhaseWindowTCN baseline + 0.2 → 窗口交互路线成立。

---

### ⚪ P4：CO2/N2 不可学性根因诊断（与架构改动并行）

| 分析任务 | 方法 | 目的 |
|---|---|---|
| CO2/N2 的 cross-split 方差分析 | 读 split_summary.json 中新增的 component stats | 确认 CO2/N2 在不同 split 间是否分布一致 |
| CO2/N2 对 CH4 的偏相关 | 条件 R² 矩阵 | 确认 CO2 是否被 CH4 协方差"遮盖" |
| Ridge CO2/N2 per-bin 性能 | read ridge_all_modalities 的 conditional_metrics | 确认 ridge 的 CO2/N2 R² 中哪部分来自哪种特征 |

**若确认 CO2/N2 本质不可学**（条件 R² 显示即使给定 CH4 和 H2，CO2/N2 残差仍接近噪声），则重新定义成功标准——不要求 CO2 和 N2 正 R²，只考核 H2 和 overall。

## 决策总流程

```
P0: 延长训练 + 损失加权（Stage 1.5）
├─ overall R² >= 0.6 且 N2 R² > 0
│  └─ P1: Multi-seed 验证（3 seeds）→ 通过则进入主线
├─ overall R² >= 0.5 但 < 0.6（灰色区域）
│  └─ P2: backbone 扩容 → 再判断
└─ overall R² < 0.5
   └─ P2: backbone 扩容

P2: backbone 扩容
├─ 有效（>= 0.6）
│  └─ P1: Multi-seed
└─ 无效
   └─ P3: PhaseWindowTCN + window_attention（换技术路线）

P4: CO2/N2 根因诊断（与 P0-P3 并行，不做 blocking 依赖）
```
