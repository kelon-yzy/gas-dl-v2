## 1. 总体目录结构

```
src/
├── dl/                    # 深度学习链路
│   ├── data/              # 数据加载与预处理
│   ├── models/            # 模型定义（15+ 个模型）
│   ├── training/          # 训练循环与优化器
│   └── experiments/       # 实验编排脚本
├── ml/                    # 传统机器学习链路
│   ├── patent_model/      # 专利模型实现
│   └── scripts/           # 训练与网格搜索脚本
├── sim/                   # 数据生成与仿真

│   ├── sim_common/        # 共用物理函数
│   ├── sim_v2/            # V2 仿真逻辑
│   └── lut/               # NDIR 查找表
```

**核心架构**：
```python
# 三模态四输出 + 动态融合
TraditionalFusionModel
├── acoustic branch     # 声学模态基学习器
├── optical branch      # 光学模态基学习器
├── thermal branch      # 热导模态基学习器
└── meta ridge          # 三模态预测再融合
    ↓
输出: {
    'acoustic': [4],   # 声学预测
    'optical': [4],    # 光学预测
    'thermal': [4],    # 热导预测
    'fused': [4]       # ✅ 融合预测（主结果）
}
```

**Feature Profile 定义**：
```python
FEATURE_PROFILES = {

    'v3_raw_tph': {

```

**数据生成流程**：
```python
# generate_waveform_dataset.py
1. 工况采样（10000 个 base condition）
2. 多噪声种子（每个 base × 3 个 noise seed = 30000 序列）
3. 序列生成（每序列 120 时步）
   - 慢通道：8 个传感器信号
   - 通道 1：超声对射波形（1000 采样点）
   - 通道 2：光纤麦克风波形（2000 采样点）
4. 量化存储（int16 + scale）
5. Split 生成（4 路：train/val/test/extrapolation）
6. Scaler 拟合（仅 train split）
7. 质量检查（方向性验证）
```

### 6.2 配置文件格式

```yaml
# 示例：slow_only_tcn_formal.yaml
model:
  name: tcn
  params:
    input_dim: 8
    hidden_dim: 64
    num_channels: [64, 128, 256]
    kernel_size: 3
    dropout: 0.1

data:
  dataset_type: waveform_v3
  npz_path: ../../data/waveform_v3_seedpath_formal
  split_dir: ../../data/waveform_v3_seedpath_formal/splits
  scaler_path: ../../data/waveform_v3_seedpath_formal/scalers/scaler_slow_sequence.json
  time_window: all

training:
  epochs: 200
  batch_size: 16
  optimizer: adamw
  lr: 0.001
  weight_decay: 1e-5
  seed: 42

early_stopping:
  patience: 30
  metric: val_macro_RMSE
  mode: min
```
