### 4.2 G3a：敏感度曲线

**原理**：用已训练模型，按环境变量（T/P/RH）分箱统计 RMSE

**优势**：
- ✅ 无需重训练，秒级出结果
- ✅ 适合快速迭代查看趋势

**输出**：9 张曲线图（3 个模型 × 3 个环境变量）+ CSV 数据表

**运行命令**：
```powershell
python src\pipeline\sensitivity_scan.py \
  --predictions outputs\exp01_traditional\runs\...\predictions.csv \
  --condition-grid outputs\exp01_traditional\data\condition_grid_v1.csv \
  --output-dir outputs\exp04_adaptation\G3a_sensitivity
```

### 4.3 G3b：噪声鲁棒性

**原理**：对测试集注入不同级别的传感器噪声

**训练增强**：
- σ_train ∈ {0, 0.5, 1.0}
- 训练时给 T_C / P_MPa / H_RH 加 N(0, σ_train) 噪声

**测试评估**：
- σ_test ∈ {0, 0.5, 1.0, 2.0}
- 测试时评估不同噪声级别下的性能

**主指标**：
- `degradation_ratio = perturbed_RMSE / clean_RMSE`

**输出**：RMSE vs 噪声等级曲线

### 4.4 G3c：工况泛化（留一域评估）

**域定义**：基于 condition_grid 的三维分箱

- T_bin：按 T_C 三分位分 3 档（低 / 中 / 高）
- P_bin：按 P_MPa 三分位分 3 档（低 / 中 / 高）
- RH_bin：按 H_RH 中位数分 2 档（干 / 湿）

**初始网格**：3×3×2 = 18 域

**合并规则**：样本量 < 500 的稀疏域会合并，最终约 9 个域

**评估方式**：轮流 hold-out 1 域，N-1 域训练

**主指标**：
- `per_domain_holdout_RMSE`
- `in_domain_RMSE`（同 split 全域随机划分对照）
- `domain_gap = holdout_RMSE - in_domain_RMSE`

**输出**：18 域 RMSE 均值±标准差

### 4.5 Track C：跨域微调（可选）

**地位**：可选实验，时间允许再做，不进默认验收

**流程**：
1. Track A 的预训练模型（N-1 域上训完）
2. 在 hold-out 域上 fine-tune N=50 / 100 / 200 / 500 样本
3. 报告 fine-tune 后 RMSE 与样本量关系

**主指标**：`sample_efficiency` 曲线（每个模型一条线）

**输出目录**：`outputs/exp04_adaptation/`

**运行命令**：
