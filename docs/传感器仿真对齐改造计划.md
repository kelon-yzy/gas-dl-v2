> 依据 [`docs/references/传感器硬件资料整理.md`](references/传感器硬件资料整理.md) 附录 A.4 的后续动作制定。
> 目标：将超声/ADC 仿真链路与实际硬件型号（PSC200K 200 kHz、NI USB-6453 20-bit/1 MS/s）对齐。
> 制定日期：2026-07-02

## 0 背景与现状

附录 A.4 列出三项待处理问题，本计划覆盖其中两项需改代码的：

| 问题                  | 决策         | 是否动代码          |

| 1. 超声频率 40→200 kHz  | 对齐 PSC200K | 是              |

  - `sim/generation/slow.py:183,193`
  - `sim/generation/syngas/slow.py:241,251`

## 1 改造原则

1. **先验证物理可行性，再改代码**。200 kHz 下声学衰减量级与 40 kHz 差异巨大（经典吸收与 H₂ 扩散项均 ∝ f²，放大约 25 倍），可能在长声程上把回波幅度压到噪声以下。必须先跑数值核对，确认信号可用，再全面改造。
2. **参数化优先于改常量**。把频率/采样率/位深从模块级硬编码提到 `WaveformSpec`/`FiberMicSpec` 字段 + `PROCESSING_PARAMS` 字段，默认值给硬件对齐值。避免下一次换型号又改一遍。
3. **位深与 dtype 解耦**。20-bit 无 numpy 原生类型，存储用 int32，文件名改为 `*_int32.npy`，dtype 跟着 spec 走，下游不硬编码。
4. **每阶段独立可验证**。每阶段产出可运行的代码 + 测试通过 + benchmark 重生成核对，不一次性大改。
5. **旧 benchmark 作废标注**。频率/采样率/位深任一改变都使旧数据失效，重生成后在 manifest 加 `sim_revision` 标记。

## 2 阶段划分

```
Phase 0  物理可行性核对（不改代码，只跑数值）
   ↓  验证 200 kHz 下回波 SNR 可用
Phase 1  参数化重构（行为不变，为改值做准备）
   ↓  测试全绿，默认值仍 40kHz/16bit
Phase 2  频率对齐 200 kHz + 采样率 1 MS/s
   ↓  衰减常数核对 + 重生成 benchmark
Phase 3  ADC 位深对齐 20-bit
   ↓  dtype int32 + 下游兼容
Phase 4  benchmark 重生成 + 测试更新 + 旧数据作废
   ↓  主线 462 测试通过
Phase 5  低优先级项（TCS 注释、慢通道量化）
```

各阶段无强依赖时序硬锁，但 Phase 0 必须先于 Phase 2；Phase 1 建议先于 Phase 2/3，降低合并冲突风险。

## Phase 0 物理可行性核对

**目标**：在动代码前，先用数值实验确认 200 kHz / 1 MS/s 下超声信号在当前声程范围内可检测，避免改完发现信号被衰减吃没。

**不改代码**，用临时脚本调用现有 `hidden_attenuation_v2()`，传入 `f_hz=200000` 计算衰减曲线。

### 0.1 核对内容

| 项                 | 方法                                                                                         | 通过判据                                                       |
| ----------------- | ------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| 总衰减系数 α(f=200kHz) | 对典型气样（纯 N₂、H₂ 10%/90% N₂、CH₄ 100%）计算 `alpha_classical + 弛豫 + H₂扩散`                         | 记录量级，与 40 kHz 对比                                           |
| **最恶劣工况衰减**       | **x_h2=50%（H₂ 扩散项 `x·(1-x)·f²` 的抛物线顶点）+ L=1.8m + 高温端**，计算 `exp(-αL)`                       | 幅度不低于噪声判据                                                  |
| 回波幅度 `exp(-α·L)`  | L=0.2/0.5/1.0/1.8 m 四档                                                                     | L=1.8m 时幅度 ≥ 10×噪声（噪声 1 mV）即 `exp(-αL) ≥ 0.01`             |
| 弛豫峰位置             | 检查 `f_relax_*`（28k~100k）相对 200 kHz 的位置                                                     | 弛豫项在 200 kHz 下不出现反常峰值                                      |
| SNR               | `peak_abs_v / noise_std_v`                                                                 | ≥ 20 dB（当前 40 kHz 量级作基准）                                   |
| **回波幅度量级**        | 记录各气样在各声程下的 `peak_abs_v`，确定信号落在 NI-6453 哪一档量程内                                             | 输出 `daq_full_scale_v` 推荐值（±2.5V / ±5V / ±10V），供 Phase 3 使用 |
| **数据量 ×5 可行性**    | 采样率 1 MS/s 后波形维度 5000/10000，估算正式 benchmark（6000 序列 × 多 timestep）的 `.npy` 文件体积、生成时间、DL 训练显存 | 若不可接受，评估缩短 `measurement_window_s` 后最长 TOF 是否仍在窗内           |

### 0.2 风险与预案

- **风险**：H₂ 扩散衰减项 `k_diffusion_h2 * f²` 在 200 kHz 下放大 25 倍，高 H₂ 浓度 + 长声程可能 `exp(-αL) → 0`。
- **预案 A**：若仅长声程失效，缩短 `conditions.py` 的 `L_m` 上限（当前 1.8 m）至衰减可接受范围，并在文档记录。
- **预案 B**：若全面失效，核对 `k_diffusion_h2=1.6e-3` 的文献来源，可能该常数本身是按 40 kHz 标定的经验值，需重新查文献。这一步要查证，不能凭感觉调常数。
- **预案 C**：若弛豫常数需重标定，先用文献值（Bass/Franklin 1970s 系列、ANSI S1.26）核对 `alpha_lambda_max_*` 和 `f_relax_*` 在 200 kHz 量级是否合理。

### 0.3 产出

- 一份核对记录（数值表 + 图），归档到 `docs/` 下，作为 Phase 2 衰减常数是否调整的依据。
- 明确结论：200 kHz 下信号是否可用，`L_m` 范围是否需要调整，衰减常数是否需要重标定。
- **`daq_full_scale_v` 推荐值**：根据回波幅度量级确定 NI-6453 输入量程（±2.5V / ±5V / ±10V），作为 Phase 3 输入，避免 Phase 3 悬而未决。
- **数据量 ×5 可行性结论**：是否需要缩短 `measurement_window_s`，若缩短则给出推荐值及最长 TOF 校验结果。

**卡点**：若结论是"200 kHz 下信号不可用且无法通过调参挽救"，停止后续阶段，回到附录 A.3 问题 1 重新决策（可能需保留 40 kHz 或换型号假设）。

### 0.4 核对结果与决策（2026-07-02 完成）

核对记录见 [`Phase0_物理可行性核对记录.md`](Phase0_物理可行性核对记录.md)。结论：

- **200 kHz 在原声程范围（0.2~1.8 m）与组分范围（CH₄≥40%）下不可用**：典型天然气（H₂5/CH4 80/CO2 10）在 L≥0.5m SNR 跌破 20dB，L≥1.0m 信号完全被 CH₄/CO₂ 弛豫吸收淹没。
- 物理原因：CH₄/CO₂ 振动弛豫吸收在 200 kHz 接近峰值（P=0.5MPa 下峰位 ~140 kHz），叠加经典吸收 ∝f² 放大 25 倍。弛豫常数为标准 Bass 文献值，预案 B（H₂ 扩散常数）/C（重标弛豫）均无效。
- daq_full_scale_v 推荐 ±2.5 V（信号峰值 ≤0.91V，20-bit LSB=4.77μV）。
- 数据量 ×5：formal-6000 从 23GB 增至 115GB，可承载。

**用户决策：选项 C——缩短 L_m 至 ≤0.3m + 改 200kHz，对齐 PSC200K。**

已知后果（记录在案，不阻塞执行）：

1. L_m 作为条件变量近乎退化：`conditions.py` LHS 范围 [0.2, 1.8] → [0.2, 0.3]，跨度 0.1m，TOF 动态范围从 0.15~6.7ms 压缩到 0.15~1.12ms，声学通道区分力下降。
2. 序列内多光程扫描 `path_lms=[0.2,0.25,0.3,0.35,0.4]` 越界，需改为 ≤0.3m（如 [0.18,0.20,0.22,0.25,0.28]）。
3. SNR 裕度偏薄：L=0.3m 时典型天然气约 28dB（裕度 8dB），高 CO₂ 同量级；L=0.2m 才到 40dB。Phase 2 会核对具体裕度，必要时把上限收到 0.25m。

据此调整后续阶段：Phase 2 增加声程范围修改，Phase 3 不变。

## Phase 1 参数化重构

**目标**：把频率/采样率/位深从硬编码提到 spec 字段，`_digitize_waveform` 位深参数化。本阶段**不改默认值**，行为与当前完全一致，全部测试应原样通过。

### 1.1 `waveforms.py`

- `WaveformSpec` 新增字段：
  - `daq_bits: int = 16`（新增）
  - `adc_max: int`（由 `daq_bits` 在 `__post_init__` 推导：`2**(daq_bits-1) - 1`）——替代原 `adc_max_int16` 字段名。由于 dataclass 使用 `frozen=True`，推导需用 `object.__setattr__(self, 'adc_max', ...)` 模式，或改为 property。
  - `waveform_dtype: str = "int16"`（存储 dtype，与 `daq_bits` 联动：16→int16, 17~32→int32）
- 模块级常量 `CENTER_FREQUENCY_HZ`、`SAMPLE_RATE_HZ`、`ADC_MAX_INT16` 保留为 `WaveformSpec` 默认值的来源，不再被业务逻辑直接 import。
- `_digitize_waveform()` 签名改为接收 `adc_max` 和 `dtype`，内部按位深推导 scale，dtype 跟随 spec：
  
  ```python
  scale_factor = daq_full_scale_v / adc_max
  waveform_int = np.clip(np.round(waveform / scale_factor), -adc_max, adc_max).astype(dtype)
  ```
  
  返回值 key 从 `"waveform_int16"` 改为 `"waveform_int"`（下游同步改，见 1.2）。
- 文件名由 spec 决定：`f"ultrasonic_{waveform_dtype}.npy"`，下游加载跟着改（见 1.3）。

- 超声：1000 → 5000
- 光纤：2000 → 10000

- 若 Phase 0 结论为"数据量可接受"：直接使用新采样率。
- 若 Phase 0 结论为"需缩短 `measurement_window_s`"：按推荐值调整，并核对最长 TOF 仍在窗内。
- DL 训练端：波形输入维度 ×5，可能需要调整 batch size 或加 1D 池化层，具体在 Phase 4 端到端验证时确认。

### 2.4 验证

## Phase 3 ADC 位深对齐 20-bit

**目标**：波形量化从 16-bit 改到 20-bit，对应 NI-6453。

**前置**：Phase 1 完成（位深已参数化）。可与 Phase 2 并行，但建议在 Phase 2 之后，避免同时改频率和位深导致问题定位困难。

### 3.1 参数修改

- `WaveformSpec.daq_bits` 默认 16 → 20
- `waveform_dtype` 默认 `"int16"` → `"int32"`（20-bit 无原生类型，用 int32 存储）
- `adc_max` 由 `daq_bits` 推导：`2**19 - 1 = 524287`
- `daq_full_scale_v`：**按 Phase 0 核对结论选定量程**（Phase 0 §0.3 输出推荐值）。NI-6453 支持 ±0.2/±2.5/±5/±10 V，根据回波幅度量级选择分辨率最优的档位。

### 3.2 DL 模型归一化系数同步

`waveform_int16_scale` 默认值 `32767.0` 需同步改为新 `adc_max`（`524287`），否则模型 forward 归一化系数错 16 倍，直接导致推理错误。

| 文件                              | 行号      | 改动                                                                       |
| ------------------------------- | ------- | ------------------------------------------------------------------------ |
| `dl/models/cnn1d_tcn_fusion.py` | 23, 203 | `waveform_int16_scale: float = 32767.0` → 改为从 spec 或 config 读取 `adc_max` |
| `dl/models/phase_window_tcn.py` | 29, 124 | 同上                                                                       |

建议将字段名从 `waveform_int16_scale` 重命名为 `waveform_adc_scale`，默认值跟随 spec 的 `adc_max`。已有训练配置中显式指定 `waveform_int16_scale` 的（如 `test_run_experiment.py:477` 的值 `5.0`），保持其显式值不变——显式覆盖优先于默认值。

### 3.3 下游兼容

## Phase 5 低优先级项

附录 A.4 中影响"低"的三项，按需处理，不阻塞主线。

### 5.1 TCS 经验 λ 公式补注释

`acoustic_physics.py:250-251` 的 `0.00155`、`-0.00011` 系数，补注释说明拟合来源（H₂-N₂ 真实 λ 混合的线性近似），标注与 TCS205 物性表的对应关系。不改公式。

### 5.2 慢通道 ADC 量化

慢通道（V_NDIR_*, V_TCS, T_C, P_MPa, H_RH, L_m）当前 float32 无量化。严格对齐 ADS8684（16-bit, ±5V 或 ±10V）可补一级量化。优先级低，因为慢通道噪声主要来自动力学注入，量化影响小。若补，在 `slow.py` 输出阶段加量化函数，量程按 ADS8684 实际配置。

### 5.3 SHT45 噪声

当前噪声（0.05°C/0.1%RH）小于 SHT45 标称精度（0.1°C/1.0%RH），相当于理想传感器。若要对齐实际精度，把噪声提到标称精度量级。优先级低，按需。
