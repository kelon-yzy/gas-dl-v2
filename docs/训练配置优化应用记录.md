## 历史变更记录

曾尝试把 `batch_size` 提升到 32，并配套把学习率提高到 `0.0002` 或 `0.001`。该方向在旧 24 GiB 环境出现 OOM，因此已回退为 `batch_size=16`、`lr=0.00015`。

新 48 GiB 服务器具备重新测试 `batch_size=24/32` 的条件，但这属于候选实验，不是当前默认配置。候选测试顺序和验收标准见 `docs/训练配置优化方案.md`。

## 废弃口径

以下旧口径不再作为执行依据：

- `batch_size=32` 是默认优化配置。
- 显存必然从 `17GB` 降到 `6-8GB`。
- Phase 1 + Phase 2 必然压缩到 `2.5-3.5 小时`。
- smoke dataset 结果可直接代表正式 full dataset 显存。

再按主文档做 worker、compile、batch 候选实测。
