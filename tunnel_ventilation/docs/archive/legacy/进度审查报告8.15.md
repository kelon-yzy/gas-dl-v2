## 一、课题方向与证据链

主线是 tv3 掘进通风 CO₂/O₂/N₂ 三组分反演，问题定义已经从"找更好的模型"转成三段因果链：信息够不够 → 估计效率高不高 → 不确定度可不可信。这个转向是对的，MRS-6 的判断（"精度预算是硬件问题，不是算法问题"）也站得住。

问题在于，**连续六个阶段给出的是同一个答案**：

| 阶段          | 结论                                      | 实质                                  |
| ----------- | --------------------------------------- | ----------------------------------- |
| 可辨识性 v1     | `information_source_upgrade_required`   | 单向 TOF 联合 Fisher 秩=1                |

## 二、MEI-4 C2 的失败机制（文档里没写的部分）

C2 只记录了"M1/M1b/M2 均未过 24 条主覆盖带"。我把冻结产物重算了一遍，机制是三个现象的同一个原因：

**1. 拒绝率主导 test，且原因单一**

| 方法  | test 拒绝         | OOD 拒绝         | 拒绝原因构成                                       |
| --- | --------------- | -------------- | -------------------------------------------- |
| M1  | 205/648 = 31.6% | 42/648 = 6.5%  | 100% `truncation_interval_numerical_failure` |
| M1b | 183/648 = 28.2% | 42/648 = 6.5%  | 同上                                           |
| M2  | 240/648 = 37.0% | 71/648 = 11.0% | 同上                                           |

触发条件是 65536 个 Sobol 候选中落在物理域内的少于 2048（<3.125%），即 **97% 以上的高斯质量在物理域外**。

**2. 能构造出区间的样本上，覆盖率系统性高于名义值**

test O₂ 条件覆盖 `0.607 / 0.912 / 0.984 / 0.998`，对应名义 `0.5 / 0.8 / 0.9 / 0.95`。

**3. 区间宽于整个工作量程**

| 域    | O₂ 50%  | O₂ 90%  | O₂ 95%      | 采样量程        |
| ---- | ------- | ------- | ----------- | ----------- |
| test | 1.97 pp | 4.80 pp | **5.72 pp** | **3.20 pp** |
| ood  | 1.10 pp | 2.69 pp | 3.21 pp     | 3.20 pp     |

test 的 95% 区间是 O₂ 全量程（18.00–21.20%）的 **1.8 倍**，90% 区间也超量程；OOD 的 95% 区间恰好等于量程。

同时 `o2_laplace_to_crb_ratio` 中位数 = 1.0003 —— 拉普拉斯曲率本身正确，等于 CRB。所以这不是实现缺陷，也不是"后验过于自信"。三个现象是一件事：**K4 + 登记噪声下，单样本 O₂ 后验宽到无法支撑比"在量程内"更细的陈述**。

这与 B4 的 S1 test O₂ P90=1.66 pp、MRS-2 的 2.40、MRS-6 的 1.0–1.3 完全自洽。MEI-4 的第 4 号研究问题在 C2 就有答案了。

**一个被忽略的规格问题**：C0 冻结的后验域是 `raw3 非负 + sum=100%`，`method_input_policy` 的 `allowed_assets` 只含干扰参数标定先验，**没有组分先验**。而登记数据实际由受约束 LHS 生成（CO₂ 0.03–5.00%，O₂ 18.00–21.20%）。也就是说 M1/M1b/M2 用的是单纯形上的平坦先验，比真实生成分布在 O₂ 方向宽约 30 倍。区间超量程、97% 质量出域，直接由此而来。

## 三、C3 的两个判断

**判断一：计算成本已经不是障碍。**

本机实测（10 个 test 混合物 × 3 初值）：

- 前向模型单次 **73.6 μs**
- S1 单初值求解 **204.6 ms**，每混合物 3 初值 **614 ms**
- M2b 登记规模 1296 × 200 × 3 = 777,600 次求解 → 单核 **44.2 h**，12 worker 理想线性 **≈ 3.7 h**
- SBC/PPC 便宜得多

`tv3/audit/mrs_ei_mei4_parallel.py`（574 行）的 P1/P2 并行改造已落地，多 worker 一致性测试通过。缺的只有 P0/P3 基准和 P5 正式运行。一个通宵可以完成。当初中止是因为串行实现下 M2b 日志停在 1/1296，projected 44 h——这个问题已经被解决了。

**判断二：按现契约，C3 跑完不能改变 verdict。**

C0 冻结的 `mc_protocol` 中 `sbc.methods` 与 `ppc.methods` 都是 `["M1","M1b","M2"]`，**不含 M2b**（`tv3/audit/mrs_ei_mei4_mc.py:42` 的 `MC_METHODS` 一致）。而 `verdict_state_machine` 要求 `M1_or_M2_or_M2b_passes_complete_calibration_gate`，complete gate = 覆盖 + SBC + PPC。

于是 `tv3/audit/mrs_ei_mei4_c4.py:73-82` 把 M2b 的 `complete_calibration_gate_passed` 硬编码为 `False`，注明"M2b has no registered SBC/PPC evidence in the frozen C3 protocol"。加上 M1/M1b 的覆盖已在 C2 失败：

> **T1 在 C2 结束时就已注定为 True，`mei4_deterministic_posterior_retained` 结构上不可达。**

契约 §4 方法矩阵写着 M2b"可成为冻结后验基线（替代 M2）"，C3 登记表却没给它非退化门证据——这是 C0 自身的矛盾。花 3.7 h 运行 M2b，只能产出一份注定不合格的覆盖报告。

**附带一个循环依赖**：`mrs_ei_mei4_c4.py:144` 从 `m2b_report["cost"]["forward_calls"]` 读实测值判 T4，而 T4 的语义是"M2b 必要但成本超预算"，本该是跳过 M2b 的理由。按事前估算，M2b 需 1.02e8 次前向调用，登记预算 1e6，**超出 102 倍**，T4 早已满足。

## 四、CC-SBI（C4）评估

技术上可行且极便宜：训练抽样每条 = 1 次前向 = 73.6 μs，20 万条约 15 s 单核，比 M2b 便宜三个数量级。它对每个样本都能输出区间，直接消除 30% 拒绝率；在登记生成模型上做摊销推断，SBC 校准近乎构造性成立。**大概率能过覆盖门。**

但有一个必须先处理的公平性问题：CC-SBI 按契约"联合采样组分、干扰参数、设计与模型族"训练，**天然使用真实 LHS 先验**；M1/M1b/M2 用的是平坦单纯形先验。两者不在同一规格下比较，CC-SBI 的胜出会来自先验规格而非方法本身。

对应的报告要求应该预先写死：主指标用 **先验宽度→后验宽度的收缩比**，而不是绝对区间宽度。否则会出现一个符合项目自身标准的假阳性——覆盖门通过、区间"很窄"，但测量信息贡献接近零。C0 已经预注册了"不得通过缩窄先验制造高精度"，这条正好适用。

## 六、建议

**推荐路径**：先做一次 C0′ 版本化契约修订，再执行 C3 全量。修订三项：

- 补齐 M2b 的 SBC/PPC 登记，或明确将 M2b 降级为诊断路径并写明其 verdict 不可达；
- T4 改为事前预算估算（登记 1e6 vs 实测规模 1.02e8）；
- 把登记组分先验（LHS 采样域）纳入 M1/M2 的后验域，使其与 CC-SBI 同规格——这不属于禁止的"先验缩窄重标定"，因为它就是真实生成分布。

理由：C3 现在只需一个通宵，成本已不是问题；但契约缺陷不修，运行完仍然无法用于裁决。修订的边际成本远低于继续搁置。

**备选 A（纪律最干净）**：按现契约执行 C3 全量（约 4–5 h @12 worker），拿到完整六件套，接受 `mei4_uncertainty_failed`，再单独决定 CC-SBI。代价是明知 M2b 不可能过门仍要花 3.7 h。
