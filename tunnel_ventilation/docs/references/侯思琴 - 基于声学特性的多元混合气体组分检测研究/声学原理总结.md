论文的核心思想可以概括为：**气体组分改变混合气体的热力学性质和分子能量交换过程，进而同时改变超声波的传播速度与衰减强度；测得声速 \(c\) 和衰减系数 \(\alpha\)，即可反演气体组分与浓度。**

原论文：[侯思琴 - 基于声学特性的多元混合气体组分检测研究.pdf](<../侯思琴 - 基于声学特性的多元混合气体组分检测研究.pdf>)

**1. 声学检测的物理基础**

超声波本质上是气体介质中的微小压力扰动。声波经过时，局部气体发生周期性压缩和膨胀，引起压力、密度、温度和分子运动状态变化。

对于小振幅、理想、绝热传播过程，声速为：

\[
c=\sqrt{\frac{\mathrm dP}{\mathrm d\rho}}
\]

结合理想气体状态方程：

\[
c=\sqrt{\frac{\gamma RT}{M}}
\]

其中：

- \(c\)：声速；
- \(\gamma=C_p/C_v\)：比热容比；
- \(R\)：气体常数；
- \(T\)：绝对温度；
- \(M\)：摩尔质量。

这说明声速由气体的摩尔质量、比热容比和温度共同决定：

- 温度升高，声速通常增大；
- 摩尔质量减小，声速通常增大；
- 氢气摩尔质量很小，因此声速远高于二氧化碳、氮气等；
- 摩尔质量和比热容比相近的气体，声速差异很小，仅靠声速难以区分。

例如论文指出，CO 与 N₂ 的摩尔质量和比热容比接近，声速响应几乎重合，因此必须引入第二个声学参数。

**2. 混合气体中的声速响应**

论文把混合物的摩尔质量和比热性质按各组分占比加权，建立多元混合气体声速模型：

\[
c=
\sqrt{
\frac{RT}{\sum_i w_iM_i}
\sum_i w_i\gamma_i
}
\]

其中 \(w_i\) 为第 \(i\) 种气体的组分占比，并满足：

\[
\sum_i w_i=1
\]

因此，测得声速后，可以依据预先建立的“声速—浓度”关系反推组分。

声速通道的主要特点是：

- 对摩尔质量差异大的组分非常灵敏，如 H₂ 与 N₂；
- 响应速度快，适合实时测量；
- 对摩尔质量相近的气体存在辨识退化；
- 温度会直接进入声速公式，必须测温并补偿。

**3. 声衰减的物理机理**

实际气体不是无耗散的理想介质。声波传播过程中，声能会转化为热能或分子内能，论文把衰减分为四类：

- 黏滞损失；
- 热传导损失；
- 分子弛豫损失；
- 散射和几何扩散损失。

在均匀纯气体和平面波近似下，论文主要考虑吸收衰减：

\[
\alpha=\alpha_c+\alpha_r
\]

其中 \(\alpha_c\) 是经典衰减，\(\alpha_r\) 是分子弛豫衰减。

经典衰减由黏滞和热传导组成：

\[
\alpha_c=
\frac{\omega^2}{2\rho c^3}
\left[
\frac{4}{3}\mu'
+k\left(\frac{1}{C_v}-\frac{1}{C_p}\right)
\right]
\]

可见经典衰减受频率、密度、声速、黏度、热导率和比热容影响，并大体随频率平方增加。频率越高，组分间的衰减差异通常越明显，但有效传播距离也越短。

**4. 分子弛豫衰减**

多原子分子除了平动自由度，还有转动和振动自由度。声波引起周期性压缩、升温时，平动能量会向转动和振动能量转移。

转动自由度通常能较快达到平衡，而振动自由度需要一定的弛豫时间。能量交换相对声波周期出现滞后，会造成不可逆的声能损失。

论文给出的弛豫衰减模型为：

\[
\alpha_r
=
\sum_i
\frac{\pi D_i}{c}
\frac{f^2/f_i}
{1+f^2/f_i^2}
\]

其中：

- \(f\)：超声频率；
- \(f_i\)：第 \(i\) 种振动模式的弛豫频率；
- \(D_i\)：弛豫强度。

当声波周期与弛豫时间处于相近尺度时，弛豫吸收最明显。因此，衰减不仅取决于分子质量，还携带分子结构和内部自由度信息：

- 单原子气体主要表现为经典衰减；
- 双原子气体以经典衰减为主；
- CO₂ 等多原子气体具有明显的振动弛豫衰减。

这正是衰减能够补充声速、区分声速相近气体的原因。

**5. 声速的测量原理**

论文采用 TOF，即飞行时间法。已知发射端与接收端之间的距离 \(L\)，测得传播时延 \(\Delta t\)：

\[
c=\frac{L}{\Delta t}
\]

时延不是简单依靠阈值判断，而是对发射、接收信号进行互相关：

\[
R_{12}(\tau)=\int x_1(t)x_2(t+\tau)\,\mathrm dt
\]

互相关峰值对应传播时延：

\[
\Delta t=\arg\max_\tau R_{12}(\tau)
\]

为提高噪声和混响条件下的时延估计稳定性，论文使用广义互相关和 PHAT-\(\beta\) 加权，基本流程为：

\[
\text{信号采集}
\rightarrow
\text{滤波降噪}
\rightarrow
\text{FFT}
\rightarrow
\text{互功率谱}
\rightarrow
\text{PHAT-}\beta\text{加权}
\rightarrow
\text{IFFT}
\rightarrow
\text{峰值定位}
\]

**6. 衰减系数的测量原理**

论文假设声强随距离指数衰减：

\[
I(x)=I_0e^{-\alpha x}
\]

平面波中：

\[
I=\frac{P^2}{2Z}
\]

压电换能器输出电压与声压近似线性：

\[
P=aU
\]

因此：

\[
U^2(x)=U_0^2e^{-\alpha x}
\]

取对数可得：

\[
2\ln U(x)=-\alpha x+2\ln U_0
\]

沿传播方向改变接收换能器位置，测量多个距离上的电压幅值；对 \(2\ln U\) 与 \(x\) 做线性拟合，即可由斜率得到衰减系数：

\[
\alpha=-\text{slope}
\]

这里论文式（2-28）印成了正号，并称 \(\alpha\) 为斜率，但这与其前面的 \(I=I_0e^{-\alpha x}\) 不一致。按物理定义和数学推导，指数项及拟合斜率应为负号。

**7. 声速—衰减联合反演**

单一声速相当于一个观测方程，对多组分混合物通常不足以唯一确定浓度。论文把声速和衰减作为两个相互补充的观测量：

\[
\begin{cases}
c=F(w_1,w_2,\ldots,T,P,f)\\
\alpha=G(w_1,w_2,\ldots,T,P,f)\\
\sum_iw_i=1
\end{cases}
\]

对三元混合气体，只有两个独立浓度变量，因此理论上可由 \(c\) 和 \(\alpha\) 两个独立观测量求解。

论文采用曲面交线法：

1. 在浓度空间建立声速曲面和衰减曲面；
2. 用实测声速值对声速曲面作等值截面；
3. 用实测衰减值对衰减曲面作等值截面；
4. 两条等值曲线的交点给出两个组分浓度；
5. 第三个组分由浓度和为 1 得到。

实验证例中，\(c=303.26\ \mathrm{m/s}\)、\(\alpha=0.025\ \mathrm{m^{-1}}\) 对应约 20% CO₂、30% N₂ 和 50% Ar。

**8. 浓度场重建原理**

论文还把点式检测扩展为声学层析重建。将测量区域离散成若干网格，假设每个网格内部浓度和声速均匀。

第 \(i\) 条声路的传播时间为：

\[
t_i=\sum_j l_{ij}s_j
\]

其中：

- \(l_{ij}\)：第 \(i\) 条声路在第 \(j\) 个网格中的长度；
- \(s_j=1/c_j\)：第 \(j\) 个网格的声慢度。

写成矩阵形式：

\[
\mathbf L\mathbf s=\mathbf t
\]

论文使用最小二乘法求解：

\[
\hat{\mathbf s}
=
(\mathbf L^\mathrm T\mathbf L)^{-1}
\mathbf L^\mathrm T\mathbf t
\]

然后按照声速—浓度模型把声慢度场转换为浓度场，再通过插值细化网格。

其仿真模型采用 20 个超声换能器、58 条有效声路和 27 个网格。该结果证明的是给定理想模型和指定噪声条件下的数值可行性，不等同于实际工业现场精度。

**9. 论文实验系统**

实验系统由配气、测量和采集三部分组成：

- N₂、CO₂、Ar 气瓶及质量流量控制器；
- 密闭气体腔、温度计和压力计；
- 收发一体式超声换能器；
- CTS-8077PR 脉冲发生接收仪；
- USB-5133 数据采集卡；
- 采样率 100 MS/s；
- 超声频率 135 kHz；
- 换能器可沿导轨改变间距。

声速采用不同位置下的 TOF 测量；衰减采用多个距离上的电压幅值拟合。

**10. 影响因素与适用边界**

| 因素     | 对声速的影响                   | 对衰减的影响                   |
| ------ | ------------------------ | ------------------------ |
| 温度     | \(c\propto\sqrt T\)，影响显著 | 改变黏度、热导率和弛豫过程            |
| 压力、密度  | 理想气体声速中影响较弱              | 直接影响吸收和弛豫频率              |
| 湿度     | 改变混合物物性                  | 对分子弛豫尤其敏感                |
| 超声频率   | 理想声速基本不变                 | 经典衰减约随 \(f^2\) 增长，弛豫呈频散峰 |
| 气流     | 引入顺逆流传播时间偏差              | 引起幅值波动和路径偏折              |
| 颗粒、雾滴  | 可能引起声速路径变化               | 产生额外散射衰减                 |
| 换能器与几何 | 影响时延零点                   | 影响幅值、波束扩散和系统损耗           |

因此，工程应用不能把全部幅值下降都解释为气体吸收。换能器响应、几何扩散、壁面反射、散射、温度和压力变化必须通过标定或模型分离。

**总体评价**

该论文建立的是一种“双特征声学指纹”检测方法：

\[
\boxed{
\text{组分变化}
\rightarrow
\text{混合物热力学与分子结构变化}
\rightarrow
(c,\alpha)\text{变化}
\rightarrow
\text{组分浓度反演}
}
\]

声速主要反映摩尔质量和比热性质，衰减主要反映黏滞、热传导及分子弛豫。两者联合能够提高多组分气体的可辨识性，但前提是温度、压力、湿度、频率和测量几何受控，并且 `(c,\alpha)` 到浓度的映射在目标浓度范围内具有唯一解。
