## 1 系统概述

本系统面向**掺氢天然气**管道场景，采用多种传感原理（热导、红外 NDIR、超声波、光纤声传感）实现气体组分的多模态检测，辅以温湿度补偿，并通过 ADC / 数据采集卡完成信号数字化。系统核心传感器与数据采集器件如下：

| 序号  | 器件                | 检测对象 / 功能         | 检测原理             |
|:---:| ----------------- | ----------------- | ---------------- |
| 1   | TCS205            | 氢气含量 / 气体热导率      | 热导法（薄膜电阻加热）      |
| 2   | TraceGas-HC-NDIR  | 甲烷及烷烃类可燃气体        | 非色散红外（NDIR）      |
| 3   | TraceGas-NDIR-CO₂ | 二氧化碳              | 非色散红外（NDIR）      |
| 4   | SHT45             | 环境温度 & 相对湿度       | CMOSens 电容式 / 带隙 |
| 5   | PSC200K           | 超声波传播特性（声速 / TOF） | 压电陶瓷超声           |
| 6   | LB-FOM-D30L       | 声压 / 声衰减波形        | 光纤声光转换 + 光电解调    |
| 7   | ADS8684 / ADS8688 | 模拟信号采集            | 16-bit SAR ADC   |
| 8   | NI USB-6453       | 高精度数据采集           | 20-bit 同步采样 DAQ  |

## 2 TCS205 气体热导传感器

**制造商：** Xensor Integration（代理：广州安凯电子）
**资料来源：** `TCS205 气体热导传感器.pdf`

### 2.1 工作原理

传感器芯片由硅微机械加工制成，核心为面积约 1 mm² 的绝热薄膜。薄膜上有两条薄膜电阻 Rm1、Rm2，用于加热薄膜并测量膜温 Tm。薄膜上方覆盖带腔体的硅盖片，构成热导测量室（体积 ~0.2 mm³）。气体通过侧面开口以扩散方式进入测量室（非流动），避免流速干扰。

芯片固体部分另有两条电阻 Rt1、Rt2 用于测量和补偿环境温度。通过维持膜的超额温度 ΔT 恒定，测量维持该温度所需的功率或信号变化，即可反映气体热导率 λ 的变化。

### 2.2 主要应用

- 测量氢气含量（氢的热导率远高于其他气体）
- 二元气体分析（CO₂/N₂、O₂/N₂ 等）
- 天然气鉴别与分类
- 沼气 / 消化池气体监测
- 氦气、氙气含量测定

### 2.5 引脚与接口

- **封装：** TO5-style 8 引脚底座
- **接线材料：** 金丝键合
- **气体接触材料：** Si, SiNx, 金, 环氧树脂

### 2.6 推荐应用电路

资料提供了三种典型电路方案：

1. **恒定超额温度模式**（ΔT=const）：Rm1+Rm2 串联在两个运放之间形成正反馈环路，Rt1+Rt2 提供一阶温度补偿。灵敏度示例：1% He in N₂ → U1 变化约 140 mV。
2. **恒定膜电流模式**（im=const）：通过温补负参考电压驱动恒流，R4 实现二阶温度补偿。
3. **惠斯通电桥模式**：可配合标准应变计仪表使用，对角电压 Udiag 作为输出信号。

## 3 TraceGas-HC-NDIR 可燃气体红外传感模块

**制造商：** 深圳市痕量气体传感科技有限公司
**资料来源：** `可燃气体红外传感器-说明书V1.5.pdf`

### 3.1 工作原理

基于**比尔-朗伯定律**，采用 NDIR（非色散红外）原理。使用 LED 窄带光源和快速响应光电二极管（PD），结合低功耗电路和优化光学系统实现气体浓度检测。

| 支持气体类型   | CH₄ 和 i-C₄H₁₀（可切换）            |
| 测量范围     | 0 ~ 100 %LEL                  |

### 3.5 常用通信指令

| 指令          | HEX               | 功能       | 回复说明                                             |
| ----------- | ----------------- | -------- | ------------------------------------------------ |
| `DATAE`     | 44 41 54 41 45    | 读取浓度     | 5 字节：浓度H + 浓度L + 状态码 + BCC + 0x0D                |
| `DATAF`     | 44 41 54 41 46    | 读取浓度+温湿度 | 9 字节：浓度(2B) + 状态码 + 温度(2B) + 湿度(2B) + BCC + 0x0D |
| `ZERO2`     | 5A 45 52 4F 32    | 零点调整     | "ZERO2 OK"                                       |
| `CALB XXXX` | 43 41 4C 42 20 XX | 量程调整     | "CALB OK"                                        |
| `INIT`      | 49 4E 49 54       | 恢复默认     | "INIT OK"                                        |
| `SGAS X`    | 53 47 41 53 20 XX | 切换气体类型   | "Current Gas Type CH4/C4H10"                     |
| `USERSET`   | —                 | 查询用户设置   | 返回各项补偿系数                                         |

**浓度解算：** 浓度值 = (H×256 + L) / 100 (%VOL)

**温度解算：** T(°C) = 175.0 × 温度值 / 65535 - 45.0

**湿度解算：** RH(%) = 100.0 × 湿度值 / 65535

### 3.6 注意事项

- 上电后需预热 ≥60 s，调零前需温度变化 <0.6°C/min
- 传感器配有疏水膜，污染严重时需更换
- 校准建议使用 ≤60%LEL 目标气体
- 禁止带电热插拔
- 请勿焊接引脚，使用配套管座连接
- 电池供电建议 ≥3.3 V，以保证低温供电稳定

### 7.1 工作原理

PDF 描述：前端采用**声光转换**将声音信号转为光信号，经光纤传输；后端经**光电转换**还原为声音电信号。相对传统电容/压电麦克风，前端可做成无源光路，适合强电磁干扰、易燃易爆等场景。

结合项目专利文稿中的用法，本系统采用「探头 + 解调机箱」分离架构：

- **光纤探头**：深入气团，拾取声压 / 声衰减相关光参量；
- **光纤麦克风机箱（解调端）**：完成光电解调与放大，输出模拟电信号至高速 DAQ。

与 PSC200K 的分工（专利表述）：PSC200K 侧重声速 / TOF；光纤麦克风侧重声衰减波形与高保真声压特征。

### 7.6 使用注意（结合 PDF + 系统语境）

- 探头端为光路拾音，适合气室内本安 / 抗 EMI 布置；解调机箱与锂电池宜放在腔外。
- 频响从 3 kHz 起，**不覆盖**可听声低频段；若需环境噪声或次声，需另配传感器。
- 与 PSC200K（200±10 kHz）频带有重叠，可做声速（压电）与声衰减（光纤麦）对照，但两者灵敏度、指向性、安装位置不同，不可直接互换标定。
- 耳机口为模拟输出：接入 USB-6453 前确认电平，避免过载；若同时使用 TF 卡 WAV，注意与 DAQ 时钟不同步。
