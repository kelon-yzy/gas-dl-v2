## 2. 数据 schema 契约

代码常量，位于 `tv3/sim/core/tunnel_ventilation_schema.py`：

```python
COMPONENT_FIELDS = ("x_CO2", "x_O2", "x_N2")     # 3 列预测目标
BACKGROUND_FIELDS: tuple[str, ...] = ()           # 空：N₂ 是显式目标，不是背景气
SLOW_CHANNELS = (
    "V_NDIR_CO2", "V_TCS", "T_C", "P_MPa", "H_RH", "L_m", "piston_position_m",
)                                                  # 7 通道
SPLIT_FIELDS = ("sequence_id", "mixture_id")
SPLIT_NAMES = ("train", "val", "test", "extrapolation")
```

- 慢通道 **7 个**，无 `V_NDIR_CH4`（场景无 CH₄）。见到 8 通道的数据即为旧本地污染集，见 §5。
- 模态分组 `SLOW_MODAL_GROUPS`：optical / thermal / environment（`:43-47`）。
- 标签严格满足 `x_CO2 + x_O2 + x_N2 = 100%`，N₂ 写入 `labels/y.npy`。
- split 主键是 `mixture_id`，不是 `sequence_id`。
- ID 规范：MixtureId `M000001`，SequenceId `Q000001`。

manifest 必须含 `composition_scheme` / `background_fields` / `slow_channels` / `labels` / `sim_revision`。

## 3. 模型输出与损失契约

### 3.1 输出

正式模型直接输出三个 raw 值，`output_mode="raw3"`、`out_dim=3`。`cnn1d_tcn_fusion` 在 tv3 下必须用 `raw3`，`gas_head` 由校验拒绝。

### 3.2 禁用清单

以下一律不使用，不是"当前不用"而是契约禁止：

```text
gas_head
N₂ 闭包回填（二输出 + 第三列反算）
ILR / ALR
target_transform
free_component_mse
闭包残差头
compositional_mse / ilr_mse / weighted_free_component_mse   # 闭包类 loss
```

闭包类 loss 由 `validate_loss_composition_scheme()` 在 tv3 场景自动拒绝。可用的是开放类：`weighted_component_mse` / `mse` / `mae` / `smooth_l1` / `huber`。

### 3.3 sum_abs_error

数据层 sum=100% 严格闭包，但 `sum_abs_error` 只作监控指标，不是强制输出约束，也不能替代 O₂ 性能陈述。

参考值：Ridge 近零；R5-T val `0.0307`；B7 约 `2e-4–4e-4`；TabPFN `0.157` 但 O₂ 更好。闭包误差与 O₂ 精度之间没有单调关系。

### 3.4 真值量隔离

`tof_s`、真实声速、真实衰减系数 α 只能进 oracle 审计或辅助目标，不得进入部署输入。任何用了这些量的结果，谈可部署性时按 §12 扣除膨胀量。

### 3.5 失败必须可见

缺少 manifest、waveform scale、slow metadata 或必需数组时，程序直接失败。不允许静默后备路径、默认填充或降级为可用子集。

## 6. 波形与 DL 输入通路契约

### 6.1 通道组装顺序

```text
慢通道（slow） → 归一化前统计量（stats） → 波形样本
```

### 6.2 预处理

输入契约为 `dequantize_waveforms`，可选 `normalize_waveforms` / `waveform_stats_features`。

正式波形配置默认 `waveform_preprocess: "gpu"`：DataLoader 只搬运 `int16` 数据和缩放系数，反量化、统计量、z-score 在设备侧完成，数值语义与 `cpu` 路径对齐。

**`gpu` 路径不支持 `window` / `phase_windows` / `augment`**，违反时直接失败。需要这三项时显式切 `cpu` 并作为对照运行。

实现见 `tv3/dl/data/waveform_preprocess.py`，操作手册见 `operations/server_training_guide.md` §4.5。

### 6.3 scaler

输入和目标的 scaler 只能由训练集拟合。模板标定同样只允许训练集基线中位数，禁止使用精确仿真器模板。

### 6.4 深度模型训练约束

- 保留逐目标 target scaling（这是已验证的优化条件，不是可选项）。
- 前端涉及 TOF 时，损失单位用 sample 或 μs。**秒量级会让梯度接近零**。
- 训练可微模板时限制相关峰搜索窗；禁止用全局池化作为 TOF 主路径（会抹掉位置信息）。
- 模板残差必须有 L2、平滑或频域带宽约束。
- 联合损失中的组分项、TOF/peak 辅助项、模板正则项分开记录。
- 不同时大改前端、头部、损失和 split 后再做归因。

## 7. 仿真物理规格

### 7.1 波形与采集（`tv3/sim/generation/waveforms.py:25-72`）

| 参数        | 值              | 常量名                               |
| --------- | -------------- | --------------------------------- |
| 载波中心频率    | 200 kHz        | `CENTER_FREQUENCY_HZ`             |
| burst 周期数 | 8              | `BURST_CYCLES`                    |
| 采样率       | 1 MS/s         | `SAMPLE_RATE_HZ`                  |
| 超声帧长      | 5 ms → 5000 点  | `ULTRASONIC_MEASUREMENT_WINDOW_S` |
| 光纤麦帧长     | 10 ms          | `FIBER_MIC_MEASUREMENT_WINDOW_S`  |
| 物理 ADC 位深 | 20-bit         | `DEFAULT_DAQ_BITS`                |
| DAQ 量程    | 2.5 V（NI-6453） | `daq_full_scale_v`                |
| 系统固定延迟    | 80 μs          | `system_delay_s`                  |
| 电缆延迟      | 2 μs           | `cable_delay_s`                   |
| 延迟校正量     | 82 μs          | `delay_correction_s`              |
| 触发抖动 std  | 3 μs           | `trigger_jitter_std_s`            |
| 换能器带宽     | 20 kHz         | `transducer_bandwidth_hz`         |
| ringdown  | 4 周期           | `transducer_ringdown_cycles`      |

波形模型：8-cycle burst + 二阶谐振带通换能器响应 + Lagrange 分数延迟。

**波形峰值 = 真实 TOF + 82 μs 固定延迟 + 抖动**。直接把峰位当 TOF 会得到 84 μs 量级的伪误差，这不是峰值定位精度。

### 7.2 存储（`tv3/sim/generation/tunnel_ventilation/benchmark.py:201-213`）

tv3 生成路径**无条件**使用 `waveform_dtype="int16"` + `per_timestep_scale=True`。物理 ADC 仍是 20-bit，存储时按每 timestep 峰值定标压缩为 int16——实测峰值只占满量程约 22%，per-timestep scale 的量化步长比固定 scale 小约 4.6 倍。

`skip_fiber_mic` 不同：CLI 的 `--skip-fiber-mic` 是 `store_true`，**默认 False**（生成光纤麦波形）。正式 tv3 数据集生成时显式传该 flag；双向 preset 内置为 `True`（`generate_tunnel_ventilation_benchmark.py:51`）。跳过后数据集体积 17 GB → 3 GB，误差/噪声影响约 1%，光纤麦代码保留可恢复。

注意 `WaveformSpec` 类的字段默认值是 `int32` / `per_timestep_scale=False`（`waveforms.py:59-60`），由 tv3 生成路径覆盖，不要拿类默认值当实际存储格式。

### 7.3 声程与仿真版本

- 声程扫描：`(0.18, 0.20, 0.22, 0.25, 0.28)` m — `tv3/sim/generation/tunnel_ventilation/benchmark.py:70`
  200 kHz 下声程上限约 0.3 m，长声程信号被弛豫吸收淹没。
- 单向 `sim_revision.tag = "v6-phys-strict"` — 同文件 `:288`

### 7.4 物性与声速

| 量          | CO₂   | O₂      | N₂    |
| ---------- | -----:| -------:| -----:|
| M，g/mol    | 44.01 | 31.9988 | 28.01 |
| γ，300 K    | 1.289 | 1.400   | 1.400 |
| λ，mW/(m·K) | 16.6  | 26.4    | 25.8  |

```text
c = sqrt(gamma_mix * R * T / M_mix)      # 理想气混合
```

热导用 Wassiljewa-Mason-Saxena 混合规则。

- O₂/N₂ 靠摩尔质量差（14.3%）产生约 6.4% 声速差，这是超声通道区分两者的物理基础。
- O₂/N₂ 的 γ 相同，热导差约 2.3% —— TCS 对两者只有边际辨识力。
- O₂ 是同核双原子，无红外活性，**不设 NDIR 通道**。
- 场景只有 CO₂ 一个红外活性组分，**无光学串扰矩阵**。
- 干空气下 O₂ 的 V-T 弛豫频率约 24 Hz/atm，远低于 200 kHz 载波，工程实现取 `alpha_o2 ≈ 0`。
- 当前模型里 P/RH 主要影响衰减、光学与慢通道，未经消融不得当作声速校正主项。

`PROCESSING_PARAMS["t_delay_s"] = 0.00008` — `tv3/sim/generation/tunnel_ventilation/acoustic_physics.py:25`

## 8. 组分域与采样

两个域并存，默认 narrow。定义在 `tv3/sim/generation/tunnel_ventilation/conditions.py:47-67`：

| 域          | x_CO2       | x_O2         | x_N2         | 用途         |
| ---------- | ----------- | ------------ | ------------ | ---------- |
| narrow（默认） | 0.03–5.00%  | 18.00–21.20% | 73.80–81.97% | 单向正式链路     |
| wide（危害监测） | 0.03–10.00% | 15.00–25.00% | 65.00–84.97% | 仅 F 线可显式选择 |

- `x_N2 = 100 - x_CO2 - x_O2`，被动计算，角点自动满足。
- 采样方式：CO₂/O₂ 受约束 LHS。
- wide 域使用独立的 `*-wide` 数据集名（写一次不覆盖），`apply_composition_domain_dataset_slug()` 强制此规则。
- **单向默认始终 narrow**，不得静默改写单向历史链路。
- **MRS / MRS-EI 全线使用 narrow 域**。`configs/tv3_mrs_ei/design_space.json` 登记四个 O₂ 窄窗（中心 18.4 / 19.2 / 20.0 / 20.8，宽 0.8，铺满 18.00–21.20%）与 CO₂ 网格 `[0.03, 2.515, 5.0]`（上限 5.0 而非 wide 的 10.0）；该目录下无任何 wide 引用。冻结产物的 `design_condition_id` 带 `o2_18_4|co2=0.03` 一类窄域标记。带 `-wide` 的配置文件只有 4 个，全部是 `tv3_bidir_*`。

O₂ 的 narrow 量程只有 **3.20 个百分点**。这个数在判断区间宽度是否有意义时反复用到。**引用 MEI 系列区间宽度时分母固定为 3.20**，不要误用 wide 域的 10.00 pp——wide 域只属于已判 `f5_model_protocol_failed` 的 F 线。

## 9. 划分语义与证据边界

### 9.1 四个划分器

| 划分器 | 含义                  | 能证明什么                                  |
| --- | ------------------- | -------------------------------------- |
| R   | 随机                  | 域内稳定性对照                                |
| L   | LHS 边界              | 域内对照；与同 seed 的 S-L 共享 OOD 集，**不算独立证据** |
| S-Y | `y_margin_ood` 目标边界 | 组分边界 OOD                               |
| S-L | `lhs_boundary`      | 组分边界 OOD                               |

### 9.2 必须遵守的表述边界

- **S-Y 的三个划分 seed 共享同一个 `ood_set_hash`**。重复实验只能量化同一 OOD 集上的划分内方差与训练 seed 方差，不是三次独立验证。
- S-L 的三个划分 seed 的 OOD 集不同，才能复核随 seed 变化的 OOD。
- S-Y 与 S-L 的 B7 OOD O₂ R² 分别约 `0.434` 与 `0.700`，**差 0.27**。不得合并成一个"OOD 性能"数字。
- 现有正式数据的 `extrapolation` 只是随机打乱后剩余的样本，**不是物理 OOD**。
- 从未验证过的条件：真实硬件 OOD、湿空气、设备 profile holdout、时间漂移、校准批次、Sim2Real 波形统计距离。这些不能出现在任何能力声明里。

### 10.1 S1 后验基线的登记参数与已知边界

MEI-4 C0 登记的区间构造参数（`configs/tv3_mrs_ei/mei4_execution_contract.json:103-111`）：

| 项      | 值                          |
| ------ | -------------------------- |
| 区间类型   | `equal_tailed`             |
| 名义水平   | 0.5 / 0.8 / 0.9 / 0.95     |
| 数值方法   | 打乱 Sobol 参数空间拒绝抽样 + 倍分辨率复核 |
| 初始候选   | 65536                      |
| 复核候选   | 131072                     |
| 最小接受候选 | 2048                       |

接受数低于 `2048 / 65536 = 3.125%` 时，`sample_nonnegative_tangent_gaussian` 抛 `truncation_interval_numerical_failure`（`tv3/ml/mrs_posterior.py:195-196`）。等价说法：**超过 96.9% 的切空间高斯质量落在非负物理域外时无法构造区间**。

以下三项引用 C2 结果时必须一并说明。证据均在 freeze `20260730T071532806157Z_76811228bcea`。

**边界 1 · 拒绝原因按方法不同，不得合并成单一机制陈述。**

`laplace_diagnostics.json` 的实测构成：

| 方法  | test 拒绝           | test 原因构成                                                       | ood 拒绝           |
| --- | ----------------- | --------------------------------------------------------------- | ---------------- |
| M1  | 205 / 648 = 31.6% | 截断失败 205（100%）                                                  | 42 / 648 = 6.5%  |
| M1b | 183 / 648 = 28.2% | 截断失败 183（100%）                                                  | 42 / 648 = 6.5%  |
| M2  | 240 / 648 = 37.0% | `m1_proposal_unavailable` 205 + `psis_k_hat_exceeded_for_M2` 35 | 71 / 648 = 11.0% |

只有 M1 / M1b 是 100% 截断失败。M2 有 35 次（占其拒绝的 14.6%，占 648 的 5.40%）是 PSIS 超阈，与截断无关。`curvature_not_positive_definite` 与 `curvature_condition_number_exceeded` 在六个分组中均未出现。

**边界 2 · S1 点估计本身可能出域。**

同一 freeze 的 `complete_hessian` 审计中 **4 / 24** 个探针状态为 `unavailable`，错误为 `S1 parameters are outside the registered physical domain`（test `M000649` / `M001001`，ood `M001297` / `M001473`）。

`s1_replay` 的 24 / 24 一致只说明复解可重现，**不说明解落在物理域内**。两者不可互相代替陈述。

## 12. 报告纪律

这些是数值表述要求，违反会让结论失真。

1. **窄窗能力不能用整体 R² 汇报。** 0.8% O₂ 分箱内的 R² 即使用 oracle 特征也全为负（−9.2 ~ −2.6）。整体量程（18.0–21.2%）上的粗档位可分辨，与窄窗精细回归是两件事。bin 内 R² 只作诊断。

2. **oracle 结果要扣掉约 0.18 的膨胀量。** R0 oracle Ridge val 0.6025 vs D0-observed Ridge 0.4226。任何用 `tof_s`、真实声速、真实 α 的结果谈可部署性时先扣这个量级。TabPFN 的 0.667 同样是探针，不是部署能力。

3. **OOD 各机制分列，不合并。** 见 §9.2。

4. **拒绝率必须完整报告，拒绝原因按方法与域分列。** 不得通过拒绝大量样本后只展示提高的 R²，也不得把多个方法的拒绝原因合并成单一机制陈述（见 §10.1 边界 1）。

5. **选择条件覆盖率与无条件覆盖率同时给出，并标注各自样本量。** 两者差距很大：M1 test O₂ 的选择条件覆盖率（只算能构造区间的 443 个样本）为 `0.6072 / 0.9120 / 0.9842 / 0.9977`，无条件覆盖率（全部 648 个）为 `0.4151 / 0.6235 / 0.6728 / 0.6821`，对应名义 `0.5 / 0.8 / 0.9 / 0.95`。`coverage_report.json` 里的 `coverage` 字段记的是无条件值。只报选择条件会把 31.6% 的拒绝隐掉。
   
   `within_acceptance_band` 按无条件值判定。M1 的 8 个 O₂ 主覆盖带中只有 `ood @ 0.95` 落在接受带内，其余 7 条全部不过。

6. **0.4 vol% 的地位**：2026-07-25 起由强制门降级为**参考标注**。历史结论均在原强制门下判定，不改写、不因门槛变化重跑。恢复强制门需业务侧重新决策。

7. **最小报告集合**：

| 维度          | 必报                                                                          |
| ----------- | --------------------------------------------------------------------------- |
| 整体回归        | 各组分 R²、MAE、RMSE、bias、P90 绝对误差                                               |
| O₂ 业务区间     | 预先固定 bins 的 MAE、bias、P90、相邻档可分概率、coverage、样本量                               |
| Worst group | T、RH、L、flow、SNR、device、day、calibration_session、gas_batch、composition_corner |
| 链路健康        | peak P95、声速 bias、flow 残差、reciprocity error、SNR、multipath score、delay drift  |
| 稳定性         | train/val/test/OOD gap，多 seed 均值、标准差、最差 seed                                |
| 闭包          | sum_abs_error（仅监控）                                                          |

8. **区间验收**（若输出不确定度）：90% coverage 目标 88%–92%，95% 目标 93%–97%，关键环境组不低于 nominal −5%，按每个划分器分开验收。**同时检查区间宽度相对量程是否有意义**——覆盖率合格但区间宽于工作量程时，结论固定为观测信息不足（见 §10.1）。

9. **非正式工程测量不写入正式 freeze。** 本机计时、冒烟结果、未验收草稿只进对应计划文档。

## 13. 产物与 freeze 规则

### 13.1 目录

```text
outputs/
├── tv3_d0/ tv3_d2/ tv3_d2b/ tv3_r5/ tv3_r7/ tv3_rocket/     # 早期与回归头

├── tv3_identifiability/ tv3_ec_msw/ tv3_mrs/ tv3_bidir/
├── runs/tv3_mrs_ei/<阶段>/freezes/                           # MRS-EI 版本化冻结
├── runs/tv3_mrs_ei/mei4_posterior_calibration/attempts/      # C3 可恢复分片，非证据
├── summary/                                                   # 跨运行汇总
└── archive/{debug,legacy_dl,local_600,early,superseded}/     # 历史与调试
```

新的冒烟或调试运行直接写入 `archive/debug/`。查旧文档提到的路径时加 `archive/` 前缀。

### 13.2 freeze 规则

```text
outputs/runs/tv3_mrs_ei/<阶段>/freezes/<UTC时间戳>_<短哈希>/
```

- 每次新建目录，**不覆盖**旧证据。
- 每个 freeze 自带 `evidence_manifest`（SHA256）和 `source_snapshots/`，可独立校验，不依赖工作区状态。
- `attempts/` 与 `freezes/` 物理分离。分片只用于恢复计算，不是科学证据，不触发阶段状态晋升。
- 聚合报告和 freeze 写在全部子任务成功之后。**中途终止的运行没有产物，内存结果不算证据。**

### 13.3 冻结登记表不随文档移动更新

`configs/` 下参与 SHA256 冻结的登记表（`tv3_bidir/parameter_registry*.json`、`tv3_mrs/stage_status.json`、`tv3_mrs_ei/design_space.json` 等）里的文档路径字符串是**登记时点的 provenance 记录**。文档移动或改名时**不要修改这些字符串** —— 改动会改变文件哈希，破坏已冻结产物的校验链。

要查这类路径指向的文档现在在哪，用文件名到 `docs/` 下搜索。

运行时会真正读取路径的代码（例如 `scripts/run_tv3_mei3_*_solver_audit.py` 的 git 脏检查清单）不在此列，那些必须跟随移动更新。

### 13.4 秩结论的容差要求

SVD 离散秩对容差敏感（0.1× / 10× 容差分别改变 81/216 和 97/216 个点的秩）。任何秩结论必须跨 `1e-7 / 1e-6 / 1e-5` 三档一致才成立。
