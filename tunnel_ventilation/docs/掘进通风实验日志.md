## 1. 项目至今学到的

一年后回看，这个项目值得记住的是下面八条。

**1. O₂ 有一堵物理墙，位置在 1.0–2.4 vol%。**

这是全项目最重要的事实，由六次相互独立的测量给出同一个答案：

| 来源                  | 日期    | 窄窗 O₂ 精度                                             |
| ------------------- | ----- | ---------------------------------------------------- |
| D0 oracle（用真值特征）    | 07-08 | 0.8% bin 的 R² 全负（−9.2 ~ −2.6）                        |
| 可辨识性 v1 单向 TOF      | 07-13 | P90 = 8.85–12.99 vol%（1 K + 3 μs 情景）                 |
| 双向 F4               | 07-24 | 拒绝率降到 0，窄窗 P90 仍远高于 0.4                              |
| MRS-2 多频            | 07-24 | 最佳臂 median P90 ≈ 2.40 vol%                           |
| MRS-6 硬件扫描          | 07-25 | 饱和层 1.0–1.3 vol%，第一约束是 L 先验 0.1 mm                   |
| MEI-3 B4 / MEI-4 C2 | 07-30 | S1 test P90 = 1.66；单样本 95% 后验区间 5.72 pp > 量程 3.20 pp |

整体量程（18.0–21.2%）上的粗档位可分辨，窄窗口精细回归不行。**用整体 R² 汇报窄窗能力是错的**，项目已经把这条固定成报告纪律。

0.4 vol% 这个门 2026-07-25 起降级为参考标注，不再作强制判据——但这是业务决策，不改变物理事实。

**2. 目标尺度比网络结构重要得多。**

R5 小 MLP 在 observed 特征上是 −0.18（训练集就失败）。R5-T 只加了逐目标标准化，其余全不动，变成 0.646。同一配方迁到 RawDSP 上（B6）同样成立。

在此之前项目怀疑过闭包、加权、早停、输入标准化——逐条排除后才定位到目标尺度。教训是：**多目标回归先看目标的量纲和量级，再看结构**。

**3. 残差分解是唯一稳定超过 0.69 的可部署结构。**

B7 = 折外 Ridge 主趋势 + (64,64) 小 MLP 学残差 → test O₂ 0.700。

对照：所有端到端波形路线全部是负 R² —— R1b MiniRocket（−0.195）、fusion v3_l2（−0.061）、D2 TOF-PhaseNet（−0.011）、EC-MSW E1（−0.006）、E1r（−0.010）。**五次，五种不同结构，同一个结果。**

**4. 物理先验加在特征上有效，加在结构上做早期隔离有害。**

- 加在特征上（RawDSP 提取、校准栈 + SNR）：有效，B1 达到 observed 平价。
- 加在结构上（模块 C 按物理组各自压到 16 维）：24 条矩阵全线不合格，test ΔR² −0.13 ~ −0.15。
- 同参数量的随机置换分组（C2）反而比物理分组好 0.09–0.17 —— 说明问题不是容量，是**早期隔离切断了跨组关系**。
- 加在求解器上（MEI-3 VarPro 条件线性块）：结构成立，但改善的 CI 下界 0.0116 < 实践界 0.02，不过门。

**5. 前置条件通过不等于目标达成。这个坑踩了五次。**

| 前置条件          | 通过了                            | 但是                             |
| ------------- | ------------------------------ | ------------------------------ |
| E1r 帧保真       | peak MAE 0.037 sample          | 序列级 B1 平价失败（O₂ R² −0.010）      |
| F5 流速解耦       | 成对声速偏差 1.81 → 0.037 m/s（降 98%） | OOD O₂ MAE 只改善 0.117 vol%，判据不过 |
| MRS-2 升秩      | 秩 1 → 3–5，多频信息确实是新的            | P90 2.40 vs 门 0.4              |
| MEI-3 VarPro  | 结构准入，参数差 1e-17 量级              | 改善 CI 下界不过实践界                  |
| MEI-4 Laplace | 曲率 / CRB = 1.00035，构造完全正确      | 区间宽于整个工作量程                     |

每次都是"机制上做对了，但收益不够"。**新方案立项时要预先问：机制成立之后，收益的量级是多少？** 只论证机制可行不够。

**6. 真值特征的膨胀量约 0.18。**

R0 oracle Ridge 0.6025 vs D0-observed Ridge 0.4226。任何用 `tof_s`、真实声速、真实 α 的结果，谈可部署性时要先扣掉这个量级。TabPFN 的 0.667 同样是探针，不是部署能力。

**7. OOD 不是一个概念，是一族概念。**

同一个 B7，S-L 划分器上 OOD O₂ R² = 0.700，S-Y 上只有 0.434，差 0.27。而且 S-Y 的三个划分种子共享同一个 OOD 集合，只能量化划分内方差，不算三次独立验证。

现在报告纪律是：**各机制分列，不合并成一个"OOD 性能"数字**。当前所谓 extrapolation 也只是随机剩余样本，不是物理 OOD。

**8. 失败必须分解到机制才算完成。**

MEI-4 C2 当时只写了"M1/M1b/M2 均未过 24 条主覆盖带"。两周后复读冻结产物才定位到主导机制：M1/M1b 的拒绝 100% 来自截断数值失败，M2 的多数拒绝继承自它，触发点是 96.9% 以上的切空间高斯质量落在物理域外——而这直接由"用了单纯形上的平坦先验、而登记数据实际由受约束 LHS 生成"造成。分方法的完整拒绝构成、区间宽度与覆盖率两种统计见[事实源 §10.1](掘进通风代码契约事实源.md)。

**有机制的失败能指出下一步改什么；没机制的失败只能重跑。** 这两周的空转本可以避免。

## 2. 实验时间轴

### 2.1 建场景（07-06 ~ 07-07）

从 hydrogen_ng / syngas 分出独立子工程 `tv3`，三组分 CO₂/O₂/N₂，sum=100% 严格闭包但模型层不用闭包残差头。

定下几条一直没变的契约：正式输出 `raw3` / `out_dim=3`；不用 `gas_head`、N₂ 回填、ILR/ALR、`target_transform`；`sum_abs_error` 只作监控；真值量只能进 oracle 审计。

同期完成波形归一化稳定化和 DL 训练动力学修复 v2。

> 事后看，`raw3` 这条契约挡住了后面反复出现的"二输出 + N₂ 回填能不能修复 O₂"的诱惑。数学上标签只有两个自由度，但回填只是机械消掉闭包误差，对 O₂ 没有帮助——Ridge 能同时做到近零闭包和有效 O₂，TabPFN 闭包误差 0.157 但 O₂ 更好，两者没有单调关系。

### 2.2 信息在哪：D0 六组特征拆分（07-08）

一次性问清楚"O₂ 的信息在哪个通道里"。600 序列本地集先探路，clean 6000 上出正式数：

| 配置                    | val     | test    | extrap  | 读法          |
| --------------------- | -------:| -------:| -------:| ----------- |
| slow-only Ridge（600）  | −0.05   | —       | —       | 慢通道里没有 O₂   |
| R0 oracle Ridge       | 0.6025  | 0.6389  | 0.5567  | 真值上限        |
| D0-observed Ridge     | 0.4226  | 0.4571  | 0.3708  | **测量级线性基线** |
| D0-tof-only           | 0.3879  | 0.4236  | 0.3347  | TOF 是主信息源   |
| D0-slow-only          | −0.0013 | −0.0026 | −0.0348 | 只剩慢通道就归零    |
| D0-no-tof             | −0.0013 | −0.0026 | −0.0348 | 与上一行同一个配置   |
| D0-no-tcs             | 0.4297  | 0.4559  | 0.3827  | TCS 可以不要    |

> 2026-08-20 更正：`no-tof` 与 `slow-only` 的配置文件里 `physics_arrays` 都是空列表、`include_slow` 都为真，两者特征定义等价，只是构建器名字不同，指标逐位相同。原表把它们并成一行写"去掉 TOF 就崩"，实际移除的是全部五个超声派生数组。可支持的表述是"移除全部超声派生量后归零"；TOF 的主导地位由正向证据给出——仅保留四个 TOF 相关数组仍达 test 0.4236，是 observed 0.4571 的 93%。这批配置里没有、也无法构造"保留声速、单独移除 TOF"的消融，因为估计声速由 TOF 派生。

同时做了 0.8% O₂ 分箱，oracle 下 R² 全负（−9.2 ~ −2.6）。

**这一天定下三件事**：D0-observed 成为后面所有模型的对照基准；oracle 膨胀量 0.18 被登记；窄窗物理极限被首次观察到，且结论是"用真值都做不到"。

同期 R1a/R1b MiniRocket：TOF 标量序列 0.515（不如 oracle），原始波形 −0.195。随机卷积对这个问题无效。

### 2.3 raw 波形第一次尝试：D2 TOF-PhaseNet（07-08）

正式训练 −0.015 / −0.011 / −0.012。三组分全线低于 D0。

失败成因查清了五条，都是实现层面的：

1. 全局平均/最大池化对平移不敏感，丢掉了 TOF 的位置信息；
2. 匹配滤波核和 softargmax 温度固定，辅助输出在可训练投影层之前；
3. 梯度审计发现两个辅助输出 `requires_grad=false`，辅助损失根本训不到峰值估计器；
4. TOF 以秒为单位、峰值以归一化索引为单位，直接算 SmoothL1，辅助项量级约 1e-9，相对主损失可忽略；
5. 波形峰值对应"真实 TOF + 82 μs 固定延迟 + 抖动"，84.2 μs 的 MAE 不能解释成峰值定位误差。

**结论范围严格限定在这一个实现上**，不推广成"所有原始波形路线失败"。新路线独立立项为 D2b / RawDSP，不在旧实现上叠补丁。

| R5' TabPFN    | 0.6673  | 0.6594  | 0.6279  | ✅ 非部署上限探针          |

R5 失败前排除过一批猜测——输入没标准化（否，用了 StandardScaler）、O₂ 没加权（否，权重 [1,2,1]）、早停被 CO₂/N₂ 掩盖（否，直接按 val O₂ R² 早停）、MLP 得自己发现 L/TOF（否，观测声速已在输入里）。逐条排除后才定位到目标尺度，R5-T 一次通过。

TabPFN 的边界写得很清楚：**它证明当前 864 维特征里存在可被强表格先验利用的非线性，不证明链路可部署、不证明真实 OOD 下还有 0.66、不证明普通 MLP 能复现**。

### 2.5 RawDSP 复现测量级：D2b / B 系列（07-10 ~ 07-13）

这是项目最顺的一段。目标是用固定 DSP 从保存的原始波形重新估计出 D0-observed 那几个量，证明测量级基线不依赖仿真器同步生成的数组。

- **帧保真**：train-only 模板标定，peak P95 = 0.04443 sample，全帧接受。
- **B1 平价**：RawDSP Ridge 0.4280 / 0.4786 / 0.3695，相对 D0-observed 差 +0.0054 / +0.0215 / −0.0013，通过 ≤0.05 门。
- **B6**：RawDSP + 目标标准化 MLP，三个新增种子 0.5581 / 0.5356 / 0.4835，`stable_pass`。
- **B7**：折外 Ridge + (64,64) 残差 MLP，0.6964 / 0.7001 / 0.6157，`residual_pass`。
- **B7 协议**：R / L / S-Y / S-L × 3 划分种子 × 3 训练种子 = 36 行完整矩阵，`protocol_pass`。

| 划分器 | test            | OOD                 | 相对 B1 Δtest / ΔOOD |
| --- | ---------------:| -------------------:| ------------------:|
| R   | 0.6880 ± 0.0190 | 0.6429 ± 0.0256     | +0.2323 / +0.1923  |
| L   | 0.6590 ± 0.0198 | 0.7006 ± 0.0231     | +0.2208 / +0.2606  |
| S-Y | 0.6756 ± 0.0119 | **0.4340 ± 0.0279** | +0.1740 / +0.7009  |
| S-L | 0.6975 ± 0.0100 | **0.7002 ± 0.0260** | +0.1895 / +0.2570  |

07-13 冻结 B7 为默认 RawDSP 预测头，此后所有新模型必须以它为配对基线。

**S-Y 和 S-L 差 0.27 这件事，是"OOD 不是单一概念"的直接来源。**

288 个组分级 0.8% O₂ 分箱的 R² 仍然全负（均值 −4.01 / −5.69）。B7 把整体做上去了，窄窗没动。

### 2.6 物理引导结构证伪：模块 C（07-12）

想法是把特征按物理组分别压缩到 16 维再融合。24 条正式矩阵完整、审计通过、判定 `grouped_failed`：test ΔR² 相对 B7 为 −0.1482 / −0.1392 / −0.1303 / −0.1350，S-Y / S-L 的 OOD 差 −0.2662 / −0.1823，远低于 −0.01 非劣门。

关键对照是 C2：同为 28,051 参数，只是把分组随机置换，OOD 反而比 C1 高 0.0929 / 0.1706。**所以问题不是参数量，是物理分组的早期隔离本身。**

结论范围限定为"各物理组先独立压到 16 维"这一配方，不推广成全部物理引导结构失败。停止该分支的维度、组 dropout、组 gating 与 C1 编码器 TabM 调参。

### 2.7 转折点：可辨识性 v1（07-13）

前面所有工作都在问"哪个模型更好"。这一天开始问"信息够不够"。

冻结 B1/B7 之后做单向 TOF 的表示审计，189 个点：

- O₂ / CO₂ / T / L 的**联合 Fisher 秩 = 1**（声速只作 TOF 的派生诊断量，没有重复计入）；秩亏意味着无法对干扰参数做边缘化。
- 1 K 温度误差 + 3 μs 触发抖动下，0.8% O₂ 窄窗的联合 P90 = 8.85–12.99 vol%。
- 预注册门：P90 ≤ 0.4 vol%、单项干扰参数比例 ≤ 50%、拒绝率 ≤ 5%。前两项远超。
- flow 在 v1 中未表示，阻断规则拒绝了 189/189 个点，100% 拒绝率同样超门。

verdict = `information_source_upgrade_required`，永不改写。

**这个结论重新定义了整个项目**：主问题从"找更好的模型"变成三段因果链 —— 信息够不够 → 估计效率高不高 → 不确定度可不可信。后面 F 线、MRS 线、MRS-EI 线全部是这条链上的节点。

### 2.8 端到端门控：EC-MSW（07-13 ~ 07-17）

想在原始波形上做多尺度学习编码器 + 门控，一次性替掉 DSP 前端。

| 阶段               | 结果                               | 数                                                     |
| ---------------- | -------------------------------- | ----------------------------------------------------- |
| E1               | ❌ `frame_fidelity_failed`        | 帧 peak MAE 71–72 sample，P95 ≈ 155 sample（门 0.15/0.25） |
| E1r（模板锚点，绕过学习投影） | ❌ `b1_parity_failed`             | 帧通过（MAE 0.037），序列 O₂ R² −0.0089 / −0.0097 / −0.0165   |
| E1d 诊断           | ✅ `minimal_deployable_set_found` | 见下                                                    |
| E1d-SB           | ✅ `parity_passed`                | O₂ 0.393 / 0.453 / 0.369                              |
| E1r attachment   | ✅ `attachment_passed`            | 帧 + 序列同时通过                                            |
| E2s-LS 消融        | ✅ 但不晋升                           | Δ vs e1d_sb = +0.0006 级，可忽略                           |
| D1               | ✅ `deploy_probe_passed`          | 支线闭合                                                  |

E1d 是这段最有价值的部分——它用逐级累加定位了信息缺口的确切位置：

1. E1d-0 正对照 ΔR² = 0（探针本身没问题）；
2. E1d-1 学习嵌入 / 峰位 LMM / 相位窗，**全部不过门**；
3. E1d-2 累加 delay / corrected TOF / TOF-L / 声速，**仍只有 0.13–0.21**；
4. E1d-3 加入 `ultrasonic_snr_db` 后**跳变过门**，达到 0.393 / 0.453 / 0.369。

**结论：仅靠 TOF-L 校准补不回 O₂ 信息，必须有 SNR。** 这条后来直接否掉了"纯 TOF-L 加权 LS 声速头"的 E2s 提案（前置门 E1d-2 未过）。

全程 `e2_allowed=false`，FiLM / attention / MoE 一次都没启动。理由是：清洁仿真里全帧接受、没有坏帧和质量异质性，质量感知注意力没有学习对象。

### 2.9 信息源升级尝试之一：双向超声 F 线（07-21 ~ 07-24）

v1 说 flow 未表示导致全拒绝，那就把 flow 表示出来。双向 AB/BA 测量一阶解耦流速。

- F0–F4 通过。可辨识性 v2 把 `flow_projection` 标记为 `implemented_physics`，**拒绝率降到 0**。但窄窗 P90 仍远高于 0.4，业务结论 `coarse_monitoring_only`。
- F5-wide 正式矩阵（宽域组分，6000 样本，S-Flow 10 格 + F5-S 60 格）：
  - 判据 (a) **失败**：B1 A1/A3 的 OOD O₂ MAE 从 1.23635 → 1.11981，只改善 0.11654 vol%。
  - 判据 (b)(c)(d) 全部通过。
  - 成对声速偏差 1.8067 → 0.03681 m/s，**降了 98%**。
  - 判据 (e) 混用了全相位帧 P95（16.60 μs）和 F3 稳态多声程门（0.10 μs），登记为审计口径缺口。

verdict = `f5_model_protocol_failed`，不进入 F6-wide，不许调门或重训规避判据 (a)。窄域 F5 / F6 不排期。

**这是"机制成立、收益不够"的第一个清晰样本**：流速确实被解耦掉了，声速偏差降了两个数量级，但 O₂ 的回归误差几乎没动。说明限制 O₂ 的不是流速。

### 2.10 信息源升级尝试之二：多频弛豫谱 MRS（07-24 ~ 07-25）

## 3. 反复被验证的规律

这些是跨多个实验重复出现的，比单次结论更值得记住。

**R1 · 先算信息量，再谈模型。**
MRS 线的顺序是典型：MRS-2 纯前向 Fisher 审计判生死，通过了才允许生成数据和训练。结果 MRS-2 就否了，省掉了整条 MRS-3/4/5。相比之下 D2、E1 都是先训练再发现前端不成立。

**R2 · 负对照要先于正结果。**
B0 的三组分同乘缩放（前向完全不变）、MEI-1 的合成偏差平行/正交/混合方向、MRS-2 的单频负对照、E1d-0 的正对照 ΔR²=0 —— 每一个都在正式结论前排除了一类伪信号。C1 vs C2（物理分组 vs 随机置换、同参数量）也是这个作用。

**R3 · 结论要写清楚适用范围。**
"D2 失败"限定为该实现，不是所有波形路线；"C1 失败"限定为"各组独立压到 16 维"，不是所有物理引导；"MRS-2 失败"限定为预注册门下，且明确写成硬件问题不是算法问题。范围写窄一点，后面才不会误伤能做的方向。

**R4 · 冻结防得住事后调门，防不住事前的契约矛盾。**
MEI-4 的流程纪律很严——C0 把 24 条覆盖带、拒绝语义、抽样规模、触发阈值全部预注册。但没人在冻结前检查"M2b 有没有登记 SBC/PPC"，结果跑到 C3 才发现目标 verdict 不可达。**冻结之后应该有一次一致性审查：每个可能的 verdict 是否都有可达路径。**

**R5 · 单位和量级问题伪装成结构问题。**
D2 的辅助损失 1e-9（秒 vs 归一化索引）、R5 的目标未标准化、MEI-1 的设计跨度 0.4565%／0.6725% 低于实践等价带 0.02（但高于数值保护带）—— 三次都是量级问题伪装成别的问题：前两次表现为"模型学不动"，第三次表现为"有一个设计排名"，实际只有 1 个可分辨秩级。

**R6 · 便宜的诊断优先。**
E1d 用 Ridge 探针逐级累加特征，几分钟就定位到 SNR 是缺口；MRS-2 纯前向审计没有训练成本；C2 的复读没有新计算。相比之下 F5-wide、E1 各花掉一次完整的服务器训练。

**R7 · 一个数不要在两个地方维护。**
项目状态曾在 6 处并行维护（记忆库、统一路线、docs/README、active/README、名词导读、审查报告），静止空气计划头部长期写着已被推翻的 `mei1_inconclusive_forward_model`。这不是文档洁癖问题——过时状态会导致按错误前提做决策。

## 5. 还开着的问题

**5.1 MEI-4 C3 的恢复决策 —— 已于 2026-08-20 关闭**

当时两个判断同时成立：计算成本已不是障碍（3.7 h @12 worker），但按现契约跑完也不能改变 verdict（M2b 结构上不可达）。

决策结果是选[执行计划](active/tv3_mrs_ei_mei4_execution_plan.md) §10 的 **P-C 路径**（以 C2 证据直接收尾），并按该路径要求做了显式契约修订冻结。经过与产物见 §2.13。C3 / C4 / C5 的恢复执行已进入禁令清单，重开需要新立项文档、对 C0 三处矛盾的显式处置和新的授权记录。

**5.2 CC-SBI（C4）是否值得**

技术上可行且极便宜——训练抽样每条 = 1 次前向 = 73.6 μs，20 万条约 15 s 单核，比 M2b 便宜三个数量级。它对每个样本都能输出区间，直接消除 30% 拒绝率；在登记生成模型上做摊销推断，SBC 校准近乎构造性成立。**大概率能过覆盖门。**

但有个必须先处理的公平性问题：CC-SBI 天然使用真实 LHS 先验，M1/M1b/M2 用的是平坦单纯形先验。不在同一规格下比较，CC-SBI 的胜出会来自先验规格而非方法本身。

对应的报告要求应该预先写死：**主指标用"先验宽度→后验宽度的收缩比"，不用绝对区间宽度**。否则会出现符合项目自身标准的假阳性——覆盖门通过、区间"很窄"，但测量信息贡献接近零。

`mei4_cc_sbi_training_draws` 授权未开。

**5.3 从未执行的并行线**

静止空气 `flow=0` 计划（S0–S4）自 07-24 立项至今没有产物，`outputs/tv3_static_air_simulation/` 不存在。

**5.4 从未验证的部署条件**

以下全部没有证据，不能出现在任何能力声明里：真实硬件 OOD、湿空气、设备 profile holdout、时间漂移、校准批次、Sim2Real 波形统计距离。当前所谓 extrapolation 只是随机剩余样本。

**5.5 工程遗留**

## 附：这份日志的维护方式

- **什么时候更新**：某个实验产生正式 verdict 时，追加一条时间轴条目（四要素：问题 / 动作 / 结果 / 教训）。

- **和事实源的分工**：[代码契约事实源](掘进通风代码契约事实源.md)回答"能不能这么写"，本日志回答"怎么走到这一步的、学到了什么"。同一个数不要在两边都维护——日志里的数是为了支撑判断，契约与常量以事实源为准。
