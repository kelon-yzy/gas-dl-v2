# 5. 实验协议

## 5.1 四种划分器及其各自能够证明的内容

分布外行为不是单一性质，因此本协议登记四种分区方案，并在全过程中保持其结果分离。

| 划分器 | 构造 | 可支持的结论 |
| --- | --- | --- |
| R | 随机 | 域内稳定性的参考 |
| L | 拉丁超立方边界 | 域内参考；与同随机种子的 S-L 共享留出集，因此**不是独立证据** |
| S-Y | 带目标边界选择器的基于 SPXY 距离的训练选择 | 组分边界分布外 |
| S-L | 带边界选择器的基于 SPXY 距离的训练选择 | 组分边界分布外 |

该距离构造属于基于 `X`-`Y` 距离的样本集划分家族，缩写为 **SPXY**，即样本的联合特征和目标距离；登记的特征与目标权重为 0.5（权重为 1.0 时，该准则退化为 Kennard–Stone）。两个变体仅在产生留出集的选择器上不同。它带有五项不依赖假设而由实现强制的不变量：训练样本只从域内池抽取；留出集由独立选择器产生；验证集和测试集从余下域内样本以目标分层方式抽取；任何距离计算之前特征和目标均标准化；一旦选择退化即**显式失败**，而非回退为随机划分。

留出集画像只使用测量级输出和慢速通道，排除真值物理量；一个曾包含这些真值量的早期画像仅作为敏感性分析保留。

凡出现这些划分器的结果，都必须说明以下三点；第 6.4 节给出支撑数值：

- S-Y 的三个划分随机种子收敛为**单个**留出集，因此重复运行度量的是划分内和训练随机种子方差，而非三次独立验证；
- 同一冻结头在 S-Y 与 S-L 上的留出 `R²` 相差 0.27，二者不得合并；
- 正式数据集的 `extrapolation` 分区只是洗牌的随机余量，**不是**物理上不同的工况。

## 5.2 随机种子矩阵

冻结头在完整的四个划分器 × 三个划分随机种子 × 三个训练随机种子矩阵上评估，共 36 次运行。报告量为均值、标准差和最差随机种子，而非最佳一次运行。

本文的标准差是在一个单元九次运行上计算的总体标准差。需要明确该约定，是因为在该单元大小下，它与样本标准差约定相差 `sqrt(8/9)`，足以影响与外部引用数值的比较。

## 5.3 预注册门槛与版本化冻结

每个阶段在运行**之前**登记其合同：门槛阈值、拒绝语义、采样量、触发阈值，以及与每种可能结果关联的解释约束。

产物写入仅追加的版本化目录：

```
outputs/runs/<line>/<stage>/freezes/<UTC timestamp>_<short hash>/
```

每个目录携带 SHA-256 证据清单与源快照，任何图表都无需参照工作树即可重新推导。可恢复计算分片写入物理隔离目录，仅用于恢复，绝不会提升阶段状态。**只有所有子任务成功后，才写入汇总报告和冻结本身**，因此中断运行不留下产物，内存中的结果也不是证据；当某一阶段中途终止时，这一规则成为承重规则。

这一纪律的两个后果值得明确，因为它们限制了论文可以提出的主张。第一，看到结果后绝不调整门槛；当业务精度要求后来被降级为参考标记时，记录为独立决策，历史裁决保持不改写。第二，冻结无法检测内部不一致的合同，因此第 4.8 节的冻结后一致性审查是在事后加入，而不是最初设计的一部分。

## 5.4 两条带

数值比较以两条登记带为门槛，两者区别并非修辞。二者均与其所约束的跨度处于同一无量纲相对尺度：

| 带 | 数值 | 含义 |
| --- | ---: | --- |
| 数值保护带 `δ_num` | 2.82e−05（低成本配置）/ 9.06e−05（压力配置，也是门槛使用的共享上界） | 低于该值的差异无法与数值运算区分；由前向模型计算，而非人为选择 |
| 实践等价带 `δ_prac` | 0.02 | 大于 `δ_num` 但低于该值的差异是真实的，却不值得采用；这是预先登记的业务决策 |

结果必须超过 `δ_num` 才可报告，超过 `δ_prac` 才可采用。本研究中，同一类量在不同位置触发了两条带，因此二者均被报告而非合并为单一容差（`table9_bands_and_frame_fidelity.csv`）。

秩判定还带有额外要求：离散秩只有在三个容差数量级内稳定时才被接受，因为否则奇异值阈值会实质改变计数。

## 5.5 报告要求

六项要求约束数值可以如何呈现。它们在本文中被执行，也是作者认为最可直接复用的协议部分。

**R1：不得使用全量程指标报告窄窗口能力。** 在 0.8 vol % 分箱内，即使使用真值特征，`R²` 也为负。全量程粗区分和窗口内精细回归是不同问题；分箱 `R²` 是诊断量，而非标题指标。

**R2：真值特征结果必须明确标注其上界性质。** 真值上界配置（`oracle`）的 `R²` 比测量级基线高 0.18。任何基于模拟器内部量得到的结果，在解释为可部署能力前都必须考虑这一差距；探针结果必须明确标注为探针，而不能作为部署性能。

**R3：分布外机制必须分别列出，绝不合并。**

**R4：必须完整报告拒绝率，并按方法和域分解拒绝原因。** 不允许呈现丢弃大量样本后算出的改进指标；也不允许将不同拒绝原因合并为一个机制陈述。

**R5：同时给出两种覆盖率统计及各自样本量。** 选择条件值和无条件值的差异可超过 0.3，接受决策使用无条件值。

**R6：区间接受还须将宽度与工作量程比较。** 对每个划分器，名义 90 % 覆盖率接受区间为 88–92 %，名义 95 % 为 93–97 %，关键环境组不得低于名义值减 5 %。**当覆盖率正确但区间宽于所需分辨的量程时，结论固定为观测信息不足**；三种缩窄修复方式，即收窄先验、温度缩放和保形重校准，被禁止且会由代码拒绝。

回归结果的最低报告集合包括：逐组分 `R²`、平均绝对误差、均方根误差、偏差和绝对误差第 90 百分位；预先固定分箱及样本数上的业务窗口量；登记分组变量下的最差组结果；链路健康诊断；带多随机种子统计的训练、验证、测试、留出差距；以及作为监测量的闭合误差。
