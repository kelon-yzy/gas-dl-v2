# 9. 局限性

## 9.1 证据基础完全来自合成数据

本文所有数值均来自前向模型。声速采用理想气体混合模型，热导率采用 Wassiljewa–Mason–Saxena 混合规则，振动弛豫采用洛伦兹形式，光学响应采用经验模型，相关常数取自标准参考资料。**所有结果均未经过物理仪器验证。**

因此，本文结论均以前向算子能够正确描述目标灵敏度为前提。审计所得界限表示，在该前提下任何估计器均无法越过的信息上限。若前向模型在目标灵敏度方向上存在偏差，该界限也会随之失真。本研究尚未检验这一风险，后续需要使用更高保真数据或物理测量进行验证。

## 9.2 从未测试的条件

以下内容均未被评估，因此不得出现在由本研究导出的任何能力陈述中：真实硬件下的分布外行为、潮湿空气、设备配置文件留出、时间漂移、标定批次变化，以及波形统计的仿真到现实距离。正式数据集名为 `extrapolation` 的分区只是洗牌的随机余量，并不是物理上不同的工况；之所以报告它，只是因为协议登记了它。

## 9.3 报告数值不得有的三种解读

**分布外结果不得合并。** 同一冻结头在一种边界选择器下达到 0.7002，在另一种下为 0.4340。此外，目标边界选择器的三个划分随机种子收敛为单一留出集，因此其重复运行度量的是划分内和训练随机种子方差，而非三次独立验证。

**真值特征结果不能代表部署能力。** 真值上界配置（`oracle`）的 `R²` 比测量级基线高 0.18。强表格先验在测试集达到 0.6594，在训练集达到 0.9811，因此本文仅将其作为上界探针报告。

**粗能力与细能力是不同主张。** 冻结头在全工作量程达到 0.70。在 0.8 vol % 窗口内，即使使用真值特征，`R²` 也为负。两个数都不能代替另一个。

## 9.4 方案没有达到自身要求，而且本可闭合该问题的评估集并不完整

实测窄窗口精度为 1.0–2.4 vol %，而预注册要求为 0.4 vol %。该要求后来通过独立业务决策被降级为参考标记；降级不改变任何物理发现，也没有重写任何历史裁决。

不确定性阶段登记了六部分评估集：基于模拟校准的秩直方图、经验覆盖率、负对数似然、连续排序概率分数、后验预测检查和分布外覆盖率。**其中四部分存在；校准秩直方图和后验预测检查不存在。** 完整 Monte-Carlo 阶段曾开始但被终止；由于只有全部子任务成功后才写入汇总报告，因此没有留下产物，所见进度不是证据。参数 bootstrap 后验和摊销推断方法从未运行。

因此，该路线以部分证据结束，并通过明确的版本化合同修订记录了豁免、原因和后果。所得裁决的登记语义为*未通过*，不得被引用为任何形式的通过。

## 9.5 预注册本身的缺陷

冻结合同在事后发现三项缺陷。它们是合同设计问题，而非实验结果，故单独列出。

1. **后备后验方法从未录入校准方法列表**，因此忠实实现将其完整校准门槛硬编码为 false，目标裁决在查看任何数据前便结构上不可达。
2. **原本用于跳过昂贵计算的触发器，条件却从该计算的测得成本中读取**，因此计算运行前它无法触发。先验估计显示需求约为登记预算的 100×，这意味着触发器本应一开始就触发。
3. **确定性方法在受约束单纯形上使用平坦先验，而登记观测由受约束拉丁超立方设计生成。** 因此绝对区间宽度在不同规格间不可比，物理域外过量后验质量是该不匹配的直接结果，而非测量本身的属性。

第 3 项也约束未来工作：任何与使用生成先验的方法的比较，都必须以从先验到后验的收缩比为主指标，而不是绝对区间宽度，否则会接受一种满足所有形式准则、但测量几乎不贡献信息的结果。

## 9.6 手稿准备阶段进行的更正

从冻结产物重新生成每个引用数值后，发现内部记录中有五个句子错误描述了其数值。五个数本身均正确且已冻结；没有任何更正改变结论，其中两项强化了底层发现。

| 陈述 | 缺陷 | 更正后 |
| --- | --- | --- |
| 区间下界“达到 14.931 %” | 取自四个名义水平中最不极端的一项，却被表述为总体最小值 | 12.062 % |
| 两项消融被表述为独立 | 不同构建器名称下的特征定义相同 | 一项消融，主张收窄 |
| 五个端到端结果列在一起 | 两个来自验证集，三个来自测试集 | 报告全部三个分区 |
| 设计跨度“0.71 %，低于数值带” | 数值和带均错误；冻结决策理由指向实践带 | 0.4565 % / 0.6725 %，高于数值带，低于实践带 |
| 判据实现“29 行” | 不符合该文件任何行数口径 | 34 行 |

报告这些更正，是因为它们代表严格冻结纪律仍无法消除的失败模式：错误存在于文字而非产物中。采用的对策，即从冻结输出以程序方式生成每个引用值并记录源路径与摘要，只在手稿阶段引入；它本可更早发现全部五项。

## 9.7 审计框架的范围

审计链决定在登记的观测模型和噪声预算下目标精度是否可达、不可达时哪项规格形成约束、候选估计器改进是否超过实践等价带，以及所报告区间能否据此行动。

它不决定模型失配下的行为（第 9.1 节），也不决定审计失败的方案是否可能在另一种目标定义下成功：覆盖全范围的粗分类和窗口内精细回归是不同问题，审计只回答被提出的那个问题。

第 7.4 节的迁移分析基于导入层级依赖和两项物理准则，尚未通过将框架实际迁移到其他方案而验证。“该做法在多组分气体传感文献中缺失”的主张基于数据库检索，应表述为*未找到*，而不是*不存在*。

## 9.8 工程说明

正文引用的计算成本数值，即单次前向评估 73.6 μs、单初始化求解 204.6 ms，是单台机器上的非正式测量，不属于任何冻结产物。

作者机器上的项目测试套件报告 520 个通过、51 个失败和 24 个报错。每个失败均为开发平台特有的临时目录权限错误，而不是代码回归；不确定性阶段测试可独立通过。依赖数据集生成或波形缓存的测试，在该环境问题解决前不得声称通过。
