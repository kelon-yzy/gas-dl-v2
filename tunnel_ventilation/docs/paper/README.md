## 这批文档是什么，不是什么

**是**：把 tv3 三年积累的方法链——前向物理、测量级信号处理、三段审计、实验协议、结果、讨论——按论文的组织方式完整梳理一遍，让每个结论和支撑它的数都能被追溯。梳理过程本身产出了五处记录更正和一次领地判定，这是主要收益。

**不是**：最终投稿论文。以下都没做，也暂不做——期刊 LaTeX 模板与格式、英文润色、图的绘制、字数裁剪、cover letter。若将来决定投稿，这里是素材，不是稿件。

**为什么按论文结构写**：论文结构强制回答"这个结论的证据是什么、适用范围多大、不能声称什么"，比按代码模块组织更容易暴露漏洞。事实证明有效——五处描述漂移和 Rodgers 领地问题都是在这个过程里发现的。

理由见下方"描述漂移"一节：五处错误全部是手工转述造成的，数字本身都在冻结产物里没问题。

## 文献检索的结论（2026-08-20，影响 §1 框架）

完整记录在 [`00_related_work.md`](00_related_work.md)。三条必须知道的：

**1. “先算信息量再建模型”不是新顺序。** Rodgers 2000《大气探测反演方法：理论与实践》第 2 章“信息量分析”（正式英文题名保留于参考文献，DOI `10.1142/3171`，2273 次引用）系统阐述了这套做法，大气遥感界已使用三十年。第 1 节原定的核心贡献声明不能使用。

**2. 本方案的传感概念本身也不新。** Phillips、Dain 和 Lueptow 于 2003 年发表的《基于声学性质的气体组分传感器理论》（正式英文题名保留于参考文献，DOI `10.1088/0957-0233/14/1/311`，50 次引用）**就刊载于目标期刊 MST**，使用声速和声衰减反演三组分混合气的组成。必须正面引用，不能回避。

**3. 目标期刊定位反而更稳。** 三条最相关文献（Phillips 2003、Zhu 2018、Zhang 2020）全部在 Measurement Science and Technology。

### §1 框架的调整

- **不能写**："本文提出在算法开发之前先做信息量审计的方法。"
- **改写为**："信息量审计在大气遥感反演中是成熟做法，但在多组分气体传感文献里尚未常规化。本文把它迁移过来，并针对该场景的秩亏结构给出 CRB 与 DFS 都失效时仍可计算的目标单位判据；负结果链条量化了这个做法缺席的代价。"

叙事从"我们提出一个新顺序"改成"**一个成熟领域的标准做法，在相邻领域缺席，代价是什么**"。已同步调整 §4.1、§4.3.3 与 §7.6。

### §2.2 的核心对比（写 §2 时新算出来的，此前文档没有）

| 量 | 值 |
| --- | ---: |
| 整个 O₂ 工作量程（18.00→21.20 vol%）引起的声速变化 | **0.79 m/s**（0.23%） |
| 1 K 温度误差引起的声速变化 | **0.58 m/s** |
| 后者占前者 | **0.73** |

**一个 1 K 的温度误差，就相当于目标扫过整个工作量程所产生信号的 73%。** 这是全文对"为什么这个方案难"最直接的定量陈述，比"纯组分声速差 23.31 m/s"有用得多——后者看起来问题很容易。

顺带澄清：文档旧写法"声速差约 6.4%"没写分母。实测 N₂−O₂ = 23.31 m/s，占 c_N₂ 6.60%、占 c_O₂ 7.07%。§2.2 两个都给并标明分母。

## 写作过程中发现的描述漂移（累计 5 处）

前两处在收尾冻结里已更正，第 3、4、5 处在 2026-08-20 写 §6 / §7 / §9 时发现。五处的共同点：**数字本身都在冻结产物里，错的是描述这个数字的那句话**。

| # | 旧描述 | 缺陷 | 对结论的影响 |
| --- | --- | --- | --- |
| 1 | 区间下界"最小到 14.931%" | 取自 50% 名义水平，四档中最不极端的一档，被当成总体最小值 | 无。真实最小值 12.062%，更极端 |
| 2 | D0 的 `no-tof` 与 `slow-only` 并列成两行证据 | 两个配置文件的特征定义完全等价，只是构建器名不同 | 数值无影响；支撑表述需收窄 |
| 3 | 五个端到端结果列在一起 | 两个取自验证集、三个取自测试集 | 无。三个数据分区上全部为负，结论更强 |
| 4 | “设计跨度 0.71% 低于数值保护带” | 值与带都错：主档位是 0.4565%，且它**高于**数值带、**低于**实践带；冻结的 `decision_reason`（决策原因）写的是实践带 | 无。判定不变，但记录指错了机制 |
| 5 | `error_budget.py`"29 行" | 实际 34 行总计 / 27 行非空，与任何口径都不符 | 无。实质性的那半（无领域依赖）核实成立：只 import `__future__` / `math` / `collections.abc` |

第 4 处最值得注意——审稿人核对时会在同一个冻结文件里看到 `ranking_resolvable_numerical = true`，与那句话直接矛盾。已同步更正 `docs/掘进通风实验日志.md` §2.11 与 §3-R5、`docs/methods/tv3_算法方法论文说明.md` §6.3 / §8.1 / §8.4.3，以及手稿 §1.5、§4.5.3 与 §7.1。

这正是"引用数值必须由脚本从冻结产物生成"这条规则的理由：描述漂移能穿过严格的冻结纪律，因为它住在散文里而不在产物里。

**2026-08-21 复核补记：更正本身也会漏传。** 第 5 处（29 → 34 行）当时只改到 §1.5 与 §9.6，`07_discussion.md` §7.4、`00_related_work.md` §3(a) 与本文件都还留着旧值——其中 §7.4 与同一文件里 §7.3 的更正表直接矛盾。同批还发现 §1.5 与 §00 把漂移计数写成"四处"，而 §7.3 / §8 / §9.6 写的是"五处"。已全部统一。这说明纠错动作也需要一次全文检索，改一处不等于改完。

## 术语约定（全文统一）

| 概念 | 对应英文术语 | 避免使用 |
| --- | --- | --- |
| 目标参数 | target parameters `θ` | analyte, measurand（歧义） |
| 干扰参数 | nuisance parameters `η` | interference, confounder |
| 等效目标误差 P90 | equivalent target error at the 90th percentile | propagated error（不够具体） |
| 拒绝 | rejection（输出被拒绝，样本仍计入分母） | failure, exclusion |
| 选择条件覆盖率 | selection-conditional coverage | conditional coverage（与条件覆盖率混淆） |
| 无条件覆盖率 | unconditional coverage | marginal coverage |
| 冻结 | freeze / frozen artifact | checkpoint, snapshot |
| 实践等价带 | practical-equivalence band | tolerance（与数值容差混淆） |

`θ` 与 `η` 的分块记号全文一致；不要在不同章节用 `x` / `p` 混指组分。
