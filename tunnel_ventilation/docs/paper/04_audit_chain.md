# 4. 三阶段审计链

## 4.1 为什么问题的提问顺序重要

传感反演研究的常规顺序是：*选择估计器，训练或拟合它，报告误差指标，再用更好的估计器重复这一过程*。这一顺序存在结构性盲点：它无法区分“估计器较弱”的方案和“观测首先就不含足够目标信息”的方案。两者都会表现为大误差，也都会引出同一种回应，即构建更大的模型。

**替代顺序并非新创。** 在大气遥感中，这是 Rodgers 最优估计框架所规范的标准做法：在构建反演之前，先由前向模型和误差协方差计算信息量、信号自由度和平均核，据此决定给定仪器能够和不能够分辨什么 [Rodgers 2000, Ch. 2]。本节的贡献不在于该顺序，而在于标准框架无法为当前问题提供的两件事：一种在通常信息量度未定义的秩亏条件下仍可计算的判据（第 4.3.3 节），以及审计失败时的明确输出（第 4.4 节）。

促使采用该顺序的成本不对称性十分显著。纯前向的信息量审计只需在工作点网格上评估已知前向算子的灵敏度；它不需要合成数据集、训练，单核数分钟即可完成。一次基于波形数据集的端到端训练则需要数小时 GPU 时间；若前端最终被证明规格错误，所得数值根本无法回答任何问题。

因此，我们反转顺序。审计链依次提出三个问题，每个问题有一个预注册门槛；只有前一问题通过，才允许进入下一问题：

| 阶段 | 问题 | 决定事项 |
| --- | --- | --- |
| I | 在纳入干扰参数后，观测中是否包含足够关于 `θ` 的信息？ | *任何*估计器能否达到目标 |
| II | 在已有信息下，估计器距离该界限有多近？ | 是否值得构建更好的估计器 |
| III | 报告的不确定性是否可信？ | 输出能否据此行动 |

阶段 I 的失败不是关于算法的负结果，而是关于传感方案的正结果；它会将投入重定向至第 4.4 节的硬件需求反演，而不是更深的网络。

## 4.2 问题形式与四个杠杆

将第 `s` 个观测视图写为：

```
y_s = F(θ, η_s; d_s, ψ) + δ(z_s, d_s) + ε_s,     ε_s ~ (0, Σ_s).
```

其中，`θ` 是目标参数，`η_s` 是该视图的干扰参数（温度、声程、增益、触发延迟等），`d_s` 是可控设计变量（频率、压力、湿度、驻留时间），`ψ` 是视图间共享参数，`δ` 是模拟器未表达的模型失配，`Σ_s` 是观测协方差；它可以同时包含逐通道和跨通道共模结构。

在一个工作点处对 `F` 线性化，并将 Jacobian 分为目标块和干扰块后，可由 Schur 补得到 `θ` 的有效 Fisher 信息：

```
I_eff(θ) = I_θθ − I_θη (I_ηη + Λ_η)^(−1) I_ηθ,      I_ab = J_a^T Σ^(−1) J_b,
```

其中 `Λ_η` 编码真实可得的干扰参数先验信息，即标定而非假设。Fewster 和 Jupp 表明，当新增观测时，感兴趣参数的有效信息仍保持单调性：新来源只有在提供现有来源尚未提供的条件信息时，才会缩短置信区间 [Fewster & Jupp 2013]。重复相同测量并不会改善可辨识性。

这恰好给出四个彼此不可替代的杠杆：

1. **改变设计 `d` 或前向物理 `F`。** 这会改变 `J` 中的灵敏度方向，是从测量端提高信息上限的唯一杠杆。
2. **改变采样协议或噪声协方差 `Σ`。** 同步激励、参考通道和共模识别可以降低有效噪声，或利用逐通道独立假设会丢弃的结构。
3. **增强 `Λ_η`。** 这必须来自真实标定或可辩护的物理知识。一个网络若从训练数据中隐式假设更紧的干扰先验，并不是在使用该杠杆，而是在泄漏。
4. **改变估计器。** 在固定观测模型下，它至多逼近 `I_eff^(−1)`，无法越过它。

大多数模型比较研究只操作第 4 个杠杆；阶段 I 的任务正是确定真正约束问题的是否是其他三个杠杆。

## 4.3 阶段 I：信息充足性

### 4.3.1 带步长稳定性检查的灵敏度

灵敏度通过有界中心差分计算。因为在下游秩计算中，伪灵敏度与真实灵敏度不可区分，所以每个导数还需在 `h/2` 和 `2h` 下再计算两次；相对差异高于登记阈值时，该点被标记为不稳定，并与结果一起报告不稳定点数。没有这一检查，数值噪声将进入 Jacobian 并虚增表观秩。

### 4.3.2 将秩作为第一道门槛

对单个标量观测，Fisher 矩阵是外积，故无论名义未知参数有多少，其秩恒为一。这是结构性而非数值性缺陷：当秩 `< dim(η)+1` 时，干扰块无法边缘化，无法获得仅针对 `θ` 的条件界。检测它只需一次 Jacobian 评估。

秩由奇异值谱以**相对**阈值确定，即奇异值按最大奇异值缩放。离散秩对该阈值敏感，因此，只有当秩在三个容差数量级内**保持一致**时，秩的主张才被接受。在案例研究中，将容差分别扰动为 ×0.1 和 ×10 后，多频审计网格的 216 个工作点中离散秩分别在 81 个和 97 个点发生变化；单个容差下报告的秩不可复现。

> **网格大小。** 本文出现三个不可互换的网格：第一次单向审计用 189 点，双向审计用 567 点，多频审计则每个观测臂用 216 点。第 4.6 节的后验阶段不是网格，而是每个域 648 个登记样本。

### 4.3.3 等效目标误差：在秩亏下仍可使用的判据

Cramér–Rao 下界恰好在最有用的秩亏条件下不可用。最优估计框架中的信息量度也是如此：信号自由度和平均核都通过一个在纳入先验后必须可逆的系统定义；当干扰块根本无法边缘化时，它们无法返回目标单位下的数值。因此，我们定义一个在该条件下仍可计算的判据。对于标量观测摘要 `τ`，将每个干扰不确定性传播到目标单位：

```
σ_θ^(j) = | (∂τ/∂η_j) / (∂τ/∂θ) | · σ_{η_j},
P90     = z · sqrt( Σ_j (σ_θ^(j))^2 ),        z = Φ^(−1)(0.95) = 1.6449.
```

两项性质使其成为全研究跨方法的统一计量单位。第一，它用目标的物理单位表达，因此无需参照任何回归模型、数据集划分或训练随机种子，就可以直接与业务精度要求比较。第二，`z` 是零均值高斯误差下**绝对误差第 90 百分位**，即 `Φ^(−1)(0.95)`，而不是 `Φ^(−1)(0.90)`；若报告单侧分位数，会低估要求 22 %。

若目标灵敏度 `∂τ/∂θ` 为零或非有限值，实现会拒绝继续，而不会返回一个大数：目标灵敏度消失与传播误差很大是不同情形，不能被悄然合并。

> **实例化。** 在本案例中，`τ` 是单向飞行时间，`θ` 是 O₂ 摩尔分数，`η` 包含温度、声程和触发延迟。在 1 K 温度误差和 3 μs 触发抖动下，窄窗口 `P90` 为 8.85–12.99 vol %，而目标为 0.4 vol %。

### 4.3.4 预注册的三重门槛

只有以下三项同时满足，阶段 I 才通过；阈值均在审计运行前固定：

- **精度**：`P90 ≤ ε`，即目标要求；
- **归因**：任一单独干扰参数不得占总量超过比例 `f`，避免一次通过完全由一个主导项造成，而随后一次标定变化就会使它失效；
- **可接受性**：被阻塞规则拒绝的工作点比例不超过 `r`。

第三道门槛包含一项很容易遗漏的规则：若一个已知会影响观测的物理机制**完全未在前向模型中表示**，则每个工作点都应被拒绝。未表示的机制不是小模型误差；它使审计无从判断，而不是令人放心。在案例研究中，由于第一次前向模型中没有整体流动，189 个点全部被拒绝；正是这一拒绝，而非精度数值，证明了构建双向测量的合理性。

### 4.3.5 阶段 I 的对照

在任何正向主张之前运行两个对照：

- **负对照臂**：复现已知退化配置（例如单频观测），并且必须返回退化秩；
- 对前向算子进行**零方向检查**。若目标参数化包含精确零方向，审计会报告任何估计器都无法利用的信息。在本案例中，将三个摩尔分数按同一比例缩放后，前向输出的色散声速变化为 `0.0`、吸收变化为 `2.2e−16`；总丰度不是可估计自由度，问题必须在 `(n−1)` 维切空间中表述。

## 4.4 阶段 I′：硬件需求反演

阶段 I 失败时，有效问题不是“下一步换哪个估计器”，而是“任何估计器要成功需要什么条件”。因此我们反演审计：固定目标 `ε`，扫描噪声水平和干扰先验精度空间，记录门槛通过的位置。

这项扫描返回阶段 I 失败本身无法给出的三类内容：

1. **约束项排序**：单独收紧哪一项规格最能降低 `P90`；
2. **饱和下限**：无论其他规格收紧到何种程度仍存在的精度下限，据此识别无法通过采购消除的约束；
3. **极端规格栈的可行性**：目标在物理可实现的硬件条件内是否可达，以及需要何种规格。

这将死路转化为采购规格，也使失败可证伪：后续测量活动要么满足所述规格，要么不满足。

> **实例化。** 常规硬件中的任何组合都无法通过，精度在 1.0–1.3 vol % 饱和。第一约束是 0.1 mm 的声程先验，第二是 2 % 的衰减标定。极端规格栈（抖动 ≤ 10 ns、温度 ≤ 0.1 K、声程 ≤ 10 μm、衰减 ≤ 0.1 %、双重湿度和压力调制）达到 `max P90 = 0.287`。另外，频率点数*不是*瓶颈：四点和八点相差不足 1 %。

## 4.5 阶段 II：估计效率

只有阶段 I 通过，或阶段 II 被明确作为附带阶段 I 裁决的求解器验证练习运行时，才允许进入阶段 II。它询问给定估计器实际提取了多少可用信息。

### 4.5.1 可分离结构与可变投影

许多物理反演是可分离的：当其余参数固定时，部分参数以线性或仿射方式进入观测。将非线性块记为 `β`，条件线性块记为 `a`：

```
min_{β,a} || W^(1/2) [ y − A(β) a − b(β) ] ||^2 + R_β(β) + R_a(a),
```

可变投影对每个 `β` 闭式消去 `a`，并优化约化目标 `φ(β) = L(β, a*(β))`。Golub 和 Pereyra 证明，该过程既减少搜索维数，也通常改善条件性 [Golub & Pereyra 2003]。

两项实现规则比代数本身更重要：

- **线性块成员资格是物理主张，而非便利选择。** 一个参数若以非线性方式进入多个观测通道，即便线性近似能拟合，也必须留在 `β` 中。本案例的声程进入飞行时间、幅值和相位，正因如此保留在非线性块中。
- **每个条件线性参数都需要自己的先验，并且必须登记其作用范围。** 被声明为“设备配置文件 × 频率、跨样本共享”的逐频标定偏移是标定；若允许其逐样本漂移，则是会吸收目标变化的额外自由度。

### 4.5.2 求解器比较可以主张什么

固定迭代预算下的求解器比较衡量的是优化进度，而非统计效率。通过为比较附加明确的解释约束，并与误差同时报告达到的目标值和迭代数，这两者被分开。否则，一个仅在预算内收敛更快的求解器很容易被写成效率更高的估计器。

### 4.5.3 两条带及两者都需要的原因

- **数值保护带 `δ_num`。** 小于该带的差异无法与数值运算本身区分。它由前向模型计算，而非人为选择。
- **实践等价带 `δ_prac`。** 大于 `δ_num` 但小于 `δ_prac` 的差异是真实的，却不值得采用。它是比较前登记的业务决策。

一个结果必须超过 `δ_num` 才可报告，超过 `δ_prac` 才可采用；二者经常给出不同判断。下列四个数均为相对跨度，因此按同一尺度报告。在案例中，两个登记噪声配置下候选设计排序的跨度为 0.004565 和 0.006725（0.4565 % 和 0.6725 %），共享的 `δ_num = 9.06e−05`、`δ_prac = 0.02`。这些跨度是数值带的 50 倍和 74 倍，说明排序在算术上真实而非噪声；但它们又比实践带低 3.0 到 4.4 倍，所以该排序对选择设计没有价值。冻结决策理由显式写出实践带，且可区分的排序层级数为一。若仅报告排序“不可分辨”，将无法知道是哪一种机制触发了结论。

### 4.5.4 阶段 II 的门槛

采用条件是**改进幅度的 bootstrap 置信区间下界**超过 `δ_prac`，而不是点估计超过该带。在案例中，点估计为 0.0278 和 0.0245，而 `δ_prac = 0.02`；置信下界为 0.0116 和 0.0074，因此保留简单基线。若根据点估计设置门槛，便会在证据不足的情况下采用更复杂的求解器。

## 4.6 阶段 III：不确定性可信度

### 4.6.1 曲率与精确干扰边缘化

在估计值处构造白化曲率 `H = J^T J`，并通过 Schur 补精确边缘化干扰块：

```
Σ_θ = ( H_θθ − H_θη H_ηη^(−1) H_θη^T )^(−1).
```

实现用两种方式计算它：Schur 补和联合逆矩阵的相应分块；二者在条件数自适应容差下比较，若不一致即失败。正定性和条件数也分别设为门槛。

### 4.6.2 构造性的正确性检查

在解释任何区间之前，先用一个它必须复现的量验证构造：Laplace 标准差与逐样本 Cramér–Rao 下界之比应为一。在案例中，中位数比值为 1.00035。这一点对*失败解释*很重要：曲率一旦验证，后续覆盖率问题就不能归因于算术错误，而必须由后验几何或先验规格解释。

### 4.6.3 物理域截断与拒绝语义

受约束参数的后验必须截断到可行集。我们抽取扰乱的低差异序列，通过后验协方差映射，并保留可行抽样；使用分辨率加倍的重算保护分位数。当接受比例低于登记下限时，构造会**清晰失败**，而不是返回退化区间。

这种失败具有诊断意义，并非仅为防御。低于下限的接受率意味着“超过 `1 − floor` 的后验质量位于物理域之外”，它将问题定位到先验规格，或定位到自身就在可行域之外的估计值。在案例中，下限为 3.125 %，即当超过 96.9 % 的质量不可行时，构造会报告该问题。

每个覆盖率统计的分母都包含被拒绝样本，并对它们作标记。拒绝绝不能成为获得更好看数值的途径。

### 4.6.4 重要性采样可靠性

当校正步骤需要对提议分布重加权时，通过向最大权重拟合广义 Pareto 分布并报告形状参数 `k̂`，诊断权重的尾部行为。超过登记阈值时，样本的校正被标记为不可靠，并记录为**独立拒绝原因**。若把它与数值拒绝混合，就会错误归因机制：案例中，一种方法的拒绝 100 % 为截断失败，另一种方法则混有继承的提议失败和 5.40 % 真实 `k̂` 超阈值。

### 4.6.5 校准审计

覆盖率本身不是校准。登记的审计集合包括：

- **基于模拟的校准**：从联合模型重复抽样得到秩直方图，并检验其均匀性；
- **后验预测检查**：将复制数据统计量与观测统计量比较，并设置系统偏离的尾部阈值；
- 在多个名义水平、多个域和多个组分上检查**覆盖率带**，并对完整带集合进行多重性校正。

进入裁决状态机的每种方法都必须在*所有*这些项目中登记。第 4.8 节说明为何这一看似吹毛求疵的要求在本研究中恰恰失效。

### 4.6.6 同时报告两种覆盖率统计

存在拒绝时，有两个覆盖率数值，二者可能相差极大：

```
选择条件覆盖率 = covered / (n − rejected)
无条件覆盖率     = covered / n
```

两者都必须连同样本量报告，且接受决策必须使用无条件数值。案例中，95 % 名义水平的选择条件覆盖率为 0.9977，基于 443 个保留样本；而全部 648 个样本上的无条件值为 0.6821。若只报告前者，就会用表面极佳的数值掩盖 31.6 % 的拒绝率。

### 4.6.7 宽度检查及被禁止的修复方式

覆盖率正确是必要条件，但并不充分。最终检查将区间宽度与目标的工作量程比较。**当覆盖率正确，但区间宽于该量要被分辨的范围时，结论固定为“观测信息不足”。**

此时有三种可用修复方式，且三者均被预注册为禁止：收窄先验、温度缩放和保形重校准。每一种都会产生更窄且仍通过覆盖率检查的区间，但都是用假设替代测量。禁止通过代码执行，即后验构造器会拒绝这些设置，而不是留给审稿纪律。

> **实例化。** 单样本 95 % 区间的中位宽度为 5.72 pp，而工作量程为 3.20 pp，比例为 1.79。在四个名义水平上，下界最低达 12.062 %，即比采样下限 18.00 % 低 5.94 pp。覆盖率即使有偏，也是偏保守的。

## 4.7 正结果之前先做负对照

每个阶段至少包含一个必须先触发的对照，随后其正结果才可被接受。模式统一：构造一个正确答案预先已知的配置，并要求机制得到该答案。

| 对照 | 形式 | 检测内容 |
| --- | --- | --- |
| 前向零方向 | 沿可疑不变性方向扰动目标 | 参数化中的不可估计方向 |
| 退化臂 | 复现秩已知的配置 | 数值噪声造成的虚增秩 |
| 正对照探针 | 在参考特征集上运行管线 | 探针自身缺陷而非候选方案缺陷 |
| 等容量置换 | 保持参数量，随机打乱结构分组 | 将容量造成的结果错误归因于结构 |
| 打乱配对 | 破坏方法利用的配对关系 | 泄漏和普通正则化效应 |

等容量置换值得强调，因为它颠倒了预期。在案例中，一个物理驱动的分组瓶颈弱于非结构化基线；对照保持参数量相同但随机置换分组，在四个划分器上，其分布外 `R²` 比物理分组高 0.09–0.17。因此，缺陷应归因于物理相关通道之间的过早隔离，而非容量。没有这一对照，该结果只会被解读为“物理先验在这里无帮助”。

## 4.8 先冻结再运行，以及冻结无法提供的审查

每个阶段在运行前登记其合同：门槛、拒绝语义、样本量、触发阈值以及与每个可能结果相关的解释约束。产物写入带版本的仅追加目录，包含 SHA-256 证据清单和源代码快照，因此任何数值都无需参照工作树即可重新推导。所有子任务成功后才写入汇总报告；中断运行不会留下产物，内存中的结果不是证据。

这可以防止事后调整门槛。它**不能**防止内部不一致的合同，本研究本身即为一例。合同预注册了 24 条覆盖率带、拒绝语义、采样量和触发阈值，却从未将被设想为后备后验基线的方法录入校准方法列表。忠实实现该合同后，其完整校准门槛被硬编码为 false，目标裁决在查看任何数据之前就**在结构上不可达**。直到数周后尝试最后一阶段时，这一缺陷才暴露。

因此，我们增加一个冻结纪律本身不能提供的步骤：

> **冻结后的一致性审查。** 合同冻结后、阶段运行前，枚举状态机可以产生的每种裁决，并给出可到达它的路径。没有可到达路径的裁决属于合同缺陷，人工检查即可低成本发现，而无需等执行发现。

另外两类同族缺陷也值得指出，因为它们会反复出现：一种**实现依赖于它本来应跳过的计算本身的触发器**，本例读取了本应避免运行的计算所测得的成本，若使用先验估计则会在阶段开始前触发；另一种是**同一比较中不同组件的规格不匹配**，本例的确定性方法在受约束单纯形上使用平坦先验，而登记数据由受约束拉丁超立方设计生成，所以不同方法的绝对区间宽度不可比，物理域外过量后验质量也正是这一原因造成的。

一般规则是：冻结规定一个数在计算*之后*可以被允许成为什么。只有检查才能确保问题本身是否可回答。

## 4.9 审计链决定什么，不决定什么

**它决定。** 在已登记观测模型和噪声预算下目标精度是否可达；不可达时哪项规格形成约束；候选估计器的改进是否超过实践等价带；所报告的区间能否据此行动。

**它不决定。** 任何关于模型失配条件下性能的结论。阶段 I 中的每个界限都以前向算子正确为条件；若前向模型在目标灵敏度方向上是错误的，它会给出自信但错误的界限。阶段 I′ 通过报告具体约束规格而非单一数字来部分缓解这一问题，但链条不包含对系统性错误 `F` 的测试。建立这一点需要更高保真数据或物理测量，超出纯模拟研究范围。

**第二个不决定事项。** 方案即使未通过阶段 I，是否可能在不同目标定义下成功。覆盖完整范围的粗分类可能可行，而窄窗口内精细回归不可行；二者是不同问题，审计只回答被提出的那个问题。用全量程指标报告窄窗口能力会混淆两者，第 5 节的报告规则禁止这一做法。
