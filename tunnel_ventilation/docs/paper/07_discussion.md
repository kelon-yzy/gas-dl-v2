# 7. 讨论

## 7.1 在研究中反复出现的六项判断

以下每项均在不止一个实验中出现，涉及不同机制和不同阶段。它们按实际应用顺序陈述。

**1. 先计算信息预算，再选择估计器。** 多频路线在生成任何数据集之前，先运行纯前向 Fisher 审计作为生死门槛；门槛失败，整个下游生成、训练和评估链从未构建。两条端到端路线采用了相反顺序，即先训练、随后发现前端不可接受；它们各自耗费一次完整训练运行，才得到审计在数分钟内即可给出的结论。这种不对称并非边际差异：第 6.5.1 节在两个学习式前端失败后，用特征集上的 ridge 探针在数分钟内定位了决定性的缺失量。

**2. 正结果之前先运行负对照。** 本研究的四个对照分别提前排除了某类伪信号：前向零方向（第 4.3.5 节）在任何求解器编写前表明总丰度不是可估计自由度；单频观测臂复现退化秩，确认审计对其应检测的条件敏感；正对照探针返回严格为零的偏差，因而排除了探针自身责任；等容量置换（第 6.6 节）则颠覆了对结构性结果的直观解读。最后一项最强。若没有它，一个物理分组瓶颈比基线低 0.13–0.15，只能解读为*物理先验在这里没有帮助*。有了它，即参数量相同、分组随机置换、分布外 `R²` 高 0.093 至 0.171，结论就变得具体且可行动：代价来自物理相关通道间的过早隔离，而非容量问题。

**3. 严格收窄每项结论的适用范围。** 学习式前端失败是关于该实现的陈述，而不是关于波形域学习的陈述；分组失败是关于“每组在任何跨组交互之前都独立压缩为 16 维”的陈述，而不是关于物理先验整体的陈述，事实上第 6.3 节表明应用于特征构建的物理先验正是使线性基线达到测量级同等性的原因；多频失败是关于登记噪声预算的陈述，且明确标为硬件结论而非算法结论。收窄范围不是谦逊，而是避免负结果关闭仍然开放方向的必要条件。

**4. 前置条件通过不等于目标已满足。** 见第 7.2 节。

**5. 单位和量级问题会伪装成结构问题。** 本研究中有三个实例，最初都被理解为其他问题：一个辅助损失在以秒计的量和归一化索引之间计算，使该项相对于主目标约为 1e−9，最初被理解为训练失败；目标量级为 1、20 和 78，却没有逐目标标准化，导致同一网络在自身训练集上失败（第 6.3 节），最初被理解为容量或正则化问题；两个噪声配置下候选设计排序跨度为 0.004565 和 0.006725，最初被理解为设计发现，而实际上它是数值带的 50 至 74 倍、却比实践带低 3.0 至 4.4 倍，且只有一个可区分的排序层级（`table9_bands_and_frame_fidelity.csv`）。无论是多目标回归还是设计比较，都应先检查单位和量级，再检查结构。

**6. 失败必须分解到机制层面才算完整。** 后验评估最初只记录没有方法通过覆盖率门槛。两周后，在没有新计算的情况下重新读取相同冻结产物，得到如下链条：截断失败 → 超过 96.9 % 的切空间质量位于物理域外 → 平坦先验与生成数据的受约束设计不一致 → 除尾部泄漏之外，部分似然峰本身不可行。带有机制的失败说明下一步应改什么；没有机制的失败只能重新运行。

## 7.2 机制已建立，但量级不足

本研究最具可迁移性的单项观察是：一个机制可以严格按设计被证明有效，却仍无法把目标量移动到有意义的程度。它在五种不同机制上发生了五次，每次前置条件都以高精度验证：

| 已验证的前置条件 | 失败的目标判据 |
| --- | --- |
| 帧级模板锚定，峰值 MAE 为 0.0375 个采样点，而门槛为 0.15 | 序列级同等性失败，目标 `R²` 为 −0.0097 |
| 流动解耦，配对声速偏差下降 97.96 % | 分布外 MAE 改善 0.1165 vol %，而门槛为 0.50 |
| 多频可辨识性，秩 1 → 5 | 最佳观测臂中位 P90 为 2.40 vol %，而门槛为 0.4 |
| 可变投影在参数上精确至 1.04e−17 | 改进置信下界为 0.0116，而带为 0.02 |
| Laplace 曲率与 Cramér–Rao 比为 1.00035 | 95 % 区间中位宽度为 5.72 pp，而量程为 3.20 pp |

左列的精度使这一模式具有启发性。这些并不是机制只完成了一半的情形。投影精确到机器 epsilon；曲率精确到小数点后四位；流动解耦将偏差降低两个数量级。每种情形中，机制原本要控制的量都被控制了，而感兴趣的量几乎没有移动。

实际后果是对方案阶段的一项要求：**在构建机制之前，先估计即使它完美工作能够带来的改进量级，并将该估计与门槛比较。** 证明机制正确是必要条件，但本研究表明它经常不充分。以上五项中的四项本可由事前数量级估计预测为失败；流动解耦案例除外，因为在解耦前流动对误差预算的贡献确实未知，这本身也是先做低成本前向审计的理由。

## 7.3 冻结能防什么，不能防什么

本研究每个阶段均在运行前登记合同：门槛、拒绝语义、采样量、触发阈值及每个结果关联的解释约束。产物仅追加，并携带 SHA-256 清单和源快照。这套机制对其设计威胁按预期工作：看到结果后没有移动任何门槛，0.4 vol % 业务要求也通过独立决策被明确降级为参考标记，没有悄然放松，历史裁决亦未改写。

但它未能防止另外两种失败模式，二者都值得说明，因为都不局限于本研究。

**合同缺陷。** 后验合同预注册了 24 条覆盖率带及所有相关语义，但被设想为后备基线的方法从未被录入校准方法列表。忠实实现因而将其完整校准门槛硬编码为 false，目标裁决在检查任何数据之前就结构上不可达，直到尝试最终阶段才被发现。同一合同中还出现两项同族缺陷：一个本来应跳过昂贵计算的触发器，反而从那项计算所测成本读取条件；另一项规格不匹配则是确定性方法在受约束单纯形上使用平坦先验，而登记观测由受约束设计生成，使绝对区间宽度在方法间不可比。

补救很低成本，但当时没有：**冻结后、运行前，枚举状态机可输出的每一种裁决，并给出抵达它的路径。** 没有可达路径的裁决属于缺陷，人工检查数分钟即可发现，执行却可能数周才发现。

**描述漂移。** 冻结确保数字不能改变，但不能保证描述该数字的句子准确。手稿准备期间出现了五例，均在不做新计算的前提下，从冻结产物重新生成每个引用值时发现：

| 描述 | 缺陷 | 对结论的影响 |
| --- | --- | --- |
| “区间下界达到 14.931 %” | 取自四个名义水平中最不极端的 50 % 水平，却被表述为总体最小值 | 无；真实最小值为 12.062 %，更极端 |
| 两项消融被表述为独立 | 两个配置文件在不同构建器名下声明相同特征定义 | 数值无影响；支撑主张必须收窄 |
| 五个端到端结果列在一起 | 两个取自验证集，三个取自测试集 | 无；全部五条在三个划分上均为负 |
| “设计排序跨度 0.71 %，低于数值保护带” | 主配置跨度为 0.4565 %，且高于数值带、低于实践带；冻结决策理由写的是实践带 | 无；决策未变，但记录指错机制 |
| 判据实现“29 行” | 与该文件的任何行数口径都不一致（总行数 34，非空行 27） | 无；实质性主张，即无领域依赖，仍成立 |

五项均未改变结论，其中两项更正后反而强化了底层发现。正因如此，它们值得报告：这是严格冻结纪律仍无法消除的失败模式，因为它们存在于文字而非产物中。第四项最具启发性，因为读者核查主张时会在同一冻结文件中看到 `resolvable_numerical = true`，而该句试图概括的内容恰与之冲突。

它们的分布也具有信息：三项涉及引用的是*哪个*数，一项涉及该数说明的是*哪种机制*，一项是简单误计。只有第二类会使读者误解研究已经确立的内容，也是最不可能仅靠重读发现的一类。

本文采用的对策是从冻结输出中以程序方式生成每个引用值，并记录源路径与摘要，使误描述成为会失败的检查，而不是读起来合理的句子。本文的结果和讨论由覆盖 46 个源文件的 17 份产物支撑。

## 7.4 适用范围与迁移条件

**首先给出必要陈述：该方案没有达到自身目标。** 窄窗口判据为 1.0–2.4 vol %，预注册目标为 0.4 vol %。可迁移的是审计框架和工程结构，而不是经验证的检测方案。把这项工作当作可直接移植的解决方案会造成错误预期。

**按代码耦合度划分。** 组件按其对场景专属模块的实际依赖分为四层。将干扰不确定性传播到目标单位的判据，即承载全研究的判据，仅 34 行，完全无领域依赖。残差分解头、指标和协议层、打包与划分机制、模型和训练层同样与场景无关，因为通道按名称解析，目标维度由数据而非常量确定。信号处理前端和第一次可辨识性审计各自仅导入一个物理函数和一个组分常量；替换这两项，即可将包含匹配滤波、包络锁定、亚采样插值、稳健噪声估计和多声程回归的整套处理链用于任意超声飞行时间测量。后验机制在实质上与维度无关，但绑定在三组分切空间基与固定观测行步长上，需泛化而非替换。只有物理常数、组分域、冻结设计、载频与声程限制、新鲜空气标定假设和冻结裁决真正不可迁移。

代码库中已有三种闭合结构不同的场景并存：一个四组分闭合系统、一个带背景气的四目标开放系统，以及当前这个将背景气提升为显式目标的三组分闭合系统。这直接支持框架层面的主张；增加第四个场景是已经走过三次的路径。

**按物理条件划分。** 两项判据决定可适配性：每个目标组分是否有专属直接通道，以及目标工作量程相对于观测灵敏度的大小。组分摩尔质量差异显著、或每个目标都有直接通道的方案，比当前方案处于更有利条件；这里两个难区分组分的摩尔质量仅差 14.24 %、热容比仅差 0.35 %，困难目标跨度也仅为 3.20 个百分点。结构上与本方案相似的情形，即一个红外活性组分作为锚点、其余组分由声学推断，是自然的迁移目标；其中若干方案的工作量程远宽于 3.20 个百分点，这构成实质不同的条件。痕量检测以及任何摩尔质量相等的组分对都不在声学路径能力范围内，本研究为这一边界提供证据，而非反证。

**在新方案中采用该框架前的五项检查。**

1. 每个目标组分是否有专属直接通道？若没有，在训练任何模型前先计算 Fisher 秩。
2. 应预期任何单个标量观测都存在秩亏；本例在全部 189 个工作点均成立。只有加入第二个独立物理机制后，干扰参数才可能被边缘化。
3. 将目标工作量程相对于观测噪声定量化。狭窄量程会直接导致精度不足，且在模型出现前就能看见。
4. 确定硬件实际可以提供哪些干扰先验。本例的约束项是 0.1 mm 声程先验，这是采购问题而非算法问题。
5. 若组分满足闭合约束，检查缩放零方向，并在降维切空间中求解。总丰度不是可估计自由度。

## 7.5 本研究无法解决的一个问题

摊销后验推断，即在模拟器抽样上训练条件密度估计器，在这里技术上可行且成本低：一次训练抽样只需一次前向评估，因此 20 万条训练集在单核上只需数秒，比其可替代的重采样路径低三个数量级。它会为每个样本产生区间，从而完全消除 28–37 % 的拒绝率；由于它在登记生成模型上摊销，其校准几乎可构造性满足。基于现有证据，它很可能通过覆盖率门槛。

它没有运行，原因不是资源，而是公平性问题。这类模型按构造使用真实受约束生成先验，而本文评估的确定性方法在单纯形上使用平坦先验。因此，摊销方法的更窄区间会将先验规格差异与方法差异混淆；第 6.10 节表明先验规格并非小项，正是它使超过 96.9 % 的后验质量落在物理域之外。

该结论要求在运行任何此类比较前先登记：**主指标必须是从先验宽度到后验宽度的收缩比，而非绝对区间宽度。** 否则比较将允许一个虚假的正结果：覆盖率通过、区间很窄，但测量对后验的贡献接近于零。这是“部分似然峰本身位于可行域外”这一发现的直接推论：将平坦先验替换为正确的窄先验后，后验会被先验主导。

## 7.6 对传感反演模型选择研究的含义

多组分气体反演文献主要围绕估计器比较组织。本研究表明，这种组织存在一个盲点，而且弥补它的成本很低。

**修正方法早已存在于相邻领域。** 大气遥感已在三十年前就通过前向模型，在构建反演前计算信息量、信号自由度和平均核，目的正是确定仪器能够分辨什么 [Rodgers 2000, Ch. 2]。这一做法在该领域属于教科书内容，却在多组分气体传感文献中实际上缺失；声速加声衰减的声学传感概念自 [Phillips *et al.* 2003] 起已可获得，但没有配套的可辨识性分析。因此，本文的观察不是这种顺序是否可能，而是它缺席的代价是什么，案例研究也量化了该代价。

在固定观测模型下，更换估计器只能逼近有效信息给出的界限，无法越过它。当方案受信息量限制时，估计器比较衡量的只是各候选方法逼近一个已低于需求的界限的程度，并被呈现为性能排序。本文中五种结构不同的端到端架构在每个划分上均给出负 `R²`，第六种应用于派生标量序列的架构为 0.5152；如果不知道界限已低于需求，把这种差异读作架构排序就是在解读不可达目标周围的噪声。

本研究中两条训练优先路线各自耗费一次完整训练，才得到前向审计数分钟即可给出的结论。审计通过时，估计器比较才有意义，因为剩余差距确实可归因于估计器。审计失败时，有效问题从*哪个模型*转为*哪项规格*，第 6.8 节表明后者具有具体且可证伪的答案。

以这种方式报告的负结果不是没有发现。它是关于传感方案的陈述；本文由六种相互一致的独立判定支持，其中四种完全不涉及拟合模型。
