# 2. 问题设定与前向模型

## 2.1 传感任务

在严格闭合约束下，需要从多模态合成测量中同时恢复三个组分：

| 组分 | 工作量程（vol %） | 红外活性 | 可观测途径 |
| --- | --- | --- | --- |
| CO₂ | 0.03 – 5.00 | 是 | 非色散红外，以及声速、弛豫吸收和热导率 |
| **O₂** | **18.00 – 21.20** | **否**（同核双原子分子） | 通过摩尔质量影响声速；热导率贡献极弱 |
| N₂ | 73.80 – 81.97 | 否（同核双原子分子） | 同 O₂ |

三个目标中有两个没有专属测量通道。这一结构特征使本问题不同于每个分析物均配有直接传感器的常见构型，也使第 4 节的可辨识性问题不再是可选项，而是不可回避的问题。

每条序列的测量由 128 个时间步组成，包含 7 条慢速通道（一条光学、一条热学，以及五条环境或几何通道），并附带以 1 MS/s 采样的超声帧。

## 2.2 为什么问题困难：定量说明

两个难以区分的组分，其热容比仅相差 0.35 %（O₂ 为 1.3947，N₂ 为 1.3996，来自第 2.5 节登记的热容），因而分离它们的主要声学依据是 14.24 % 的摩尔质量差异。在 300 K 下，登记常数给出 N₂ 和 O₂ 的纯组分声速分别为 353.03 m/s 与 329.72 m/s，差值为 **23.31 m/s**，相当于氮气声速的 6.60 % 和氧气声速的 7.07 %。若单独报告该差值，问题看上去是可解的。

但这不是正确的量。真正重要的不是纯组分之间的对比，而是扫过实际工作量程所产生的信号，而该量程只有 3.20 个百分点宽：

| 量 | 工作点 | 数值 |
| --- | --- | ---: |
| 整个 O₂ 工作量程内的声速变化（18.00 → 21.20 vol %） | CO₂ = 0.03 vol %，300 K（348.444 → 347.653 m/s） | **0.79 m/s**（0.23 %） |
| CO₂ 量程另一端处的同一跨度 | CO₂ = 5.00 vol %，300 K（342.801 → 342.044 m/s） | 0.76 m/s（0.22 %） |
| 1 K 温度误差引起的声速变化 | CO₂ = 2.52 vol %，O₂ = 19.60 vol %，25 → 26 °C | **0.58 m/s** |
| 后者占第一行的比例 | | **0.73** |

表中各量在不同工作点计算，第二列已明确记录；因而该比例是关于采样域的数量级陈述，并不是同一工作点上的导数比。即使取 CO₂ = 5.00 vol % 的跨度，该比例也仅从 0.73 变为 0.76，因此结论不依赖于此处的选点。

**仅 1 K 的温度误差，就会使观测量变化达到目标在整个工作量程内扫动所引起变化的 73 %。** 声程和触发延迟误差也会进入同一标量观测量。因此，目标信号不仅很小，而且与必须从中分离出的干扰项量级相当。第 4.3 节说明这对可辨识性的含义，第 6.8 节将其转化为硬件规格。

## 2.3 形式化定义

令序列 `i` 的标签为 `y_i = (x_CO₂, x_O₂, x_N₂)_i ∈ ℝ³`，满足

```
x_CO₂ + x_O₂ + x_N₂ = 100,     x_• ≥ 0.
```

观测为 `o_i = { w_{i,t} ∈ ℝ^5000 , s_{i,t} ∈ ℝ^7 }`，其中 `t = 1…128`，
`w` 是以 1 MS/s 采样的超声帧，`s` 是 7 条慢速通道。

以下四项建模承诺由合同固定，并对结果具有承重作用：

1. **模型输出三个原始数值。** 虽然标签只有两个自由度，但预测两个组分、再反填第三个组分，只是机械地消除了闭合误差，并不能帮助困难组分。证据是闭合误差与目标精度并不单调相关：岭回归可达到近零闭合误差但精度中等，而强表格先验的闭合误差为 0.157，却具有更好精度。
2. **不使用基于闭合的输出头和变换**：不使用残差闭合头、对数比变换、目标变换或闭合类损失。闭合误差只监测，不施加约束。
3. **隔离真值量。** 模拟器内部的飞行时间、真实声速和真实衰减仅用于真值上界审计（`oracle`），不得进入可部署输入路径。
4. **按组分评估。** 困难组分的 `R²`、平均绝对误差和绝对误差第 90 百分位是主要指标。

## 2.4 采样设计

组分在 `(x_CO₂, x_O₂)` 平面上通过受约束拉丁超立方采样抽取，第三个组分被动计算，因此角点天然满足非负性。环境参数独立且均匀抽取：温度 15–35 °C、压力 0.10–0.709 MPa、相对湿度 20–80 %，以及每条序列的基础声程 0.2–0.3 m。

每条序列被等比例组织为四个相位窗口：基线、暴露、稳态和恢复。其中两个具有明确的下游用途：基线窗口用于第 3.5 节的延迟标定，稳态窗口用于多声程回归。波形合成将声程扫过五个固定设置，即 0.18、0.20、0.22、0.25 和 0.28 m；这些设置独立于上文每条序列的基础声程登记，且不随其变化。在 200 kHz 载频下，实用上限约为 0.3 m，超过该值后弛豫吸收将占主导。

数据划分以混合物标识符为键，而不是序列标识符，因此同一混合物不会出现在多个分区中。

## 2.5 声速

采用按摩尔分数加权的理想气体混合：

```
c_mix = sqrt( γ_mix R T / M_mix ),
M_mix = Σ_k y_k M_k,   c_p,mix = Σ_k y_k c_p,k,   γ_mix = c_p,mix / (c_p,mix − R).
```

纯组分常数取自 `table10_forward_model_constants.csv`：CO₂、O₂、N₂ 的摩尔质量分别为 0.04401、0.031998 和 0.02801 kg/mol，热容分别为 37.13、29.38 和 29.12 J/(mol K)。

## 2.6 吸收：经典项与振动弛豫项

```
α_total = α_cl + Σ_j α_j ,      j ∈ {CO₂, N₂, O₂, H₂O}
```

其中经典项按 `f² P⁻¹ sqrt(T/T₀)` 缩放，每个弛豫过程采用洛伦兹形式：

```
α_j λ = (αλ)_max,j · y_j · 2 f f_r,j / (f² + f_r,j²),      α_j = (α_j λ) f / c_mix.
```

登记的弛豫参数如下：

| 过程 | `f_r`（Hz/atm） | `(αλ)_max` | 在 200 kHz 载频下的状态 |
| --- | ---: | ---: | --- |
| CO₂ | 28 000（湿度催化，每 % 系数 0.015） | 0.12 | 活跃 |
| H₂O | 100 000 | 0.01 | 活跃 |
| N₂ | 9 | 0.004 | 深度冻结 |
| O₂ | 24 | **0** | 可忽略；实现为零 |

最后一行值得明确说明，因为它是设计约束，而非出于便利的近似。氧气弛豫频率比载频低四个数量级，因此在该载频下氧气对吸收没有贡献。**这也是多频扩展的理由**：将探测频率降低到接近 `f_r`，即可使该过程重新进入可观测频带。第 6.7 节报告该扩展的结果。

## 2.7 多频前向算子

独立算子支持多频审计，且不改动单载频链路；二者在 200 kHz 下的吸收差异被显式登记，而非悄然吸收进模型。

弛豫强度由振动热容导出，而非经验固定。对于特征温度为 `θ_vib`、简并度为 `g` 的谐振子：

```
C_vib / R = g x² e^x / (e^x − 1)²,      x = θ_vib / T,
```

O₂、N₂ 和 CO₂ 的 `θ_vib` 分别为 2270 K、3390 K 和 960 K（CO₂ 的后二重简并弯曲模）。相对色散台阶以及借助 Kramers–Kronig 关系得到的吸收峰为：

```
Δc/c = (γ−1)² / (2γ) · y_j · C_vib,j / R,      (αλ)_max = π Δc/c.
```

随后，声速色散和总吸收为：

```
c(f) = c_eq [ 1 + Σ_j (Δc_j / c_eq) f² / (f² + f_r,j²) ],
α(f) = α_cl(f) + Σ_j α_j(f),
```

氧气和氮气弛豫频率则采用依赖湿度的形式，这使相对湿度成为可主动调制的实验变量，而不只是纯干扰项。

观测算子针对每个频率按固定行序返回三个量：延迟 `L/c(f)`、对数幅值 `−α(f)L`，以及相位 `−2πf τ(f)` 加登记的分支整数。登记的观测噪声分别为 0.5 μs、0.02 和 0.1 rad，协方差为对角阵。冻结频率集合为 {25, 63, 100, 200} kHz。

## 2.8 热导率

采用 Wassiljewa–Mason–Saxena 混合规则，其中 Wilke 相互作用系数由摩尔质量和黏度计算，而非查询表格：

```
λ_m = Σ_i y_i λ_i(T) / Σ_j y_j φ_ij,
φ_ij = [1 + (η_i/η_j)^{1/2} (M_j/M_i)^{1/4}]² / sqrt(8(1 + M_i/M_j)).
```

纯组分热导率用幂律进行温度校正，指数分别为 0.87、0.80 和 0.77。热传感器电压与 `λ_m` 线性相关，并含有基线漂移项和温度项。两个难以区分组分的热导率仅相差 2.3 %，而摩尔质量相差 14.24 %，因此预计该通道对它们贡献很小；第 6.2 节验证了这一预测。

## 2.9 光学通道

场景中恰有一个红外活性组分，因此**无需串扰矩阵**；相对于同一代码库中的兄弟场景，这是一个简化，后者之一需要 3×3 光学串扰模型。CO₂ ν₃ 带的吸光度采用经验线性形式，探测器输出遵循带漂移和噪声的 Beer–Lambert 响应。仅实现经验光学后端，未实现逐线光谱后端。

## 2.10 波形合成与采集

| 参数 | 数值 |
| --- | --- |
| 载波频率 | 200 kHz |
| 突发长度 | 8 个周期 |
| 采样率 | 1 MS/s |
| 超声帧 | 5 ms → 5000 个采样点 |
| 转换器分辨率 / 满量程 | 20 bit / 2.5 V |
| 系统延迟 / 线缆延迟 / 校正 | 80 μs / 2 μs / 82 μs |
| 触发抖动（标准差） | 3 μs |
| 换能器带宽 / 振铃 | 20 kHz / 4 个周期 |

波形是经过二阶谐振带通换能器响应的 8 周期突发信号，并使用五阶 Lagrange 分数延迟滤波器实现亚采样位置放置。

**波形峰值位于真实飞行时间加 82 μs 再加抖动的位置。** 若将峰值位置直接当作飞行时间，会得到约 84 μs 的表观误差；这不是峰值定位误差。该实现细节曾导致一次误诊（第 6.5 节），在此明确写出，是因为任何复现实现都会遇到它。

帧以每时间步缩放的 16 位整数存储；物理转换器仍为 20 位，测得峰值约占满量程的 22 %，因此每时间步缩放给出的量化步长约比固定标度细 4.6 倍。正式生成跳过光学麦克风通道，在误差和噪声仅约 1 % 变化的代价下，将数据集从 17 GB 缩减至 3 GB。

## 2.11 前向模型未表示的内容

第 4.9 节的限制在此明确：详细水蒸气弛豫、耦合多物种弛豫、低频衍射与近场效应及完整换能器频响，均登记为搁置且非阻塞的未建模项。单向链路也没有整体流动，首次可辨识性审计已将其判为完全拒绝而非小误差（第 6.7 节）。模型未拟合失配项，所有结果均以前述前向算子正确为条件。
