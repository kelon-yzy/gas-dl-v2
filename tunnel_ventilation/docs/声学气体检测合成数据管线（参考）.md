## 步骤1：CoolProp / NIST 生成参考声速与经典衰减

**目标**：获得任意 T、P 下纯/混合气体的平衡声速 \( c_0 \) 与经典粘滞+热传导衰减 \( \alpha_{\rm class} \propto f^2 \)。

**核心资源与链接**  

- **NIST Chemistry WebBook Fluid Properties**（免费在线交互）：  
  https://webbook.nist.gov/chemistry/fluid/  
  支持 N₂、O₂、CO₂、CH₄、H₂O 纯流体；输出声速、密度、Cp/Cv、粘度、热导。可导出表格。  
- **CoolProp**（推荐首选，开源 REFPROP 替代）：  
  - 官网/文档：https://coolprop.org/  
  - GitHub：https://github.com/CoolProp/CoolProp  
  - PyPI：`pip install CoolProp`  
  - 在线计算器：https://ibell.pythonanywhere.com/  
  - 支持多组分混合物（HEOS 或 REFPROP 后端）、Python/MATLAB 接口。  

**关键实现要点**  

```python
import CoolProp.CoolProp as CP
# 示例：空气-like 混合（N2 0.79 + O2 0.21）
c = CP.PropsSI('A', 'T', 298.15, 'P', 101325, 'N2[0.79]&O2[0.21]')  # 声速 m/s
# 粘度、热导、Cp、Cv 同理 → 计算 Stokes-Kirchhoff 经典衰减
```

经典衰减公式（Stokes-Kirchhoff）：  
\[
\alpha_{\rm class} = \frac{2\pi^2 f^2}{\rho c^3} \left( \frac{4}{3}\eta + \eta_b + \frac{(\gamma-1)\kappa}{C_p} \right)
\]  
其中 η 剪切粘度、κ 热导、η_b 体粘度（可近似）。CoolProp 直接提供大部分参数。

**输出**：参考 \( c_0(T,P,x) \) 与 \( \alpha_{\rm class}(f) \) 基线，用于后续叠加弛豫贡献。

## 步骤2：Bass 参数 + SSH / 复合模型重建弛豫谱（1 Hz–10 GHz）

**目标**：在经典基础上叠加振动弛豫（V-T / V-V），生成完整 \( \alpha(f/P) \) 与色散 \( c(f) \)。

**核心参数与模型源**  

- **Bass 大气吸收标准**（N₂/O₂ + H₂O 催化核心）：  
  - Bass et al., *J. Acoust. Soc. Am.* 88, 2019 (1990 Update)  
  - Bass et al., *J. Acoust. Soc. Am.* 97, 680 (1995 Further developments)  
  - 在线计算器：https://sengpielaudio.com/calculator-air.htm（快速验证 T/RH/f 影响）  
  - ISO 9613-1 实现：python-acoustics 库  
    GitHub：https://github.com/python-acoustics/python-acoustics  
    （`acoustics.standards.iso_9613_1_1993` 模块直接可用）  
- **SSH 理论 + 复合/分解模型**（HUST 路线，覆盖 N₂/O₂/CO₂/CH₄/H₂O）：  
  - 鄢舒/王殊 2008《物理学报》：宽频重建算法（1 Hz–10 GHz）  
    https://wulixb.iphy.ac.cn/article/doi/10.7498/aps.57.4282  
  - 贾雅琼等 2011 paper.edu.cn 预印本（复合弛豫时间 reciprocal sum）：  
    https://www.paper.edu.cn/releasepaper/content/201101-450  
  - 贾雅琼等 2012《物理学报》：有效比热容与弛豫时间分解对应  
    https://wulixb.iphy.ac.cn/article/doi/10.7498/aps.61.095101  
  - 有效比热复形式：  
    \[
    C_{V,\rm eff}(\omega) = C_{\rm tr+rot} + \sum_s \frac{C_{{\rm vib},s}}{1+i\omega\tau_s}
    \]  
    由此导出 α 与 c 色散。复合 τ 可用 reciprocal sum 或分解 V-T/V-V。

**规划实现**  

1. 用 Bass 公式得 O₂/N₂ 弛豫频率 \( f_r \)（湿度敏感）。  
2. 叠加 HUST 复合模型处理 CH₄/CO₂ 等多模式。  
3. 频率扫描 log 空间 1 Hz–10 GHz，归一化 \( f/P \)。  
4. 碰撞直径 σ 可微调匹配实验（文献推荐）。

**输出**：全谱函数 `alpha(f, T, P, x)`、`c(f, T, P, x)`。

## 步骤3：与 Ejakov / Dain 图比对验证

**目标**：验证模型准确性，尤其 N₂ 背景 + CH₄/H₂O 体系。

**关键验证数据源**  

- **Dain & Lueptow 2001**（理论结果，多图）：  
  - Results 论文 PDF（免费）：  
    https://faculty.mccormick.northwestern.edu/richard-lueptow/docs/jasa-dain-results-01.pdf  
  - Theory 论文：*J. Acoust. Soc. Am.* 109, 1955 (2001)  
  - 更多 Lueptow 组资源：https://faculty.mccormick.northwestern.edu/richard-lueptow/docs/  
  - 覆盖 N₂-CH₄-H₂O 三组分、组成/T/P 影响，α 无量纲谱。  
- **Ejakov et al. 2003**（实验 + 计算）：  
  *J. Acoust. Soc. Am.* 113, 1871–1879  
  链接：https://pubs.aip.org/asa/jasa/article/113/4/1871/549179/Acoustic-attenuation-in-gas-mixtures-with-nitrogen  
  （ResearchGate 常有 PDF）  
  N₂ 背景混合物实验衰减数据，直接用于 HUST 模型比对。  

**验证方法**  

- 数字化论文图（WebPlotDigitizer）提取峰值位置/高度/数量级。  
- 计算 RMSE 或相对误差（峰位 < 10–20% 通常可接受；微调 σ 可改善）。  
- 经典部分用 CoolProp + Stokes-Kirchhoff 对照。  
- 额外：Petculescu & Lueptow 系列（行星大气扩展）可作扩展验证。

**成功标准**：谱线趋势、衰减数量级、峰位横坐标与文献一致（贾雅琼 2011 已证明复合模型可达此水平）。

## 步骤4：目标混合气组分扫描 → 合成数据集 → 训练反演模型

**目标混合气**：O₂/N₂ 主背景（0–100% O₂）+ 微量 H₂O（0–3%）、CO₂（0–5%）、CH₄（0–10%）。T = 280–320 K，P = 0.5–2 atm。

**合成策略**  

1. 网格/拉丁超立方采样：摩尔分数空间 + T/P。  
2. 调用步骤1+2 模型生成每点全谱（或关键多频点：音频 + 超声 20 kHz–几 MHz + 可选 GHz）。  
3. 输出格式：CSV/HDF5/JSON（特征 = 多频 α + c + T/P；标签 = 组分向量）。  
4. 数据增强：加噪声（测量不确定性 1–5%）、温度漂移。  
5. 规模建议：1k–10k 样本起步，可扩展。

**反演模型规划**  

- 基线：非线性最小二乘（拟合有效比热/τ 参数）或查找表插值。  
- ML：随机森林 / XGBoost / 神经网络（输入谱特征 → 输出浓度）。  
- 工具：scikit-learn、PyTorch/TensorFlow；可用 CoolProp 实时生成训练数据。  
- 评估：交叉验证 + 与声速-only 对比（突出弛豫对相近 M 气体的增益）。

**存储与开源建议**  

- 生成脚本开源到 GitHub。  
- 数据集托管 Zenodo / Figshare（便于引用）。  
- 可加入经典 Bass 空气数据作为基准。
