## 1. 论文定位

### 1.1 核心论点

**在投入算法开发之前，用纯前向的信息量审计判定传感方案能不能达到目标精度；并且失败必须分解到机制才算完成。**

这不是一篇"我们提出了更好的模型"的论文。它回答的是一个更前置的问题：给定一套传感器组合和噪声预算，目标参数的精度上限由什么决定，怎样在几分钟内判定出来，以及判定为不足之后应该改什么。

### 1.2 为什么值得发表

三条理由，按强度排序：

1. **完整的负结果链条，每一步都有冻结产物支撑。** 绝大多数论文只报告成功。tv3 有六次相互独立、方法各异的测量给出同一个物理墙位置（1.0–2.4 vol%），还有五种不同结构的端到端模型全部为负 R²。这类证据密度在传感器论文里少见。
2. **方法学本身可迁移，且与气体种类、传感器模态、网络结构全部无关。** 三条最有价值的产出是：纯前向审计前置于数据生成、等效目标误差 P90 作为跨方法统一判据、拒绝率与两种覆盖率同时报告的区间验收要求。
3. **一个反面教材是真发现**：冻结防得住事后调门，防不住事前的契约矛盾。C0 把 24 条覆盖带、拒绝语义、抽样规模全部预注册，唯独没检查"每个可能的判定是否都有可达路径"，结果目标 verdict 结构上不可达，跑到 C3 才发现。这条对任何做预注册研究的人都有用。

### 1.3 不能声称的

- 不能声称提出了一个达标的检测方案（O₂ 窄窗 P90 实测 1.0–2.4 vol%，预注册门 0.4 vol%）。
- 不能声称"首次把深度学习用于声学弛豫谱组分反演"——ARGD（Liu 等 2023，Results in Physics）已经做过 CO₂/CH₄/N₂ 的 BiGRU + 注意力反演。
- 不能声称任何真实硬件能力。全部结果基于合成数据。

## 4. 候选期刊

### 4.1 首选：Measurement Science and Technology（IOP）

| 项 | 评估 |
| --- | --- |
| 匹配度 | **最高**。声学弛豫谱反演的既有工作（Zhu 2018、Zhang 2020）就发在这里，审稿人熟悉这条线 |
| 主题契合 | 期刊明确接收测量方法、不确定度评估、传感方案设计与极限分析 |
| 仿真研究接受度 | 高。该刊有相当比例的纯建模/仿真论文 |
| 负结果接受度 | 中等偏上。需要把方法学贡献写在前面，把负结果写成方法的验证案例 |
| 风险 | 需要正面处理"无硬件验证"；建议在 cover letter 里主动说明 |

### 4.2 次选：IEEE Transactions on Instrumentation and Measurement

| 项 | 评估 |
| --- | --- |
| 匹配度 | 高。Fisher 信息 + CRB + 变量投影 + 不确定度校准的组合非常 TIM |
| 优势 | 影响力高于 MST；方法学导向的论文占比大 |
| 风险 | 对实验验证的期待通常高于 MST；纯仿真需要更强的理论贡献支撑。**若首选被拒且审稿意见指向"理论贡献不足"，改投这里前需要补强第 6 章的一般化表述** |

### 4.3 备选：Measurement（Elsevier）

主题范围广，测量不确定度与传感方案评估都在范围内。相比 MST 的劣势是审稿人对声学弛豫谱这条线不一定熟悉，需要更多背景铺垫。

### 4.4 不建议

| 期刊 | 原因 |
| --- | --- |
| Sensors and Actuators B: Chemical | 偏材料与器件，纯仿真 + 负结果几乎没有机会 |
| IEEE Sensors Journal | 偏器件实现，方法学负结果容易被判贡献不足 |
| JASA | 论文重点是方法学不是声学物理；弛豫模型本身没有新贡献 |
| Sensors（MDPI） | 容易接收但影响力低，不匹配学位论文的支撑需求 |

### 4.5 投稿顺序

```
Measurement Science and Technology
   │ 拒 + 意见指向"理论贡献不足"
   ├──> 补强第 6 章一般化 ──> IEEE TIM
   │ 拒 + 意见指向"背景不足 / 范围过窄"
   └──> Measurement
```

## 5. 审稿风险与应对

| 风险 | 可能性 | 应对 |
| --- | --- | --- |
| "没有真实硬件验证" | **高** | 在 Introduction 就写明本工作的目标是判定方法而非检测方案；Limitations 第 1、2 条主动声明；强调审计结论是"任何算法都越不过的下界"，这个性质不依赖硬件实现 |
| "负结果贡献不足" | 高 | 把方法学写在前面，负结果作为方法的验证案例。Table 1 的六源一致性是关键——它证明的不是"我们失败了"，而是"这个判定方法在六种独立路径上给出一致答案" |
| "为什么不试试更强的模型" | 中 | 用 CRB 与 Fisher 秩回答：观测不变时换反演器最多逼近下界。再用五种结构的负 R² 与 TabPFN 上限探针（0.667，仍需扣 0.18 膨胀量）说明已经探过上限 |
| "0.4 vol% 的门是不是定得太严" | 中 | 说明该门自 2026-07-25 起降级为参考标注，且历史结论均在原门下判定、不因门槛变化重跑；同时给出不依赖门的绝对量：95% 区间中位数 5.72 pp 宽于整个 3.20 pp 工作量程 |
| "C0 契约矛盾是不是实验缺陷" | 中 | 主动写进 Limitations 第 10 条并说明它是契约设计问题、与后验方法性能无关；把它转成 Discussion 里的方法学发现 |
| "六件套不完整" | 中 | Limitations 第 9 条说明 SBC/PPC 缺失、终态语义为未通过、收尾按显式契约修订进行，并给出冻结路径供复核 |
