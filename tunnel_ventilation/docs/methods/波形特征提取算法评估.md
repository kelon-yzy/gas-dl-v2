# 波形特征提取算法评估

> 本文档评估 tv3 场景中 `CNN1D` 对 `5000` 点 raw 超声波形的特征提取能力不足问题,检索并排序更先进的替代算法。
> 前置:`DeepAcousticEncoder1D` 实测 val R²=+0.019,远逊于 Ridge R²=0.918,根因是 encoder 架构而非融合层(见 [dl_training_plan.md §11.4](../archive/legacy/dl_training_plan.md#114-服务器验证结果tv3-formal-6000-50-epoch-单-seed-rtx-5880))。
> 关联文档:[dl_training_plan.md](../archive/legacy/dl_training_plan.md)、[rocket_hydra_regression_implementation_plan.md](../archive/completed/rocket_hydra_regression_implementation_plan.md)、[small_sample_dl_strategies.md](small_sample_dl_strategies.md)、[waveform_normalization_plan.md](../archive/completed/waveform_normalization_plan.md)。

> **2026-07-08 实测回填**:Top2(MultiRocket raw 波形卷积)已由 R1a/R1b formal-6000 实测验算:R1b(raw 5000 点卷积)val O₂ R²=-0.195,R1a(标量序列卷积)val O₂ R²=0.515,两者均不如 R0(物理标量序列统计)的 0.603。R1b−R1a=−0.71 < 0.05,**raw 波形卷积路线证伪**。Top2 得分从 9.0 下调至 6.0(仅在 DL 端到端分支场景保留参考价值,不再作为 Ridge 特征路线推荐);Top1(TOF 物理特征工程)得分维持 9.5--R0 实质已是其离线实现且表现最优。详见 [rocket_hydra §0](../archive/completed/rocket_hydra_regression_implementation_plan.md)。

## 核心回答

针对掘进通风场景 `5000` 点/帧 raw 超声波形的特征提取缺陷,经过文档分析与文献检索,给出如下算法推荐排序。**得分 = 适用性 × 性能潜力 × 与 tv3 物理结构匹配度 × 小样本可行性**(600–6000 序列规模)。

## 背景说明

tv3 场景的核心数据形态是:每帧 `5000` 点 raw 超声波形(200 kHz 载波、1 MS/s 采样、20-bit ADC),外加 7 维 slow 慢通道,序列长 `T=512`。物理上,O₂ 与 N₂ 的区分**完全依赖声速差 6.4%(摩尔质量 32 vs 28)**,体现为亚样本级别的 TOF 偏移(<0.002 μs 精度,Lagrange 5 阶分数延迟 FIR 实现)。

当前 [cnn1d_tcn_fusion.py](../../tv3/dl/models/cnn1d_tcn_fusion.py) 的 `DeepAcousticEncoder1D` 用 4 层 `Conv1d + BatchNorm1d + ReLU`(stride=2 下采样),再 `adaptive_avg_pool1d + adaptive_max_pool1d + log1p(abs().mean())` 三个粗统计量拼成 64 维 embedding。实测结论([dl_training_plan.md §11.4](../archive/legacy/dl_training_plan.md#114-服务器验证结果tv3-formal-6000-50-epoch-单-seed-rtx-5880)):

- 最好结果 `v3_l2` val **R²=+0.019** / O₂ **R²=-0.061**,远逊于 R0 Ridge 物理统计量基线 **R²=0.918**。
- 已确认 P-9c 触发:加入波形模态后 O₂ R² 仍未转正,`CNN1D encoder 未能从 raw waveform 中提取有效的 O₂ 区分特征`。

### 现有 CNN1D 的三层局限性

1. **池化丢相位信息**:`avg+max` 池化对平移不敏感,而 TOF 差异正是一次回波的位置偏移——池化掉的就是要提取的。这是现有文档未点明的架构级根因。
2. **可学习卷积核在 6000 序列下欠拟合**:无先验的 3–7 宽度卷积核难以稳定学到亚样本相位相关,小样本下梯度噪声大。
3. **BatchNorm1d 在 batch=16 临界**:小样本统计量不稳,文档([waveform_normalization_plan.md §7.3](../archive/completed/waveform_normalization_plan.md#73-batchnorm-在小-batch-下的风险))已标记风险。
4. **embedding 尺度不对齐**:ultrasonic(64 维)与 slow(64 维)直接 concat,`v2` 因此训练发散 R²=-295,LayerNorm 后仅 +0.019。

`dl_training_plan.md §9.5 T5` 已规划 ROCKET 分支但未落地;`small_sample_dl_strategies.md` 覆盖 9 类小样本策略但未针对"高维波形特征提取"做架构级评估。本文档补齐这一缺口。

## 步骤指南

### 阶段 A:低成本高 ROI 优先(1–3 天)

1. **实现 TOF 物理特征工程**
   验证点:提取的 `tof_us` 与真实 O₂ 浓度的单变量相关系数 > 0.6,且加回 slow 后 Ridge val O₂ R² 相对 R0 提升。

2. **实现 MultiRocket 波形分支**
   验证点:T5 分支单独做 Ridge 时 val O₂ R² > 0;加入 slow 后 O₂ R² > 0.3。
   说明:与 [rocket_hydra_regression_implementation_plan.md](../archive/completed/rocket_hydra_regression_implementation_plan.md) 阶段 B/C 同步,该文档已规划 MiniRocket/MultiRocket,未落地。

3. **TCN Hidden Probe(T1)**
   验证点:probe 若 < 0.3 则确认前端 encoder 失败,锁定 Top1/2 为建设方向。
   说明:见 [dl_training_plan.md §9.2 T1](../archive/legacy/dl_training_plan.md#92-直接迁移的技术阶段-ⅱ-后可用) 与 [experiment_roadmap.md Ⅱ-0](../archive/legacy/experiment_roadmap.md#ⅱ-0-tcn-hidden-probe低成本前置诊断)。

4. **决策门**:若 Top1+2 后 O₂ R² ≥ 0.70 → 达标,进阶段 B;否则进阶段 B。

### 阶段 B:架构级升级(3–7 天)

5. **替换 `DeepAcousticEncoder1D` 为 wav2vec 式编码**
   验证点:单帧回到 batch_size × embedding_len 后再 over T,`adaptive_avg_pool1d` 不再用作主 pooling;val_loss 相对 v3_l2 下降。

6. **BatchNorm1d → LayerNorm/GroupNorm**
   验证点:训练曲线 val_loss 不抖动;不破坏现有测试。

   验证点:沿 exposure/recovery/full 三窗口提取统计量,统计量对 O₂ 有边际增益。

8. **TCN 加大感受野**
   验证点:receptive_field 覆盖单帧周期;train_loss 起步 < 100。

### 阶段 C:数据增强 + 集成

9. **S1 数据增强**:val R² 相对无增强 +0.05(见 [small_sample_dl_strategies.md S1](small_sample_dl_strategies.md#s1-数据增强data-augmentation))。

## 代码示例

### 示例 1:TOF 物理特征提取(最优先落地)

```python
import numpy as np
import torch
import torch.nn as nn


class TOFFeatureExtractor(nn.Module):
    """从单帧 raw 超声波形提取 TOF/声速/衰减物理特征,输出 8 维。
    与现有 DeepAcousticEncoder1D 并行,作为 PhaseStatMLP 的替代输入。
    设备兼容:支持 torch(端到端)与 numpy(离线预处理)两路。"""

    def __init__(self, sample_rate: float = 1e6, carrier_freq: float = 2e5,
                 ref_tof_us: float = 850.0, sound_path_m: float = 0.245):
        super().__init__()
        self.sample_rate = sample_rate
        self.carrier_freq = carrier_freq
        self.ref_tof_us = ref_tof_us
        self.sound_path_m = sound_path_m
        self._ref_phase = None

    def forward(self, waveform: torch.Tensor) -> torch.Tensor:
        x = waveform.float()  # (B, T, L)
        # 协同下行采样,匹配 200kHz 载波主频
        decimated = x[..., ::5]
        reference = self._reference_envelope(decimated[:1])
        features = []
        for t_idx in range(x.shape[1]):
            frame = decimated[:, t_idx, :]  # (B, L_dec)
            env = self._envelope(frame)
            tof_us, peak_amp = self._estimate_tof(env, reference)
            pulse_len = self._pulse_width(env)
            attenuation = torch.log1p(peak_amp)
            sound_speed = self.sound_path_m / (tof_us * 1e-6 + 1e-12)
            features.append(torch.stack([
                tof_us, peak_amp, attenuation, pulse_len,
                sound_speed, tof_us * tof_us, attenuation * pulse_len,
                sound_speed * peak_amp
            ], dim=-1))
        return torch.stack(features, dim=1)

    def _envelope(self, x: torch.Tensor) -> torch.Tensor:
        # 需 torch>=2.1 的 signal API 或改用 scipy.signal.hilbert 离线预处理
        analytical = torch.signal.hilbert(x)
        return torch.abs(analytical)

    def _reference_envelope(self, x: torch.Tensor) -> torch.Tensor:
        if self._ref_phase is None:
            self._ref_phase = self._envelope(x)[0].detach()
        return self._ref_phase

    def _estimate_tof(self, env: torch.Tensor, ref: torch.Tensor) -> tuple[torch.Tensor, torch.Tensor]:
        # 互相关 + 抛物线插值实现亚样本精度(对标 Azar 2010)
        corr = torch.nn.functional.conv1d(
            env.unsqueeze(1), ref.flip(-1).unsqueeze(1), padding=ref.shape[-1] - 1
        ).squeeze(1)
        peak_idx = corr.argmax(dim=-1)
        parabolic_shift = self._parabolic_interp(corr, peak_idx)
        tof_samples = peak_idx.float() + parabolic_shift
        tof_us = tof_samples / (self.sample_rate / 5.0) * 1e6 - self.ref_tof_us
        peak_amp = corr.gather(-1, peak_idx.unsqueeze(-1)).squeeze(-1)
        return tof_us, peak_amp

    @staticmethod
    def _parabolic_interp(corr: torch.Tensor, peak_idx: torch.Tensor) -> torch.Tensor:
        # 3-point 抛物线插值亚样本峰值定位
        left = corr[..., peak_idx - 1].clamp_min(1e-12)
        center = corr[..., peak_idx].clamp_min(1e-12)
        right = corr[..., peak_idx + 1].clamp_min(1e-12)
        denom = (left - 2 * center + right).clamp_min(1e-12)
        return 0.5 * (left - right) / denom

    def _pulse_width(self, env: torch.Tensor) -> torch.Tensor:
        # 包络半高宽,作为脉冲展宽度(携带频散信息)
        peak = env.max(dim=-1, keepdim=True).values
        half_mask = (env > 0.5 * peak).float()
        return half_mask.sum(dim=-1)

    def get_8dim_names(self) -> list[str]:
        return ["tof_us", "peak_amp", "log_attenuation", "pulse_width",
                "sound_speed", "tof_sq", "atten_x_pulse", "speed_x_amp"]
```

**使用方式**:在 `dataset.py` 的 `_build_single_input` 中用 numpy 版离线提取得 `phase_stats` 张量并写入 manifest,经现有 `PhaseStatMLP` 入口接入 `CNN1DTCNFusionRegressor`(model_kwargs 已支持 `phase_stat_dim`,见 `cnn1d_tcn_fusion.py`)。

### 示例 2:MultiRocket 固定核波形分支

```python
import torch
import torch.nn as nn


class MultiRocketBranch(nn.Module):
    """固定随机核 1D 卷积 + 多池化算子(max/mean/PPV/slope),
    输出低维统计特征,供下游 TCN 或 Ridge 消费。
    零学习的核参数由 seed 固定,小样本下稳定性远超可学习 Conv1d。"""

    def __init__(self, in_channels: int = 1, num_kernels: int = 512,
                 kernel_sizes: tuple[int, ...] = (7, 9, 11),
                 features_per_kernel: int = 4, seed: int = 42):
        super().__init__()
        self.num_kernels = num_kernels
        self.features_per_kernel = features_per_kernel
        torch.manual_seed(seed)
        params = []
        pad_max = max(kernel_sizes)
        self.pad_max = pad_max
        for _ in range(num_kernels):
            k = kernel_sizes[torch.randint(0, len(kernel_sizes), (1,)).item()]
            weight = torch.randn(1, in_channels, k) * 0.1
            bias = torch.randn(1) * 0.1
            padding = k // 2
            params.append((weight, bias, padding))
        self.weights = nn.Parameter(torch.stack([p[0] for p in params]), requires_grad=False)
        self.biases = nn.Parameter(torch.stack([p[1] for p in params]).squeeze(-1), requires_grad=False)

    def forward(self, waveform: torch.Tensor) -> torch.Tensor:
        B, T, L = waveform.shape
        flat = waveform.reshape(B * T, 1, L).float()  # (B*T, 1, L)
        conv_out = torch.nn.functional.conv1d(
            flat, self.weights, bias=self.biases, padding=self.pad_max // 2
        )
        conv_out = conv_out.reshape(B, T, self.num_kernels, -1)
        max_pool = conv_out.amax(dim=-1)
        mean_pool = conv_out.mean(dim=-1)
        positive = (conv_out > 0).float()
        ppv = positive.mean(dim=-1)
        diff = conv_out[..., 1:] - conv_out[..., :-1]
        slope = diff.mean(dim=-1)
        feat = torch.cat([max_pool, mean_pool, ppv, slope], dim=-1)
        return feat  # (B, T, num_kernels * features_per_kernel)
```

**接入方式**:并行于 `DeepAcousticEncoder1D`,经一个 `nn.Linear(num_kernels * 4, waveform_embedding_dim)` 投影到 64 维,再走现有 `TCN + shared_head`。配置侧加 `waveform_branch: "multirocket"` 切换。

### 示例 3:wav2vec 式 raw 波形编码器

```python
import torch
import torch.nn as nn


class Wav2VecStyleEncoder(nn.Module):
    """对标 wav2vec 2.0:raw 波形 → LayerNorm → 大 stride 首层 conv
    → 多层 conv featureExtractor → LayerNorm 投影到 embedding_dim。
    用 GroupNorm 替代 BatchNorm1d,避开 batch=16 小样本统计量不稳。"""

    def __init__(self, waveform_length: int = 5000, embedding_dim: int = 64,
                 first_kernel: int = 10, first_stride: int = 5,
                 channels: tuple[int, ...] = (32, 64, 64, 64),
                 dropout: float = 0.1):
        super().__init__()
        self.input_norm = nn.LayerNorm(waveform_length)
        layers = []
        current = 1
        for idx, hidden in enumerate(channels):
            stride = first_stride if idx == 0 else 2
            kernel = first_kernel if idx == 0 else 7
            padding = kernel // 2
            layers.extend([
                nn.Conv1d(current, hidden, kernel_size=kernel,
                          stride=stride, padding=padding, bias=False),
                nn.GroupNorm(num_groups=8, num_channels=hidden),  # 替代 BatchNorm1d
                nn.GELU(),
                nn.Dropout(dropout),
            ])
            current = hidden
        self.feature_extractor = nn.Sequential(*layers)
        with torch.no_grad():
            dummy = torch.zeros(1, 1, waveform_length)
            feat_len = self.feature_extractor(dummy).shape[-1]
        self.proj_norm = nn.LayerNorm(current * feat_len)
        self.proj = nn.Linear(current * feat_len, embedding_dim)

    def forward(self, waveform: torch.Tensor) -> torch.Tensor:
        if waveform.ndim != 3:
            raise ValueError(f"expected (B, T, L), got {tuple(waveform.shape)}")
        B, T, L = waveform.shape
        x = self.input_norm(waveform.reshape(B * T, L)).reshape(B, T, L)
        flat = x.reshape(B * T, 1, L)
        feat = self.feature_extractor(flat)
        pooled = feat.flatten(start_dim=1)
        embedding = self.proj(self.proj_norm(pooled))
        return embedding.reshape(B, T, -1)
```

**接入方式**:在 `CNN1DTCNFusionRegressor.__init__` 中把 `DeepAcousticEncoder1D` 替换为 `Wav2VecStyleEncoder`,保留 `waveform_adc_scale=1.0`(配合 `normalize_waveforms=true` 已生效)。配置侧加 `waveform_encoder: "wav2vec"` 开关,默认保持现有 `DeepAcousticEncoder1D` 以不破坏 v3_l2 可复现性。

## 注意事项

### 数据预处理

1. **TOF 提取前需对齐波形起点**:所有序列的发射起始相位必须一致,否则 TOF 差异被起点抖动淹没。检查 manifest 中 `phase_schedule` 是否对齐到同一 trigger。
2. **`normalize_waveforms=true` 必须与 `dequantize_waveforms=true` + `waveform_adc_scale=1.0` 共存**(CLI 已强校验,见 [waveform_normalization_plan.md §11.5](../archive/completed/waveform_normalization_plan.md#115-复审修复闭环2026-07-07))。物理 TOF 提取用归一化前波形更稳,实现时需保留两路。
3. **正式波形训练默认 `waveform_preprocess: "gpu"`**：int16+scale 上卡后再 dequant/stats/z-score，与 CPU 组装数值对齐；`window`/`phase_windows`/`augment` 须用 `cpu` 路径。见 [server_training_guide.md §4.5](../operations/server_training_guide.md#45-波形数据通路-waveform_preprocessp1-吞吐) 与 [waveform_normalization_plan.md §12](../archive/completed/waveform_normalization_plan.md#12-设备侧预处理扩展2026-07-14)。
4. **MultiRocket 核 seed 必须固定**(示例中 `seed=42`),否则不同 run 特征不可比。固定后才能做公平 ablation。
5. **augmentation 与归一化交互**:`jitter_std` z-score 后退化为绝对噪声,`gaussian_noise_std` 需重标定到 0.01–0.1 量级([waveform_normalization_plan.md §7.1](../archive/completed/waveform_normalization_plan.md#71-augmentation-与归一化的交互));验证归一化效果前先 `augment: null`。gpu 预处理路径本身禁止 augment。

### 模型训练

6. **BatchNorm1d 在 batch=16 临界**(文档 §7.3 已标),wav2vec/MultiRocket 分支一律换 LayerNorm 或 GroupNorm;`DeepAcousticEncoder1D` 内部 BatchNorm 在落 Top1/2 之前不动。
7. **先关增强建基线**:`augment: null` 跑通 Top1/2/Wav2Vec 三路,确认 val R² > v3_l2 的 0.019,再单独开增强归因增益。
8. **Loss 用 fixed `[1,2,1]` 不用 `inverse_train_var`**:v3b 已证明后者把 N₂ 权重压到 0.51 削弱 O₂ 学习([dl_training_plan.md §11.4.1](../archive/legacy/dl_training_plan.md#1141-总览) v3b vs v3)。
9. **FiLM/gated fusion 不追加**:v3_l3 已证明相对 v3_l2 无收益,说明瓶颈不在融合层而在 encoder,Top1/2/Wav2Vec 解决 encoder 后再评估是否重新启用。

### 超参数调整

10. **MultiRocket 核数**:从 512 起步,若 O₂ R² 不动再加到 1024–2048;特征维度大时下游加 `nn.Linear` 降到 64 维防止 slow 分支被淹没(现有 `v3_l2` 已标"slow 被稀释"风险)。
11. **wav2vec 首层 stride**:stride=5 对应 5× 下采样,5000→1000 点;若 TOF 差异被下采样抹平(检查首层输出是否承载亚样本信息),降到 stride=2。
12. **Ridge teacher 蒸馏 β 退火**:`β₀=0.3, T_anneal=30`,后期必须切回 ground-truth 避免复制 Ridge bias([dl_training_plan.md §9.3 T6](../archive/legacy/dl_training_plan.md#93-条件迁移的技术阶段-ⅲ-备选));O₂ teacher 无效(O₂ R²≈0),蒸馏只对 CO₂ 有效。
13. **early stopping patience=10**(TCN),新增分支后建议统一 patience=15,给物理特征分支更宽收敛窗口。

**推断/未验证声明**:Hydra、Mamba、iTransformer 在气体浓度回归场景的增益来自时序分类/回归的迁移推断,项目内未直接验证,落地前需用 tv3-smoke 做 3 epoch 通路验证 + tv3-formal-6000 单 seed 50 epoch 验证。
