## 示例 1:TOF 物理特征提取(Top1,最优先落地)

### 设计要点

- 从单帧 raw 超声波形端到端提取 TOF / 声速 / 衰减物理特征,输出 8 维向量
- 与现有 `DeepAcousticEncoder1D` 并行,作为 `PhaseStatMLP` 的替代输入
- 支持两路使用:torch 端到端(可微,供 DL 反传)与 numpy 离线预处理(供 Ridge)
- 互相关 + 3 点抛物线插值实现亚样本 TOF 精度,对标 Azar 2010 IEEE T-UFFC

### 实现

```python
from __future__ import annotations

import numpy as np
import torch
import torch.nn as nn


class TOFFeatureExtractor(nn.Module):
    """从单帧 raw 超声波形提取 TOF/声速/衰减物理特征,输出 8 维。

    与现有 DeepAcousticEncoder1D 并行,作为 PhaseStatMLP 的替代输入。
    设备兼容:支持 torch(端到端)与 numpy(离线预处理)两路。

    Args:
        sample_rate: 采样率(Hz),tv3 默认 1e6。
        carrier_freq: 载波频率(Hz),tv3 默认 2e5。
        ref_tof_us: 参考 TOF(μs),用于把绝对 TOF 转成相对偏移。
        sound_path_m: 声程(m),tv3 L_m 范围 0.2~0.3,取中值 0.245。
    """

    def __init__(
        self,
        sample_rate: float = 1e6,
        carrier_freq: float = 2e5,
        ref_tof_us: float = 850.0,
        sound_path_m: float = 0.245,
    ) -> None:
        super().__init__()
        if sample_rate <= 0 or carrier_freq <= 0:
            raise ValueError("sample_rate 与 carrier_freq 必须为正")
        if sound_path_m <= 0:
            raise ValueError("sound_path_m 必须为正")
        self.sample_rate = sample_rate
        self.carrier_freq = carrier_freq
        self.ref_tof_us = ref_tof_us
        self.sound_path_m = sound_path_m
        self._ref_phase: torch.Tensor | None = None

    def forward(self, waveform: torch.Tensor) -> torch.Tensor:
        """对 (B, T, L) 波形逐帧提取 8 维物理特征,返回 (B, T, 8)。"""
        if waveform.ndim != 3:
            raise ValueError(f"expected (B, T, L), got {tuple(waveform.shape)}")
        x = waveform.float()
        # 协同下行采样,匹配 200kHz 载波主频(5 倍过采样 → 1 倍)
        decimated = x[..., ::5]
        reference = self._reference_envelope(decimated[:1])
        features: list[torch.Tensor] = []
        for t_idx in range(x.shape[1]):
            frame = decimated[:, t_idx, :]  # (B, L_dec)
            env = self._envelope(frame)
            tof_us, peak_amp = self._estimate_tof(env, reference)
            pulse_len = self._pulse_width(env)
            attenuation = torch.log1p(peak_amp)
            sound_speed = self.sound_path_m / (tof_us * 1e-6 + 1e-12)
            # 8 维:原始 4 维 + 4 维交互项,供下游 Ridge/MLP 捕获非线性
            features.append(torch.stack([
                tof_us, peak_amp, attenuation, pulse_len,
                sound_speed, tof_us * tof_us, attenuation * pulse_len,
                sound_speed * peak_amp,
            ], dim=-1))
        return torch.stack(features, dim=1)

    def _envelope(self, x: torch.Tensor) -> torch.Tensor:
        """Hilbert 变换取包络。需 torch>=2.1 的 signal API,
        或改用 scipy.signal.hilbert 离线预处理路径。"""
        analytical = torch.signal.hilbert(x)
        return torch.abs(analytical)

    def _reference_envelope(self, x: torch.Tensor) -> torch.Tensor:
        """缓存参考波形包络,用于互相关 TOF 估计。"""
        if self._ref_phase is None:
            self._ref_phase = self._envelope(x)[0].detach()
        return self._ref_phase

    def _estimate_tof(
        self, env: torch.Tensor, ref: torch.Tensor,
    ) -> tuple[torch.Tensor, torch.Tensor]:
        """互相关 + 抛物线插值实现亚样本 TOF 精度(对标 Azar 2010)。"""
        corr = torch.nn.functional.conv1d(
            env.unsqueeze(1), ref.flip(-1).unsqueeze(1), padding=ref.shape[-1] - 1,
        ).squeeze(1)
        peak_idx = corr.argmax(dim=-1)
        parabolic_shift = self._parabolic_interp(corr, peak_idx)
        tof_samples = peak_idx.float() + parabolic_shift
        tof_us = tof_samples / (self.sample_rate / 5.0) * 1e6 - self.ref_tof_us
        peak_amp = corr.gather(-1, peak_idx.unsqueeze(-1)).squeeze(-1)
        return tof_us, peak_amp

    @staticmethod
    def _parabolic_interp(corr: torch.Tensor, peak_idx: torch.Tensor) -> torch.Tensor:
        """3 点抛物线插值亚样本峰值定位。"""
        left = corr[..., peak_idx - 1].clamp_min(1e-12)
        center = corr[..., peak_idx].clamp_min(1e-12)
        right = corr[..., peak_idx + 1].clamp_min(1e-12)
        denom = (left - 2 * center + right).clamp_min(1e-12)
        return 0.5 * (left - right) / denom

    def _pulse_width(self, env: torch.Tensor) -> torch.Tensor:
        """包络半高宽,作为脉冲展宽度(携带频散信息)。"""
        peak = env.max(dim=-1, keepdim=True).values
        half_mask = (env > 0.5 * peak).float()
        return half_mask.sum(dim=-1)

    @staticmethod
    def get_8dim_names() -> list[str]:
        """返回 8 维特征名,供 manifest 与 feature_names.json 记录。"""
        return [
            "tof_us", "peak_amp", "log_attenuation", "pulse_width",
            "sound_speed", "tof_sq", "atten_x_pulse", "speed_x_amp",
        ]
```

### 接入方式

- **离线 Ridge 路径**:在 `tv3/ml/rocket_features.py` 中用 numpy 版(`scipy.signal.hilbert`)离线提取得 `phase_stats` 张量,写入 manifest,经 `PhaseStatMLP` 入口接入 `CNN1DTCNFusionRegressor`(model_kwargs 已支持 `phase_stat_dim`,见 `cnn1d_tcn_fusion.py`)。
- **端到端 DL 路径**:把 `TOFFeatureExtractor` 作为 `CNN1DTCNFusionRegressor` 的可选分支,与 `DeepAcousticEncoder1D` 并行,投影到 64 维后拼接。

## 示例 2:MultiRocket 固定核波形分支(Top2)

### 设计要点

- 10000 固定随机卷积核(零训练)+ 4 池化算子(max/mean/PPV/slope)
- 小样本下稳定性远超可学习 Conv1d:核参数 `requires_grad=False`,只有下游 Linear 训练
- 与 [rocket_hydra_regression_implementation_plan.md §4.3](../archive/completed/rocket_hydra_regression_implementation_plan.md) P1 对齐,该文档已规划未落地

### 实现

```python
from __future__ import annotations

import torch
import torch.nn as nn


class MultiRocketBranch(nn.Module):
    """固定随机核 1D 卷积 + 多池化算子(max/mean/PPV/slope),
    输出低维统计特征,供下游 TCN 或 Ridge 消费。

    零学习的核参数由 seed 固定,小样本下稳定性远超可学习 Conv1d。

    Args:
        in_channels: 输入通道数,raw 波形为 1。
        num_kernels: 固定核数量,建议 512 起步,不足再加到 1024-2048。
        kernel_sizes: 核长度候选,tv3 超声 TOF 偏移在 7~11 样本量级。
        features_per_kernel: 每核 4 池化算子。
        seed: 核随机初始化 seed,必须固定以保证 run 间可比。
    """

    def __init__(
        self,
        in_channels: int = 1,
        num_kernels: int = 512,
        kernel_sizes: tuple[int, ...] = (7, 9, 11),
        features_per_kernel: int = 4,
        seed: int = 42,
    ) -> None:
        super().__init__()
        if in_channels < 1 or num_kernels < 1:
            raise ValueError("in_channels 与 num_kernels 必须为正")
        if not kernel_sizes:
            raise ValueError("kernel_sizes 不能为空")
        self.num_kernels = num_kernels
        self.features_per_kernel = features_per_kernel
        torch.manual_seed(seed)
        params: list[tuple[torch.Tensor, torch.Tensor, int]] = []
        pad_max = max(kernel_sizes)
        self.pad_max = pad_max
        for _ in range(num_kernels):
            k = kernel_sizes[torch.randint(0, len(kernel_sizes), (1,)).item()]
            weight = torch.randn(1, in_channels, k) * 0.1
            bias = torch.randn(1) * 0.1
            padding = k // 2
            params.append((weight, bias, padding))
        # 核参数不训练,只训练下游投影
        self.weights = nn.Parameter(
            torch.stack([p[0] for p in params]), requires_grad=False,
        )
        self.biases = nn.Parameter(
            torch.stack([p[1] for p in params]).squeeze(-1), requires_grad=False,
        )

    def forward(self, waveform: torch.Tensor) -> torch.Tensor:
        """对 (B, T, L) 波形逐帧提取 MultiRocket 特征,返回 (B, T, num_kernels * 4)。"""
        if waveform.ndim != 3:
            raise ValueError(f"expected (B, T, L), got {tuple(waveform.shape)}")
        B, T, L = waveform.shape
        flat = waveform.reshape(B * T, 1, L).float()  # (B*T, 1, L)
        conv_out = torch.nn.functional.conv1d(
            flat, self.weights, bias=self.biases, padding=self.pad_max // 2,
        )
        conv_out = conv_out.reshape(B, T, self.num_kernels, -1)
        # 4 类池化算子,对标 MultiRocket(Tan 2022)
        max_pool = conv_out.amax(dim=-1)
        mean_pool = conv_out.mean(dim=-1)
        positive = (conv_out > 0).float()
        ppv = positive.mean(dim=-1)  # proportion of positive values
        diff = conv_out[..., 1:] - conv_out[..., :-1]
        slope = diff.mean(dim=-1)
        feat = torch.cat([max_pool, mean_pool, ppv, slope], dim=-1)
        return feat  # (B, T, num_kernels * features_per_kernel)
```

### 接入方式

并行于 `DeepAcousticEncoder1D`,经一个 `nn.Linear(num_kernels * 4, waveform_embedding_dim)` 投影到 64 维,再走现有 `TCN + shared_head`。配置侧加 `waveform_branch: "multirocket"` 切换,默认保持现有 `DeepAcousticEncoder1D` 以不破坏 v3_l2 可复现性。

## 示例 3:wav2vec 式 raw 波形编码器(Top5)

### 设计要点

- 对标 wav2vec 2.0(Baevski 2020, arXiv:2006.11477):raw 波形 → LayerNorm → 大 stride 首层 conv → 多层 conv → LayerNorm 投影
- 用 GroupNorm 替代 `DeepAcousticEncoder1D` 内部的 `BatchNorm1d`,避开 batch=16 小样本统计量不稳([waveform_normalization_plan.md §7.3](../archive/completed/waveform_normalization_plan.md#73-batchnorm-在小-batch-下的风险) 已标风险)
- 首层 stride=5 对应 5× 下采样(5000→1000),对齐 wav2vec 2.0 首层 k=10 stride=5

### 实现

```python
from __future__ import annotations

import torch
import torch.nn as nn


class Wav2VecStyleEncoder(nn.Module):
    """对标 wav2vec 2.0:raw 波形 → LayerNorm → 大 stride 首层 conv
    → 多层 conv featureExtractor → LayerNorm 投影到 embedding_dim。
    用 GroupNorm 替代 BatchNorm1d,避开 batch=16 小样本统计量不稳。

    Args:
        waveform_length: 单帧波形点数,tv3 默认 5000。
        embedding_dim: 输出 embedding 维度,与 DeepAcousticEncoder1D 对齐 64。
        first_kernel: 首层核长度,对标 wav2vec 2.0 k=10。
        first_stride: 首层步长,对标 wav2vec 2.0 stride=5(5× 下采样)。
        channels: 各层通道数,默认 (32, 64, 64, 64)。
        dropout: dropout 率,小样本下建议 0.1-0.2。
    """

    def __init__(
        self,
        waveform_length: int = 5000,
        embedding_dim: int = 64,
        first_kernel: int = 10,
        first_stride: int = 5,
        channels: tuple[int, ...] = (32, 64, 64, 64),
        dropout: float = 0.1,
    ) -> None:
        super().__init__()
        if waveform_length < 1:
            raise ValueError("waveform_length 必须为正")
        if not channels:
            raise ValueError("channels 不能为空")
        self.input_norm = nn.LayerNorm(waveform_length)
        layers: list[nn.Module] = []
        current = 1
        for idx, hidden in enumerate(channels):
            stride = first_stride if idx == 0 else 2
            kernel = first_kernel if idx == 0 else 7
            padding = kernel // 2
            layers.extend([
                nn.Conv1d(
                    current, hidden, kernel_size=kernel,
                    stride=stride, padding=padding, bias=False,
                ),
                nn.GroupNorm(num_groups=8, num_channels=hidden),  # 替代 BatchNorm1d
                nn.GELU(),
                nn.Dropout(dropout),
            ])
            current = hidden
        self.feature_extractor = nn.Sequential(*layers)
        # 探测展平后维度,避免手算 stride 链出错
        with torch.no_grad():
            dummy = torch.zeros(1, 1, waveform_length)
            feat_len = self.feature_extractor(dummy).shape[-1]
        self.proj_norm = nn.LayerNorm(current * feat_len)
        self.proj = nn.Linear(current * feat_len, embedding_dim)

    def forward(self, waveform: torch.Tensor) -> torch.Tensor:
        """对 (B, T, L) 波形逐帧编码,返回 (B, T, embedding_dim)。"""
        if waveform.ndim != 3:
            raise ValueError(f"expected (B, T, L), got {tuple(waveform.shape)}")
        B, T, L = waveform.shape
        # LayerNorm 对每帧独立归一化,对标 wav2vec 2.0 "raw waveform normalized to zero mean unit variance"
        x = self.input_norm(waveform.reshape(B * T, L)).reshape(B, T, L)
        flat = x.reshape(B * T, 1, L)
        feat = self.feature_extractor(flat)
        pooled = feat.flatten(start_dim=1)
        embedding = self.proj(self.proj_norm(pooled))
        return embedding.reshape(B, T, -1)
```

### 接入方式

在 `CNN1DTCNFusionRegressor.__init__` 中把 `DeepAcousticEncoder1D` 替换为 `Wav2VecStyleEncoder`,保留 `waveform_adc_scale=1.0`(配合 `normalize_waveforms=true` 已生效,见 [waveform_normalization_plan.md §11](../archive/completed/waveform_normalization_plan.md#11-实施记录2026-07-07))。配置侧加 `waveform_encoder: "wav2vec"` 开关,默认保持现有 `DeepAcousticEncoder1D` 以不破坏 v3_l2 可复现性。正式波形配置默认 `waveform_preprocess: "gpu"`（设备侧 dequant/z-score，见 [server_training_guide.md §4.5](../operations/server_training_guide.md#45-波形数据通路-waveform_preprocessp1-吞吐)）。

## 注意事项

- 示例 1 的 `torch.signal.hilbert` 需 torch>=2.1;若环境为 torch 2.0,改用 `scipy.signal.hilbert` 离线预处理路径。
- 示例 2 的核 `requires_grad=False`,但 `nn.Parameter` 仍会计入 state_dict;保存/加载时注意区分。
- 示例 3 的 `GroupNorm(num_groups=8)` 要求 `hidden` 能被 8 整除,默认通道配置 (32, 64, 64, 64) 满足。
- 所有示例的代码为架构示意,未包络 registry/factory 装饰;落地时按 [../../CLAUDE.md](../../../CLAUDE.md) 编码规范补 `@register_model`、dataclass 配置、logger。
