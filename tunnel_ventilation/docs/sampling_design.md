# 掘进通风三组分采样设计

> 本文档定义 CO₂/O₂/N₂ 三组分的 LHS 采样方案、联合约束、状态分层标签与验收标准。
> 实现入口：`tv3/sim/generation/tunnel_ventilation/conditions.py`

## 一、组分区间

### 1.1 目标组分范围

| 变量      | 最小值 (%) | 最大值 (%) | 说明                    |
| ------- | -------:| -------:| --------------------- |
| `x_CO2` | 0.03    | 5.00    | 新鲜空气 (~0.04%) 到局部积聚上限 |
| `x_O2`  | 18.00   | 21.20   | 正常空气 (~20.9%) 到低氧下限   |
| `x_N2`  | 73.80   | 81.97   | 由 CO₂ 和 O₂ 的范围间接决定    |

### 1.2 联合约束

```
x_CO2 + x_O2 + x_N2 = 100.0%
```

`x_N2` 在采样阶段由 `100 - x_CO2 - x_O2` 计算得到，但 **写入 labels 作为显式预测目标**，不作为 `background_fields`。

N₂ 的有效范围验证：

- 最小 N₂ = 100 - 5.00 - 21.20 = 73.80%
- 最大 N₂ = 100 - 0.03 - 18.00 = 81.97%

### 1.3 环境变量范围

| 变量      | 范围          | 说明                           |
| ------- | ----------- | ---------------------------- |
| `T_C`   | 沿用 v6 链路    | 环境温度                         |
| `P_MPa` | 沿用 v6 链路    | 大气压力                         |
| `H_RH`  | 沿用 v6 链路    | 相对湿度                         |
| `L_m`   | 0.20–0.30 m | 200 kHz 超声声程（v6-phys-strict） |

## 二、采样方法

### 2.1 策略

采用 **受约束 LHS**（Latin Hypercube Sampling）：

1. 在 `(x_CO2, x_O2)` 二维空间做 LHS 采样
2. 计算 `x_N2 = 100 - x_CO2 - x_O2`
3. 校验 `x_N2` 落在有效范围 [73.80, 81.97] 内
4. 环境变量 `(T_C, P_MPa, H_RH, L_m)` 独立做 LHS，与组分拼接

### 2.2 伪代码

```python
import numpy as np
from scipy.stats.qmc import LatinHypercube

def sample_tunnel_ventilation(n_samples: int, seed: int) -> np.ndarray:
    """生成 CO₂/O₂/N₂ 三组分采样点。

    Returns:
        shape (n_samples, 3)，列序 [x_CO2, x_O2, x_N2]
    """
    rng = np.random.default_rng(seed)
    sampler = LatinHypercube(d=2, seed=rng)

    # 在 (CO2, O2) 空间 LHS 采样
    unit_samples = sampler.random(n=n_samples)
    x_co2 = 0.03 + unit_samples[:, 0] * (5.00 - 0.03)
    x_o2 = 18.00 + unit_samples[:, 1] * (21.20 - 18.00)

    # 计算 N₂
    x_n2 = 100.0 - x_co2 - x_o2

    # 校验
    assert np.all(x_n2 >= 73.80 - 1e-6), "N₂ 低于预期下限"
    assert np.all(x_n2 <= 81.97 + 1e-6), "N₂ 超过预期上限"

    return np.column_stack([x_co2, x_o2, x_n2])
```

### 2.3 与 syngas 采样的差异

| 维度    | syngas            | 掘进通风                  |
| ----- | ----------------- | --------------------- |
| 自由维度  | 4 个独立组分           | 2 个独立（CO₂, O₂），N₂ 为残差 |
| 总量约束  | sum < 100%（N₂ 补余） | sum = 100%（严格）        |
| N₂ 处理 | 背景气，不入 labels     | 显式目标，写入 labels        |
| 采样复杂度 | 4D LHS + 联合约束     | 2D LHS，N₂ 自动满足        |

## 三、状态分层标签

### 3.1 分层定义

| 状态                  | 判定条件                                         | 物理含义      |
| ------------------- | -------------------------------------------- | --------- |
| `fresh_air`         | `x_CO2 < 0.1` 且 `x_O2 > 20.5`                | 新鲜空气，通风良好 |
| `ventilation_decay` | `x_CO2 ∈ [0.1, 2.0]` 且 `x_O2 ∈ [19.5, 20.5]` | 通风效率下降趋势  |
| `co2_accumulation`  | `x_CO2 > 2.0`                                | CO₂ 局部积聚  |
| `oxygen_depletion`  | `x_O2 < 19.0`                                | 缺氧风险区域    |

一条样本可能同时满足多个条件（例如 `co2_accumulation` + `oxygen_depletion`），评估时按主状态归类。

### 3.2 实现要求

- 分层边界值写入配置文件（`configs/state_thresholds.json`），不散落在代码中
- 分层标签不作为模型输入，仅用于评估分层
- 每种状态在正式数据集中应有足够样本量（建议 ≥ 总量的 10%）

### 3.3 与安全规程的关系

本文档的分层阈值用于实验评估分层，**不直接等同于现场安全报警阈值**。正式报警阈值需依据目标场景的安全规程单独确认。

## 四、验收标准

### 4.1 采样覆盖率

- 每个组分的值域被 LHS 均匀覆盖
- `x_CO2` 的极端值（< 0.1% 和 > 4.0%）各有 ≥ 5% 的样本
- `x_O2` 的低值区（< 19.0%）有 ≥ 10% 的样本

### 4.2 约束满足

- 100% 样本满足 `|x_CO2 + x_O2 + x_N2 - 100| < 1e-6`
- 0% 样本的 `x_N2` 超出 [73.80, 81.97] 范围

### 4.3 状态分层覆盖

- 四种状态均有代表性样本
- 无状态占比 > 50%（避免数据不平衡）

### 4.4 可复现性

- 相同 `seed` 产出相同的 condition grid
- 不同 `seed` 产出不同但同分布的 condition grid
