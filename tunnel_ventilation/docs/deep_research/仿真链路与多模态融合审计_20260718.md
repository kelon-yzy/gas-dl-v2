# 掘进通风仿真链路与多模态融合审计：从硬件资料到正式证据

## 摘要

本审计回答三个问题：RQ1，当前仿真是否复现了真实传感器的测量链；RQ2，现有算法是否真正利用多模态互补信息；RQ3，已有实验能否把性能增益归因于多模态，而不是单一强模态、容量增加、数据契约或泄漏。

结论是分层的。当前 `tv3` 足以支持“受控、静止、均匀气体条件下的物理可辨识性、RawDSP 契约和算法消融”；但不足以声称复现掘进通风现场的完整多模态传感链。最大缺口不是再加一个网络，而是缺少通风输运与空间布局、真实器件传递函数、异步采样与通信故障、跨模态共享扰动、设备级漂移和实物校准。算法侧已有 `slow`、`ultrasonic`、`fiber_mic` 分支及 `FiLM/gated` 选项，但正式默认路径是 `slow + ultrasonic` 的物理统计特征与 OOF residual；`fiber_mic` 没有进入正式性能结论，TOF 是主要信息源，TCS 边际，端到端 raw fusion 还没有通过非劣门。因此，当前结果不能写成“多模态融合优势已被充分验证”。

## 1. 研究问题与判定尺度

### RQ1：测量链复现度

判定对象不是“是否有同名数组”，而是以下链路是否闭合：

```text
气体源项/通风场 → 局部组分与温湿压 → 传感器物理响应
→ 模拟/数字接口与采样时钟 → 量化、饱和、丢包、延迟
→ 时间对齐与质量标记 → 可部署特征/模型输入
```

### RQ2：融合机制

分别检查表示、对齐、交互和决策四层：是否保留模态特有信息，是否显式处理不同采样率与时间延迟，是否按质量动态调节模态权重，是否在模态缺失、退化和 OOD 下仍能使用互补信息。

### RQ3：增益归因

只有同时满足“参数/FLOPs 匹配的单模态基线、正确配对优于错配、单模态/两两/全模态消融、独立 OOD 与缺失模态测试、跨 seed 稳定”，才能把增益归因于互补，而不是把多列输入或更大容量误写成多模态协同。

## 2. 证据与方法

本地证据包括硬件资料、`tv3` 仿真与模型源码、配置、正式输出和测试。外部证据采用 `smart-search deep` 生成研究计划，主搜索接口因区域 403 不可用，按工具规约改用 Exa 检索并对关键页面执行 `fetch`；因此外部结论只采用已抓取正文或摘要支持的强度。

硬件基准来自 [传感器硬件资料整理](../references/传感器硬件资料整理.md)：该文档标题和系统概述实际面向“掺氢天然气管道”，包含 TCS205、TraceGas-HC-NDIR、TraceGas-NDIR-CO2、SHT45、PSC200K、LB-FOM-D30L、ADS8684/8688、NI USB-6453，而不是专门为掘进通风 `CO2/O2/N2` 场景编写。这个范围不一致本身就是一个需要冻结的契约问题。

## 4. 当前仿真链审计

### 4.1 场景、输运与空间层：不足以代表掘进通风

`tunnel_ventilation_schema.py:33-42` 把输入组织为 7 个 slow 通道和 `CO2/O2/N2` 三个显式目标；`conditions.py:5-17, 108-134` 采用二维 LHS，N2 由总量闭包得到。`slow.py:150-186, 290-315` 先构造标准新鲜空气和 target，再对组分、slow equilibrium 和通道值做线性 blend；`T_C/P_MPa/H_RH` 在 `slow.py:194-198` 直接写成每条序列的 base 值，`L_m` 同时作为声程和 piston 位置。

因此当前模型是“均匀气体 + 单一声程 + 阶段曝光”的观测代理，不是通风场数字孪生。没有源项位置、风速/方向、对流-扩散、湍流、局部回流、断面分布、多点传感器、障碍物和传感器安装姿态。项目自己的 `tv3_identifiability.json` 已将 `flow_projection` 标记为 `not_represented` 且 `blocks_go_verdict=true`，所以不能把当前结果外推为现场风流条件下的复现。

矿井排放研究也显示，测量频率和时机会带来显著的时间偏差；这支持把“事件时机、空间位置和采样率”作为独立 OOD，而不是继续增加同一均匀序列的样本量。

### 4.2 慢通道：有响应代理，但不是器件链

`slow.py:318-378` 对 `V_NDIR_CO2` 和 `V_TCS` 使用随机化 rise/decay time constant、random walk、drift slope 和 Gaussian noise，这是有价值的第一层动态代理；但它们作用在已算出的 equilibrium 值上，而不是从真实光路、热导芯片和通信输出逐级生成。缺失项包括：

- NDIR 预热、T90、自然扩散、疏水膜、污染/凝露、状态码、UART 低频采样和零/span 校准；
- TCS205 膜温控制、扩散腔、流速隔离、ADC 电路、气体交换与周级漂移；
- SHT45 的 2–4 s 响应、迟滞、I2C/CRC、加热器和长期漂移；
- 跨模态共享温湿压/流场扰动、设备级增益/偏置、跨日期标定和老化。

这意味着当前 `V_NDIR_CO2`、`V_TCS` 更接近“物理量经过经验响应和独立噪声后的数值通道”，不是从硬件接口可复现的观测。

### 4.3 超声 PSC200K：链路覆盖最好，但仍是 proxy

`waveforms.py:20-36, 47-67` 明确记录 200 kHz、1 MS/s、20-bit、固定系统/电缆延迟、3 μs trigger jitter 和二阶谐振带通 proxy；`waveforms.py:220-286` 由声速、衰减、延迟和分数采样位移生成脉冲，加入噪声、裁剪、质量分数和 accepted 标记。这一层已覆盖“传播 → 回波波形 → 量化”的骨架。

但 `transducer_bandwidth_hz=20 kHz` 的注释明确写着“datasheet 未给出、按典型约 10% 估计”，不是 PSC200K 实测传递函数；没有双向 TOF、流速/Doppler、声程边界多径、安装耦合、空间湍流或通道间时钟误差。Bates 等的联合流量/组分仪器正是通过双向声速、压力、温度和 CFD 几何来解耦流动影响，因此当前单向 `flow=0` 代理只能支撑静止气体可辨识性。

### 4.4 光纤声学：接口存在，物理真实性不足

`waveforms.py:85-121, 289-371` 提供探头压力场、固定反射、光链路损耗、相位到电压、噪声和饱和，说明代码并非完全忽略 `fiber_mic`。但默认 `optical_wavelength_nm=1550`，而硬件资料给 LB-FOM-D30L 为 1310 nm；代码仍使用 `fiber_interferometric_proxy_v1` 与 `linear_phase_demodulation_proxy_v1`，没有 3–300 kHz 实测幅频/相频、解调机箱滤波、耳机输出链、探头安装耦合和独立时钟。更重要的是，`tv3_d2b` 正式 RawDSP 配置只列 ultrasonic physics arrays，`ec_msw_e1.py:215-216` 直接拒绝 `fiber_mic_channels != 0`，因此该模态尚未形成正式性能证据。

### 4.5 ADC、通信与时间层：结构性缺口

当前波形以整数数组和 per-timestep scale 写入，能表达量化和饱和；但 slow、ultrasonic、fiber_mic 在 `slow.py:202-249` 同一 timestep 内同步生成。没有 UART ≤1 Hz、SHT45 秒级采样、NDIR T90、WAV/DAQ 双时钟、通道 skew、丢包、重复帧、时间戳漂移或异步重采样。`augmentation.py` 主要对拼接后的 NTC 整体施加窗口、统一位移、幅度缩放和噪声，不能替代按模态独立的时钟/丢包/故障模型。

## 5. 算法与正式证据审计

### 5.1 架构能力：有多分支，但默认不是跨模态对齐

`cnn1d_tcn_fusion.py:241-277` 为 slow、ultrasonic、可选 fiber_mic 分别建立 encoder；默认 `fusion_mode="concat"`，可选 `film_gate`。`forward` 在 `:422-474` 先分别编码，再直接拼接，之后进入共享 TCN 和 `last/mean/max` 池化。`FiLM/gated` 是条件调制与逐分支门控，不是跨模态时间对齐或 cross-attention；没有 timestamp/age、质量条件或异步采样的显式输入。

多模态时间序列综述 Jiang et al.（arXiv:2503.13709）将 fusion、alignment、transference 分开，并明确指出异构分布、modality gap、时间错位和噪声会妨碍互补信息利用。由此，当前架构应被命名为“中间层 concat / 条件门控基线”，不能因为存在 `FiLM` 类名就称为已完成的动态多模态融合。

### 5.2 正式默认路径主要是超声统计 + slow，不是全硬件多模态

`tv3_d2b_raw_dsp_ridge.json` 与 `tv3_d2b_oof_ridge_residual_mlp.json` 的输入是 7 个 slow 通道加 ultrasonic RawDSP physics arrays（TOF、peak、sound speed、correlation peak、SNR、quality、accepted），再做 phase/early/sequence statistics；没有 fiber_mic，也没有 NDIR/温湿度的独立硬件时间轴。B7 的 OOF residual MLP 仅在同一特征契约上学习残差。

因此 B7 相对 B1 在重复 split 上出现约 `+0.14` 到 `+0.26` 的 test O2 R2 增益，说明 residual head 对当前 RawDSP 契约有价值；它不能单独证明“多传感器互补”。正确归因需要至少比较：slow-only、ultrasonic-only、两两组合、全模态、参数匹配单模态、随机错配和质量/时间干预。

### 5.3 正式结果已经暴露主导模态与表示瓶颈

- `outputs/README.md:26`：E1r 三 split 的 frame fidelity 虽通过，但冻结 sequence embedding 相对 B1 的 O2 ΔR2 为 `-0.4118 / -0.4461 / -0.3689`，判定 `b1_parity_failed`；仅补 peak 坐标不足以保留有效信息。
- `outputs/tv3_ec_msw/e1d_s20260704/verdict.json`：加入 calibration、correlation peak、PSR、SNR 后的 compact set 通过 parity，说明有效信息更接近“校准 + 相关质量 + SNR”，而不是端到端波形自动学出新的跨模态关系。
- `outputs/README.md:17,26`：分组 bottleneck 为 `grouped_failed`；E2/attention 路线被禁止；历史 `tv3_tcn_multimodal*` 被归档且注明 O2 未学到。
- `fiber_mic` 没有正式 OOD、缺失和性能矩阵；因此不能给它分配已验证的互补贡献。

这些结果更支持“TOF/RawDSP 是当前主导观测，slow 负责校准和环境上下文，TCS 边际较小，fiber 尚未证实”，而不是“所有模态已被模型充分利用”。

### 5.4 缺失模态、退化和 OOD 证据不够

当前测试大量检查“缺文件时应报错”，这证明数据契约严格，但不是部署期缺失模态鲁棒性。没有完整/单缺失/多缺失、随机缺失/连续块缺失、偏置/漂移/饱和/低 SNR/错位/冲突配对矩阵，也没有模态质量驱动的拒绝或可靠性校准。

Ma et al.（CVPR 2022, DOI `10.1109/CVPR52688.2022.01764`）在多个基准中显示，严重缺失时多模态性能可低于单模态，且 early/late 融合没有跨数据集通用最优策略。SimMMDG（NeurIPS 2023, arXiv:2310.19795）则用模态共享/特有分解、跨模态翻译、跨域和缺失消融来验证互补。它们不能直接替代本项目实验，但给出了本项目尚缺的证据类型。

## 6. 综合判断

| 维度           | 当前等级 | 可以声称                          | 不能声称                            |
| ------------ | ---- | ----------------------------- | ------------------------------- |
| 物理场          | 不足   | 均匀、静止、阶段曝光代理                  | 掘进通风现场输运/空间复现                   |
| NDIR/TCS/SHT | 部分   | 经验通道、慢响应和简单漂移                 | 器件级 transfer function、通信/标定/凝露链 |

| 归因证据         | 不足   | B7 对当前 RawDSP 契约有残差增益         | B7 增益来自全硬件多模态协同                 |

## 7. 优先级与可证伪验收

### P0：先修仿真契约

1. 将项目拆成两个明确 schema：`tv3 tunnel ventilation CO2/O2/N2` 与硬件资料对应的 `H2/CH4/CO2`。若硬件资料只是参考，不得继续用它作为 `tv3` 的完整实物依据。
2. 增加流速/方向、源项位置、断面空间、对流-扩散/湍流、局部温湿度和多点传感器；至少做 `flow`、位置和布局 holdout。
3. 为每个器件建立 `transfer_function/profile_id`：NDIR 的预热/T90/采样/状态码，TCS 的热与扩散双时间常数，SHT 的 t63/迟滞/漂移，PSC 的实测频响/延迟，fiber 的实测幅频/相频/解调链。
4. 引入真实时间轴：slow 的秒级采样、波形的 MHz 采样、UART/I2C/DAQ 时间戳、丢包/重复帧/时钟漂移/通道 skew，并保留每模态 `timestamp`、`age`、`quality`。
5. 将随机化改为共享扰动 + 设备/日期/校准会话随机效应；当前 `calibration_status="pending"` 的 proxy 不得作为实物等价。

### P1：再做融合归因

1. 固定参数和计算预算，完成 `slow-only / ultrasonic-only / fiber-only / pairwise / all` 矩阵；正确配对与随机错配必须有显著差异。
2. 做模态级独立 dropout、块缺失、SNR/偏置/漂移/饱和/错位/冲突；比较 concat、late fusion、FiLM-gate、cross-attention/temporal alignment。
3. 检查 modality collapse：单模态遮挡性能、每模态梯度/表示贡献、gate 与质量的关系、共享/特有表示分解。
4. 每个 selector 报告组分 R2/MAE/P90、窄 O2 bins、worst-group、OOD AUROC/FPR95、coverage、interval width、rejection rate 和 3–5 个 seed 的均值/标准差。

### P2：实物闭环

用风洞/气室/短期现场矩阵校准波形和 slow 通道：至少覆盖 O2/CO2 档位、温湿压、流速、声程、换能器对、日期、气瓶/配气批次；以参考分析仪和独立时间戳验证 sim-to-real，而不是用少量实测数据掩盖仿真域差。

## 8. 结论（逐一回答 RQ）

**RQ1：是否充分复现？** 不充分。它已复现受控静止条件下的组分到声速/衰减/单向 TOF/经验慢通道/整数波形的骨架，但没有复现掘进通风最关键的输运、空间、器件传递函数、异步接口、共享扰动和现场校准。最准确的名称是“静止均匀气体的多观测代理 benchmark”。

**RQ2：是否充分利用多模态优势？** 还没有。代码有多分支和可选门控，但正式默认路径主要消费 slow + ultrasonic RawDSP；没有显式跨模态时间对齐、模态缺失/退化训练或质量条件可靠性权重。`fiber_mic` 尚未进入正式证据，端到端 raw fusion 和 grouped bottleneck 也未通过门。

**RQ3：增益能否归因于互补？** 不能。B7 的稳定增益说明 OOF residual 对当前 RawDSP 特征有效，不等价于多硬件模态协同。完成 P0 的链路/时间/故障建模，再按 P1 的参数匹配、错配负控、模态消融和 OOD 协议，才有资格把增益写成互补信息利用。

## Tool Calling Brief

- 工具：本地 `rg`、PowerShell 只读读取、`smart-search deep`、`smart-search exa-search`、`smart-search fetch`。
- 原因：建立本地代码证据链，并对硬件测量学与多模态融合结论做外部交叉核验。
- 输入摘要：硬件 Markdown、`tv3` 仿真/模型/配置/输出、NDIR/超声/多模态融合/Sim2Real 检索词。
- 结果概览：本地证据支持“静止均匀气体代理 + RawDSP/OOF 默认路径”；外部证据支持必须显式建模动态响应、异步/缺失/错位、流动解耦和实物校准。主搜索接口因区域 403，外部检索采用 Exa + fetch，并已在结论中降低未直接对应本型号的规格证据强度。
