## 一、为什么需要一条新计划

MRS-2 已经证明，多频声速、衰减、湿度和压力观测能把联合费舍尔秩（Fisher rank）从 1 提高到 3--5。信息维度增加了，但信息强度仍然不足：登记噪声下，最佳观测臂的窄窗 O2 最大 P90 约为 4.03 vol%。MRS-6 又确认，K=4 与 K=8 的差异小于 1%，继续增加相似频点几乎没有收益。当前误差下限主要受飞行时间（time of flight, TOF）、温度、声程、幅度标定和前向模型误差共同限制。

2026-07-25 的业务决策已把 0.4 vol% 从强制门降为参考线。最低成本候选变成 `obs-cfreq` K4、TOF 标准差 0.5 μs、温度先验 0.1 K，对应最大 / 中位 P90 约 1.51 / 1.23 vol%。这给出了现实起点，却没有回答三个问题：固定 K4 是否已经是成本约束下的较优设计；现有解析求解距离统计下界还有多远；算法给出的不确定度能否相信。

因此，新计划不从“换什么网络”出发，而是按以下因果顺序推进：

```text
前向模型可信度
      ↓
测量条件是否真的增加目标信息
      ↓
确定性求解器能否充分利用已有信息
      ↓
学习型求解与后验是否带来可验证增益
      ↓
台架、高保真或真实配对证据是否支持进一步扩展
```

只要上游门没有通过，下游模型就不启动。这样可以避免用更复杂的网络掩盖硬件或前向模型问题。

## 三、研究问题与可证伪假设

### 3.1 研究问题

1. 在相同频点数、总能量、总时长和硬件频带下，能否找到比固定 K4 更稳健的测量设计？
2. 在观测不变时，变量投影能否比普通高斯--牛顿法更稳定地消除延迟、声程和幅度等干扰参数？

## 四、统一理论框架

### 4.1 观测模型

把第 `s` 个测量条件下的观测写成：

```text
y_s = F(theta, eta_s; d_s, psi) + delta(z_s, d_s) + epsilon_s,
epsilon_s ~ N(0, Sigma_s).
```

- `theta` 是三组分目标；
- `eta_s` 是该条件下的温度、湿度、声程、延迟和增益等干扰参数；
- `d_s` 是频率、功率、停留时间、压力和湿度等实验设计变量；
- `psi` 是不同测量共享的物理参数；
- `delta` 是前向模型没有表示的偏差；
- `Sigma_s` 是逐频独立噪声与跨频共模噪声组成的协方差。

目标参数的有效费舍尔信息由舒尔补（Schur complement）给出：

```text
I_eff
  = I_theta,theta
  - I_theta,eta (I_eta,eta + Lambda_eta)^(-1) I_eta,theta.
```

这个公式决定了本计划的阶段顺序。改变实验设计 `d` 或噪声协方差 `Sigma`，有机会改变信息下限；消去干扰参数或更换求解器，只能提高估计效率；模型偏差 `delta` 没有被控制时，雅可比矩阵本身可能就是错的。

### 4.2 三类增益必须分开报告

| 增益      | 含义                                             | 对应阶段                     |
| ------- | ---------------------------------------------- | ------------------------ |
| 信息增益    | `I_eff` 增大，克拉默--拉奥下界（Cramér--Rao bound, CRB）降低 | MEI-2、MEI-5、条件成立时的 MEI-7 |
| 估计增益    | 在同一 `I_eff` 下更接近统计下界                           | MEI-3、MEI-4、MEI-6        |
| 模型可信度增益 | 修正错误的前向梯度或扩大有效适用域                              | MEI-1、MEI-7              |

任何报告都不得把估计增益写成信息增益，也不得把仿真内部校准写成现场可信度。

## 六、评价门如何冻结

### 6.1 不再设任意绝对精度门

新计划保留三条参考线，但不把它们混成通过条件：

- 历史参考：0.4 vol%；
- 低成本固定 K4 参考：最大 / 中位 P90 约 1.51 / 1.23 vol%；
- 极端全栈参考：最大 P90 约 0.287 vol%。

实验是否继续，必须分开判断数值可分辨性和实践意义。数值保护带记为 `delta_numerical`：

```text
delta_numerical = max(
  两倍有限差分步长扰动造成的 P90 相对变化,
  两倍独立新进程复算造成的 P90 相对变化,
  优化器相对容差
).
```

实践等价界单独记为 `delta_practical=0.02`。它高于 MRS-6 已观察到的 K4 与 K8 小于 1% 差异，用来防止把工程上无意义的小差异写成算法突破；它不是数值误差。SVD 容差只影响离散秩判定，不进入使用普通逆矩阵的 CRB-P90，因此单独报告 `1e-7 / 1e-6 / 1e-5` 三档容差下的秩区间与奇异值谱，不混入 `delta_numerical`。离散秩结论只有在三档容差下都成立时才能作为门；否则只能作为诊断。MEI-0 必须按噪声口径用实际复算结果冻结 `delta_numerical`，并独立冻结 `delta_practical`。

### 6.2 四组正式门

1. **信息门**：相同成本下，稳健设计在冻结有限登记集合中的最坏 P90 改善必须先超过 `delta_numerical`，并进一步超过 `delta_practical`。有限登记信息审计报告精确配对差值和数值界，不使用没有抽样总体定义的 bootstrap。
2. **求解门**：主指标固定为测试集和分布外条件下的 O2 配对 P90。新求解器相对冻结确定性基线的改善必须超过 `delta_practical`，且分层配对 95% 置信区间下界也必须超过该界；平均绝对误差（MAE）、收敛失败率和最坏组误差均不得退化超过 `delta_practical`。CRB 效率和迭代次数用于解释机制，不能替代主指标。若某阶段只研究数值收敛，必须在 MEI-0 单独登记为数值实验，不得据此声明组分性能增益。
3. **校准门**：50% / 80% / 90% / 95% 后验区间的经验覆盖率必须落在按样本量计算的二项分布 95% 接受区间内；同时报告区间宽度和拒绝率。
4. **机制门**：硬件或多视图机制必须先通过专属负对照，才能把收益归因于共模、多视图或模型偏差约束。

门值、样本量、随机种子和自助法次数全部写入 MEI-0 登记表。正式结果产生后不得回看数据调整。

## 七、执行阶段

### MEI-0：目标、成本和证据登记冻结

本阶段只建立契约，不运行正式算法比较。

必须冻结：

- 目标方向：O2 窄窗误差，同时完整报告 CO2、N2 与闭包监控；
- 候选频带：25--200 kHz；基准 K4 为 `{25, 63, 100, 200}` kHz；
- 成本函数：频点数、总声能、总测量时间、RH / 压力切换时间和稳态等待时间，并冻结 D0 可复算成本账本；
- 前向模型族：MRS-1 单弛豫加和基线，以及湿空气 `c_eq`、H2O 参数、耦合弛豫、衍射 / 近场、换能器响应的登记扰动；
- 噪声族：逐频独立、低秩共模、混合协方差三类，但共模情景只作敏感性分析，不能代替台架证据；
- 216 个窄窗点、留出工况、有限差分步长、SVD 容差、跨容差秩报告规则和 `delta_num`；
- 所有阶段的配置摘要和 SHA256。

产物：`model_family_registry.json`、`design_space.json`、`metric_registry.json`、`stage_status.json`。

结论状态：`mei0_registry_frozen` 或 `mei0_registry_incomplete`。后者不允许进入 MEI-1。

### MEI-1：前向可信度包络与偏差方向审计

这一阶段回答“优化的是不是一个过于理想的仿真器”。它不训练自由残差网络。

1. 在 MRS-1 基线上逐项加入已登记的物理扰动或参数包络；无法实现的项保留为 `not_represented`。结构代理与合成偏差只作诊断，**不得**用注释或代理消掉 `not_represented`。
2. 比较各模型族的 O2 目标雅可比方向、**逐点**主角度（报告最大值与预注册分位数）、费舍尔秩和固定 K4 的设计排名。主角门打在逐点统计量上，不得只比较平均雅可比。
3. 构造与目标雅可比**数学上**平行、正交和混合的合成偏差（观测空间投影后再映射到 `c_f`），检查稳健设计与求解器在最不利偏差下是否仍成立。
4. 设计排名必须按 `delta_num` 做相对等价类并列；若全设计落在等价带内，记为排名不可分辨，不得把浮点 Spearman=1 写成稳定最优设计证据。
5. 正式门使用完整窄窗网格（216 点）；stride 抽样只允许冒烟。
6. 若有可用的 COMSOL 局部声学或其他高保真子集，只作为独立留出模型族；不得自动恢复 COMSOL G2+。

通过条件：设计排名在 `delta_num` 可分辨前提下跨模型族稳定，主要瓶颈稳定，且不存在未表征项足以翻转结论。结论状态为 `mei1_forward_envelope_supported`。

若关键排名随合理模型扰动翻转，或存在仍具阻断作用的 `not_represented` 项无法证明不翻转，输出 `mei1_inconclusive_forward_model`，停止推进并先补前向物理。若没有物理 blocker、稳定性翻转或执行问题，但全部 K4 设计仍位于 `delta_practical` 内，则输出 `mei1_fixed_k4_retained`，冻结 D0 K4、跳过 MEI-2 并进入 MEI-3；不得通过事后降低实践界制造设计增益。

### MEI-2：稳健目标导向 c 最优设计

本阶段只计算前向灵敏度、有效费舍尔信息和成本，不生成波形。

| 设计臂 | 设计                      | 作用                     |
| --- | ----------------------- | ---------------------- |
| D0  | 固定 K4 `{25,63,100,200}` | MRS-6 低成本基准            |
| D1  | 等成本随机 K4                | 判断优化是否优于随机选点           |
| D2  | 中心工况局部 c 最优 K4          | 暴露只优化中心点的脆弱性           |
| D3  | 跨工况、跨模型族稳健 c 最优 K4      | 主候选                    |
| D4  | 2--3 点粗测 + 条件 K4 定向测量   | 当前 D0 时间预算下不可行，只作自适应诊断 |
| D5  | 等总能量 K8                 | 等能量但不等时，只作冗余诊断         |

目标函数为：

```text
min_d  max_xi [c^T I_eff(d, xi)^(-1) c]
       + lambda_time * Time(d)
       + lambda_energy * Energy(d).
```

其中 `xi` 同时覆盖工况和模型族。低 RH、高压力死角必须进入约束，不能只在结果图中附带展示。D4 的停止规则也必须计入控制和等待成本。

MEI-0 冻结的 D0 成本为相对声能 `0.000375238095238095 s`、墙钟时间 `0.23 s`。D4 即使把 pilot 复用于总 K4，含控制开销仍需 `5.23 s`；D5 经功率缩放可等能，但墙钟时间为 `0.47 s`。因此当前只有 D1--D3 可进入等成本信息门，D4/D5 不得据此声称信息优势；若未来改变硬件时序预算，必须先新建 MEI-0 冻结，不能在 MEI-2 现场改门。

通过条件：当前只允许 D3 在相同总成本下通过信息门，并且在未参与优化的工况与模型族中仍不退化。D4/D5 只报告诊断结果，不参与通过判定。D3 通过后冻结为 `mei2_information_design_supported`；否则输出 `mei2_fixed_k4_retained`，保留固定 K4。未来若要恢复 D4，必须先按新的硬件时序预算重冻结 MEI-0。

### MEI-4：后验基线与覆盖率审计

> 执行细化：[MEI-4 执行计划](tv3_mrs_ei_mei4_execution_plan.md)（C0 契约冻结 → C1 机制审计 → C2 冻结数据评价 → C3 蒙特卡洛授权停点 → C4 条件性 CC-SBI → C5 裁决）。

准入：B5 的 `allowed_next_stage=null` 和 `no_mei4_transition=true` 表示本阶段尚未启动。运行前必须先冻结独立、版本化的 MEI-4 执行契约：记录 B4/B5 父 manifest、可用数据范围与任何新增仿真授权、S1 输入白名单及方案 A 标定先验、划分和随机种子、后验方法顺序、统计门和 append-only 输出目录。该契约不得重写 B4/B5 freeze，也不得把 B4 的稀疏仿真授权推定为新的后验训练数据授权。

本阶段仍使用冻结前向模型和设计，不生成正式波形数据。冻结 S1 是正式确定性基线；S2 只能作为条件线性结构的受控后验比较路径，不能替代 S1 成为学习型后续基线。比较：

1. S1 全参数似然的拉普拉斯近似，并以 S2 剖面似然拉普拉斯近似作登记的受控比较；
2. 参数自助法或重要性采样后验；
3. 覆盖率校准的基于仿真后验推断（CC-SBI），仅在前两种方法表现出多峰、边界偏差或计算成本问题时启动。

CC-SBI 使用置换不变集合编码器处理可变频点，输出满足单纯形约束的三组分后验。训练时联合采样组分、干扰参数、实验设计和模型族。评价必须包含基于仿真的校准（simulation-based calibration, SBC）秩直方图、经验覆盖率、负对数似然（NLL）、连续秩概率评分（CRPS）、后验预测检验和分布外覆盖率。

若覆盖率正确但区间很宽，结论只能是“观测信息不足”。不得通过温度缩放或缩窄先验制造高精度。SBC、经验覆盖率、NLL、CRPS、后验预测检验和 OOD 覆盖率必须在同一冻结划分上报告；不能只以区间宽度或点估计误差宣布通过。结论状态为 `mei4_posterior_calibrated`、`mei4_deterministic_posterior_retained` 或 `mei4_uncertainty_failed`。

### MEI-5：同步多正弦与跨频协方差台架门

前置条件是具备参考负载、重复采集能力、同步激励链路和可核对的总能量。没有硬件时，本阶段保持 `blocked_by_hardware_evidence`，不得用有利的仿真相关性代替实测。

执行顺序：

1. 在空腔或参考负载上重复采集顺序 K4，估计跨频误差协方差；
2. 用对角、低秩共模和混合协方差模型做留出重复的似然比较；
3. 只有共模方差的置信区间排除 0，且低秩模型在留出重复上优于对角模型，才生成低峰均比多正弦；
4. 在总声能、总时长和换能器工作区间相同的条件下比较顺序 K4 与同步 K4；
5. 报告目标 CRB、信噪比、互调、峰均比、克拉默斯--克勒尼希残差和设备温升。

如果共模证据不成立，输出 `mei5_independent_noise_retained`；如果共模成立且等成本目标信息通过信息门，输出 `mei5_multisine_supported`。互调或独立噪声主导时停止多正弦分支。

### MEI-6：独立谱学基准与学习型求解协议

只有 MEI-2 至少证明一种设计优于固定 K4，或者 MEI-3 明确证明确定性求解仍存在可学习的稳定误差，才允许建立本阶段。它使用新数据模式 `tunnel-ventilation-mrs-ei-1` 和新基准 `tv3-mrs-ei-*`，不复用 MRS-3 名称。

最低数据形态是稀疏谱观测，不默认生成全波形：

```text
frequency_hz, c_observed, alpha_observed(optional),
quality, design_id, view_id, device_profile_id,
T_C, P_MPa, H_RH, L_m
```

若 MEI-5 通过，再增加复传递函数和跨频协方差字段。任何真值谱只进入审计数组。

正式模型矩阵：

| 模型            | 作用                     |
| ------------- | ---------------------- |
| H1-new        | 未来可选的独立解析方法；不得称为历史 S0  |
| GN            | 全参数高斯--牛顿法             |
| VarPro        | MEI-3 冻结确定性求解器         |
| NP-VPNet      | 只学习预条件、阻尼、异方差权重或小型残差先验 |
| CC-SBI        | 只在 MEI-4 获准时进入         |
| 黑盒 MLP / ARGD | 容量匹配负对照，不承担创新声明        |

NP-VPNet 每一步都必须调用同一个前向模型和数据一致性项。若它不优于确定性 VarPro，就输出 `mei6_learned_solver_no_gain`，不增加展开层数或主干网络。

### MEI-7：高保真 / 真实数据条件分支

本阶段同时容纳正交模型偏差和共享潜变量，但二者不能互相替代。

#### 7.1 正交模型偏差

前置是独立的高保真或真实标定数据。比较无偏差模型、自由残差和正交模型偏差：

```text
Phi_perp = [I - J(J^T W J)^(-1)J^T W] Phi.
```

正交约束相对于 O2 / CO2 目标雅可比定义，防止残差网络吞掉组分灵敏度。若真实偏差主要沿目标方向，必须扩大不确定度或补充物理，不能强制投影后宣称成功。

#### 7.2 共享潜变量多视图

前置是同一 `mixture_id` 在组分稳定窗口内的多频、双湿或双压配对。组分潜变量共享，T、RH、P、延迟和增益按视图独立。必须执行错误配对、时间打乱、单视图和屏蔽设计标签四个负对照。

只有正确配对相对全部负对照，在测试集、分布外条件和后验预测检验上都改善，才能输出 `mei7_multiview_supported`。错误配对也改善时，应判为泄漏或普通正则化效应。

### MEI-8：综合判定与路线收尾

最终只允许以下结论状态：

| 结论状态                                | 含义                                 |
| ----------------------------------- | ---------------------------------- |
| `mrs_ei_information_gain_supported` | 新测量设计在登记模型族和留出工况中稳定降低目标下界          |
| `mrs_ei_estimation_gain_only`       | 信息下限未变，但求解器或后验更接近下界、校准更可信          |
| `mrs_ei_fixed_k4_retained`          | 优化设计没有越过数值保护带，保留 MRS-6 固定 K4 粗监测候选 |

| `mrs_ei_hardware_evidence_required` | 共模、多正弦或真实配对机制缺少硬件证据                |
| `mrs_ei_simulation_only`            | 仿真域内结果成立，但不能形成现场能力声明               |

任何状态都必须同时给出相对 0.4 vol% 参考线、相对固定 K4 粗精度参考和对应成本。不得只给单个最优数字。

## 八、数据划分、泄漏控制与统计协议

1. 以 `mixture_id` 为组分主键；同一混合物的多个视图不得跨训练集和测试集。
2. 模型族、设计条件、环境边界和设备配置分别建立分布外划分；联合极端条件单列报告。
3. 相邻设计点不能随机拆分后伪装成分布外泛化。
4. 自适应设计只使用当前样本已经观测到的信息，不能读取真值组分或未来视图。
5. 每个正式比较至少使用 3 个数据划分随机种子和 3 个训练随机种子；确定性求解器也要报告多初值稳定性。
6. 配对差值使用分层自助法，层级至少包含混合物和设计条件；同时报告效应量与 95% 置信区间。
7. 多重假设按阶段族控制，不把六个假设的最佳结果挑出来单独报告。
8. 泄漏负对照触发后，冻结该次运行，完成来源审计前不得引用任何性能指标。

- 变量投影解与联合最小二乘解在可分离测试问题上相同；
- 不可分离参数不会被错误放入线性块；
- 单纯形投影保持非负和为 100%；
- 共模 / 独立协方差的合成数据可以被正确区分；
- 缺失来源、哈希、数组或不允许的真值输入时显式失败。

### 10.2 最小执行顺序

```text
MEI-0 登记冻结
  → MEI-1 前向包络
  → MEI-2 稳健设计
  → MEI-3 确定性求解
  → MEI-4 后验审计

硬件证据具备后：MEI-5
MEI-2/3/4 至少一项通过后：MEI-6
高保真或真实配对数据具备后：MEI-7
最后统一进入 MEI-8
```

首期 MEI-0 至 MEI-3 不生成正式波形、不使用 GPU，也不需要恢复 F 线或 COMSOL G2+。

## 十一、停止条件

1. MEI-1 显示合理前向扰动会翻转设计排名：停止实验设计优化，先补物理。
2. MEI-2 没有设计越过 `delta_num`：冻结固定 K4，不继续两阶段自适应或增加频点。
3. MEI-3 变量投影不适用或不优于全参数高斯--牛顿法：保留确定性基线，不启动 NP-VPNet。
4. MEI-4 覆盖率失败：不得用该后验做拒绝策略或精度声明。
5. MEI-5 没有实测共模证据：不生成有利相关噪声，不启动多正弦模型训练。
6. MEI-6 学习型模型不优于确定性 VarPro：停止增加展开层、注意力或变换器主干。
7. MEI-7 缺少高保真 / 真实数据：OMD-GreyBox 只能做合成证伪，不能形成仿真到真实结论。
8. 错误配对或时间打乱仍带来多视图增益：判泄漏，停止该分支。
9. 任一结果只在验证集或单一模型族成立：判未通过。
10. 新提案试图改写历史结论、恢复 MRS-3、回退主键语义或绕过来源登记：直接拒绝。

### 13.2 下一次重冻结前必须解决的问题

以下问题是 2026-07-27 MEI-1 重跑后的新增评审结论，不回写或改写既有 MEI-0 / MEI-1 freeze。涉及门值、数据模式或阶段依赖的修改必须形成新的版本化冻结。

1. **统一主决策噪声口径。** 计划把 TOF 标准差 `0.5 μs`、温度先验 `0.1 K` 的低成本 K4 作为现实起点，但当前 `delta_num` 与 MEI-1 排名使用 `registered_mrs2` 的 TOF `3 μs`、温度先验 `1 K`。下一次 MEI-1 必须冻结主口径，并至少在两套噪声预算下报告设计等价类、瓶颈和排名稳定性；不得用较差噪声预算下的不可分辨结论直接代表低成本候选。
2. **拆分数值误差与实践等价界。** `delta_numerical` 只由 FD 收敛、独立进程复算和适用的优化器容差确定；`delta_practical` 单独表达最小有意义增益。若通过条件要求改善超过 `delta_practical`，则配对置信区间下界也必须超过该界，而不是只要求大于 `0`。
3. **补齐统计估计量和重采样总体。** 对 216 个确定性登记工况、有限模型族上的最坏 CRB-P90，不得直接套用未定义总体的 bootstrap。MEI-0 必须分别冻结信息门与学习型实验的估计量、随机单位、分层单位、样本量、重采样方法、同时置信规则和阶段内多重检验方法；若目标是有限登记集合上的确定性最坏值，应报告精确差值与数值界，不伪造抽样置信区间。校准门还必须报告分组 / 条件覆盖率和拒绝后的选择条件覆盖率。
4. **把驱动预算与实际声能分开。** 当前成本账本只能证明频点数、墙钟时间和输入驱动代理配平。F5 换能器幅相响应未标定前，任何候选不得声称等入射声能；应将字段改名为驱动预算，或加入逐频实测声功率、工作区间和不确定度后再建立实际声能账本。
5. **使 VarPro 与观测 schema 一致。** 若 MEI-3 要消去延迟、声程和增益，数据模式必须保留足以表达该结构的原始 TOF、幅度 / 相位或复传递函数及其协方差，不能只保留 `c_observed` 和可选 `alpha_observed`。逐频标定偏移必须定义跨样本、设备和视图的共享层级及独立先验，禁止为单次 K4 配置四个无约束自由偏移。
6. **消除 `raw3` 与单纯形投影冲突。** 正式点估计当前要求直接 `raw3`、不强制闭包，而 MEI-4 与测试清单又要求三组分后验或输出投影到和为 100% 的单纯形。下一次冻结必须明确点估计与后验各自的参数化、公开输出语义和闭包监控方式；不得在训练、推断或评价中静默重归一化。**2026-07-29 处置**：B0 已关闭该问题。共享前向对组分整体缩放精确不变，`raw3` 缩放雅可比在三档容差下秩恒为 2，零方向与组分向量 `|cos|=1`。当前干基 schema 将非负与 `sum=100%` 登记为物理定义域，总量不再作为第三个待估自由度；S1--S3 在二维正交切空间联合更新三列输出，不回填 N2，不做静默归一化或求解后投影。最终处置见 [MEI-3 后续执行计划](tv3_mrs_ei_mei3_execution_plan.md) §11.4。
7. **建立显式阶段状态转移表。** MEI-3 允许 `mei3_varpro_not_applicable`，因此 MEI-4 和 MEI-6 不能无条件引用 S2 / VarPro。必须冻结“MEI-3 通过则使用 S2，否则使用 S1”的基线选择，并统一 MEI-6 到底要求 MEI-2、MEI-3，还是 MEI-4 中哪些状态。不存在的求解器不得出现在强制比较矩阵中。**2026-07-29 处置**：Phase A 已证明结构适用，B2 已输出 `mei3_solver_core_verified`，所以“不适用”不再是当前后续分支；B4 正式比较已输出 `mei3_full_parameter_baseline_retained`，后续基线保留冻结 S1。
8. **把高压力域前移到 MEI-1。** 当前 216 点正式网格只有 `0.101325 MPa`，而 MEI-2 要求覆盖最高 `0.709 MPa` 的低 RH、高压力死角。压力扩展域的前向梯度、参数有效性和模型包络必须先经 MEI-1 审计，不能在未经审计的外推域上做稳健设计优化。

### 13.4 当前三个阻断项的通俗解释与验收边界

当前阻断不是程序算错，而是现有证据还不能证明“按当前前向模型选出的频率，换到真实装置和高压力环境后仍然有效”。三个阻断项彼此独立，必须分别关闭。

#### 13.4.1 F2–F5 未表征

`not_represented` 表示当前只有类别登记或人为代理，没有足以限定真实偏差大小的来源证据。代理扰动可以用来做压力测试，但不能代替正式模型族。

| 模型族         | 通俗含义                              | 当前缺口                                   | 清除阻断所需的最低证据                                                              |
| ----------- | --------------------------------- | -------------------------------------- | ------------------------------------------------------------------------ |
| F2 H2O 弛豫参数 | 水蒸气会改变弛豫频率、强度、声速和衰减               | 当前 H2O 参数仍是未验证 proxy                   | 可追溯文献或独立数据；参数定义、单位、上下界及语义；覆盖温度、湿度、压力、频率范围；实现或 holdout 路径；证据 SHA256       |
| F3 耦合弛豫     | O2、N2、H2O 等弛豫过程可能相互影响，不一定能简单相加    | 当前 5% cross-mix 只是假设                   | 共享前向模块中的可追溯耦合实现，或独立数值参考形成的 holdout；零耦合退化测试、梯度测试和适用域说明                    |
| F4 衍射 / 近场  | 管道、换能器孔径和安装几何会改变传播时间、相位与幅度        | 当前代理没有绑定实际几何和可信误差范围                    | 适用几何和 25–200 kHz 下的解析包络，或已存在且获授权的独立高保真子集；必须报告 TOF / 相位 / 幅度偏差及收敛证据       |
| F5 换能器响应    | 不同频率经过真实发射与接收链路后会有不同幅度、相位、群延迟和声功率 | 当前只有衰减 ripple 代理，`obs-cfreq` 看不到真实设备链路 | 已有台架标定、带不确定度的厂商幅相曲线或独立设备数据；覆盖设备、频率、工作区间及温压影响；没有证据时必须保持 `not_represented` |

任一模型族只有同时具备非空引用、`implementation_or_holdout_path`、真实存在的 `evidence_path`、匹配的 `evidence_sha256`、有物理含义的 `parameter_or_bias_bounds` 和 `bound_semantics`，才允许改为 `represented_traceable` 或 `independent_holdout_available`。不得用任意百分比代理、注释或“代理未翻转排名”清除阻断。

当前六个候选频率任选四个，共 15 个 K4。它们在数值上可以排序，但工程差异很小：

| ------------------------ | --------------- | ------------:| ---------------:|
| 低成本                      | 环境 216          | 0.758%       | 0.330%          |
| 低成本                      | 压力 216 / 正式 432 | 0.456%       | 0.148%          |
| `registered_mrs2_stress` | 环境 216          | 0.712%       | 0.170%          |
| `registered_mrs2_stress` | 压力 216 / 正式 432 | 0.673%       | 0.200%          |

这些差异远大于 `delta_numerical`，所以不是浮点误差；但全部小于预注册的 `delta_practical=2%`，所以 15 个设计仍属于同一个实践等价类。当前证据更支持“固定 K4 已经足够”，而不是“找到了明显更好的 K4”。

解决方式只能是：先补齐前向证据后重新计算；若仍低于 2%，保留固定 K4 并停止频点优化，或者在新的 MEI-0 中预注册真正不同的设计变量，如新频带、相位 / 衰减观测、不同 K 或路径长度。不得因为看到当前最大跨度只有 0.76% 就事后降低 2% 门。

#### 13.4.3 高压力有效性未验证

216 个 `0.5 / 0.709 MPa` 压力点已经实际进入 MEI-1，阻断原因不是缺点，而是当前公式和参数主要在常压附近使用，尚无证据证明它们在目标压力下仍然准确。压力证据必须明确覆盖 `0.5–0.709 MPa`，并说明温度、湿度、组分和频率适用范围。仅证明程序能输出高压力结果，或仅证明平衡声速可计算，均不等于整个弛豫、衍射和换能器链路已经验证。

可接受来源为覆盖目标范围的文献或权威数据库、与当前实现独立的热物性 / 声学参考、已有压力台架数据，或经单独授权后取得的新数据。正式验证还必须预注册比较指标、允许误差、校准与 holdout 分离规则，并把报告路径和 SHA256 写入新的 MEI-0。

### 13.5 下一轮处置顺序

1. **先做证据盘点，不先写复杂算法。** 建立 F2、F3、F4、F5 与高压力域的证据矩阵，逐项记录现有文献、现有数据、适用范围、缺口和是否需要外部授权。
2. **优先确认 F5 是否可取得。** 若没有既有标定，也不授权新硬件采集，则 F5 无法关闭，MEI-1 必须继续阻断；这一事实应在投入其他大规模工作前确认。
3. **联合处理 F2 与高压力证据。** 优先寻找同时覆盖目标温湿度、25–200 kHz 和 0.5–0.709 MPa 的 H2O 弛豫及声学参数；常压证据不得外推成高压力证据。
4. **处理 F3 与 F4。** F3 建立可追溯耦合实现或独立参考；F4 选择适用几何的解析包络或经授权的高保真子集。不得自动恢复 COMSOL G2+。
5. **对 F5 作显式授权决策。** 有现成证据则登记并验证；需要新台架时必须先取得独立授权，再设计最小标定矩阵。F5 完成前成本只能称 drive budget，不能称实际等声能。
6. **建立新的版本化 MEI-0。** 将新证据、实现路径、适用域、误差边界、状态转移和哈希写入 registry，运行专项测试和 manifest 校验；不得修改现有 freeze。
7. **从新父 freeze 重跑 MEI-1。** 必须继续使用 432 点、双噪声和三个排名域，不得删除压力点、缩小模型族或用 stride 结果代替正式门。
8. **按结果分流。** 只有全部物理证据通过、压力域有效、六个排名域均越过实践界且无稳定性翻转时，才可评审 MEI-2。若物理证据完整但排名仍低于 2%，应保留固定 K4；若要在 MEI-1 直接形成终止状态，必须先在新的 MEI-0 中补充该状态转移，不能偷用尚未运行的 MEI-2 verdict。若物理证据仍缺失或排名翻转，则继续输出 `mei1_inconclusive_forward_model`。

上一轮处置全过程保持 `allowed_next_stage=null` 和四类授权为 `forbidden_until_explicit_authorization`；13.6 的新 freeze 只将下一阶段改为 MEI-3，四类授权仍未改变。

### 13.6 F2--F5 证据处置与固定 K4 转移

2026-07-28 完成 [F2--F5 文献与公开数据证据审查](../references/tv3_mrs_ei_f2_f5_public_evidence_review_20260728.md)。检索确认 F2/F3 存在可追溯的实验速率、压力缩放和多组分耦合模型路径，F4/F5 存在可追溯的衍射建模与空气中换能器校准路径；但未找到覆盖当前完整温压域、实际孔径和 `device_profile_id` 的公开原始 holdout。

为避免无限期阻断与虚假验证并存，下一版本冻结采用以下不变量：

1. `parked_nonblocking` 不等于 `represented_traceable`，不得登记伪造边界或宣称物理闭合。
2. F2/F3 在 `obs-cfreq` 登记仿真信息设计中非阻断；F4/F5 在理想传播且不含设备幅相声明的信息设计中非阻断。
3. F2/F3 继续限制绝对衰减和完整耦合物理声明；F4/F5 继续限制正式波形、实际声能、硬件精度和现场泛化声明。
4. 高压力点保留为诊断结果，未验证的高压力能力不进入正式结论。
5. 若重新审计后无其他 blocker 且所有 K4 仍位于 `delta_practical=2%` 内，输出 `mei1_fixed_k4_retained`，固定 D0 K4，跳过 MEI-2 并允许进入 MEI-3 确定性求解审计。
6. 上述状态不改变四项授权；新数据、正式波形、benchmark 和硬件试验仍需独立显式授权。
