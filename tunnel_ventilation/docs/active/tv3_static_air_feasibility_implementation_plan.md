# tv3 静止空气 O₂ 可测性实施计划

> 状态：**规划中；替代当前暂停的双向声学 / flow holdout P0**
>
> 目的：先回答“在经过独立确认的静止空气条件下，现有单向声学链路能否达到 O₂ 业务门限”。本计划的任何通过结论只适用于静止空气受控条件，不能外推为掘进通风现场能力。

## Context

`tv3_identifiability` v1 已完成。它正确暴露：单向 TOF 的 O₂ / CO₂ / T / L 联合 Fisher 秩为 1，1 K 温度和 3 μs trigger jitter 情景的窄窗口 P90 为 8.85–12.99 vol% O₂；当前数字孪生没有 flow 传播，故部署范围内的 verdict 为 `information_source_upgrade_required`。

本轮执行决策是暂停 `raw_dsp_bidirectional_v1` 和 flow holdout，不把“仿真中未建 flow”误写为“现场一定静止”。静止空气必须是独立、可验证的实验范围。

## Task

### 1. 静止空气范围契约

1. 用密闭或无通风的测试腔建立静止空气工况；每次采集记录独立的风速核验结果、腔体状态、声程、温度、湿度、压力和校准会话。
2. 只有风速核验满足预先登记的静止条件时，样本才可进入静止空气集；未核验或发生气流的样本直接拒绝，不用单向 TOF 推断 flow。
3. 预测输入仍只可使用可部署测量：波形、慢通道和经标定的元数据。参考 O₂、真实 TOF、真实声速和参考风速只用于标签、校准或审计。

### 2. 执行顺序

1. **S0：测量链校准。** 测量实际 trigger jitter、固定延迟稳定性、声程重复性和温湿度测量误差；用实测值替换 v1 的 1 K、3 μs 情景假设，保留校准证据。
2. **S1：静止空气 holdout。** 在已知 O₂ / CO₂ / N₂ 配气中留出独立浓度、温湿度、声程或校准会话组合；不得只随机切分同一批次重复样本。
3. **S2：静止范围误差审计。** 使用同一组业务门：P90 O₂ ≤ 0.4 vol%、单项 nuisance 比例 ≤ 50%、拒绝率 ≤ 5%。拒绝原因必须明确为风速核验失败、质量不足或超出静止范围。
4. **S3：最小模型对照。** 仅在 S0–S2 通过后，用固定 RawDSP builder 的 B1 / B7 做静止 holdout 对照；不在本计划启动新的模型结构。

### 3. 判定边界

| 结果 | 含义 | 后续动作 |
| --- | --- | --- |
| `static_air_supported` | 静止范围内三项业务门都通过，且 holdout 稳定 | 保留为静止空气能力结论；现场 flow 路线仍暂停，不升级为部署声明 |
| `static_air_insufficient` | 静止范围内仍有 P90、nuisance 或拒绝率失败 | 优先按温度、时序和声程误差预算改测量链；不靠新回归头掩盖 |
| `static_air_audit_failed` | 静止条件、参考仪表、标签或 provenance 不完整 | 修校准与采集协议，不训练模型 |

## Non-goals

- 不生成 `raw_dsp_bidirectional_v1`，不建立 flow holdout，不修改当前 v1 单向 TOF 审计产物。
- 不把静止空气结果写成矿井通风现场、风速变化或安全联锁能力。
- 不改变 raw3、`mixture_id`、B1/B7、现有 RawDSP builder 或冻结基线。
