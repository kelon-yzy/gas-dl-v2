## 2. 噪声预算扫描：单独收紧 TOF 或温度不可达门

扫描：σ_TOF ∈ {3, 1, 0.5, 0.2, 0.1, 0.05, 0.02, 0.01} μs × T 先验 ∈ {1, 0.5, 0.2, 0.1} K × 4 臂（其余噪声保持登记值：α 标定 2%、RH 先验 2%、L 先验 0.1 mm、NDIR CO₂ 先验 0.05 vol%）。摘录（max P90 / median P90，vol% O₂）：

| 臂           | 3 μs, 1 K（=MRS-2） | 0.5 μs, 1 K | 0.01 μs, 0.1 K（扫描极限） |
| ----------- | ----------------- | ----------- | -------------------- |
| obs-cfreq   | 6.16 / 5.39       | 4.46 / 4.17 | 1.32 / 1.07          |
| obs-calpha  | 5.70 / 3.79       | 4.14 / 3.00 | 1.32 / 1.07          |
| obs-rh-diff | 4.47 / 2.78       | 3.72 / 2.32 | 1.29 / 1.01          |
| obs-p-scan  | 4.03 / 2.40       | 3.64 / 2.19 | **1.09 / 0.74**      |

**结论 1**：`required_jitter_at_registered_priors` 对所有臂为 **null**，(σ_TOF × T 先验) Pareto 通过集为**空**——即使 σ_TOF=10 ns 且 T 先验 0.1 K，P90 仍在 **≈1.0–1.3 vol%** 饱和，距 0.4 门约 2.7×。TOF 精度与控温**不是唯一瓶颈**。

**草案 §2 的"0.5 μs 量级即接近门限"粗算作废**：完整噪声模型重算表明 1/σ² 缩放假设不成立（信息随 σ_TOF 收紧后转为先验受限）。

| 变体                                               | max P90   | median P90 | 过 0.4 规格目标          |
| ------------------------------------------------ | --------- | ---------- | ------------------- |
| 基线（RH 2%、L 0.1 mm、CO₂ 0.05、α 2%）                 | 1.091     | 0.739      | 否                   |
| RH 先验 → 0.1%                                     | 1.051     | 0.701      | 否（RH 非约束项）          |

| TOF 逐频精度 σ_TOF | ≤ 10 ns                                 | 收紧 300×（3 μs jitter）  |

## 6. 现实性评定（D 支决策输入）

- σ_TOF ≤10 ns 意味着 1 MS/s 采样下 0.01 个采样点级的亚采样定位且逐频独立成立；L ≤10 μm 为干涉级标定；两者叠加双压控制——**该栈在工程上属极端配置**。
- 对照：业务门若维持 0.4 vol%，多频声学路线的硬件门槛显著高于 TDLAS 760 nm 后备路线的常规规格；本说明书为两条路线的成本对比提供声学侧定量输入，不替代决策。
- 若业务门允许放宽至 ≈1.4 vol%（max）/ ≈1.1 vol%（median），则 obs-cfreq（K4、无 α/控湿/控压）+ 0.5 μs TOF + 0.1 K 控温即可达（1.51/1.23），部署改造成本最低——该选项**超出本线 claim scope，需业务侧另行决策**。

## 7. 模型边界（规格数字的理想化前提）

以下 `not_represented` / 近似项在 ns/μm 级规格下将成为主导误差，规格数字是模型理想化**下界**：

1. 低频衍射/近场（registry `not_represented`；15 kHz 下限先验残差未进噪声模型）；
2. **c_eq 无湿度依赖**：真实湿空气经摩尔质量效应 Δc 可达 ~0.5–0.9 m/s（域内 RH 跨度），远大于弛豫通道信号，现前向模型未表达（2026-07-25 审查确认，建议后续以 `not_represented` 补登记）；
3. 单弛豫加和近似（无 Dain–Lueptow 耦合矩阵）；H₂O 弛豫参数仍为经验占位（Bass 1995 边界核验未完成）；CO₂ f_r 湿度系数 0.015/% 为低置信 legacy 值；
4. FD 数值注记：MRS-2 的 unstable_fd_count=567 主要来自 T=15/35 ℃ 域边界单侧差分截断（≤14% 局部扰动），不改变量级结论。

## 9. 原理与解读要点（2026-07-25 分析回填）

供后续读者快速理解本说明书数字的来历与解读方式：

1. **CRB/P90 是什么**：给定"观测对各未知量的灵敏度（Jacobian）+ 观测噪声/先验"后，Cramér–Rao 下界给出**任何算法都不可能超越的精度下限**；P90 = 1.645×CRB 标准差（|误差| 的 90 分位）。用它判定"硬件问题还是算法问题"——若理论下限都超参考线，换任何模型都无济于事。
2. **单频秩 1 的本质**：单频 TOF 只提供一个声速方程，却要解 (O₂, CO₂, T, L) 四个未知量；一个方程解不出四个未知数，与回归器深浅无关。
3. **多频升秩的物理来源**：O₂ 弛豫峰位 f_r,O 随湿度在域内移动（2.3–166 kHz，典型工况 ≈51 kHz 恰在频段中央）；N₂ 峰位低约两个数量级、强度低约 19 倍——峰位/强度双重非对称是 O₂↔N₂ 可分的机制。
4. **数量级链条（为什么 MRS-2 fail）**：单频声速灵敏度 ∂c/∂x_O₂≈0.227 m/s/vol%；但 O₂ 专属的带内色散差分信号只有 ≈0.0048 m/s/vol%，折算 TOF 差分 ≈0.01 μs/vol%，被登记 3 μs jitter 淹没约 300 倍；另有温度墙 ≈2.6 vol% O₂/K（T 先验 1 K 单项即 ≈4.3 P90）。
5. **饱和机制（§2 表的解读）**：误差预算服从短板逻辑——把计时/温度这两块板补高后，水位由下一块短板决定。收紧 σ_TOF 与 T 后短板转为声程标定 L：0.1 mm / 0.25 m = 4×10⁻⁴ 相对误差 → 表观声速偏 ≈0.14 m/s → ≈0.6 vol% O₂ 等效 ×1.645 ≈ 1.0 vol%，与 §2 饱和值严格吻合（§3 诊断独立验证）。
6. **K=4 为什么够**：谱形由带内 ≤3 个活跃弛豫过程决定（2N+1 参数计数），且 O₂ 峰位居频段中央，4 个对数分布频点已足以约束谱形；10/16 kHz 低频点无独立贡献且低于几何可信下限。
7. **解读边界**：CRB 是"至少需要这么好"的下界，不是"做到即成"的保证；§7 的模型理想化项（衍射、c_eq 湿度效应、单弛豫近似）在 ns/μm 级会成为主导误差。
8. **决策含义（结合 §0）**：强制门暂缓后，本说明书的角色从"过门判据"变为**精度-成本对照表**——0.4 参考线对应极端硬件栈（§3），≈1.4 vol% 参考精度对应最低成本方案（§6），业务侧按需选档。
