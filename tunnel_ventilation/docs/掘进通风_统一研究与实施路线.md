# 掘进通风多传感器气体组分反演：统一研究与实施路线

> 用途：将算法研究方向、测量系统改进、正式验证和路线决策收束为一份执行依据。后续讨论新模型、新物理或新硬件时，先回到本文所列的因果问题、证据和通过门，而不是按“模型层级”或“方法数量”推进。
>
> 正式数据基线：clean **tv3-formal-6000**。当前默认可部署预测头：**B7 OOF Ridge + residual MLP**。B1/B7 基线冻结日期：2026-07-13。
>
> 来源文档保留用于追溯；本文整合其仍有效的结论，并以本文的优先级与停止条件作为后续工作依据。

---

## 1. 核心结论：问题不再是“再找一个更深的模型”

当前链路已经证明：原始超声波形中的可用信息能够由冻结 RawDSP 恢复，且 Ridge 主趋势加小型残差网络能够稳定利用其中的一部分非线性。它尚未证明：系统在真实通风、湿空气、设备差异和时间漂移下仍具有足够的 O₂ 分辨能力。

因此，项目的主问题应改写为：

> 在小样本、高维强共线传感特征与仿真—硬件差异并存时，怎样先量化声学信息相对环境和设备扰动的可辨识边界，再用物理校正、有限残差学习和不确定性输出，得到可验证、可拒绝、可部署的气体组分反演结果？

这一定义带来三条直接决策。

1. **先验证测量能力，再扩展模型。** 若 O₂ 信号本身小于温度、湿度、流速、声程或延迟的不确定度，增加网络容量不能制造信息。
2. **模型只学习显式物理校正后的剩余关系。** 现有 B7 是该原则下的默认头；任何替代头必须解释它解决了哪一种残余误差，并在相应 OOD 上证明收益。
3. **部署结论必须包含边界。** 点预测、区间、支持度、质量标记和拒绝状态缺一不可；单个随机划分上的 R² 不能代表现场能力。

当前推荐的总链路如下：

~~~text
当前仿真 P0：显式 flow=0 的静止单向波形
  → 参数来源登记、扰动数字孪生、版本化 RawDSP
  → 量化温度、湿度、声程、延迟、SNR 与设备 profile
  → 物理统计特征 + NDIR、TCS、环境量
  → Ridge 主趋势 + 冻结 B7 residual 或通过统一替代门的新头
  → 点预测 raw3 + 预测区间 + OOD/质量标记 + 拒绝状态
~~~

这里每一步都服务于一个可检验的因果关系：物理变量影响波形，波形经测量链路变成特征，特征覆盖与分布变化决定模型能否外推，预测误差和样本支持度共同决定是否应当输出数值。

## 2. 不可改变的契约、基线与已知边界

### 2.1 正式契约

- 正式模型直接输出 **x_CO2、x_O2、x_N2** 三个 raw 值，**out_dim = 3**。
- 不使用 N₂ 闭包回填、gas_head、ILR/ALR、target_transform、free_component_mse 或闭包残差头。
- **sum_abs_error** 仅作监控，不作为强制闭包损失。
- true TOF、true sound speed 和 true alpha 只能用于 oracle 审计或辅助目标，不能进入部署输入。
- observed builder 冻结为 **d0_observed_physics_stats_v1**；RawDSP 正式 builder 冻结为 **d0_raw_dsp_physics_stats_v1**。
- 新增双向、湿空气、多频或流速补偿时，必须创建新的 builder、manifest 和独立消融，不能把新物理悄悄混入旧结果。双向和流速补偿当前暂停，保留为后续独立方向。
- 缺失 manifest、waveform scale、slow metadata 或必需数组时必须失败；不允许静默 fallback。
- 旧本地 600 数据仅可用于代码、DSP 和 waveform fidelity 调试，不得产生正式性能结论。

### 2.2 已冻结的有效证据

| 证据 | 结论 | 对后续工作的含义 |
|---|---|---|
| D2b RawDSP 帧级 fidelity | clean 6000 的 peak P95 约 0.044 sample，全部帧 accepted；RawDSP Ridge 已达到 D0-observed parity | 当前瓶颈不是“能否从波形找到 TOF”，而是环境扰动、真实硬件和表格头的泛化 |
| B7 OOF Ridge residual | repeated split 与双 selector 协议均通过；R / L / S-Y / S-L 相对 B1 的增益为正 | B7 冻结为默认 RawDSP 头，新增模型必须以它为配对基线 |
| S-Y 与 S-L | B7 OOD O₂ R² 分别约为 0.434 ± 0.028 与 0.700 ± 0.026 | OOD 不是单一概念；不能将 S-L 的结果概括为全部 OOD 或现场泛化 |
| 0.8% O₂ 窄区间 | 即使用 oracle 特征，R² 仍为负 | 窄区间精确回归存在物理分辨率风险，应先做误差预算再承诺业务精度 |
| 冻结 v1 单向 TOF 可辨识性审计 | 189 点差分稳定；O₂/CO₂/T/L 联合 Fisher 秩为 1，声速未重复计入；1 K 与 3 μs 情景的窄窗口联合 P90 为 8.85–12.99% O₂ | P90=`0.4 vol%`、nuisance=`50%`、拒绝率=`5%` 均已判定失败；flow 未表示使 189/189 点被拒绝，verdict=`information_source_upgrade_required` |
| C1 physical grouped bottleneck | 24 条正式矩阵判定 grouped_failed；同参数 C2 随机置换更好但仍不替代 B7 | 早期按“物理组”独立压缩损失了跨组关系；停止该分支，不把失败误解为所有物理引导无效 |
| R5-T、B6 与 TabPFN | 目标标准化是已验证的优化条件；TabPFN 说明存在非线性，但仅是非部署上限探针 | 小样本非线性值得研究，但必须用可部署 RawDSP、OOF 和正式 OOD 证明 |
| D2 TOF-PhaseNet、ExtraTrees | 前者原实现失败，后者训练—验证 gap 很大 | 不回到旧 D2 补丁路线，也不开展无边界树模型调参 |

### 2.3 已知能力边界

- O₂ 在 18.0%–21.2% 全范围具有粗粒度可辨识信号；TOF 与声速是主要信息源。
- 窄 O₂ 窗口的精细变化可能低于系统的物理分辨能力，不能以“更高 R²”替代这一判断。
- 当前所谓 extrapolation 并不等价于真实物理 OOD；环境、设备、日期、校准批次和配气批次尚需独立验证。
- 当前 clean 仿真中的帧质量过于均匀：全帧 accepted，未出现 boundary hit 或 clipping。因此，quality-aware attention 在未构造坏帧或真实质量异质性前没有充分的学习对象。
- 首轮审计只把单向 TOF 作为独立声学观测；P/RH/SNR 在 v1 不构成独立 TOF 信息，flow projection 未表示。因此，当前不能把条件 CRLB 或情景 P90 写成多 nuisance 已解耦的现场误差上限。

## 3. 用因果问题组织工作，而不是按方法堆叠

下表是本项目唯一需要持续回答的主问题。每个问题都给出可观测证据、干预方式和失败后的行动，避免以抽象层级代替解释。

| 因果问题 | 要验证的机制 | 必需证据 | 通过后的行动 | 不通过时的行动 |
|---|---|---|---|---|
| O₂ 在目标区间是否可分辨？ | 组分引起的 TOF、相位、吸收或色散变化大于 nuisance 传播误差 | 灵敏度、Fisher information、误差预算、最小可分辨 O₂ 变化 | 保留连续回归目标 | 转为分档/趋势监测，并评估多频或 TDLAS |
| 单向 TOF 是否被气流污染？ | 沿声路流速与声速混叠；双向测量可一阶解耦 | AB/BA reciprocity、flow holdout、校正残差 | ⏸ 当前暂停；后续以独立双向数据版本验证 | 静止空气阶段不推断 flow，不用模型硬拟合流速误差 |
| 仿真是否覆盖真实测量成因？ | 湿空气、设备响应、延迟、噪声、多径和老化共同改变波形 | dry/humid、device holdout、真实波形统计距离 | 建立可校准数字孪生并扩展训练域 | 先做参数识别、硬件校准或传感链路重构 |
| 测试是否代表部署变化？ | 不同 OOD 机制导致不同误差模式 | 独立 selector、group holdout、OOD set hash | 将各机制分列报告，支持模型替换判断 | 不宣称泛化，不以随机 split 结果推进 |
| 何时可相信一次预测？ | 误差与支持距离、质量、校正残差及环境条件相关 | coverage、interval width、risk-coverage、reject audit | 输出区间、质量等级与拒绝状态 | 不部署精确数值输出 |
| B7 之外的模型是否真有价值？ | 新结构能解释 B7 未处理的特定残余机制 | 同协议的 ID、双 selector、环境/硬件 OOD 与可靠性改进 | 通过统一替代门后替换 B7 | 保留 B7，停止该结构 |
| 单频声学是否缺少信息源？ | 多频相位、吸收和色散带来条件独立的 O₂ 信息 | nuisance-marginalized Fisher information 与设备随机化后的增益 | 进入多频硬件实现 | 及时进入 TDLAS 或混合路线决策 |

## 4. 按证据依赖关系执行

工作顺序由“后一步能否解释前一步造成的误差”决定。WP 编号仅用于追踪产物，不代表额外的理论层级。

### 4.1 先冻结可比较的基线

在引入任何新物理或模型前，冻结 RawDSP builder、B1 Ridge、B6、B7、重复划分 selector、OOD set hash、train-only template、target scaler 和 feature scaler。每次正式运行至少记录：

- git commit、Python 与依赖版本；
- 数据集 hash、builder 名称、physics version；
- split seed、training seed、selector 与 calibration config；
- 模型配置、输入特征版本和结果 verdict。

验收标准是 B1、B6、B7 可复现，协议行数、hash 与 verdict 一致。建议产物目录：

~~~text
outputs/tv3_baseline_freeze/
  manifest.json
  baseline_metrics.json
  split_hashes.json
  environment.json
~~~

这一步的作用是排除“训练随机性、数据版本或特征泄漏造成假增益”这一竞争解释。

### 4.2 先回答物理上限：可辨识性、灵敏度与误差预算

对冻结仿真器和新物理仿真器分别扰动下列变量：

~~~text
x_O2, x_CO2, x_N2
T, P, RH, L, airflow_projection
system_delay, tx_delay, rx_delay, trigger_jitter
SNR, gain, phase, transducer_response, multipath, dust_attenuation
~~~

计算 TOF 与关键特征对变量的局部导数、Jacobian、条件数、Fisher information、近似 Cramér–Rao lower bound、nuisance-marginalized O₂ information，以及每项误差折算成的等效 O₂ 误差。必须单列：

- 全 O₂ 范围与 0.8% 窄窗口的信号变化；
- 1 K 温度误差、RH 误差、0.5/1.0 m/s 沿程流速的等效 O₂ 误差；
- 声程、固定延迟、jitter 与 SNR 的误差贡献；
- 不同环境条件下的理论分辨率和 P90 误差。

只有在目标业务环境内，理论 P90 O₂ 误差不超过 `0.4 vol%`、关键 nuisance 校正后的残余不超过 `0.8 vol%` 窄窗口信号的 50%、且联合条件下信息不接近奇异时，才继续追求窄区间连续回归。该 0.4/50% 门限的法规、文献和项目内推导见 `references/tv3_identifiability_business_threshold_evidence.md`；它们是研究判定门，不是安全联锁性能声明。否则冻结“精确数值回归”目标，转为分档/趋势监测并进入信息源升级决策。

截至 2026-07-13，`outputs/tv3_identifiability/` 已完成冻结 v1 单向 TOF 首轮审计：基线与差分审计通过，联合 Fisher 秩亏按预期暴露；P90=`0.4 vol%`、nuisance=`50%` 与拒绝率=`5%` 均已登记并显式失败。`v1_blocking_nuisance_reject_all` 因未表示 flow 拒绝 189/189 点，故当前部署范围状态是 `information_source_upgrade_required`。这不以该情景 P90 代替真实硬件误差，也不构成补齐双向 flow 后声学路线的最终否定。实际实验暂时无法进行，当前执行方向限缩为静止空气仿真可辨识性，不改变上述事实。

### 4.3 显式消除可测的物理混叠

#### 当前仿真 P0：静止空气可辨识性

当前先不实现双向传播和 flow holdout。静止空气作为独立仿真情景，必须在配置和 manifest 中显式固定 `flow=0`；这只定义数字孪生边界，不代表真实现场静止。trigger jitter、固定延迟、声程、T/RH/P、SNR 和设备 profile 的范围必须区分代码已实现物理、文献边界与工程敏感性情景，未表示项继续阻断能力结论。

静止空气仿真阶段先完成参数表示审计和来源登记，再生成联合扰动设计，执行灵敏度、Fisher、Monte Carlo P90 与独立 composition、T/RH/P、L、jitter、SNR、device-profile holdout；最后用 P90=`0.4 vol%`、nuisance=`50%`、拒绝率=`5%` 审计。通过只允许写成“已登记仿真分布内支持”，不改写现有 `information_source_upgrade_required`，也不外推为真实静止空气或掘进通风现场能力。详见 `active/tv3_static_air_feasibility_implementation_plan.md`。

#### 并行 P1：COMSOL 隧道多物理场 → DL

与气室 P0 孪生隔离。目标是用 COMSOL 6.3 补齐巷道通风、空间浓度和后续局部声学，再投影到现有传感器正演与 DL，形成独立 schema `tunnel-ventilation-comsol-1`。截至 2026-07-20：G0 registry 已冻结（formal 仍 `g0_input_blocked`，smoke 允许）；G1 CFD smoke 判定 `g1_cfd_smoke_passed`（`TurbulentFlowkeps`，三档网格质量守恒）。下一步为 G2 三组分瞬态输运。smoke **不得**进入正式训练，也不得改写 B1/B7 或现场能力声明。详见 `active/tv3_comsol_multiphysics_dl_implementation_plan.md` 与 `COMSOL/tunnel_transport/README.md`。

#### 双向声学与气流解耦

> **已立项（执行待前置门）。** 实施契约、先验误差预算与 F0–F6 阶段门以 [active/tv3_bidirectional_ultrasound_implementation_plan.md](active/tv3_bidirectional_ultrasound_implementation_plan.md) 为准；本节保留原设计约束供追溯。立项不改写 v1 verdict，也不撤销静止空气 P0。

单向传播满足：

~~~text
t_down = L / (c + v_path)
t_up   = L / (c - v_path)

c      = L / 2 × (1 / t_down + 1 / t_up)
v_path = L / 2 × (1 / t_down - 1 / t_up)
~~~

其中 v_path = v × cos(alpha)。双向方案不应只增加两列特征，而要检验其是否真正减少了流速导致的声速偏差。新契约建议为 **raw_dsp_bidirectional_v1**，至少含 waveform_ab、waveform_ba、L_m、T_C、P_MPa、H_RH、pair_id 和 calibration_session_id，并输出双向 TOF、peak、SNR、quality、声速、flow projection、reciprocity error 与 corrected TOF。

对照应固定 Ridge/B7 头，只比较单向、单向加实测风速校正、双向解耦声速、双向全特征和双向但不提供 flow。通过条件是 corrected sound speed bias 降低、flow holdout 的 O₂ MAE 改善、S-Y/S-L 不明显退化，且设备间 reciprocity 可稳定校准。初始校正残差目标为不超过 0.10 μs，最终门限以误差预算为准。

#### 湿空气与测量系统数字孪生

监督标签仍遵循现有干基 raw3 契约；传播模型根据 T、P、RH 计算水蒸气分压，并将干基组分转换为参与声速、密度、吸收、分子弛豫和换能器负载计算的湿基组分。这样区分了“标签是什么”和“波形为何改变”，避免模型把湿度影响错误归因给 O₂。

新物理版本建议为 **acoustic_measurement_v2**，显式纳入：

- 设备：transducer_id、transducer_pair_id、frequency_response、temperature_response、tx_delay、rx_delay、gain、phase、noise PSD、clock drift、aging_state、installation_angle、path_offset；
- 现场：airflow_profile、dust_attenuation、condensation、multipath、reflector_position、非均匀温湿度；
- manifest：physics_version、humidity_model、flow_model、transducer_profile_id、noise_profile_id、delay_profile_id、multipath_profile_id、calibration_session_id、randomization_seed。

正式对照至少包含 dry v1→dry v1、humid v2→humid v2、dry v1→humid v2、humid v2→dry v1，以及同设备、已见设备和完全留出设备。新物理只有同时解释真实波形主要统计量、恢复 dry→humid 域差、改善 device holdout 且不使用 oracle 输入时，才可进入正式模型比较。

### 4.4 让验证覆盖真实变化机制，而不是只覆盖标签边界

保留 R、L、S-Y、S-L 四个 selector，并始终将 S-Y 和 S-L 分列。新增 selector 必须对应一个明确的部署原因：

| 变化原因 | selector 示例 |
|---|---|
| 环境条件 | S-T、S-RH、S-Flow、S-Path、S-SNR、S-Delay、S-Dust、S-Multipath |
| 硬件与采集 | S-Device、S-Pair、S-Day、S-Cal、S-Cylinder、S-Site |
| 联合极端情况 | 高湿+低温+低 SNR；高流速+声程边界；留出设备+日期；高湿+粉尘+增益下降；非均匀温度+多径 |

协议规则：

- 每个 selector 单独形成 OOD 集，保存 config 与 OOD set hash；
- 训练 seed 和 split seed 分开；设备、日期、批次按组划分；
- calibration split 与 test/OOD 完全隔离；
- 特征选择仅使用训练集；
- 同一个 OOD 集上的不同训练 seed 只量化训练方差，不能被称为独立 OOD 证据；
- 不允许把多个 OOD 合并为一个平均 R²。

每个 selector 报告 O₂ R²、MAE、RMSE、bias、P90 absolute error、worst-bin/worst-group MAE、sum_abs_error、coverage、interval width、rejection rate 和 train-support distance。模型替换的最低稳定性要求为 3 个 split seed × 3 个 training seed。

### 4.5 用最小真实硬件闭环检验因果链

真实试验的目的不是制造大量帧，而是主动打破仿真中“同设备、同日期、同条件”的隐含相关性。最小矩阵应包含：

- O₂ 至少 5 档、CO₂ 至少 3 档，以及相同 O₂/不同 CO₂、近似同声速/不同组成的困难对照；
- 3 个温度档、3 个湿度档、3 个流速档、2 个声程、2–3 对换能器、3 个独立采集日期和多个配气/气瓶批次；
- 每轮按 零气 → 标准气 → 目标气 → 标准气复测 → 零气复测 执行，以测得零点、span、滞后、残留和响应时间。

每条记录至少保存 gas_certificate_id、gas_batch_id、reference_analyzer_id 与 uncertainty、温湿压/流速参考、transducer_pair_id、installation_geometry、calibration_session_id、acquisition_day 和 operator。正式划分单位是气瓶/批次、日期、换能器、校准会话与安装点，绝不能随机按帧拆分。

通过硬件闭环至少要求：RawDSP 在真实波形上完成 fidelity 审计；校正声速对参考条件具有稳定 bias；B1/B7 在留出设备和日期上得到有效结果；区间覆盖达标；模型误差能够与参考标签不确定度区分。若这里失败，优先修物理、校准或传感链路，而不是增加模型宽度。

## 5. 模型工作只能作为可证伪的条件分支

下表保留两份源文档中的算法方向，但每一项都绑定了它要解释的机制和停止条件。

| 分支 | 要解释的残余机制 | 启动前提与对照 | 通过条件 | 停止条件 |
|---|---|---|---|---|
| 冻结 B7 OOF Ridge residual | Ridge 解释稳定主趋势，小型网络解释 OOF residual | 当前默认头；维持 raw3、目标标准化、训练集 OOF Ridge、零初始化 residual 输出 | 已通过现有重复 split 与双 selector | 不扩大结构；除非新计划明确提出并验证不同机制 |
| 小型 flat residual、O₂-only residual、flat TabM | B7 是否过参数化、共享任务是否压制 O₂，或仍有可部署非线性未被利用 | 固定小网格；flat 输入；与 B7 参数量接近；相同 split/OOD/UQ | test O₂ R² 均值至少 +0.01，且 S-Y、S-L、环境、设备/日期 OOD、closure 与 coverage 均不退化 | 任一统一替代门失败即保留 B7，不继续扩大搜索 |
| 多任务结构诊断 | CO₂ 的 NDIR 主导信息与 O₂/N₂ 的声学主导信息可能发生负迁移 | 比较共享 trunk、独立 heads、模态分支与 single-target；记录各层梯度 cosine 和范数 | 有可重复冲突证据且结构改动改善独立 OOD | 无系统冲突或独立模型不优于共享模型时，不引入 PCGrad/CAGrad |
| 质量感知 DeepSets/Set Transformer | 帧质量异质导致固定统计聚合损失有效信息 | 先构造固定统计基线，再注入坏峰、低 SNR、jitter、缺帧和不同 accepted 比例 | 在坏帧、缺帧和 quality 分层 test/OOD 上优于固定聚合，且 attention 与质量关系可解释 | 注入后仍无增益时，接受固定聚合已足够 |
| 可微 RawDSP 前端 | 模板、局部峰值或条件响应在新环境/硬件下存在系统失配 | A0 Fixed DSP 对照 A1 residual-template、A2 conditional-template、A3 local peak corrector；A4 fully learned CNN 仅消融 | 先改善帧级 fidelity，再改善 B1/B7 的 test/OOD；模板修正受平滑/带宽约束 | 相对 A0 无稳定增益即保留冻结 DSP；不与组分头同时无边界联调 |
| TabPFN OOF 教师蒸馏 | 非部署教师发现的非线性能否压缩到小型 RawDSP 学生 | 教师训练预测必须 OOF；与 R5 纯监督实验隔离；比较 absolute、residual、排序蒸馏 | 真实标签损失与 OOD 同时改善，且不继承教师的 OOD 错误 | 仅改善当前随机 split 或依赖泄漏时停止 |
| 领域内波形自监督 | 标签少但可获得覆盖真实变化的无标签波形 | 掩码峰重建、TOF/quality 预测、噪声一致性、物理参数 holdout；避免记忆模板/seed | 相对随机初始化在独立 mixture 与参数 holdout 上稳定改善 | 只改善仿真随机 split 时不扩大预训练 |
| TabPack 等新型表格集成 | 参数高效集成是否降低调参成本并改善稳健性 | 先完成 flat TabM；相同 split、参数与计算预算 | 在既定替代门内优于其基线 | 成本明显上升而无额外收益时停止 |

### 5.1 所有深度模型的共同训练约束

- 保留已验证的 **target scaling**；输入和目标的 scaler 只能由训练集拟合。
- 前端涉及 TOF 时以 sample 或 μs 为损失单位，避免秒量级梯度近零。
- 若训练可微模板，限制相关峰搜索窗；禁止用会抹除位置信息的全局池化作为 TOF 主路径。
- 模板残差必须有 L2、平滑或频域带宽约束，防止其退化成无物理约束卷积。
- 联合损失中的组分项、TOF/peak 辅助项和模板正则项必须分开记录；不能同时大改前端、头部、损失和 split 后再归因。
- 强闭包损失、真值声速输入和未缩放的秒级 TOF 损失不作为默认设计。

### 5.2 已冻结的停止项

除非有新的正式证据且另立冻结计划，以下工作不得重启：

~~~text
C1 physical grouped bottleneck
C1 bottleneck dimension tuning
C1 group dropout
C1 group gating
C1 encoder TabM
旧 D2 patch 路线
ExtraTrees 无边界调参
N2 闭包回填
~~~

## 6. 可信输出不是附加功能，而是部署条件

在不扩大 B7 容量的前提下，每个预测应至少给出：

~~~text
prediction_raw3
o2_lower, o2_upper
confidence_level
support_distance
quality_score
ood_flag
reject_flag, reject_reason
~~~

### 6.1 区间、OOD 与拒绝

- 用与训练、test、OOD 完全独立的 calibration split 做 90% 和 95% split conformal。
- 条件区间可以依赖 T、RH、flow、SNR、quality、reciprocity_error、device_id 与 support_distance；可比较分组 conformal、conformalized quantile regression 和 covariate-shift weighted conformal。
- 至少实现一种轻量支持距离：kNN、Mahalanobis、PCA/whitened distance、density ratio 或 calibration residual model。
- 拒绝原因必须可追溯，例如区间过宽、支持距离过大、reciprocity error 过大、双向校正残差过大、SNR 过低或关键 metadata 缺失。

验收按每个 selector 分开进行：90% coverage 目标 88%–92%，95% coverage 目标 93%–97%，关键环境组 coverage 不低于 nominal −5%；拒绝后风险必须下降，同时完整报告 rejection rate。不得通过拒绝大量样本后只展示提高的 R²。

### 6.2 结果报告的最小集合

| 维度 | 必报内容 |
|---|---|
| 整体回归 | 每个组分的 R²、MAE、RMSE、bias、P90 absolute error |
| O₂ 业务区间 | 预先固定 bins 的 MAE、bias、P90、相邻档位可分概率、coverage、样本量；bin 内 R²仅作诊断 |
| Worst group | T、RH、L、flow、SNR、device、day、calibration_session、gas_batch、composition_corner 的 MAE、bias、coverage、interval width |
| 链路健康 | peak P95、sound speed bias、flow residual、reciprocity error、SNR、multipath score、delay drift、zero/span drift |
| 稳定性 | train/val/test/OOD gap，多 seed 均值、标准差与最差 seed |
| 闭包 | sum_abs_error，仅监控，不替代 O₂ 性能 |

## 7. 信息源升级与最终路线决策

### 7.1 多频的目标是增加独立信息，不是增加特征数量

多频候选可为离散频点、短 chirp 或多载波 burst，但频率选择要最大化 **O₂ conditional Fisher information**，并受换能器响应、湿度敏感度、温度敏感度、衰减、SNR、相位稳定性和增益漂移约束。

每个频率提取 TOF、phase、amplitude、SNR、coherence 和 quality；重点使用抗公共漂移的差分量，例如相位差、对数幅值比、TOF 差、group delay 和 dispersion slope。比较单频 TOF、多频 TOF、多频幅值、多频差分、多频全特征、增益随机化后多频、湿空气多频和设备 holdout 多频。

只有当 nuisance-marginalized O₂ information、S-Y/S-L、环境 worst-group 与窄窗口 O₂ MAE 同时改善，且增益在设备/增益随机化后仍存在时，才进入多频硬件实现。

### 7.2 少量实测数据用于校准因果参数，不用于掩盖域差

> **暂缓保留。** 当前实际实验不可用，本节只定义实验条件恢复后的 Sim2Real 校准顺序，不是近期执行任务。当前参数扫描必须标记为文献边界或工程情景，不能冒充实测校准分布。

Sim2Real 校准应依次估计真实噪声 PSD、换能器频响、固定延迟与漂移、增益/相位/SNR 分布、多径和异常波形比例，并据此限定 domain randomization 的可信区间。对照固定仿真、宽范围盲随机化、实测校准随机化、实测微调与二者组合。

成功标准是仿真—实物核心波形统计距离下降、实物 holdout 改善、仿真/环境 OOD 不被牺牲，且校准参数可解释、可复现。

### 7.3 声学路线的明确出口

完成可辨识性、双向校正、湿空气/设备建模、环境与硬件 OOD、B7-UQ 和多频信息量验证后，若满足任一条件，则恢复 760 nm O₂ TDLAS：

- 真实硬件 O₂ 性能持续低于业务目标；
- 窄窗口 MAE 不满足要求；
- 预测区间过宽或可接受拒绝率下仍不达标；
- device holdout 失败；
- 误差预算表明 nuisance floor 高于目标精度；
- 多频没有增加可用信息；
- 声学路线的成本、复杂度或维护要求高于专用 O₂ 传感。

届时优先采用混合路线：

~~~text
NDIR CO2
+ 静止单向超声（当前仿真 P0）：`flow=0` 扰动分布内的 O2/N2 可辨识性
+ 双向超声（暂停保留）：粗粒度 O2/N2、流速与一致性诊断
+ TDLAS O2：精确 O2 通道
~~~

## 10. 最终决策规则

项目不以“某个 split 的 O₂ R² 更高”作为成功标准，而以以下链条是否闭合为准：

~~~text
可辨识性足够
  → 关键物理扰动被测量或校正
  → 仿真与真实硬件的波形成因一致到可审计程度
  → 环境/设备/时间 OOD 可分机制验证
  → 预测区间与拒绝策略校准有效
  → 任何新模型在上述边界内稳定优于 B7
~~~

任一箭头断裂时，下一步应修复该箭头指向的物理、数据或验证问题，而不是在下游增加新的抽象模型层。这样才能让每一项工作都回答“误差为何产生、干预为何有效、何时应停止”，而不是只增加一个看似更复杂的架构名称。
