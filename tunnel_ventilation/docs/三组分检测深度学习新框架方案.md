# 三组分检测深度学习新框架方案

> **2026-07-09 状态更新**：本方案 P1 主推的 **D2（Differentiable TOF-PhaseNet）已训练证伪**（tv3-formal-6000，O2 val R²=−0.015，退化为均值预测，三组分全面低于 D0-observed；辅助 TOF 84.2μs 未优于 observed 82.0μs）。结合此前 R1b（MiniRocket raw 波形）证伪，**raw-waveform 端到端 → 可微 TOF 前端两条路均已封闭**。可部署 baseline 定为 D0-observed（O2 val 0.42）。**R5'（physics_stats + TabPFN）代码已落地，本地 smoke test 通过，待服务器 6000 正式运行**。详见 [d2_tof_phasenet_implementation_plan.md](d2_tof_phasenet_implementation_plan.md) 训练结论、[r5_tabpfn_implementation_plan.md](r5_tabpfn_implementation_plan.md) 实施记录与记忆库 §6.4 末/§6.7。本文档以下 D2 内容保留为设计记录。
>
> 目标：面向 tv3 掘进通风三组分检测任务（CO2 / O2 / N2），在已有 Ridge 物理特征基线有效、端到端 raw waveform DL 失效、MiniRocket raw 波形路线证伪的基础上，重新构建一组更贴合物理机理的深度学习算法框架。
> 
> 核心结论：后续 DL 不应继续走“raw waveform -> 通用 CNN/TCN -> 三组分”的纯端到端路线，而应改为 **物理引导的深度学习**：把 TOF、相位、声速残差、温压补偿、传感器关系作为网络结构、辅助任务或图结构的一部分。

## 1. 当前实验事实

已有结果说明，数据中确实存在 O2 / N2 可辨识信息，但当前深度学习前端没有提取到关键的亚样本 TOF / 相位信息。

| 实验              | 输入与方法                                  | 关键结果                              | 结论                            |
| --------------- | -------------------------------------- | --------------------------------- | ----------------------------- |
| slow-only Ridge | slow 标量                                | O2 R2 约 -0.05                     | slow 通道几乎不能单独辨识 O2            |
| R0              | slow + 超声物理标量统计 + RidgeCV              | val O2 R2 = 0.603                 | 物理特征路线成立，但未达 0.70 验收线         |
| R1a             | MiniRocket on 超声标量序列                   | val O2 R2 = 0.515                 | 卷积统计不如 R0 多窗口统计               |
| R1b             | MiniRocket on raw 5000 点波形             | val O2 R2 = -0.195                | raw 波形随机卷积无增量                 |
| v3_l2 DL fusion | z-score + LayerNorm 的 CNN1D-TCN fusion | overall R2 = 0.019，O2 R2 = -0.061 | 训练稳定性改善，但 encoder 未提取有效 O2 特征 |

关键问题不是“数据完全没有信号”，而是：

1. O2 / N2 的主要差异在声速和 TOF，属于弱、精细、亚样本级别信号。
2. 通用 CNN1D 池化容易捕获能量、包络等粗统计，却不一定能精确估计 TOF / 相位。
3. R0 可能使用了部分仿真 oracle 特征，例如 `ultrasonic_alpha_true_npm`，需要先拆分可观测特征与真值特征。
4. 现有 concat / FiLM / gate 融合没有解决强 CO2 分支压制弱 O2 信号的问题。

## 2. 文献依据

### 2.1 气体混合物浓度估计

- Wang et al. 2024 提出 Gas Graph Convolutional Transformer，用图结构处理气体混合物浓度估计和鲁棒泛化问题。该方向提示本项目可以把传感器、模态、物理派生量建成异构图，而不是简单拼接。
  - DOI: [10.1021/acssensors.3c02654](https://doi.org/10.1021/acssensors.3c02654)
- Pareek et al. 2021 使用 Hybrid 3DCNN-RBM 处理气体传感器阵列浓度估计，说明深层结构可以用于气体混合物浓度回归，但需要对传感器阵列结构建模。
  - DOI: [10.1109/jsen.2021.3105414](https://doi.org/10.1109/jsen.2021.3105414)
- Wang et al. 2025 进一步研究 heterogeneous sensor array 上的 graph-driven gas mixture identification and concentration estimation。
  - DOI: [10.1109/tim.2025.3588932](https://doi.org/10.1109/tim.2025.3588932)

### 2.2 超声 TOF 与时延估计

- Chen et al. 2010 使用 adaptive Morlet wavelet filter 进行超声 TOF 估计。该类方法说明 TOF 提取本身是一个信号处理问题，不适合完全交给通用 CNN 隐式学习。
  - DOI: [10.1016/j.measurement.2010.01.001](https://doi.org/10.1016/j.measurement.2010.01.001)
- Angrisani et al. 2006 使用 Kalman filtering 进行超声 TOF 估计，为“状态估计 + 神经网络残差”的混合路线提供依据。
  - DOI: [10.1109/tim.2006.870123](https://doi.org/10.1109/tim.2006.870123)
- Salvati et al. 2021 使用 CNN-based parametrized GCC-PHAT features 做 time-delay regression。它比直接 raw CNN 更贴近本项目的 TOF 本质。
  - DOI: [10.21437/interspeech.2021-988](https://doi.org/10.21437/interspeech.2021-988)

### 2.3 时间序列与波形深度模型

- PatchTST 通过 patch 化降低长序列 attention 成本，并支持自监督预训练。
  - arXiv: [2211.14730](https://arxiv.org/abs/2211.14730)
- iTransformer 将变量作为 token，更适合建模多变量物理通道之间的关系。
  - arXiv: [2310.06625](https://arxiv.org/abs/2310.06625)
- Temporal Fusion Transformer 提供变量选择、门控残差和可解释融合机制。
  - DOI: [10.1016/j.ijforecast.2021.03.012](https://doi.org/10.1016/j.ijforecast.2021.03.012)
- TS2Vec 使用层级对比学习学习时间序列表征，可作为 raw waveform / 物理序列预训练参考。
  - arXiv: [2106.10466](https://arxiv.org/abs/2106.10466)
- SincNet 用可解释的参数化滤波器处理 raw waveform，提示本项目可以用可学习滤波器替代普通第一层 CNN。
  - DOI: [10.1109/slt.2018.8639585](https://doi.org/10.1109/slt.2018.8639585)

## 3. 新 DL 框架设计

### D0：R0-observed 可观测特征拆分

目的：先确认 R0 的 0.603 有多少来自真实可观测信号，有多少来自仿真 oracle 特征。

#### D0 实施目标

D0 不是一个追求最高分的新模型，而是后续 D1-D5 的基准闸门。它必须给出三个结论：

1. 当前 R0 中 O2 R2 = 0.603 的有效部分有多少来自可部署传感器观测。
2. `ultrasonic_alpha_true_npm`、true sound speed 等仿真真值对 O2 / N2 结果的抬升幅度是多少。
3. 后续 DL 实验应对比的真实基线是 D0-observed，而不是含 oracle 的 R0。

#### D0 不变量

1. 所有 D0 实验使用同一数据集、同一 split、同一标签和同一评估脚本；默认数据集为 `data/tv3-formal-6000`。
2. 输出仍为 `x_CO2`、`x_O2`、`x_N2` 三组分直接回归，不启用闭包残差头、不启用 `target_transform`、不把 N2 作为背景字段。
3. D0-observed 与后续可部署模型禁止使用任何由真实组分直接计算、仿真侧直接给出的 oracle 特征。
4. 缺失必要数组、特征名漂移、非有限特征、split 行数不一致时应直接失败，不添加静默 fallback、mock 特征或默认替代值。
5. 每个 D0 特征集合必须使用独立 `feature_builder` 和独立输出目录，避免复用旧 cache 污染结果。
6. 结论只看 train 以外 split：`val`、`test`、`extrapolation`；train 只用于判断过拟合。

#### D0 特征分层

现有入口 `tv3/ml/rocket_features.py` 的 `DEFAULT_PHYSICS_ARRAYS` 包含以下数组：

```python
(
    "ultrasonic_tof_s",
    "ultrasonic_tof_observed_s",
    "ultrasonic_peak_index",
    "ultrasonic_sound_speed_m_per_s",
    "ultrasonic_sound_speed_estimated_m_per_s",
    "ultrasonic_alpha_true_npm",
    "ultrasonic_tof_quality",
    "ultrasonic_tof_accepted",
)
```

按 D0 目的分为三层：

| 层级 | 特征 | 用途 |
| --- | --- | --- |
| forbidden oracle | `ultrasonic_alpha_true_npm`、`ultrasonic_sound_speed_m_per_s` | 只允许出现在 D0-oracle 和贡献诊断中，不允许进入 D0-observed、D1-D5 的部署路径 |
| audit-only / 辅助监督候选 | `ultrasonic_tof_s` | 若它来自仿真真实 TOF 或无噪声 TOF，只能用于 D0-oracle 或 D2 auxiliary target；不得作为 D0-observed 输入 |
| observed physics | `ultrasonic_tof_observed_s`、`ultrasonic_peak_index`、`ultrasonic_sound_speed_estimated_m_per_s`、`ultrasonic_tof_quality`、`ultrasonic_tof_accepted` | D0-observed 主输入，也是后续 D1 / D4 的可部署基线输入 |
| slow observed | `V_NDIR_CO2`、`V_TCS`、`T_C`、`P_MPa`、`H_RH`、`L_m`、`piston_position_m` | 可观测慢通道；全部允许进入 D0-observed |

实施前必须确认 `ultrasonic_tof_s` 的语义来源：如果它是仿真真值或理想无噪声 TOF，归入 `audit-only`；如果它确认为传感器算法输出，则需要在文档和 config 中改名或注明来源，避免与 `ultrasonic_tof_observed_s` 形成双来源真相。

#### D0 实验矩阵

建议新增以下基线：

| 实验          | 输入                                                                               | 目的                 |
| ----------- | -------------------------------------------------------------------------------- | ------------------ |
| D0-oracle   | 当前 R0 全部物理标量                                                                     | 复现实验上限             |
| D0-observed | 移除 `alpha_true`、true sound speed 等不可观测真值，只保留 observed TOF / peak / quality / 环境量 | 估计真实传感器可部署上限       |
| D0-tof-only | 仅 TOF / peak / quality + slow                                                    | 判断 O2 是否主要由 TOF 支撑 |
| D0-slow-only | 仅 slow 7 通道 | 作为 slow-only 对照，确认 O2 不能主要靠慢通道伪相关解释 |
| D0-no-tof | D0-observed 移除 `tof_observed`、`peak_index`、`tof_quality`、`tof_accepted` | 估计 TOF 相关观测对 O2 的必要性 |
| D0-no-tcs | D0-observed 移除 `V_TCS` | 估计 TCS 热导弱信号对 O2 / N2 的边际贡献 |

第一轮最低必须完成 `D0-oracle`、`D0-observed`、`D0-tof-only`；其余三组用于解释贡献，若时间不足可作为第二批。

**D0 判读结论（规则触发情况）**：

- **规则3 触发**：oracle 0.6025 − observed 0.4226 = **0.1799 > 0.10**，R0 明显受 oracle 特征抬升，**优先 D2，不急做复杂融合**。
- **规则4 触发**：tof_only 0.3879 ≈ observed 0.4226（差 0.035），O2 主要由 TOF 支撑，D2 优先级上升。
- **规则5 未触发**：no_tof −0.0013 ≈ slow_only，TOF 移除后 O2 完全失效，无泄漏（estimated_sound_speed 随 TOF 一并移除）。
- **规则6 触发**：no_tcs 0.4297 vs observed 0.4226，差 0.007 < 0.02，TCS 降级。
- **规则7 触发**：即使 oracle 的 o2_bins 也全负（−9.2 ~ −2.6），结论写"可分辨大档位，窄区间精细辨识不足"。

**下一步：D2 优先、D1 暂缓**。D2 上限 oracle 0.6025，空间 0.18；D1 不解决 oracle 膨胀根源，天花板 observed 0.42–0.47。R5'（D0-observed + 小 MLP）作 D2 启动前预检。详见 [掘进通风项目记忆库.md §6.4/§8.4](掘进通风项目记忆库.md)。

> **2026-07-09 修订**：上述"D2 优先"判断已被训练结果推翻——D2 实测 O2 val R²=−0.015（远低于 D0-observed 0.4226），raw waveform 端到端路线证伪。修订为：**R5'（physics_stats + 小 MLP）** 作下一步预检；D2/D1 端到端与序列路线均不再作为 O2 提升主线。

#### D0 判读规则

以 O2 为主，CO2 / N2 为约束：

1. 若 `D0-observed O2 R2 >= D0-oracle O2 R2 - 0.03`，说明 R0 几乎没有 oracle 膨胀，D1 / D4 可直接以 D0-observed 为强基线推进。
2. 若差距在 `0.03-0.10`，说明 oracle 有边际影响；D1 仍可推进，但所有论文式表述必须以 D0-observed 为真实基线。
3. 若差距 `> 0.10`，说明 R0 明显受 oracle 特征抬升，应优先推进 D2 的 TOF / phase 可微估计，不应急于做复杂融合。
4. 若 `D0-tof-only` 接近 D0-observed，说明 O2 主要由 TOF 相关量支撑；D2 优先级上升。
5. 若 `D0-no-tof` 仍接近 D0-observed，需要排查是否存在 estimated sound speed 泄漏或 slow/env 伪相关。
6. 若 `D0-no-tcs` 与 D0-observed 差距小于 0.02，TCS 对 O2/N2 的边际贡献可暂时降级；若差距大于 0.05，D1/D3 应保留 thermal node。
7. 若 D0-observed 的 `o2_bins` 仍全部为负，即使整体 O2 R2 接近 0.60，也应把结论写成“可区分大档位，窄区间精细辨识不足”。

### D1：Observed-Physics PatchTST / iTransformer

目的：不直接处理 raw waveform，先让深度时序模型消费可观测物理序列，验证深度模型能否超过 Ridge。

输入：

- `tof_observed`
- `peak_index`
- `tof_quality`
- estimated sound speed
- NDIR CO2
- TCS
- temperature / pressure / humidity
- path length
- phase position

结构候选：

```text
-+-+- physical sequences (B, T, C)
      -> channel-wise normalization
      -> PatchTST 或 iTransformer backbone
      -> attention / mean pooling
      -> component-specific heads
      -> CO2 / O2 / N2
```

关键设计：

- 对每个物理通道保留独立 token 或 patch，不把所有通道过早混成一个 timestamp token。
- 使用 O2 加权 MSE，但不取消 CO2 / N2 直接监督。
- 输出仍为三组分直接回归，不使用 N2 闭包残差头。

验收：

- 对比 D0-observed Ridge，而不是对比含 oracle 的 R0。
- O2 val / test / extrapolation 均提升超过 0.05 才算有效。
- `o2_bins` 不能比 D0-observed 明显恶化。

### D2：Differentiable TOF-PhaseNet

目的：替代当前 `DeepAcousticEncoder1D` 的普通 CNN 前端，让网络显式学习 TOF / phase / envelope 等物理量。

结构：

```text
raw ultrasonic frame (B, T, L)
  -> fixed or learnable matched filters
  -> envelope / Hilbert-like magnitude
  -> cross-correlation or GCC-PHAT feature map
  -> softargmax lag / peak sharpness / phase delay / SNR
  -> temporal TCN or Transformer
  -> CO2 / O2 / N2 heads
```

可输出的中间物理特征：

- soft TOF
- peak index
- peak sharpness
- correlation peak ratio
- phase delay
- local envelope energy
- bandwidth / peak width
- SNR proxy

训练方式：

- 主任务：三组分回归。
- 辅助任务：预测仿真侧已有的 `ultrasonic_tof_s`、`ultrasonic_peak_index`、`tof_quality`。
- 辅助任务只作为训练监督，不作为推理输入，避免 oracle 泄漏。

优势：

- 把 R0 的物理优势转成 DL 可学习目标。
- 保留 raw waveform 路线，但不再依赖普通 CNN 自发发现亚样本 TOF。
- 中间量可诊断：如果 TOF 辅助任务都学不好，则不应继续调三组分 head。

### D3：GasGraph Fusion Transformer

目的：解决简单 concat / FiLM / gate 难以表达传感器物理依赖的问题，避免强 CO2 分支压制弱 O2 分支。

节点设计：

| 节点                        | 输入                                    | 主要贡献                |
| ------------------------- | ------------------------------------- | ------------------- |
| CO2 optical node          | NDIR CO2                              | CO2 主信息             |
| thermal node              | TCS                                   | O2 / N2 弱信息         |
| acoustic TOF node         | TOF / phase / peak                    | O2 / N2 主信息         |
| acoustic attenuation node | envelope / energy / attenuation proxy | CO2 / N2 / H2O 耦合信息 |
| environment node          | T / P / RH / path length              | 声速与传感器补偿            |
| phase node                | ventilation phase / timestep position | 动态响应上下文             |
| optional fiber node       | fiber_mic derived features            | 备选增量                |

结构：

```text
per-node encoder
  -> graph attention / graph transformer
  -> temporal encoder over 512 timesteps
  -> component-specific heads
```

图边先验：

- environment -> acoustic TOF
- environment -> thermal
- CO2 optical -> attenuation
- acoustic TOF -> O2 / N2 heads
- CO2 optical -> CO2 head

验收：

- O2 head 的 attention / gate 必须能显示使用 acoustic TOF node。
- 如果 O2 仍主要依赖 CO2 optical node，则说明融合仍在走伪相关。

### D4：Ridge-Teacher Residual DL

目的：降低 DL 从零学习绝对浓度的难度，让模型只学习 R0-observed 没有解释的残差。

结构：

```text
Ridge_observed prediction
  + residual_network(observed physics + D2 raw-derived features)
  -> final CO2 / O2 / N2
```

训练目标：

```text
loss = MSE(y_pred, y_true)
     + lambda_residual * MSE(residual_pred, y_true - y_ridge)
```

关键约束：

- Ridge teacher 必须来自 D0-observed，不能用 oracle R0。
- residual 不能无限放大，建议加 residual norm penalty。
- 若 residual 只提升 train 而不提升 val / test / extrapolation，则判定过拟合。

验收：

- 相对 D0-observed，O2 val / test / extrapolation 均提升超过 0.05。
- CO2 不得低于 D0-observed 超过 0.02。
- `sum_abs_error` 不能恶化。

### D5：Self-Supervised Acoustic Pretraining

目的：解决 6000 sequence 对端到端 raw waveform 学习仍偏少的问题。

预训练任务：

| 任务                          | 输入                         | 目标                           |
| --------------------------- | -------------------------- | ---------------------------- |
| masked patch reconstruction | raw ultrasonic patches     | 重建被 mask 的局部波形               |
| time-shift prediction       | 人工平移波形                     | 预测 shift 大小                  |
| adjacent contrastive        | 相邻 timestep / 非相邻 timestep | 拉近同一 sequence 局部上下文          |
| TOF auxiliary               | raw waveform               | 预测 observed TOF / peak_index |

使用方式：

1. 先用所有 raw ultrasonic frame 预训练 encoder。
2. 冻结或半冻结前几层。
3. 接 D2 或 D3 做三组分微调。

验收：

- 预训练后的 encoder 在 TOF auxiliary probe 上显著优于随机初始化。
- 微调后 O2 至少超过 D0-observed + 0.05，否则不继续扩大预训练复杂度。

## 4. 推荐实验顺序

```text
D0: R0-observed Ridge / MLP
  -> D1: observed physics PatchTST or iTransformer
  -> D2: differentiable TOF-PhaseNet
  -> D3: GasGraph Fusion Transformer
  -> D4: Ridge-teacher residual DL
  -> D5: self-supervised pretrain + D2/D3 fine-tune
```

优先级：

| 优先级 | 实验  | 原因                     |
| --- | --- | ---------------------- |
| P0  | D0  | 先拆清 oracle 与可观测上限      |
| P0  | D1  | 最小 DL 改动，直接验证物理序列深度建模  |
| P1  | D2  | raw waveform 路线的正确重启方式 |
| P1  | D4  | 小样本下比纯端到端更稳            |
| P2  | D3  | 对多模态融合最有潜力，但实现复杂       |
| P2  | D5  | 适合作为 D2/D3 仍不足时的增强     |

## 5. 不建议继续的方向

1. 不继续 R3 / R4 / R6 raw MultiRocket / Hydra 主线：R1b 已经给出负结果。
2. 不直接加深现有 `cnn1d_tcn_fusion`：问题不是容量不足，而是前端没有对准 TOF / phase。
3. 不把 N2 改成闭包残差头：仍保持 CO2 / O2 / N2 三组分直接监督。
4. 不把 `alpha_true`、true sound speed 等仿真真值混入可部署模型输入。
5. 不用复杂融合结构掩盖前端失败；如果 TOF / phase probe 失败，应先修前端。

## 6. 近期落地建议

第一轮只实现 D0 + D1 + D2 的最小闭环：

1. 新增 D0-observed 特征配置，明确排除 oracle 特征。
2. 在现有 `patchtst.py` 或新增 `observed_physics_transformer.py` 中实现 D1。
3. 新增 `tof_phase_net.py`，先用 fixed matched filter + softargmax，不急于做复杂可学习滤波器。
4. 为 D2 增加 auxiliary metrics：TOF MAE、peak index MAE、TOF correlation。
5. 所有实验统一输出 val / test / extrapolation 的 per-component R2、MAE、RMSE 和 `o2_bins`。

第一轮成功标准：

- D0-observed 明确给出真实可观测上限。
- D1 或 D2 至少有一个使 O2 R2 相对 D0-observed 提升超过 0.05。
- 若 D2 的 TOF auxiliary 学不好，停止 raw waveform DL 路线，回到物理序列模型。
