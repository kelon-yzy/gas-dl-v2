## 一、项目边界与硬不变量

### 1.1 场景

tv3 面向掘进工作面空气质量监测，使用 NDIR、超声、TCS 和可选 fiber_mic 信号预测：

```python
COMPONENT_FIELDS = ("x_CO2", "x_O2", "x_N2")
BACKGROUND_FIELDS = ()
SLOW_CHANNELS = (
    "V_NDIR_CO2",
    "V_TCS",
    "T_C",
    "P_MPa",
    "H_RH",
    "L_m",
    "piston_position_m",
)
```

- 数据 schema：`tunnel-ventilation-1`
- 数据集命名：`tv3-*`
- 包入口：`pip install -e ./tunnel_ventilation` 后使用 `python -m tv3.xxx`
- 场景只含 CO₂/O₂/N₂；CH₄、CO 或 O₂ 专用硬件属于新阶段

### 1.2 模型与数据契约

1. 标签严格满足 `x_CO2 + x_O2 + x_N2 = 100%`，但正式模型必须直接输出 `raw3`、`out_dim=3`。
2. 不使用 `gas_head`、N₂ 闭包回填、ILR/ALR、`target_transform`、`free_component_mse` 或闭包残差头。
3. `sum_abs_error` 是监控指标，不是强制输出约束。
4. 仿真真值 `tof_s`、true sound speed、true alpha 只能作为 oracle 审计或 auxiliary target，不能进入部署输入。
5. 正式 observed 头冻结为 `d0_observed_physics_stats_v1`；变更特征必须使用新 builder 名称。
6. 缺失 manifest、waveform scale、slow metadata 或必需数组时直接失败，不添加静默 fallback。
7. 波形 DL 输入契约：`dequantize_waveforms` + 可选 `normalize_waveforms` / `waveform_stats_features`；组装通道顺序为 slow → 归一化前 stats → 波形样本。正式波形配置默认 **`waveform_preprocess: "gpu"`**（DataLoader 只搬 int16+scale，设备侧 dequant/stats/z-score），数值语义与 `cpu` 路径对齐；gpu 路径不支持 `window` / `phase_windows` / `augment`，违例直接失败。

### 1.3 数据可信度

- clean `tv3-formal-6000`：仅在服务器，7 个 slow 通道，无 `V_NDIR_CH4`。
- 旧本地 `tv3-formal` 600：含额外 `V_NDIR_CH4`，slow 特征已污染，不得用于正式模型比较。
- 本地旧数据的 raw ultrasonic 链路仍可用于峰值定位和 waveform fidelity 调试，但必须显式注明不是正式性能证据。

### 1.4 名词导读与联更义务

- 初学者与协作入口：`docs/methods/tv3_名词与实验顺序导读.md`。按实验顺序（契约 → D0 → D2/D2b → R 系列 → B1–B7 → 模块 C → 可辨识性）分级解释 tv3 名词；**不**替代本记忆库的正式结论源。
- **强制联更**：新增或重命名正式实验阶段、代码模块、算法/builder/头、协议门禁、verdict 状态或关键物理量时，必须**同一变更批次**更新该导读中的名词定义、分级位置与索引；禁止只改代码或专项计划而留下过时讲解。
- 导读与本记忆库冲突时，以本记忆库的正式指标与不变量为准，并回头修正导读。
- 纯本地 smoke、未验收草稿可暂缓写入导读；一旦进入 `active/` 正式计划、默认头/协议或本记忆库结论表，导读必须同步可读。

### 2.2 当前结论栈

1. **O₂ 不是完全无信号**：整体 18–21.2% 范围内，TOF/声速可以支持粗粒度辨识。
2. **窄区间存在物理墙**：即使 oracle 在 0.8% O₂ bins 内 R² 仍全负；模型不应承诺精细分辨。
3. **D0-observed 是测量级 baseline**：它读取仿真器同步生成的 observed TOF、peak、estimated sound speed 和 quality。D2b B1 已以 RawDSP 特征复现其线性组分性能；train-calibrated 帧级 fidelity 已通过。
4. **D2 失败不等于所有 raw waveform 路线失败**：当前失败实现的 auxiliary 峰值输出不可训练，TOF 指标还混入固定延迟坐标偏置。
5. **TabPFN 证明当前 observed 特征契约存在可学习非线性**，但不证明 raw 传感链路已部署，也不证明真实 OOD 泛化。
6. **默认 R5 的失败主要是目标尺度导致的优化问题**：R5-T 仅增加逐目标标准化；三个新增 seed 的 O₂ R²均值为 val/test/extrap `0.6631 / 0.6438 / 0.5890`，标准差 `0.0082 / 0.0055 / 0.0197`。
7. **闭包不是已证实根因**：正式 raw3 契约不变；二输出加 N₂ 回填不能作为当前主线的“最小修复”。
8. **B6 稳定证明 R5-T 配方可迁移到 RawDSP**：三个新增 seed 的 O₂ R²均值为 val/test/extrap `0.5581 / 0.5356 / 0.4835`，标准差 `0.0096 / 0.0170 / 0.0036`；每个 seed 均超过 B1 对应门槛，但仍低于 R5-T observed。
9. **B7 `protocol_pass`：OOF Ridge + 残差 MLP 是当前默认 RawDSP 头**：完整 `R / L / S-Y / S-L × 3 split seed × 3 training seed` 矩阵通过审计。B7 对 B1 的 test / OOD O₂ ΔR²均值为 R `+0.2323 / +0.1923`、L `+0.2208 / +0.2606`、S-Y `+0.1740 / +0.7009`、S-L `+0.1895 / +0.2570`；`sum_abs_error` 约 `2e-4–4e-4`。不扩大本 residual 结构。
10. **OOD 结论有 selector 边界**：S-L 的 B7 OOD O₂ R²为 `0.7002 ± 0.0260`，S-Y 仅为 `0.4340 ± 0.0279`，后者相对 B1 虽显著提升但不支持“所有 OOD 均达到 0.70”。S-Y 三个 split seed 的 OOD 集相同，只量化同一 target-margin OOD 上的 ID 划分与训练 seed 方差；S-L 才提供随 seed 变化的 OOD 集复核。
11. **模块 C P0 已证伪物理早期分组**：在冻结 B7 的 12 个派生 split 上，C1 physical grouped bottleneck 的 24 条正式矩阵完整且审计通过，但判定 `grouped_failed`。C1 的 test O₂ R²相对 B7 在 R / L / S-Y / S-L 的均值差为 −0.1482 / −0.1392 / −0.1303 / −0.1350；S-Y / S-L OOD 差为 −0.2662 / −0.1823，均远低于 −0.01 非劣门。
12. **失败来自早期物理隔离，不是总容量下降**：同为 28,051 参数的 C2 permuted 在 S-Y / S-L 上相对 C1 的 OOD 均值高 0.0929 / 0.1706，但 C2 自身仍不能替代 B7，尤其 S-Y OOD 为 0.2877、较 B7 低 0.1733。当前证据只否定“各物理组先独立压缩到 16 维”的 C1 配方，不泛化为全部低参数或全部物理引导结构失败。
13. **当前分流**：停止 C1 的 bottleneck 维度、group dropout、group gating 与 C1 encoder TabM 扩展；B7 保持默认 RawDSP 头。若研究 flat residual TabM，须另立冻结计划；所有 OOD 仍分别报告 S-Y 与 S-L。
14. **首轮可辨识性审计确认单向 TOF 需要信息源升级**：冻结 B1/B7 后在 189 个点完成 v1 审计；声速仅作为 TOF 派生诊断，未重复计入 Fisher。对 O₂、CO₂、T、L 的联合 Fisher 秩为 1，不能做 nuisance 边缘化；1 K 温度与 3 μs trigger jitter 情景下，0.8% O₂ 窄窗口的联合 P90 为 8.85–12.99% O₂。已基于法规下限、温湿补偿超声文献和窄窗口宽度预注册 P90=`0.4 vol%`、单 nuisance 比例=`50%` 和拒绝率=`5%`（见 `references/tv3_identifiability_business_threshold_evidence.md`）；当前预算远超前两门。flow 未由 v1 表示，因而 `v1_blocking_nuisance_reject_all` 拒绝 189/189 点，100% 拒绝率也超过门限，正式 verdict 为 `information_source_upgrade_required`。这限定为单向 TOF 情景，不是部署精度或对补齐 flow 后声学路线的最终否定。
15. **静止空气仿真可辨识性仍并行，不推翻 v1 verdict**：S 线在配置中显式固定 `flow=0`，登记 trigger jitter、固定延迟、声程、T/RH/P、SNR 与设备 profile 边界；通过只说明已登记数字孪生范围内成立，不得改写为真实静止空气或掘进通风现场能力；详见 `active/tv3_static_air_feasibility_implementation_plan.md`。
16. **COMSOL P0 气室孪生已登记边界**：推荐打开 `tunnel_ventilation/COMSOL/tv3_acoustic_p0_clean.mph`（`flow=0`、混合气 `ρ/c`、200 kHz TX、RX 变量 `p_rx`、输出时间 `range(0,1e-6,1e-3)`）。声速公式与 Python `acoustic_physics` 对齐（见 `p0_sound_speed_acceptance.csv`）。NDIR / TCS 以独立解析通道验收，不与声学同瞬态强耦合。本孪生只服务正演与可辨识性对照，**不得**改写 B7 或现场精度声明；入口见 `COMSOL/README.md`。
17. **双向 F 线 F4 已解除 flow 阻断，业务仍为粗监测**：identifiability v2（`outputs/tv3_bidir/identifiability_v2/`）将 `flow_projection` 标为 `implemented_physics`，拒绝率 0；联合声学 Fisher 非秩亏。窄窗 P90 名义臂 max≈4.37 vol% O₂（主导 1 K 温度）、保守臂≈9.58（主导 3 μs jitter），故业务 verdict=`coarse_monitoring_only`，**不**改写 v1 目录与结论行。F5 幅度门已预注册（A3−A1≥0.5、A3−A2≤0.25、零锚点 Δ≤0.05、selector ΔR²≥−0.01）；五臂协议代码与 `bidir-formal-6000` preset 已就绪，正式 `tv3-bidir-6000` 训练与门控回填须在服务器完成后再进 F6。

## 三、物理、采样与传感链路

### 3.1 核心物理

| 量        | CO₂   | O₂      | N₂    | 判读                |
| -------- | -----:| -------:| -----:| ----------------- |
| M，g/mol  | 44.01 | 31.9988 | 28.01 | O₂/N₂ 质量差使声速可辨    |
| γ，300 K  | 1.289 | 1.400   | 1.400 | O₂/N₂ 无 γ 差异      |
| λ，mW/m·K | 16.6  | 26.4    | 25.8  | TCS 对 O₂/N₂ 仅边际有效 |

当前声速模型：

```text
c = sqrt(gamma_mix * R * T / M_mix)
```

声速直接依赖组分和温度；当前模型中的 P/RH 主要影响衰减、光学与慢通道，不应未经消融就当作声速校正主项。

### 3.2 仿真规格

| 参数               | 值                                                                                 |
| ---------------- | --------------------------------------------------------------------------------- |
| 载波 / 采样率         | 200 kHz / 1 MS/s                                                                  |
| ultrasonic frame | 5 ms，5000 点                                                                       |
| 物理 ADC / 存储      | 20-bit；正式数据 int16 + per-timestep scale；训练默认设备侧 dequant（`waveform_preprocess=gpu`） |
| 声程扫描             | steady phase 使用 0.18、0.20、0.22、0.25、0.28 m                                        |
| 固定延迟             | system 80 μs + cable 2 μs                                                         |
| trigger jitter   | std 3 μs                                                                          |
| waveform 模型      | 8-cycle burst + transducer response + Lagrange fractional delay                   |

### 3.3 传感器贡献

| 模态         | 对 CO₂ | 对 O₂/N₂    | 当前判断                 |
| ---------- | ----- | ---------- | -------------------- |
| V_NDIR_CO2 | 强     | 无直接信息      | CO₂ 主通道              |
| ultrasonic | 强间接信息 | 主信息源       | D2b 主战场              |
| V_TCS      | 有边际信息 | O₂/N₂ 差异很弱 | no_tcs 与 observed 接近 |
| fiber_mic  | 未正式评估 | 未知         | 低优先级                 |
| O₂ TDLAS   | 无     | 直接信息       | 突破 0.70 的物理后备路线，当前暂停 |

### 3.4 采样与 split

- `x_CO2`：0.03–5.00%
- `x_O2`：18.00–21.20%
- `x_N2 = 100 - x_CO2 - x_O2`
- 采样：CO₂/O₂ 受约束 LHS

现有 formal 数据的 random extrapolation 只是 shuffle 剩余，不是真正 OOD。B7 已完成 observed-only repeated split + 双 selector 复核：R/L 仅作 ID 稳定性对照，S-Y（`y_margin_ood`）与 S-L（`lhs_boundary`）均为组分边界 OOD 证据。

- S-Y 三个 split seed 的 `ood_set_hash` 相同；重复只量化同一 OOD 集上的 ID 划分与训练 seed 方差。
- S-L 三个 split seed 的 OOD 集不同；L 与同 seed 的 S-L 共享 `lhs_boundary` OOD 集，L 不额外构成独立 selector 证据。
- 因而 B7 可以声明相对 B1 的双 selector OOD 增益，但不能将任一单 selector 的绝对 R²外推为全部物理 OOD 或真实硬件泛化。

## 五、根因与模型审查

### 5.1 D0-observed 的语义

`d0_observed_physics_stats_v1` 使用：

- `ultrasonic_tof_observed_s`
- `ultrasonic_peak_index`
- `ultrasonic_sound_speed_estimated_m_per_s`
- `ultrasonic_tof_quality`
- `ultrasonic_tof_accepted`

这些量由仿真器生成 waveform 时同步计算，并非从保存的 raw waveform 重新估计。因此它是 D2b 要复现的测量级上限；在 RawDSP parity 通过前，不称为现有端到端 raw 可部署链路。

### 5.2 D2 为什么失败

1. 旧 CNN 的 global avg/max pooling 对平移不敏感，丢失 TOF 位置信息。
2. D2 的 matched filter 核和 softargmax temperature 固定；`aux.tof_s` 与 `aux.peak_index` 在可训练 projection 前输出。
3. 梯度审计：主 prediction 可训练，但两个 auxiliary 输出 `requires_grad=false`；辅助 loss 不能训练峰值估计器。
4. TOF 以秒、peak 以归一化 index 做 SmoothL1，现有量级下 auxiliary 项约 `1e-9`，相对主 loss 可忽略。
5. waveform peak 对应 true TOF + 82 μs 固定延迟 + jitter；84.2 μs MAE 不能直接解释为峰值定位误差。
6. D2 没有显式生成 corrected TOF 与 `sound_speed=L_m/tof`，把校准、除法和 L_m 去混杂交给小样本 TCN 隐式学习。

D2 正式失败结论保留，但原实现不再继续叠补丁。新路线独立为 D2b / RawDSP。

### 5.3 D2b 局部证据

旧本地 600 的 8 条序列 × 64 帧，共 512 帧，只做 raw waveform fidelity：

| 指标                               | 结果                      |
| -------------------------------- | -----------------------:|
| 完整模板相关后的连续 peak MAE              | 0.019 sample，即 0.019 μs |
| peak bias / std                  | −0.00017 / 0.021 sample |
| peak P95 绝对误差                    | 0.030 sample            |
| 重建声速对 stored estimated speed MAE | 0.010 m/s               |

这证明仿真 waveform 信息可由固定 DSP 恢复。clean 6000 的正式 manifest 已确认 train-only template、全量 6000 序列和非 diagnostic 模式；B1 Ridge 的 val/test/extrap O₂ R² 为 0.4280 / 0.4786 / 0.3695，相对 D0 差值为 +0.0054 / +0.0215 / -0.0013，模型 parity 通过。train-calibrated 帧级 fidelity 已通过：peak P95 为 0.04443 sample，且 val、test、extrapolation 的全部门均通过。

### 5.4 R5 小 MLP 的正确判读

R5 实际已经具备：

- 输入 `StandardScaler`
- loss 权重 `[1, 2, 1]`
- 直接按 val O₂ R² early stopping
- observed estimated sound speed 输入

因此以下说法不成立：

- “输入没有标准化”
- “O₂ 没有加权”
- “早停被 CO₂/N₂ 掩盖”
- “MLP 必须自己发现 L/TOF”

默认 R5 后真正待验证的因素曾包括：

1. **目标中心化与尺度**：已由 R5-T 验证为默认 R5 失败的主要因素；R5-T 只标准化训练目标便在三 eval split 通过 D0+0.05。
2. **模型相对样本过大**：864 特征、约 4200 train rows、254,723 参数，属于高维强共线表格，不是低维表格。
3. **共享 trunk 的多任务冲突**：可能存在，但没有 gradient cosine 或独立目标对照证据。
4. **表格归纳偏置**：TabPFN 成功不意味着从零训练 MLP 应该成功。
5. **特征冗余**：大量 phase/window 统计可能使普通 MLP 优化困难。

### 5.5 闭包与多目标判断

- 数学上标签只有两个自由度，但正式模型契约选择 raw3 直接输出。
- 二输出加 N₂ 回填会机械消除 closure error，却不保证 O₂ 改善。
- Ridge raw3 可以同时取得近零 closure error 和有效 O₂；TabPFN O₂ 高但 closure error 非零。
- 因此闭包回填只能作为显式变更契约后的独立研究分支，不能混入 R5-T 或 R7 主实验。

若要检验多目标梯度冲突，应比较：

1. shared-trunk raw3 MLP；
2. 三个独立 single-target MLP，最终组合为 raw3；
3. shared trunk + 独立 heads。

该对照不改变正式输出契约。

### 5.6 TabPFN 结论边界

可确认：

> 当前 864 维 simulator-derived observed 特征和当前随机 split 下，存在可被强表格先验利用的非线性。

尚不能确认：

- 非线性来自真实硬件物理而非仿真派生特征；
- raw waveform 到 observed 特征的链路已闭环；
- 真正 OOD 或新硬件条件下仍保持 0.66；
- 普通 MLP、树模型或轻量部署头能复现同等收益。

10. EC-MSW E1d 正式找到 compact 集合：只允许实现该集合的可部署 sequence builder 并重过 parity；禁止把完整 RawDSP 当端到端改进，禁止启动 E2 FiLM/attention/MoE；禁止仅用 TOF-L LS 头绕过 SNR 需求。
11. EC-MSW E1d-SB 正式 `parity_passed` 后：只允许 E1r attachment（probe-only）联合审计；attachment 未过门前不得启动 E2，不得用 full B1 包装端到端改进。
12. EC-MSW E1r attachment 正式 `attachment_passed` 后：仍禁止 E2 FiLM/attention/MoE；B7 保持默认头；可选 LS 消融不得删掉 SNR。
13. EC-MSW E2s-LS 正式 `ls_ablation_passed` 但相对 e1d_sb 的 O₂ 增益可忽略：不晋升 LS；默认序列表示保持无 LS 的 e1d_sb；下一步仅允许另立的可部署联合系统计划。
