## 一、项目概述

**掘进通风场景**（代号 `tv3`）是 `gas-dl-v2` 多模态气体检测项目的第三个检测场景，独立于掺氢天然气（`hg`/`wv4-*`）与合成气（`sg`/`sg4-*`）主线。场景面向巷道掘进面附近空气质量的实时监测，核心任务是基于 **NDIR 光学 + 超声波 + 光纤麦克风 + TCS 热导** 四模态传感器仿真信号，预测空气中 **CO₂ / O₂ / N₂** 三组分浓度。

**场景边界**：掘进通风，不引入可燃气体或毒性气体扩展；后续若加入 CH₄、CO，应作为新阶段单独评估。

**与 hg / sg 的本质差异**：

1. **空气基底**：组分以空气为主背景（N₂ ≈ 78%，O₂ ≈ 21%），而非可燃气体混合物。
2. **N₂ 是预测目标**：不同于 syngas 中 N₂ 作为背景气，本场景直接预测 N₂，写入 labels，不作为 `background_fields`。
3. **O₂ 可观测性受限**：O₂ 为同核双原子，无红外指纹，仅能通过声学和热导间接推断。

**子工程化**：2026-07-07 场景隔离重构后，tv3 成为自包含子工程，包名 `tv3`，独立 `pyproject.toml`，原 `src/` 下的 sim/dl/ml/pipeline/common 全部迁入 `tunnel_ventilation/tv3/` 下，`pip install -e ./tunnel_ventilation` 后以 `python -m tv3.xxx` 调用。

**clean 6000 D0 关键结果（val）**：oracle O₂ R²=0.6025、observed=0.4226、tof_only=0.3879、slow_only=−0.0013、no_tof=−0.0013、no_tcs=0.4297。

**核心判读**：

1. **Oracle 膨胀 0.18**：oracle 0.6025 − observed 0.4226 = 0.1799 > 0.10，R0 的 0.603 不可部署，真实 baseline 是 D0-observed 0.4226。
2. **o2_bins 物理极限**：即使 oracle 在 0.8% O₂ 窗口内 R² 也全负（−9.2 ~ −2.6），O₂ 窄区间辨识是物理极限，任何模型无法突破。
3. **TOF 是 O₂ 唯一可辨识来源**：tof_only ≈ observed，no_tof ≈ slow_only（O₂ 完全失效）。
4. **TCS 边际贡献微小**：no_tcs ≈ observed，差 0.007，TCS 降级。
5. **6000 样本 Ridge 健康度**：train-val gap 0.06–0.08，非过拟合，D0-observed 0.4226 是可信线性上限。

**结论：D2 优先、D1 暂缓**。D2（可微 TOF-PhaseNet）上限 oracle 0.6025，空间 0.18；D1 不解决 oracle 膨胀根源，天花板 observed 0.42–0.47。详见 §6.4 与 §8.4。

## 三、物理建模与仿真链路

### 3.1 仿真链路规格（v6-phys-strict）

| 参数      | 值                             | 说明                                              |
| ------- | ----------------------------- | ----------------------------------------------- |
| 超声载波    | 200 kHz (PSC200K)             | 200kHz 下长声程信号被 CH₄/CO₂ 弛豫吸收淹没，L_m 限制在 0.2–0.3 m |
| 采样率     | 1 MS/s (NI-6453)              |                                                 |
| ADC 位深  | 20-bit int32（物理 ADC），存储 int16 |                                                 |
| 超声窗口    | 5 ms -> 5000 点                |                                                 |
| 光纤麦克风窗口 | 10 ms -> 10000 点              |                                                 |
| 量程      | ±2.5 V                        |                                                 |
| 声程 L_m  | 0.20–0.30 m                   |                                                 |
| 分数延迟    | Lagrange 5 阶 FIR              | 亚样本 TOF 精度 <0.002μs                             |

### 3.2 三组分物性常数

| 气体  | M (g/mol) | γ (300K) | cp (J/mol·K) | c₀ (m/s) | λ₀ (mW/m·K) | η (Pa·s) |
| --- | ---------:| --------:| ------------:| --------:| -----------:| --------:|
| CO₂ | 44.01     | 1.289    | 37.13        | ~270.3   | 16.6        | 1.491e-5 |
| O₂  | 31.9988   | 1.400    | 29.38        | ~330.4   | 26.4        | 2.058e-5 |
| N₂  | 28.01     | 1.400    | 29.12        | ~353.1   | 25.8        | 1.781e-5 |

**O₂/N₂ 物理差异（辨识基础）**：

- 摩尔质量差 14.3%（32 vs 28）-> 声速差约 6.4%（~22 m/s）-> 超声通道区分两者的主要物理基础
- 热导率差约 2.3%（Δλ ≈ 0.6 mW/m·K）-> TCS 提供边际辨识力
- γ 相同（均 1.400）-> 声速差异完全来自摩尔质量，无比热比信号

**声学物理实现**（`tv3/sim/generation/tunnel_ventilation/acoustic_physics.py`）：

- 声速：理想气混合 `c = sqrt(γ_mix · R · T / M_mix)`，与主线同公式
- 热导：Wassiljewa-Mason-Saxena 混合规则，Wilke φ_ij 由公式计算无需查表
- 衰减：`α = α_classical + α_co2 + α_n2 + α_o2 + α_h2o`，其中 **α_o2 = 0**（O₂ V-T 弛豫频率 ~24 Hz/atm，200 kHz 载波下工程取 0）
- 空气组成下 c_mix ≈ 346 m/s @25°C（已通过单元测试交叉验证）

### 3.3 光学通道

- 仅 **CO₂** 有 NDIR 通道：ν₃ 吸收带 2349 cm⁻¹（4.26 μm），empirical_v1 后端可用
- O₂/N₂ 同核双原子，无红外活性，不设光学通道
- 无光学串扰矩阵（仅 CO₂ 一个红外活性组分）
- HITRAN 后端代码完整但被硬禁用，CLI 拒绝 `hitran_hapi_v1`

### 3.4 慢通道（7 通道，无 V_NDIR_CH4）

| 通道                      | 物理模型                                    | 动态性         | 组分辨识力             |
| ----------------------- | --------------------------------------- | ----------- | ----------------- |
| V_NDIR_CO2              | `2.5·exp(-α_co2)`，α_co2 含 CO2/RH/P/T 项  | 双 tau 上升/下降 | CO₂ 强             |
| V_TCS                   | `1.1 + 15·(λ_mix-0.026) + 0.004·(T-20)` | 双 tau 上升/下降 | O₂/N₂ 弱（2.3% 热导差） |
| T_C / P_MPa / H_RH      | 静态 = condition base 值                   | 无           | 无（环境条件）           |
| L_m / piston_position_m | phase schedule 驱动，5 档扫描 0.18-0.28m      | 扫描阶段线性      | 无（已知量）            |

phase blend 的 baseline 语义固定为标准新鲜空气（CO₂ 0.04%、O₂ 20.90%、N₂ 79.06%）。

## 四、数据契约与采样设计

### 4.1 组分字段约定

```python
COMPONENT_FIELDS = ("x_CO2", "x_O2", "x_N2")
BACKGROUND_FIELDS = ()  # N₂ 是目标，不是背景
SLOW_CHANNELS = ("V_NDIR_CO2", "V_TCS", "T_C", "P_MPa", "H_RH", "L_m", "piston_position_m")  # 7 通道
```

- `composition_scheme = "tunnel_ventilation"`，`schema_version = "tunnel-ventilation-1"`
- 数据集前缀 `tv3-*`，manifest 必含 `composition_scheme` / `background_fields` / `slow_channels` / `labels`
- 下游加载器优先读 manifest，不直接 import 全局常量推断 schema

### 4.2 采样区间与约束

| 变量    | 范围 (%)        | 说明              |
| ----- | ------------- | --------------- |
| x_CO2 | 0.03 – 5.00   | 新鲜空气到局部积聚上限     |
| x_O2  | 18.00 – 21.20 | 正常空气到低氧下限       |
| x_N2  | 73.80 – 81.97 | 由 CO₂ 和 O₂ 间接决定 |

联合约束：`x_CO2 + x_O2 + x_N2 = 100.0%`（严格闭包，`|sum-100|<1e-6`）。

**采样方法**：受约束 LHS，在 (CO₂, O₂) 二维空间采样，N₂ = 100 - CO₂ - O₂ 自动满足。

### 4.3 状态分层（评估用，不作模型输入）

| 状态                | 判定条件                                     | 物理含义      |
| ----------------- | ---------------------------------------- | --------- |
| fresh_air         | x_CO2 < 0.1 且 x_O2 > 20.5                | 新鲜空气，通风良好 |
| ventilation_decay | x_CO2 ∈ [0.1, 2.0] 且 x_O2 ∈ [19.5, 20.5] | 通风效率下降趋势  |
| co2_accumulation  | x_CO2 > 2.0                              | CO₂ 局部积聚  |
| oxygen_depletion  | x_O2 < 19.0                              | 缺氧风险区域    |

### 4.4 模型输出契约

- tv3 多模态 `cnn1d_tcn_fusion` 必须使用 `output_mode="raw3"`、`out_dim=3`，三组分直接线性输出
- `gas_head` 与 `target_transform`（ILR/ALR）在 tv3 路径下显式拒绝
- `sum_abs_error` 可作监控项，但不通过闭包残差头强制归零

### 4.5 存储优化（2026-07-05）

tv3 默认采用 **int16 + per-timestep scale + `--skip-fiber-mic`**：

- int32 -> int16：per-timestep scale 按每时步波形峰值定标，量化误差 max ~1e-5 V，远小于噪声 std 1e-3 V（误差/噪声 ≈ 1%）
- 跳过 fiber_mic：光纤代码全部保留，后续去掉开关即可恢复
- 物理 ADC 仍为 20-bit，存储 dtype 改为 int16

| 规模      | int32 + fiber_mic | int16 + skip-fiber-mic | 减幅   |
| ------- |:-----------------:|:----------------------:|:----:|
| 600 序列  | 17 GB             | 3 GB                   | -82% |
| 6000 序列 | 172 GB            | 29 GB                  | -83% |

### 4.6 SPXY 数据集划分策略（待实施）

当前 tv3 数据集划分为纯随机 shuffle（`random_mixture_id_split_v4`），LHS 的 space-filling 被破坏，extrapolation split 仅为 shuffle 末尾剩余。`spxy_split_implementation_plan.md` 设计了修订方案，核心不变量：

1. **SPXY 只在 ID pool 内选 train**（保证训练集覆盖 X/Y 空间），不参与 extrapolation 选择。
2. **extrapolation 由独立 OOD 规则产生**（`y_margin_ood` / `lhs_boundary` / `kmeans_boundary`），不来自 SPXY 剩余集。
3. **X/Y 特征必须先 `StandardScaler`**，否则跨数量级特征（tof ~10⁻⁷、声速 ~340）会使距离被大量级维度主导。
4. **val/test 不递归 SPXY**，改为从 ID 剩余样本做 Y 分箱分层随机。
5. SPXY 核心循环必须向量化（`np.min(d_xy[remaining][:, train_idx], axis=1)`），N=6000 时纯 Python O(N²·train_size) 不可接受。
6. **划分策略分工**：SPXY/LHS 分箱分层 → train 覆盖；K-means 边界簇 → OOD 候选；XYOnion 外壳 → OOD 备选；repeated stratified K-fold → 性能方差量化。

推荐第一版落地组合：`spxy_v1 (α=0.5) + y_margin_ood`。实验对照矩阵含 random/LHS stratified/SPXY/K-means OOD/XYOnion smoke 五组 split × TCN/Ridge 两个模型，共 12 runs。详见 `spxy_split_implementation_plan.md`。

### 5.2 Loss 体系

- **允许**：`weighted_component_mse`、`mse`、`mae`、`smooth_l1`、`huber`
- **拒绝**（闭包类）：`compositional_mse`、`ilr_mse`、`free_component_mse`、`weighted_free_component_mse`
- `validate_loss_composition_scheme()` 自动拒绝闭包 loss
- `target_transform` 不可用（ILR/ALR 依赖 sum=100% 闭包头）
- 推荐权重 [1.0, 2.0, 1.0]：O₂ 物理可观测信号最弱，2× 权重补偿学习难度
- conditional_metrics 固定按 `o2_bins` / `co2_bins` 分箱

### 5.3 三层归一化方案（针对 raw 波形尺度问题）

v2 实测暴露 fusion 模型 raw 波形与 slow 标量尺度失衡问题，方案按成本从低到高分三层：

| 层   | 方案                                 | 对标          | 实测结果                       |
| --- | ---------------------------------- | ----------- | -------------------------- |
| 层 1 | 数据层 per-timestep z-score + 幅度统计侧通道 | wav2vec 2.0 | v3 val R²=-3.03            |
| 层 2 | 模型层拼接前 LayerNorm                   | UTOPYA      | v3_l2 val R²=+0.019（最优）    |
| 层 3 | FiLM 调制 + gated fusion             | UTOPYA      | v3_l3 val R²=-0.001（无额外收益） |

工程约束：`normalize_waveforms=true` 必须同时满足 `dequantize_waveforms=true` 与 `waveform_adc_scale=1.0`；CLI 支持 `--no-normalize-waveforms` / `--no-dequantize-waveforms` 回退；`raw3` 输出头由训练标签均值初始化 bias。

### 5.4 固定特征回归分支（Rocket 系列）

针对端到端 DL 训练失效，实现固定卷积核时序特征 + Ridge/ElasticNet/小 MLP 的稳健回归链路：

| 实验  | 特征                                    | 模型        | val O₂ R² | 状态      |
| --- | ------------------------------------- | --------- |:---------:| ------- |
| R0  | slow + TOF/sound_speed/alpha 物理标量统计   | RidgeCV   | 0.603     | ✅ 当前最优（oracle 膨胀，不可部署） |
| R1a | MiniRocket(tof_s 标量序列) + slow         | RidgeCV   | 0.515     | ✅ 不如 R0 |
| R1b | MiniRocket(raw 5000 点波形) + slow stats | RidgeCV   | -0.195    | ✅ 证伪    |
| R5' | D0-observed 864 特征 + **TabPFN**        | TabPFN    | -         | 🔶 代码已落地，本地 smoke test 通过（600 seq），待服务器 6000 正式运行（observed 非线性上限预检，判 D1 生死，见 `r5_tabpfn_implementation_plan.md`） |
| R5  | R0 特征 + 小 MLP                         | small MLP | -         | ⏳ 可与 R5' 并行交叉验证 |

## 七、关键问题与诊断

### 7.1 O₂ 可辨识性风险（核心科学问题）

| 物理量                  | O₂     | N₂     | 差异    | 可辨识性    |
| -------------------- | ------ | ------ | ----- | ------- |
| 摩尔质量 M (g/mol)       | 32.00  | 28.01  | 14.3% | 影响声速    |
| 比热比 γ                | 1.400  | 1.400  | 0%    | 无区分能力   |
| 声速 c₀ (m/s, 300K)    | ~330.6 | ~353.1 | 6.4%  | 可测（超声）  |
| 热导率 λ (mW/m·K, 300K) | ~26.3  | ~25.8  | ~2.3% | 边际（TCS） |

**结论**：O₂/N₂ 辨识是物理上可行但边际困难的任务，声速是主要物理通道，TCS 提供边际补充。

**D0 o2_bins 物理极限确认（2026-07-08，clean 6000）**：即使 oracle（无噪声真值声速/TOF/衰减）在 0.8% O₂ 窗口内 R² 也全负（val −9.2 ~ −2.6，test −8.5 ~ −1.3）。这是物理可辨识性的分辨率极限，不是测量噪声问题--O₂ 18–21% 范围内相邻 0.8% 窗口的声速差异，远小于 T_C / P_MPa / L_m 等环境变量引起的 TOF 变化。结论：O₂ 可分辨大档位（18–21% 量级，整体 val O₂ R² 达 0.60），窄区间（0.8% 窗口）精细辨识不足，任何模型（含 D2）都无法突破 oracle 的 bin 级表现。论文式表述应写"可分辨大档位，窄区间精细辨识不足"。

| fiber_mic  | 完整（反射+解调）                     | 同上                         | 默认跳过  | 待验证                                                  | R3f 待评估，需先确认是否与 R1b 同样失效 |
| NDIR 光学    | empirical 完整，HITRAN 禁用        | 并入 slow                    | ✅     | 无（O₂/N₂ 无红外吸收）                                       | HITRAN 优先级低              |

**V_NDIR_CH4 异常已核查闭合（2026-07-08）**：本地 tv3-formal（600 序列）用旧 schema 生成，manifest/slow.npy 含 8 列 V_NDIR_CH4（有实信号，mean=2.53，std=0.19，与 V_NDIR_CO2 弱负相关 −0.03），污染本地 D0 observed/tof_only/slow_only 结果。服务器 tv3-formal-6000 用当前 schema 生成，经 scripts/check_slow_channels.py 核查为 CLEAN（7 通道无 V_NDIR_CH4），clean 6000 D0 结果可信。本地 600 数据集需重新生成才能用于本地调试。根因是 schema 移除 CH₄ 后未重新生成旧数据集，非 rocket_features.py 代码 bug。

### 7.3 DL fusion 远逊于 Ridge 的主要原因

1. Ridge 的优势在于特征层面：直接在 slow 特征上做线性回归，与目标有强线性相关。
2. CNN1D encoder 未从 waveform 中提取到有效特征：5000 点 raw waveform 经 4 层 CNN1D -> 64 维 embedding，可能只捕获粗糙统计量（能量、包络），而非物理上关键的亚样本 TOF 差异。
3. 数据量不足：600 mixture / 6000 序列对端到端从 waveform 学习组分浓度偏少。
4. slow 分支被淹没：LayerNorm 对齐了 embedding 尺度，但 TCN 融合后 slow 分支的强特征信息可能在 128 维 concat 空间中被 64 维 waveform embedding 稀释。
5. 现有 `DeepAcousticEncoder1D` 的 `avg+max` 池化对平移不敏感，而 TOF 差异恰是位置偏移--池化掉的就是要提取的信号。
