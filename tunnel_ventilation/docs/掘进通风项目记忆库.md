## 一、项目边界与硬不变量

### 1.1 场景

tv3 面向掘进工作面空气质量监测。系统使用非分散红外（non-dispersive infrared, NDIR）、超声、热导传感器（thermal conductivity sensor, TCS）和可选的光纤麦克风（`fiber_mic`）信号，预测以下三种气体的体积分数：

```python
COMPONENT_FIELDS = ("x_CO2", "x_O2", "x_N2")
BACKGROUND_FIELDS = ()
SLOW_CHANNELS = (
    "V_NDIR_CO2",
    "V_TCS",
    "T_C",
    "P_MPa",
    "H_RH",
    "L_m",
    "piston_position_m",
)
```

- 数据模式（schema）：`tunnel-ventilation-1`
- 数据集命名：`tv3-*`
- 包入口：`pip install -e ./tunnel_ventilation` 后使用 `python -m tv3.xxx`
- 场景只含 CO₂/O₂/N₂；CH₄、CO 或 O₂ 专用硬件属于新阶段

### 1.2 模型与数据契约

1. 标签严格满足 `x_CO2 + x_O2 + x_N2 = 100%`，但正式模型必须直接输出 `raw3`、`out_dim=3`。
2. 不使用 `gas_head`、N₂ 闭包回填、ILR/ALR、`target_transform`、`free_component_mse` 或闭包残差头。
3. `sum_abs_error` 是监控指标，不是强制输出约束。
4. 仿真真值 `tof_s`、真实声速（true sound speed）和真实衰减系数（true alpha）只能用于真值上限（oracle）审计或辅助目标（auxiliary target），不能进入部署输入。
5. 正式观测特征头（observed head）冻结为 `d0_observed_physics_stats_v1`；变更特征时必须使用新的特征构建器（builder）名称。
6. 缺失清单（manifest）、波形缩放系数（waveform scale）、慢通道元数据（slow metadata）或必需数组时，程序必须直接失败，不得添加静默后备路径（fallback）。
7. 波形深度学习（deep learning, DL）输入契约为 `dequantize_waveforms`，并可选用 `normalize_waveforms` / `waveform_stats_features`。通道按“慢通道（slow）→ 归一化前统计量（stats）→ 波形样本”的顺序组装。正式波形配置默认 **`waveform_preprocess: "gpu"`**：数据加载器（DataLoader）只搬运 `int16` 数据和缩放系数，反量化、统计量计算和标准分数归一化（z-score）在设备侧完成，其数值语义与 `cpu` 路径对齐。`gpu` 路径不支持 `window` / `phase_windows` / `augment`，违反契约时直接失败。

### 1.3 数据可信度

- 清洁正式数据 `tv3-formal-6000`：仅在服务器，含 7 个慢通道（slow channel），不含 `V_NDIR_CH4`。
- 旧本地 `tv3-formal` 600：含额外的 `V_NDIR_CH4`，慢通道特征已被污染，不得用于正式模型比较。
- 本地旧数据的原始超声（raw ultrasonic）链路仍可用于峰值定位和波形保真度调试，但必须明确注明它不是正式性能证据。

### 1.4 名词导读与联更义务

- 初学者与协作入口：`docs/methods/tv3_名词与实验顺序导读.md`。按实验顺序（契约 → D0 → D2/D2b → R 系列 → B1–B7 → 模块 C → 可辨识性）分级解释 tv3 名词；**不**替代本记忆库的正式结论源。
- **强制联更**：新增或重命名正式实验阶段、代码模块、算法、特征构建器（builder）、预测头、协议门禁、结论状态（verdict）或关键物理量时，必须在**同一变更批次**更新该导读中的名词定义、分级位置与索引；禁止只改代码或专项计划而留下过时讲解。
- 导读与本记忆库冲突时，以本记忆库的正式指标与不变量为准，并回头修正导读。
- 纯本地冒烟测试（smoke）和未验收草稿可以暂缓写入导读；一旦内容进入 `active/` 正式计划、默认预测头、默认协议或本记忆库结论表，导读必须同步更新到可读状态。

### 2.2 当前结论栈

1. **O₂ 并非完全没有信号**：在 18%–21.2% 的整体范围内，飞行时间（time of flight, TOF）和声速足以支持粗粒度辨识。
2. **窄区间受到物理上限约束**：即使使用仿真真值上限（oracle），0.8% O₂ 分箱（bin）内的 R² 仍然全部为负。因此，模型不能承诺精细分辨窄浓度变化。
3. **D0-observed 是测量级基线（baseline）**：它读取仿真器同步生成的观测飞行时间、峰值位置、估计声速和质量指标。D2b B1 已用原始数字信号处理特征复现其线性组分性能；基于训练集标定的帧级保真度也已通过。
4. **D2 失败不代表所有原始波形路线都失败**：当前实现的辅助峰值输出不可训练，而且 TOF 指标混入了固定延迟造成的坐标偏置。失败结论只适用于这一实现。
5. **TabPFN 证明当前观测特征契约中存在可学习的非线性**，但它不能证明原始传感链路已经具备部署条件，也不能证明模型能够泛化到真实分布外条件。
6. **默认 R5 主要败在目标尺度造成的优化困难**：R5-T 只增加逐目标标准化。三个新增随机种子的 O₂ R² 均值在验证集、测试集和外推集上依次为 `0.6631 / 0.6438 / 0.5890`，标准差依次为 `0.0082 / 0.0055 / 0.0197`。
7. **闭包不是已证实根因**：正式 raw3 契约不变；二输出加 N₂ 回填不能作为当前主线的“最小修复”。
8. **B6 的稳定结果说明 R5-T 配方可以迁移到 RawDSP**：三个新增随机种子的 O₂ R² 均值在验证集、测试集和外推集上依次为 `0.5581 / 0.5356 / 0.4835`，标准差依次为 `0.0096 / 0.0170 / 0.0036`。每个随机种子都超过 B1 的对应门槛，但仍低于使用观测特征的 R5-T。
9. **B7 达到 `protocol_pass`，并成为当前默认 RawDSP 预测头**：该预测头由折外岭回归和残差多层感知机构成。完整的 `R / L / S-Y / S-L × 3 split seed × 3 training seed` 矩阵通过审计。B7 相对 B1 的测试集 / 分布外 O₂ ΔR² 均值分别为：R `+0.2323 / +0.1923`、L `+0.2208 / +0.2606`、S-Y `+0.1740 / +0.7009`、S-L `+0.1895 / +0.2570`；`sum_abs_error` 约为 `2e-4–4e-4`。当前不扩大这套残差结构。
10. **分布外结论受划分器（selector）边界限制**：S-L 的 B7 分布外 O₂ R² 为 `0.7002 ± 0.0260`，S-Y 只有 `0.4340 ± 0.0279`。后者虽然相对 B1 明显提高，但不能支持“所有分布外场景都达到 0.70”。S-Y 的三个划分随机种子共享同一个分布外数据集，只能量化同一目标边界（target-margin）分布外集上的域内（in-distribution, ID）划分方差和训练随机种子方差；S-L 才能复核随随机种子变化的分布外数据集。
11. **模块 C P0 已证伪物理早期分组**：在冻结 B7 的 12 个派生 split 上，C1 physical grouped bottleneck 的 24 条正式矩阵完整且审计通过，但判定 `grouped_failed`。C1 的 test O₂ R²相对 B7 在 R / L / S-Y / S-L 的均值差为 −0.1482 / −0.1392 / −0.1303 / −0.1350；S-Y / S-L OOD 差为 −0.2662 / −0.1823，均远低于 −0.01 非劣门。
12. **失败来自早期物理隔离，不是总容量下降**：同为 28,051 参数的 C2 permuted 在 S-Y / S-L 上相对 C1 的 OOD 均值高 0.0929 / 0.1706，但 C2 自身仍不能替代 B7，尤其 S-Y OOD 为 0.2877、较 B7 低 0.1733。当前证据只否定“各物理组先独立压缩到 16 维”的 C1 配方，不泛化为全部低参数或全部物理引导结构失败。
13. **当前分流**：停止调整 C1 的瓶颈维度、组丢弃（group dropout）、组门控（group gating）和 C1 编码器（encoder）TabM。B7 保持默认 RawDSP 预测头。若研究平坦残差 TabM（flat residual TabM），必须另立冻结计划；所有分布外结果仍分别报告 S-Y 与 S-L。
14. **首轮可辨识性审计确认单向 TOF 需要增加新的信息来源**：冻结 B1/B7 后，v1 审计覆盖了 189 个点。声速只作为 TOF 的派生诊断量，没有重复计入费舍尔信息（Fisher information）。O₂、CO₂、温度 T 和声程 L 的联合费舍尔秩只有 1，因此无法对干扰参数（nuisance parameter）做边缘化。在 1 K 温度误差和 3 μs 触发抖动（trigger jitter）条件下，0.8% O₂ 窄窗口的联合 P90 为 8.85%–12.99% O₂。项目已依据法规下限、温湿补偿超声文献和窄窗口宽度，预先登记 P90=`0.4 vol%`、单项干扰参数比例=`50%` 和拒绝率=`5%`；当前误差预算远超前两项门槛。由于 v1 未表示流速（flow），`v1_blocking_nuisance_reject_all` 拒绝了 189/189 个点，100% 拒绝率也超过门限，正式结论状态为 `information_source_upgrade_required`。该结论只适用于单向 TOF 情景，既不是部署精度声明，也不是对补充流速信息后声学路线的最终否定。
15. **静止空气仿真可辨识性作为并行路线保留，但不推翻 v1 结论**：S 线在配置中明确固定 `flow=0`，并登记触发抖动、固定延迟、声程、T/RH/P、信噪比（signal-to-noise ratio, SNR）和设备配置范围（profile）。即使该路线通过，也只能说明结论在已登记的数字孪生范围内成立，不能改写成真实静止空气或掘进通风现场能力。它不阻塞 MRS-EI，详见 `active/tv3_static_air_feasibility_implementation_plan.md`。

### 3.4 采样与数据划分（split）

- `x_CO2`：0.03–5.00%
- `x_O2`：18.00–21.20%
- `x_N2 = 100 - x_CO2 - x_O2`
- 采样：CO₂/O₂ 受约束 LHS

现有正式数据的随机外推集（random extrapolation）只是随机打乱后剩余的样本，并不是真正的分布外数据。B7 已完成“仅观测特征的重复划分 + 双划分器”复核：R/L 只用于域内稳定性对照；S-Y（`y_margin_ood`）和 S-L（`lhs_boundary`）才是组分边界的分布外证据。

- S-Y 三个划分随机种子的 `ood_set_hash` 相同；重复实验只能量化同一分布外集上的域内划分方差和训练随机种子方差。
- S-L 三个划分随机种子的分布外集不同；L 与相同随机种子的 S-L 共享 `lhs_boundary` 分布外集，因此 L 不能额外算作独立划分器证据。
- 因此，B7 可以声明相对 B1 在双划分器分布外测试中的增益，但不能把任一单独划分器的绝对 R² 外推成全部物理分布外场景或真实硬件泛化能力。

## 五、根因与模型审查

### 5.1 D0-observed 的语义

`d0_observed_physics_stats_v1` 使用：

- `ultrasonic_tof_observed_s`
- `ultrasonic_peak_index`
- `ultrasonic_sound_speed_estimated_m_per_s`
- `ultrasonic_tof_quality`
- `ultrasonic_tof_accepted`

这些量由仿真器生成波形（waveform）时同步计算，并不是从保存的原始波形（raw waveform）重新估计。因此，D0-observed 是 D2b 需要复现的测量级上限；在 RawDSP 一致性（parity）通过之前，不能把它称为现有的端到端原始波形部署链路。

### 5.2 D2 为什么失败

1. 旧卷积神经网络（CNN）的全局平均 / 最大池化（global avg/max pooling）对平移不敏感，因此丢失了 TOF 的位置信息。
2. D2 的匹配滤波器（matched filter）核和软最大值温度（softargmax temperature）固定不变；`aux.tof_s` 与 `aux.peak_index` 在可训练投影层（projection）之前输出。
3. 梯度审计发现：主预测输出可以训练，但两个辅助输出的 `requires_grad=false`，所以辅助损失无法训练峰值估计器。
4. TOF 以秒为单位，峰值以归一化索引为单位，两者直接计算平滑 L1 损失（SmoothL1）。在现有量级下，辅助项约为 `1e-9`，相对主损失可以忽略。
5. 波形峰值对应“真实 TOF + 82 μs 固定延迟 + 抖动”。因此，84.2 μs 的平均绝对误差不能直接解释为峰值定位误差。
6. D2 没有显式生成 corrected TOF 与 `sound_speed=L_m/tof`，把校准、除法和 L_m 去混杂交给小样本 TCN 隐式学习。

D2 正式失败结论保留，但原实现不再继续叠补丁。新路线独立为 D2b / RawDSP。

### 5.3 D2b 局部证据

旧本地 600 的 8 条序列 × 64 帧，共 512 帧，只做 raw waveform fidelity：

| 指标                               | 结果                      |
| -------------------------------- | -----------------------:|
| 完整模板相关后的连续 peak MAE              | 0.019 sample，即 0.019 μs |
| peak bias / std                  | −0.00017 / 0.021 sample |
| peak P95 绝对误差                    | 0.030 sample            |
| 重建声速对 stored estimated speed MAE | 0.010 m/s               |

这说明固定数字信号处理（digital signal processing, DSP）可以恢复仿真波形中的信息。清洁正式数据 6000 的清单已确认：模板只由训练集标定（train-only template），包含全部 6000 条序列，并使用非诊断模式。B1 岭回归在验证集、测试集和外推集上的 O₂ R² 为 0.4280 / 0.4786 / 0.3695，相对 D0 的差值为 +0.0054 / +0.0215 / -0.0013，模型一致性通过。训练集标定的帧级保真度也已通过：峰值 P95 为 0.04443 个采样点，验证集、测试集和外推集的全部门槛均通过。

### 5.4 R5 小 MLP 的正确判读

R5 实际已经具备：

- 输入使用标准化器 `StandardScaler`；
- 损失权重为 `[1, 2, 1]`；
- 直接按照验证集 O₂ R² 进行早停（early stopping）；
- 输入中已经包含观测估计声速（observed estimated sound speed）。

因此以下说法不成立：

- “输入没有标准化”
- “O₂ 没有加权”
- “早停被 CO₂/N₂ 掩盖”
- “MLP 必须自己发现 L/TOF”

默认 R5 后真正待验证的因素曾包括：

1. **目标中心化与尺度**：R5-T 已确认这是默认 R5 失败的主要因素。它只标准化训练目标，就在三个评价数据划分（evaluation split）上通过 D0+0.05。
2. **模型相对样本量过大**：数据有 864 个特征、约 4200 行训练样本和 254,723 个模型参数，属于高维、强共线的表格数据，而不是低维表格。
3. **共享主干（shared trunk）的多任务冲突**：这种冲突可能存在，但目前没有梯度余弦相似度（gradient cosine）或独立目标对照证据。
4. **表格归纳偏置**：TabPFN 成功不意味着从零训练 MLP 应该成功。
5. **特征冗余**：大量 phase/window 统计可能使普通 MLP 优化困难。

### 5.5 闭包与多目标判断

- 数学上标签只有两个自由度，但正式模型契约选择 raw3 直接输出。
- 二输出加 N₂ 回填会机械地消除闭包误差（closure error），却不能保证 O₂ 预测改善。
- `raw3` 岭回归可以同时取得近零闭包误差和有效的 O₂ 预测；TabPFN 的 O₂ 表现较好，但闭包误差不为零。
- 因此闭包回填只能作为显式变更契约后的独立研究分支，不能混入 R5-T 或 R7 主实验。

若要检验多目标梯度冲突，应比较：

1. 共享主干（shared-trunk）的 `raw3` 多层感知机；
2. 三个独立的单目标（single-target）多层感知机，最后组合成 `raw3`；
3. 共享主干 + 独立预测头（heads）。

该对照不改变正式输出契约。

### 5.6 TabPFN 结论边界

可确认：

> 在当前 864 维仿真器派生观测特征和随机数据划分下，确实存在可被强表格先验利用的非线性。

尚不能确认：

- 非线性来自真实硬件物理而非仿真派生特征；
- 从原始波形到观测特征的链路已经闭环；
- 真正的分布外条件或新硬件条件下仍能保持 0.66；
- 普通 MLP、树模型或轻量部署头能复现同等收益。

### 6.8 停止条件

1. R5-T train O₂ 仍为负：目标尺度不是主因，停止同架构调参。
2. R7 与 residual MLP 均不超过 0.4726：保留 Ridge，observed-space 轻量非线性承接失败。
3. D2b frame fidelity 失败：先修 DSP，不训练组分模型。
4. D2b parity 成功但所有头无增益：波形提取已解决，限制在回归头或物理上限。
5. 任一增益只出现在 val，不同步到 test/当前 extrapolation：判为未通过。
6. 所有 observed/RawDSP 头稳定低于 0.70：接受声学路线整体上限，等待 O₂ 专用传感通道。
7. C1 physical grouped bottleneck 在完整 24 条矩阵 `grouped_failed`：停止该分支的维度、dropout、gating 与 C1 encoder TabM 调参，保留 B7。
8. EC-MSW E1 正式 frame fidelity 与 B1 parity 均失败：停止 E2；不得用延长训练、放宽门限或直接增加动态模块绕过前端表示缺陷。
9. EC-MSW E1r 正式 frame fidelity 通过但 B1 parity 失败：停止同结构续训和头部调参；先完成 E1d，未恢复三组分 parity 前 `e2_allowed=false`。
10. EC-MSW E1d 正式找到 compact 集合：只允许实现该集合的可部署 sequence builder 并重过 parity；禁止把完整 RawDSP 当端到端改进，禁止启动 E2 FiLM/attention/MoE；禁止仅用 TOF-L LS 头绕过 SNR 需求。
11. EC-MSW E1d-SB 正式 `parity_passed` 后：只允许 E1r attachment（probe-only）联合审计；attachment 未过门前不得启动 E2，不得用 full B1 包装端到端改进。
12. EC-MSW E1r attachment 正式 `attachment_passed` 后：仍禁止 E2 FiLM/attention/MoE；B7 保持默认头；可选 LS 消融不得删掉 SNR。
13. EC-MSW E2s-LS 正式 `ls_ablation_passed` 但相对 e1d_sb 的 O₂ 增益可忽略：不晋升 LS；默认序列表示保持无 LS 的 e1d_sb；下一步仅允许另立的可部署联合系统计划。

### 8.3 更新规则

仅在以下事件发生时更新本文件：

- 清洁正式数据 6000 产生新的正式指标；
- 数据、模型输出或特征契约改变；
- 关键路线通过或触发停止条件；
- 新证据推翻当前根因判断；
- 正式数据划分或硬件链路改变；
- `outputs/` 正式产物目录重组或归档（archive）迁移；此时只更新 §七的目录布局和 `outputs/README.md`，不改正式指标路径；
- 名词导读路径、职责或 §1.4 联更义务变更（仅改索引与不变量表述，不借此改写未验收实验结论）。

本地冒烟测试、纯代码落地和未验收猜测只写入对应实施计划，不进入当前结论表。

**与名词导读的联更（强制）**：凡新增或实质变更正式实验、默认算法、特征构建器（builder）、模型预测头、协议或结论状态语义，除按需更新本文件和专项计划外，还必须同步更新 `methods/tv3_名词与实验顺序导读.md` 中的对应名词、分级章节和文末索引。验收清单必须回答：“新名词是否已写入导读？旧释义是否已经修正？”没有完成联更，就不能认为本次变更的文档已经齐全。
