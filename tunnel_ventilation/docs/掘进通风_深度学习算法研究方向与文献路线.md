# 掘进通风多传感器气体组分反演的深度学习算法研究方向与文献路线

> 用途：集中记录本课题适合深入研究的深度学习算法方向、模型结构、实验顺序、停止条件和核心文献，供开题、论文设计与后续实验复查。
> 
> 检索日期：2026-07-10；可行性复核：2026-07-11。
> 
> 项目依据：`掘进通风项目记忆库.md`、`active/d2b_raw_dsp_implementation_plan.md`、`active/d2b_raw_dsp_mlp_implementation_plan.md`、`active/b7_oof_ridge_residual_mlp_implementation_plan.md`、`active/r5_mlp_implementation_plan.md` 中截至 2026-07-11 的 clean `tv3-formal-6000` 正式实验结论。本文不改变项目既有数据、输入和输出契约。
> 
> 2026-07-11 复核结论：总方向可行；近端主线改为**冻结 RawDSP / observed 特征上的结构化小样本残差学习**。B7 OOF Ridge residual 已 residual_pass；可微 DSP 与质量集合学习降为有条件增强，不宜三模块一次并联作为默认总创新。

## 1. 一页结论

### 1.1 推荐的课题总方向

**面向小样本多传感器气体组分反演的物理引导分层深度学习方法。**

近端默认链路（已验证 Fixed DSP，不强制端到端可微）：

```text
原始超声波形
    ↓
冻结 RawDSP（匹配滤波 + 物理窗峰定位 + 延迟校正 + 声速）
    ↓
序列级物理统计特征（864 observed / 1008 RawDSP）+ NDIR、TCS、环境量
    ↓
按物理模态分组的低维编码器
    ↓
Ridge 线性物理基线 + 小型 TabM / Residual MLP 非线性残差
    ↓
CO₂、O₂、N₂ 三目标 raw3 直接输出
    ↓
多 seed / SPXY / 独立 OOD + conformal 不确定性区间
```

完整研究栈（论文增强，按消融启用，不默认一次全开）：

```text
原始超声波形
    ↓
物理初始化的可微 RawDSP / 匹配滤波与 TOF 校正   ← 模块 A，消融项
    ↓
帧级 TOF、声速、峰形、SNR、quality 等物理特征
    ↓
质量感知的 DeepSets / Set Transformer 多帧聚合   ← 模块 B，需坏帧注入
    ↓
序列表示 + NDIR、TCS、温度、压力、湿度、路径长度
    ↓
按物理模态分组的低维编码器 + Ridge 残差头         ← 模块 C，近端主创新
    ↓
raw3 输出 + OOD / conformal
```

### 1.2 最适合形成论文创新的三个模块

按 **ROI / 证据成熟度** 排序，不是按实现顺序堆叠：

1. **结构化小样本表格残差网络（模块 C，近端主创新）**：保留 Ridge 的稳定主趋势，让低容量 TabM/ResNet 只学习 OOF 线性基线的非线性残差，并通过分组编码和特征稀疏化控制 864–1008 维强共线输入。已有 Ridge、TabPFN、R5-T、ExtraTrees 证据链支撑。
2. **质量感知的帧集合学习（模块 B，有条件创新）**：把一条序列中的多帧测量视为无序或弱有序实例集合，由网络根据峰值可信度、SNR、quality 和 accepted 信息学习聚合权重。当前 clean 仿真全帧 accepted，必须配合坏帧 / 缺帧 / 低 SNR 注入才有论文故事。
3. **物理初始化的可微信号处理前端（模块 A，消融增强）**：将已验证的匹配滤波、峰值定位、固定延迟校正和声速计算写成可微模块，只学习小范围修正。Fixed DSP 帧级 fidelity 已远超门限，增量空间可能很小，不宜再当作“必须先做的主创新”。

### 1.3 主线优先级

| 优先级 | 算法方向                                  | 定位                              |
| --- | ------------------------------------- | ------------------------------- |
| P0  | 冻结 B7 residual；分组 bottleneck / 小型 TabM | 近端主线（模块 C）；B7 residual_pass 已通过 |

## 2. 项目事实对算法方向的约束

### 2.1 已确认的有效证据

定性结论：

- O₂ 在完整 18%–21.2% 范围内不是完全无信号，TOF/声速可以支持粗粒度辨识。
- 在 0.8% O₂ 局部区间内，即使 oracle 特征的 R² 仍为负，说明存在物理分辨率墙。
- D0-observed Ridge 是测量级线性基线，但其 observed TOF 等量由仿真器同步生成，不能直接等同于已闭环的 raw-waveform 部署链路。
- RawDSP Ridge 已在 clean 6000 上达到 D0-observed parity，说明原始波形中的可用信息能够由固定 DSP 恢复。
- 原 D2 TOF-PhaseNet 的失败主要涉及位置不敏感池化、不可训练辅助峰值、辅助损失量级错误和缺失显式物理校正，不能推导为“所有 raw waveform 深度学习路线失败”。
- R5-T 仅加入训练目标标准化，就从默认 MLP 的负 O₂ R² 修复到约 0.58–0.66，说明优化尺度是已证实的重要根因。
- TabPFN 显示 observed 特征中存在可学习的非线性，但它目前只是非部署上限探针。
- ExtraTrees 出现接近 1.0 的训练 O₂ R² 和约 0.45 的验证 R²，显示小样本高维输入存在严重过拟合风险。
- 当前所谓 extrapolation 仍不是真正物理 OOD，所有新模型都需要 SPXY、独立 OOD selector 或重复划分验证。

补充健康度：

- D0-observed：train O₂ 0.501 → val 0.423，gap 0.078。
- TabPFN：train O₂ 0.981 → val 0.667，gap 0.314，但三 eval split 同步领先。
- R5-T：train O₂ 0.8792；val `sum_abs_error≈0.0307`，高于 Ridge 近零水平，继续作 raw3 监控项。
- 闭包误差与 O₂ 性能无单调关系；二输出加 N₂ 回填不能作为当前主线“最小修复”。
- 默认 R5 已具备输入标准化、O₂ 加权、按 val O₂ early stop 与 estimated sound speed；失败主因是目标尺度，不是“没标准化输入”或“早停被 CO₂ 掩盖”。

### 2.2 不允许被新算法破坏的正式契约

- 模型直接输出 `x_CO2`、`x_O2`、`x_N2` 三个 raw 值，`out_dim=3`。
- 不以 N₂ 闭包回填代替第三个模型输出。
- `sum_abs_error` 是监控指标，不是强制闭包约束。
- true TOF、true sound speed、true alpha 只能用于 oracle 审计或 auxiliary target，不能进入部署输入。
- 缺失 manifest、waveform scale、slow metadata 或必需数组时直接失败，不添加静默 fallback。
- observed 特征契约被冻结为 `d0_observed_physics_stats_v1`；RawDSP 正式契约为 `d0_raw_dsp_physics_stats_v1`；新增物理坐标必须建立新 builder 名称并独立消融。

### 2.3 对研究目标的重新表述

课题不宜表述为“用更深网络获得任意精度的 O₂ 测量”，而应表述为：

> 在存在物理不可辨识区间、小样本、高维强共线输入和仿真—部署差异的条件下，研究如何把已知声学测量链路嵌入神经网络，提高全范围气体组分反演的样本效率、稳定性、分布外泛化和不确定性可信度。

开题与摘要应坚持上述表述；不承诺突破约 0.70 的声学路线综合上限，也不承诺 0.8% O₂ bins 全部正 R²。

### 2.4 可行性评估与模块 ROI（2026-07-11）

| 方向                  | 可行性   | 判断                                         |
| ------------------- | ----- | ------------------------------------------ |
| 总方向（物理引导分层 DL）      | 高     | 比更深黑盒波形网络更贴项目事实与契约                         |
| 模块 C：分组残差 / TabM    | 最高    | B7 residual_pass 已通过；下一跳分组 bottleneck / residual TabM |

主要风险：

1. **三模块一次并联**：变量纠缠，难归因。必须按 §10 消融；论文创新宜收成 1–2 个。
2. **可微前端 ROI 被高估**：提取问题 largely solved；瓶颈在表格头与真 OOD。
3. **集合学习依赖质量异质**：clean 6000 全帧 accepted，无对照注入则故事偏弱。
4. **单 seed / random split**：R5-T 与 TabPFN 的 extrapolation 不是物理 OOD。
5. **文档状态滞后风险**：`掘进通风项目记忆库.md` 若仍写 “fidelity 待补”，以 `active/d2b_raw_dsp_implementation_plan.md` 的正式审计为准。

## 3. 主方向：物理引导的分层深度学习

建议暂命名为：

**PG-QSet-TabM：Physics-Guided Quality-aware Set Tabular Model**

### 3.1 模块 A：物理初始化的可微 RawDSP 前端

#### 3.1.0 当前定位（2026-07-11）

Fixed RawDSP（A0）已在 clean 6000 上通过帧级 fidelity 与 B1 Ridge parity。模块 A 的研究价值转为：

- 检验少量可学习修正相对冻结 DSP 是否还有稳定增益；
- 为仿真—硬件失配预留可校准前端；
- 作为相对“全学习 CNN”的归纳偏置消融。

**不作为近端默认主创新。** 未先跑通模块 C / B6 前，不把端到端可微前端与组分头同时大规模联调。

#### 3.1.1 核心思想

用经典匹配滤波器初始化一维卷积核，使网络在初始化时严格或近似实现现有 RawDSP：

\[
r(\tau)=\sum_t x(t)h(t-\tau)
\]

随后只学习物理模板的有限修正：

\[
h_{\text{learned}}=h_{\text{physical}}+\Delta h_\theta
\]

在相关峰附近使用局部 soft-argmax、抛物线插值或可微概率峰值估计：

\[
\hat\tau=\sum_{i\in\mathcal N}i\cdot
\frac{\exp(r_i/T)}{\sum_{j\in\mathcal N}\exp(r_j/T)}
\]

再显式计算：

\[
t_{\text{corrected}}
=t_{\text{peak}}-t_{\text{system}}-t_{\text{cable}}
\]

\[
\hat c=\frac{L}{t_{\text{corrected}}}
\]

这种设计属于“可微信号处理”或“模型驱动深度学习”，重点不是用 PINN 求 PDE，而是将已知测量算子作为强归纳偏置嵌入网络。DDSP 证明经典信号处理模块可以与自动微分和神经网络直接组合；匹配滤波也可以构造为具有解析初始化的神经网络，再在数据上进行有限训练。[R1][R2]

#### 3.1.2 推荐比较版本

| 版本                      | 前端参数                              | 目的                         |
| ----------------------- | --------------------------------- | -------------------------- |
| A0 Fixed-DSP            | 全部冻结                              | 作为已验证 RawDSP 基线            |
| A1 Residual-template    | 仅训练 `Δh`                          | 检验少量模板修正是否提高不同条件下 fidelity |
| A2 Conditional-template | 温湿度、L、quality 生成低维模板修正            | 检验环境条件相关响应                 |
| A3 Local peak corrector | 固定相关输出，仅训练峰附近 ±8/±16 sample 的偏移修正 | 低风险亚采样校正                   |
| A4 Fully learned CNN    | 无物理初始化                            | 仅作消融，不作为默认路线               |

#### 3.1.3 关键约束

- 相关峰搜索必须限制在物理可达窗口内。
- 禁止使用会抹除位置信息的全局平均/最大池化作为 TOF 主路径。
- `Δh` 使用 L2、平滑或频域带宽正则，防止网络完全破坏模板。
- TOF 辅助损失使用 sample 或 μs 单位，不能直接用导致梯度接近零的秒量级。
- clean 6000 的 Fixed DSP 帧级 fidelity 门已通过；若改模板 / 窗口 / 数据集，须重新过门后再训组分头。
- 端到端可微前端与组分头联调前，先完成相对 A0 的帧级 fidelity 与 B1/B6 对照，避免重蹈 D2 梯度量级问题。

#### 3.1.4 可形成的研究问题

- 物理初始化能否降低达到相同 fidelity 所需的样本量？
- 模板只允许低秩/平滑修正，是否比完全可训练卷积更稳定？
- 条件化模板在路径长度、温度、湿度和 SNR OOD 下是否有效？
- 学习模板修正与学习峰值修正，哪个贡献更大？

### 3.2 模块 B：质量感知的多帧集合学习

#### 3.2.0 当前定位（2026-07-11）

每条序列约 512 帧；现有 D0 / RawDSP 契约已将帧级量压成 mean/std/min/max/range/first/last/delta/slope 与 phase-window 统计。集合模型是在替换这套固定聚合，而不是从零发明输入。

关键限制：clean 6000 的 D2b 审计显示**全部帧 accepted，且无 boundary hit / clipping**。在未注入坏帧、缺帧或低 SNR 之前，quality-aware attention 几乎没有可学的质量异质，论文故事偏弱。

因此模块 B 的启用条件是：先完成固定统计基线，再做 §3.2.3 的鲁棒性实验；若注入后仍无 test/OOD 增益，按停止条件接受“当前聚合已足够”。

#### 3.2.1 为什么采用集合模型

一条气体样本通常包含多帧超声测量。若这些帧对应同一稳定混合物，帧的排列本身不是主要信息，而帧间质量差异、jitter、异常峰和可靠性分布才是关键。Deep Sets 给出了排列不变集合函数的基础形式，Set Transformer 则利用注意力显式建模集合元素之间的相互作用。[R3][R4]

每帧可构造：

\[
z_i=[
\hat t_i,\hat c_i,
\text{peak}_i,
\text{peak-width}_i,
\text{PSR}_i,
\text{SNR}_i,
q_i,
\text{accepted}_i,\ldots]
\]

基础 DeepSets 聚合：

\[
z_{\text{seq}}=\rho\left(\sum_i\phi(z_i)\right)
\]

质量感知注意力聚合：

\[
\alpha_i=\operatorname{softmax}
\left(a_i+\beta\log(q_i+\epsilon)\right)
\]

\[
z_{\text{seq}}=\sum_i\alpha_i\phi(z_i)
\]

#### 3.2.2 推荐基线与增强模型

1. mean/std/quantile 固定统计；
2. DeepSets；
3. Set Transformer；
4. quality 仅作为普通输入；
5. quality 显式进入 attention logit；
6. 双质量分支：物理 quality + learned quality；
7. 帧顺序确有信息时，再加入很弱的相对时间编码进行对照。

#### 3.2.3 适合的鲁棒性实验

- 随机删除 10%、25%、50% 帧；
- 注入错误峰、低 SNR 和大 jitter 帧；
- 改变 accepted frame 比例；
- 固定有效帧数量，比较不同质量分布；
- 按路径长度、温湿度和 quality quartile 分层评估；
- 检查 learned attention 与物理 quality 的单调性和失配样本。

#### 3.2.4 可能的论文创新

- 面向连续气体组分回归的质量引导 Set Transformer；
- 物理测量质量与神经可信度的联合建模；
- 从帧级不确定性传播到组分级区间；
- 对坏帧、帧缺失和测量拒绝机制的可解释鲁棒聚合。

---

### 3.3 模块 C：分组结构化表格残差网络

#### 3.3.0 当前定位（2026-07-11）

**近端主创新与最高 ROI 模块。** 证据链已齐：

- Ridge：稳定线性主趋势；
- TabPFN：observed 空间存在可学习非线性（非部署上限）；
- R5-T：目标标准化即可把可部署 MLP 拉到接近 TabPFN；
- ExtraTrees：高维小样本下易严重过拟合；
- B1 RawDSP Ridge：可部署特征链路已闭环；
- B6 RawDSP MLP：三个新增 seed 已稳定证明 R5-T 配方可迁移到 RawDSP（均值 `0.5581 / 0.5356 / 0.4835`）；
- B7 OOF Ridge residual：三新增 seed **residual_pass**（均值 `0.6964 / 0.7001 / 0.6157`），成为当前默认 raw-DSP 头候选。

近端执行顺序：冻结 B7 residual（不扩大结构）→ 分组 bottleneck → residual TabM；并行建立独立 split / OOD 评价。不要等模块 A/B 完成后再开始。

#### 3.3.1 为什么不能继续使用大而平的普通 MLP

当前训练样本约 4200，而 observed/RawDSP 特征约 864–1008 维，且包含大量相邻窗口、phase 和统计冗余。默认 R5 的 `(256, 128)` 约 25 万参数，属于高维强共线表格上的过参数化风险，而不是“低维表格小网络”。典型表格基准显示，中等规模表格任务中树模型仍是强基线；神经网络的关键困难包括对无信息特征不够鲁棒、不能自然保留数据方向，以及不易拟合不规则目标函数。[R5]

R5-T 成功说明目标标准化必须保留，但不能由此推导“更大的 MLP 一定更好”。推荐将总参数控制在约 2 万–8 万，并显式注入特征分组和线性残差结构。

#### 3.3.2 物理分组建议

- `G1`：raw/corrected TOF；
- `G2`：estimated sound speed 和变换坐标；
- `G3`：peak index、峰宽、峰曲率、旁瓣；
- `G4`：quality、SNR、accepted、缺失率；
- `G5`：phase/window 统计；
- `G6`：NDIR CO₂；
- `G7`：TCS；
- `G8`：温度、压力、湿度、路径长度和 piston position。

每组使用独立 bottleneck：

```text
Linear(group_dim → 8或16)
LayerNorm
SiLU
Group Dropout
```

再拼接为 64–128 维低维表示。

#### 3.3.3 Ridge + 非线性残差

主预测结构：

\[
\hat{\mathbf y}
=
\hat{\mathbf y}_{\text{Ridge}}
+
f_\theta(e)
\]

必须遵循：

- 训练样本的 Ridge 预测由 K-fold out-of-fold 方式生成；
- residual target 在训练折内标准化；
- residual head 最后一层零初始化，使初始模型等价于 Ridge；
- 最终仍输出三个 raw3 值，不做 N₂ 回填；
- 正式评估同时记录 O₂ R²、CO₂/N₂ 指标和 `sum_abs_error`。

#### 3.3.4 TabM 的作用

TabM 使用参数高效集成，在一个模型中产生多个弱成员预测并联合训练。论文的大规模比较显示，它为表格深度学习提供了强而实用的性能—效率基线。[R6]

推荐起始范围：

- ensemble members：4、8；
- width：64、128；
- depth：2、3；
- dropout：0、0.05、0.10；
- weight decay：`1e-5`、`1e-4`、`1e-3`；
- target scaling：始终开启；
- 对比 absolute head 与 residual head；
- 记录 ensemble member 方差，作为模型不确定性诊断。

#### 3.3.5 特征选择

LassoNet 将线性跳连和非线性网络通过层级约束结合，可输出从稠密到稀疏的特征正则路径，适合判断 864/1008 维输入中是否存在大量冗余。[R7]

推荐顺序：

1. 物理组消融；
2. bottleneck 维度消融；
3. group dropout；
4. train-only stability selection；
5. LassoNet；
6. 只在前述方法不足时考虑更复杂的 feature-token Transformer。

## 4. 第二方向：领域内超声波形自监督预训练

### 4.1 定位

自监督预训练适合作为主线增强，而不是在 6000 条序列上直接训练大型基础模型。项目仿真器可以生成大规模多样化波形，因此更合适的是**领域内预训练**，而不是直接套用在一般传感器、金融或医疗时间序列上训练的通用模型。

SimMTM 通过多个互补掩码视图恢复时间序列局部结构；MOMENT 展示了大规模时间序列预训练在有限监督任务中的潜力；TSLANet 则使用频域自适应和轻量卷积应对噪声、小数据和过拟合。[R8][R9][R10]

### 4.2 建议预训练任务

- 遮挡相关峰局部并重建相关响应；
- 预测被遮挡帧的 TOF、peak 或 quality；
- 相同混合物不同噪声增强视图的一致性学习；
- 判断两帧是否来自同一混合物或相邻物理条件；
- 预测路径长度、jitter 等级和 SNR 区间；
- 用固定 RawDSP 特征作为 teacher，蒸馏帧级 embedding；
- 频域带宽遮挡和载波相位扰动恢复。

### 4.3 建议编码器

```text
物理/带通初始化卷积
    ↓
多尺度局部 1D 卷积
    ↓
可选频谱块
    ↓
小型 Transformer / 状态空间层
    ↓
帧级 embedding
```

不建议在当前阶段使用大型原始波形 Transformer。首先应证明：

- 预训练相对随机初始化显著提高下游结果；
- 收益在独立 mixture split 和 OOD 条件下存在；
- 表示没有只记住仿真模板、路径长度或数据生成 seed；
- 与固定 RawDSP 相比具有额外信息，而不是只做昂贵近似。

## 5. 第三方向：表格基础模型教师蒸馏

### 5.1 定位

TabPFN 已在项目 observed 特征上表现出较强非线性能力。较新的 TabPFN-2.5 报告还提供了向紧凑 MLP 或树集成蒸馏的路线。[R11]

本项目可研究：

> 用 TabPFN 作为非部署教师，指导小型物理残差学生学习高阶非线性，同时保持 RawDSP 输入、低延迟和可控模型规模。

边界：R5 / R5-T 正式实验保持纯监督，不使用 TabPFN 输出作训练标签。蒸馏是独立 P1/P2 分支，必须用 OOF teacher prediction，不能与 R5 判据混报。

### 5.2 蒸馏结构

教师：

\[
\hat y_T=\operatorname{TabPFN}(X_{\text{train}},Y_{\text{train}},x)
\]

学生：

\[
\hat y_S=\hat y_{\text{Ridge}}+f_\theta(x)
\]

损失：

\[
\mathcal L
=
\alpha\mathcal L(\hat y_S,y)
+
(1-\alpha)\mathcal L(\hat y_S,\hat y_T)
\]

### 5.3 防止蒸馏泄漏

- 训练集 teacher prediction 必须通过 leave-one-fold-out / OOF 方式生成；
- 不能让教师看到某训练样本标签后，再把该样本的近乎记忆输出作为学生监督；
- 独立报告真实标签损失和 teacher 模仿损失；
- 比较蒸馏绝对目标、蒸馏 Ridge residual、蒸馏排序关系三种方式；
- 重点检查 OOD 下教师错误是否被学生继承。

### 5.4 研究问题

- TabPFN 非线性是否可压缩到 2 万–8 万参数？
- residual distillation 是否比 absolute distillation 更稳定？
- teacher ensemble variance 能否用于样本加权？
- RawDSP 学生能否逼近 observed-space 教师？
- 蒸馏收益是否只来自当前随机 split 的邻域结构？

## 6. 第四方向：多任务冲突与模态解耦

### 6.1 动机

三个目标的信息源并不对称：

- CO₂ 主要由 NDIR 提供直接信息；
- O₂/N₂ 主要依赖超声 TOF 和声速；
- TCS 对 O₂/N₂ 的贡献较弱；
- N₂ 与另两个组分存在标签相关性，但正式模型仍需直接输出 raw3。

因此共享 trunk 可能产生负迁移，但目前尚无梯度证据。

### 6.2 必须先做的结构对照

| 编号  | 结构                              |
| --- | ------------------------------- |
| M0  | 完全共享 trunk + raw3 head          |
| M1  | 共享编码器 + 三个独立 heads              |
| M2  | CO₂ 光学分支 + O₂/N₂ 声学分支 + 融合层     |
| M3  | 三个独立 single-target 网络，最终组成 raw3 |
| M4  | 分组 mixture-of-experts，按模态软路由    |

### 6.3 梯度诊断

记录：

\[
\cos(g_i,g_j)
=
\frac{g_i^\top g_j}{\|g_i\|\|g_j\|}
\]

以及：

- 每个任务梯度范数；
- 负 cosine 的比例；
- 各层冲突分布；
- O₂-only 与 shared 模型的训练/验证差异；
- 冲突是否集中在共享前端、表格融合层或输出头。

只有确认存在长期冲突后，才使用 PCGrad 或 CAGrad。PCGrad 将冲突梯度投影到其他任务梯度的法平面；CAGrad 在平均目标下降和最差任务局部改进之间进行权衡。[R12][R13]

## 7. 第五方向：OOD 泛化与不确定性估计

### 7.1 为什么必须作为主论文评价维度

当前随机 mixture split 不能代表真正物理外推。深度学习模型若只在相邻混合物、相似路径长度和相似环境条件中插值，可能得到高指标但不具备部署价值。

建议建立：

- repeated stratified split；
- SPXY split；
- O₂/CO₂ target-margin OOD；
- 路径长度 holdout；
- 温度区间 holdout；
- 湿度区间 holdout；
- 低 quality / 低 SNR OOD；
- 仿真器参数或模板响应 holdout。

### 7.2 不确定性输出

可采用 TabM/多 seed ensemble：

\[
\hat y=\frac1M\sum_m\hat y_m
\]

\[
\sigma_{\text{model}}^2
=
\frac1M\sum_m(\hat y_m-\hat y)^2
\]

再用独立 calibration split 构造 conformal interval。标准 conformal prediction 依赖交换性；在 covariate shift 下，可使用重要性加权 conformal，但其有效性依赖密度比估计或足够的无标签目标域样本。[R14]

### 7.3 必须报告的可信度指标

- 90% / 95% 区间覆盖率；
- 平均区间宽度；
- O₂ 各 bin 覆盖率；
- 路径长度、温湿度、quality 分层覆盖率；
- OOD 样本区间是否自动变宽；
- 误差与预测方差的排序相关性；
- 不可辨识窄区间中模型是否给出更低置信度。

## 8. 新近方向跟踪：TabPack

TabPack 于 2026-07-06 发布，扩展了 TabM/BatchEnsemble 一类隐式 MLP 集成：在一次训练中并行采样不同超参数的成员，并动态选择集成成员，目标是减少传统超参数搜索依赖。[R15]

对本项目的判断：

- 优点：可能降低 R5-T/TabM 的人工调参成本，并提供更丰富的成员差异；
- 风险：论文重点是中到大型公共数据集，尚不能直接推断适合约 4200 个训练样本、1008 维强共线物理特征；
- 建议：先稳定复现 TabM，再将 TabPack 作为相同 split、相同参数/计算预算下的跟踪对照；
- 不应因为发布时间新就替代已验证的 Ridge、R5-T 和小型 residual TabM。

## 9. 联合模型与损失设计

### 9.1 推荐联合损失

\[
\mathcal L
=
\mathcal L_{\text{gas}}
+
\lambda_t\mathcal L_{\text{tof}}
+
\lambda_p\mathcal L_{\text{peak}}
+
\lambda_h\mathcal L_{\text{template-reg}}
+
\lambda_q\mathcal L_{\text{quality}}
\]

#### 气体组分损失

\[
\mathcal L_{\text{gas}}
=
\sum_{k\in\{CO_2,O_2,N_2\}}
w_k\operatorname{Huber}
\left(
\frac{\hat y_k-y_k}{s_k}
\right)
\]

其中 `s_k` 仅由训练集计算，保留 R5-T 已验证的目标标准化。

#### TOF 损失

\[
\mathcal L_{\text{tof}}
=
\operatorname{SmoothL1}
\left(
\frac{\hat t-t}{1\ \mu s}
\right)
\]

使用 μs 或 sample 单位，确保梯度量级可见。

#### 峰值概率损失

在真实峰附近构造高斯软标签：

\[
p_i^*\propto
\exp\left(-\frac{(i-i^*)^2}{2\sigma^2}\right)
\]

使用 KL 或 cross-entropy 学习峰值分布，而不是只回归归一化 index。

#### 模板修正规则

\[
\mathcal L_{\text{template-reg}}
=
\|\Delta h\|_2^2
+
\eta\|\nabla\Delta h\|_2^2
\]

### 9.2 不建议默认加入的损失

- 强制三输出和为 100 的大权重闭包损失；
- 使用 true sound speed 作为输入；
- 未做单位缩放的秒级 TOF SmoothL1；
- 同时大规模调整前端、头部、损失和 split；
- 仅优化平均三目标指标而不监控 O₂ R²。

## 12. 停止条件

1. ~~D2b train-calibrated frame fidelity 未通过：停止训练组分深度头，先修复 DSP。~~ **已通过（2026-07-10/11）。** 若后续改模板、改窗口或换数据集导致 fidelity 回退，重新触发本条。
2. R5-T 在多 seed 或独立 split 上不能稳定超过 Ridge：不把单次 0.66 作为正式算法结论。
3. B6 在 RawDSP 上不能相对 B1 同步提升：说明 R5-T 收益尚未迁移到可部署特征链路；先诊断特征契约差异，再扩大模块 A/B。
4. residual TabM、分组编码在无坏帧设定下都不能同步提高 test/OOD：接受当前冻结特征上的轻量非线性难以稳定利用；质量集合模型另以注入实验判定。
5. 任何模型只改善 val，不改善 test 和独立 OOD：判定未通过。
6. 所有 RawDSP/observed 头在严格 OOD 下稳定低于 0.70：将其解释为声学路线及数据覆盖的综合上限，而不是无限调参。
7. 可微前端相对 Fixed DSP 无稳定 test/OOD 增益：停止扩大模块 A，保留 A0 冻结 DSP。
8. 坏帧注入下集合模型不优于固定统计聚合：停止扩大模块 B。
9. 自监督只改善当前仿真随机 split、不改善参数 holdout：停止扩大预训练规模。
10. 多任务独立模型不优于共享模型，且梯度 cosine 无系统冲突：不引入 PCGrad/CAGrad。
11. TabPack 或大型 Transformer 计算成本显著增加但不优于小型 residual TabM：停止该分支。

## 16. 文档维护规则

仅在以下情况更新本文：

- clean 6000 或后续正式数据产生新的多 seed / OOD 指标；
- RawDSP fidelity、输入特征或输出契约发生正式变化；
- 主模型模块通过验收或触发停止条件；
- 新论文被复现并在本项目数据上产生可靠证据；
- 真实硬件数据可用，研究重心进入 sim-to-real；
- 对照项目记忆库 / active 计划后，发现本文事实或优先级过时（例如 2026-07-11 将 D2b fidelity 从“待补”更正为“已通过”）。

未经正式验收的单次实验、只改善训练集的模型和无法复现的新论文结果，只记录为“候选/跟踪”，不写入主结论。

与其他文档冲突时的优先级：

1. clean `tv3-formal-6000` 的 `metrics.json` / fidelity 审计产物；
2. `active/d2b_*`、`active/r5_*` 等已标注正式结果的实施计划；
3. 本文的算法方向与优先级；
4. `掘进通风项目记忆库.md` 的执行摘要（若滞后，应回写记忆库，而不是让路线图倒退）。
