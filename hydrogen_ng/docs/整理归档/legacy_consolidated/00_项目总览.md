## 1. 项目背景

### 1.1 研究目标

基于 V3.1 双通道 waveform 仿真数据，对四组分（x_H2 / x_CH4 / x_CO2 / x_N2）混合气体检测进行完整的**传统机器学习（ML）与深度学习（DL）公平对比**，作为正式交付的实验整理结果。

### 1.2 核心创新点

V3.1 数据集相对 V3.0 的核心变化是将原先单通道 waveform 升级为**两条物理独立链路**：

- **通道 1**：超声对射波形（TOF 链路）
- **通道 2**：光纤麦克风波形（声衰减 / 多次反射混响链路）

### 1.3 与旧项目的关系

- 旧项目路径：`../深度学习测试/`
- **代码来源**（参考，不依赖）：
  - DL：`sequence-models/models/`, `data/`, `training/`
  - ML：`traditional-models/patent-sim-model/`
  - 数据生成：`simulation-data/scripts/`, `sim_common/`, `sim_v2/`
- **数据策略**：不直接复用旧单通道数据包，而是重新生成 V3.1 双通道数据集
- **独立性**：拷贝与改造完成后，本项目可独立运行

## 2. 三个核心验证目标

### G1：ML vs DL 检测能力对比

**问题**：在相同的 V3.1 双通道 waveform 数据上，传统机器学习（信号处理 + 浅模型）与深度学习（端到端从波形学习）哪个更好？

**主指标**：

- `macro_RMSE`：四组分 RMSE 取均值（主指标）
- `macro_MAE`：四组分 MAE 取均值
- `macro_MRE`：仅在 x_H2 / x_CH4 上取均值
- `per_component R²`：x_H2, x_CH4, x_CO2, x_N2 四个
- `sum_error`：预测和减 100% 的绝对误差

### G2：模态与动态融合对比

**问题**：三种模态四输出基学习器及其动态融合结果，哪个最适合当前双通道数据？

**主指标**：`macro_RMSE` + 参数量 + 训练时长

**对比维度**：

- 传统 ML：`acoustic / optical / thermal / fused` 四类输出
- 深度学习：Early / Middle / Late 三种融合策略

### G3：环境适应性评估

**问题**：模型在不同温度 / 压力 / 湿度组合下是否稳定？是否能跨工况迁移？

**三个子实验**：

| 子实验           | 做什么                       | 怎么评估                     | 输出               |
| ------------- | ------------------------- | ------------------------ | ---------------- |
| **G3a 敏感度曲线** | 用已训练模型，按 T/P/RH 分箱统计 RMSE | 无需重训练，复用 predictions.csv | 9 张曲线图 + CSV     |
| **G3b 噪声鲁棒性** | 对测试集注入 5 级传感器噪声           | 测试环境补偿效果                 | RMSE vs 噪声等级曲线   |
| **G3c 工况泛化**  | 18 个环境域逐一留出做测试            | 评估跨域泛化                   | 18 域 RMSE 均值±标准差 |

**主指标**：

- `domain_gap` = test_holdout_domain - test_in_domain
- `degradation_ratio` = perturbed_RMSE / clean_RMSE
- `sample_efficiency` = RMSE vs fine-tune 样本数（可选）

## 9. 代码原则

研究型实验项目，**不做防御性编程**：

- ❌ 不写 try/except；路径错、参数错、文件缺失，让它崩出栈
- ❌ 不做默认值兜底；配置漏了就报错
- ❌ 不做参数边界检查；输入异常就让 numpy/torch 自己崩
- ✅ 文档与状态控制照常做，但代码只走 happy path
