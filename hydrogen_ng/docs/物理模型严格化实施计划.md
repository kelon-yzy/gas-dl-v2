# 物理模型严格化实施计划

> 依据 [`传感器硬件资料整理.md`](references/传感器硬件资料整理.md) 附录 A.4 与三条改进建议制定。
> 目标：将声速、波形采样、热导三个物理子模型从工程代理升级为严格物理公式，提升仿真对真实硬件信号的可迁移性。
> 制定日期：2026-07-03

## 0 背景与范围

当前仿真链路（`v5-200khz-20bit-L03`）已对齐硬件型号（PSC200K 200kHz / NI-6453 20-bit / L_m≤0.3m），但三个物理子模型仍是工程代理：

| 子模型                                  | 当前实现                          | 问题                                                           |
| ------------------------------------ | ----------------------------- | ------------------------------------------------------------ |
| 声速 `hidden_sound_speed_v2`           | 纯组分声速摩尔分数线性加权 + 温度修正          | 声速不能直接加权（c∝√(γ/M) 高度非线性）；H₂ 5% 时偏差 ~7%，10% 时 ~13%，50% 时 ~45% |
| 波形采样 `simulate_waveform_measurement` | 1 MS/s 直接生成，TOF 量化到整数样本       | 5 samples/cycle + ±0.5 sample 量化，组分辨度接近量化阈值                  |
| 热导 `_hidden_lambda_mix`              | 线性经验 `0.034+0.00155·x_H2-...` | H₂-N₂ 混合热导非线性凹函数，H₂ 高浓度偏差 3~6%                               |

本计划采用三个方案（已决策）：

1. **声速**：理想气混合 `c=sqrt(γ_mix·R·T/M_mix)`（不实施 GERG-2008/AGA-10，过度工程）
2. **波形**：Lagrange 分数延迟 FIR 实现亚样本 TOF 定位（1 MS/s 输出不变）
3. **热导**：Wassiljewa-Mason-Saxena (WMS) 混合规则（不实施 Brokaw 严格理论）

三者作为新物理后端版本 `v6-phys-strict` 统一落地。

_GAS_CP = {"H2": 28.84, "CH4": 35.64, "CO2": 37.13, "N2": 29.12}
_R_GAS = 8.314

def hidden_sound_speed_v2(x_h2, x_ch4, x_co2, x_n2, t_c):
    # 摩尔分数 → 归一
    fracs = {"H2": max(x_h2,0)/100, "CH4": max(x_ch4,0)/100,
             "CO2": max(x_co2,0)/100, "N2": max(x_n2,0)/100}
    s = sum(fracs.values()) or 1.0
    fracs = {k: v/s for k, v in fracs.items()}
    # 混合摩尔质量与混合 cp（理想气摩尔分数加权）
    m_mix = sum(fracs[k] * _GAS_M[k] for k in fracs)           # kg/mol
    cp_mix = sum(fracs[k] * _GAS_CP[k] for k in fracs)          # J/mol/K
    gamma_mix = cp_mix / max(cp_mix - _R_GAS, 1e-9)
    t_k = t_c + 273.15
    c_mix = math.sqrt(gamma_mix * _R_GAS * t_k / max(m_mix, 1e-9))
    return max(c_mix, 200.0)   # 保留下限

## 3 Phase 2：Lagrange 分数延迟 TOF 定位

### 3.1 目标

`simulate_waveform_measurement` 当前将 TOF 量化到整数采样点（`int(round(tof * sample_rate_hz))`），在 1 MS/s 下量化步长 1 μs。1% H₂ 浓度变化对应 ΔTOF ≈ 0.2~2.7 μs（视组分和声程），量化误差占比可达 ±24%。

改用 **Lagrange 分数延迟 FIR 滤波器**，在 1 MS/s 采样率下实现亚样本精度的脉冲定位（精度 <0.002 μs），消除量化阶梯效应。

> **方案选择说明**：审查（2026-07-03）对比了两种方案——(A) 10× 过采样 + `resample_poly` 降采样、(B) 1 MS/s + Lagrange 分数延迟 FIR。方案 B 在 TOF 精度（<0.002 μs vs 0.1 μs）、计算开销（~1.02× vs ~8× 基线）、内存（1× vs 10×）上全面优于方案 A，且不存在过采样方案的噪声缩放问题（白噪声经 LPF 降采样后有效噪声降低 √10 倍）。核心文献：Laakso & Välimäki (1996) "Splitting the Unit Delay", IEEE Signal Processing Magazine, DOI:10.1109/79.482137（1065 次引用）。

### 3.2 Lagrange 分数延迟原理

5 阶 Lagrange 插值器使用 6 个系数，在信号频率 < 0.8×Nyquist 的范围内提供高精度分数延迟。200 kHz 载波在 1 MS/s 下为 0.4×Nyquist，恰好在高精度区间内，分数延迟误差 <0.002 采样 = 0.002 μs（Välimäki & Haghparast, 2007, IEEE SPL, DOI:10.1109/lsp.2007.898856）。

### 3.3 改动点

**`src/sim/generation/waveforms.py`**：

新增分数延迟函数（约 20 行）：

```python
def _lagrange_fractional_shift(signal: np.ndarray, delay_samples: float,
                                order: int = 5) -> np.ndarray:
    """在 1 MS/s 采样率下，将信号精确移动 delay_samples（含整数 + 小数部分）。

    使用 Lagrange 插值 FIR，5 阶在 0~0.8×Nyquist 内精度 < 0.002 采样。
    """
    n_int = int(math.floor(delay_samples))
    frac = delay_samples - n_int
    if abs(frac) < 1e-9:
        # 整数延迟，直接移位
        return np.roll(signal, n_int)
    N = order
    half = N // 2
    h = np.ones(N + 1)
    for k in range(N + 1):
        for j in range(N + 1):
            if j != k:
                h[k] *= (frac - (j - half)) / ((k - half) - (j - half))
    # 整数移位 + 分数延迟卷积
    shifted = np.roll(signal, n_int)
    return np.convolve(shifted, h, mode='same').astype(signal.dtype)
```

### 3.4 性能影响

- Lagrange 5 阶 FIR：每个输出样本 6 次乘加 + 1 次 `np.convolve`（mode='same'），单波形开销 <0.1 ms。
- 总体生成时间：与当前 1 MS/s 方案基本持平（~1.02× 基线），**不增加 benchmark 生成时间**。
- 内存：无额外内存分配。

### 3.5 验证

- A/B 对比：同一 condition 用旧方案（整数 round）和新方案（分数延迟）生成波形，对比 TOF 峰值位置。新方案下相近 TOF（差 0.3 μs）应产生可区分的波形形状（旧方案会被 round 到相同 peak_index）。
- 频谱核对：新波形在 200 kHz 载波附近频谱应无量化阶梯边带。
- DL A/B：smoke benchmark 训练对比 test R²（可选，Phase 4 做）。
- `test_waveform_physics.py` 的 `peak_index` 断言改为允许 ±1 采样容差（分数延迟后峰值可能偏移 1 个采样点）。

### 3.6 风险

- Lagrange 插值在信号频率 >0.8×Nyquist 时精度下降。200 kHz 载波在 1 MS/s 下为 0.4×Nyquist，安全裕度充足。
- 光纤麦克风 `simulate_fiber_mic_measurement` 同步改造（同样分数延迟逻辑），改动量小。
- `waveform_samples` 输出不变（仍 5000/10000），下游 dataset/DL 模型 in_channels 不变。

### 3.7 备选方案

若后续需要更精确地模拟换能器带宽限制或前端模拟滤波器效应，可回退到 2~4× 过采样 + 降采样方案（而非 10×，以控制性能开销）。该场景下噪声应在降采样后注入，Kaiser 窗 β 提高到 10~14（~80~100 dB 阻带衰减，匹配 20-bit ADC 动态范围）。

### 4.1 目标

### 4.2 纯组分常数表

### 4.3 改动点

**hg** `src/sim/generation/acoustic_physics.py:253`：

```python
_GAS_LAMBDA = {"H2": 0.1858, "CH4": 0.0340, "CO2": 0.0166, "N2": 0.0258}
_GAS_ETA = {"H2": 8.90e-6, "CH4": 1.108e-5, "CO2": 1.491e-5, "N2": 1.781e-5}
_LAMBDA_T_EXPONENT = {"H2": 0.78, "CH4": 0.82, "CO2": 0.87, "N2": 0.77}

def _wilke_phi(i, j):
    """Wilke 粘度混合函数 φ_ij。"""
    eta_ratio = (_GAS_ETA[i] / _GAS_ETA[j]) ** 0.5
    m_ratio = (_GAS_M[j] / _GAS_M[i]) ** 0.25
    num = (1.0 + eta_ratio * m_ratio) ** 2
    den = math.sqrt(8.0 * (1.0 + _GAS_M[i] / _GAS_M[j]))
    return num / den

def _lambda_at_t(gas: str, t_c: float) -> float:
    """纯组分热导率的温度修正（幂律）。"""
    return _GAS_LAMBDA[gas] * ((t_c + 273.15) / 298.15) ** _LAMBDA_T_EXPONENT[gas]

def _hidden_lambda_mix(x_h2, x_ch4, x_co2, x_n2, t_c):
    # Wassiljewa-Mason-Saxena: λ_m = Σ y_i λ_i(T) / Σ y_j φ_ij
    fracs = {"H2": max(x_h2,0)/100, "CH4": max(x_ch4,0)/100,
             "CO2": max(x_co2,0)/100, "N2": max(x_n2,0)/100}
    s = sum(fracs.values()) or 1.0
    fracs = {k: v/s for k, v in fracs.items()}
    lam = 0.0
    for i, yi in fracs.items():
        denom = sum(fracs[j] * _wilke_phi(i, j) for j in fracs)
        lam += yi * _lambda_at_t(i, t_c) / max(denom, 1e-12)
    return lam
```

**注意**：`_hidden_lambda_mix` 当前签名是 `(x_h2, x_co2, t_c)`，不含 x_ch4/x_n2。WMS 需要全组分，签名改为 `(x_h2, x_ch4, x_co2, x_n2, t_c)`。调用方 `_tcs_voltage` 已有全组分参数可直接透传；`main_sensor_features` 同步改。温度修正改为对每个纯组分分别施加幂律 `λ_i(T) = λ_i(298)·(T/298)^n_i`（各组分指数不同：H₂ 0.78, CH₄ 0.82, CO₂ 0.87, N₂ 0.77），再代入 WMS 混合公式，而非对混合后的 λ_mix 做统一乘法。

> **审查修正**（2026-07-03）：旧代码 `lam *= (t_c+273.15)/298.15` 是线性修正（T^1.0），与文档标注的幂律 T^0.78 不一致，且不区分各组分的温度指数差异（H₂ ~0.78, CO₂ ~0.87）。现改为逐组分幂律修正后再混合。

**syngas** `src/sim/generation/syngas/acoustic_physics.py:366`：同上，多 CO（λ=0.0249, η=1.777e-5, M=0.02801, T 指数=0.77）。

### 4.4 V_TCS 联动

`_tcs_voltage`（L258）公式 `V = baseline + slope·(λ_mix - offset) + ...` 不变，但 `λ_mix` 现在是 WMS 值（量级 0.026~0.19）。需核对 `tcs_lambda_offset=0.026`（N₂ 基准）仍合理——WMS 下纯 N₂ λ=0.0258 ≈ 0.026 ✓，offset 不变。`tcs_response_slope=15.0` 可能需重新标定（WMS λ 范围上限因 H₂ λ 修正为 0.1858 而略有变化，但 slope 大概率不变，需核对 V_TCS 输出量级）。

### 4.5 验证

- 与 Roder 1984 实验数据对比 H₂-N₂ / H₂-CH₄ 混合热导曲线，确认偏差在 ±5~8% 以内（WMS 对大质量比混合物的典型精度，Vesovic 2001 评估为 ±6~8%）。
- 回归测试 `test_acoustic_physics_regression.py` 的 V_TCS 金值更新。
- 核对 V_TCS 在 LHS 组分范围的分布（应与旧值量级一致，H₂ 高浓度区略低，因 WMS 是凹函数）。

### 4.6 风险

- `_hidden_lambda_mix` 签名变更（加 x_ch4/x_n2）影响调用链，需改 `main_sensor_features` 与 `thermal_conductivity_sensor_feature`。
- syngas 的 `_hidden_lambda_mix` 已含 x_co，签名改动较小（加 x_ch4/x_n2）。
- 各组分 T 指数（H₂ 0.78, CH₄ 0.82, CO₂ 0.87, N₂/CO 0.77）在 15~35°C 范围实测符合 NIST 数据。若 T 范围保持 15~35°C，逐组分修正与统一指数修正的差异 <1%，但逐组分方案物理上更严格。

## 6 验证与回退

| 风险                  | 影响         | 应对                                                      |
| ------------------- | ---------- | ------------------------------------------------------- |
| 声速公式引入新偏差           | TOF 特征失真   | 与旧值逐工况对比；H₂ 高浓度区差异大（线性→理想气 7~45%）但物理正确                  |
| Lagrange 分数延迟在高频失真  | 载波变形       | 200kHz 在 1MS/s 下为 0.4×Nyquist，远低于 0.8×Nyquist 精度边界      |
| 分数延迟后 peak_index 偏移 | 测试断言失败     | 改为 ±1 采样容差或用互相关验证 TOF                                   |
| WMS 需要全组分签名         | 调用链改动      | 改 `_hidden_lambda_mix` 接全组分参数，`_tcs_voltage` 已有全组分可直接透传 |
| V_TCS 量级漂移          | DL 训练输入分布变 | 核对 WMS λ 范围（0.026~0.19），必要时重标 tcs_response_slope        |
| WMS 精度 ±5~8%（非 <2%） | 热导模型系统偏差   | 对仿真训练数据可接受（优于旧线性公式 3~6%），且能捕捉正确的凹函数形状                   |
| 测试金值批量更新            | 工作量        | 用脚本重新计算金值，逐 case 人工核对量级                                 |

回退策略：每 Phase 独立 commit，任一 Phase 卡点可回退到上一 Phase，不影响主线 472 测试。

## 8 不在本计划范围

- **GERG-2008 / AGA-10 真实气体状态方程**：低压（≤0.7MPa）下理想气混合足够（偏差 <0.5%，Lozano-Martín et al. 2020），GERG-2008 实现需数百参数，过度工程。若未来要迁移到实测数据或高压（>2MPa）场景再考虑。
- **Brokaw / 严格 Chapman-Enskog 热导理论**：WMS 精度约 ±5~8%（Vesovic 2001），严格理论可达 ±2~3% 但需 Lennard-Jones 势能参数，收益不抵成本。Hirschfelder-Eucken 方法（±2~3%）可作为后续提升选项。
- **10× 过采样 + resample_poly 方案**：审查后改用 Lagrange 分数延迟 FIR（精度更高、零性能开销、无噪声缩放问题）。若后续需要模拟前端模拟滤波器带宽效应，可回退到 2~4× 过采样方案（见 §3.7）。
- **NDIR 滤光片占位符替换**：仍待 TraceGas datasheet（见 [`传感器硬件资料整理.md`](references/传感器硬件资料整理.md) 附录 A.4）。
- **RCDW 子工程**（`rcdw_mgda/`）：独立模块，本计划仅涉及主线 `src/`。
