## 1 系统概述

本系统面向**掺氢天然气**管道场景，采用多种传感原理（热导、红外 NDIR、超声波）实现气体组分的多模态检测，辅以温湿度补偿，并通过 ADC / 数据采集卡完成信号数字化。系统核心传感器与数据采集器件如下：

| 序号  | 器件                | 检测对象 / 功能    | 检测原理             |
|:---:| ----------------- | ------------ | ---------------- |
| 1   | TCS205            | 氢气含量 / 气体热导率 | 热导法（薄膜电阻加热）      |
| 2   | TraceGas-HC-NDIR  | 甲烷及烷烃类可燃气体   | 非色散红外（NDIR）      |
| 3   | TraceGas-NDIR-CO₂ | 二氧化碳         | 非色散红外（NDIR）      |
| 4   | SHT45             | 环境温度 & 相对湿度  | CMOSens 电容式 / 带隙 |
| 5   | PSC200K           | 超声波传播特性      | 压电陶瓷超声           |
| 6   | ADS8684 / ADS8688 | 模拟信号采集       | 16-bit SAR ADC   |
| 7   | NI USB-6453       | 高精度数据采集      | 20-bit 同步采样 DAQ  |

## 2 TCS205 气体热导传感器

**制造商：** Xensor Integration（代理：广州安凯电子）
**资料来源：** `TCS205 气体热导传感器.pdf`

### 2.1 工作原理

传感器芯片由硅微机械加工制成，核心为面积约 1 mm² 的绝热薄膜。薄膜上有两条薄膜电阻 Rm1、Rm2，用于加热薄膜并测量膜温 Tm。薄膜上方覆盖带腔体的硅盖片，构成热导测量室（体积 ~0.2 mm³）。气体通过侧面开口以扩散方式进入测量室（非流动），避免流速干扰。

芯片固体部分另有两条电阻 Rt1、Rt2 用于测量和补偿环境温度。通过维持膜的超额温度 ΔT 恒定，测量维持该温度所需的功率或信号变化，即可反映气体热导率 λ 的变化。

### 2.2 主要应用

- 测量氢气含量（氢的热导率远高于其他气体）
- 二元气体分析（CO₂/N₂、O₂/N₂ 等）
- 天然气鉴别与分类
- 沼气 / 消化池气体监测
- 氦气、氙气含量测定

### 2.5 引脚与接口

- **封装：** TO5-style 8 引脚底座
- **接线材料：** 金丝键合
- **气体接触材料：** Si, SiNx, 金, 环氧树脂

### 2.6 推荐应用电路

资料提供了三种典型电路方案：

1. **恒定超额温度模式**（ΔT=const）：Rm1+Rm2 串联在两个运放之间形成正反馈环路，Rt1+Rt2 提供一阶温度补偿。灵敏度示例：1% He in N₂ → U1 变化约 140 mV。
2. **恒定膜电流模式**（im=const）：通过温补负参考电压驱动恒流，R4 实现二阶温度补偿。
3. **惠斯通电桥模式**：可配合标准应变计仪表使用，对角电压 Udiag 作为输出信号。

## 3 TraceGas-HC-NDIR 可燃气体红外传感模块

**制造商：** 深圳市痕量气体传感科技有限公司
**资料来源：** `可燃气体红外传感器-说明书V1.5.pdf`

### 3.1 工作原理

基于**比尔-朗伯定律**，采用 NDIR（非色散红外）原理。使用 LED 窄带光源和快速响应光电二极管（PD），结合低功耗电路和优化光学系统实现气体浓度检测。

| 参数       | 指标                            |
| -------- | ----------------------------- |
| 检测原理     | NDIR                          |
| 采样方式     | 自然扩散式                         |
| 检测气体     | 甲烷（CH₄）及烷烃类气体                 |
| 支持气体类型   | CH₄ 和 i-C₄H₁₀（可切换）            |
| 测量范围     | 0 ~ 100 %LEL                  |
| 测量精度     | ±3 %LEL（25°C）                 |
| 预热时间     | ≤ 60 s                        |
| 响应时间 T90 | ≤ 15 s                        |
| 运行温度     | -40°C ~ +70°C                 |
| 环境湿度     | 0 ~ 98 %RH（无凝露）               |
| 通信接口     | UART（TTL 电平），≤1 Hz            |
| 通信波特率    | 9600（默认），可选 19200/38400/57600 |
| 工作电压     | 3.0 V ~ 5.0 V                 |

| 重量       | 22 g                          |
| 预期寿命     | 8 ~ 10 年                      |

| MODE 0（常规）    | 625 µA     |

### 3.4 引脚定义

| 引脚编号 | 标志  | 功能          |
|:----:|:---:| ----------- |
| 1    | +   | 电源正极        |
| 2    | -   | 电源负极        |

配套插孔：Harwin H3182-05

### 3.5 常用通信指令

| 指令          | HEX               | 功能       | 回复说明                                             |
| ----------- | ----------------- | -------- | ------------------------------------------------ |
| `DATAE`     | 44 41 54 41 45    | 读取浓度     | 5 字节：浓度H + 浓度L + 状态码 + BCC + 0x0D                |
| `DATAF`     | 44 41 54 41 46    | 读取浓度+温湿度 | 9 字节：浓度(2B) + 状态码 + 温度(2B) + 湿度(2B) + BCC + 0x0D |
| `ZERO2`     | 5A 45 52 4F 32    | 零点调整     | "ZERO2 OK"                                       |
| `CALB XXXX` | 43 41 4C 42 20 XX | 量程调整     | "CALB OK"                                        |
| `INIT`      | 49 4E 49 54       | 恢复默认     | "INIT OK"                                        |
| `SGAS X`    | 53 47 41 53 20 XX | 切换气体类型   | "Current Gas Type CH4/C4H10"                     |
| `USERSET`   | —                 | 查询用户设置   | 返回各项补偿系数                                         |

**浓度解算：** 浓度值 = (H×256 + L) / 100 (%VOL)

**温度解算：** T(°C) = 175.0 × 温度值 / 65535 - 45.0

**湿度解算：** RH(%) = 100.0 × 湿度值 / 65535

### 3.6 注意事项

- 上电后需预热 ≥60 s，调零前需温度变化 <0.6°C/min
- 传感器配有疏水膜，污染严重时需更换
- 校准建议使用 ≤60%LEL 目标气体
- 禁止带电热插拔
- 请勿焊接引脚，使用配套管座连接
- 电池供电建议 ≥3.3 V，以保证低温供电稳定

# 附录 A：仿真实现对照分析（2026-07-02）

> 本附录对照本文件第 2~8 章列出的实际器件型号，核对 `src/sim/` 仿真代码的建模方式，逐器件说明一致性与偏差。证据均给出代码位置（相对项目根目录）与关键常数。

## A.1 总体判断

仿真物理建模方向正确（Beer-Lambert、HITRAN 谱线、声速混合、热导响应、弛豫衰减齐全），但与实际硬件型号存在三处实质偏差，按影响排序：

1. 超声载波频率 40 kHz ≠ PSC200K 实际 200 kHz（影响声学可观测性分布）；
2. NDIR 滤光片 FWHM 为行业参考占位值，非 TraceGas 实际 datasheet；
3. 波形 ADC 位深需按实际信号链路确认（16-bit 还是 20-bit）。

## A.2 逐器件对照

### A.2.1 PSC205 气体热导传感器

| 项 | 硬件 (TCS205) | 仿真 | 位置 |
|---|---|---|---|
| 建模方式 | 恒 ΔT 模式，ΔT=30~70°C，几何因子 G=3.6 mm | 经验线性电压模型 | `src/sim/generation/acoustic_physics.py:258-265` |
| 热导率 λ | 真实气体 λ（H₂~0.180, CH₄~0.034, CO₂~0.016, N₂~0.026 W/(m·K)） | `λ=0.034 + 0.00155·x_H2 − 0.00011·x_CO2 + 0.00002·(T−25)` | `acoustic_physics.py:250-251` |
| 时间常数 | 薄膜热 <5 ms，气体扩散 <100 ms | 系统级双 τ=10~60 s | `src/sim/generation/slow.py:22-31` |

- V_TCS 公式：`V = 1.1 + 15·(λ−0.026) + 0.004·(T−20) + N(0,0.006)`，系数定义在 `acoustic_physics.py` 的 `PROCESSING_PARAMS`（`tcs_response_slope=15.0`、`tcs_lambda_offset=0.026`、`tcs_temperature_response=0.004`）。
- 经验 λ 混合的 H₂ 贡献斜率（0.00155 per %H₂）与真实 H₂-N₂ 混合（0→100%，λ 从 0.026→0.180，约 0.00154 per %）数值接近，方向正确，但并非来自真实物性表加权。
- 系统级时间常数（秒级）远大于 TCS205 芯片时间常数（毫秒级），代表气室+传感器整体响应，不是芯片本身；这一区别文档此前未显式说明。
- 未建模 ΔT、加热功率（≤30 mW）、膜温上限 180°C、几何因子 G。对组分回归任务影响有限，但对传感器设计验证场景不适用。

### A.2.2 TraceGas-HC-NDIR / TraceGas-NDIR-CO₂ 红外模块

| 项 | 硬件 | 仿真 | 位置 |
|---|---|---|---|
| CH₄ 通道 | TraceGas-HC-NDIR，UART ≤1 Hz 数字浓度 | 模拟电压 V_NDIR_CH4，Beer-Lambert | `src/sim/generation/slow.py:331-339` |
| CO₂ 通道 | TraceGas-NDIR-CO₂，ADC 数字量 | 模拟电压 V_NDIR_CO2 | 同上 |
| 滤光片 | 实际 datasheet 未知 | **占位符**：CH₄ 3030 cm⁻¹/FWHM 147；CO₂ 2347 cm⁻¹/FWHM 93 | `configs/data/spectral-defaults.json` |
| HITRAN 谱线 | — | ✓ Voigt 线型，T/P 展宽 | `src/sim/generation/spectral/hitran_backend.py:140-149` |
| 光程 L | — | 0.2~1.8 m，多光程扫描 | `src/sim/generation/conditions.py:40` |
| T/P 依赖 | — | HITRAN 展宽 + H₂O 串扰 + 经验漂移项 | `acoustic_physics.py:190-195, 242-247` |

- Beer-Lambert 主公式：`V = baseline·exp(−A_observed)`，baseline=2.5 V，下限 0.1 V。
- 滤光片参数代码注释已明确标记为 "industry-reference placeholders, not the actual datasheet of the target TraceGas-HC-NDIR series sensor"，是**已知缺口**。中心波数（3030/2347 cm⁻¹）与实际模块中心波长（CH₄ ~3.3 μm、CO₂ ~4.26 μm）方向一致，但 FWHM 直接影响吸收积分定量，占位值会扭曲标定。
- 仿真在"光电二极管后、模块内 MCU 前"取模拟信号，跳过了 TraceGas-HC 的 UART 数字化与 TraceGas-CO₂ 的 ADC 数字化。保留物理信息更多，但与模块级实际输出（≤1 Hz、已量化）存在差异。

### A.2.3 PSC200K 超声波传感器

| 项 | 硬件 (PSC200K) | 仿真 | 位置 |
|---|---|---|---|
| 中心频率 | **200 kHz ±10** | **40 kHz** | `src/sim/generation/waveforms.py:19`、`acoustic_physics.py:33` |
| 采样率 | — | 200 kS/s | `waveforms.py:21` |
| 声速混合 | — | H₂=1306, CH₄=446, CO₂=268, N₂=353 m/s，温度修正 +0.6 m/s/°C | `acoustic_physics.py:39-42, 45-57` |
| 声衰减 | — | 经典吸收 + CO₂/CH₄/N₂/H₂O 弛豫 + H₂ 扩散 | `acoustic_physics.py:60-159` |
| 回波振幅 | — | `exp(−α·L) + N(0, 0.0008)` | `acoustic_physics.py:180` |
| 换能器响应 | — | 二阶带通谐振核，带宽 12 kHz，4 周期 ringdown | `waveforms.py:357-374` |

- **频率偏差是本次对照影响最大的项**。声学衰减与频率强相关：经典吸收 ∝ f²，200 kHz 比 40 kHz 大 25 倍；CO₂/CH₄/N₂/H₂O 的 V-T 弛豫峰在 28~100 kHz 区间，两个频率下各组分衰减对比度完全不同；H₂ 扩散衰减项表现也随频率变化。
- 仿真 40 kHz 训练出的声学特征，与 200 kHz 实测波形可观测性分布不在同一量级，直接迁移到 PSC200K 采集的真实数据上存在风险。
- 采样率 200 kS/s 对 40 kHz 载波够用（5×过采样），但对 200 kHz 载波违反奈奎斯特，需同步提到 ≥500 kS/s。
- 衰减常数（`alpha_classical_K_ref=1.84e-11`、各 `alpha_lambda_max`、`f_relax_*`）在频率参数化公式中显式含 f，改频率后弛豫峰相对位置变化，需要重新核对量级。

### A.2.4 SHT45 温湿度传感器

| 项 | 硬件 (SHT45) | 仿真 | 位置 |
|---|---|---|---|
| T_C | ±0.1°C, t63%=2 s | 直接取 condition baseline + N(0,0.05)°C | `src/sim/generation/slow.py:158-160` |
| H_RH | ±1.0%RH, t63%=4 s | 直接取 condition baseline + N(0,0.1)%RH | 同上 |
| I²C 0x44 | — | 不建模通信层 | — |

- 温湿度作为环境已知条件输入，方向合理。仿真噪声（0.05°C/0.1%RH）小于 SHT45 标称精度（0.1°C/1.0%RH），相当于按理想传感器处理。
- 未建模 t63% 响应延迟，但温湿度变化慢，影响可忽略。基本可接受。

### A.2.5 ADS8684 / ADS8688 与 NI USB-6453 ADC

| 项 | 硬件 | 仿真 | 位置 |
|---|---|---|---|
| 波形通道 | NI-6453 20-bit 或 ADS8684 16-bit | **16-bit**, ±5 V, 200 kS/s, LSB≈152.6 μV | `waveforms.py:341-354` |
| 慢通道 | ADS8684 16-bit SAR | **未量化**，float32 存储 | `slow.py` |

- 波形量化函数 `_digitize_waveform()`：`scale = 5.0/32767`，int16 截断到 ±32767，对应 ±5 V 量程。
- 波形前端噪声：超声 1 mV，光纤麦克风 ≈0.14 mV。
- 慢通道（V_NDIR_*, V_TCS, T_C, P_MPa, H_RH, L_m）存为 `np.float32`，无 ADC 量化、无 DNL/INL 误差建模。慢通道噪声主要来自 multi-τ 动力学注入，缺量化影响较小但严格说不完整。

### A.2.6 syngas 场景的 V_NDIR_CO 通道

syngas 场景在 9 慢通道中加入 `V_NDIR_CO`（`src/sim/core/syngas_schema.py:27-38`），实现完整 CO NDIR 光谱前向（`src/sim/generation/syngas/optical_backend.py`，CO 网格 1980~2310 cm⁻¹）与 3×3 串扰矩阵（`src/sim/generation/syngas/optical_crosstalk.py`）。本硬件清单中并无 CO NDIR 模块，syngas 场景若要硬件落地需额外采购 CO NDIR。

## A.3 关键问题处理决策

### 问题 1：超声载波频率对齐 200 kHz

**决策：对齐 PSC200K 实际 200 kHz，同时把 L_m 声程范围上限从 1.8m 压缩到 0.3m。**

依据 Phase 0 物理可行性核对（见 [`Phase0_物理可行性核对记录.md`](../Phase0_物理可行性核对记录.md)）：200 kHz 下 CH₄/CO₂ 振动弛豫吸收接近峰值，典型天然气（CH₄≥55%）在 L≥0.5m 信号被完全淹没；压缩声程至 ≤0.3m 后 SNR 回到 28~47dB，信号可用。

代价：L_m 作为条件变量跨度从 1.6m 压到 0.1m，TOF 动态范围从 0.15~6.7ms 压到 0.15~1.12ms，声学通道区分力下降；序列内多光程扫描 `path_lms` 同步改为 ≤0.3m。

需联动修改：
- `waveforms.py:19` `CENTER_FREQUENCY_HZ = 40000.0` → `200000.0`
- `acoustic_physics.py:33` `acoustic_excitation_frequency_hz = 40000.0` → `200000.0`
- `waveforms.py:21` 采样率 `200000` → `1000000`（满足奈奎斯特，对齐 NI-6453 同步采样率）
- `conditions.py:40` L_m 上限 `1.8` → `0.3`，syngas 同步
- 序列内 `path_lms` 改为 ≤0.3m 的 5 档
- 重新核对 `acoustic_physics.py:21-32` 各衰减常数在 200 kHz 下的量级（Phase 0 已确认弛豫常数为标准 Bass 值，量级合理，无需重标定）
- `waveforms.py:53` `transducer_bandwidth_hz=12000` 与 ringdown cycles 需按 200 kHz 重新评估
- 已生成的 benchmark（`wv4-*`、`sg4-*`）需重新生成，旧结果作废并标注

### 问题 2：NDIR 滤光片仍使用占位符

**决策：暂保留 `configs/data/spectral-defaults.json` 中的占位 `center_cm1`/`fwhm_cm1`，不替换为 TraceGas 实际 datasheet。**

理由：TraceGas-HC-NDIR / TraceGas-NDIR-CO₂ 的滤光片 datasheet 暂不可得。占位值（CH₄ 3030 cm⁻¹/FWHM 147、CO₂ 2347 cm⁻¹/FWHM 93、syngas CO 2145.92 cm⁻¹/FWHM 82.89）中心波长方向正确，定性可用。代码注释已标记为占位。待取得实际 datasheet 后再替换，并在替换时重生成依赖 NDIR 的 benchmark。

### 问题 3：波形 ADC 链路按 NI-6453

**决策：超声波形走 NI USB-6453，对应 20-bit、1 MS/s/ch 同步采样。**

理由：PSC200K 中心频率 200 kHz，ADS8684 最高 500 kS/s 仅 2.5×过采样，且为 16-bit；NI-6453 提供 20-bit、1 MS/s/ch 同步采样，满足 200 kHz 载波的奈奎斯特与过采样需求。

需联动修改：
- `waveforms.py` 量化位深 16-bit → 20-bit：`ADC_MAX_INT16=32767` 改为 20-bit 等价（`ADC_MAX_INT20=524287`），`_digitize_waveform()` 量化逻辑同步调整。
- 采样率与问题 1 联动，建议设为 1 MS/s（对齐 NI-6453 同步模式）。
- `waveform_spec.json` 写入新的 `sample_rate_hz`、`daq_bits`、`daq_full_scale_v`，下游 dataset 加载与归一化需兼容。
- 量程按 NI-6453 实际可选 ±0.2/±2.5/±5/±10 V 之一确认（当前 ±5 V，需核对超声回波实际幅度是否落在该量程）。
- 慢通道仍走 ADS8684（16-bit），若要严格对齐可补一级 16-bit 量化，优先级低于波形链路。
