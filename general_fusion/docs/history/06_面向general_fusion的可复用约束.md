# 面向 general_fusion 的可复用约束

> 核验日期：2026-08-27  
> 阶段：H0-7 首轮完成  
> 当前主线事实源：[general_fusion/项目总体规划.md](../../项目总体规划.md)  
> 跨项目综合：[05_跨项目算法比较矩阵.md](05_跨项目算法比较矩阵.md)  
> 失败根因：[04_失败经验与根因图谱.md](04_失败经验与根因图谱.md)

本页将历史证据转换为 general_fusion A0-A6 的前置约束、候选研究卡和继续/暂停/关闭条件。它不改变 A0-A6 的阶段定义，不在 H0 阶段选定最终模型；当前阶段状态、代码所有权和时间安排仍以 `general_fusion/项目总体规划.md` 为唯一事实源。

## 1. 先决契约检查

### 1.1 已冻结的主线不变量

以下内容可以直接作为 A0 的检查项：

- 数据集差异只进入适配器和任务头，融合核心不硬编码气体名称、固定通道数或数据集路径。
- Ar-He-CO₂ 按 `mixture_id` 分组；xylene 按完整 workbook 分组；跨数据集分别训练只声称架构复用，不声称 zero-shot。
- scaler 只由训练组拟合；验证、测试和盲测不得参与统计量估计。
- 输入契约显式表达 signals、sensor identity/type、valid mask、quality、time 或 delta time、target、target mask、group 和 dataset identity。
- 真实可观测量、oracle 特征、后验真值、离线测量和推理时不可用输入必须分开登记。
- 历史的 `mixture_id`、`sequence_id`、`base_condition_id`、`noise_seed_index` 和 `noise_seed` 语义不直接移植到新 benchmark；新主线不得用旧字段构成隐藏依赖。

### 1.2 主线文档—代码路径冲突的处置

首轮审查发现 `general_fusion/项目总体规划.md` §1.3 曾使用 `src/sim/`、`src/dl/`、`src/ml/`、`src/pipeline/`，而 `general_fusion/README.md`、`pyproject.toml`、测试导入路径和实际骨架统一使用 `src/gf/sim/`、`src/gf/dl/`、`src/gf/ml/`、`src/gf/pipeline/`。2026-08-27 已将主线计划表对齐到实际包布局；未新增实现，也未改变包结构。

该冲突现已在 general_fusion 文档范围内消除。A0 动作 2 仍需把项目计划、README、`pyproject.toml`、测试导入路径和实际目录作为同一项契约检查，避免后续再次漂移。

## 2. 历史约束到 A0-A6 的映射

| 阶段                     | 必须吸收的历史约束                                                 | 本阶段最小证据                                            | 失败或暂停条件                                            | 禁止的历史迁移                                                        |
| ---------------------- | --------------------------------------------------------- | -------------------------------------------------- | -------------------------------------------------- | -------------------------------------------------------------- |
| A0 契约冻结                | task、输入可观测量、输出自由度、闭合、group、scaler、metric、部署输入和代码所有权       | 两类适配器共享样本契约；`mixture_id`/workbook 分组测试；文档、包配置和目录一致 | 字段语义冲突、oracle 混入、split 泄漏、路径契约未收敛                  | 直接复用旧主键、固定气体头、旧窗口、旧产物目录                                        |
| A1 Ar-He-CO₂ benchmark | 信息审计先于容量；cheap baseline、最佳单模态、简单融合和固定融合必须先有               | 数据质量、Fisher/rank 或等价信息诊断；Ridge/GBDT/轻量基线；互补性与误差结构  | 最佳简单基线已达上限，或多模态没有可辨识互补                             | 以历史 TV3、syngas 或 GIB 绝对指标代替新 benchmark 证据                      |
| A2 通用融合核心              | 一次只引入一个可解释机制；保留 raw/phase/DSP、输出 head、OOF residual 和无机制对照 | 固定 split、多个 seed、配对区间、单项消融、参数量/效率、分层误差             | 相对最佳强基线收益不稳定、不能由消融归因或只在单一 split 成立                 | 复制固定通道旧模型；把 attention、物理命名或容量增长写成机制收益                          |
| A3 xylene 外部验证         | 六路 QCM 是同一物理原理阵列；完整 workbook 分组；标签和近饱和边界显式处理              | 同一融合核心独立训练；文件级 split、训练组 scaler、标签审计、强基线和失败文件表     | split 或标签不可复核，或收益只来自数据集专属分支                        | zero-shot、六种异构模态、把 ppm 与气体百分比直接比较                              |
| A4 变传感器与可靠性            | 真实缺失、未见组合、质量退化、冲突、OOD、UQ 与拒识要先定义；动态权重需要可校准质量观测            | 完整输入、随机 dropout、插补、mask、等权/固定权重、质量路由和失败输出全矩阵       | clean cost 超容忍范围、质量预测未校准、只测随机 dropout 或 UQ gate 未过 | 默认启用 RCDW hard suppression/ErrorNet；把标准化扰动写成物理退化               |
| A5 小规模真实 Ar-He-CO₂     | 仿真—真实边界、校准批次/盲测批次、独立重复和实际配比范围必须冻结                         | 纯气、二元、三元配比的原始数据、盲测记录、重复、仿真—真实差距和协议审计               | 真实数据不足以覆盖声明范围；盲测前调参；把窗口当独立实验重复                     | 用真实数据反向污染主 DL 训练；声称未采集配比或复杂工况泛化                                |
| A6 论文与一致性              | 每条主张绑定来源、scope、evidence、gate、版本和限制；负结果不能隐藏                | 主张—证据矩阵、图表单一事实源、版本和 hash、限制条件、反向审稿                 | 数值、术语、阶段状态或失败边界不一致                                 | 把 prerequisite pass 写成 target pass，把 freeze 写成 scientific pass |

## 3. 候选算法研究卡

候选卡按研究问题组织，不按历史网络名称组织。每张卡的最小实现都必须先通过 A0/A1 前置门；未满足前置门时只保留为 `park` 或 `negative_control`。

### C-01：强简单基线与信息预算

| 项目             | 内容                                                     |
| -------------- | ------------------------------------------------------ |
| 研究问题           | 多模态观测是否提供超出最佳单模态和固定特征 baseline 的可辨识互补信息？               |
| 可观测依据          | signals、统计/DSP、sensor mask、group split、目标标签和训练组 scaler |
| 最小实现           | 单模态 Ridge/GBDT、全输入 Ridge/GBDT、简单拼接 MLP、等权或固定权重融合       |
| 主指标            | A0 冻结的范围归一化 MAE；辅以 component-wise MAE/RMSE/R²、最差分层和效率  |
| 必要消融           | 单模态、去除每种模态、随机分组对照、不同特征集合；所有对照同一 split 和 seed 规则        |
| 反例             | 最佳单模态已达上限，或加入模态没有稳定互补，或收益来自 split/scaler 差异            |
| kill criterion | cheap probe 未显示可辨识互补，停止大规模融合和大型网络搜索，回到数据/物理设计          |
| 升级条件           | 多个分组和 seed 下仍有可复核的互补误差结构，才进入 A2 机制卡                    |

### C-02：输入保真与输出契约对照

| 项目             | 内容                                                             |
| -------------- | -------------------------------------------------------------- |
| 研究问题           | 绝对 timing、相位、质量量和输出闭合是否比扩大 encoder 更先决定可学性？                    |
| 可观测依据          | raw/DSP/phase、absolute TOF 或 delta time、PSR/SNR/校准量、输出自由度、闭合残差 |
| 最小实现           | 统一 encoder 下做 raw/feature/phase 和 raw4/显式闭合 head 的单因素对照        |
| 主指标            | 分组 component-wise 误差、闭合残差、低浓度分层、输入重建/有效信息检查和推理成本               |
| 必要消融           | pooling、时间信息、质量特征、target scale、输出 head、loss 权重分别消融             |
| 反例             | 所需物理量在推理时不可获得，或不同 head 同时存在产物冲突和 evaluator 复用                  |
| kill criterion | 输入保真或 head provenance 无法闭合时，停止性能排名和信息上限解释                      |
| 升级条件           | 数据、head、scaler、evaluator 和逐样本输出全闭环，且收益可以由单因素消融归因               |

### C-03：OOF 结构化残差

| 项目             | 内容                                                                              |
| -------------- | ------------------------------------------------------------------------------- |
| 研究问题           | 强 baseline 的 OOF 残差是否与真实可观测的物理或质量特征存在稳定关系？                                      |
| 可观测依据          | OOF baseline prediction、residual、观测特征、分组 split 和 OOD 协议                         |
| 最小实现           | Ridge/GBDT baseline + OOF residual MLP；并列无 residual、in-sample residual 和随机残差负对照 |
| 主指标            | 相对 baseline 的配对误差差异、残差分层、OOD 最差组、参数量和训练/推理成本                                    |
| 必要消融           | 是否 OOF、是否加入质量特征、residual 分支容量、固定/随机残差和单模态输入                                     |
| 反例             | residual 只在 in-sample 有效，或 OOF 后收益消失，或加入分支只增加参数不改变误差结构                          |
| kill criterion | 无 OOF 外推证据或不能超过预注册收益门时，保留 baseline，关闭残差升级                                       |
| 升级条件           | 多 seed、多分层和 OOD 下稳定，且 residual 关联可解释，才进入 A2 主候选                                 |

### C-04：质量感知的静态或学习式融合

| 项目             | 内容                                                     |
| -------------- | ------------------------------------------------------ |
| 研究问题           | 当前输入能否稳定估计各传感器或模态的质量，并用它改善退化场景而不伤害 clean 场景？           |
| 可观测依据          | valid mask、quality、退化类型、真实误差或独立质量标签、冲突和 OOD 样本         |
| 最小实现           | mask/quality 拼接、固定权重、校准后的轻量 gate；动态 ErrorNet 只作为后续受控对照 |
| 主指标            | clean 性能变化、退化收益、最差组误差、校准误差、拒识率、误抑制率和开销                 |
| 必要消融           | 无质量、显式质量、随机 dropout、真实缺失、物理退化、冲突观测、等权/固定权重             |
| 反例             | quality 只能由后验真值获得，或与真实误差无关，或 clean cost 超过容忍范围         |
| kill criterion | 质量未校准、真实退化收益不存在或 hard suppression 误触发，停止动态路由           |
| 升级条件           | 质量观测部署可得，校准和 clean-cost gate 通过，才进入 A4 扩展              |

### C-05：可变传感器集合与显式失败输出

| 项目             | 内容                                                       |
| -------------- | -------------------------------------------------------- |
| 研究问题           | 传感器缺失、未见组合、漂移、尖峰、饱和和冲突时，融合核心能否识别风险并合理退化？                 |
| 可观测依据          | sensor identity/type、valid mask、quality、time、退化生成规则和失败标签 |
| 最小实现           | mask-aware encoder、完整输入基线、零值/统计插补、随机 dropout、固定融合和显式拒识头  |
| 主指标            | 组合分层误差、完整输入退化、最差组、失败率、拒识覆盖、校准和额外成本                       |
| 必要消融           | 训练见过/未见组合、单模态全缺失、真实退化/随机 dropout、mask 与 quality 去除       |
| 反例             | 只用随机 dropout 且不能覆盖真实退化，或失败状态无法被模型和评估器区分                  |
| kill criterion | 未见组合或真实退化下没有可解释保护，或失败输出不可靠，暂停 A4 主张                      |
| 升级条件           | 全部必测退化和 OOD 条件完成，失败输出和成本边界可复核                            |

### C-06：外部数据适配器复用

| 项目             | 内容                                                                   |
| -------------- | -------------------------------------------------------------------- |
| 研究问题           | 同一融合核心能否通过适配器适配不同气体对象与传感体系，而不写数据集专属分支？                               |
| 可观测依据          | workbook identity、QCM array sensor identity、标签表、质量标记、不规则采样和文件级 split |
| 最小实现           | xylene adapter、三组分任务头、共享 FusionCore、同类别单通道/简单融合/强基线                  |
| 主指标            | 文件级总体和分层误差、留组成/跨浓度结果、失败文件率、训练/推理成本                                   |
| 必要消融           | 共享 core、适配器、任务头、文件级 split、标签边界和近饱和文件排除规则                             |
| 反例             | 同一 workbook 跨 split、近饱和标签不明确，或需要专属融合分支才能获得收益                         |
| kill criterion | 文件级契约和标签不可复核，或收益无法与数据集专属逻辑分离，收缩为适配范围分析                               |
| 升级条件           | 同一 core 独立训练完成，且结果与强基线和失败边界可复核，才支持 A3 外部复用主张                         |

## 4. 路线继续、暂停与关闭条件

| 路线                       | 当前处置             | 继续条件                                                | 暂停/关闭条件                        |
| ------------------------ | ---------------- | --------------------------------------------------- | ------------------------------ |
| Ridge/GBDT 与单模态 baseline | 继续，进入 A0/A1      | 统一接口、分组切分、scaler 和指标冻结                              | 数据已证明无互补且达到预注册上限               |
| raw/phase/DSP 表示         | 受控重写             | 关键观测量真实可得，输入和 pooling parity 通过                     | absolute timing/质量量丢失，或收益无法归因  |
| OOF residual             | A2 候选            | OOF 无泄漏，残差与观测量稳定关联                                  | 只有 in-sample 收益或无法超过 baseline  |
| 输出 head/target scale     | A0/A2 单因素对照      | head identity、closure、target transform 和 metrics 一致 | 产物冲突、evaluator 复用或目标语义不一致      |
| 动态权重/ErrorNet            | park             | 恢复数据与 checkpoint，质量可观测、校准和 clean-cost gate 通过       | correlation 未确认、扰动非物理或误触发持续    |
| hard suppression/拒识      | negative control | 只在真实退化、校准和显式失败协议通过后重开                               | clean error 增加或错误抑制过多          |
| 大型 Transformer           | 暂停               | A1/A2 证明强基线和信息互补仍有明确空间                              | cheap probe 不支持，或只靠容量掩盖契约/信息问题 |
| xylene 外部验证              | A3 准备            | workbook split、标签审计和共享 core 契约冻结                    | 只能通过数据集专属分支或无法声称独立训练           |
