# 候选研究入口与杀停条件

> 核验日期：2026-08-27  
> 阶段：H0-7 首轮执行入口完成  
> 约束与研究卡：[06_面向general_fusion的可复用约束.md](06_面向general_fusion的可复用约束.md)  
> 当前主线计划：[general_fusion/项目总体规划.md](../../项目总体规划.md)

本页把 H0-7 的候选卡压缩为进入 general_fusion 后可执行的顺序、最小产物和杀停条件。它不是新的阶段计划，也不替代 `项目总体规划.md` 的 A0-A6 状态；候选未满足前置条件时不得提前实现或长跑。

## 1. 固定执行顺序

```text
A0 契约与 smoke
    ↓
A1 信息审计 + cheap baseline
    ↓
A2 表示/输出对照 → OOF 残差（最多保留一个主方法和一个备选）
    ↓
A3 xylene 适配器复用
    ↓
A4 真实缺失/质量退化/冲突/OOD/UQ
    ↓
A5 小规模真实 Ar-He-CO₂ 验证
```

任一上游阶段未通过时，后续路线只保留为研究问题或负对照；不得通过增加网络、候选或数据规模绕过阶段门。

## 3. 每个入口的统一验收字段

每个入口开始前，运行目录至少应能回溯以下字段：

1. `task_id`、`dataset_id`、数据版本和数据 manifest；
2. `mixture_id` 或完整 workbook 的 group 规则，及 train/validation/test/OOD/blind 划分；
3. 输入 modality、sensor identity/type、valid mask、quality、time/delta time 和部署可用性；
4. output head、target transform、闭合规则、单位和 metric definition；
5. 配置快照、代码版本、seed、checkpoint、metrics、退出码和产物 hash；
6. 主指标、分层指标、效率、失败率、置信区间或校准指标；
7. 预注册反例、kill criterion、升级条件和实际 claim scope。

缺少其中任一项时，记录状态只能是 `implemented`、`smoke_only`、`blocked` 或 `unknown`，不得登记为 formal pass。

## 4. 暂不开放的路线

| 路线 | 暂停原因 | 重新开放条件 |
| --- | --- | --- |
| 大型 Transformer 或更大 generic waveform model | 历史失败首先指向信息、表示、pooling、输出和协议问题；A1 尚未证明存在可利用空间 | A1 强 baseline 和信息审计完成，并且 A2 有可归因机制需求 |
| RCDW ErrorNet 动态权重 | data/checkpoint 缺失，误差相关性 unknown，质量校准未闭合 | 恢复 exact artifacts，独立 calibration、真实物理退化和 clean-cost gate 全通过 |
| RCDW hard suppression | 历史 smoke 有 clean cost 和大量触发，阈值语义未校准 | 物理退化集上收益稳定、误抑制可控且显式失败输出通过 |
| TV3 MRS-EI C3 | C2 freeze 的 semantic verdict 为 not_passed，C3 未获批准 | 新协议、新 gate 和显式复核授权；不能从旧 freeze 自动恢复 |
| GIB P3 → P4 | 七类候选在 G3-4 全部拒绝，`enter_P4_count=0` | P1/P2 产生新的信息假设并重新预注册 gate |
| syngas 128 结果直接进入当前主线 | 当前主线窗口为 512，历史 128 结果已 superseded | 独立 512 data manifest、experiment record 和 formal 结果闭环 |
