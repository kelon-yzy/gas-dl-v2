## 1. 文档职责

本文件把 A0 拆成可顺序执行、可验收的工作包，只维护步骤、依赖、交付物和阶段门。字段、shape、mask、标签和错误语义一经评审，唯一写入 `01_统一任务与接口契约.md`；指标、切分、seed、置信区间和收益门唯一写入 `02_评价协议与基线矩阵.md`。本文件不复制这两份契约的最终取值。

A0 的结论性目标是：使用真实来源的最小 Ar-He-CO₂ 仿真样本和真实 `xylene-e-nose` 工作簿样本，通过两个数据集适配器进入同一个无数据集分支的 `FusionCore`，完成确定性前向与自动测试。A0 不训练正式模型，不评价算法性能，也不生成正式规模数据。

## 3. A0 不变量

以下条件在全部工作包中持续生效：

1. 主任务为三组分浓度回归；分类仅保留为未来可配置辅助头，不进入 A0 smoke 的成功条件。
2. 数据集差异只进入适配器和任务头；`FusionCore` 不读取气体名称、数据集路径、固定通道数或数据集专属条件分支。
3. Ar-He-CO₂ 的 `group_id` 来源必须是 `mixture_id`，不得回退或重写为 `sequence_id`。
4. 新 benchmark 和 smoke 不依赖 `base_condition_id`、`noise_seed_index` 或 `noise_seed`。
5. xylene 的 `group_id` 是完整工作簿身份；同一工作簿的窗口不得跨 split。
6. scaler 只允许在训练组上 `fit`，验证组和测试组只能 `transform`。
7. `dataset_id` 只用于选择适配器、任务头和结果分层，不作为融合机制输入。
8. 缺失、质量、时间和标签不可用状态必须显式表达；不得用静默填充值掩盖契约错误。
9. smoke 使用可追溯的真实来源最小样本；测试夹具可以裁剪数据，但不得改变标签、分组或传感器语义。
10. 新代码只落在 `src/gf/*`、`configs/*` 和 `tests/*` 的既定职责内，不直接依赖历史子工程包。

## 5. 分步执行

### A0-0：资产、依赖与来源预检

**目标**：先确认 smoke 所需输入真实存在，避免接口按想象设计。

执行项：

- [x] 核对 `general_fusion/pyproject.toml`、`src/gf/*`、`configs/*`、`tests/*` 与总体规划中的代码所有权一致。
- [x] 建立 Ar-He-CO₂ 候选模态表；每项记录物理量、单位、传感器来源、推理时是否可观测、生成实现位置、单样本原始 shape 和当前可用状态。
- [x] 只保留“来源明确且当前可生成”的 v1 模态；缺少来源或实现的候选明确排除，不创建占位数据。
- [x] 核对 xylene 原始目录、47 个工作簿、标准六通道、表头变体、文件名标签和近饱和文件边界。
- [x] 核对读取 Excel 所需的直接依赖；若项目依赖中缺失，必须显式登记并在 A0-4 添加，不依赖开发机偶然安装状态。
- [x] 选定各数据集的最小 smoke 资产：Ar-He-CO₂ 使用物理生成器产生的小规模 pilot，且至少包含三个不同 `mixture_id`；xylene 至少使用三个有明确 ppm 标签的真实工作簿裁剪窗口。每类数据都必须足以构造互斥的 train、val、test 分组。

**阶段门 G0**：每个进入 v1 的 Ar-He-CO₂ 模态都有可追溯来源和可执行生成入口；xylene 文件可读取且标签可解析。任一条件不满足时，停止接口实现并先修复资产或缩减模态清单。

## 7. 风险、停止条件与处置

| 风险或触发信号 | 立即处置 | 禁止做法 |
| --- | --- | --- |
| Ar-He-CO₂ 候选模态没有物理来源或生成实现 | 从 v1 清单移除，记录为后续候选 | 用随机数组或旧气体字段补位 |
| xylene 表头、标签或时间轴无法无歧义解析 | 显式报错并修订适配规则 | 静默重命名、插值或填默认标签 |
| 同一 `group_id` 出现在多个 split | 结果作废，修复 split 根因并重跑 | 仅在评估阶段过滤重复样本 |
| `FusionCore` 需要数据集分支才能前向 | 退回 A0-2，重划适配器或任务头职责 | 在核心增加第二套路径 |
| 契约无法表达可变传感器或时间长度 | 修改唯一批次契约并同步测试 | 为 xylene 单独维护一种核心输入 |
| 评价阈值在看到正式结果后需要改变 | 保留原协议与结果，另立有版本的新协议 | 覆盖原阈值或不记录变更 |
| A0 smoke 开始承担性能比较 | 停止并移交 A1/A2 | 扩大模型、调参或选择最优 seed |
