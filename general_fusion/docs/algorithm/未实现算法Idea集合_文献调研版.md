> 重要说明：本文登记待检验假设与已关闭候选，不是已通过算法清单。`GF-I14` 已在 A2 判定科学失败并放弃；当前没有活跃算法候选，其他“建议”“优先级”和“预期”仍不代表已有实验结果。

## 摘要

本调研围绕三个问题展开：

1. 哪些已发表机制真正适配本项目的异构传感器、可变传感器集合和多组分定量契约？
2. 哪些方法能回应历史复盘已经暴露的表示损失、残差结构、模态支配和可靠性问题？
3. 哪些尚未实现的组合可以形成可证伪、可按 A0–A4 进入或杀停的算法 Idea？

检索结果显示，直接针对“掺氢天然气、多物理传感、多组分定量、严格组外划分”的深度学习证据仍然稀疏。现有直接证据更多证明了热导率、声速、密度等互补物理量具有联合辨识价值，而不是证明某一种大型深度网络已经胜出。另一方面，集合建模、未见模态组合、缺失模态鲁棒、非规则时间序列和分布无关区间校准已经存在较成熟的方法基础，但多数来自视觉、医疗、机器人或通用时间序列，不能直接外推为本项目结论。

因此，本集合的主线不是堆叠一个更大的通用模型，而是形成受项目契约约束的可证伪假设。首轮 A2 已否决 `GF-I01` 所代表的简单集合聚合路线，A2 的 residual 路线也未进入 formal；A2H 与 A2M 随后分别以 `NEGATIVE_RESULT` 和 `MLP_RETAINED` 关闭。`GF-I14 TQIF-Net` 又在 A2 两档容量筛选中显著劣于 matched C0，已判定科学失败并整体放弃。当前不自动提升登记册中的其他 Idea，必须先根据失败证据重新定义问题，再登记新的算法 ID。

## 1. Context：项目边界与不可破坏的不变量

### 1.1 当前任务边界

- `general_fusion` 已完成 A0、A1、A2、A2H、A2M 首轮实验及 TQIF A2 候选轮；TQIF 已失败放弃，A3 因没有冻结创新候选暂不进入。
- 本文登记未实现 Idea 与已关闭历史候选，不新增模型代码，也不把负结果改写为“已通过”。
- 每阶段最多保留一个主方案和一个备份方案；本文是研究库存，不是并行开发队列。
- Ar–He–CO₂ 数据必须按 `mixture_id` 分组；二甲苯数据必须按完整工作簿分组。
- scaler 只能在训练组拟合。
- 不允许把 `mixture_id` 回退或重写为 `sequence_id`。
- 新正式 benchmark 不依赖 `base_condition_id`、`noise_seed_index`、`noise_seed`。

### 1.2 通用融合核心的不变量

融合核心不得硬编码：

- 气体名称或固定组分数；
- 固定传感器种类或固定通道数；
- 数据集路径、工作簿结构或某一版特征列；
- 某一历史实验的主键和临时产物命名。

允许变化的是数据适配器、单传感器编码器和任务输出头；核心机制只接收带身份、类型、可用性和质量元数据的 token 集合。

### 1.3 从历史复盘继承的约束

- 通用端到端波形网络曾因绝对 TOF、时序、斜率、PSR、SNR 和标定信息被池化或归一化抹除而失败；新 Idea 必须证明没有重演信息秩损失。
- `OOF Ridge + residual MLP` 在限定历史作用域内显示出可迁移结构，但不等于在 `general_fusion` 已验证。
- 动态 ErrorNet、硬抑制和无校准可靠性门控缺少稳定误差相关性，并可能付出 clean-cost；只能作为条件触发方案或负对照。
- 单纯扩大 Transformer 容量没有先验正当性；只有 A1 强基线证明仍有稳定可学习残差时才允许进入。
- 输出头必须先冻结组分顺序无关、总量约束、零组分语义和损失口径，模型比较才有意义。

## 2. Task：检索问题、方法与证据等级

### 2.1 冻结研究问题

- **RQ1：适配性。** 哪些公开方法可以原生处理异构传感器、可变集合、同类型相关通道和未见传感器组合？
- **RQ2：根因对齐。** 哪些机制直接回应历史复盘中的绝对物理量丢失、模态支配、非规则采样、结构化残差和过度置信？
- **RQ3：可证伪性。** 如何把方法迁移写成带基线、消融、进入门槛和杀停条件的 Idea，而不是不可验证的模型拼盘？

### 2.2 检索视角

本次按五个视角串行检索并交叉核对：

1. 掺氢天然气与混合气体的多物理传感、传感器阵列和校准；
2. 集合建模、可变模态和未见模态组合；
3. 非规则时间序列、表征学习和小数据建模；
4. 不确定性、校准、共形区间和选择性回归；
5. 反向审稿：查找理论缺陷、任务迁移不成立和总体指标掩盖子组退化的证据。

由于当前协作约束未授权子代理，本轮五个视角由同一研究流程串行完成；这降低了独立研究者之间的互证强度，因此所有迁移结论均按“假设”处理。

### 2.3 证据等级

| 等级   | 定义                | 本文用法                   |
| ---- | ----------------- | ---------------------- |
| `D1` | 直接混合气体或本项目数据源论文   | 支撑问题真实性、传感器互补性和数据语义    |
| `M1` | 经同行评议的通用方法原论文     | 支撑机制存在与原任务能力，不支撑气体任务收益 |
| `A1` | 相邻化学计量学、时间序列或传感任务 | 支撑条件性设计，不直接外推性能        |
| `P1` | 预印本或尚未充分复核的新方法    | 只作为停车场灵感，不进入首轮主线       |
| `L1` | 本项目历史复盘和台账        | 支撑本地根因与进入条件，不等同外部可复现证据 |

### 2.4 检索后的核心判断

1. **多物理互补比“大模型”更有直接证据。** 掺氢天然气研究表明，热导率与声速或密度的组合可在天然气来源变化下联合估计氢浓度和热值；这支持跨物理传感，但不证明端到端神经网络必然优于轻量基线。[R1–R2]
2. **同类型阵列不应伪装成独立模态。** 二甲苯数据来自六个不同 MOF 涂层的 QCM 阵列，通道具有不同亲和性，但共享同一测量原理和潜在共模漂移；更合理的做法是先建模阵列内部关系，再与其他传感类型融合。[R3]
3. **训练分布设计可能比模型复杂度更重要。** 随机混合气校准能显式覆盖遮蔽效应和气体交互；顺序单气体校准在更真实混合物上可能失败。这要求鲁棒实验优先构造物理可解释的组合和干扰，而不是只做独立高斯噪声。[R4]
4. **集合模型与可变模态有方法基础，但仍需气体任务验证。** Deep Sets、Set Transformer 和 Unseen Modality Interaction 分别提供置换不变、元素交互和未见模态组合建模基础；它们的原始实验并不覆盖本项目的多组分气体定量。[R7–R9]
5. **置信度不能由一个未经校准的门控分数代替。** 多模态分类研究发现，移除或破坏模态后模型置信度可能反而升高；深度证据回归又存在理论解释不足。因此 A4 必须把点预测、区间覆盖、状态输出和组别风险分开验证。[R12, R18–R21]
6. **非线性模型的价值取决于响应机理。** 一项 H₂、CO、CH₄、CO₂ 传感器阵列研究中，PLS 与 ANN 都能建模，但 ANN 对具有明显非线性响应的 CH₄ 更有优势，传感器老化又以不同方式影响两类模型；这支持“先诊断非线性和漂移，再决定容量”，而不是默认深网胜出。[R5]
7. **单一物理量可能存在局部失效区。** 二元 Xe 混合气的超声 TOF 实验展示了实时测量可行性，也报告了中间浓度区的不连续与精度局限；这类反例支持保留多物理互补和分段误差审计。[R6]

## 5. A 类：通用集合核心

### GF-I01 异构传感器 Token 集合融合（HSTF）

**状态：** `REPRESENTATIVE_TESTED / NOT_PROMOTED / A2_ROUND1_NEGATIVE`

首轮代表实现为 masked-mean Deep Sets，不等同于已穷尽所有集合注意力结构；但该路线不再作为当前候选继续扩容。

**要修复的问题。** 固定拼接向量把传感器数量、排列和通道维度写死，无法自然支持传感器新增、缺失或不同数据集的适配器。

**核心机制。** 每个可用传感器由所属适配器编码为一个 token：

\[
z_i = \phi_{t_i}(x_i, q_i, m_i, c), \qquad
h = \rho\!\left(\sum_{i \in S} z_i\right)
\]

其中，`t_i` 是传感器类型，`q_i` 是显式质量量，`m_i` 是可用性掩码，`c` 是温度、压力、湿度、流量等上下文，`S` 是当前可用传感器集合。第一版使用 Deep Sets 式求和或均值聚合；只有当 A1 证明传感器交互是剩余误差来源时，才替换为 Set Transformer。

token 应包含传感器身份和类型，但集合核心对输入顺序置换不变。新增传感器通过注册适配器进入，核心不添加按气体名称或通道位置编写的分支。

**文献锚点与迁移边界。** Deep Sets 给出集合函数的置换不变结构，Set Transformer 增加集合元素之间的注意力交互。[R7–R8] 两者未在本项目数据和严格组外拆分上验证；本 Idea 的新意若存在，只能来自“异构传感器适配器 + 项目契约 + 气体定量验证”的组合，而不能宣称发明集合模型。

**最小实验。** 在同一冻结 split 和 scaler 契约下比较：

1. Ridge 或 PLS；
2. 固定向量 MLP；
3. Deep Sets token 融合；
4. Set Transformer 只作为容量对照。

**必要消融。** 去除传感器身份、去除类型、去除环境上下文、sum 与 mean 聚合、随机打乱 token 顺序、减少一个传感器。

**进入门槛。** A0 schema 能稳定表达 `sensor_id`、`sensor_type`、`available`、`quality` 和上下文，且 A1 已有可复现固定向量基线。

**杀停条件。** Deep Sets 在全部正式分组拆分上不优于同参数量固定向量 MLP，且置换或可变集合能力没有带来 A4 可测收益；此时保留简单接口，不升级注意力容量。

**阶段位置。** A2 首轮代表实现未晋级；接口思想被 TQIF 的 sensor token 契约吸收，不继承旧成绩。

### GF-I02 目标查询式组分融合（TQCF）

**状态：** `MERGED_INTO_GF-I14 / NO_STANDALONE_RESULT`

**要修复的问题。** 一个全局融合向量可能迫使所有目标组分共享同一传感器权重，但 H₂、CH₄、CO₂ 或二甲苯异构体的可辨识线索可能不同。

**核心机制。** 为任务适配器声明的每个目标槽创建查询 token `u_k`，由查询对传感器 token 做交叉注意力：

\[
h_k = \operatorname{CrossAttention}(u_k, \{z_i\}_{i\in S}),
\qquad \hat y_k = g(h_k)
\]

`k` 不是硬编码气体名，而是任务输出槽。气体或异构体语义由任务适配器提供；融合核心只处理 `K` 个查询。

**文献锚点与迁移边界。** Set Transformer 的 pooling-by-attention 说明可用可学习种子从集合提取不同摘要。[R8] 把种子解释为可配置组分查询是本项目迁移假设，尚无直接气体定量证据。

**最小实验。** 不再单独实现；作为 TQIF 2×2 因子矩阵中的 `Q1-C1` 与 `TQIF-H0-I1` 比较，并与共享查询模型对齐参数量。

**必要消融。** 共享查询与独立查询、查询数 `K` 的配置性、注意力熵、不同组分的传感器归因稳定性。

**进入门槛。** A1 的逐组分单传感器结果已显示 He 与 CO₂ 依赖不同观测线索；该证据只允许目标查询进入 TQIF 消融，不预判其有效。

**杀停条件。** 查询注意力没有跨 seed 稳定性，或收益可由等参数量 MLP 解释；不得仅凭漂亮注意力图保留模型。

**阶段位置。** 已并入 `GF-I14`，不再作为独立候选或独立创新点计数。

### GF-I14 目标查询式传感器交互融合网络（TQIF-Net）

**状态：** `SCIENTIFIC_FAILURE / ABANDONED / NO_REUSE`

**要修复的问题。** 首轮实验表明，单纯 MLP、Deep Sets、输出投影、residual、ResNet 或 FT-Transformer 均不足以形成有创新性且稳定胜出的融合核心。它们主要学习一个共享全局表示，无法同时回答“某个目标组分应从哪些传感器取证”与“哪些传感器组合提供了单传感器之外的互补证据”。

**核心机制。** 每个传感器先编码为带 `sensor_id`、`sensor_type`、质量量和 mask 的 token。对每个有效无序传感器对构造共享低秩交互 token：

\[
r_{ij}=\phi_{pair}([z_i+z_j,\ |z_i-z_j|,\ z_i\odot z_j,\ e_{\{t_i,t_j\}}]),\quad i<j
\]

任务适配器只声明 `target_slot_id`。每个目标查询先对传感器 token 取局部证据，再对 pair token 取互补证据，并用目标特异门融合两者：

\[
l_k=\operatorname{Attn}(q_k,Z),\quad
p_k=\operatorname{Attn}(l_k,R),\quad
h_k=l_k+\sigma(g_k)\odot p_k
\]

门值只属于表示融合，不解释为可靠性或置信度。输出头统一支持 A2 的固定总量组成与 A3 的可变总量 ppm；融合核心不得出现气体名称分支，也不为固定传感器对建立独立子网络。

**设计完整度。** 正式候选同时定义输入接口、融合结构、输出约束、训练损失、复杂度预算、归因矩阵、跨数据集适配边界和停止规则。首轮只优化冻结的组分损失，不叠加熵、正交、对比学习、可靠性或物理辅助损失；额外机制只有在独立诊断成立后才能升版。

**最小实验。** A2 已完成 A2M-MLP、两档 matched C0 和两档完整 `TQIF-H0` 的五 seed 比较。两档 full 均未通过容量门，因此按预注册规则在进入 2×2 消融前停止；A2H 和 A2M 不执行。

**必要消融。** 原计划在容量门通过后运行“共享或目标查询 × 无 pair 或有 pair”的 2×2 因子矩阵；由于两档容量门均失败，本轮未触发该消融，不能对 query、pair 或任务头单独归因。

**进入门槛。** 本轮未通过：token16 相对 C0 退化 343.05%，token32 退化 77.99%，两档均为 0 / 5 seed 改善，且 token32 的 CO₂ 超限退化。两个配对置信区间均完全大于 0。

**失败分析。** 失败跨两档容量和全部五个 seed，且 full / C0 参数差低于 2%，因此不是参数量不公平或单一初始化造成。token16 的 seed 方差和最差值很高，token32 虽更稳定仍全面退化；两档 TQIF 的组成和误差也明显高于 C0。证据支持“低维三标量任务不需要 query 与 pair 带来的额外优化自由度，独立目标输出又削弱组成一致性”这一解释。由于 2×2 消融未触发，不能把责任唯一归给 query、pair 或任务头。

**放弃决定。** 不再扩大网络、延长训练、增加 seed、替换优化器、补跑 STR 或将局部组件改名为 TQIF-v2。实现和产物只作复现，任何新候选必须使用新算法 ID、独立问题定义和新预注册计划。

**阶段位置。** 机器终态为 `NEGATIVE_RESULT`、`allowed_next_phase=null`；项目决策为 `SCIENTIFIC_FAILURE / ABANDONED`。未新增 A2I，也不得进入 A2H、A2M 或 A3。详细结果见 [TQIF 失败归档](12_TQIF新算法设计与A2至A2M验证计划.md)。

### GF-I03 类型分层传感器融合（THSF）

**状态：** `IDEA_ONLY / NOT_IMPLEMENTED / NO_RESULT`

**要修复的问题。** 六个 MOF-QCM 通道虽有不同涂层亲和性，但共享测量原理、环境影响和潜在共模漂移；把它们当六个独立“模态”会高估独立证据量。

**核心机制。** 先在传感器类型内部聚合，再跨类型聚合：

\[
g_t = A_{\text{within}}(\{z_i:t_i=t\}),
\qquad h = A_{\text{across}}(\{g_t\})
\]

类型内 token 保留 `sensor_id` 或涂层身份。只有一个类型时，模型退化为阵列内部集合建模；多个物理类型时，再做跨类型融合。

**文献锚点与迁移边界。** 二甲苯源论文明确使用六个不同 MOF 涂层的 QCM 阵列识别三元异构体混合物，证明阵列内部差异有信息价值。[R3] 论文没有验证本分层网络结构。

**最小实验。** 在二甲苯工作簿组外拆分上比较平铺拼接、单层集合、类型分层集合；在多物理数据上再检查跨类型层是否有增益。

**必要消融。** 去掉涂层身份、打乱传感器身份、共享与独立类型编码器、类型内均值与注意力、显式共模分量去除。

**进入门槛。** 相关性和漂移诊断证明同类型通道存在显著共模结构，同时通道差分仍含目标信息。

**杀停条件。** 分层模型只降低训练误差，组外误差不改善；或把同类型通道压缩后丢失关键差异。

**阶段位置。** A3 二甲苯优先，也可作为 A2 多物理层次化扩展。

## 6. B 类：时间与物理表示

### GF-I04 物理锚定双视图编码器（PADVE）

**状态：** `IDEA_ONLY / NOT_IMPLEMENTED / NO_RESULT`

**要修复的问题。** 纯原始波形网络可能丢失绝对 TOF、相位、斜率、PSR、SNR 和标定量；纯 DSP 特征又可能漏掉可学习的局部波形形态。

**核心机制。** 对同一个传感器构建“部署可计算 DSP 视图”和“原始序列残差视图”，先在传感器内部融合成一个 token，避免把同源两视图伪装成独立模态：

\[
z_i = z_i^{\text{dsp}} + \alpha_i\,r_i^{\text{raw}},
\qquad \alpha_i \in [0,1]
\]

`z_i^{dsp}` 保留绝对量和质量量；原始分支只学习 DSP 基线未解释的残差。归一化必须保留绝对时标和幅值语义，不能对每条样本独立标准化后再声称学习了绝对 TOF。

**文献锚点与迁移边界。** 直接混合气体研究支持声学与热学测量的互补性，[R1–R2] 但未证明本双视图网络。该设计主要来自本项目 `L1` 级失败根因。

**最小实验。** DSP-only、raw-only、普通拼接、物理锚定残差四组；相同参数预算，正式 group split。

**必要消融。** 移除绝对 TOF、移除质量量、取消残差结构、把两视图错误当作两个传感器、样本级归一化与训练集全局归一化对照。

**进入门槛。** DSP-only 基线已强，且 raw-only 的残差与波形局部结构存在可重复关联。

**杀停条件。** 双视图不能在至少两个 seed 和全部关键子组上稳定优于 DSP-only，或 clean 性能收益依赖不可部署特征。

**阶段位置。** A2 条件主机制；一次只能与集合核心引入一个新自由度。

### GF-I05 非规则时间编码器（NCDE-lite）

**状态：** `IDEA_ONLY / NOT_IMPLEMENTED / NO_RESULT`

**要修复的问题。** 二甲苯工作簿存在非规则采样、缺测块和尖峰；固定网格插值可能把采样间隔和缺测机制抹平。

**核心机制。** 将时间戳、观测值和观测掩码构成连续控制路径，由轻量 Neural CDE 编码每个 QCM 通道或类型内序列。输出仍是传感器 token，不把 CDE 写入通用融合核心。

**文献锚点与迁移边界。** Neural CDE 面向部分观测、非规则采样的多变量时间序列，原论文覆盖通用基准而非气体阵列。[R13] 因此它是二甲苯专用编码器候选，不是通用默认。

**最小实验。** 手工统计、规则重采样加 1D CNN、GRU-D 类掩码基线、NCDE-lite；按完整工作簿拆分。

**必要消融。** 去掉时间间隔、去掉缺测掩码、不同插值方式、类型内共享动力学与逐通道动力学。

**进入门槛。** 缺测率、时间间隔和误差之间存在可重复关系，且规则重采样基线仍有结构化残差。

**杀停条件。** 计算代价明显增加但不优于重采样加轻量 CNN；或收益只来自泄漏了工作簿长度、顺序或文件身份。

**阶段位置。** A3；A1 前不得实现。

### GF-I06 训练组内自监督传感器预训练（TG-SSL）

**状态：** `IDEA_ONLY / NOT_IMPLEMENTED / NO_RESULT`

**要修复的问题。** 工作簿和混合物组数有限，监督训练可能不足以学习稳定动态模式。

**核心机制。** 只在当前 outer-fold 的训练工作簿或训练 `mixture_id` 内做层次时间对比学习，再把编码器用于监督任务。验证组和测试组不得出现在预训练、增强统计或负样本队列中。

**文献锚点与迁移边界。** TS2Vec 通过增强视图和层次对比学习获得多尺度时间表示，在通用分类、预测和异常检测基准上有效。[R14] 其默认增强不保证保持气体浓度、绝对幅值或响应动力学，因此必须逐项做物理语义审计。

**最小实验。** 从零训练、训练组内预训练、错误的全数据预训练只作为泄漏演示且不得进入正式结果；比较冻结编码器和微调。

**必要消融。** 裁剪、遮挡、幅值缩放、时间抖动逐项验证；凡会改变浓度语义或绝对物理量的增强不得进入正式协议。

**进入门槛。** 训练组标签规模确实限制监督模型，且无标签训练序列充分；A0 已冻结组边界传播方式。

**杀停条件。** 线性探针和正式监督任务均无稳定收益，或任何收益依赖跨组预训练或不符合物理语义的增强。

**阶段位置。** A1–A3 条件触发，不作为默认预处理。

## 7. C 类：基线、残差与输出契约

### GF-I07 分组 OOF 基线残差融合（OOF-BPR）

**状态：** `REPRESENTATIVE_TESTED / NOT_PROMOTED / A2_ROUND1_NEGATIVE`

**要修复的问题。** 小样本下，深网可能重复学习 Ridge、PLS 或树模型已经稳定解释的主趋势；直接把 in-sample 基线预测送入残差网会造成泄漏和虚假收益。

**核心机制。** 在 outer-train 内再按同一业务组键生成 out-of-fold 基线预测，残差网络只看到严格 OOF 预测：

\[
\hat u = u_{\text{base, OOF}} + r_\theta(z, u_{\text{base, OOF}})
\]

其中 `u` 是由 A0 冻结的对称组合坐标或输出头隐变量，不允许临时在浓度空间、比例空间和 log-ratio 空间之间切换。推理时基线在完整 outer-train 上重训，残差网络使用与训练契约一致的基线输出。

**文献锚点与迁移边界。** Stacked Generalization 奠定了用不同模型层级减少泛化误差的框架，DeepGBM 说明树模型与深模型的混合已有成熟先例。[R16–R17] 本项目历史复盘另有 `L1` 级 OOF residual 结构证据，但不构成当前数据结果。

**最小实验。** 单独 Ridge 或 PLS、单独 GBDT、单独 MLP、非 OOF 残差泄漏对照、严格 grouped-OOF 残差。

**必要消融。** 不同基线、残差输入是否含原始 token、残差幅度分布、按组分和浓度区间的残差相关性。

**进入门槛。** A1 证明基线强且剩余误差在训练组内可预测；内层 OOF 使用与 outer split 同语义的组键。

**杀停条件。** 残差在 OOF 上接近不可预测，或增益只存在于非 OOF 训练；此时返回基线，不增加 ErrorNet 或二级门控。

**阶段位置。** A2 首轮代表实现未晋级，保持历史负结果，不进入 TQIF 首轮实现。

### GF-I08 对称总量–比例输出头（STR-Head）

**状态：** `REPRESENTATIVE_TESTED / NOT_PROMOTED / CONTRACT_REUSED`

**要修复的问题。** 多组分输出既有非负和总量约束，又可能要求组分排列语义对称；直接逐维回归容易出现负值、总量漂移和固定气体顺序耦合。

**核心机制。** 对 `K` 个任务槽输出 logits `a`：

\[
p = \operatorname{softmax}(a)
\]

固定总量任务使用 `\hat y = T_{fixed}p`；可变总量任务使用 `\hat T=\operatorname{softplus}(t)` 和 `\hat y=\hat T p`。`K`、总量类型、零组分语义和组分标签由任务适配器声明。若需要集合式输出匹配，匹配规则必须在 A0 冻结，不能在评估阶段临时排序以改善指标。

**文献锚点与迁移边界。** 这是由本项目输出不变量推导的工程研究假设，不把 softmax 或组合数据变换包装为算法创新。

**最小实验。** 独立非负回归头、归一化后处理、STR-Head；分别报告逐组分误差、总量误差和约束违反率。

**必要消融。** 固定总量与可变总量、共享与分离总量头、零组分样本、不同组分排列、是否需要显式匹配。

**进入门槛。** A0 已冻结任务 head schema、标签身份、总量语义、零值策略和评估口径。

**杀停条件。** 约束头降低物理违规但显著恶化关键组别误差，且无法通过正确任务语义解释；不得用后处理隐藏错误。

**阶段位置。** A2 首轮 H1/H2 未独立晋级；固定或可变总量接口继续作为任务头契约复用，收益必须与 TQIF 融合表示分开归因。

### GF-I09 物理性质一致性辅助头（PCAH）

**状态：** `IDEA_ONLY / NOT_IMPLEMENTED / NO_RESULT`

**要修复的问题。** 纯监督浓度损失可能产生数值接近标签、但与声速、热导率、密度或热值不一致的预测；在组外天然气来源变化时尤其危险。

**核心机制。** 模型预测组成后，通过经验证的可微物理模型或训练组内冻结的物理代理，回算可观测性质并施加辅助残差：

\[
\mathcal L = \mathcal L_{target} + \lambda
\sum_{j\in O} w_j\,\ell\big(g_j(\hat y,T,P), s_j\big)
\]

`O` 只包含该样本真实可用的物理观测。`g_j` 必须标明适用压力、温度和组分范围；未经验证的理想气体假设不能成为隐藏真值。

**文献锚点与迁移边界。** 掺氢天然气理论研究显示热导率与声速或密度组合对氢浓度和热值有辨识潜力，[R2] 直接传感器融合研究也使用超声、热导率和环境补偿。[R1] 这些工作不证明物理辅助损失一定改善深度学习。

**最小实验。** 无物理辅助、固定 `λ` 辅助、只把物理量作为输入、错误物理模型负对照；按天然气来源或组成组外评估。

**必要消融。** 每个物理残差单独启用、真实模型与代理模型、不同适用域、是否只用于训练还是同时做推理一致性检查。

**进入门槛。** 已有可追溯、适用域明确且误差小于目标辨识尺度的物理模型；传感器量纲和校准版本冻结。

**杀停条件。** 物理模型误差与标签误差同量级，或辅助项只把模型拉向错误近似；此时保留输入特征，不保留损失约束。

**阶段位置。** A2–A3 条件机制，不能在物理模型未核验前实现。

## 8. D 类：缺失、质量与可靠性

### GF-I10 未见组合子集一致性（UCSC）

**状态：** `IDEA_ONLY / NOT_IMPLEMENTED / NO_RESULT`

**要修复的问题。** 常规 modality dropout 只覆盖训练时抽到的缺失模式，无法保证测试时未见传感器组合；无条件逼迫子集预测复制全模态预测，又可能在信息确实不足时制造过度自信。

**核心机制。** 使用共享 token 空间和集合聚合处理任意可用集合；训练时枚举或采样由 A4 协议定义的物理可行子集。只对“有足够可辨识信息”的子集施加可靠性加权一致性：

\[
\mathcal L_{subset}=r(S')\,
d\big(f(S'),\operatorname{stopgrad}(f(S))\big),
\qquad S'\subset S
\]

若子集缺失了关键可辨识物理量，则目标不是强行一致，而是扩大区间或输出 `degraded/abstain`。

**文献锚点与迁移边界。** Unseen Modality Interaction 通过公共空间、可用模态求和和可靠性伪监督处理训练未见的模态组合，并包含机器人状态回归实验。[R9] 其数据模态和损失与气体定量不同；本 Idea 不承诺直接复现其收益。

**最小实验。** 随机独立 dropout、按传感器类型 dropout、留一传感器、留一类型、训练未见组合；完整输入与缺失输入分开报告。

**必要消融。** 无一致性、无可靠性权重、所有子集强一致、公共空间求和与普通 mask 拼接、组合内见过与未见过。

**进入门槛。** A4 已定义有效、退化和不可辨识子集，且届时冻结核心的可变集合接口已通过契约测试。

**杀停条件。** 缺失鲁棒收益以显著 clean-cost 为代价，或未见组合不优于简单重训或 mask 基线；不得继续叠加更重 MoE 掩盖问题。

**阶段位置。** A4 第一优先缺失机制。

### GF-I11 梯度解耦传感器学习（GDSL）

**状态：** `IDEA_ONLY / NOT_IMPLEMENTED / NO_RESULT`

**要修复的问题。** 强传感器可能主导共享编码器更新，使弱传感器在缺失强模态时不可用；但若没有梯度冲突证据，直接做复杂解耦会成为无依据保护逻辑。

**核心机制。** 先记录各传感器或类型损失对共享参数的梯度方向和范数。只有稳定出现负余弦冲突或单一模态范数长期压倒其他模态时，才投影冲突梯度，并按可用性开关共享参数。

**文献锚点与迁移边界。** GMD 在医学分割和情感分析上把模态支配与缺失模态退化联系起来，并用梯度冲突消除和动态共享处理。[R15] 尚无气体定量证据。

**最小实验。** 先做只读梯度诊断；若触发，再比较普通多任务训练、损失重加权、梯度裁剪和 GDSL。

**必要消融。** 只做范数平衡、只做冲突投影、按单传感器与按类型分组、clean 与 missing 性能。

**进入门槛。** 至少多个 seed 和训练阶段稳定观察到同一模态支配模式，并与缺失性能相关。

**杀停条件。** 梯度冲突不稳定、与缺失误差不相关，或简单损失尺度校正已解决问题。

**阶段位置。** A4 条件触发；不能作为默认优化器逻辑。

### GF-I12 校准质量信息融合（CQIF）

**状态：** `IDEA_ONLY / NOT_IMPLEMENTED / NO_RESULT`

**要修复的问题。** SNR、PSR、残差或 ErrorNet 分数不天然等于预测精度；对相关的 QCM 通道独立做精度加权还会重复计算证据并产生过窄区间。

**核心机制。** 每个传感器或传感器类型产生局部预测和尺度参数，在类型内先处理相关性，再跨类型融合。质量量只作为可解释输入，不直接被当作真实精度。最终尺度在独立 calibration 组上校准：

\[
\hat y = \left(\sum_t \Lambda_t\right)^{-1}
\sum_t \Lambda_t\hat y_t
\]

这里的 `Λ_t` 是经约束和校准的类型级精度，而不是每个相关通道的任意门控权重。若局部预测冲突，输出显式 `conflict_score`，而不是静默压低某个传感器。

**文献锚点与迁移边界。** 可微滤波工作说明把不确定性和结构化融合结合是可行方向，[R22] Deep Evidential Regression 提供单次前向的不确定性参数化。[R18] 但后续研究指出 DER 更接近启发式而非精确不确定性量化，[R19] 因此本文不把证据分数当作免校准置信度。

**最小实验。** 均匀融合、质量特征拼接、未校准精度加权、校准类型级融合；完整输入和预定义故障分别测试。

**必要消融。** 通道级与类型级精度、去掉质量量、去掉 calibration、相关性修正、冲突输出。

**进入门槛。** A4 有独立 calibration 组，质量量与误差关系在训练组上可重复，且定义了相关传感器分组。

**杀停条件。** 校准后质量权重与误差仍无正相关，或 clean-cost 明显；返回均匀或集合聚合，不启用硬抑制。

**阶段位置。** A4，在 `GF-I10` 之后。

### GF-I13 单调风险与显式拒判（MREA）

**状态：** `IDEA_ONLY / NOT_IMPLEMENTED / NO_RESULT`

**要修复的问题。** 点预测正常不代表系统可靠；移除一个有效传感器后区间可能反而变窄。即使总体选择性风险下降，纯组分、二元、三元、低浓度或故障子组也可能变差。

**核心机制。** 模型输出四部分：

1. 点预测；
2. 经独立 calibration 组共形化的预测区间；
3. `valid / degraded / abstain` 状态；
4. `conflict_score` 和可用传感器集合。

把多模态校准中的原则迁移到回归：从完整且有效的传感器集合移除一个已知有信息的传感器时，校准风险不得降低、区间不得系统性变窄。该约束不用于“移除一个已损坏传感器”的比较，因为去掉坏数据本来可能改善预测。

采用 Conformalized Quantile Regression 生成异方差自适应区间，但只宣称在协议要求的交换性条件下具有有限样本边际覆盖；不声称对任意 OOD 或每个气体子组自动覆盖。[R20]

**文献锚点与迁移边界。** CML 在分类中发现模态被移除或破坏后置信度可能升高，并提出置信度不应随有效模态移除而增加的原则。[R12] 选择性回归研究进一步证明，降低总体 coverage 可能让某些子组更差。[R21] 把两者迁移到多组分气体回归是待验证 Idea。

**最小实验。** 点预测、未校准分位数、CQR、CQR 加状态头；绘制总体与子组 risk–coverage 曲线。

**必要消融。** 去掉单调约束、去掉子组审计、按样本随机 calibration 与按组 calibration、完整、缺失和故障三类输入。

**进入门槛。** A4 已冻结 calibration 组、coverage 目标、拒判代价、关键业务子组和状态契约。

**杀停条件。** 区间在正式 split 上持续欠覆盖，或拒判只改善总体指标却恶化任何冻结关键子组；不得只调阈值隐藏失败。

**阶段位置。** A4 收口机制，依赖前面的点预测和质量协议稳定。

## 9. 不建议当前实现的方向

### 9.1 大型 fleximodal MoE 或稀疏 Transformer

FuseMoE 和 MAESTRO 等方法为任意模态数、缺失模态和非规则动态提供了丰富结构，[R10–R11] 但其容量、训练复杂度和原任务与当前 A0 的数据规模及气体定量契约不匹配。它们暂列 `P1` 级灵感；只有轻量集合基线证明存在稳定容量瓶颈时再复核。

### 9.2 通用端到端波形模型

若模型没有显式保留绝对 TOF、相位、斜率、PSR、SNR 和标定信息，不能再次以“减少特征工程”为理由进入。它应继续作为负对照，而不是主线。

### 9.3 默认 ErrorNet、硬抑制和隐式降级

历史复盘未建立稳定误差相关性，且此类门控可能伤害 clean 输入。没有独立 calibration、相关性证据和显式状态输出时，不得启用。

### 9.4 生成式补全缺失传感器

补全信号可能看似逼真却不保持组分可辨识性，并掩盖真正的不可辨识子集。A4 应优先使用集合缺失建模、区间扩大和拒判；生成式补全只可作为独立研究，不进入当前首轮。

### 9.5 只有随机 dropout 的“鲁棒训练”

随机独立 dropout 未覆盖传感器类型整体失效、相关通道共模漂移、未见组合和物理不可辨识场景。它只适合作为最低基线。

## 10. 建议的阶段化研究队列

### 10.1 A0：只冻结契约

- 冻结 sensor token schema、质量字段、可用性语义和类型注册方式；
- 冻结 `GF-I08` 所需的输出槽、总量、零组分和排列规则；
- 冻结 group split 与 scaler fit scope；
- 不训练本文件中的任何新模型。

### 10.2 A1：形成可解释的进入证据

- 建立 Ridge、PLS、GBDT、固定向量 MLP 和轻量时间基线；
- 输出逐组分、逐浓度区间、逐混合物阶数和逐工作簿残差；
- 诊断同类型相关性、模态支配、缺测机制和质量量–误差关系；
- 只有诊断信号存在，才激活对应条件 Idea。

### 10.3 A2 至 A2M：TQIF 单候选证据链（已失败关闭）

- `GF-I01` 简单集合路线和 `GF-I07` residual 路线保持首轮历史结论，不重新命名或并入 TQIF 成绩；
- `GF-I14 TQIF-Net` 已完成 A2 实现、契约测试、基线与容量筛选；
- 两档完整 TQIF 均未通过容量门，项目已登记 `SCIENTIFIC_FAILURE / ABANDONED`；
- 未新建 A2I，也未并行引入其他辅助机制；A2H 与 A2M 取消，TQIF 不再是候选。

### 10.4 A3：冻结算法的泛用性验证

- A3 的前提是仿真链产生正结果并冻结创新算法；TQIF 已失败放弃，A3 当前阻塞；
- 统计编码器、TCN、GRU、轻量时序 Transformer 或条件 Neural CDE 只作为传感器编码器候选；未来同一编码器必须比较 concat 与届时冻结的新融合算法；
- `GF-I03`、`GF-I05` 和 `GF-I06` 只有出现类型共模、不规则采样或小样本瓶颈的独立诊断后才允许进入，不得借 A3 数据反向发明融合核心；
- A3 保持暂停，不以 xylene 数据反向选择新算法。

### 10.5 A4：可靠性收口顺序

1. `GF-I10` 未见组合子集一致性；
2. 若有梯度支配证据，再测试 `GF-I11`；
3. 有独立 calibration 后测试 `GF-I12`；
4. 最后用 `GF-I13` 输出区间、状态和分组 risk–coverage。

## 11. 所有 Idea 共用的验收矩阵

### 11.1 必报指标

- 整体与逐组分 MAE、RMSE；
- 固定业务阈值下的合格率；
- 纯组分、二元、三元和低浓度子组；
- 完整、缺失、退化和冲突输入；
- 多 seed 中位数、离散度和最坏 seed；
- 参数量、推理时延和可部署特征依赖；
- 若输出区间：coverage、平均区间宽度、组别 coverage；
- 若允许拒判：总体及各关键子组 risk–coverage 曲线。

### 11.2 共用否决项

出现任一项即不得宣称算法有效：

- split、scaler、预训练或增强统计跨越正式组边界；
- 使用 `sequence_id` 替代 `mixture_id`；
- benchmark 依赖被禁止的历史字段；
- 只报告随机样本拆分或单 seed 最好值；
- 以 test set 选择模型、阈值、温度参数或 calibration；
- 只有总体指标改善，关键冻结子组恶化；
- 依赖不可部署特征或未说明的理想化物理量；
- 用吞错、默认权重、静默补全或隐式硬抑制掩盖失败。

## 12. 反向审稿与尚未解决的问题

### 12.1 “通用”是否只是接口通用

传感器 token 接口可以支持不同传感器数，但不意味着训练好的模型能零样本接收新物理传感器。新增传感器类型仍需要适配器、标定数据和域验证。本文只主张架构契约通用，不主张跨物理域零样本泛化。

### 12.2 置换不变是否会抹掉身份

置换不变要求输入顺序不影响输出，不等于删除传感器身份。若 token 不含 `sensor_id`、涂层或类型，QCM 通道的物理差异会被错误对称化。因此 `GF-I01` 和 `GF-I03` 必须同时满足“顺序不变、身份保留”。

### 12.3 一致性是否会制造过度自信

当子集不可辨识时，强制它复制全模态预测会把知识蒸馏变成伪标签污染。`GF-I10` 必须先定义可辨识子集，并让不可辨识子集扩大区间或拒判。

### 12.4 共形区间是否覆盖 OOD

CQR 的有限样本保证依赖交换性等条件，不能自动覆盖新的天然气来源、传感器故障或强分布漂移。A4 应把边际 coverage、冻结子组 coverage 和 OOD 状态识别分开报告。

### 12.5 注意力或门控权重是否可解释

注意力权重和精度权重不天然等于物理贡献。只有在传感器移除、反事实扰动、重复 seed 和校准误差上稳定，才可作为辅助解释；不得据此单独做机理结论。

### 12.6 Idea 的新颖性是否足够

本文完成的是机制适配检索，不是面向专利或论文投稿的穷尽式 novelty search。Deep Sets、Set Transformer、OOF stacking、Neural CDE、CQR 等核心部件均已有明确先例。未来若选定投稿主线，必须再对所选组合、任务设定、损失和评估协议做专项相似工作检索。

## 13. 结论

本登记册当前没有活跃候选。下一步不是从 P1 条目中直接挑一个训练，而是先基于强 MLP 接近任务上限、三标量缺少额外交互信息、组成一致性需要显式保持三个事实重新定义问题：

- `GF-I14 TQIF-Net` 已判定 `SCIENTIFIC_FAILURE / ABANDONED`，不得重开、改名或局部修补；
- `GF-I01` 与 `GF-I07` 保留未晋级结论，MLP 只作为强对照，不再承担创新算法角色；
- 新候选必须采用新的算法 ID、问题定义、机制假设、强基线余量审计和独立预注册计划；
- `GF-I03`、`GF-I05` 和 `GF-I06` 服务于二甲苯及小样本时间序列，不得在 A3 反向改造融合核心；
- `GF-I10–GF-I13` 构成从缺失组合到校准拒判的 A4 链条，但每一步都有独立进入条件；
- 大型 MoE、通用 Transformer、生成式补全和硬抑制目前缺乏足够进入证据，应继续停放。

这 14 个 Idea 的共同验收标准不是“网络更复杂”，而是：在严格组外协议下修复一个已诊断根因，并形成问题定义、完整结构、训练契约、归因对照、跨数据集边界和明确杀停条件。仅替换层数、宽度、激活函数或优化器，追加 post-hoc gate/ErrorNet，或把已有模型改名，均不登记为新算法。
