# 算法文献结合仿真与实施证据的再评估

> 日期：2026-09-05。读取范围：算法 idea 目录的总报告及八份论文整理、上一轮仿真资料分析、当前代码和保存产物。
> 本文为研究判断，不是执行计划或候选注册；不改变冻结门、阶段依赖及已关闭算法结论。

## 1. 重新判断

这批算法资料增强了“可靠性、缺失与适应值得研究”的依据，但没有推翻上一轮“先证明数据包含可利用信息，再选融合机制”的判断。需要修正的是第一轮调研中的优先级：**不能因论文用了图、注意力或 TCN，就将其作为当前项目默认骨干；也不能把若干已有模块的组合直接认定为算法创新。**

建议重点评估的研究问题是：**在物理选择性不同、测量质量变化的传感器之间，如何保留互补信息，并对当前观测能支持的组成预测给出可信风险估计。** MoNIG 提供回归对照，QMF 提供权重与误差关联的检验思路，M3AE 提供缺失训练参考；它们都不能直接充当已验证的新主线。

具体取舍：

- **提高阅读与对照优先级：** MoNIG、QMF，以及已有登记册中的校准、子集可辨识性约束。
- **条件保留：** M3AE 的缺失训练思想、DMAW 的可靠性学习、GraphANet 的时序图表示。
- **作为输出契约：** KKT-hPINN 启发的约束处理；单独加 softmax 不构成新的融合算法。
- **推迟到数据条件具备：** TikUDA 的无标签目标域适应、MDFE-Net 的少样本适应；二者解决不同的数据访问问题。
- **继续关闭：** 已失败的 TQIF 原候选。新论文不能作为重开或局部改名的理由。

## 4. 会实质改变方案的七个判断

### 4.1 物理选择性、测量质量和预测不确定性必须分开

在当前 [NDIR 实现](../../src/gf/sim/a2_sensor_devices.py) 的 `simulate_ndir` 中，光谱链读取 CO₂、温度和压力；在相同局部 CO₂ 轨迹、温压、设备参数下，改变 Ar 与 He 的比例不会改变其干净响应。

例如固定 CO₂ 为 20%，配方 `[Ar,He,CO₂]=[70,10,20]` 与 `[10,70,20]` 在匹配的进气、输运和环境下，NDIR 的干净轨迹相同。这是根据当前前向模型得到的反例，不是新运行的实测结果。

由此可见：

- 干净 NDIR 单独预测 Ar、He 可能误差很大，但这不表示 NDIR 损坏。
- NDIR 对 CO₂ 的信息可能帮助超声与热导解除混合组成歧义；单模态全向量误差大不等于联合贡献小。
- “强模态主导”可能是合理物理选择性，也可能是训练问题；必须先诊断，不能默认做梯度平衡。

因此，QMF 中“权重与单模态损失关联”的目标值得测试，但不能把所有传感器都当成可独立给出同等完整答案的专家。更适合本问题的检验量是：加入或移除某模态后，特定组分或组成方向的预测风险如何变化。

### 4.2 QMF 与 MoNIG 是参考机制，尚不是本项目的可信度保证

QMF 原文将有效不确定性估计作为假设，并在决策级分类融合中实现能量分数与训练历史损失排序约束。把它改成回归 NLL、组件权重或任意 softmax 门控后，不能继续直接声称继承原证明。训练历史损失也不同于气体信号的时间历史，推理阶段不能读取目标标签。[QMF 方法 §4](https://proceedings.mlr.press/v202/zhang23ar/zhang23ar.pdf)

MoNIG 直接针对回归，包含单模态 NIG、融合分布和由联合特征形成的 pseudo modality，因此更适合列入概率回归对照。保留联合分支尤其值得关注，因为互补信息不一定能压缩为几个单模态点预测。[MoNIG §4](https://papers.nips.cc/paper/2021/file/371bce7dc83817b7893bcdeed13799b5-Paper.pdf)

但 NIG 参数的 AU / EU 分解不能自动识别物理噪声、训练覆盖不足和不可辨识性。已有理论分析将标准 DER 视为带有数学局限的启发式估计；该工作已发表于 AAAI 2023，旧登记册只标为 2022 预印本的题录已不完整。[Meinert et al.](https://arxiv.org/abs/2205.10060)

本项目应检验总预测风险、区间覆盖、区间宽度和误差排序。单模态分支与 pseudo modality 来自同一组测量，不是独立新增证据；相关通道、共享噪声下尤其不能把精度累加解释成独立贝叶斯证据的自动保证。

### 4.3 组件级权重和闭合概率输出存在结构性冲突

这是本次对笔记迁移公式的代数检查。假设两个单模态预测都合法：`p₁=(0.8,0.1,0.1)`、`p₂=(0.1,0.8,0.1)`。若分别为各组分选择看起来更可靠的预测，得到 `(0.8,0.8,0.1)`，总和为 1.7。

因此，“每个组分分别归一化模态权重”并不能保证最终组成闭合。随后再次归一化或投影又会改变各分量误差、均值和不确定性。

MoNIG 笔记中“一个 softmax 均值头，加一个独立 NIG 头”的方案也需要修正：若 NIG 的位置参数不是实际交付的组成均值，NLL 和区间就没有评价最终预测；即使均值相同，独立 Student-t 分布仍不是定义在 simplex 上的联合组成分布。

可行研究需统一点预测和概率对象。固定总量为 1 的随机组成满足 `Cov(Y)·1=0`；非退化的不确定性不能只用彼此独立的三维方差完整描述。可以研究自由组成坐标及其映射，或明确的受约束联合分布，但需处理边界零值，不能把坐标变换本身包装为新算法。

### 4.4 M3AE 的一致性不能要求学生恢复不存在的信息

M3AE 针对缺失 MRI 的表征学习与分割，其任务与气体反演不同。[M3AE](https://ojs.aaai.org/index.php/AAAI/article/view/25253)

对传感器子集 S，平方误差下最优预测及其不可约风险为：

$$
f_S^*(X_S)=\mathbb E[Y\mid X_S],\qquad
\inf_f\mathbb E\|Y-f(X_S)\|^2
=\mathbb E\,\mathrm{tr}\,\mathrm{Cov}(Y\mid X_S).
$$

如果某子集不能区分不同配方，即使全模态教师准确，学生也不能在每个样本上复制教师。强行要求逐样本一致会产生平均化、伪标签误导或压制完整观测的独有信息。仍可训练条件均值或条件分布，但不能把它宣称为恢复了原本不可辨识的浓度。

缺失实验应先划分可用、退化与不可辨识子集；按组分报告可保留的能力，并评价区间或拒判。三路已知传感器的七种非空子集，与接受训练从未出现的新物理传感器，是两种不同主张。零信号也不能兼任缺失标志。

总报告 Idea 5 的“质量趋于零就自然等于缺失”只能作为带显式可用性标志的建模约定：有偏但可校准的测量仍可能含信息，缺失则没有观测，不能仅靠一个连续分数混同。

### 4.5 GraphANet 的“异构”被总报告扩大解释了

作者原文把**时间点作为节点，多传感器读数作为节点特征**。不同阵列改变节点特征宽度，并采用相同超参数在不同数据集上验证。它支持时间图表示和跨数据集架构适配，不能直接支持传感器节点图、任意缺失输入或同一权重零样本迁移。[原文 §III–IV](https://arxiv.org/html/2412.13891v1)

本地详细笔记已经指出时间节点，但总报告仍把它排在“解决异构传感体系”的第一位，这一推荐理由需要收窄。节点特征联合输入仍可学习跨通道映射，不能反过来说原模型完全无法学习传感器关系。

当前可以将它视为后续符合信息条件时的时序对照；没有依据宣称图必然优于 concat，也不能为创造图网络优势而人为注入无来源交互项。原论文是载气中的 ppm 目标气体，预测目标不一定穷尽混合组成；缺少总和 100% 约束不能一概视作原论文缺陷。

### 4.6 TikUDA 和 MDFE-Net 对应两份不同的实验契约

TikUDA 利用无标签目标域输入对齐回归表示；其正则化逆 Gram 结构有明确回归动机，但不是零目标域访问的泛化。[TikUDA §III](https://arxiv.org/html/2411.06917v2)

必须区分硬件响应变化和真实浓度分布变化。例如源、目标设备均满足 `x=y`，但目标气体浓度范围扩大，则特征尺度变大可能完全正确。强行对齐尺度可能抹掉浓度差异。仅有 PCA 重叠或域距离下降，不能证明目标浓度预测更好；增益变化与浓度变化在无标签情形下还可能混淆。

MDFE-Net 笔记中的 MAML 使用有标签 support set 适应，再由分离的 query set 评价。普通 fine-tuning 同样可以使用少量样本，因此不能以“微调必然需要大量标签”为前提证明 MAML 优势。应在相同标定样本、预训练数据、更新预算下比较。

当前单套参考硬件与标定 profile 不等于多台独立设备，xylene 也不是 Ar-He-CO₂ 的无标签同任务目标设备。跨设备路线的关键资源是多设备或多批次标定及独立盲测，而不是多加入一个损失函数。没有这些数据时，TikUDA 与 MAML 都只能停留在候选研究设定。

### 4.7 硬约束和物理辅助损失需要匹配实际预测目标

KKT 等式投影约束的是线性等式；例如向量 `(1.2,-0.1,-0.1)` 已经总和为 1，等式投影不会消除负值。simplex 投影另外包含非负约束。当前 [task_heads.py](../../src/gf/dl/task_heads.py) 已有独立回归、simplex projection、fixed-total softmax 等，不能将它们重新作为未实现创新提出。

当前动态标签是最终目标配方，前缀观测对应进气、气室与局部器件状态。直接把最终配方代入平衡前向模型，并强迫它匹配尚未到达稳态的电压或 ToF，会施加错误约束。必须明确状态传播及部署可获得的环境输入；真实温压、tau、clean signal 等 oracle 数据不能悄悄进入普通模型。

辅助预测已作为输入的 ToF 若仅形成重构捷径，也不自动带来物理信息。物理约束必须作用于有意义的共享状态或最终预测，并与普通重构对照。物理专属算子应由适配器或明确的辅助任务提供，保持融合核心可复用。

已有 [Idea 登记册](未实现算法Idea集合_文献调研版.md) 的 GF-I10 已要求不可辨识子集扩大区间或拒判，GF-I11 要求先诊断梯度问题，GF-I12 已讨论质量校准与相关证据，GF-I13 对应区间和选择性输出。**所以“QMF + MoNIG + dropout + 物理头”既与外部方法重叠，也与内部研究卡重叠。** 本次不分配新算法 ID。

当前最有价值的增量是把“可靠性”具体化为测量退化与组成方向信息的区别，并统一最终均值、协方差或区间的语义。它有研究价值，但尚未形成足以注册的独立算法。若最终只是冻结 MLP 后再接一个 ErrorNet 或换权重函数，仍不满足现有登记规则。

## 6. 可证伪的最小验证路径

以下是未来协议的建议，不启动运行，也不放宽现有门槛。

1. **先确认问题存在。** 在开发分组上分别固定配方改变测量退化、固定退化改变配方；评估各传感器子集的局部歧义和联合贡献。短前缀中必须保留未知输运状态的影响，不能以已知 oracle 参数的上限代替可学习余量。
2. **让质量真正对应观测误差。** 分开标定偏置、随机测量噪声、失锁、饱和和缺失；保留共享噪声的相关性。质量输入必须在推理时可计算，不能直接使用合成噪声真值或目标误差。已有数据冻结失败要按原因处理，不能只改阈值。
3. **同预算比较一个主要机制。** 保留当前强 concat、LAST / EWMA / STAT 等对应协议基线；未来可靠性协议至少区分固定融合、普通 Gaussian 回归、MoNIG 及拟议机制。所有方法使用相同输入、增强、输出约束、标签预算和分组；不能只给新模型训练退化样本。
4. **用归因对照排除伪收益。** 固定权重、打乱质量、去掉质量输入、仅增强、强制所有子集一致，以及忽略相关性的概率融合分别检验目标机制。传感器干预应成对控制配方与其他条件，而不是仅比较整体注意力图。
5. **评价点预测与可信度。** 按组分、缺失子集、退化类型和短前缀报告误差；在相同保留率下比较 risk，在相同目标覆盖下比较区间宽度，并审计零组分、闭合与联合覆盖。不能通过全部拒判或无限宽区间获得表面可靠性。

开发误差学习只能使用训练组内 OOF 等严格隔离的数据；校准、选择与最终测试分开。若后续采用共形方法，交换性条件及 OOD 局限仍需说明，不能自动保证任意故障分布下覆盖。

明确停止条件：质量信号与真实误差或干预贡献无稳定关系；仅增强已解释全部收益；优势依赖 oracle 信息；不可辨识子集仍过度自信；或者 clean 成本超过届时预注册容忍范围。现有 A4 评价文档给出的 `macro_RNMAE` clean 绝对增加上限为 0.005，不能通过重新命名指标绕过。[现有评价协议](02_评价协议与基线矩阵.md)

## 7. 可行性评议与阶段取舍

**致命问题审查只保留两项。**

- **CRITICAL，拒绝原版本：** 在相同三标量任务上重开 TQIF，或将其局部改名。已有 matched 负结果和放弃决定直接否定这条执行路线，不再通过评分将其包装为可继续。
- **HIGH，收窄后再评估：** 一次性主张时序增益、可靠融合、任意缺失和跨设备快速适应。当前数据与实验契约不能同时验证这些主张，且组合机制难以归因。

仅对收窄后的“区分测量退化与组成信息的可信联合回归”给出设计阶段评分，5 分为中性起点，分数不是性能预测：

| 维度           | 暂评分  | 依据                             |
| ------------ | ----:| ------------------------------ |
| Higher：精度    | 5/10 | 有互补保留的机制动机，但没有新候选超过强基线的结果      |
| Faster：速度    | 4/10 | 增加概率或风险建模可能增加开销，暂无端到端延迟证据      |
| Stronger：稳健性 | 7/10 | 针对错误降权、缺失歧义、过度置信提出可检验机制；这是潜力评分 |
| Cheaper：成本   | 5/10 | 或可减少错误决策，尚未证明降低算力或标定成本         |
| Broader：适用范围 | 6/10 | 可保留共享核心和可配置任务头，但外部体系尚未验证       |

总体判断为 **有条件继续论证，尚未达到新算法实施入口**。最强价值在稳健性，不是已知的 clean 精度或效率优势。范式检视为 3/8：挑战“单模态应独立预测完整组成”这一隐含前提有价值，但不依赖新技术突破，也没有证据表明会改变整个领域的研究范式，应按具体方法问题表述。

资源匹配方面，当前工程已有分组、前向模型和基线审计基础，适合开展问题诊断；多设备标定与实测质量校准的资源尚未在本次材料中确认。用户工时、算力预算和数学研究投入未知，不据此虚构完成周期或投稿保证。

按现行 [总体规划](../../项目总体规划.md)，当前仍先处理 A2-DYN 数据资格与信息余量；A3 在仿真候选通过后验证同一核心的架构复用；缺失和可靠性进入 A4；真实小样本应用验证归 A5。如果要把可靠性改为当前主创新，应正式调整研究问题和阶段依赖，不能一边沿用“完整 clean 精度优先”的门槛，一边用缺失收益代替晋级。本文只指出这一取舍，不修改计划。
