## 0. 文档职责与 A2 研究问题

本文件只负责把总体规划中的 A2 拆成可编码、可验证、可杀停的实施步骤，不维护阶段状态、正式结果或跨阶段时间表。A2 是否开始、通过或失败，仍以《项目总体规划》和后续 A2 评审记录为准。

A2 冻结回答三个问题：

1. 在 A1 formal v1 的固定三传感器完整输入上，带身份与类型的传感器 token 集合核心能否稳定超过最佳强基线？
2. 收益来自输出闭合、传感器编码还是集合聚合中的哪一个因素？
3. 若集合核心未过门，严格 grouped OOF 的基线残差是否仍包含可预测结构，足以支持一个低容量备选？

核心判断：**A2 首轮主机制固定为轻量 Deep Sets 式传感器 token 聚合；输出头先独立审计，OOF residual 只作条件备选。Set Transformer、物理辅助损失、质量门控和大型混合模型不进入首轮实现。**

## 1. A1 起点与对 A2 的约束

### 1.1 已冻结事实

| 事实     | A1 证据                                                                                                      | 对 A2 的约束                                         |
| ------ | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 数据版本   | `gf-a1-v1-20260827-r1`；content SHA256 为 `310f9471f99c704fdeb68b846c5d8b351d701bbd7f6cef172a08ceccc77110c4` | 不修改配方、split、物理参数或观测文件；A2 配置必须引用该 hash            |
| 独立单位   | 1200 个唯一 `mixture_id`；840 / 180 / 180 的 train、val、test                                                     | 所有训练、OOF、bootstrap 和逐组输出继续以 `mixture_id` 为单位     |
| 样本形态   | 三个传感器，每个传感器 `T=1`、`F=1`；`quality=1`，无缺失                                                                    | 不声称时序、质量感知、缺失鲁棒或动态可靠性；A2 中质量权重与 masked mean 数学等价 |
| 组成空间   | 300 个二元边界样本、900 个三元内部样本；纯气只用于端点审计，不进入 train、val、test                                                       | 正式分层只写二元、三元和浓度区间；不得生成不存在的纯气成绩                    |
| 可辨识性   | 内部 Jacobian 满秩；超声与热导近共线，NDIR 提供独立 CO₂ 轴                                                                    | 集合模型有多物理互补输入，但不能把模型权重解释为物理贡献                     |
| 最佳强基线  | B5 固定拼接 MLP 五 seed：val `0.00581589 ± 0.00103384`，test `0.00647441 ± 0.00120615`                            | A2 主门比较五个独立 seed 的配对结果，不能只与 B4 GBDT 比较           |
| B5 集成  | 五 seed 预测均值：val `0.00437865`，test `0.00495217`                                                             | 作为次级部署对照；不能替代“五个独立 seed 的平均性能”进入主统计门             |
| 当前共享核心 | `FusionCore` 是 A0 smoke 骨架，当前未在 formal A1 上训练                                                              | A0 smoke 通过不等于 A2 模型已实现或集合机制已获益                  |

### 1.2 A1 后新增的决策

1. B5 已显著优于 B4，说明三标量输入仍有可学习非线性，但也把 A2 的剩余收益压到较小范围。A2 不允许用更大的网络、更多 test 反馈或 seed 集成掩盖这一难度。
2. B5 的独立输出存在负预测和组成和偏差。只读的 val 诊断显示，对五个 B5 seed 做“非负化后闭合到 100”可把平均 val `macro_RNMAE` 从约 `0.005816` 降到约 `0.005443`。该诊断不是正式结果，但足以说明输出约束必须先作为公平对照，不能与集合机制捆绑归因。
3. formal v1 的传感器数始终为 3，故 A2 只能验证完整输入下的集合归纳偏置和接口复用准备，不能验证可变集合收益。传感器缺失与未见组合留到 A4。
4. A1 test 的基线成绩已经在评审记录中公开。A2 开发阶段必须程序化禁止候选模型读取 test；所有激活、调参和杀停判断只使用 outer-train、inner OOF 与 val。最终报告需注明“A1 基线 test 已公开，但 A2 候选 test 在结构与超参数冻结后才首次运行”。

### 1.3 与总体规划的一个显式差异

总体规划 A2 要求按纯气、二元和三元混合分层，但冻结的 formal v1 明确排除了纯气端点。A2 不修改 v1 来补齐纯气；本阶段将纯气分层记为 `NA: not present in gf-a1-v1`。若后续坚持把纯气纳入训练或正式评价，必须新建数据版本和协议版本，并重新执行 A1 数据门，不得在 A2 中静默追加样本。

## 2. 文献检索结论与方法取舍

### 2.1 检索问题和证据边界

文献检索围绕三条线并行进行：集合函数及其表示局限、闭合组成输出与结构零、强 tabular 基线与 grouped OOF stacking。候选文献通过 DOI、出版社、NeurIPS、PMLR 或 JMLR 官方页核验题名、作者、年份和摘要。外部论文均未直接覆盖本项目的 Ar-He-CO₂ 数据、`mixture_id` 分组和 `macro_RNMAE`，因此只用于选择可证伪机制，不用于预告性能。

### 2.2 证据到决策的映射

| 证据主题         | 文献综合                                                                              | A2 决策                                                                        |
| ------------ | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 置换不变集合函数     | Deep Sets 支持 `rho(sum phi(x_i))` 一类集合结构；Set Transformer 用注意力显式建模元素交互。[R1–R2]      | 首轮只实现带 `sensor_id`、`sensor_type` 的轻量 Deep Sets；身份保留、顺序不变                     |
| 集合表示局限       | sum decomposition 的普适性依赖足够宽的潜在空间；过窄瓶颈可导致表示失败。[R3–R4]                              | 预注册两个小宽度并做参数匹配；不能把人为窄瓶颈的失败解释为集合模型无效                                          |
| 小集合注意力       | Set Transformer 的主要优势是集合交互与大集合可扩展性，而 A1 只有三个 token。[R2]                           | 除非 train-only 残差显示稳定传感器交互，Set Transformer 保持 `deferred`；不实现诱导点版本             |
| 组成输出         | 组成数据位于 simplex；softmax 能保证非负与闭合，但只覆盖严格正的内部。[R5–R6]                                | STR-Head 是独立输出因素，不是融合创新；与无约束头和确定性 simplex 投影做 matched audit                  |
| 结构零          | log-ratio 对零无定义；rounded-zero 插补不能直接用于配方定义的结构零；sparsemax 可输出精确零但原证据不来自组成回归。[R7–R8] | 不使用伪计数、ALR、CLR 或 ILR 主线；单列 CO₂=0 的 100 个样本，STR 边界失败时才开放 sparsemax 诊断臂        |
| 强 tabular 基线 | MLP 与树模型的相对优劣受数据特征与调参预算显著影响，不存在普适赢家。[R9–R11]                                      | 保留 A1 原始 B5，并增加同训练器、同 head、同预算的 Torch concat 控制；树模型只作强基线和互补性探针               |
| OOF stacking | Stacked Generalization 与 Super Learner 都要求元学习器使用未见样本的交叉验证预测。[R12–R13]             | 残差备选只接受严格 grouped OOF prediction；先线性 stack 和 Ridge residual，再考虑 residual MLP |
| 小样本 CV       | 小样本交叉验证误差条较大，单折或 fold 标准误不能支撑稳定收益。[R14]                                           | 使用固定五 seed、逐 group 配对差、2000 次 group bootstrap；不按最好 seed 晋级                   |

## 3. A2 总体实验结构

### 3.1 主方案、备选与停车场

| 角色     | 路线                                            | 当前处置                     | 开放条件                               |
| ------ | --------------------------------------------- | ------------------------ | ---------------------------------- |
| 主方案    | `GF-I01` 异构传感器 token + Deep Sets masked mean  | `IMPLEMENT_FIRST`        | A2-0 与 A2-1 通过                     |
| 公平公共因素 | `GF-I08` 固定总量输出头                              | `AUDIT_BEFORE_MAIN`      | A2-2 matched head audit            |
| 备选     | `GF-I07` grouped OOF baseline residual        | `DIAGNOSE_THEN_OPTIONAL` | A2-4 的 OOF 残差可预测性门通过               |
| 容量对照   | 小型 full Set Transformer                       | `DEFERRED`               | Deep Sets 已过基础门，且残差存在稳定跨传感器交互      |
| 条件机制   | `GF-I02` 目标查询、`GF-I04` 双视图、`GF-I09` 物理辅助      | `PARK`                   | 当前数据分别缺少目标专属传感器证据、raw 视图或已核验物理残差需求 |
| A4 路线  | `GF-I10` 至 `GF-I13`、ErrorNet、hard suppression | `OUT_OF_SCOPE`           | A4 协议、真实退化和 calibration 独立开放       |

### 3.2 归因矩阵

正式候选按 2×2 最小矩阵组织，不把多个机制一次性堆叠：

| ID   | 传感器表示与融合                             | 输出          | 用途        |
| ---- | ------------------------------------ | ----------- | --------- |
| `C0` | A1 原始 sklearn B5，三个标准化标量固定拼接         | 独立回归        | 冻结强基线     |
| `C1` | Torch concat，和主模型共享训练器与预算            | 独立回归        | 训练框架与容量控制 |
| `C2` | Torch concat                         | A2-2 选定的闭合头 | 隔离输出约束收益  |
| `M1` | sensor token + Deep Sets masked mean | 独立回归        | 隔离集合聚合收益  |
| `M2` | sensor token + Deep Sets masked mean | A2-2 选定的闭合头 | A2 主候选    |

主融合机制的归因比较是 `M2 - C2`；输出头的归因比较是 `C2 - C1`；整体方法与历史强基线比较是 `M2 - C0`。如果 A2-2 没有闭合头通过门，则 `C2=C1`、`M2=M1`，不为凑齐矩阵保留无收益模块。

## 4. 分步实现

### A2-0：冻结 A2 契约与 test 访问边界（2–3 天）

目标：把 A1 数据、A2 模型选择、搜索预算、运行产物和最终 test 解锁条件写成机器可检查的配置。

实施：

1. 新建 `configs/eval/a2_eval.json`，schema 固定为 `gf-a2-eval-1`；继承 `gf-eval-1` 的指标、五 seed、2000 次 bootstrap、5% 收益门和组分退化上限，不覆盖 A1 配置。
2. 新建 `configs/train/a2_train.json`，登记优化器、loss、最大 epoch 或迭代数、early-stopping 信息权限、两个预注册容量档和每类模型相同的搜索 trial 数。
3. 新建 `configs/experiment/a2_head_audit.json`、`a2_deepsets.json` 和 `a2_formal.json`；全部固定 A1 data version、content hash、split seed、训练 seeds 和允许读取的 split。
4. 将 B5 主比较定义为五个独立 seed 的配对均值；`B5__mean` 仅作为次级 ensemble 对照。
5. 开发模式只允许读取 train 与 val。`--unlock-test` 必须同时校验候选配置 hash、选定 checkpoint hash、主图表模板 hash 和正式运行状态；缺任一项即显式失败。
6. 将当前工作树版本、dirty 状态、配置 hash、数据 hash、split hash、退出码和预测 hash 写入每个 run manifest。

影响文件：

- `configs/train/a2_train.json`
- `configs/eval/a2_eval.json`
- `configs/experiment/a2_*.json`
- `src/gf/pipeline/a2_benchmark.py`
- `tests/test_a2_protocol.py`

阶段门：

- test 锁可由自动测试证明有效；
- 不出现 `sequence_id`、`base_condition_id`、`noise_seed_index` 或 `noise_seed` 依赖；
- A1 manifest hash 不匹配时立即失败；
- 搜索预算、seed、主指标和最终图表字段均已配置化。

### A2-1：抽取唯一评价实现并复现 A1 强基线（3–4 天）

目标：先消除评价函数只存在于 `gf.ml.baselines` 的多来源风险，再证明新管线没有改变 A1 数值语义。

实施：

1. 将 `evaluate_predictions`、component 指标、group 聚合和 group bootstrap 抽到 `src/gf/dl/evaluation.py`，作为神经模型与传统基线共同的唯一评价实现。
2. `src/gf/ml/baselines.py` 改为调用共享评价模块；删除原位置的重复实现，不保留第二套兼容分支。
3. 用原配置重放 A1 pilot smoke，并对 formal 已保存 predictions 做离线重评；新旧汇总在浮点容差内一致。
4. 保留原始 B3、B4、B5 结果；在 train / val 上登记相同 trial 预算的 `B4-tuned` 与强 Torch concat，但不得据此改写 A1 评审记录。
5. 检查 Torch concat 能否在同输入、train-only scaler、目标缩放和五 seed 下达到与 B5 同量级表现；若差距来自训练器，先关闭训练器差异，不进入集合机制比较。

影响文件：

- `src/gf/dl/evaluation.py`
- `src/gf/ml/baselines.py`
- `src/gf/dl/training.py`
- `tests/test_a1_metric_regression.py`
- `tests/test_a2_training_contract.py`

阶段门：

- A1 离线重评数值不漂移；
- scaler 只由相应训练组拟合；
- Torch concat 的失败可由 loss、优化器、容量或输入差异明确定位；
- 若基线复现未闭合，A2 停在本步，不用集合模型掩盖问题。

### A2-2：输出 head matched audit（3–5 天）

目标：确定闭合约束是否本身构成主要收益，并冻结后续模型共用的输出语义。

固定编码与融合为 Torch concat，只改变输出映射：

| ID   | Head                        | 约束           | 说明                   |
| ---- | --------------------------- | ------------ | -------------------- |
| `H0` | 三维线性独立回归                    | 无            | 与 B5 语义对齐            |
| `H1` | 线性输出的确定性 simplex projection | 非负、和为 100    | 无训练参数的推理后处理对照        |
| `H2` | `100 * softmax(logits)`     | 严格正、和为 100   | `GF-I08` 的 A2 固定总量分支 |
| `H3` | sparsemax 固定总量              | 可精确为零、和为 100 | 仅当 H2 在结构零组明显失败时开放   |

实施约束：

1. H0、H1、H2 使用相同输入、backbone、loss、seed、训练预算和模型选择规则；H1 只改变推理映射。
2. 不使用伪计数，不对结构零做 log-ratio 变换，不把 softmax 称为 logistic-normal。
3. 不因 softmax 自动更换成 categorical cross-entropy；首轮沿用同一连续回归 loss，避免 head 与 loss 同时变化。
4. 报告整体、二元、三元、逐组分、CO₂=0 的 100 个边界样本、负值率、越界率、组成和偏差及零组分残余预测。
5. 只使用 train、inner OOF 和 val 选定 head。H2 只有在五 seed val 平均改善达到预注册 5% 门、至少四个 seed 同向、任一组分不超过既定退化上限时才成为公共头；否则保留 H0。

影响文件：

- `src/gf/dl/task_heads.py`
- `src/gf/dl/evaluation.py`
- `configs/model/a2_heads.json`
- `tests/test_a2_task_heads.py`

阶段门：输出约束收益、边界代价和物理违规均可独立归因；未通过的 head 不进入主模型。

### A2-3：实现并筛选轻量 Deep Sets 主机制（1.5–2 周）

目标：在完整三传感器输入上验证“身份保留、顺序不变”的集合融合是否优于固定拼接。

实现路径：

1. 在 `sensor_encoders.py` 增加 A2 标量 token 编码器。输入只使用 train-only 标准化后的观测值和显式 `sensor_id`、`sensor_type`；A1 中恒定的 quality、time、delta time 不作为可学习预测量。
2. 在 `fusion_core.py` 将首轮正式聚合固定为 masked mean；sum 只作单因素消融。现有 A1 `quality=1` 时，reliability weighting 必须与 masked mean 产生相同输出，不得声明质量自适应。
3. token 顺序可任意打乱，但身份和类型嵌入必须随 token 同步移动；`dataset_id`、目标名称和固定 sensor count 不进入核心。
4. 预注册两个满足表示宽度下界的小容量档；Torch concat 与 Deep Sets 使用相同训练器、相同 head、相同 trial 数，参数量尽量匹配到 ±10%。不能精确匹配时，用一低一高两个 concat 容量对照夹住主模型参数量。
5. 每个候选先跑 smoke 与单 seed train / val，再运行五 seed val。只有按预注册 val 门晋级的一个配置才允许进入 formal test。

必做消融：

- `C1` 与 `M1`：固定拼接对 masked mean；
- 去除 `sensor_id`；
- 去除 `sensor_type`；
- sum 对 mean；
- 六种 token 排列的输出一致性；
- 逐一移除一个传感器的只读敏感性分析；
- 参数量较低和较高的 concat 容量对照。

注意：移除传感器只用于检查模型是否依赖互补信息，不作为缺失鲁棒性结果，也不训练缺失组合。

影响文件：

- `src/gf/dl/sensor_encoders.py`
- `src/gf/dl/fusion_core.py`
- `src/gf/dl/training.py`
- `configs/model/a2_concat.json`
- `configs/model/a2_deepsets.json`
- `tests/test_a2_fusion_core.py`
- `tests/test_a2_model_parity.py`

阶段门：

- 五 seed val 平均相对最佳合格强基线改善至少 5%；
- 至少四个 seed 方向一致；
- 任一组分 `RNMAE_i` 绝对退化不超过 `0.005`；
- 改善能由 `M2 - C2` 归因到集合机制，而不是 head、参数量或预处理；
- 排列测试严格通过，模型源码不含数据集或气体名称分支。

若本步未通过，不实现 Set Transformer。先执行 A2-4 的备选诊断；若备选也未通过，A2 形成负结果并按总体规划返回 A1 或收缩方法声明。

### A2-4：grouped OOF 残差备选诊断（4–6 天，条件执行）

目标：只在训练数据内判断 B5 或 GBDT 的剩余误差是否可由观测量稳定预测，避免 in-sample residual 泄漏。

实施：

1. 在 outer-train 内生成固定五折 fold manifest；fold 按 `mixture_id` 互斥，并保持二元、三元条件覆盖。不得临时使用 `sequence_id` 或其他历史主键。
2. 每个 inner fold 的 scaler、基模型和任何特征选择只在 inner-train 拟合；OOF 行记录训练 group hash、模型配置 hash 和预测 hash。
3. 先计算 B5、B4-tuned 的 OOF 残差相关性和非负线性 oracle stack。若线性 stack 已不能稳定改善 B5，停止更复杂 stacking。
4. residual 标签固定为 `target - base_prediction_oof`。按顺序测试 Ridge residual、浅层 GBDT residual；只有二者显示稳定的正 OOF explained variance 和 val 改善后，才开放小型 residual MLP。
5. 保留 in-sample residual 与随机打乱 residual 作为泄漏和无结构负对照，但它们不能参与候选排序。
6. 推理时基模型在完整 outer-train 上重训；残差模型使用与训练阶段同一输出坐标和可观测输入。

影响文件：

- `src/gf/ml/oof.py`
- `src/gf/dl/residual.py`
- `configs/model/a2_oof_residual.json`
- `tests/test_a2_oof_contract.py`

激活门：重复 grouped OOF 中，相对 B5 的中位改善达到预注册 5% 门、配对 group bootstrap 95% CI 不跨 0、关键组分不退化。未通过即关闭 `GF-I07`，不升级 DeepGBM、ErrorNet 或第二级门控。

### A2-5：冻结候选并执行一次 formal test（3–5 天）

进入条件：A2-0 至 A2-3 全部通过，或 A2-4 产生唯一合格备选；模型结构、head、超参数、seed、checkpoint 选择规则和报告模板均已冻结。

执行：

1. 由 val 选择唯一主候选和唯一最佳强基线；不得在 test 上逐组分拼接赢家。
2. 使用训练 seeds `17, 29, 43, 71, 101` 完整重跑并保存每个 seed，不静默删除失败运行。
3. 解锁 test 一次，生成逐 `mixture_id` 预测；同 seed 方法和基线做配对误差比较。
4. 以 `mixture_id` 为单位做 2000 次、seed `20260827` 的双侧 95% percentile bootstrap。
5. 主门使用五个独立 seed 的平均 `macro_RNMAE`；另报最坏 seed、seed 离散度和预测集成，但集成不替代主门。
6. 分层报告二元、三元、CO₂=0、各组分浓度区间、worst group、P90 group、参数量、训练时间、推理时间和峰值显存。纯气固定为 `NA`。

正式 PASS 必须同时满足 `gf-eval-1` 的五项 A2 主方法晋级门。否则结果登记为正式负结果，不调整 5% 门、不再打开 test 搜索新结构，也不跳到 A3 寻找偶然正结果。

### A2-6：产物汇总、反向审稿与阶段关闭（2–3 天）

产物：

- `outputs/runs/a2/<run_id>/`：配置快照、manifest、日志、checkpoint、逐组预测、metrics 和退出状态；
- `outputs/summary/a2/`：自动生成的模型矩阵、配对区间、消融、分层误差和效率表；
- `outputs/reports/a2/`：A2 自动报告与失败样本图；
- `docs/algorithm/07_A2评审记录.md`：阶段证据、PASS / FAIL、claim scope 和进入 A3 的决定。

关闭前反向审稿：

1. 删除 head 后，集合机制是否仍有收益？
2. 用参数量更高的 concat 后，收益是否仍存在？
3. 任何结论是否依赖 B5 seed 集成而不是五个独立运行？
4. 是否把固定三传感器结果写成了可变集合、质量自适应或硬件泛化？
5. 是否存在 test 驱动的候选、阈值、temperature、calibration 或图表选择？
6. 是否出现第二套 metric、split、scaler、summary 或手工维护数值？

全部结果由运行产物生成。阶段关闭时再同步《项目总体规划》和 README 的状态；本文件不提前写 `A2_COMPLETED`。

## 8. 杀停与重新开放规则

| 情况                                | 处置                                 |
| --------------------------------- | ---------------------------------- |
| Torch concat 不能复现 B5 同量级表现        | 停在 A2-1，修复训练器、loss、目标缩放或预算差异       |
| 输出闭合改善物理违规但未过精度门                  | 保留 head 负结果；主集合模型使用 H0             |
| STR 只在内部点有效、结构零明显退化               | 不用伪计数修补；开放一次 H3 sparsemax 诊断或返回 H0 |
| Deep Sets 不优于 matched concat      | 关闭主机制，不升级注意力；转 A2-4 训练内诊断          |
| OOF residual 不可预测或只在 in-sample 有效 | 关闭备选，保留 B5，A2 记负结果                 |
| 收益只来自参数量、test 反馈或 seed 集成         | 结果作废或降级，不进入 A3                     |
| test 正式门未通过                       | 冻结负结果，返回 A1 或收缩“通用融合核心优于强基线”的声明    |
| 发现 A1 数据、split 或物理错误              | 停止 A2，升版数据并重新执行 A1；不在 A2 就地修补      |

Set Transformer 只有在 Deep Sets 基础训练已闭合、train-only 残差显示跨传感器条件交互、并且参数匹配对照无法解释该交互时才可新建协议重新开放。大型 Transformer、DeepGBM、ErrorNet、hard suppression、UQ 和可靠性路由均不因 A2 失败自动开放。
