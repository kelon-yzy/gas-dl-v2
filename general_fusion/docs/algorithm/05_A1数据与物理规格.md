# A1 数据与物理规格

状态：A1-0 至 A1-5 已执行；formal v1 已冻结。  
适用数据集：Ar-He-CO2 三组分合成 benchmark。  
数据契约版本：gf-a1-data-1。

## 1. 数据边界

- 目标标签固定为 x_Ar_pct、x_He_pct、x_CO2_pct，单位为 mol%。
- 每条配方只有一个稳态观测，T=1，dt=1 s；因此 B8 时序模型在 A1 标记为不适用。
- mixture_id 是唯一 group_id；不生成 sequence_id，也不生成 base_condition_id、noise_seed_index 或 noise_seed。
- 采样先按排序后的唯一 mixture_id 使用 GroupShuffleSplit(random_state=20260827) 抽取 test 15%，再在剩余样本上按 3/17 抽取 val，最终比例为 70/15/15。
- 二元边界点排除纯气端点；纯 Ar、纯 He、纯 CO2 只用于单位、方向、端点和饱和审计，不进入训练、验证或测试。

| 版本        | 二元  | 三元内部 | 总数   | train/val/test |
| --------- | ---:| ----:| ----:| -------------- |
| pilot     | 60  | 180  | 240  | 168/36/36      |
| formal v1 | 300 | 900  | 1200 | 840/180/180    |

组合值以 0.01 mol% 量化，并由第三个组分闭合到 100 mol%，避免逐项四舍五入破坏守恒。

## 3. 物理观测模型

### 3.1 超声 ToF

混合气声速为

c = sqrt(gamma * R * T / M)

观测为

t_ToF = L / c + t_delay

其中 M 为混合摩尔质量，gamma=Cp/(Cp-R)，Ar、He、CO2 的摩尔质量和定压热容来自当前仓库已迁移的物理实现。实现位置为 src/gf/sim/ar_he_co2.py。

### 3.2 热导电压

热导率使用 Wilke 混合法：

k_mix = sum_i(x_i * k_i / sum_j(x_j * Phi_ij))

再使用显式线性转换：

V_TCS = 1.1 + 15.0 * (k_mix - 0.026)

热导率、黏度和摩尔质量参数沿用本地物理实现中的 Ar-He-CO2 参数；该电压关系是 benchmark 参考模型，不是目标硬件重新标定结果。

### 3.3 CO2 NDIR

NDIR 使用 Beer-Lambert 形式：

V_NDIR = V0 * exp(-A)

A1 固定参考工况下的吸收度为：

A = 0.04269004521460337 * x_CO2_pct * (P/P0) * (T0/T)

该有效系数的来源链为：本地 HAPI/HITRAN 计算、CO2 参考滤光片中心 2347 cm-1、FWHM 93 cm-1，再将 0.2 m 计算结果归一到 0.01 m 参考光程。源版本登记为 hitran_hapi_v1，计算结果和配置来自相邻 hydrogen_ng 子项目的 spectral backend 与共享 HITRAN cache。

硬件资料登记的 TraceGas NDIR CO2 模块只有 0–50000 ppm 范围、1500 ppm 精度和 ADC 输出信息；当前没有目标模块的实际滤光片中心、FWHM、光程或 ADC 电压标定。因此 A1 的 NDIR 是“来源可追溯的参考光学模型”，不是目标 TraceGas 模块的实测标定。目标硬件证据替换属于后续物理迁移验收项，不能把本系数回写为实测真值。

## 5. A1-2 信息审计门禁

门禁使用内部三元配方的 0.01 mol% 中心差分，输出按传感器分辨率归一化。formal v1 实际结果：

| 审计项                             | 结果          | 门禁     |
| ------------------------------- | -----------:| ------ |
| Jacobian 内部点 full-rank fraction | 1.000000    | PASS   |
| Jacobian condition number P95   | 95.706046   | <1000  |
| condition number 最大值            | 388.754833  | 记录     |
| acoustic/TCS 最大方向余弦             | 0.999999983 | 记录为近共线 |
| NDIR 与其余模态的最大方向余弦               | 0.919091363 | <0.999 |
| NDIR 动态范围/噪声尺度                  | 154.063     | >=10   |

超声和热导对组成的方向接近共线是已暴露的退化方向；NDIR 提供独立的 CO2 轴，因而整体 Jacobian 仍保持二阶满秩。NDIR 在无 CO2 的 Ar-He 二元边界处达到基线端点，formal 样本中为 100/1200，属于已登记的单模态饱和区间，不被伪装为额外信息。
