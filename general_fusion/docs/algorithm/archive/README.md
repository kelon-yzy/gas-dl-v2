## 1. 为什么归档而不是删除

这些文件是「分步执行计划」，但正文同时承载了各首轮的**预注册协议**：候选集合、困难轴定义、模型矩阵、比较预算、晋级门与交付清单。对应的评审记录（`07_A2评审记录.md`、`11_A2M评审记录.md`、`outputs/reports/a2h_v2/`）只登记结论，不复制协议正文。删除它们会让已关闭结论失去可追溯的判定依据，与 v11 §0 的保存要求冲突。

因此处理方式是：**移入本目录 + 头部加归档状态块 + 保留正文逐字不改**。每份文件的头部已写明它管辖哪一轮、实际终态是什么、当前事实源在哪里。

## 5. 引用本目录时的约束

- 可以引用这里的协议**解释历史结论怎么来的**。
- 不可以把这里的阈值、收益门、困难轴或模型矩阵直接搬进新一轮实验；v11 §4.4 要求新正式实验另建有版本的协议。
- 不可以修改这里的正文数值。发现表述错误时，在头部归档块补一条更正注记，不覆盖原文。
