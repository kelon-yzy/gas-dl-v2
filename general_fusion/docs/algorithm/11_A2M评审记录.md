# A2M 主流深度学习架构对照评审记录

> 评审日期：2026-08-29  
> 阶段：A2M  
> 终态：`MLP_RETAINED`  
> 评审结论：完成负结果关闭，冻结 A2M-MLP 作为 A3 完整输入参考

## 1. 结论摘要

A2M 按冻结计划完成 A2M-0 至 A2M-6。A1 的历史 B5 明确登记为 `B5-SK`，当前统一 PyTorch 主基线登记为 `A2M-MLP`；A1 formal v1 文件保持只读。A2M formal 使用独立的 `gf-a2m-v1-20260829-r1` holdout，一次评价三个架构、各自冻结 recipe 和五个 seed。

没有非 MLP 架构通过开发集和 formal 的联合晋级门。最终冻结：

- 主基线与 A3 完整输入参考：`A2M-MLP / mlp_lbfgs_width32`；
- `A2M-RESNET`、`A2M-FTT`：保留为已运行的主流架构负对照，不声称架构劣势具有跨数据集普遍性；
- `T=1` 上的 TCN、GRU / LSTM 和 temporal Transformer：不运行、不排名，交由 A3 的真实时间维协议；
- 不触发 matched-optimizer MLP audit，因为没有候选达到开发晋级门。

| 项目 | 结果 |
| --- | --- |
| 历史身份 | `B5-SK`，只读 A1 formal v1 |
| 新主基线身份 | `A2M-MLP`，PyTorch concat MLP |
| 保存预测经共享 evaluator 重算 | 通过；CSV 八位小数序列化误差在 `1e-8` 量级内 |
| 当前 sklearn 重拟合相对保存预测最大绝对差 | `0.7625766004398571` |
| 当前 sklearn 重拟合相对保存预测平均绝对差 | `0.12362112765450657` |

当前运行时记录为 Python 3.13.11、NumPy 2.5.0、SciPy 1.18.0、scikit-learn 1.7.1、PyTorch 2.11.0+cu128、MKL、CPU、float32；确定性开关按运行时指纹记录，未改写 A1 文件。

## 4. A2M-4：开发集比较

主实验严格为 3 个架构 × 2 个 recipe × 5 个 seed，共 30 次；seed 为 `17、29、43、71、101`。B3、B4 使用 `gf/ml/baselines.py` 的唯一全输入实现同步重跑，未使用 B5-SK 参与 recipe 排名。

### 4.1 选择结果

| 模型 | 选中 recipe | 主轴 stress-val macro_RNMAE（calibration / environment / iid / joint / noise） | 晋级状态 |
| --- | --- | --- | --- |
| `A2M-MLP` | `mlp_lbfgs_width32` | `0.031676 / 0.018357 / 0.005600 / 0.029923 / 0.012702` | 主基线保留 |
| `A2M-RESNET` | `resnet_width32_blocks2` | `0.187839 / 0.181494 / 0.171921 / 0.186869 / 0.184581` | 未通过；iid 相对退化 `29.6982%` |
| `A2M-FTT` | `ftt_token16_block1_heads2` | `0.242337 / 0.218458 / 0.217557 / 0.236656 / 0.222342` | 未通过；iid 相对退化 `37.8469%` |

两个非 MLP 候选在每条主轴均为 0 / 5 seed 同向改善，未形成合格改善轴；配对 `mixture_id` bootstrap 的差异方向也支持退化。因此没有触发参数匹配、同优化器 MLP 审计。

同步 B3 / B4 的主轴 stress-val macro_RNMAE 见机器汇总；B4 仍明显弱于统一 PyTorch MLP，A2M 没有把传统基线误命名为新架构结果。

## 5. A2M-5：formal 确认

formal 在 holdout 解锁后只执行一次，同时评价三个架构、冻结 recipe 和五个 seed；每个轴使用 2000 次以 `mixture_id` 为单位的 paired bootstrap。结果如下，composition 仅作诊断。

| 模型 | recipe | iid | calibration | environment | joint | noise | composition 诊断 | formal gate |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| `A2M-MLP` | `mlp_lbfgs_width32` | 0.005150 | 0.071973 | 0.063540 | 0.135047 | 0.032876 | 0.002699 | reference |
| `A2M-RESNET` | `resnet_width32_blocks2` | 0.153122 | 0.134944 | 0.124296 | 0.121961 | 0.138668 | 0.174190 | FAIL |
| `A2M-FTT` | `ftt_token16_block1_heads2` | 0.191919 | 0.183036 | 0.177736 | 0.175598 | 0.189513 | 0.293392 | FAIL |

formal 中 RESNET 和 FTT 相对 A2M-MLP 的 iid 退化分别为 `28.7344%` 和 `36.2681%`，两个候选均无 qualifying stress axis，最终 `passing_candidates=[]`。因此终态为 `MLP_RETAINED`，不是 `POSITIVE_RESULT`，也不是“无稳定差异”：候选退化方向清晰，且未满足非劣化条件。

## 6. A2M-6：关闭与 A3 交接

A3 完整输入参考冻结为 `A2M-MLP / mlp_lbfgs_width32`，保留五个 seed 的 checkpoint 与独立结果；A3 不根据外部数据结果反向重开 A2M 候选池。

A3 的时序矩阵已写入并冻结在 [A3 时序架构矩阵](../../configs/experiment/a3_temporal_matrix.json)，只在具有真实时间维的 A3 执行：

1. 统计特征 MLP；
2. 轻量 TCN；
3. 单层 GRU；
4. 轻量 temporal Transformer。

这些模型没有在 A2M 的 `T=1` 数据上运行，不能用 A2M 结果评价时序归纳偏置。A2M 结论只适用于三个完整传感器、单次稳态标量观测、当前仿真物理和已登记困难轴，不外推为真实硬件、缺失传感器或通用时序结论。
