## 2. A1-0 物理规格结论

超声 ToF 和热导模型沿用当前仓库中已迁移且可检查的物理方程。NDIR 不再自动复用 A0 历史经验系数，而使用本地 HAPI/HITRAN 计算得到的 CO2 参考光学有效系数，固定为 0.01 m 参考光程，并在规格文档中登记了计算条件、光谱参考和硬件证据边界。

目标 TraceGas 模块当前仅有 NDIR 能力、量程、精度和 ADC 输出的本地资料，没有实际滤光片中心、FWHM、光程或 ADC 电压标定。因此本阶段的 NDIR 证据足以支撑“可追溯参考仿真 benchmark”，不足以支撑真实硬件校准；该限制已写入规格和本记录，不作为隐藏替代。

## 5. 泄漏与复现检查

- 每条观测只有一个时间点；不生成 sequence_id、base_condition_id、noise_seed_index 或 noise_seed。
- mixture_id 同时作为 group_id，train、val、test 交集为空。
- scaler 只使用 train group 拟合，val 和 test 仅执行 transform。
- observations.npz 使用非 pickle 读取；manifest canonical JSON 与数组字节共同计算 content_sha256。
- 相同 generation_seed、split_seed 和配置重复生成得到相同内容哈希。
- formal v1 在 pilot gate 通过后生成；其 manifest、配置快照、summary 和 report 已保存。
