## 3. 阶段结果

### 3.1 A2-1：评价与 Torch concat 对照

共享 evaluator 已从传统基线抽取为唯一实现，A1 原有指标回归通过。五个 seed 的 direct scalar Torch concat val `macro_RNMAE` 为：

`0.0027186960 ± 0.0001335298`

相对 A1 B5 独立 seed val 均值 `0.00581589` 的相对差为 `-0.53253999`，同量级门 PASS。该结果证明训练器、目标缩放和 train-only scaler 可以工作，但不替代 A2-3 的 matched C1 对照。

### 3.2 A2-2：matched head audit

| head                      | val mean macro_RNMAE | 相对 H0    | 同方向改善 seed |
| ------------------------- | --------------------:| --------:| ----------:|
| H0 independent regression | 0.0077716512         | —        | —          |
| H1 simplex projection     | 0.0057024229         | 26.6253% | 2 / 5      |
| H2 softmax fixed-total    | 0.0064097397         | 17.5241% | 2 / 5      |

H1、H2 都满足平均改善和组分退化上限，但都不满足至少 4 / 5 个 seed 同方向改善。因此没有闭合 head 晋级；后续主机制已按计划使用 H0，避免把输出闭合收益混入集合聚合归因。H3 sparsemax 未开放。

### 3.3 A2-3：H0 对照下的 Deep Sets

参数量为 C1 `519`、M1 `515`，相对差 `0.7707%`，参数匹配通过。五 seed val 结果为：

- C1 ordered concat：`0.0077716512`；
- M1 sensor token + masked mean：`0.0083504342`；
- M1 相对 C1 变差 `7.4474%`，仅 `3 / 5` 个 seed 同方向改善；三个组分的 M1 平均 RNMAE 均更高。

因此 Deep Sets 主机制关闭，不打开 Set Transformer 或更大模型搜索。

### 3.4 A2-4：grouped OOF residual

残差学习器只消费 grouped OOF prediction，5 折均按 `mixture_id` 隔离，记录 1680 行 provenance。

- B5 + Ridge residual：base val `0.0055978073`，corrected val `0.0056263612`，相对改善 `-0.5101%`；三个 OOF explained variance 均为负；2000 次 group bootstrap 的 95% CI 为 `[-9.45e-06, 6.60e-05]`，跨过 0。
- B4 + Ridge residual：相对 B5 变差 `158.4467%`，Ar / He / CO2 的 RNMAE 增量为 `[0.01816692, 0.00516668, 0.00327503]`，触发组分退化门。

两条 residual 路线均关闭，不升级第二级门控、DeepGBM 或 ErrorNet。

## 4. A2-5 处置与 claim scope

A2-0、A2-1 通过，但 A2-2 没有产生合格 head，A2-3 的 matched Deep Sets 也未超过 C1，A2-4 没有产生合格 residual 备选。因此不满足 A2-5 的进入条件，正式 test 保持锁定；本记录不报告 A2 候选 test 成绩，也不把 A1 已公开的 B5 test 成绩冒充 A2 结果。

本阶段支持的最窄结论是：在固定三传感器、稳态、A1 formal v1 数据上，当前轻量 token + Deep Sets masked mean 没有稳定超过 matched ordered concat；输出闭合约束的平均收益也不足以通过 seed 稳定性门。不能声称“通用融合核心优于强基线”，不能声称可变传感器集合收益、质量自适应、时序收益或真实硬件泛化。
