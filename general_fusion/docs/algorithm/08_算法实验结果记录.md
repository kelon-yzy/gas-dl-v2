## 4. 按算法展开

### 4.1 B0：训练集均值

**原理。** 计算训练目标均值，对所有输入输出同一个三组分向量。它不读取传感器，仅用于确认 split、评价和结果导出没有出现异常低误差。

**结果。** val 为 `0.22183848`，test 为 `0.22938730`，二者接近，符合无信息模型预期。

**问题与结论。** B0 没有检测能力，不能作为可部署方案。它的作用是提供任务难度下界，并防止把数据泄漏或标签常数化误判为算法进步。

### 4.2 B1 / B2：单传感器 Ridge 与 GBDT

**原理。** B1 使用 Ridge 学习单路标量到三个组分的线性映射；B2 使用浅层 GBDT，以加法树拟合单路信号的非线性映射。两者用于判断每个传感器单独含有什么信息。

| 传感器 | B1 val / test | B2 val / test | 主要信息表现 |
| --- | ---: | ---: | --- |
| ultrasonic ToF | 0.14313947 / 0.14523221 | 0.13064145 / 0.12460882 | 对 He 较敏感，但不能独立分离 Ar 与 CO₂ |
| thermal conductivity voltage | 0.14827581 / 0.15194481 | 0.12568312 / 0.12789344 | B2 的 He val RNMAE 为 0.01841143，但 Ar、CO₂ 仍高 |
| NDIR CO₂ voltage | 0.16074995 / 0.16262742 | 0.12824376 / 0.12752144 | B2 的 CO₂ val RNMAE 为 0.01162840，但 Ar、He 均约 0.18 |

**问题与结论。** 三组分闭合后仍有两个自由度，单个标量通常不足以唯一恢复组成。B2 能准确恢复传感器直接敏感的组分，却无法补回缺失的正交信息。单传感器模型保留为互补性证据，不进入主候选。

### 4.3 B3：全输入 Ridge

**原理。** 将三路标准化标量固定拼接，使用 Ridge 学习一个线性逆映射。

**结果。** val / test 为 `0.06080560 / 0.05438875`；val 的 Ar、He、CO₂ RNMAE 分别为 `0.09057165 / 0.02880095 / 0.06304421`。

**问题与结论。** 多传感输入显著优于单传感器，证明互补信息真实存在；但声速、Wilke 混合热导和 Beer–Lambert 响应形成非线性正向映射，线性逆模型明显欠拟合。B3 作为可解释、低容量基线保留。

### 4.4 B4：全输入 GBDT

**原理。** 对三路拼接输入分别训练多输出 GBDT，通过多棵浅树的分段函数逼近平滑非线性逆映射。

**结果。** val / test 为 `0.01774493 / 0.01740693`；val 的 Ar、He、CO₂ RNMAE 为 `0.03172648 / 0.01099593 / 0.01051238`。相对 B3，三组分均明显改善，Ar 仍是主要误差来源。

**问题与结论。** B4 是合格强树基线，但当前结果只证明同分布插值。树模型的分段预测尚未经过温压外推、标定变化或组成区域整块留出测试；这些问题进入 A2H。

### 4.5 B5、direct Torch concat 与 C1：固定拼接 MLP

**原理。** 将三路传感器标量按固定顺序拼接，由全连接网络联合学习非线性逆映射。与后融合不同，隐藏层可以直接学习跨传感器交互。

**A1 结果。** B5 五个独立 seed 的 val / test 为 `0.00581589 ± 0.00103384 / 0.00647441 ± 0.00120615`；五模型预测均值进一步达到 `0.00437865 / 0.00495217`。集成改善来自方差抵消，只作为次级部署对照。

**A2 结果。** direct Torch concat 的 val 为 `0.00271870 ± 0.00013353`，证明 Torch 训练器、目标缩放和 train-only scaler 能稳定工作。参数匹配审计中的 C1 为 `0.00777165 ± 0.00346646`，与 direct 版本不能直接互换，因为模型容量和比较职责不同。

**问题与结论。** 固定拼接 MLP 是当前最强算法族，但依赖三个完整传感器及固定顺序。不同容量和训练配置的数值差异说明，后续机制比较必须使用 matched 参数量、同 head、同训练预算；不能把训练器差异归因于融合创新。A2 尚未产生候选 test，因此 B5 仍是冻结强基线。

### 4.6 B6 / B7：预测级后融合

**原理。** 先用每个传感器独立预测完整组成，再对三个组成预测做等权平均或按 val 误差反比加权。

**结果。** B6 val / test 为 `0.11941066 / 0.11841780`；B7 为 `0.11939310 / 0.11843572`。验证误差权重与等权几乎没有差异。

**问题与结论。** 单传感器预测阶段已经丢失其他传感器提供的正交信息，事后平均不能恢复这些联合关系。B6/B7 作为“后融合不等于联合辨识”的负对照保留，不继续优化固定权重。

### 4.7 H0 / H1 / H2：组成输出头

**H0 原理。** 三个组分独立回归，不保证非负或总和为 100。它与普通回归语义一致，是输出约束审计的控制组。

**H1 原理。** 先由 H0 输出，再确定性投影到非负、总和为 100 的单纯形。投影没有训练参数，只改变推理输出几何。

**H2 原理。** 网络输出三个 logits，经 `100 × softmax(logits)` 得到严格正且总和为 100 的组成。

| Head | val mean ± std | Ar / He / CO₂ mean RNMAE | 约束表现 | 结论 |
| --- | ---: | --- | --- | --- |
| H0 | 0.00777165 ± 0.00346646 | 0.00899382 / 0.00475945 / 0.00956168 | 存在负值、越界和总量偏差 | 控制组 |
| H1 | 0.00570242 ± 0.00134319 | 0.00750186 / 0.00306024 / 0.00654517 | 非负且数值闭合 | 平均改善，但仅 2 / 5 seed 同向，未晋级 |
| H2 | 0.00640974 ± 0.00150708 | 0.00719726 / 0.00628458 / 0.00574738 | 严格正且数值闭合 | 平均改善，但 He 退化且仅 2 / 5 seed 同向，未晋级 |

**问题与结论。** 输出闭合能减少物理违规，却没有稳定提升五个 seed。H1 只修正输出几何；H2 无法对二元边界中的结构零输出精确零。H3 sparsemax 因开放条件未满足而未执行，没有结果。后续必须继续把输出头收益与融合表示收益分开归因。

### 4.8 C1 与 M1：ordered concat 对 Deep Sets

**C1 原理。** 三个传感器表示按固定顺序拼接，保留每个位置的独立表示。

**M1 原理。** 每个传感器的标量、`sensor_id` 和 `sensor_type` 编码为 token，再用 masked mean 聚合。该结构对 token 排列不变，目标是支持传感器集合接口。

**匹配条件。** C1 参数量为 519，M1 为 515，相对差 `0.7707%`，满足 ±10% 参数匹配门；两者使用相同 H0 和训练协议。

**结果。** C1 val 为 `0.00777165 ± 0.00346646`，M1 为 `0.00835043 ± 0.00200209`。M1 相对变差 `7.4474%`，Ar、He、CO₂ 平均 RNMAE 分别增加 `0.00096501 / 0.00066235 / 0.00010899`，只有 3 / 5 seed 相对方向满足要求。

**问题与结论。** A1 始终提供三个完整传感器，集合大小和组合没有变化，因此排列不变能力没有对应的困难场景。masked mean 还可能压缩固定拼接保留的传感器特异关系。当前 M1 关闭，不因负结果自动升级 Set Transformer；真正的可变集合收益留到 A4 独立验证。

### 4.9 GF-I07：grouped OOF residual

**原理。** 在 outer-train 内按 `mixture_id` 建立五折，基模型只对未见过的 inner-val group 生成 OOF 预测。残差学习器拟合 `target - base_prediction_oof`；推理时再把残差修正加回完整 outer-train 重训的基模型。这样避免使用 in-sample residual 制造虚假收益。

**协议。** 五折均保持 `mixture_id` 互斥，记录 1680 行 provenance；先使用 Ridge residual，只有残差可预测时才允许升级复杂模型。

**B5 结果。** base val 为 `0.00559781`，corrected val 为 `0.00562636`，相对变差 `0.5101%`。三个 OOF explained variance 为 `-0.012946 / -0.019465 / -0.012474`；2000 次 bootstrap 的 95% CI 为 `[-9.45e-06, 6.60e-05]`，跨过 0。

**B4 结果。** base val 从 `0.01774493` 改善到 `0.01446735`，说明 B4 的 OOF 残差存在部分结构；但 corrected B4 仍比 B5 基线差，且相对 B5 的组分退化超过门限，因此不能晋级为 A2 备选。

**问题与结论。** 对当前最强 B5，剩余误差没有稳定可预测结构；对较弱 B4，残差修正只能追回部分基模型欠拟合，无法超过 B5。GF-I07 关闭，不开放 residual MLP、DeepGBM、ErrorNet 或二级门控。

## 5. 跨算法结论

1. 多传感器联合输入是主要有效因素：B3/B4/B5 均显著优于单传感器与后融合。
2. 非线性建模是第二个主要因素：B4 和 B5 明显优于 B3。
3. 固定拼接 MLP 是当前冻结强基线；其低误差也暴露出 A1 v1 的同分布插值任务接近饱和。
4. 输出约束改善了物理合法性和平均误差，但尚未满足 seed 稳定性门。
5. Deep Sets 没有在固定三个完整传感器上超过 matched concat；这是否意味着可变集合机制无效，必须由 A4 的缺失与未见组合协议回答。
6. B5 的 OOF residual 不可预测，继续叠加残差网络没有进入证据。
7. A2 没有候选进入 formal test，不能声称通用融合核心优于 B5。

#### 6.2 原理与困难轴

A2H 保持三路完整稳态观测，并以 `mixture_id` 作为分组主键；在此基础上独立改变观测条件，再用 oracle、最近邻和 matched 基线拆分误差来源。A2H 不覆盖 A1 v1，也不读取 A2 test。

| environment | 温度、压力环境块隔离 | 模型能否跨工况泛化 |

#### 6.8 问题清单

1. composition 轴未达到资格门，不能与其余四轴一起作为算法晋级依据。

3. M1 在固定三路完整传感器上未体现集合归纳偏置收益；这不等价于证明可变传感器集合无效，缺失与未见组合仍由 A4 验证。
4. hard-test 只解锁一次，B5 作为冻结主基线未发生解锁后调参。

## 7. A2M 主流深度学习架构对照

### 7.1 研究定位与终态

A2M 在三个完整传感器、`T=1` 稳态标量输入上比较统一 PyTorch concat MLP、Tabular ResNet 和轻量 FT-Transformer。历史 A1 `B5-SK` 只作身份与复现参照；新架构排名使用 `A2M-MLP` 作为唯一 PyTorch 主基线。

A2M-0 的复现状态为 `PASS_WITH_NEW_REFERENCE`：A1 保存的 B5 预测经共享 evaluator 重算通过，但当前 sklearn LBFGS 运行时相对保存预测的最大绝对差为 `0.7625766004398571`。A1 缺少历史运行时指纹，故冻结 A1 v1、登记差异并建立 A2M 新参考，不覆盖历史数值。

### 7.2 数据、预算与模型

### 7.4 结果、问题与结论

开发集完成 30 / 30 次运行。RESNET 和 FTT 在主轴上均未形成合格改善，iid 相对退化分别为 `29.6982%` 和 `37.8469%`；没有候选触发 matched-optimizer MLP audit。formal 中两者 iid 相对退化分别为 `28.7344%` 和 `36.2681%`，`passing_candidates=[]`，终态为 `MLP_RETAINED`。

A2M 结论限定在完整三传感器、单次稳态标量观测、当前仿真物理与登记困难轴内。它不支持时序模型、缺失传感器、真实硬件或跨数据集的架构优越性声明。TCN、GRU / LSTM 和 temporal Transformer 已转交 A3 的真实时间维协议，未在 `T=1` 上运行。

## 10. 维护规则

- 新结果只能在 summary、manifest 和配置已经落盘后登记。
- 已关闭算法保留历史结果，不因后续新版本静默删除；新数据版本另起小节比较。
- 同一算法在不同数据、split、head、容量或训练器下必须分开命名，禁止只保留最好结果。
- A2H 的同分布、噪声、环境 OOD、标定失配和组成留出结果必须分别记录，不能只写总体平均。
- test 未解锁时明确写 `NA`，不得用 val、历史 test 或集成结果替代。
