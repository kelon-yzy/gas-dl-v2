1. 本文只登记已经运行且有正式 summary、manifest 或评审记录的算法。Idea 假设仍由[未实现算法 Idea 集合](未实现算法Idea集合_文献调研版.md)维护。

3. A1 已公开 val 和 test；A2 候选只运行 train / val，formal test 未解锁；A2H v2 在冻结协议下仅解锁一次 hard-test；A2M 使用独立 holdout 并仅解锁一次。A2 表中的 test 均为 `NA`，不得用 A1 的 B5 test 代替。
4. 主指标为 `macro_RNMAE`：三个组分 MAE 分别除以固定量程 100 mol% 后取平均。因此 `0.005` 对应平均绝对组分误差约 `0.5 mol%`。
5. 五 seed 结果默认报告独立模型的均值与标准差；预测集成单列，不能替代独立 seed 稳定性进入晋级门。
6. 当前结论只适用于固定温压、三路完整传感器、单次稳态观测和同分布组成空间，不外推为跨工况、缺失传感器或真实硬件结果。
7. 可读性要求：术语第一次出现时给出日常语言定义（统一见 §2.1 术语速查）；关键数值紧跟通俗换算；推断性文字必须标注"这是解读"或"这是推断"。本文既是证据索引，也要让第一次接触项目的读者不看代码就能明白每个阶段发生了什么。

## 4. 按算法展开

### 4.1 B0：训练集均值

**原理。** 计算训练目标均值，对所有输入输出同一个三组分向量。它不读取传感器，仅用于确认 split、评价和结果导出没有出现异常低误差。

**结果。** val 为 `0.22183848`，test 为 `0.22938730`，二者接近，符合无信息模型预期。

**问题与结论。** B0 没有检测能力，不能作为可部署方案。它的作用是提供任务难度下界，并防止把数据泄漏或标签常数化误判为算法进步。

### 4.2 B1 / B2：单传感器 Ridge 与 GBDT

**原理。** B1 使用 Ridge 学习单路标量到三个组分的线性映射；B2 使用浅层 GBDT，以加法树拟合单路信号的非线性映射。两者用于判断每个传感器单独含有什么信息。

| 传感器 | B1 val / test | B2 val / test | 主要信息表现 |
| --- | ---: | ---: | --- |
| ultrasonic ToF | 0.14313947 / 0.14523221 | 0.13064145 / 0.12460882 | 对 He 较敏感，但不能独立分离 Ar 与 CO₂ |
| thermal conductivity voltage | 0.14827581 / 0.15194481 | 0.12568312 / 0.12789344 | B2 的 He val RNMAE 为 0.01841143，但 Ar、CO₂ 仍高 |
| NDIR CO₂ voltage | 0.16074995 / 0.16262742 | 0.12824376 / 0.12752144 | B2 的 CO₂ val RNMAE 为 0.01162840，但 Ar、He 均约 0.18 |

**问题与结论。** 三组分闭合后仍有两个自由度，单个标量通常不足以唯一恢复组成。B2 能准确恢复传感器直接敏感的组分，却无法补回缺失的正交信息。单传感器模型保留为互补性证据，不进入主候选。

### 4.3 B3：全输入 Ridge

**原理。** 将三路标准化标量固定拼接，使用 Ridge 学习一个线性逆映射。

**结果。** val / test 为 `0.06080560 / 0.05438875`；val 的 Ar、He、CO₂ RNMAE 分别为 `0.09057165 / 0.02880095 / 0.06304421`。

**问题与结论。** 多传感输入显著优于单传感器，证明互补信息真实存在；但声速、Wilke 混合热导和 Beer–Lambert 响应形成非线性正向映射，线性逆模型明显欠拟合。B3 作为可解释、低容量基线保留。

### 4.4 B4：全输入 GBDT

**原理。** 对三路拼接输入分别训练多输出 GBDT，通过多棵浅树的分段函数逼近平滑非线性逆映射。

**结果。** val / test 为 `0.01774493 / 0.01740693`；val 的 Ar、He、CO₂ RNMAE 为 `0.03172648 / 0.01099593 / 0.01051238`。相对 B3，三组分均明显改善，Ar 仍是主要误差来源。

**问题与结论。** B4 是合格强树基线，但当前结果只证明同分布插值。树模型的分段预测尚未经过温压外推、标定变化或组成区域整块留出测试；这些问题进入 A2H。

### 4.5 B5、direct Torch concat 与 C1：固定拼接 MLP

**原理。** 将三路传感器标量按固定顺序拼接，由全连接网络联合学习非线性逆映射。与后融合不同，隐藏层可以直接学习跨传感器交互。

**A1 结果。** B5 五个独立 seed 的 val / test 为 `0.00581589 ± 0.00103384 / 0.00647441 ± 0.00120615`；五模型预测均值进一步达到 `0.00437865 / 0.00495217`。集成改善来自方差抵消，只作为次级部署对照。

**A2 结果。** direct Torch concat 的 val 为 `0.00271870 ± 0.00013353`，证明 Torch 训练器、目标缩放和 train-only scaler 能稳定工作。参数匹配审计中的 C1 为 `0.00777165 ± 0.00346646`，与 direct 版本不能直接互换，因为模型容量和比较职责不同。

**问题与结论。** 固定拼接 MLP 是当前最强算法族，但依赖三个完整传感器及固定顺序。不同容量和训练配置的数值差异说明，后续机制比较必须使用 matched 参数量、同 head、同训练预算；不能把训练器差异归因于融合创新。A2 尚未产生候选 test，因此 B5 仍是冻结强基线。

### 4.6 B6 / B7：预测级后融合

**原理。** 先用每个传感器独立预测完整组成，再对三个组成预测做等权平均或按 val 误差反比加权。

**结果。** B6 val / test 为 `0.11941066 / 0.11841780`；B7 为 `0.11939310 / 0.11843572`。验证误差权重与等权几乎没有差异。

**问题与结论。** 单传感器预测阶段已经丢失其他传感器提供的正交信息，事后平均不能恢复这些联合关系。B6/B7 作为“后融合不等于联合辨识”的负对照保留，不继续优化固定权重。

### 4.7 H0 / H1 / H2：组成输出头

**H0 原理。** 三个组分独立回归，不保证非负或总和为 100。它与普通回归语义一致，是输出约束审计的控制组。

**H1 原理。** 先由 H0 输出，再确定性投影到非负、总和为 100 的单纯形。投影没有训练参数，只改变推理输出几何。

**H2 原理。** 网络输出三个 logits，经 `100 × softmax(logits)` 得到严格正且总和为 100 的组成。

| Head | val mean ± std | Ar / He / CO₂ mean RNMAE | 约束表现 | 结论 |
| --- | ---: | --- | --- | --- |
| H0 | 0.00777165 ± 0.00346646 | 0.00899382 / 0.00475945 / 0.00956168 | 存在负值、越界和总量偏差 | 控制组 |
| H1 | 0.00570242 ± 0.00134319 | 0.00750186 / 0.00306024 / 0.00654517 | 非负且数值闭合 | 平均改善，但仅 2 / 5 seed 同向，未晋级 |
| H2 | 0.00640974 ± 0.00150708 | 0.00719726 / 0.00628458 / 0.00574738 | 严格正且数值闭合 | 平均改善，但 He 退化且仅 2 / 5 seed 同向，未晋级 |

**问题与结论。** 输出闭合能减少物理违规，却没有稳定提升五个 seed。H1 只修正输出几何；H2 无法对二元边界中的结构零输出精确零。H3 sparsemax 因开放条件未满足而未执行，没有结果。后续必须继续把输出头收益与融合表示收益分开归因。

### 4.8 C1 与 M1：ordered concat 对 Deep Sets

**C1 原理。** 三个传感器表示按固定顺序拼接，保留每个位置的独立表示。

**M1 原理。** 每个传感器的标量、`sensor_id` 和 `sensor_type` 编码为 token，再用 masked mean 聚合。该结构对 token 排列不变，目标是支持传感器集合接口。

**匹配条件。** C1 参数量为 519，M1 为 515，相对差 `0.7707%`，满足 ±10% 参数匹配门；两者使用相同 H0 和训练协议。

**结果。** C1 val 为 `0.00777165 ± 0.00346646`，M1 为 `0.00835043 ± 0.00200209`。M1 相对变差 `7.4474%`，Ar、He、CO₂ 平均 RNMAE 分别增加 `0.00096501 / 0.00066235 / 0.00010899`，只有 3 / 5 seed 相对方向满足要求。

**问题与结论。** A1 始终提供三个完整传感器，集合大小和组合没有变化，因此排列不变能力没有对应的困难场景。masked mean 还可能压缩固定拼接保留的传感器特异关系。当前 M1 关闭，不因负结果自动升级 Set Transformer；真正的可变集合收益留到 A4 独立验证。

### 4.9 GF-I07：grouped OOF residual

**原理。** 在 outer-train 内按 `mixture_id` 建立五折，基模型只对未见过的 inner-val group 生成 OOF 预测。残差学习器拟合 `target - base_prediction_oof`；推理时再把残差修正加回完整 outer-train 重训的基模型。这样避免使用 in-sample residual 制造虚假收益。

**协议。** 五折均保持 `mixture_id` 互斥，记录 1680 行 provenance；先使用 Ridge residual，只有残差可预测时才允许升级复杂模型。

**B5 结果。** base val 为 `0.00559781`，corrected val 为 `0.00562636`，相对变差 `0.5101%`。三个 OOF explained variance 为 `-0.012946 / -0.019465 / -0.012474`；2000 次 bootstrap 的 95% CI 为 `[-9.45e-06, 6.60e-05]`，跨过 0。

**B4 结果。** base val 从 `0.01774493` 改善到 `0.01446735`，说明 B4 的 OOF 残差存在部分结构；但 corrected B4 仍比 B5 基线差，且相对 B5 的组分退化超过门限，因此不能晋级为 A2 备选。

**问题与结论。** 对当前最强 B5，剩余误差没有稳定可预测结构；对较弱 B4，残差修正只能追回部分基模型欠拟合，无法超过 B5。GF-I07 关闭，不开放 residual MLP、DeepGBM、ErrorNet 或二级门控。

## 5. 跨算法结论

1. 多传感器联合输入是主要有效因素：B3/B4/B5 均显著优于单传感器与后融合。
2. 非线性建模是第二个主要因素：B4 和 B5 明显优于 B3。
3. 固定拼接 MLP 是当前冻结强基线；其低误差也暴露出 A1 v1 的同分布插值任务接近饱和。
4. 输出约束改善了物理合法性和平均误差，但尚未满足 seed 稳定性门。
5. Deep Sets 没有在固定三个完整传感器上超过 matched concat；这是否意味着可变集合机制无效，必须由 A4 的缺失与未见组合协议回答。
6. B5 的 OOF residual 不可预测，继续叠加残差网络没有进入证据。
7. A2 没有候选进入 formal test，不能声称通用融合核心优于 B5。

## 6. A2H 高难度仿真与分布外泛化（2026-08-28 关闭，终态 `NEGATIVE_RESULT`）

### 6.1 这一节回答什么问题

A1 的结果是：固定拼接 MLP（B5）在常规数据上误差很低。A2H 要回答的下一个问题是——**当实验条件偏离训练条件（传感器标定漂移、温压环境变化、噪声放大、多因素叠加、组成区域留出）时，B5 还稳吗？有没有更聪明的融合机制能比它更稳？**

**结论：** 四个困难方向确实让 B5 明显变差，最严重时（标定漂移）误差约为常规条件的 3.4 倍；但两个候选机制（C1 有序拼接、M1 Deep Sets 传感器 token 聚合）都没有通过预注册晋级门。C1 只在标定漂移一个方向平均改善 30.88%，代价是 CO₂ 组分误差恶化超过上限；M1 在四个合格方向全部不如 B5。阶段以 `NEGATIVE_RESULT` 关闭，B5 继续作为主强基线进入 A2M 与 A3。

研究定位（预注册约束）：高难度仿真、困难度资格审计和一次性 hard-test formal 关闭；研究目的是区分样本覆盖、噪声压力、环境变化、标定失配和组成区域留出各自对误差的贡献。

### 6.2 实验设计：五个困难方向与三类参照

A2H 保持三路完整稳态观测，以 `mixture_id` 作为分组主键；每个方向独立改变一种条件，再用三类参照拆分误差来源：

- **oracle 反演**——假设模型知道真实工况参数，误差还剩多少：区分"信息缺失"与"噪声下限"；
- **最近邻**——训练集里最相似配方的距离：区分"记住了样本"与"学到了映射"；
- **matched 基线**——参数量对齐的对照模型：把"融合机制的差异"与"模型大小的差异"分开。

A2H 不覆盖 A1 v1，也不读取 A2 的 test。

| 困难方向 | 主要扰动或留出 | 主要回答 |
| --- | --- | --- |
| calibration | 零点、增益、光程和响应曲线变化 | 标定失配是否破坏反演 |
| environment | 温度、压力环境块隔离（训练与测试环境互斥） | 模型能否跨工况泛化 |
| joint | 温压、噪声、标定和组成变化组合施加 | 单因素结论能否承受联合压力 |
| noise | 独立重复、分级噪声和共同扰动 | 误差何时接近噪声下限 |
| composition | 浓度带、单纯形区域和结构零留出 | 覆盖外推与边界输出是否稳定 |

### 6.3 数据与执行协议

| 项目 | 冻结设置 |
| --- | --- |
| 数据版本 | `gf-a2h-v2-20260828-r1` |
| 数据规模 | 2100 个 `mixture_id`、3045 条观测；开发视图 2610 条，hard-test 435 条 |
| content hash | `67f9f4841e80f0c1f7d355dcaa8b6e954c46475621cc1fbf196f68c814cdb4de` |

三条访问纪律的用意：

- **train-only 标准化**：标准化统计量只从训练数据估计，验证与测试不参与，防止评价集信息漏进模型；

- **hard-test 一次解锁**：全部候选、配置、checkpoint 和图表模板的 hash 验证通过后才解锁一次，解锁后不得再改模型或阈值——防止"看着答案改答案"。

### 6.4 困难度资格审计：哪些方向"难得有意义"

一个方向要能用于比较算法，必须同时满足两点：**它确实让基线明显变差**（有压力），且**变差的部分原则上可以恢复**（不是物理不可辨识）。审计用三个量检查（定义见 §2.1）。以标定轴为例说明 oracle headroom 的读法：拼接基线在压力数据上误差 4.26 mol%，而知晓真实标定参数的 oracle 误差只有 0.008 mol%——误差几乎全部来自"不知道标定变了"，而不是噪声，因此这部分误差原则上可学习。

| 方向 | 拼接基线误差：常规 → 压力（mol%） | 相对 iid 退化 | oracle headroom | Jacobian P95 条件数 | 资格结果 | 未通过原因 |
| --- | --- | ---: | ---: | ---: | --- | --- |
| calibration | 1.26 → 4.26 | 2.3849 | 0.9981 | 86.29 | PASS | — |
| composition | 0.56 → 0.66 | 0.1945 | 0.9865 | 40.35 | FAIL | 退化未达到资格门 |
| environment | 1.12 → 1.41 | 0.2597 | 0.9951 | 72.36 | PASS | — |
| joint | 1.51 → 3.25 | 1.1532 | 0.9897 | 77.87 | PASS | — |
| noise | 0.98 → 1.28 | 0.2975 | 0.9777 | 66.18 | PASS | — |

五个方向的 Jacobian 满秩比例均为 1.0，信号全部在登记范围内。

composition 未过资格门的解读（这是解读，不是新数据）：留出设计本身有效，但基线只慢了 19%，说明训练点已把二维组成空间覆盖得足够密——与 A1 关闭诊断"同分布插值偏易"一致。因此该方向不能作为算法晋级依据，只在 formal 中作诊断。

### 6.5 开发集结果：B5 在压力下的表现

`macro_RNMAE` 越低越好；括号内为平均每组分误差的 mol% 换算。学习曲线和噪声响应同时显示：减少训练覆盖或放大噪声都会使误差上升。标定漂移是伤害最大的方向。

| --- | ---: |
| calibration | 0.02862（2.9） |
| environment | 0.01244（1.2） |
| joint | 0.03245（3.2） |
| noise | 0.01098（1.1） |

环境上下文对照（ENV-C0 = 不把环境条件给模型，ENV-C1 = 把环境条件作为额外输入提供；数值为对应 stress-val `macro_RNMAE`）：

| 模型 | ENV-C0 | ENV-C1 | 观察 |
| --- | ---: | ---: | --- |
| B5 | 0.01244 | 0.05831 | 提供上下文后反而明显变差 |

### 6.6 matched 算法比较：两个候选为什么没晋级

比较条件先说清楚：C1（有序拼接）与 M1（传感器 token + 聚合）的真实参数量为 519 与 515，相对差 0.77%，满足 ±10% 匹配门；两者与 B5 使用相同 H0 输出头和训练协议。也就是说，唯一待检验的系统差异是融合机制本身。

晋级门（预注册）的通俗版本：候选必须在合格方向稳定优于 B5（五 seed 至少四个同向改善，配对 bootstrap 置信区间支持），且任何单组分误差的恶化不超过预注册上限。下表数值为相对 B5 的平均变化。

| 候选 | calibration | environment | joint | noise | 处置 |
| --- | --- | --- | --- | --- | --- |
| C1 | 改善 30.88% | 退化 25.26% | 退化 11.85% | 退化 93.10% | 未晋级 |
| M1 | 退化 18.53% | 退化 121.90% | 退化 16.75% | 退化 175.03% | 未晋级 |

seed 稳定性与组分约束（晋级的两个附加条件）：

- C1：calibration 上 4 / 5 seed 同向改善，但 CO₂ 组分退化 0.005424 超过预注册上限——单方向收益加关键组分恶化，按规则一票否决。
- M1：calibration 仅 2 / 5 seed 同向，最大组分退化 0.016535；四个方向均无稳定收益。

C1 的教训是"平均改善不能掩盖关键组分恶化"：它在标定轴平均好了三成，但 CO₂ 误差恶化超过上限。M1 在所有方向都更差——固定三路完整传感器时，排列不变与 token 聚合没有对应的困难场景，masked mean 还可能压缩拼接保留的传感器特异关系（这是机制层面的推断）。真正的可变集合收益留到 A4 独立验证。

### 6.7 hard-test 与最终结论

因为没有候选通过晋级门，预注册规则直接冻结 B5 为 selected 模型；hard-test 实际测量的就是 B5 自己，作为最终确认。selected 与 B5 相同，因此主基线差异 gate 不适用；结果只用于最终确认，不回流训练或调参。

| --- | ---: |
| iid | 0.003800（0.38） |
| noise | 0.018705（1.9） |
| environment | 0.017697（1.8） |
| calibration | 0.053087（5.3） |
| composition | 0.001945（0.19） |
| joint | 0.043560（4.4） |

终态 `NEGATIVE_RESULT` 的含义：不是实验失败，而是得到了一个明确的负答案——在当前登记的压力范围内，没有复杂融合机制稳定优于强基线，且证据链完整、可复查。据此，A3 使用冻结 B5 作为完整输入对照，不开放更大网络、residual 或未注册候选池。

### 6.8 问题清单

1. composition 轴未达到资格门，不能与其余四轴一起作为算法晋级依据。
2. C1 的 calibration 改善局限于单轴，且 CO₂ 组分退化超过 0.005 上限。
3. M1 在固定三路完整传感器上未体现集合归纳偏置收益；这不等价于证明可变传感器集合无效，缺失与未见组合仍由 A4 验证。
4. hard-test 只解锁一次，B5 作为冻结主基线未发生解锁后调参。

## 7. A2M 主流深度学习架构对照（2026-08-29 关闭，终态 `MLP_RETAINED`）

### 7.1 这一节回答什么问题

A2 与 A2H 之后，主基线一直是参数量只有 227 的拼接 MLP。A2M 回答的疑问是：**B5 会不会只是有限候选里最好——在真正适合这类数据的主流深度架构（Tabular ResNet、FT-Transformer）面前还站得住吗？**

**结论：站得住。** 在相同数据、相同预算、相同评价协议下，ResNet 与 FT-Transformer 都明显差于统一 PyTorch MLP——formal 同分布误差分别约为 MLP 的 30 倍与 37 倍，开发集五个 seed 无一形成同向改善。没有任何非 MLP 架构通过晋级门，MLP 以 `MLP_RETAINED` 留任，并冻结为 A3 的完整输入参考模型。历史 A1 `B5-SK` 只作身份与复现参照，不参与排名。

时序架构（TCN、GRU/LSTM、temporal Transformer）不参加本次比较：A2M 的输入是单次稳态观测（`T=1`），没有时间维，时序结构无从发挥；它们的对照协议已冻结在 [A3 时序架构矩阵](../../configs/experiment/a3_temporal_matrix.json)，由有真实时间维的 A3 执行。

### 7.2 A2M-0：先解决"同一配置训练不出同一模型"

比较架构之前必须先回答一个更基本的问题：A1 当年的 B5 结果今天还能复现吗？结论是**精度水平能复现，预测本身不能逐位复现**：

- A1 保存的预测文件没有问题：用共享评价器重算，与当年 summary 一致（test macro_RNMAE 0.00495217）。
- 但在当前软件环境用同一 scikit-learn 配置重新拟合，得到的是一个精度相当（test 0.00474160）、预测却不同的模型：与保存预测的最大绝对差为 `0.7625766004398571`（单位与组分浓度一致，约 0.76 mol%），平均绝对差 `0.12362112765450657`（约 0.12 mol%）。
- 原因分类为 `DEPENDENCY_RUNTIME_DRIFT_NO_HISTORICAL_FINGERPRINT`：依赖版本随时间漂移，且 A1 当时没有保存运行环境指纹，差异无法进一步定位。

处置（不改变任何历史数值）：A1 文件保持只读；历史身份冻结为 `B5-SK`；新主线统一使用 PyTorch 重实现的主基线 `A2M-MLP`，复现状态登记为 `PASS_WITH_NEW_REFERENCE`，并从此记录完整运行时指纹（Python 3.13.11、NumPy 2.5.0、SciPy 1.18.0、scikit-learn 1.7.1、PyTorch 2.11.0+cu128、MKL、CPU、float32）。

### 7.5 结论与边界

- 终态 `MLP_RETAINED` 不是"没有稳定差异"：差异方向清晰——两个非 MLP 候选全面退化，未满足非劣化条件，因此 MLP 留任。
- 冻结 `A2M-MLP / mlp_lbfgs_width32` 为 A3 完整输入参考，保留五个 seed 的 checkpoint 与独立结果；A3 不根据外部数据结果反向重开 A2M 候选池。
- 结论边界：只适用于三个完整传感器、单次稳态标量观测、当前仿真物理与已登记困难轴；不支持时序模型、缺失传感器、真实硬件或跨数据集的架构优劣声明。TCN、GRU / LSTM 和 temporal Transformer 已转交 A3 的真实时间维协议，未在 `T=1` 上运行。

## 8. GF-I14 TQIF-Net（2026-08-31 失败放弃，终态 `SCIENTIFIC_FAILURE / ABANDONED`）

### 8.1 这一节回答什么问题

TQIF 用目标查询和无序传感器对交互，让每个气体组分主动检索与自己相关的跨传感器证据。本轮回答：这种完整融合核心在相同容量和相同训练协议下，是否稳定优于去掉 query 与 pair 机制的 matched concat（C0）。

**结论：没有。** 两档完整 TQIF 相对各自 C0 分别退化 343.05% 和 77.99%，均未通过预注册容量门。机器选择产物为 `NEGATIVE_RESULT`；项目决策进一步登记为 `SCIENTIFIC_FAILURE / ABANDONED`：放弃当前 TQIF 结构，不再调参、扩容或进入 A2H、A2M，下一轮必须重新构思新算法。

### 8.2 Idea、原理与实验范围

- **Idea 对应：** `GF-I14 TQIF-Net`。
- **原理：** 三路传感器先形成带身份与类型信息的 token；共享 pair 模块提取无序传感器对证据；每个目标组分使用独立 target slot query 依次读取单传感器和 pair 证据。已执行的 `TQIF-H0` 使用三个独立回归输出，不强制总和为 100 mol%；原计划的结构化任务头因容量门失败未运行。
- **数据与 split：** 当前 A1 train / val；允许先读取冻结聚合文件再按 split 逻辑过滤，但 test 不进入训练、选择、预测或指标。
- **训练与统计：** 固定 seed `17、29、43、71、101`；A2-TQIF-2 完成 15 个基线运行，A2-TQIF-3 完成 10 个 full 新运行并复用 10 个 C0 运行，形成两档各 10 个逻辑格；配对统计以 `mixture_id` 为组、bootstrap 2,000 次。
- **matched 约束：** token16 与 token32 的 full / C0 参数差分别为 0.76% 和 1.32%，均低于 10% 上限。

### 8.3 结果

下表均为五个 seed 的 val `macro_RNMAE`；`0.005` 约等于平均每组分 `0.5 mol%` 绝对误差。

| 模型 | mean | std | 95% seed bootstrap CI | 参数量 | 相对同档 C0 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A2M-MLP | 0.005637 | 0.000386 | [0.005329, 0.005961] | 227 | 不适用 |
| C0 token16 | 0.007890 | 0.001124 | [0.006996, 0.008833] | 5,987 | 参照 |
| TQIF-H0 token16 | 0.034959 | 0.025749 | [0.015157, 0.060317] | 6,033 | 退化 343.05% |
| C0 token32 | 0.006176 | 0.000542 | [0.005730, 0.006653] | 23,123 | 参照 |
| TQIF-H0 token32 | 0.010993 | 0.002081 | [0.009249, 0.012788] | 22,817 | 退化 77.99% |

token16 为 0/5 seed 改善，TQIF 减 C0 的 paired group bootstrap 95% CI 为 `[0.017962, 0.021428]`，三个组分 RNMAE 均超限退化。token32 也为 0/5 seed 改善，paired CI 为 `[0.003081, 0.004389]`，且 CO₂ RNMAE 退化 `0.006066`，超过 `0.005` 上限。两个区间都完全大于 0，即完整 TQIF 的误差稳定更高。

### 8.4 失败分析

**直接证据：**

1. 失败跨容量、跨 seed：两档均为 0/5 seed 改善，配对置信区间完全大于 0，不是单一初始化偶发失效。
2. 不是参数量不公平：full 与 C0 的参数差只有 0.76% 和 1.32%，但误差分别增至 C0 的 4.43 倍和 1.78 倍。
3. 简单模型更适配当前任务：227 参数的 A2M-MLP 为 0.005637；C0 token32 为 0.006176，只比 MLP 高约 9.55%，说明三路标量的主要映射已能由简单拼接模型学习，复杂交互没有带来新观测信息。
4. token16 优化不稳定：其标准差 0.025749，高于均值量级，最差 seed 达 0.079707；token32 虽降低波动，五个 seed 仍全部差于 C0。
5. 输出闭包一致性明显变差：预测组分和偏离 100 mol% 的平均绝对值，TQIF token16 和 token32 分别约为 4.83 和 1.47 mol%，对应 C0 仅约为 0.44 和 0.50 mol%。
6. 两档 TQIF 的五个 seed 都在第 20 个、即最后一个 epoch 取得选中 checkpoint，表明在冻结预算内没有提前稳定收敛；这只能证明其同预算优化效率不足，不能证明追加 epoch 可以挽救。

**由证据支持的解释：** 当前数据只有 840 个训练配方、三个稳态标量输入，目标映射平滑且低维。传感器 token、无序 pair、两级 attention 和独立 target query 增加了表示自由度与优化路径，却没有增加观测信息；独立目标输出还削弱了组成闭包的一致性。因此 TQIF 的结构复杂度与当前任务不匹配，收益不足以抵消优化难度和 seed 敏感性。

**无法由本轮证明：** 由于容量门失败后按计划跳过 2×2 消融，不能判断 query、pair 或 H0 任务头中哪一个是唯一根因，也不能声称结构化任务头能够修复 TQIF。上述机制不得拆出、改名后直接作为下一候选。

### 8.5 放弃决定与边界

`GF-I14 TQIF-Net` 按当前结构整体失败并放弃。代码、配置、checkpoint 和结果只为复现与失败分析保留，不再执行以下动作：扩大 token、延长训练、追加 seed、单独替换优化器、补跑 STR head、进入 A2H/A2M，或以“TQIF-v2”名义继续局部修补。

下一候选必须使用新的算法 ID 和独立预注册计划，从强 MLP 已接近任务上限、三标量缺少额外交互信息、组成约束需要显式保持这三个事实重新定义问题；在新假设冻结前不启动训练。结论不外推到时序数据、缺失传感器、可变传感器集合或真实硬件。

**证据。** [TQIF 设计与验证计划](12_TQIF新算法设计与A2至A2M验证计划.md)、[protocol manifest](../../outputs/runs/a2/tqif/protocol_manifest.json)、[baseline summary](../../outputs/summary/a2/tqif/baseline_summary.json)、[capacity summary](../../outputs/summary/a2/tqif/capacity_summary.json)、[selection manifest](../../outputs/runs/a2/tqif/selection_manifest.json)。

## 9. 后续追加格式与可读性协议（v2，2026-08-29 起生效）

后续 A3、A4 算法结果继续按算法追加，不按实现步骤堆叠。每个算法条目按"问题—设计—结果—解读—边界"组织，至少包含：

```md
### 算法 ID 与名称

**这一节回答什么问题。** 一两个问题句，加一段不超过五行的结论（含终态）。读者只读这一段就能知道发生了什么，不需要先看表格。

**Idea 对应。** GF-Ixx、正式基线或对照。

**原理。** 机制在做什么、输入输出是什么，用日常语言解释，不照抄实现术语。

**实验范围。** 数据版本、split、允许读取的集合、seed 和 matched 对照；每个冻结项写明它防止什么（例如 train-only scaler 防泄漏、formal 一次解锁防偷看）。

**结果。** val/test、逐组分、关键子组、置信区间与资源。每个关键数值紧跟通俗换算（`0.005 ≈ 平均每组分 0.5 mol%`；`相对退化 2.38 ≈ 误差变为 3.4 倍`）。

**解读。** 只基于已登记证据；推断必须标注"这是解读"或"这是推断"；未解释的反常观察如实保留并注明"未解释"。

**边界。** 结论不适用的情形。

**证据。** summary、manifest、配置和评审记录链接。
```

可读性规则（与 §1 第 7 条配套，同等约束力）：

1. 术语第一次出现时给出日常语言定义，或引用 §2.1 术语速查；不得只写字段名。
2. 表格列名若沿用代码字段名（如 `stress_val`、`family_val`），须在表格外用一句话解释含义。
3. 一个表格单元格只放一个事实；百分比、seed 同向数、组分退化不混排在同一格。
4. 改善/退化直接写"改善 X% / 退化 X%"，不用正负号约定让读者记忆方向。
5. 解释性文字可以润色改写，但已登记数值、终态、处置与证据链接一经写入不得改动——这是"本文是可读索引、不是第二结果源"的执行方式。

如果算法只被提出但尚未运行，只保留在 Idea 集合，不在本文创建空结果条目。

## 11. 维护规则

- 新结果只能在 summary、manifest 和配置已经写入产物后登记。
- 已关闭算法保留历史结果，不因后续新版本静默删除；新数据版本另起小节比较。
- 同一算法在不同数据、split、head、容量或训练器下必须分开命名，禁止只保留最好结果。
- A2H 的同分布、噪声、环境 OOD、标定失配和组成留出结果必须分别记录，不能只写总体平均。
- test 未解锁时明确写 `NA`，不得用 val、历史 test 或集成结果替代。
- 每个新小节以"这一节回答什么问题 + 结论"开头；数值表必须能独立读懂（列名有解释、关键数值带通俗换算）。
- 既有小节允许按 §9 v2 协议改写表达以提升可读性，但已登记数值、终态、处置与证据链接不得改动；改写只动解释，不动事实。
- 反常观察（如 ENV-C1 使 B5 变差、sklearn 重拟合与保存预测不一致）必须保留并标注"未解释"或"原因分类"，不得因结果难看而删除。
