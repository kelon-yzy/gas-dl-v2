> 契约版本：`gf-a0-contract-1`  
> 冻结日期：2026-08-27  
> 状态：`FROZEN_FOR_A0_SMOKE`  
> 上位计划：[项目总体规划](../../项目总体规划.md)  
> 执行步骤：[A0 分步执行计划](00_A0分步执行计划.md)

## 1. 契约范围

本文件是 A0 的任务、数据字段、shape、mask、标签、分层接口和错误语义唯一事实源。A0 只证明 Ar-He-CO₂ 与 `xylene-e-nose` 能通过同一接口进入同一个共享融合核心，不评价模型性能。

主任务冻结为三组分浓度回归。分类不进入 A0 smoke；未来若增加分类，只能新增任务头，不能改变统一样本或 `FusionCore` 接口。

## 2. 数据集任务

| `dataset_id` | 数据职责 | 目标顺序 | 单位 | 标签约束 | `group_id` 来源 |
| --- | --- | --- | --- | --- | --- |
| `ar_he_co2` | A1–A2 主开发数据；A0 使用确定性物理 pilot | `x_Ar_pct`、`x_He_pct`、`x_CO2_pct` | mol% | 每项在 `[0,100]`，三项和为 `100±1e-6` | 原始 `mixture_id`，二者字符串完全相同 |
| `xylene_e_nose` | A3 外部验证；A0 使用真实工作簿裁剪窗口 | `C_m_ppm`、`C_o_ppm`、`C_p_ppm` | ppm | 每项非负，三项和等于文件名名义总浓度；近饱和文件无定量标签 | 完整工作簿文件名 |

两个任务均为三输出只是当前数据事实，`FusionCore` 不读取目标维度。输出维度由任务头配置。

## 3. Ar-He-CO₂ v1 模态冻结

### 3.1 纳入模态

| `sensor_id` | `sensor_type` | 模型输入 | 单位 | A0 pilot 物理链 | 推理可观测性 |
| --- | --- | --- | --- | --- | --- |
| `ultrasonic_tof` | `acoustic_tof` | 传播时间序列 | s | 理想气体混合声速 `c=sqrt(γRT/M)`，固定声程换算 ToF | 可由超声收发链测量 |
| `thermal_conductivity_voltage` | `thermal_conductivity` | 热导传感电压序列 | V | WMS 混合热导率与显式线性传感映射 | 可由热导传感器测量 |
| `ndir_co2_voltage` | `ndir` | CO₂ NDIR 电压序列 | V | Beer–Lambert `V=V0 exp(-A)`，A0 使用已登记有效吸收系数 | 可由 CO₂ NDIR 通道测量 |

A0 pilot 固定 `T=298.15 K`、`P=101325 Pa`、超声声程 `L=0.2 m`，生成 32 个、间隔 1 s 的确定性响应点。每个通道从纯 Ar 基线向目标混合物平衡响应按一阶系统过渡；时间常数只用于形成接口 smoke 的时序形态，不作为 A1 动态标定。

### 3.2 来源与证据边界

- 声速、WMS 热导与 CO₂ 经验吸收链迁移自 [hydrogen_ng 物理实现](../../../hydrogen_ng/hg/sim/generation/acoustic_physics.py)，但只迁移通用公式，不 import 历史包。
- 超声、热导和 NDIR 的可测性及硬件链依据 [传感器硬件资料整理](../../../hydrogen_ng/docs/references/传感器硬件资料整理.md)。
- Ar、He、CO₂ 的摩尔质量、定压热容、热导率和粘度常量在 `src/gf/sim/ar_he_co2.py` 集中登记；A0 只要求公式自洽和输出可追溯。
- CO₂ NDIR 有效吸收系数继承历史经验链，尚未由本课题目标滤光片和光程重新标定。因此 NDIR pilot 只证明接口可执行，不构成 A1 正式 benchmark 的定量物理证据。
- 不纳入光纤麦克风、原始超声波形、气体名称分类和任何缺少 Ar-He-CO₂ 来源的旧慢通道。

## 4. xylene v1 输入冻结

原始数据事实源为 [xylene-e-nose 数据集说明](../../../数据集/xylene-e-nose_三元二甲苯混合物/xylene-e-nose_三元二甲苯混合物数据集说明.md)。A0 适配器遵守以下规则：

1. 六路信号是同一 QCM 测量原理、不同 MOF 敏感膜的传感器阵列，不是六种物理模态。
2. 标准 `sensor_id` 顺序固定为 `HKUST1`、`CuBDC`、`CuBPDC`、`UiO66`、`UiO67`、`UiO68-NH2`；原始别名只在适配器中规范化。
3. `Time` 原始单位为 min，适配器转换为 s 后进入统一契约；不规则采样保留在 `time` 和 `delta_time` 中。
4. 文件名解析得到 `C_m_ppm`、`C_o_ppm`、`C_p_ppm`。原始 Excel 保持只读，不回写标签或质量标记。
5. `max concentration` 文件没有精确 ppm，不进入普通定量回归适配器。
6. 表头缺失、重复或语义不确定时显式报错；尤其不自动修补 `10 ppm p-xylene.xlsx` 的异常通道语义。
7. A0 smoke 从三个有明确标签、标准表头的不同工作簿各裁剪前 64 个有效时间点。裁剪不改变工作簿分组身份。

## 5. 单样本契约

单样本类型为不可变 `UnifiedSample`。设传感器数为 `S`，第 `s` 个传感器的时间长度为 `T_s`、特征宽度为 `F_s`，目标维度为 `K`。

| 字段 | 类型与 shape | 语义与约束 |
| --- | --- | --- |
| `signals` | `tuple[float32[T_s,F_s], ...]`，长度 `S` | 传感器观测；mask 为假处以 0 存储，不能据此推断有效性 |
| `sensor_id` | `tuple[str, ...]`，长度 `S` | 设备或敏感膜身份；样本内唯一 |
| `sensor_type` | `tuple[str, ...]`，长度 `S` | 物理测量类型，可重复 |
| `valid_mask` | `tuple[bool[T_s,F_s], ...]` | 与各 `signals` 完全同 shape；真表示该数值有效 |
| `quality` | `tuple[float32[T_s], ...]` | `[0,1]`；时间点级质量，1 为当前规则下无已知退化 |
| `time` | `tuple[float64[T_s], ...]` | 单位 s；每个传感器内严格递增且全为有限值 |
| `target` | `float32[K]` | 目标值；未提供的目标位置以 0 存储并由 mask 排除 |
| `target_mask` | `bool[K]` | 真表示对应目标有监督标签 |
| `group_id` | 非空 `str` | 独立实验或混合条件的切分单位 |
| `dataset_id` | 非空 `str` | 只用于适配器、任务头和结果分层 |
| `metadata` | 只读标量映射 | 保留来源身份；Ar-He-CO₂ 必含原始 `mixture_id`，xylene 必含 `workbook_name` |

空传感器、空时间轴、空特征轴、重复 `sensor_id`、shape 不一致、有效位置非有限、质量越界、时间非递增或标签语义错误均为契约失败，不做静默修复。

## 6. 批次契约

`collate_samples` 只做显式 padding，不做插值、缩放或标签推断。设批大小为 `B`，批次最大尺寸为 `S_max`、`T_max`、`F_max`、`K_max`。

| 字段 | shape | padding 与用途 |
| --- | --- | --- |
| `signals` | `float32[B,S_max,T_max,F_max]` | padding 为 0，必须与 mask 联用 |
| `valid_mask` | `bool[B,S_max,T_max,F_max]` | padding 为假 |
| `quality` | `float32[B,S_max,T_max]` | padding 为 0 |
| `time` | `float64[B,S_max,T_max]` | padding 为 0 |
| `delta_time` | `float32[B,S_max,T_max]` | 每条有效序列首项为 0，其余为相邻时间差；padding 为 0 |
| `sensor_mask` | `bool[B,S_max]` | 真表示该传感器位置存在 |
| `feature_mask` | `bool[B,S_max,F_max]` | 真表示该特征轴属于原始传感器输入 |
| `target` | `float32[B,K_max]` | padding 为 0 |
| `target_mask` | `bool[B,K_max]` | padding 为假 |
| `sensor_id`、`sensor_type` | 二维字符串元组 | padding 使用空字符串，只供编码器和审计 |
| `group_id`、`dataset_id`、`metadata` | 长度 `B` 的元组 | 不进入共享融合核心 |

同一批次可以包含不同 `dataset_id`，但任务头调用前必须按任务拆分；禁止通过 padding 使不同目标语义进入同一个损失。

## 7. 四层接口与信息权限

| 层 | 可以读取 | 禁止读取或承担 |
| --- | --- | --- |
| 数据集适配器 | 原始路径、原始字段、数据集标签规则、来源质量信息 | 模型权重、测试结果驱动的预处理 |
| 传感器编码器 | `signals`、mask、quality、time、`sensor_id`、`sensor_type` | `dataset_id`、气体名称、target |
| 共享 `FusionCore` | 传感器表示、`sensor_mask`、编码后的质量 | `dataset_id`、原始路径、目标维度、固定传感器数 |
| 任务头 | 共享表示和配置的输出维度 | 改写融合机制、读取原始数据路径 |

任务头由 pipeline 在 `FusionCore` 外依据 `dataset_id` 选择。允许不同数据集分别训练编码器和任务头参数；“通用”只指接口和融合机制复用，不表示权重零样本迁移。

## 8. Scaler 契约

1. 输入 scaler 按 `sensor_id` 对有效训练值计算均值与总体标准差。
2. `fit` 必须显式接收训练 `group_id` 集合，并记录实际参与拟合的组；集合为空、包含未知组或某传感器方差为零时显式失败。
3. scaler 实例只允许成功 `fit` 一次；验证和测试只能调用 `transform`。
4. `transform` 不改变 mask、time、quality、target、group 或 metadata。
5. 验证和测试数据不得用于缺失值估计、通道统计量或阈值估计。
6. A0 不实现目标 scaler；评价归一化分母属于评价协议，不从测试标签统计得到。

## 9. 错误语义

| 错误 | 触发条件 | 行为 |
| --- | --- | --- |
| `ContractError` | 字段、dtype、shape、mask、时间、目标或 metadata 违反本契约 | 立即抛出，错误消息包含字段与来源身份 |
| `AdapterError` | 原始文件缺失、表头歧义、标签不可解析或定量边界不成立 | 立即抛出，不跳过文件 |
| `SplitLeakageError` | 任一 `group_id` 同时出现在多个 split | 结果作废并抛出 |
| `ScalerStateError` | 未拟合即转换、重复拟合、训练组非法或零方差 | 立即抛出 |
| `KeyError` | 配置引用未知 `sensor_id` 或 `sensor_type` | 立即抛出，不映射到默认 embedding |

不捕获上述错误来返回空批次、默认预测或成功状态。
