## 6. 代码与配置审查

- `FusionCore` 源码不包含 `dataset_id`、气体名称、`mixture_id`、工作簿或固定传感器数分支。
- `src/gf/` 不直接 import `hydrogen_ng`、`syngas`、`tunnel_ventilation`、`rcdw_mgda` 或 `gas_information_bench`。
- Ar-He-CO₂ 的 `group_id` 与原始 `mixture_id` 完全相同，metadata 不包含 `sequence_id`、`base_condition_id`、`noise_seed_index` 或 `noise_seed`。
- xylene 的 `group_id` 为完整工作簿名，原始 Excel 只读，异常表头和近饱和标签显式失败。
- 两类 scaler 均只记录一个配置为 train 的 group；val 和 test 未参与 `fit`。
- 配置按 `configs/data`、`configs/model` 和 `configs/experiment` 分层，没有第二套代码内数据清单。

## 7. 已知边界

1. Ar-He-CO₂ pilot 只验证接口。CO₂ NDIR 有效吸收系数沿用历史经验代理，尚未完成目标硬件滤光片和光程标定，不能作为 A1 正式物理精度证据。
2. 三个 group 只满足 smoke 的 train、val、test 互斥测试，不支持性能估计、置信区间或多模态互补性结论。
3. xylene A0 只读取三个工作簿的前 64 行；正式 A3 必须重新生成 44 个定量工作簿的冻结 split manifest，并执行完整质量审计。
4. 当前最小编码器使用 mask-aware 统计编码和质量加权集合池化，只是接口载体，不是 A2 候选研究方法。
