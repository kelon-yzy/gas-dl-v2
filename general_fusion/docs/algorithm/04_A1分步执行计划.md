> A1 阶段状态：`COMPLETED：2026-08-28`  
> 适用项目：研究生阶段的通用多模态气体融合算法  
> 建议周期：2–3 周  
> 前置条件：A0 已关闭并通过评审

## 0. 文档职责

本文件只负责 A1 的执行顺序、工作量上限、阶段门和交付物，不重复维护已经冻结的契约与评价规则：

- 样本字段、模态张量和分组语义以 [统一任务与接口契约](01_统一任务与接口契约.md) 为准；
- split、指标、统计方式和基线定义以 [评价协议与基线矩阵](02_评价协议与基线矩阵.md) 为准；
- A0 已知限制以 [A0 评审记录](03_A0评审记录.md) 为准；
- 若本计划与上述冻结文档冲突，先修订事实源并评审，不在实现中增加兼容分支。

## 1. A1 目标与边界

A1 的唯一目标是形成一版可复现的 Ar-He-CO₂ 多模态 benchmark，并用低成本证据回答两个问题：

1. 三类传感模态组合后，是否能够辨识具有两个自由度的三组分配比；
2. 简单融合是否稳定优于最佳单模态，且任务没有简单到被传统模型直接做满。

A1 不训练论文主模型，不进行大模型搜索，也不把 A0 的三组 smoke 数据当作性能证据。

### 1.1 工作量上限

- 先生成 240 个唯一配方的 pilot；只有阶段门通过，才生成 1200 个唯一配方的正式 v1。
- 每个配方只生成一个 benchmark 观测，不复制多组噪声样本。
- pilot 只用固定 split 和单个运行种子完成 cheap probe；正式报告涉及随机训练时，才执行评价协议规定的种子。
- 超参数只允许小范围验证集选择：Ridge 最多 3 个 `alpha`，GBDT 最多 2 组浅层配置，MLP 只用 1 组固定配置。
- 不做 Transformer、贝叶斯调参、全组合消融、跨环境鲁棒性扫描或 A4 扰动矩阵。

### 1.2 实现约束

- `mixture_id` 是配方分组主键，不得回退或重写为 `sequence_id`。
- benchmark 不依赖 `base_condition_id`、`noise_seed_index` 或 `noise_seed`。
- split 只按 `mixture_id` 生成一次；同一配方的派生记录不得跨 split。
- scaler 仅拟合训练组；所有指标和模型选择规则沿用 A0 冻结协议。
- A0 中仅用于 smoke 的经验 NDIR 系数不能直接进入正式数据；必须先给出来源或校准依据。
- 没有来源或校准依据的动态时间常数不进入正式 v1。必要时 A1 使用稳态响应，即 `T=1`，不伪造时间序列研究结论。

## 2. 总体执行路径

| 步骤 | 核心问题 | 主要产物 | 预计时间 |
| --- | --- | --- | --- |
| A1-0 | 物理模型是否足以生成正式数据 | 数据与物理规格草案 | 1–2 天 |
| A1-1 | 能否稳定生成小规模、可分组的数据 | 240 配方 pilot 与 manifest | 2–3 天 |
| A1-2 | 模态是否有动态范围、可辨识性和互补性 | 无训练信息审计与 cheap probe | 2–3 天 |
| A1-3 | 最小强基线是否支持继续扩大数据 | pilot 基线汇总与阶段门结论 | 3–4 天 |
| A1-4 | 能否冻结可复现的正式 benchmark | 1200 配方正式 v1 | 2–3 天 |
| A1-5 | A1 是否允许进入 A2 | A1 评审记录 | 1–2 天 |

执行顺序不可颠倒。A1-2 或 A1-3 未通过时，停止扩大数据规模，回到物理模型与模态设计。

## 3. 数据规模与采样设计

### 3.1 固定环境

A1 v1 先固定温度、压力、光程和采样条件，隔离“组分辨识”这一核心变量。环境漂移、缺失模态和强噪声属于 A4，不在 A1 展开。

具体数值、单位、来源、有效范围、测量分辨率和不确定度统一写入 `05_A1数据与物理规格.md`，配置文件只引用这些已评审参数。

### 3.2 配方空间

| 数据层级 | 二元边界配方 | 三元内部配方 | 合计 | 用途 |
| --- | ---: | ---: | ---: | --- |
| pilot | 60，每个气体对 20 | 180 | 240 | 信息审计与 cheap probe |
| 正式 v1 | 300，每个气体对 100 | 900 | 1200 | A1 正式 benchmark |

另生成 Ar、He、CO₂ 三个纯气体参考点，仅用于单位、方向和端点检查，不参与模型训练、模型选择或主指标计算。

采样要求：

- 二元边界不重复纯气体端点；三元内部点不落在边界上。
- 三元内部使用固定种子的单纯形空间填充采样，避免规则网格在边界过密。
- 每个组分满足非负与闭合约束，内部统一使用摩尔分数计算，对外标签统一为 `mol%`。
- pilot 与正式 v1 使用独立数据版本；正式 v1 重新生成并冻结，不把 pilot 文件拼接进去。

### 3.3 传感模态

A1 仍以超声 ToF、热导电压、CO₂ NDIR 电压为三类候选模态。每类模态在进入 pilot 前必须记录：

- 物理方程或校准关系；
- 输入量、输出量和单位；
- 参数来源与有效范围；
- 纯气体端点、单调方向和预期动态范围；
- 测量分辨率与 A1 唯一的不确定度配置。

NDIR 参数证据未补齐时，A1-1 不得开始；禁止自动沿用 A0 经验值。动态参数证据未补齐时，正式数据固定为稳态响应，不设置隐式默认时间常数。

## 4. 分步执行

### A1-0：冻结数据与物理规格

**动作**

1. 审核当前 `src/gf/sim/ar_he_co2.py` 中三类传感方程、常量、单位和 A0 smoke 参数。
2. 为 NDIR 有效吸收参数补充可追踪来源或小规模校准说明；无法完成则暂停 A1，不做数值替代。
3. 决定正式 v1 使用稳态数据还是有依据的短序列，并在规格文档中写明理由。
4. 根据测量分辨率预先定义各模态的有效动态范围门和任务误差地板，避免看到模型结果后再改标准。
5. 冻结 pilot 与正式 v1 的采样配置、manifest 字段和数据版本名。

**产物**

- `docs/algorithm/05_A1数据与物理规格.md`
- `configs/data/ar_he_co2_a1_pilot.json`
- `configs/data/ar_he_co2_a1_v1.json`

**完成条件**

- 三类模态均有方程、单位、参数来源、范围和分辨率记录；
- A0 经验 NDIR 参数不再是正式数据的事实源；
- 是否保留时间维已有明确、可复核的决定；
- 配置中不存在单样本噪声种子字段或旧主键字段。

### A1-1：实现生成器并产出 pilot

**动作**

1. 在现有 `gf.sim` 边界内补充配方采样、传感响应和数据打包，不复制第二套 schema。
2. 使用 manifest 级随机种子一次性生成 240 个 `mixture_id`。
3. 按冻结协议生成 train、val、test 分组，并保存 split 清单。
4. 输出数据文件、manifest、生成配置快照和内容哈希。
5. 执行一次边界质量检查；任何失败直接报错并停止，不自动修复或跳过样本。

**只检查以下不可恢复的不变量**

- 组分有限、非负且闭合；
- 模态数值有限、单位一致、样本数量与 manifest 一致；
- `mixture_id` 唯一且 split 无交叉；
- 纯气体端点和三类模态方向符合物理规格；
- scaler 尚未接触 val 或 test 数据。

**完成条件**

- pilot 可由一条命令重新生成；
- 数据计数、哈希、配置和 split 可由 manifest 复核；
- 所有边界检查一次通过，没有静默丢样本。

### A1-2：无训练信息审计

**动作**

1. 在三元内部点计算有限差分敏感度，并按量纲归一化。
2. 计算组合模态相对于两个独立组分自由度的 Jacobian 数值秩与条件数分布。
3. 汇总每类模态的动态范围、测量分辨率比、饱和比例和退化方向。
4. 分别绘制单模态与组合模态在配方单纯形上的响应，检查大面积重叠或盲区。
5. 形成一页信息审计表，不开展额外模型训练。

**进入 cheap probe 的门**

- 至少 95% 的三元内部 pilot 点上，组合模态归一化 Jacobian 数值秩为 2；
- 每个保留模态的有效动态范围不低于其测量分辨率的 5 倍；
- 不存在未解释的非有限值、全常量通道或大面积饱和区；
- 三类模态的退化方向不完全相同，能够提出可检验的互补性假设。

任一条件失败时，记录失败区域并返回 A1-0；不通过增加模型容量绕过信息不足。

### A1-3：cheap probe 与最小强基线

**pilot 模型范围**

- B0：训练集均值；
- B1、B2：每个单模态分别运行 Ridge 和 GBDT；
- B3、B4：全模态 Ridge 和全模态 GBDT；
- B6：等权后融合；
- B7：仅用验证集确定固定融合权重。

pilot 不运行 B5 或 B8，也不做多种子统计。所有模型只使用冻结特征和小规模超参数集合，选择依据仅来自 val。

**动作**

1. 记录最佳单模态、全模态和简单融合的 val/test 指标及逐组分误差。
2. 比较各模型逐 `mixture_id` 的误差，确认不同模态是否在不同区域互补。
3. 检查全模态 GBDT 是否已落入 A1-0 预注册的误差地板；若是，判定任务过易。
4. 生成一张基线表、一张单纯形误差图和一段阶段门结论。

**扩大为正式 v1 的门**

- B3 或 B4 的 val `macro_RNMAE` 相对最佳单模态 B1 或 B2 至少改善 5%；
- 改善不是由单一组分独占，至少两个组分的 RNMAE 不高于最佳单模态对应结果；
- 全模态模型没有进入预注册误差地板，仍为 A2 留有可研究空间；
- 结果来自冻结 split，没有样本级拆分或 scaler 泄漏。

若不通过，只允许调整物理规格、采样空间或模态设计后重做一次 pilot。第二次仍不通过，则 A1 记录为失败，停止进入 A2。

### A1-4：生成并冻结正式 v1

**动作**

1. 使用通过评审的配置重新生成 1200 个唯一配方，不合并 pilot。
2. 固化数据版本、manifest、split、配置快照和内容哈希。
3. 运行评价协议中的最小完整基线矩阵；B5 使用单一固定网络配置，B8 仅在正式数据保留有依据的时间维时适用。
4. 确定性模型只运行一次；随机训练模型按冻结评价协议执行，不额外扩充种子。
5. 汇总主指标、逐组分指标、参数量和训练时间，不展开大规模消融。

**完成条件**

- 正式 v1 可由 manifest 和配置复现；
- train、val、test 的 `mixture_id` 交集为空；
- 最小完整基线都有结果或有明确的“不适用”依据；
- 数据规模、版本和 manifest 此后不因 A2 模型结果而修改。

### A1-5：评审并关闭阶段

建立 `docs/algorithm/06_A1评审记录.md`，逐项记录：

- 物理参数与校准依据是否完整；
- pilot 信息审计和两次以内的 cheap probe 结论；
- 正式 v1 的版本、规模、manifest 与 split 证据；
- 最佳单模态、传统全模态和简单融合的比较；
- 是否存在任务过易、模态冗余或局部不可辨识区域；
- `PASS`、`CONDITIONAL_PASS` 或 `FAIL` 结论及进入 A2 的限制。

只有 A1 评审为 `PASS`，才把 A2 标记为 `NOT_STARTED` 的下一阶段并开始研究模型实现。

## 5. 最小测试与验证

A1 只新增两个测试文件，不建立大规模测试体系：

| 测试文件 | 覆盖范围 |
| --- | --- |
| `tests/test_a1_data_contract.py` | 配方闭合、数值有限、ID 唯一、split 隔离、manifest 计数和物理端点 |
| `tests/test_a1_pipeline_smoke.py` | 极小数据从生成、特征、train-only scaler 到一个 Ridge 指标的端到端闭环 |

验证顺序：

1. 每个步骤只运行对应目标测试，单次目标测试控制在 60 秒内；
2. A1-4 冻结前运行一次 `python -m pytest -q`；
3. 再运行一次 pilot 或正式生成命令，核对 manifest 哈希与固定配置复现性；
4. 不增加 fuzz、随机属性测试、全参数组合测试或重复的逐层校验。

## 7. A1 最终阶段门

A1 关闭必须同时满足：

- [x] 三类正式模态均有可追踪物理或校准依据；
- [x] pilot 的可辨识性、动态范围和退化方向审计通过；
- [x] cheap probe 证明简单全模态方法优于最佳单模态；
- [x] 正式 v1 的 1200 个 `mixture_id`、split、版本和 manifest 已冻结；
- [x] 不存在 split 交叉、scaler 泄漏、旧主键依赖或单样本噪声种子字段；
- [x] 最小完整基线矩阵已完成，且任务未被传统模型做满；
- [x] 两个目标测试和一次全量测试通过；
- [x] A1 评审记录给出明确 `PASS` 结论。

未满足任一硬条件时不得以“后续模型可解决”为理由进入 A2。

执行证据见 [A1 数据与物理规格](05_A1数据与物理规格.md) 和 [A1 评审记录](06_A1评审记录.md)；formal v1 的数据、summary 与 report 位于 data/a1_formal、outputs/summary/a1_formal 和 outputs/reports/a1_formal。
