# A0 评价协议与基线矩阵

> 协议版本：`gf-eval-1`  
> 冻结日期：2026-08-27  
> 状态：`PREREGISTERED`  
> 任务与字段：[A0 统一任务与接口契约](01_统一任务与接口契约.md)  
> 适用阶段：A1–A4；A0 仅验证协议可执行性

## 1. 评价原则

1. 所有比较共享同一数据版本、group split、训练组 scaler、目标定义和评价代码。
2. 正式测试集只在模型结构、超参数、seed 集和主图表模板冻结后评价一次。
3. Ar-He-CO₂ 与 xylene 的绝对误差量纲不同，不直接比较 mol% 与 ppm。
4. 统计独立单位分别是 `mixture_id` 和完整工作簿，不把窗口或时间点当作独立重复。
5. A0 smoke 只检查接口、有限输出、mask 和梯度，不生成性能排名，也不触发算法晋级。

## 2. 数据切分

### 2.1 Ar-He-CO₂

- 分组键：`mixture_id`。
- 比例：train 70%、val 15%、test 15%。
- 算法：对排序后的唯一 `mixture_id` 使用 `GroupShuffleSplit(random_state=20260827)`；先抽取 15% test，再在剩余 85% 中以 `test_size=3/17` 抽取 val，得到总量约 70/15/15。
- 同一 `mixture_id` 的全部传感器、时间窗口、噪声实现和派生特征必须处于同一 split。
- 正式数据 manifest 必须保存每个 `mixture_id` 的 split，训练入口只读取 manifest，不在每次运行时重新切分。

### 2.2 `xylene-e-nose`

- 分组键：完整工作簿文件名。
- 普通定量回归先排除三个 `max concentration` 文件；其余 44 个工作簿参与主 split。
- 分层键只使用组分族：纯组分、二元混合、三元混合。浓度和具体配比用于结果分层，不用于把同一工作簿复制到多个集合。
- 在每个组分族内，按 `SHA256("20260827:" + workbook_name)` 升序排列，以 70/15/15 的最大余数法分配 train、val、test；组内样本数不少于 3 时每个 split 至少一个工作簿。
- 生成的工作簿清单保存为正式 split manifest，训练入口不得重新随机切分。
- 同一工作簿的所有裁剪窗口、插值结果和派生特征继承该工作簿 split。

### 2.3 A0 smoke split

A0 配置为每类数据显式登记三个不同 group，分别标记 train、val、test。该 split 只测试互斥、scaler 和接口，不作为正式实验的抽样结果。

### 2.4 泄漏检查

以下任一条件触发 `SplitLeakageError` 并使结果作废：

- train、val、test 的 `group_id` 集合存在交集；
- scaler、缺失值统计、阈值或特征选择使用 val 或 test；
- xylene 同一工作簿的窗口跨 split；
- Ar-He-CO₂ 同一 `mixture_id` 的派生样本跨 split；
- 正式 test 被用于模型选择、early stopping 或收益门调整。

## 3. 指标

### 3.1 主指标

主指标为宏平均范围归一化 MAE：

```text
RNMAE_i = mean_g(|y_gi - yhat_gi|) / R_i
macro_RNMAE = mean_i(RNMAE_i)
```

`g` 是独立 group；一个 group 有多个窗口时，先对该 group 内预测求预注册聚合，再计算 group 误差。范围分母来自任务设计，不从 test 标签估计：

| 数据集 | `R_i` | 依据 |
| --- | --- | --- |
| Ar-He-CO₂ | 三个组分均为 100 mol% | 合法范围 `[0,100]` |
| xylene | 三个组分均为 1000 ppm | 有精确标签文件的登记上限为 1000 ppm |

主指标越低越好。若未来改变任务范围，必须提升协议版本，不能用新分母覆盖旧结果。

### 3.2 辅助指标

- 各组分 MAE、RMSE、R²；
- 预测组分和与真实总量的绝对偏差；
- Ar-He-CO₂ 按纯气、二元、三元及浓度区间分层；
- xylene 按纯组分、二元、三元、总浓度和工作簿分层；
- 最差组 MAE、P90 group MAE、失败 group 比例；
- 参数量、训练时间、单样本推理时间和峰值显存。

R² 在标签方差为零的分层中记为 `NA`，不得替换为 0。低浓度相对误差不作为主指标，避免目标接近 0 时发散。

### 3.3 A4 稳健性指标

- 完整输入到退化输入的 `macro_RNMAE` 增量；
- 已见组合、未见组合、完全缺失、数值退化和冲突观测的最差组误差；
- 质量或拒识输出的校准误差、覆盖率和失败率；
- clean 条件相对 A2 冻结模型的性能代价。

## 4. Seed 与统计区间

| 项目 | 冻结值 |
| --- | --- |
| split seed | `20260827` |
| 训练 seeds | `17, 29, 43, 71, 101` |
| bootstrap seed | `20260827` |
| bootstrap 次数 | `2000` |
| 置信度 | 双侧 95% percentile CI |
| 重采样单位 | Ar-He-CO₂ 为 `mixture_id`；xylene 为工作簿 |

正式比较使用相同 seed 的方法与基线配对。先在每个独立 group 上计算方法与基线的误差差，再按 group bootstrap；窗口不得作为 bootstrap 单位。

五个训练 seed 必须全部报告。运行失败不能从均值中静默删除：只有确认是非算法性基础设施故障、修复未改变配置且保留失败证据时，允许以同一 seed 重跑一次；否则该方法不满足正式晋级条件。

## 5. 基线矩阵

| 编号 | 基线 | 输入 | 目的 | 强基线资格 |
| --- | --- | --- | --- | --- |
| B0 | 训练组目标均值 | 无传感器输入 | 最低 sanity baseline | 否 |
| B1 | 单传感器 Ridge | 每个传感器分别建模 | 测量单传感器信息量 | 是 |
| B2 | 单传感器 GBDT | 每个传感器分别建模 | 非线性单传感器上限 | 是 |
| B3 | 全输入 Ridge | 同一预处理后的全部传感器特征 | 强线性组合 | 是 |
| B4 | 全输入 GBDT | 同一预处理后的全部传感器特征 | 强树模型组合 | 是 |
| B5 | 简单拼接 MLP | 各传感器编码后直接拼接 | 无融合机制的容量对照 | 是 |
| B6 | 等权后融合 | 各单传感器预测等权平均 | 无学习权重对照 | 是 |
| B7 | 固定权重后融合 | 权重仅由 val group 的逆 MAE 确定，test 前冻结 | 静态可靠性对照 | 是 |
| B8 | 轻量时序网络 | 原始序列，参数量与主方法同量级 | 时序容量对照 | 条件性；序列任务启用 |

多输出传统模型必须对三个目标使用一致的训练组、特征与超参数搜索预算。固定权重不得由 test 误差计算。最佳强基线是在 B1–B8 的合格运行中按 val 主指标选择的单一方法，不能在 test 上逐组分拼接不同赢家。

## 6. 收益门与等价带

### 6.1 A2 主方法晋级门

相对最佳强基线，主方法必须同时满足：

1. 五 seed 平均 `macro_RNMAE` 相对下降至少 5%；
2. group 配对误差差 `method - baseline` 的 95% CI 上界严格小于 0；
3. 任一组分的 `RNMAE_i` 绝对退化不超过 `0.005`；
4. 收益在至少 4 个训练 seed 上方向一致；
5. 单项消融能将收益归因到提出的融合机制，而不是参数量、split、scaler 或预处理差异。

5% 是项目预注册的实质收益门，用于排除只达到数值舍入或轻微运行波动的提升，不声称是领域通用阈值。

### 6.2 A3 外部验证门

xylene 独立训练必须使用同一融合机制和同类基线。若未满足 §6.1 的全部条件，不隐藏结果，也不修改门槛；结论收缩为“接口与架构可复用，但稳定收益未在该外部数据上成立”。

### 6.3 A4 clean 等价带

A4 扩展在完整输入 clean 条件下相对 A2 冻结模型的 `macro_RNMAE` 绝对增加不得超过 `0.005`。该等价带只约束 clean cost；退化条件仍按 A4 预注册对照比较。

## 7. 模型选择与测试纪律

1. 超参数只根据 train 和 val 选择；test 不参与 early stopping、特征选择、权重计算或候选排序。
2. 同一阶段最多保留一个主方法和一个明确登记的备选。
3. 所有候选使用相同搜索预算；主方法不得获得额外 test 反馈轮次。
4. 正式 test 评价后，只允许修复会使全部受影响方法共同重跑的协议或实现错误。
5. 汇总表由运行产物生成，不手工维护第二套数值。

## 8. 停止规则

- A1 cheap probe 未显示超出最佳单传感器的互补信息时，停止大规模深度训练并返回物理观测设计。
- Ridge、GBDT 或最佳单传感器已达到任务分辨率上限时，不通过扩大网络制造收益空间。
- 任一 split 泄漏、test 参与 scaler 或标签语义错误都会使对应结果整体作废。
- A2 未超过强基线时保留负结果，不跳到 xylene 搜索偶然正结果。
- xylene 只能通过数据集专属融合分支获得收益时，不支持通用核心主张。
- 收益门、等价带、seed 或 CI 规则不得在看到正式 test 后静默修改。
