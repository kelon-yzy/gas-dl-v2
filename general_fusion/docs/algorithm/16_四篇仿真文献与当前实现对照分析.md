# 四篇仿真文献与 general_fusion 当前实现对照分析

> 分析日期：2026-09-05。对象：当前工作区代码及 A2-DYN 已保存产物。
> 本文是分析报告，不修改既有协议、数据、阈值、阶段状态或算法晋级规则。

## 1. 结论

现有资料支持 general_fusion 的共同状态、多机理前向模型、扰动分层和局部可辨识性分析方向。当前 A2-DYN 已实现其中相当一部分，而且在组成守恒、分组切分、因果前缀和失败记录方面比资料中的通用方案更具体。无需按方案重新搭一套仿真系统。

目前最主要的缺口是：**合成设备参数缺少实测校准，部分设备输出仍是代理模型，开发结果尚未证明时序模型在预注册范围内具有稳定增益。** 增加非线性交互项、提高采样率或扩大网络，都不能直接补上这些证据。

有两个必须分开的现状：

- 数据资格：完整 v1 为 `DATA_FREEZE_FAILED`，正式 test 模型评价和 A2-DYN-6 handoff 仍阻塞。
- 算法开发：基线运行完成，整体时间门为 `TEMPORAL_REDUNDANT`；但存在 `D-PROTOCOL / P015` 的局部正结果，不能解释成所有时序信息都无价值。

优先级应是明确任务需要的动态信息、核实代理模型和参数依据、为后续版本建立可辨识的工作域，再决定算法机制。

## 3. 四篇文献真正能带来的启示

### 3.1 Llobet：随机扰动需要表达测量过程

本地流程图将浓度配制误差、工作温度变化、测量误差和漂移放在不同环节。这对项目有价值：误差应有发生位置、重复层级和物理单位，而不是仅在输出端统一乘噪声系数。论文题录已核验，详细方法仍以本地整理为依据。[论文 DOI](https://doi.org/10.1016/S0925-4005(01)00650-5)

当前项目已具备白噪声、AR(1)、共享相关项、序列内漂移和标定档位；下一步的证据缺口是这些幅度和相关性是否代表拟用硬件。更多噪声档位本身不等于更真实。

### 3.2 Chaiyboun：传感器响应模型先于浓度反演

出版商登记摘要确认该工作使用交叉敏感阵列和矩阵法，根据五传感器响应估计 CH₄、NH₃、H₂、CO、乙醇浓度。本地流程图进一步强调由真实实验拟合前向模型。[论文 DOI](https://doi.org/10.3390/s6040270)

对 general_fusion 最值得迁移的是“有依据的前向模型—反演—验证”闭环。经验对数模型和灵敏度矩阵不能直接替换超声 EOS、WMS 热导和 NDIR 光谱积分。尤其不应规定每个模态对每种气体都必须有非零交叉敏感：机理允许的弱敏感或零敏感本身就是选择性。

### 3.3 Fernandez：关注局部信息与特征选择

原文使用降维、响应凸包和噪声体积估计分辨能力，并按工作区处理非线性与异方差。一个容易在整合方案中丢失的结果是：案例 III 最佳两个跨传感器特征的 RP 为 105，高于案例 II 完整波形经 PCA 后的 62。这个例子说明更多采样点并不保证所选表征更有用；它比较的是该实验下的特征与降维方法，并未证明原始完整信号在信息论上更差。[原文，Case Studies II–IV](https://www.frontiersin.org/journals/chemistry/articles/10.3389/fchem.2018.00209/full)

项目应借鉴其局部、噪声感知的评价思路。对连续组成回归，PCA 散点更分散、解释方差更高或聚类评分更好，都不能单独证明组成可辨识或预测增益。

### 3.4 Wen：主动调制与被动换气是不同的动态信息来源

出版商登记摘要明确：该工作给 MOX 加热器施加方波，通过温度变化产生气体相关动态响应，再建立混合物交互模型。[论文 DOI](https://doi.org/10.3390/mi10090598)

当前 A2-DYN 的主要时间变化来自进气协议、共同气室、局部输运和固定硬件下的器件响应。这与主动扫描 MOX 工作温度不等同。Wen 可以支持“研究动态信息来源”，不能直接支持“给三个平衡标量套上不同滞后后，TCN 必然比 MLP 好”，也不能为 Ar–He–CO₂ 三模态追加任意多项式交互项提供依据。

## 5. 需要明确的实现边界

### 5.1 超声：波形探针与批量序列是两条不同保真度路径

`acquire_ultrasonic_tof` 确实实现短波形、重复平均和互相关估计。但正式批量生成调用 `estimate_ultrasonic_tof_series`：把理论 ToF 乘 ADC 采样率后，按一采样点或四分之一采样点取整，再换算回秒。

`estimate_ultrasonic_quality_series` 另用幅度、内部噪声和多径能量近似计算 SNR、相关峰和锁定状态；这些量没有在该批量函数中直接驱动随机 ToF 估计误差。随后低频 ToF 仍接受统一观测扰动链。

所以准确表述应为“短波形探针支持的低频 ToF 离散代理”，不能写成“每个正式采样点都由带噪波形互相关直接产生”。后续若要研究波形质量带来的可靠性，需要在开发侧验证代理与真实估计器在 SNR、多径及亚采样相位上的误差对应关系。

代码定位：[设备模块](../../src/gf/sim/a2_sensor_devices.py) 214、361、384 行；[生成器](../../src/gf/sim/a2_dynamic_dataset.py) 1647 行。

### 5.2 热导：能量守恒成立不等于完整硬件输出已验证

`simulate_tcd` 根据热容和总热导更新加热器温度，确实具有组成相关时间常数。但最终输出是：

$$
V_{clean}(t)=V_{property}(t)+K\,[V_{bridge}(t)-V_{bridge,eq}(t)].
$$

它保留原物性电压标定，并附加电桥瞬态修正；不是简单地对真实电桥信号施加一次固定增益与偏置。稳态时修正项趋零，输出回到原物性映射。物性直通项还可能保留对当前局部状态的即时依赖，其是否削弱时间模型优势是待验证假设，不能仅凭公式下因果结论。

现有能量残差很小，验证的是内部热状态方程的数值一致性，不能据此断言该复合电压就是实测电桥输出。这里应明确保留 A1 标定兼容性的取舍，并用独立阶跃标定或物理电桥输出对照验证。

代码定位：[设备模块](../../src/gf/sim/a2_sensor_devices.py) 684–738 行。

### 5.3 温压、湿度与器件参数：不能将接口能力写成正式数据覆盖

部分底层函数支持温度数组、压力数组及流量参数，但 `_build_clean_trajectory` 传入的是环境 profile 的标量温压，TCD 调用未传入变化流量。白噪声与 AR(1) 创新项主要按通道基础标准差和 profile 倍数设置，并没有全面实现随瞬时浓度和环境变化的方差模型。

当前三组分闭合任务可以明确限定为干燥 Ar–He–CO₂。若将湿度纳入新任务，必须定义干基或湿基标签以及水蒸气如何进入状态方程，不能在闭合三元状态旁随意增加一个 RH 扰动却不解释组成语义。

器件 profile 中许多参数标注为 `sensitivity_tier_1/2`。它们是显式假设而非实测事实，当前应保留这种标注。[生成器](../../src/gf/sim/a2_dynamic_dataset.py) 282、1554 行；[硬件配置](../../configs/data/ar_he_co2_a2_dynamic_v1.json)。

### 5.4 采样命名与代码不一致

配置将采样称为 `stratified_low_discrepancy_simplex`，但 `_generate_region_compositions` 使用种子随机数：内部区为平移缩放的 Dirichlet，近边界与二元边采用均匀抽样，并做量化和去重。当前这部分代码不能直接描述为 Sobol、LHS 或确定性低差异采样。

分层 Dirichlet 本身并非错误，也无需仅因参考方案推荐 LHS 就替换它。需要先使论文方法、配置命名和真实算法一致；若后续版本确实改采样方式，再比较覆盖率与区域误差。不要为文字对齐重生成已冻结的 v1 内容。

代码定位：[数据配置](../../configs/data/ar_he_co2_a2_dynamic_v1.json) 612 行；[生成器](../../src/gf/sim/a2_dynamic_dataset.py) 1463 行。

## 6. 最新实验结果如何解释

### 6.1 冻结失败：噪声压力与资格门不相容

[R2 冻结审计](../../outputs/summary/a2_dynamic_v1/a2_dyn_4r2_freeze_audit.json)确认 schema、物理检查与纯气边界通过，唯一失败要求为 `test_dynamic_non_degenerate`：

| 指标                 | R2 结果  | 要求     |
| ------------------ | ------:| ------:|
| 至少两路动态活跃的全局比例      | 0.9329 | ≥ 0.95 |
| D-JOINT 退化比例       | 0.1954 | ≤ 0.05 |
| D-NOISE-DRIFT 退化比例 | 0.1111 | ≤ 0.05 |

活跃判据实际为 `ptp(clean) > 5 × noise_base × row_scale`。在 NOISE-10X 下，这是基础标准差的 50 倍，亦即该行白噪声标准差的 5 倍。它是预注册动态幅值筛选，不是全部相关噪声下的严格信息论极限；不能将失败直接改述为“所有信号都落到噪声以下”或“所有算法绝对不可能恢复”。

保持 v1 失败事实是正确的。后续版本可预先区分有效工作域与超出工作域的极端压力集，并在独立 pilot 中检查噪声档与可辨识性的关系；不能看完正式 test 后修改阈值或剔除失败行来使 v1 通过。

### 6.2 时间门失败：保留局部收益，限制总体结论

[开发侧基线汇总](../../outputs/summary/a2_dynamic_v1/a2_dyn_5_baselines.json)记录五个训练 seed、1,309,528 行预测和 `DEVELOPMENT_BASELINES_COMPLETE`。正式 test 未进入本轮模型评价；产物的 `test_rows_read=0` 描述其评价范围，不应扩展成底层 NPZ 从未被整体加载的磁盘访问承诺。

以下数值来自已保存的 val 配对时间门，不是本次重新训练结果：

| 候选与条件                  | 相对 B-REF 改善 | 解释                                          |
| ---------------------- | -----------:| ------------------------------------------- |
| B-STAT，D-IID，P015      | +5.34%      | 5/5 seed 同向，但配对置信区间跨零，失败                    |
| B-STAT，D-IID，P030      | −29.52%     | 劣于 B-LAST                                   |
| B-STAT，D-IID，P060      | −39.01%     | 劣于 B-LAST                                   |
| B-STAT，D-PROTOCOL，P015 | +30.34%     | 本轮唯一通过的候选 × family × horizon 格点；5/5 seed 同向 |

整体门要求 IID 与压力族在足够多个前缀同时达标，因此仍为 `TEMPORAL_REDUNDANT`。这个状态表示注册候选未满足联合条件，不是对所有算法的数学否定。

还有一个输入边界：TCN/GRU 的前缀被 `causal_sequence_matrix` 重采样为 64 点。该实现遵守无未来填充，但其结果只覆盖该表示和训练配方，不能写成“完整 1200 点时序经过充分验证仍无信息”。[时序基线](../../src/gf/dl/temporal_baselines.py) 43、485 行；[时间门实现](../../src/gf/pipeline/a2_dynamic_baselines.py) 1053、1120 行。

### 6.3 Oracle 余量不等于普通模型可获得的增益

O-KIN-OBS 虽然使用有噪观测，仍读取真实动力学、温压和校准相关的特权参数，并使用注册前向物理模型反演。因此它同时享有状态知识与模型知识，不能把其优势都归因于“历史序列信息”。

汇总中的约 0.80 headroom 对应 stress_val/P060，比较对象包括 B-EWMA、B-STAT、B-TCN；它不是对最强 B-LAST 的统一改善保证。数值按 879 个 oracle 有效行比较，另有 21 行反演无效，必须连同成功率报告。[Oracle 实现](../../src/gf/sim/a2_dynamic_audit/_baselines.py) 540、591 行；[余量汇总实现](../../src/gf/pipeline/a2_dynamic_baselines.py) 1226 行。

同样，约 0.0271 ms 的回放延迟来自当前值特征加 Ridge 的 smoke，只支持该回放路径，不能作为 TCN、GRU 或未来融合算法的端到端实时性证据。[回放代码](../../src/gf/pipeline/a2_dynamic_baselines.py) 398–425 行。

## 7. 为什么增加时序还没有自然产生算法优势

下述为由代码结构提出的解释假设，不是已经完成因果消融的结论。

**第一，变化的轨迹仍可能主要编码同一个低维配方。** 进气为固定 purge 与固定 target 之间的插值，共同气室和每一路局部输运对三个组分使用相同的该层时间常数。给定动力学时，其局部组成可写为：

$$
\mathbf{x}_{local,m}(t)=\mathbf{x}_{purge}+a_m(t)\,[\mathbf{y}_{target}-\mathbf{x}_{purge}].
$$

这保持守恒，但也使大量时间点沿同一配方方向变化。三元组成仅有两个独立自由度，三路当前值在部分工作区可能已足够约束它。未知动力学会增加反演难度，却不保证更大的时序网络能稳定获得额外信息。

**第二，任务是在过渡期预测最终配方。** 这与估计当前气室浓度、任意连续混合物跟踪、温度调制后的物种识别不同。动态价值应围绕达到给定误差所需时间、协议变化或局部歧义来证明，而不是仅比较 FULL 和一个较早前缀。

**第三，传感器质量变化与组成反演尚未完全耦合。** 超声批量质量代理与 ToF 输出扰动分开，TCD 保留原物性直通标定。二者都可能使真实硬件中的困难没有按同一方式进入观测。

**第四，特权信息和可见输入存在差距。** Oracle 已知真实动力学与环境，普通基线没有同等信息。当前余量可能包含未知参数估计问题，需要拆分后才能据此提出融合机制。

上述解释与 Fernandez 的局部特征结果、Wen 的主动调制机制并不矛盾。文献更支持先定位有效信息，再决定如何使用时序。

| ----------------------- | ------------------------------------------------------- |
| 所有模态由统一状态驱动             | 保留；允许各模态有明确的局部输运状态                                      |
| 主敏感加交叉敏感                | 由各模态物理机理决定，禁止为了互补性强行填满灵敏度矩阵                             |
| 添加混合气多项式交互项             | 不直接采用；先查 EOS、热导混合和光谱模型已含的耦合，避免重复计算                      |
| 每个通道统一套一阶响应             | 不覆盖现有设备链；一阶参数应对应气室、局部输运或具体器件状态                          |
| 恢复时各组分都按目标值指数衰减         | 对闭合三元配比不成立；应向 purge 组成恢复，并使用恢复开始时的真实状态                  |
| 受约束 LHS                 | 属可选采样设计，不是四篇论文共同要求；先纠正当前采样命名并核查覆盖                       |
| PCA 更好即可证明动态更有效         | 不成立；保留作图用途，以条件一致的回归、配对统计和局部信息审计检验                       |
| RP 等于简单全局体积比            | 只能作概念表达；实际计算需固定维度、工作域与噪声定义，处理相关性和局部非线性                  |
| 测试集统一更高噪声、更强漂移          | 分开 IID、单轴 OOD 与极端失效域；各自预注册，不让一个难度混合值掩盖来源                |
| 每个样本保存随机 seed           | 沿用项目 generation/split 级可复现机制；不引入被现有 schema 禁止的单样本噪声种子字段 |
| 直接采用建议的 simulation 目录结构 | 不采用；复用现有 `gf.sim/dl/ml/pipeline`，避免第二套事实源               |

闭合恢复的正确一般形式为：

$$
\mathbf C(t)=\mathbf C_{purge}+[\mathbf C(t_0)-\mathbf C_{purge}]\,e^{-(t-t_0)/\tau}.
$$

原方案若用于稀释背景中的痕量分析物浓度，逐分析物衰减可以成立；用于当前总和为 100% 的完整气体组成向量时，必须显式包含补入的 purge。

| P2  | 准备小规模真实校准数据                    | A5 硬件准备及独立标定记录                | 先登记纯气、二元、三元、温压和重复测量协议；校准集与盲测集隔离              |

局部信息分析中可沿用现有 Jacobian：在固定环境和动力学的条件下，以两个独立组成坐标计算灵敏度，并结合实际观测噪声协方差评价局部分辨率。若有未知环境或动力学，需继续考虑 nuisance 方向，不能用固定参数的满秩代替未知参数下可辨识性。RP/PCA 作为补充，不取代这些审计。

目前每配方仅 1–3 次观测，而且许多配方没有重复。这个重复量不支持直接可靠估计高维全时序噪声协方差；应另建固定配方与条件的开发侧 Monte Carlo 审计样本，或在已注册噪声模型下计算协方差，不能把配方变化当测量噪声。

如考虑借鉴 Wen 做主动调制，应先明确本系统可操作的物理激励及其测量收益，例如 TCD 加热功率，而不是照搬 MOX 的温度数值。该变化属于新的硬件和任务定义，必须单独规划，不能为了让深度模型胜出临时写入 v1。
