## 1. 当前目标与边界

### 1.1 要交付的研究结果

开发一套可配置的多传感数据融合深度学习架构，并形成以下证据链：

1. 在 Ar-He-CO₂ 多模态仿真数据上完成训练、强基线比较、主流深度架构对照和机制消融。
2. 在 `xylene-e-nose` 上重新训练同一融合核心，验证架构能否适配不同气体对象和传感体系。
3. 在传感器组合变化或信号质量下降时，验证融合核心的可靠性自适应能力。
4. 用少量真实 Ar-He-CO₂ 纯气及混合气数据完成最终应用验证。

当前默认以三组分浓度回归为主任务；气体分类只作为数据标签允许时的辅助任务。主任务、标签口径和主评价指标已在 A0 冻结。

### 1.2 不可变约束

- 数据集适配器和任务头可以变化，融合核心的基本机制不得为每个数据集另写一套。
- 融合核心不得硬编码气体名称、固定通道数或特定数据集路径。
- `xylene-e-nose` 的六路 QCM 信号按多传感器阵列处理，不表述为六种物理模态。
- 跨数据集分别训练只证明架构复用，不证明零样本迁移。
- 真实数据不承担深度学习的主要训练；若使用少量校准数据，必须与盲测数据分离。
- 新正式主线不得把 `mixture_id` 回退或重写为 `sequence_id`。
- 新正式 benchmark 不依赖 `base_condition_id`、`noise_seed_index` 或 `noise_seed`。
- 复杂焊接工况、焊缝质量预测、在线控制和 TV3 新实验不进入当前主线。
- 可变传感器集合方向承担学位论文第 3 章工作量，当前不单独展开“小论文二”计划。

## 3. A0——统一任务、数据与算法接口契约

### 3.1 目标

在大规模生成数据和训练前，先证明 Ar-He-CO₂ 与 `xylene-e-nose` 能通过同一套数据接口进入同一个融合核心。A0 只做最小样本 smoke，不追求性能。

### 3.2 必须冻结的契约

统一样本至少表达以下信息：

- `signals`：一个或多个传感器序列或特征张量；
- `sensor_id` 与 `sensor_type`：传感器身份和物理类型；
- `valid_mask` 与 `quality`：可用性、缺失和质量信息；
- `time` 或 `delta_time`：时序采样信息；
- `target` 与 `target_mask`：回归或分类标签；
- `group_id`：独立实验或混合条件的切分单位；
- `dataset_id`：只用于选择适配器和任务头，不进入融合机制的硬编码分支。

融合模型固定分为四层：

> 数据集适配器 → 传感器编码器 → 共享融合核心 → 任务头

A0 同时冻结 Ar-He-CO₂ 的具体模态清单、每个模态的输入形态以及物理来源。没有来源或当前无法实现的模态不加入 v1。

### 3.3 交付物与阶段门

| 交付物          | 预定位置                             | 验收                              |
| ------------ | -------------------------------- | ------------------------------- |
| 统一任务与接口契约    | `docs/algorithm/01_统一任务与接口契约.md` | 字段、shape、mask、标签和错误语义明确         |
| 评价协议与基线矩阵    | `docs/algorithm/02_评价协议与基线矩阵.md` | 主指标、分组切分、seed、置信区间和停止条件预先登记     |
| 最小数据适配 smoke | `tests/` 与 `configs/experiment/` | 两个数据集各一个小批次通过同一 `FusionCore` 前向 |

A0 通过条件：

1. 两个适配器输出同一统一样本契约，融合核心没有按数据集分支。
2. Ar-He-CO₂ 按 `mixture_id` 分组，xylene 按完整工作簿分组。
3. scaler 只由训练组拟合，验证与测试不参与任何统计量估计。
4. 主指标、强基线、seed 数、置信区间和收益门在看正式测试结果前冻结。
5. 接口、切分和错误语义均有自动测试。

## 4. A1——Ar-He-CO₂ 仿真 benchmark v1

### 4.1 关闭结论

A1 已完成并冻结 `gf-a1-v1-20260827-r1`。1200 个唯一 `mixture_id` 按 840 / 180 / 180 划分，数据契约、物理审计、信息审计、强基线和泄漏检查均通过。正式事实与数值以 [A1 数据与物理规格](docs/algorithm/05_A1数据与物理规格.md) 和 [A1 评审记录](docs/algorithm/06_A1评审记录.md) 为准。

A1 只证明固定温压、固定参考物理模型和单次稳态观测下的可辨识性与多传感互补性。它不证明跨工况、跨标定、传感器漂移、重复测量或真实硬件泛化。

### 4.2 暴露的 benchmark 问题

- 三组分闭合后目标只有两个自由度，三路标量观测在内部样本上 Jacobian 全部满秩。
- train、val、test 来自同一配方空间、同一物理方程和同一噪声分布，主要评价同分布插值。
- 温度和压力固定，ToF 与热导噪声相对动态范围很小；不存在标定偏差、批次漂移、物理参数不确定性或跨环境外推。
- 840 个训练点对二维平滑组成空间已形成较密覆盖，强拼接 MLP 接近当前任务上限，压缩了新融合机制的可验证收益空间。
- `macro_RNMAE` 以 100 mol% 量程归一化；后续必须同时报告 mol% MAE，避免仅凭小数值判断任务难度。

## 6. A2H——高难度仿真与分布外泛化实验

### 6.1 目标与边界

A2H 负责把 A1 v1 的低难度诊断转化为预注册压力实验，区分以下三种情况：样本覆盖导致的插值优势、传感噪声导致的不可约误差、环境或物理模型变化导致的分布外误差。A1 v1 保持只读，新实验必须建立独立数据版本、manifest、split hash 和评价配置。详细实施以 [A2H 分步执行计划](docs/algorithm/09_A2H分步执行计划.md) 为准。

A2H 始终保留三路完整传感器，不训练缺失组合，也不声称质量自适应；传感器缺失、未见组合和显式可靠性建模仍由 A4 负责。

### A2H 关闭结论

A2H 已按 [A2H 分步执行计划](docs/algorithm/09_A2H分步执行计划.md) 完成 A2H-0 至 A2H-7。正式数据版本 `gf-a2h-v2-20260828-r1` 包含 2100 个 `mixture_id`、3045 条观测；开发视图包含 2610 条观测，独立 hard-test 包含 435 条观测，数据 content hash 为 `67f9f4841e80f0c1f7d355dcaa8b6e954c46475621cc1fbf196f68c814cdb4de`。A1 nominal parity 通过，最大绝对差为 0。

困难度审计中 calibration、environment、joint、noise 四个轴合格；composition 因拼接基线相对 iid 退化仅 0.1945 未过资格门。各轴 Jacobian 全秩比例为 1.0，合格轴 P95 条件数约 66.2–86.3，oracle headroom 为 0.9777–0.9981。A2H-6 的 C1、M1 候选均未通过晋级门：C1 只在 calibration 平均改善 30.88%，但 CO₂ 组分退化 0.005424 超限；M1 在四个合格轴均未形成稳定收益。两者真实参数量为 519 / 515，相对差 0.77%，满足匹配容差。因此冻结 B5 作为主强基线并形成负结论。A2H-7 在 `formal_run_status=FROZEN` 下完成一次 hard-test 解锁，确认未发生解锁后调参；终态为 `NEGATIVE_RESULT`。正式数值和 hash 证据见 [A2H 正式报告](outputs/reports/a2h_v2/A2H正式报告.md)、[A2H 评审记录](outputs/reports/a2h_v2/A2H评审记录.md) 与 [A2H 结果记录](docs/algorithm/08_算法实验结果记录.md)。

### 6.2 高难度实验矩阵

| ID | 实验 | 设计 | 主要回答 |
| --- | --- | --- | --- |
| H-LC | 学习曲线 | 固定独立 test，按预注册比例使用训练集子集；每档保持相同组成覆盖规则和多个 seed | 低误差是否因二维空间已被少量样本充分覆盖 |
| H-NR | 独立重复与噪声压力 | 每个配方生成多次独立观测，分级提高噪声，并加入相关噪声和批次内共同扰动 | 模型是否只适应一次固定噪声实现，误差何时接近噪声下限 |
| H-ENV | 温度、压力环境外推 | train、val、test 按温压区间或离散环境块隔离，同时保持 `mixture_id` 互斥，禁止随机行混合 | 模型能否跨工况泛化，而不是只反演固定环境下的组成 |
| H-CAL | 标定与物理模型失配 | test 独立改变零点、增益、光程、响应系数和允许范围内的物性参数 | 仿真方程或标定轻微偏移时，算法是否仍可靠 |
| H-COMP | 组成区域留出 | 按浓度带、单纯形区域或边界类型整块留出，保留纯气、二元和三元的明确分层 | 模型能否跨组成区域插值或外推，结构零是否成为真实难点 |
| H-JOINT | 组合压力 | 在冻结的温压、噪声、标定和组成留出上组合两项以上扰动 | 单因素结果能否在更接近应用的联合变化下保持 |

所有扰动范围必须在生成候选结果前由物理依据、硬件资料或明确的敏感性区间冻结。不同观测实现的随机状态只登记在配置或运行 manifest，不生成或依赖逐样本 `noise_seed`、`noise_seed_index`；`mixture_id` 继续作为唯一分组主键，不回退为 `sequence_id`。

### 6.3 评价与算法矩阵

1. 同时报告 `macro_RNMAE`、各组分 mol% MAE、RMSE、R²、最差环境和最差组成区域，不用单一归一化小数概括难度。
2. 增加解析逆问题或数值反演 oracle，估计给定噪声与模型失配下的可达误差下限；增加最近邻基线量化样本覆盖收益。
3. 每个困难轴至少比较 B3 Ridge、B4 GBDT、B5 或 matched Torch concat、H1 输出投影和 M1 Deep Sets；只有 train-only 残差出现正 explained variance 时才重新开放 residual。
4. 所有 scaler、特征选择、早停和阈值只使用对应训练环境及允许的 val；OOD test 环境在配置和候选冻结后一次解锁。
5. 学习曲线、噪声档位和 OOD 环境均使用多个 seed 或独立生成批次，并以独立组为 bootstrap 单位。

### 6.4 阶段门

A2H 关闭前必须满足：

1. 困难轴的物理范围、数据版本、split、oracle 和测试锁均可复现，且未破坏组成闭合或基本可辨识性。
2. 至少两个独立困难轴使简单 concat 相对同分布 v1 出现预注册幅度的退化，同时 oracle 仍保留可学习空间；否则该困难轴不能用于区分算法。
3. 如果最佳强基线在所有困难轴上仍落入 oracle 等价带，结论应是 benchmark 再次饱和，不扩大网络搜索。
4. 候选晋级仍要求五 seed 中至少四个同向、配对置信区间和组分退化门通过；不能以单个最优 seed 晋级。
5. 无论结果正负，都要形成学习曲线、噪声响应曲线、OOD 分层表和失败案例清单，并据此冻结进入 A3 的方法声明。

## 7. A2M——主流深度学习架构对照与强基线收口

### 7.1 研究定位与边界

A2M 回答“当前冻结 B5 是否只是在有限候选中表现最好，还是在适合当前数据形态的主流深度架构中仍是合理选择”。详细执行以 [A2M 主流架构对照分步执行计划](docs/algorithm/10_A2M主流架构对照分步执行计划.md) 为准。

A1 与 A2H 的正式输入均为三个完整传感器的稳态标量，`T=1`。因此 A2M 的正式比较只纳入适合表格或传感器 token 输入的架构：统一 PyTorch 拼接 MLP、Tabular ResNet 和轻量 FT-Transformer；B3 Ridge、B4 GBDT 与冻结 A1 B5 继续作为参照。TCN、GRU/LSTM 和时序 Transformer 不在 `T=1` 上运行或排名，其对照协议在 A2M 关闭时冻结，并由具有真实时间维的 A3 执行。

A2M 是有界的架构对照，不重新开放大型 Transformer、MoE、外部预训练模型或无上限超参数搜索。A2、A2H 的 Deep Sets、输出头和 residual 结果保留为历史机制证据，不改名为主流架构对照结果。

### 7.2 最低交付与阶段门

A2M 必须先解决当前 A1 指标回归不一致，区分冻结的 scikit-learn B5 与 A2/A2H 的 PyTorch B5-like 实现，并记录 Python、NumPy、SciPy、scikit-learn、PyTorch、BLAS、device 和 dtype 指纹。无法解释复现差异时，阶段关闭为无效，不允许生成架构排名。

A2M 的最低完成条件：

1. A1 冻结结果保持只读；基线复现差异有明确根因、版本和自动回归测试，不放宽断言掩盖漂移。
2. 所有架构共享数据版本、`mixture_id` 分组、train-only scaler、目标、指标和每架构相同的配置试验预算。
3. 旧 A1 test 与 A2H hard-test 只作历史参照，不参与新模型选择；A2M 使用独立、预先哈希并锁定的 formal holdout，一次同时评价冻结的各架构赢家。
4. 每个架构报告五个 seed、逐组分误差、合格困难轴、配对 group bootstrap、参数量、训练时间和推理时间。
5. 非 MLP 架构只有在 iid 不劣化、至少两个合格困难轴相对统一 MLP 改善达到预注册门、至少 4 / 5 seed 同向且无关键组分超限退化时，才可替换 MLP。
6. 即使没有非 MLP 架构晋级，只要复现、协议、正式对照和失败边界完整，A2M 仍可用 `MLP_RETAINED` 关闭。

A2M 关闭后冻结一个 A3 完整输入参考模型和一组时序对照配置。A3 不以 xylene test 结果反向重开 A2M 候选池。

### 7.3 A2M 关闭结论

A2M 已完成 A2M-0 至 A2M-6。A1 历史 B5 与当前 PyTorch 主基线已按 `B5-SK` / `A2M-MLP` 分离；A2M 开发集完成 30 个主运行，formal holdout 在 `FROZEN` 状态下一次解锁，RESNET 与 FTT 均未通过联合晋级门。最终冻结 `A2M-MLP / mlp_lbfgs_width32` 为 A3 完整输入参考，A3 时序矩阵见 [A3 时序架构矩阵](configs/experiment/a3_temporal_matrix.json)，详见 [A2M 评审记录](docs/algorithm/11_A2M评审记录.md)。

## 9. A4——可变传感器集合与可靠性扩展

### 9.1 研究范围

本阶段只在 A2H 冻结的统一接口和最佳合格完整输入模型上增加集合式输入与质量建模，不另起一套数据集专属网络。若 A2H 没有新候选晋级，则使用冻结强基线作为完整输入对照，不把 A2 的负结果模型预设为有效核心。评价至少区分：

- 训练中出现过的缺失组合；
- 训练中未出现的传感器组合；
- 单传感器或传感器组完全缺失；
- 漂移、尖峰、饱和、不规则采样和冲突观测；
- 不同目标组分对传感器可靠性的差异。

### 9.2 最低对照与阶段门

最低对照包括完整输入模型、随机通道 dropout、零值或统计插补、mask 拼接、等权融合和固定权重融合。

A4 通过条件：

1. 未见组合和数值退化下的最差组性能优于预注册对照。
2. 完整输入性能不超过预注册容忍范围的退化。
3. 预测的可靠性与真实误差或注入退化具有可解释的一致关系。
4. 失败组合、额外计算成本和适用范围完整报告。

A4 的结果首先服务学位论文第 3 章；当前不为第二篇小论文单独增加任务、数据或排期。

## 10. A5——小规模真实 Ar-He-CO₂ 混合气验证

### 10.1 实验范围

只做可控、可重复的简单实验：固定总流量、压力、采样位置和采样时长，对 Ar、He、CO₂ 纯气以及预设二元、三元混合配比进行独立重复采集。混合配比以现有配气与安全条件能够稳定复现为准，不追求覆盖完整三元配比空间；真实实验不扩展到焊接过程扰动、复杂环境变化或在线闭环。

### 10.2 执行纪律

1. 采集前冻结模型结构、预处理、指标和主图表模板。
2. 每个纯气或混合配比保留独立重复，不把同一次采集的窗口当作独立实验重复。
3. 如需校准，预先划分校准批次与盲测批次。
4. 报告原始响应、组分预测结果、分配比误差以及仿真—真实差距。
5. 混合气实验只能支持实际采集浓度、配比和固定条件范围内的组分定量结论；未采集配比、浓度外推和复杂工况泛化必须单独验证。

A5 的完成门是协议执行完整、数据可追溯且结论边界准确，不以达到某个理想精度作为隐藏成功条件。

## 12. 统一评价与停止规则

### 12.1 指标

- 组分回归：主指标在 A0 冻结；建议使用宏平均的范围归一化 MAE，辅以各组分 MAE、RMSE 和 R²。
- 分类辅助任务：macro-F1、balanced accuracy 和混淆矩阵。
- 稳健性：完整输入到退化输入的性能下降、最差组误差和失败率。
- 效率：参数量、训练时间、推理时间和显存占用。

不同数据集的绝对误差量纲不同，不直接比较 Ar-He-CO₂ 百分比误差与 xylene ppm 误差；跨数据集只比较相对各自强基线的效果和结论一致性。

### 12.2 通用停止规则

- cheap probe 未显示多模态互补时，不启动大规模深度训练。
- 强基线打平任务上限时，先改数据或问题定义，不通过加深网络制造工作量。
- 收益门、等价带或测试集不得在看到结果后静默修改。
- 失败必须记录现象、机制、适用范围和停止理由。
- 每一阶段最多保留一个主方法和一个备选；主方法未完成前不扩展候选池。

## 15. 主要风险与应对

| 风险                | 触发信号                        | 处理                      |
| ----------------- | --------------------------- | ----------------------- |
| 仿真任务过易、强基线达到上限    | concat MLP 接近 oracle，复杂算法没有稳定余量 | 执行 A2H；若仍饱和，冻结负结论，不训练更大网络 |
| 困难轴破坏基本可辨识性         | oracle 同时失效或误差无上限增长          | 缩回物理范围；困难实验必须保留可学习空间       |
| OOD test 被用于调参          | 根据测试环境结果改阈值、模型或扰动范围       | 结果作废，重新升版协议与 test 环境           |
| 主流架构对照被输入语义混淆       | 在 `T=1` 上运行时序模型，或不同架构使用不同标签、split、scaler 与调参预算 | 结果作废；回到 A2M 协议，按输入适用性和统一预算重做 |
| 通用核心被数据集专属逻辑污染    | `FusionCore` 出现数据集名称或固定通道分支 | 退回 A0，逻辑下沉到适配器或任务头      |
| xylene 泄漏或独立样本数虚高 | 同一工作簿窗口跨 split              | 结果作废，按完整文件重切分           |
| 工作量扩张导致进展再次停滞     | 同时维护多个模型、多个论文支线             | 只保留当前阶段的一个主方法和一个备选      |
| 真实数据不足            | 混合配比覆盖或独立重复数量有限             | 只在实际采集范围内验证，不声称完整组分空间泛化 |
| 仿真—真实差距较大         | A5 趋势或精度不一致                 | 报告差距和模型边界，不把真实数据回填为训练主集 |
