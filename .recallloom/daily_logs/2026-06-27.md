<!-- section: confirmed_facts -->
**测试**：462 passed（pytest 收集确认），其中 syngas 增量 109 个（含 Ⅱ 的 18 个 ablation 测试），hg 353 个零回归。

**关键结果（test split，mean ± std over 3 seeds）**：
- Ⅱ-1 B 组（去 V_NDIR_CO）：TCN x_CO R² = 0.484±0.005（baseline 0.954），Ridge x_CO R² = 0.470。其他三个组分（H₂/CH₄/CO₂）几乎不变。
- Ⅱ-1 C 组（仅 V_NDIR_CO+环境）：TCN x_CO R² = 0.928±0.019，Ridge 0.941。H₂/CH₄/CO₂ 暴跌至 0.04/0.21/0.14（主光学+TCS 被移除属预期）。
- Ⅱ-2 crosstalk：TCN x_CO R² = 0.956±0.003 vs baseline 0.954；所有组分 |Δ| ≤ 0.006，无统计意义差异。
- Ⅱ-3 loss：weighted_component_mse x_CH4 R² = 0.827；mse 0.414 / mae 0.392 / huber 0.395 / smooth_l1 0.440。其他组分 R² 跨 loss 差异 ≤ 0.03。

**与原计划预期偏差**：
1. Ⅱ-1 B 组原预期 x_CO R² ~0，实测 ~0.48（损失约 50%），剩余可学性来自闭包约束 + V_TCS + 可能的 CO₂ NDIR 弱串扰。
2. Ⅱ-2 原预期下降 0.01-0.05，实测持平。3×3 线性串扰是确定性映射，模型可学逆映射。
3. Ⅱ-3 加权 vs 未加权对 CH₄ 的差异（+0.4 R²）远大于不同未加权 loss 之间的差异（≤0.03）。

**代码改动统计**：在 Stage Ⅱ 之前已完成的 462 测试中包含的 channel 子集选择（DL+Ridge 两条路径）+ crosstalk CLI 透传（physics/slow/benchmark/_parallel/CLI 五层）+ 测试覆盖均通过回归。

<!-- section: key_decisions -->
**论文写作叙事修正**：
1. CO 与 N₂ 声学简并假说的物理描述应从"完全依赖光学通道"修正为"主导依赖（损失约 50%）"，这是 Ⅱ-1 实测的直接证据，比原假说更精确。
2. Ⅱ-2 持平结果作为 informative 负结果纳入论文：线性串扰不构成模型学习难度，sim-to-real gap 在硬件层面（非线性 / 时变 / 标定漂移）而非串扰矩阵层面。
3. Ⅱ-3 的 inverse_train_var 加权（单行代码让 CH₄ R² 翻倍）作为论文核心方法学贡献突出展示，对低浓度组分检测有通用性。

**Stage Ⅱ 不做的事**：
- Ⅱ-4 CO 弛豫系数扫描：Ⅱ-1 显示声学通道仍贡献 ~50% 可学性但属于次要，扫描 alpha_lambda_max_co 优先级降至低，转 Stage Ⅲ 硬件标定可用后再做。
- 串扰系数 ε_32 敏感度扫描：Ⅱ-2 持平结论使敏感度扫描必要性降低。

**下一步主线**：Stage Ⅲ 真实硬件 sim-to-real 测试规划 + 论文初稿启动。Stage Ⅱ 已为论文提供两个科学贡献（CO 物理证据 + 低浓度组分方法学）+ 一个负结果（串扰仿真鲁棒性）。

<!-- section: risks_blockers -->
**Ⅱ-1 残留 50% 可学性来源未量化**：三种可能（闭包约束 / V_TCS 热导差 / CO₂ NDIR 弱串扰）的相对贡献未单独验证。可选后续 ablation：B 组在 sg4-formal-crosstalk 上重复（验证假设 3）、B 组再去 V_TCS（验证假设 2）。本轮不阻塞主结论。

**Stage Ⅲ 硬件路线未启动**：需要确认硬件可用性、采样协议、对标传感器型号。Ⅱ-2 持平结论说明仿真已不是 sim-to-real gap 的主因。

**hg P3 noise_std=0.005 调优未跑**：与 syngas Stage Ⅱ 并行不冲突，预计 6-12h GPU。

**多模态接入 syngas 未做**：当前结果仅基于慢通道单模态。接入 ultrasonic / fiber_mic 后 Ⅱ-1 是否仍成立、TCN 与 Ridge 差距是否拉开，是 Stage Ⅲ 前的可选验证点。
