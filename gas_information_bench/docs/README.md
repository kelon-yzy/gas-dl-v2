# GIB 子工程文档

正式规格与阶段状态分别由仓库级
[`P2_bench规格书.md`](../../docs/p2/P2_bench规格书.md) 和
[`docs/p2/README.md`](../../docs/p2/README.md) 维护。本目录只说明子工程入口，
不建立第二份规格事实源。

- 能力所有者：`configs/p2_s6_ownership_registry.json`
- 数据与 split 契约：`configs/p2_*_schema.json`、`configs/p2_split_contract.json`
- 来源与 discrepancy：`configs/p2_s5_*.json`
- 冻结实现：`gib.freeze`
- 命令行入口：`gib`
