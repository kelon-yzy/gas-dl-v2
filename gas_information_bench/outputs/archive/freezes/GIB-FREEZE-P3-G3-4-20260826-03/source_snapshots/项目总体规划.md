## 1. 重规划的依据

### 1.1 三个场景给出了同一个规划信号

到 2026-08-20 为止，三个场景的历史实验都没有证明深度学习相对调好的线性或浅层基线取得了可归因优势，但三类证据的有效范围不同：

| 场景                 | 规划信号                              | 证据状态与来源                                                                                                     |
| ------------------ | --------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| syngas             | 慢通道上的深度模型与 Ridge 基本持平             | 128 步 Stage I/II 已废弃，仅作为内部假设来源；正式引用前必须完成 512 步复现，见 [syngas 文档入口](syngas/docs/README.md)                     |
| hydrogen_ng        | 多窗口 Ridge 明显优于已运行的 PhaseWindowTCN | 当前项目内部基线，数值与适用范围见 [hydrogen_ng 文档入口](hydrogen_ng/docs/README.md)                                            |
| tunnel_ventilation | 测量级线性基线优于已运行的端到端波形结构              | 已由冻结证据链关闭，见 [代码契约事实源](tunnel_ventilation/docs/掘进通风代码契约事实源.md) 与 [实验日志](tunnel_ventilation/docs/掘进通风实验日志.md) |

因此，本规划只使用“现有实验尚未给出可归因的深度模型优势”这一跨场景判断，不把 syngas 的废弃数值当作当前正式结论。

这个观察只作为项目内部决策依据，不能作为对外的方法学发现。化学计量学已有深度模型与 PLS、SVR、轻量模型对照的同类结论；本项目的可声明内容收窄为“**算法优势出现在信息谱的哪一段**”，即 §6.1 的 S1 与 §8.3 的 4-E。证据边界见 [P1 视角 1](docs/p1/01_视角1_多传感器多组分DL现状.md) §4.2。

### 1.2 但三次的成因不同，必须分开处理

**tunnel_ventilation 是信息不足。** Fisher 秩、窄窗误差、多频审计、硬件扫描和后验区间五类证据指向同一结论：当前观测与硬件先验不足以支持目标精度，不是继续更换回归结构能解决的问题。数值与适用范围只在 tv3 的契约事实源和实验日志维护。

**syngas 和 hydrogen_ng 是另一回事。** `syngas/configs/sg4_tcn.json` 里写着：

```json
"modalities": "slow"
```

历史 Stage I/II 只把慢通道送入模型；仿真生成的超声和光纤麦克风波形没有进入该轮训练。该结果只能支持一个设计警告：若输入主要是低频、近线性的工况与传感器摘要，手工统计基线可能已经覆盖大部分可用信息。由于这批 128 步实验已废弃，新主线不得把其数值当作正式证据，相关假设必须在 P3 pilot 数据上重新验证。

### 1.3 由此得到的规划前提

**"容易出效果的仿真"不能理解成"简单问题"。** 问题越简单，线性基线越可能打平复杂模型，创新算法越没有位置。sg4 的废弃历史实验提供了这一风险信号，但新 bench 必须独立验证。

正确的判据是：**线性与强表格基线要留下可归因的空档，且空档的成因能指认到具体机制。** 这既排除 tv3 那种信息不足（空档在物理层，任何算法都拿不到），也排除 sg4 那种空档为零（信息全在慢通道的线性部分里）。

按项目自身证据，空档有三个可能来源，且都还没有被验证过：

1. **快通道波形**。原始波形中的延迟、衰减与信噪信息需要非平凡的信号处理或表示学习；普通慢通道统计量不能表达这部分信息。
2. **跨模态互补**。不同组分在光学、声学与热导模态上的可见性不同，近简并组分需要其他模态消歧。syngas 的历史消融只提供方向性线索，具体互补强度由 P3 重测。
3. **干扰参数与目标的非线性耦合**。T/P/RH/L 同时影响声速、吸收和光学响应。tv3 已验证变量投影的结构正确性，但信息不足使估计效率收益无法过门；该机制只有在信息充足的 bench 上才值得继续评估。

## 2. 新主线

```
P0  tunnel_ventilation 收尾成方法学论文        ──┐
                                                 │ 并行
P1  文献检索、候选与评估框架确定               ──┘
         │
         v
P2  专用 bench 规格设计（信息量可调）
         │
         v
P3  bench pilot + Fisher/CRB 审计 + 基线与候选晋级
         │
         v
P4  晋级算法实现、消融、信息谱扫描、跨场景复现
         │
         v
P5  应用背景筛选（用同一套审计工具）+ 实际实验规划
```

与旧主线的差别在于两点。第一，算法方向由文献与信息论分析决定，不由现成场景决定。第二，验证场景是按算法需求设计出来的，且**在投入算法开发之前就要证明这个场景有空档可争**。

### 4.1 定位

### 4.4 梳理过程的意外收获

按论文结构梳理的主要价值不在文档本身，在于它强制回答"这个结论的证据是什么、不能声称什么"，由此暴露了两类问题。

P0 的一致性审查发现多处描述漂移：冻结数字本身正确，但散文混用了名义水平、重复计算了等价消融、混合了不同 split，或使用了错误的保护带口径。具体更正只在事实源和实验日志维护。

由此产生一条必须写进 P2 规格的纪律：**引用数值必须由脚本从冻结产物生成，不手工誊写。** 描述漂移能穿过冻结纪律，因为它住在散文里而不在产物里。

**一次领地判定。** 文献检索（记录在 [00_related_work.md](tunnel_ventilation/docs/paper/00_related_work.md)）查明"先算信息量再建模型"不是新顺序——Rodgers 2000《Inverse Methods for Atmospheric Sounding》第 2 章就是这套做法的教科书，大气遥感界用了三十年，2273 引。同时 Phillips 2003 用声速 + 声衰减做三组分组成传感，就发在目标期刊上。

**这条对 P1 有直接影响**：P1 的创新点检索必须把"相邻领域是否已有成熟做法"作为固定检查项，而不只查本领域。tv3 这次是在方法梳理阶段才发现，代价还小；若在 P4 算法开发完成后才发现，代价是整条线。

### 4.5 不做的

- MEI-4 C3 恢复执行
- CC-SBI 训练
- 静止空气线（S0–S4，从未启动）
- 任何新的 tv3 实验

## 5. P1 · 文献检索、候选与评估框架确定

P1 已于 2026-08-23 关闭。该阶段确定的是候选机制、已占领领地和 P2/P3 的评估门，不直接指定 P4 必须实现的算法。C1 信息谱条件化评估作为评估框架与 T2 组合改进空间进入 P2 规格草案，不计作基础算法创新；C2–C4 只有通过 P3 G3-4 最小证伪实验后才能晋级 P4。

> **执行文档在 [docs/p1/](docs/p1/)。** 检索式、纳入排除标准、证据分级与引用核实纪律在 [docs/p1/00_检索协议.md](docs/p1/00_检索协议.md)；视角 1 结果在 [docs/p1/01_视角1_多传感器多组分DL现状.md](docs/p1/01_视角1_多传感器多组分DL现状.md)；RQ1–RQ3 与正式关闭条件在 [docs/p1/09_P1补充检索与正式关闭审查.md](docs/p1/09_P1补充检索与正式关闭审查.md)。本节只保留阶段定义，具体执行不在此维护（N7）。

### 5.1 检索的七个视角

1. **多传感器多组分气体检测的深度学习现状**——先找反例，明确哪些声明已经被占领。P1 已确认深度学习用于声学弛豫谱组分反演等宽泛声明已有先例，不能作为本项目创新点；具体文献与数值只在 [P1 视角 1](docs/p1/01_视角1_多传感器多组分DL现状.md) 维护。

2. **物理引导与可微前向反演**——algorithm unrolling、变量投影、PINN、灰箱校准

3. **多模态融合中的模态贡献可辨识与解耦**——共享潜变量可辨识性、多视图 ICA

4. **不确定度校准**——SBI、覆盖率校准、SBC、conformal

5. **低浓度与不平衡多目标回归**——尺度、加权、量级差

6. **sim-to-real 迁移与模型偏差**——正交模型偏差、数字孪生反演

7. **相邻领域是否已有成熟做法**——由 P0 的领地误判教训新增。

P0 的方法梳理查明，"先算信息量再建模型"在大气遥感反演界是教科书做法（Rodgers 2000 第 2 章，2273 引），而本项目一直把它当作可声明的方法学贡献。若这个发现推迟到 P4 算法开发完成后才出现，代价是整条线。

因此每个创新点候选必须回答：**这个机制在哪些相邻领域已经是常规做法？** 候选领域至少包括大气遥感反演、地球物理反演、医学成像重建、系统辨识、计量学、**化学计量学**。检索只查本领域不够——本领域没人做，往往不是因为难，而是因为做的人在另一个学科。

候选领域清单允许增长。每轮检索都必须再问一次“还有哪个学科在做同一件事”；化学计量学就是 P1 首轮补入后确认的重要相邻领域。见 [P1 视角 1](docs/p1/01_视角1_多传感器多组分DL现状.md) §4.1。

这一条不降低候选的价值：把成熟做法迁入尚未采用它的领域，本身是可声明的贡献，但必须写成"迁移"而不是"发明"，并说明迁移时需要克服什么（tv3 的例子是秩亏——Rodgers 那套的信息量度量在秩亏时不给出目标单位的数）。

第 2–6 项的早期构想来自 [tv3_mrs_generalizable_algorithm_ideas_20260727.md](tunnel_ventilation/docs/deep_research/tv3_mrs_generalizable_algorithm_ideas_20260727.md)。P1 已完成七视角第一轮核查和候选评审；具体检索结果、证据等级与使用边界只在 [docs/p1/](docs/p1/) 维护。

### 5.2 产出物

**（a）创新点候选集。** 每个候选必须写全五项：

| 项             | 要求                            |
| ------------- | ----------------------------- |
| 机制            | 具体改变了什么——观测、噪声协方差、先验、求解器，还是表示 |
| 现有方法为什么做不到    | 引用具体文献，不能是泛泛而谈                |
| **收益量级的先验估计** | 机制成立之后，指标能改善多少？给出数量级与推导       |
| 最小证伪实验        | 成本最低的判生死实验，且必须先于大规模训练         |
| 失效条件          | 什么情况下这个机制不成立                  |

第三项是硬要求。tv3 多次出现“机制验证成立，但收益量级不足以过门”的结果，具体实验与数值见实验日志。**只论证机制可行不足以立项。**

**（b）已占领领地清单。** 明确哪些创新声明不能再提，附文献出处。

**（c）候选进入 P2 的判据。** 预注册，不在看到 P2 结果后调整。

### 5.3 阶段门

P1 阶段门已通过并关闭：至少 3 个候选五项齐全，已占领领地和预注册判据完整，且至少 1 个候选具有可追溯的收益量级先验。补充检索确认气体传感内已有信息论 resolving power、CRLB selectivity、信息论 LOD 和局部分区先例，因此 C1 只能定位为 T2 组合改进的评估框架。该门只允许进入 P2 规格设计，不等于任何算法候选已获 P4 实施资格。正式 verdict 见 [P1 评审记录](docs/p1/评审记录.md) 与 [关闭审查](docs/p1/09_P1补充检索与正式关闭审查.md)。

### 5.4 关闭后审查（2026-08-24）

P1 的筛选用的是新颖性标准（T0–T5 领地分级，问"这能不能声称是新的"）。本次按性能标准复查——**比现有方法更快或更准，成熟组件的组合同样计入**——发现两套标准给出的排序不一致。审查**不重开 P1 文献阶段**，领地判定与措辞约束全部保留；改动只落在 P2 规格、P3 晋级门与候选集本身。

**（a）晋级的候选无法满足性能标准。** C1 是评估协议，不产生预测，没有可比较的精度或速度，§7.4 也已写明它不计作算法候选。它作为量具仍然必要——没有 oracle 上限与信息轴，"优势出现在哪一段"就无法陈述，而预注册与配对置信区间正是让一篇组合式论文通过审稿的部分。但它不应继续占据唯一晋级名额：能满足性能标准的三个候选目前全部停在"保留观察"。

**（b）C2 的收益门与项目自有证据冲突。** tv3 的冻结产物 [`table6_solver_efficiency.csv`](tunnel_ventilation/docs/paper/artifacts/table6_solver_efficiency.csv) 已在冻结观测上量过变量投影：test 域相对改进 `2.78%`（95% CI 下界 `1.16%`），OOD 域 `2.45%`（下界 `0.74%`），预注册实践等价带 `0.02`，两个点估计都超过带、两个 CI 下界都未超过，正式结论是保留简单基线。同批 `table7_structural_verification.csv` 显示该求解器实现为机器精度正确（参数差 `1.04e-17`，投影 Jacobian 相对有限差分 `8.57e-10`），因此这不是实现缺陷。

C2 现行门写的是 P90 下降 `≥ 10%`，约为上述点估计的 3.6 倍。项目对差距的解释是"tv3 信息不足"（§1.3），该解释未经验证且方向存疑：变量投影改善条件数与可分离性，不增加信息量；信息越充足，估计器越贴近 CRB，留给投影回收的空间只会更小。决定 C2 胜负的是**目标与 nuisance 雅可比的共线程度**，这与信息量是彼此独立的两个量。

同时 tv3 只测过 P90，从未测过迭代步数或计算耗时。变量投影在 Golub–Pereyra 一支文献里的经典收益本来就在非线性搜索维度下降与迭代减少，而非最终精度。C2 门里那条备选的"固定预算下迭代步数下降 `≥ 30%`"很可能才是它的真实优势轴，却始终未被测量。

**（c）候选集缺少效率轴。** 四个候选的收益门全部是精度类（R²、P90、MAE、覆盖率）。组合式改进在精度上的典型量级是 2%–5%，而项目的预注册等价带与 CI 下界要求恰好是为拒绝这一量级设计的——tv3 论文素材 [06_results.md](tunnel_ventilation/docs/paper/06_results.md) §6.9 已经演示过一次该结果。这构成一个必须正视的张力：**严格的判定纪律加上小幅的效果量，等于系统性拒绝。**

出路取正面一条：**换轴，不放宽带宽。** 计算成本与数据效率上的组合改进常是数量级差距，能同时满足"简单组合"与"通过严格门"。相邻领域已有直接范本，且两者都已登记在 P1 引用中：Fan 2025 的 PLSELM（PLS 得分矩阵 + 集成极限学习机，`10.1016/j.aca.2025.344728`）正面打赢常规 PLS、SVR 与深度学习模型，卖点含建模耗时、小数据与仪器间迁移；Liu 2024 的 PI-MTL（物理模块 + 多任务 loss wrapper，`10.1016/j.saa.2024.124857`）同时打赢 PLSR 与基准 CNN。两者都是成熟组件的组合而非新方法。P1 把它们登记为领地威胁，按性能标准它们同时也是可复用的范本。

放宽等价带是另一条路，本规划不采纳：它削弱项目现有的方法学优势，而该优势正是组合式贡献能被接受的前提。

**（d）四项处置及去向。**

## 6. P2 · 专用 bench 规格设计

这是整个规划里技术含量最高的一段。bench 的设计目标不是"造一个简单问题"，而是**造一个空档可控、成因可指认、信息量可调的问题**。

### 6.1 S1 · 信息量必须可调

bench 自带一个信息量刻度盘。通过下列旋钮，让同一个组分体系在"信息充足 → 临界 → 不足"之间连续变化：

- 传感器组合（每个模态可单独开关）
- 噪声水平（σ_TOF、光学 SNR、温度误差、触发抖动）
- 干扰参数先验宽度（T/P/RH/L 的标定精度）
- 组分窗口宽度（宽域 / 窄窗）
- **目标–nuisance 雅可比夹角**（高 / 中 / 低三档共线，2026-08-24 新增）

第五个旋钮与前四个的性质不同，必须单列。前四个改变的是有效信息总量，第五个改变的是同一信息量下的可分离性。§6.3 的"干扰参数非线性耦合"只提供启停两态，不能替代连续夹角。加这个旋钮的直接原因是 C2 的胜负由共线程度决定而非由信息量决定（见 §5.4(b)）：没有它，P3 的 G3-4 无法对 C2 给出公平判定，只能重复 tv3 那次在秩亏条件下的结果。

每一档先算目标方向的 Fisher 有效信息与 CRB，得到"该档位下任何算法都越不过的下界"。

这样算法评估从"在单点上比 R²"变成"**在信息谱上比算法优势出现在哪一段**"。这个设计本身直接回答了 tv3 留下的开放问题，也让"算法在什么条件下有用"成为可陈述的结论，而不是一个孤立数字。

S1 的基础组件不是空白：气体传感内已有 information-theoretic resolving power、CRLB selectivity、信息论检测限、局部浓度分区和特征选择。P1 保留的是更窄的 T2 组合改进空间，即把预注册信息档位、强基线、候选算法与 oracle 优势区间放在同一评估协议中。P2 应把它作为规格第一优先，但不得写成基础信息论方法的“首次”。见 [P1 视角 1](docs/p1/01_视角1_多传感器多组分DL现状.md) §2.5、§4.2、§4.6。

### 6.2 S2 · 组分体系要满足模态分工

至少 4 个组分，且同时满足：

- 至少 1 个组分只有光学可见（红外活性强、声学与热导贡献弱）
- 至少 1 个组分只有声学或热导可见（无红外活性，或摩尔质量差异显著）
- 至少 1 对组分在某个模态上近简并、在另一个模态上可分——这是跨模态消歧的直接样本
- 至少 1 个低浓度组分（量级差异，检验尺度与加权问题）

syngas 的组分体系提供了一个候选原型：CO/N₂ 在部分模态近简并、H₂ 声学对比强、CH₄ 浓度较低。P2 必须根据 C1 信息谱规格和物理前向审计重新选型，不继承废弃 Stage I/II 的数值结论。

工业应用调研提供了更适合作为首个低风险载体的 MFC 动态混气方案：优先采用 N₂/CO₂/O₂、Ar/CO₂/O₂ 或 Ar/N₂/CO₂ 等体系，由 MFC 流量提供理论标签、参考分析仪校验，并注入流量变化、组分阶跃、温压湿度扰动、MFC 偏差、泄漏、漂移和未知组分。具体气体、传感器和硬件仍须通过 S1–S5 前向审计后冻结。

### 6.3 S3 · 空档来源必须可单独开关

设计时预留 headroom 来源，每个来源都能独立关闭以做消融：

| 空档来源               | 关闭后的预期                   |
| ------------------ | ------------------------ |
| 快通道波形              | 退化成慢通道场景，重新检验强基线是否打平深度模型 |
| 干扰参数非线性耦合          | 固定 T/P/RH/L，问题接近线性       |
| 组分间交叉敏感（光学串扰、弛豫耦合） | 各通道独立，融合无对象              |

syngas 废弃的 128 步 Stage II 只提供一个方向性警告：确定性线性串扰可能被模型直接学习逆映射，未必形成有效难度。P3 必须重新比较线性、非线性与时变串扰，只有能形成可归因空档的机制才保留。

### 6.4 S4 · 双标尺 + 理论下界

每个档位都要同时给出四个参照：

1. **CRB**——理论下界
2. **oracle 上限**——用真值特征的回归结果
3. **测量级基线**——从波形经 DSP 提取特征的回归结果
4. **强基线**——Ridge / GBDT / 强表格模型

算法收益报告成”占可争夺空间（oracle 上限 − 强基线）的比例”，不只报绝对 R²。oracle 与测量级结果必须分列，具体预注册门值只在 [P1 候选集](docs/p1/创新点候选集.md) 维护。

**效率轴与精度轴并列报告（2026-08-24 新增）。** 每个档位除上述四个精度参照外，还要对每个参与比较的方法记录三个量：

| 量        | 定义                          | 用途                 |
| -------- | --------------------------- | ------------------ |
| 训练与推理计算量 | wall-clock 与迭代步数，同一硬件同一预算下测 | 支撑”更快”类收益          |
| 数据效率     | 达到目标精度所需的训练样本量              | 支撑”用更少数据达到同一精度”类收益 |
| 达标点      | 固定精度目标下的计算量与样本量             | 让效率收益与精度收益可换算      |

加这一条的理由在 §5.4(c)：组合式改进在精度轴上的典型量级落在项目预注册等价带的拒绝区内，而在效率轴上常是数量级差距。效率轴的收益同样要走 paired 多 split 多 seed 与置信区间，不得用单次计时替代。tv3 从未测过迭代步数，这是 C2 真实优势轴长期未被观察的直接原因。

算法候选调研进一步冻结 P2 pilot 数据契约的最小字段：样本级 Fisher/CRB、增量信息（新增时间窗或模态的 ΔI）、solver difficulty（iteration、convergence、condition number、residual、runtime）以及 Raw + DSP 双数据层。缺少这些字段，后续无法公平验证自适应采样、求解器路由和跨表示蒸馏。

### 6.5 S5 · sim-to-real 可信度

物理常数、噪声模型、传感器频响都要有文献或器件手册出处。仿真链路预留 model discrepancy 注入接口（正交模型偏差形式），供 P5 做 sim-to-real 评估。

这一条不能省。第三阶段的实际实验规划完全依赖仿真的物理可信度。

### 6.6 S6 · 工程归属与复用边界

新 bench 是第四个气体场景、第五个顶层子工程，与 `hydrogen_ng/`、`syngas/`、`tunnel_ventilation/` 和算法复现子工程 `rcdw_mgda/` 并列。P2 规格书必须先确定目录名、包名、schema version、ID 命名空间和依赖边界，再允许实现。

复用遵循“迁移后单一所有者”原则：

- `mixture_id` 主键 split、manifest 和 validation 契约可以迁移，但新子工程必须有自己的权威实现或显式公共依赖，不跨场景导入私有包。
- tv3 的 Fisher/CRB、VarPro、版本化 freeze 和 RawDSP 只能作为迁移来源；迁入时去除 tv3 字段、路径和常量耦合。
- 报告纪律直接复用：预注册门、负对照、oracle 隔离、freeze 不覆盖。
- P2 的 audit 复用性评估必须列出“可直接迁移、需解耦、不得复用”三类结果，避免形成多个事实源。

### 6.7 阶段门

规格书通过设计评审，六项 S1–S6 齐全，信息量刻度的三档定义明确且每档有预期 CRB。2026-08-24 起补三条：S1 须含目标–nuisance 雅可比夹角旋钮并给出三档夹角的定义方式，S4 须含效率轴的测量方式与报告格式，pilot 数据契约须支持样本级 Fisher/CRB、增量信息、solver difficulty 和 Raw + DSP 双数据层。缺任一条不通过。

## 7. P3 · bench pilot、审计与候选晋级

### 7.1 阶段门

| 门        | 内容                                            | 不通过怎么办                          |
| -------- | --------------------------------------------- | ------------------------------- |
| G3-1     | 物理前向单测通过，含负对照                                 | 修正前向                            |
| G3-2     | Fisher/CRB 审计给出三档信息量刻度                        | 调整噪声与先验旋钮                       |
| G3-3     | 生成并冻结 pilot 数据；完成完整性校验与强基线充分性验证               | 修正生成链路，或退回 §6.1–6.3 重新设计        |
| **G3-4** | **C2–C4 最小证伪实验完成，至少 1 个算法机制取得 P4 晋级 verdict** | **没有候选晋级则返回 P1/P2 重新立项，不进入 P4** |
| G3-5     | 生成、打包并校验正式数据集                                 | 修正生成与打包链路                       |

### 7.2 G3-1 的负对照要求

tv3 的 MEI-3 B0 曾发现总量缩放的前向零方向。这类零方向必须在实现阶段排查，不能等到求解器或训练阶段才发现；具体数值见实验日志和冻结产物。

新 bench 的负对照清单至少包含：单组分扰动应改变输出、总量缩放的响应、各模态对各组分的灵敏度符号与量级。

### 7.3 G3-3 · 强基线充分性门

**内容**：先生成满足 G3-1/G3-2 契约的冻结 pilot 数据，再在目标信息档位运行 Ridge、GBDT、强表格模型（TabPFN 一类），确认它们与 oracle 上限之间留下的空档达到 P1 预注册阈值。

强表格基线**不是可选项**。P1 已确认树模型在多组分气体浓度回归中属于常规做法，因此只比 Ridge 不足以证明空档存在；文献与证据等级见 [P1 领地核查](docs/p1/07_视角7_相邻领域领地核查.md)。

**如果强基线打平 oracle 上限，bench 不合格，退回重新设计。**

这条门来自 sg4 历史实验的教训：不要在正式大规模训练之后才发现强基线已接近上限。纯前向审计应先于 pilot 数据；小规模强基线应先于正式数据集和 P4 大规模训练。

阈值在 P2 规格书里预注册，不在看到结果后调整。

### 7.4 G3-4 · 算法候选晋级门

C1 是评估框架，不计作算法候选。C2–C4 按 [P1 候选集](docs/p1/创新点候选集.md) 中冻结的最小证伪实验、收益门和淘汰条件执行。只有至少 1 个候选获得 `进入 P4` verdict，P4 才允许启动。

晋级记录必须包含：候选机制、对照、信息档位、paired 多 split 多 seed 结果、置信区间、负对照、停止原因和适用范围。没有候选晋级是阶段结论，不得以”先实现再观察”为理由绕过该门。

**候选处置（2026-08-24 关闭后审查，见 §5.4）。**

| 候选                     | 处置                  | 前置条件                                                                |
| ---------------------- | ------------------- | ------------------------------------------------------------------- |
| C2 变量投影展开              | 提为主候选               | 收益门须先完成修订（见下）；bench 须具备 §6.1 第五个旋钮                                  |
| C3 目标雅可比正交 discrepancy | 降至 P5 评估，不占 G3-4 名额 | 纯仿真 bench 上偏差由自己注入、再由自己去除，效果量可由注入幅度任意放大，不构成有效证据。该机制的价值须等 P5 的真实硬件数据 |
| C4 可辨识共享 / 私有表示        | 维持保留观察              | P3 须先证明该 bench 的跨模态互补性真实存在（§6.2 的 S2 近简并对），否则该候选没有对象                |
| C5 效率类候选               | 待立项                 | 见 §12 动作 6                                                          |

**修订程序：收益门不得静默改数。** P1 的候选集是冻结版，§6 明确写了不因后续结果回溯修改门值。C2 的门要改、C5 要新增，两件的性质都属于”设门时依据的先验被自有冻结证据推翻”，与”看到 P2 结果后调整目标”是两回事，因此走显式修订而非直接编辑。参照 MEI-4 收尾契约的做法，修订记录必须包含：

1. 原门值、修订后门值与两者差距
2. 触发修订的证据出处（此处为 `table6_solver_efficiency.csv` 与 `table7_structural_verification.csv`）
3. 修订不解除任何既有淘汰条件与领地约束的声明
4. 授权记录

未完成修订记录之前，C2 仍按原 `≥ 10%` 门执行；按 §5.4(b) 的分析，该门下 C2 大概率被判淘汰。这是记录本身的紧迫性所在，不是绕过它的理由。

## 8. P4 · 算法开发与仿真验证

### 8.1 子阶段

| 子阶段 | 内容                                              |
| --- | ----------------------------------------------- |
| 4-A | 基线矩阵：Ridge / TCN / 强表格模型 × 多 seed × 多 split 机制  |
| 4-B | 晋级算法实现（仅限通过 G3-4 的候选）                           |
| 4-C | 消融：每个机制单独开关，收益归因到具体机制                           |
| 4-D | 负对照：错误配对、顺序打乱、oracle 泄漏检查、同参数量随机结构              |
| 4-E | 信息谱扫描：算法在三档信息量上的表现曲线                            |
| 4-F | 跨场景复现：在 hydrogen_ng 或 syngas 上验证不是对单一 bench 过拟合 |

### 8.2 4-D 的同参数量对照

tv3 的模块 C 提供了模板：物理分组瓶颈必须与同参数量随机置换分组比较；该对照曾证明问题来自早期隔离而非容量。任何声称“结构带来收益”的结论，都要有同参数量随机结构对照。

### 8.3 4-E 是这一段的核心产出

结果有三种可能，都可发表：

- 算法在信息充足段有优势，临界段与不足段没有——说明算法解决的是估计效率问题
- 算法在临界段有优势——说明算法在信息边缘提取了额外结构，价值最高
- 全谱无优势——负结果，配合 CRB 说明"该观测下点估计已接近下界"，同样是完整结论

第三种情况不算失败。tv3 已经证明这类结论能写成完整论文。

### 8.4 报告纪律

沿用 tv3：预注册门、多 seed、多 split 机制分列不合并、真值量只进 oracle 审计、不改门重跑。不同 OOD 构造的数值不得合并成单一“OOD 性能”。

## 9. P5 · 应用背景筛选与实验规划

### 9.1 核心方法

**用 P2 建好的信息量审计工具反过来筛选应用场景。** 这一步把 tv3 的教训制度化：先审计，再投入。

### 9.2 流程

1. **候选场景清单**（M6 起并行建立）：以工业动态混合气在线质量控制为首批低风险候选，随后纳入生物反应器尾气、焊接保护气、金属增材制造保护气氛和热处理炉气氛；工业烟气、有毒混合气和合成气作为安全/设备条件满足后的备选
2. **纯前向可行性审计**：不生成数据、不训练，只算目标组分方向的 Fisher 有效信息、CRB，以及在可获得硬件精度下的 P90
3. **三重筛选**：信息充足 × 算法有用武之地 × 硬件可得
4. **硬件需求反推**：给定精度目标反推 TOF、温度、声程和衰减标定等硬件要求；具体阈值由候选场景的前向审计生成，不从 tv3 直接复制
5. **实验规划**：硬件清单、标定方案、数据采集协议、sim-to-real 评估设计

### 9.3 第 2 步的成本

tv3 的工程基准表明，纯前向审计的成本远低于一次正式训练。该基准只用于排期，不在本规划维护具体计时数字；候选清单可以放宽，筛选应在训练前完成。

### 9.4 阶段门

选定场景 + 硬件清单 + 采集协议，且该场景的前向审计显示目标精度在可获得硬件下可达。

## 11. 从 tv3 继承的工作纪律

这些是跨多个实验重复验证过的，直接沿用，不重新讨论。

**N1 · 先算信息量，再谈模型。** MRS 线的顺序是模板：纯前向 Fisher 审计判生死，通过了才允许生成 pilot 数据和训练。MRS-2 未过门后停止了后续数据与训练；相比之下 D2、E1 都是先训练再发现前端不成立。

**N2 · 负对照要先于正结果。** 总量缩放零方向、同参数量随机置换分组、单频负对照和正对照检查，都用于在正式结论前排除伪信号。

**N3 · 结论要写清楚适用范围。** "D2 失败"限定为该实现，不是所有波形路线；"模块 C 失败"限定为"各组独立压到 16 维"，不是所有物理引导结构。范围写窄，后面才不会误伤能做的方向。

**N4 · 冻结之后要做一次一致性审查。** MEI-4 把 24 条覆盖带、拒绝语义、抽样规模全部预注册，但没人检查"M2b 有没有登记 SBC/PPC"，跑到 C3 才发现目标 verdict 结构上不可达。每个可能的 verdict 都要有可达路径。

**N5 · 单位和量级问题会伪装成结构问题。** D2 的辅助损失量纲不匹配、R5 的目标未标准化都曾表现为“模型学不动”。MEI-1 的正确口径是设计跨度 `0.4565% / 0.6725%` 高于数值保护带、低于实践保护带，不得再写成“0.71% 低于数值保护带”。多目标回归先检查量纲、尺度和门的口径，再讨论结构。

**N6 · 便宜的诊断优先。** E1d 用 Ridge 探针逐级累加特征，几分钟就定位到 SNR 是信息缺口。相比之下 F5-wide、E1 各花掉一次完整的服务器训练。

**N7 · 一个数不要在两个地方维护。** 项目状态曾在 6 处并行维护，导致按过时前提做决策。当前保持两个入口：契约事实源（硬约束）与实验日志（经验）。新 bench 建立时同样只设两个入口。

**N8 · 失败必须分解到机制才算完成。** 有机制的失败能指出下一步改什么，没机制的失败只能重跑。MEI-4 C2 最初只记录“均未过主覆盖带”，后续才定位到切空间质量大量落在物理域外，根因是先验规格不一致。P3/P4 的失败报告必须同时登记现象、机制、适用范围和停止理由。
