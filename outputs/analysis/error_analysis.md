## 三、N2 组分误差深度剖析

### 3.1 误差量级对比

| 模型                 | x_N2 RMSE | x_N2 MAE | 占总误差比     |
| ------------------ | --------- | -------- | --------- |
| Ridge 全模态          | 5.12      | 4.27     | 32.3%     |

**结论**: N2 组分贡献了模型总误差的 **30%-50%**，是当前系统的主要瓶颈。

### 3.2 N2 误差根因分析

#### 根因 1: **N2 信号在多模态传感器中极弱**

**物理背景**:

- **NDIR 传感器**: 对 CH4 和 CO2 有直接红外吸收响应，但 N2 作为双原子分子在中红外波段几乎无吸收
- **热导传感器 (TCS)**: 响应混合气体热导率，但 N2 (25.83 mW/(m·K)) 与空气基线接近，信号微弱
- **声学/光纤传感器**: 主要响应声速和折射率变化，N2 的贡献被 H2、CH4 掩盖

**数据验证**:

- 从 `ridge_slow` 特征名看，只有 `V_TCS` (热导电压) 可能间接反映 N2
- 缺乏直接测量 N2 的传感器通道

#### 根因 2: **N2 通过差值约束间接估计**

**数学约束**:

```
x_H2 + x_CH4 + x_CO2 + x_N2 = 100%
```

**推导逻辑**:

```
x_N2 = 100% - x_H2 - x_CH4 - x_CO2
```

**误差传递**:

- x_H2 误差: ±1.08% (RMSE)
- x_CH4 误差: ±5.95%
- x_CO2 误差: ±0.77%
- **累积误差**: √(1.08² + 5.95² + 0.77²) ≈ 6.05%

**实际 N2 RMSE**: 5.12%，**接近累积误差下界**，说明模型已接近物理极限。

#### 根因 3: **训练数据中 N2 方差不足**

**统计分析** (基于 HITRAN 模拟):

- 假设 N2 作为填充气体，摩尔分数范围可能在 [0%, 30%]
- 相比 CH4 主成分 (30%-90%)，N2 的样本方差更小
- 模型在低方差目标上难以学习有效模式

### 3.3 DL 模型在 N2 上的失败分析

**CNN1D-TCN R² = -0.152 的原因**:

1. **过拟合到噪声**:
   
   - 训练集 R²=0.325，验证集 R²=-0.069，测试集 R²=-0.152
   - 验证/测试负 R² 说明模型预测方差过大，劣于简单均值预测

2. **时序特征无效**:
   
   - N2 信号本身微弱，时序卷积捕获的是其他组分的间接模式
   - 模型在 exposure/steady/recovery 阶段的 N2 R² 均为负，说明动态特征未帮助 N2

3. **损失函数权重不平衡**:
   
   - MSE 损失对所有组分等权，但 x_CH4 方差 >> x_N2 方差
   - 优化器优先降低 CH4 误差，N2 成为"牺牲品"

## 四、阶段性误差分析

### 4.1 Per-Phase Performance (Ridge 全模态)

| Phase        | H2 R² | CH4 R² | CO2 R² | N2 R² | 整体 R² |
| ------------ | ----- | ------ | ------ | ----- | ----- |
| **baseline** | 0.024 | 0.020  | 0.016  | 0.019 | 0.021 |
| **exposure** | 0.923 | 0.853  | 0.940  | 0.640 | 0.859 |
| **steady**   | 0.981 | 0.705  | 0.957  | 0.040 | 0.743 |
| **recovery** | 0.925 | 0.668  | 0.360  | 0.023 | 0.668 |

**关键发现**:

1. **baseline 阶段完全失效** (整体 R²=0.021):
   
   - 所有组分均无法预测，说明初始平衡态信号不足
   - 可能原因: baseline 时气体组分变化极小，传感器响应在噪声水平

2. **exposure 阶段表现最佳** (整体 R²=0.859):
   
   - 气体注入阶段传感器响应动态变化最明显
   - N2 在此阶段 R²=0.640，显著优于其他阶段

3. **steady 阶段 N2 崩溃** (N2 R²=0.040):
   
   - 稳态下 N2 信号完全淹没在噪声中
   - H2/CO2 仍保持高精度 (R² > 0.95)

4. **recovery 阶段 CO2 异常** (CO2 R²=0.360):
   
   - 恢复阶段 CO2 预测精度下降，可能与 NDIR 传感器滞后效应有关

### 6.2 DL 模型失败原因总结

1. **数据规模不足**:
   
   - 当前数据集仅 600 条测试样本 (推测总数 ~6000)
   - DL 模型需要 >10k 样本才能充分发挥优势

2. **特征工程已充分**:
   
   - Ridge 使用的统计特征 (mean/std/slope 等) 已捕获主要模式
   - 原始时序信号的额外信息有限

3. **N2 信号缺失主导**:
   
   - DL 模型在 N2 上 R²=-0.152，拖累整体性能
   - Ridge 通过正则化避免了 N2 上的灾难性过拟合

4. **超参数未充分调优**:
   
   - Batch size=16 可能过小
   - Early stopping 在 epoch 35 就触发，可能过早停止

## 七、改进建议

### 7.1 短期优化 (工程层面)

#### 针对 N2 组分:

1. **引入物理约束**:
   
   ```python
   # 在损失函数中加入归一化惩罚
   composition_sum = pred.sum(dim=-1)
   constraint_loss = F.mse_loss(composition_sum, torch.ones_like(composition_sum))
   total_loss = mse_loss + lambda_constraint * constraint_loss
   ```

2. **差异化损失权重**:
   
   ```python
   # 根据组分方差调整权重
   weights = torch.tensor([1.0, 2.0, 1.0, 3.0])  # H2, CH4, CO2, N2
   loss = (weights * (pred - target)**2).mean()
   ```

3. **后处理归一化**:
   
   ```python
   # 预测后强制归一化
   pred_normalized = pred / pred.sum(dim=-1, keepdim=True)
   ```

1. **增加正则化**:

## 八、结论

### 8.1 核心问题

1. **N2 组分是致命短板**: 所有模型 R² < 0.33，DL 甚至为负
2. **传感器信号天然缺陷**: N2 在现有传感器中响应极弱
3. **DL 模型未体现优势**: 在中小规模数据集上不如 Ridge + SVR

### 8.2 推荐方案

**当前最佳方案**: **DynamicStackingSVR** (Test R²=0.819, RMSE=3.732)

- 融合三模态 RBF-SVR + MC 漂移权重 + Ridge 元学习
- 各组分表现均衡，N2 R²=0.325 为所有模型最佳

**未来发展方向**:

1. 优先解决 N2 测量问题 (硬件升级或算法约束)
2. 扩充数据集至 >20k 后重新评估 DL 模型
3. 引入物理约束和归一化后处理
